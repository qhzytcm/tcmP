# 竖排古籍阅读顺序重建（32 开民国铅印本）

> 本文是**版式层**方法论。核心心法：**"文本乱"往往是"顺序错"，不是"识别错"** ——
> 先怀疑自己的版式模型，再怀疑 OCR 字形。

## 触发条件

- OCR 竖排古籍后出现：文字跨条目串接、条目缺头少尾、笔画序/目录序大量违规；
- 想当然地"按字认错"加校字规则，**收效有限**；
- 需要据此生成可读的校勘底稿。

---

## 〇、分步流水线（**必须按此顺序，不可跳步**）

> 用户铁律：**"列阅读 → 繁转简（仍维持原印刷排版）→ 校正文本内容 → 之后才考虑横行排版"
> 否则乱码内容混乱难以避免。"**

| 步 | 内容 | 输出 | 关键约束 |
|---|---|---|---|
| **1** | **列阅读** —— 按本技能重排阅读序（栏→列→字）| `03-bycd-校勘底本.docx`（**繁体原文**）| **保留原印刷排版**；逐栏逐列列出，供逐字对照扫描件 |
| **2** | **繁→简** | `03-bycd-校勘底本（简体）.docx` | **仍维持原印刷排版**（栏/列数逐页一致）；**只转字形，不动结构** |
| **3** | **校正文本内容** | `03-bycd-LLM校本文.docx` | 语义校勘（补标点/正讹字）；**仍按栏列结构呈现** |
| **4** | **横行排版**（最后才做）| 16 开双栏等 | 须待 1–3 完成 |

**⚠️ 为什么顺序不能颠倒**：
- 跳过 1 → 文字串栏，后续全错；
- 跳过 2 直接校 → 简繁夹杂，讹字与繁体难分；
- 跳过 3 直接横排 → **栏列边界一丢，"哪段属于哪条"就无从纠正**，乱码无法回查。

**验证各步**：
- 步 1↔2：**栏/列块计数逐页一致**（实测 1168 页 · 3521 栏块 · 62871 列，两版相同），抽页列数相同（如 p60 均 52 列）；
- 步 2：抽样确认字形已转（`當歸→当归`、`養血→养血`、`補氣→补气`）而**列边界未变**；
- 步 3：长度比 + 新增汉字率 + **白名单回改**（双向护栏）。

## 〇·补 步4 横行排版（16开·双栏·简体·五号仿宋·页码升序·笔画索引）

**前置**：步 1–3 完成后才做（见「〇、分步流水线」）。

**规格 → 实现**（可复用 `s11_docx.py` 的排版原语）：

| 规格 | 实现 | 核验方法 |
|---|---|---|
| **16 开** 196.75×273mm | `sec.page_width/height = Mm(196.75), Mm(273)` | 查 `w:pgSz w:w="11154" w:h="15477"`（twips ÷ **56.7** = mm）|
| **双栏** | `set_columns(section, 2)` → `w:cols w:num="2" w:equalWidth="1"` | 查 `w:cols` |
| **五号仿宋** | `set_style_font(style,'仿宋',10.5)` + `_set_font` | `w:sz w:val="21"`（half-pt；21=10.5pt=五号）|
| **页码升序** | 页脚插 `PAGE` 域 | 域在**独立 footer1.xml**（document.xml 里搜不到，勿误判）|
| **索引真实页码** | 每词条插**书签** + 索引用 `PAGEREF` 域 | 域缓存文本即真实页码 |
| **笔画索引** | 按 `(首字笔画,首字码位,次字笔画,…)` 升序分组 | 首字笔画**单调不减**校验 |

**⚠️ 关键：域必须用 Word COM 更新**（python-docx 不会计算页码）：
```python
app = win32.gencache.EnsureDispatch('Word.Application'); app.Visible = False
doc = app.Documents.Open(path); doc.Fields.Update()
for s in doc.Sections: s.Footers(1).Range.Fields.Update()
doc.Repaginate(); doc.Save(); doc.ExportAsFixedFormat(pdf, 17)
```
实测：**3904 域 · 1–2 秒更新完 · 687 页**（3899 词条·16开双栏）。

**⚠️「病名待定」必须单独成组**：三段论拆分产生的无名词条（本项目 **1747/3899 = 45%**）
若按名排序，首字「病」= 10 画 → **10 画段从百余条暴增到 1897 条**，笔画索取废。
→ 解法：**有名条目按笔画排，待定条目置于末尾并单列「〔病名待定〕」组**。

**索引位置的经验**：索引置于**正文之前**时，3899 条索引 ≈ **占 160 余页**，
正文首条落在 **P166**；若希望正文靠前，应把索引**移到正文之后**（一行改动）。

## 一、书的阅读——倒翻页

传统装订为**右开本**：书脊在右，**从后往前翻页**（自右向左翻）。

- 阅读推进方向：**页序在视觉上由右向左**；
- 落实到扫描件：**扫描页序即阅读序**（扫描仪按装订序逐页拍），但**页内**是竖排右起；
- 若原书有**双面印刷折叠**（见第三节），扫描页与"书页"可能是 N:1 关系 —— **先确认再切分**。

## 二、书内容分部分（部件序列）

同一部书的**部件顺序是固定的**，可用来给扫描页分段、定编码区间。以《病源辞典》为例（**实测**）：

| # | 部件 | 扫描页 | 原书编码 | 版式 |
|---|---|---|---|---|
| 0 | 出版页／题词页／秦序／自序／大众万病头问／凡例／温灸学讲义（广告） | 0–11（12 页）| — | 竖排 |
| 1 | **病名目录** | 12–58（**47 页**）| **目录 01–47** | **每页 4 栏** |
| 2 | **病名正文**（按繁体笔画排序） | 59–1176（1118 页）| **正文 0001–1118** | **每页 3 栏** |
| 3 | 增补 | 1177–1179（3 页）| **1119–1121** | 3 栏 |
| 4 | 尾页 | 1180–1181 | — | — |

**合计 12+47+1118+3+2 = 1182** = 扫描总页数 ✓ **必须做这个算术闭合校验**。

**分段判据（可靠）**：**数"三段标记"密度**，不要数"【 个数"。
- 目录页：`病源/病状/治法` 合计 **0–1**；正文首页：**7+** ✓
- 【 个数会被"括号误认"骗过（见第六节陷阱 2）

## 三、页眉页尾识别（中缝对开双页）

**版式**：32 开铅印、**一套中缝对开双页**为一印刷单元：

```
        ┌──────────┬──────────┐
        │  后页    │  前页    │
        │ (中缝左)  │ (中缝右)  │
   页尾 │  正文…   ‖  正文…   │ 页眉
        └──────────┴──────────┘
             ↑ 中缝处无页眉无页尾
```

- **前页** = 中缝**右侧**页 → 带**页眉**（书眉在它**右边缘**）
- **后页** = 中缝**左侧**页 → 带**页尾**（书眉在它**左边缘**）
- **中缝处**（版心）**无页眉无页尾**

**书眉内容格式**：`病源辞典 + <笔画数> + <首字> + <页码编号>`
> 实测例：`病源辞典 二画 丁 0001`；p60 书眉 OCR 作 `病源爵典 二七` = 病源辞典 **二**[画] **七**[疝]…

**⭐ 判定铁律：以「中缝」为基准，不要用"奇左偶右"**

| 观测到书眉在哪端 | ⟹ 中缝在 | ⟹ 本页是 | 携带 |
|---|---|---|---|
| **右边缘** | 左 | **前页**（中缝右侧页）| **页眉** |
| **左边缘** | 右 | **后页**（中缝左侧页）| **页尾** |
| **两端皆有** | 居中 | 该扫描页含**对开双页** | 页眉+页尾 |

> ⚠️ **不要用"奇数页在左、偶数页在右"这类奇偶规律** —— 实测该相位会在**区段间漂移**
> （目录区 `p13右/p14左/p15右…`，正文区自 p69 起才交替且**相位相反**），且存在**异常页**（如 p59/p61 两端皆有）。
> **只有"以中缝为基准"的判据才稳定**：找到书眉所在边缘 → **其对边即中缝** → 由中缝定前后页。

**实现**（`s64_layout_book.py`）：
```python
hs = [(cx, t) for cx, cy, t in L
      if len(t) <= 14 and any(k in t for k in BOOKNAME_V)]   # 精确白名单！勿用单字松匹配
band = (xmax - xmin) * 0.12
lefts  = [t for cx, t in hs if cx <= xmin + band]
rights = [t for cx, t in hs if cx >= xmax - band]
if lefts and rights: kind, zhongfeng = '双页', '居中(对开双页)'
elif rights:         kind, zhongfeng = '前页', '左'      # 书眉在右 → 中缝在左
elif lefts:          kind, zhongfeng = '后页', '右'      # 书眉在左 → 中缝在右
```
> ⚠️ **书眉识别必须用精确白名单**（`BOOKNAME_V`）。用单字松匹配（如含 `源`+`群/解/路`）
> 会把正文「病源**群**見乐痣條」误判成书眉 → 实测误判 26 页。

**实测结果**：前页 **540** · 后页 **544** · 对开双页 **1**（p59）· 未判 83（空白页/书眉未识别）。

## 四、每页阅读顺序

**第一步：判定本页横向分栏数**

| 区段 | 栏数 | 栏名（自上而下）|
|---|---|---|
| **目录**（每页 4 栏）| **4** | 上栏 → 中上栏 → 中下栏 → 下栏 |
| **正文**（每页 3 栏）| **3** | 上栏 → 中栏 → 下栏 |

**第二步：栏序自上而下**（上栏读尽再读下栏）

> ⚠️ **这是最易错的一层**。把整页当成"一根扁平列序"是最常见的致命错误 —— 会把不同栏的文本**混读**成一句。

**实现**：按行 y 坐标把本页切 nbands 段：
```python
nb = 4 if 12 <= pg <= 58 else 3          # 目录 4 栏 / 正文 3 栏
ymin, ymax = min(ys), max(ys); span = ymax - ymin
for b in range(nb):
    lo = ymin + span * b / nb
    seg = [行 for 行 in L if 行.y >= lo and (行.y < ymin+span*(b+1)/nb if b < nb-1 else True)]
    ...                                   # 该栏内再排序（见第五节）
```

## 五、每栏阅读顺序

栏内是**竖排窄列**，一堆并列：

1. **栏内 N 列：从右往左**（x 降序）
2. **每列内：从上往下**（y 升序）
3. 排版细节：
   - `【病名】` **退 2 字符**（缩进）起排；
   - 正文**顶列排列**（从列首开始）；
   - 三段结构以 **`[病源]…[病状]…[治法]…`** 呈现；
   - 原书**无标点**，需**读懂后合理追加标点**。

**实现**（列聚类 + 双排序）：
```python
cols = []
for cx, cy, t in sorted(seg, key=lambda z: -z[0]):      # 右→左
    for c in cols:
        if abs(c['cx'] - cx) < xthr:                    # xthr≈45（≈字宽）
            c['segs'].append((cy, t)); break
    else:
        cols.append({'cx': cx, 'segs': [(cy, t)]})
cols.sort(key=lambda c: -c['cx'])                       # 列序右→左
text = [''.join(t for _, t in sorted(c['segs'])) for c in cols]   # 列内上→下
```

## 六、陷阱清单（血泪实测）

1. **⚡ 扁平整页读 = 全盘错序**：必须先分栏。一步修复带来
   单元数 2972→3934（≈原著"四千有余条"）、三段齐备率 48.9%→62.2% 的**质变**。
2. **⚡ 括号会被 OCR 误认/吞掉**：`【丁疤】` 可能成 `（丁疤】`（左括号误认）或 `丁笑雅】`（左括号**整只消失**）
   → 切分器须能**补回**：正则 `名(?=病达|病状|病源|治法)` 或 `名】` → `【名】`，
   **且须在名称归一之前执行**，用**函数式 `sub`** 按匹配分流。
3. **⚡ 判"正文起点"用三段标记密度，不要用【 个数**（见第二节）。
4. **⚡ 目录不能混入正文切分**：目录是"病名+页码"清单，混入会污染条目 → **目录流与正文流分开构建**。
5. **⚡ 段落 y 分栏要按本页 ymin/ymax 动态算**，不要用绝对坐标（每页扫描偏移不同）。
6. **页眉书名讹形极多**：`病源典／病源醉典／荆源静典／桐源许典／润源鲜典…` →
   用**白名单 + 长串优先**归一（**勿用泛化正则**，会误伤正文）。
7. **可用"0 次字"作强信号**：某字全书 0 次而形近字高频（`疳`=0/`丁笑`=15、`痂`=0/`丁皮`=1）
   → 该字被系统性误认，正字必在其中。

## 七、验证方法（务必做）

| 校验 | 做法 |
|---|---|
| **算术闭合** | Σ各段页数 = 扫描总页数（本例 12+47+1118+3+2 = 1182）|
| **编码递增** | 抽查书眉序号逐页 +1 无缺号（本例 `目录NN = 扫描页 − 11`，p14→03 · p58→47）|
| **页眉左右交替** | 抽查 10+ 页，确认**以中缝为基准**的前/后页判定一致（**勿用奇偶规律**）|
| **首条锚定** | 请领域专家/目录核对**二画段首名**（本例 丁疤 ①→ 丁奚疳 ②→ 丁痂皮 ③→ 七疝 ④→ 七星赶月疔 ⑤）|
| **三段齐备率** | 修复前后对比（本例 48.9% → 62.2%）|

> **最强手段：请用户/专家逐条报"第 N 个病名"** —— 5 轮就验出 **7 类系统缺陷**
> （起始页判错／括号被吞／字形被吞／字形误认／排序错乱／书名讹形／页眉页尾分置）。

## 八、与下游的衔接

- **底本一改，下游全部失效**：改版式/校字规则前，**先停下游任务（LLM 矫正等）、清锁**，
  重生成后再重启。**绝不可"边改底本边跑下游"**。
- 追加式长任务**必须加单实例锁**（并发写同一 JSONL 会把文件写坏）。
  ⚠️ Windows 上 `os.kill(pid,0)` 探测进程不可靠（抛 `WinError 87`，会被误判为"陈旧锁"而放行）
  → 锁策略用「**锁文件存在即拒绝**」+ `--force-unlock` 逃生阀。
