# 检索查询改写提示词（主诉 → 双路查询）

> 适用：医者/患者 Agent 在调用 `/semantic-search` 前，把用户口语主诉归一化为可检索的双路查询。
> 原则：**语义词保留语义密度，精确词保留词面特征**——两路各司其职，融合才有意义。

## 模板

```
用户主诉：{chief_complaint}

请改写为双路检索查询：

1. **语义词**（≤12 词，空格分隔）：提取核心症状词，用病证库常用表述
   替换口语（如「翻来覆去睡不着」→「难以入睡 多梦易醒」），
   保留症状的辨识度（程度、部位、诱因）

2. **精确词**（≤6 词，空格分隔）：从主诉中抽取可与库内文本精确匹配的
   名词性片段（病名、证候名、方剂名、专有症状）

输出 JSON：
{"semantic": "...", "keyword": "..."}
```

## 示例

| 主诉 | 语义词 | 精确词 |
|------|--------|--------|
| 最近总是睡不着，翻来覆去，还容易醒，心里烦躁 | 难以入睡 多梦易醒 心烦不安 | 失眠 多梦 |
| 天一冷就喘，喉咙里有声音，痰是白色的沫 | 呼吸急促 喉中哮鸣 咳痰清稀 遇寒加重 | 哮喘 冷哮 |
| 左边脑袋一跳一跳地疼，恶心想吐 | 偏侧搏动性头痛 恶心 胀痛 | 偏头痛 |

## 改写质量自检

- [ ] 语义词：症状可辨识（避免单字泛词「痛」「热」）
- [ ] 精确词：来自主诉原词，非翻译改写
- [ ] 语义词与精确词有区分（不是同一批词的复制）
- [ ] 输出为合法 JSON，两字段均非空

## 与检索链路的配合

```text
口语主诉 → [本提示词] → {semantic, keyword}
   → 向量路: /semantic-search?q={semantic}
   → 关键词路: 倒排/FTS 精确召回 {keyword}
   → RRF 融合 → Top-K → 鉴别诊断（Lesson 1 的 prompt-differential-diagnosis）
```
