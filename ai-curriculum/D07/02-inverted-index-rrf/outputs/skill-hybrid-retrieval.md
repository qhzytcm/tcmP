# 混合检索策略（Hybrid Retrieval）

> 口诀：**语义找候选，关键词验命中，融合定排名。**
> 向量检索抓"意思相近"，关键词检索抓"词面精确"，两路互补没有银弹——平台 `/semantic-search` 内部就是 TF-IDF 向量 + FTS5 关键词 + RRF 融合。

## 触发条件

- 检索结果疑似遗漏（关键词表述与库内不一致）
- 需要区分词面重叠的跨病种干扰（如「失眠多梦」同见于失眠与高血压）
- 查询含专有名词（方剂名、药名、证候名）——这些词精确命中价值极高
- 用户主诉是口语化长句，需要先改写再检索

## 决策表：什么时候用哪一路

| 查询特征 | 示例 | 主导路 | 理由 |
|---------|------|:------:|------|
| 口语症状描述 | 翻来覆去睡不着、心里烦 | 向量 | 语义相似，词面稀疏 |
| 专有名词 | 麻黄汤、黄连阿胶汤、心肾不交证 | 关键词 | 精确词面，倒排秒中 |
| 长句主诉 | 最近总头痛，一跳一跳的还恶心 | 先改写 → 双路 | 混合 |
| 短症状组合 | 恶寒、无汗、头身疼痛 | 双路 | 词面+语义都强 |

## 标准流程

### 1. 查询改写：主诉 → 双路查询

```
口语主诉: "最近总是睡不着，翻来覆去，还容易醒"
语义词  : "难以入睡 多梦易醒 心烦不安"   → 向量路（语义匹配）
精确词  : "失眠 多梦"                   → 关键词路（词面命中）
```

### 2. 双路检索

```bash
# 向量路（语义）
curl "https://www.zyyywaccn.com.cn/api/sages/semantic-search?q=难以入睡%20多梦易醒%20心烦不安&top_k=5"
# 关键词路（精确）——生产引擎内部为 FTS5；教学实现见 02-inverted-index-rrf/code/main.py
python code/main.py "失眠 多梦" --data ../../tcmP/kg/samples
```

### 3. RRF 融合判读

两路结果按名次融合：`score = Σ 1/(60 + rank_i)`。

| 融合模式 | 含义 | 处置 |
|---------|------|------|
| 向量+关键词双命中 | 语义与词面互相印证 | 高置信，优先呈现 |
| 仅向量命中 | 语义相似但表述不同 | 中置信，提示"可能相关" |
| 仅关键词命中 | 词面精确但语义一般 | 中置信（专名场景反更高） |
| 两路均未命中 | 无证据 | 声明"证据不足"，转人工 |

### 4. 跨病种干扰处理

「失眠多梦」同见于失眠（心肾不交）与高血压（肝阳上亢）时：
- 追加区分性症状词（如「腰膝酸软」→ 偏向失眠肾虚；「头胀面红」→ 偏向高血压）
- 交叉验证：检索结果是否与主诉的其他症状一致

## 常见错误

1. **只信一路**：纯关键词漏语义（「难以入睡」搜不到「失眠多梦」）；纯向量漏精确（「麻黄汤」被泛词稀释）
2. **融合后不看命中标记**：把「仅关键词」当成「双路印证」——参考上面的置信度表
3. **对 FTS 0 惊慌**：FTS5 默认分词器对中文整段切词导致短语匹配常空手，属正常现象，向量路兜底

## 验证

```bash

# 期望：1. [RRF ... | 向量+关键词] 原发性失眠（慢性失眠障碍）(7A00)
```
