# 鉴别诊断提示词（基于病证检索 Top-K）

> 适用：医者 Agent 拿到 `/semantic-search` 的 Top-K 结果后，生成规范化鉴别诊断。
> 原则：**LLM 只消费检索结果，不凭空编造病证**——所有结论必须锚定在 Top-K 条目上。

## 模板

```
患者主诉症状：{symptoms}

病证单元库检索 Top-{k} 结果（检索证据，非诊断结论）：
{retrieved_items}

请基于以上检索结果，输出：

1. **最可能的病证组合**：疾病名（ICD-11 编码）+ 中医证候，并说明为何首选
2. **鉴别要点**：其余候选为何可能性较低（对比关键症状差异）
3. **证据局限**：检索证据的不足（如症状词面重叠、证据等级 A/B/C）
4. **建议**：下一步（补充四诊信息 / 转诊科室 / 可考虑的方剂方向，注明须医师确认）

约束：
- 只允许引用检索结果中出现的疾病与证候，不得引入检索结果之外的新病种
- 若 Top-K 分数普遍低于 0.05，明确声明"证据不足，建议线下就诊"
- 中医诊断不得脱离四诊合参，检索结果仅供辅助
```

## 字段说明

| 占位符 | 来源 | 示例 |
|--------|------|------|
| `{symptoms}` | 用户归一化主诉 | 难以入睡 多梦易醒 心烦不安 |
| `{retrieved_items}` | `/semantic-search` 返回的 results | [1] 原发性失眠（7A00）— 心肾不交证 → 黄连阿胶汤合交泰丸 |
| `{k}` | top_k 参数 | 5 |

## 使用示例（完整调用链）

```bash
# 1. 检索
curl "https://www.zyyywaccn.com.cn/semantic-search?q=难以入睡%20多梦易醒%20心烦不安&top_k=5" -o hits.json

# 2. 将 hits.json 的 results 填入模板 {retrieved_items}，连同 {symptoms} 发给 LLM
# 3. LLM 输出按模板 1-4 节格式化报告
```

## 质量自检（LLM 输出后）

- [ ] 报告中每个病名都能在检索结果中找到出处
- [ ] 有明确的鉴别对比，而非罗列
- [ ] 包含"须医师确认/四诊合参"的免责约束
- [ ] 低分证据时给出"证据不足"声明
