# 病证检索助手（DSU Retrieval）

> 用法口诀：**先检索，再判断；拿证据，再开方。**
> 检索是平台一切智能问答的地基——本技能封装 tcmP 病证单元检索端点的标准调用方式。

## 触发条件

- 用户给出症状、病名或证候描述，需要匹配病证单元（病+证）
- 医者需要鉴别诊断候选清单
- 患者自述症状需要导诊建议
- 教学需要检索相似病证案例

## 标准流程

### 1. 归一化查询

将用户描述整理为症状关键词列表（空格分隔，≤12 词），优先保留**主诉症状**：

```
输入: "最近总是睡不着，翻来覆去，还容易醒，心里烦躁"
查询: "难以入睡 多梦易醒 心烦不安"
```

### 2. 调用检索端点

```bash
curl "https://www.zyyywaccn.com.cn/semantic-search?q=难以入睡%20多梦易醒%20心烦不安&top_k=5"
```

本地调试：

```bash
python tcmP/scripts/tcm_embed.py 难以入睡 多梦易醒 心烦 --mode diagnose --top-k 5
```

### 3. 解读结果（证据意识）

| 返回字段 | 含义 | 使用要点 |
|---------|------|---------|
| `disease` / `icd11_code` | 病侧 | 西医病名 + ICD-11 编码，可再走 `/icd` 桥接 |
| `syndrome` / `pattern_type` | 证侧 | 中医证候，八纲/脏腑/六经属性 |
| `formula` | 临床 | 推荐方剂（注意：仅检索结果，须由医师核验） |
| `evidence` | 证据 | 向量分数 + FTS 命中情况，低分结果谨慎采纳 |

### 4. 组合判断（不在本技能范围内，但必须交代）

- 检索结果 ≠ 诊断结论：Top-K 是**候选**，辨证需结合舌脉四诊
- 相似症状跨病种（如「失眠多梦」同见于失眠心肾不交与高血压肝阳上亢）——用更多症状词细化，或转医者/辨证流程

## 常见错误

1. **把检索当诊断**：直接告诉用户"你得的是 X"——禁止。应输出"相似病证候选 + 建议就医/进一步辨证"
2. **一次只给一个词**：单症状召回太宽（如"痛"），至少 2-4 个症状词组合
3. **忽略证据分数**：score < 0.05 的结果视为噪声，不要引用
4. **超长查询**：>12 个词会被截断，先压缩主诉

## 验证

```bash
# 患者端示例
curl "https://www.zyyywaccn.com.cn/semantic-search?q=恶寒重%20发热轻%20无汗&top_k=1"
# 期望：Top1 普通感冒（风寒束表证）→ 麻黄汤
```
