## 情境导入

小李跟师出诊，遇到两位患者都主诉"头痛"：

第一位张先生，头痛剧烈、怕冷、发热、无汗、脉浮紧。第二位王女士，头痛绵绵、头晕眼花、面色苍白、心悸失眠、脉细弱。

小李困惑了——都是头痛，为什么表现如此不同？老师告诉他："四诊所收集的症状和体征就像散落的拼图碎片，辨证就是把这些碎片拼成完整的病机图像。第一位是外感风寒的表证、实证，第二位则是一派虚象——具体是哪种虚证，等我们学到脏腑辨证时再来揭晓。"

本章学习的四种辨证方法，就是中医"拼图"的四种经典框架。

## 第一节 辨证概述

### 一、什么是辨证

**辨证**，即辨析证候，是将四诊（望、闻、问、切）收集到的症状、体征等临床资料，在中医理论指导下进行分析、综合，辨清疾病的病因、病位、病性及邪正关系，概括判断为某种证候的思维过程。

"证"不同于"症"和"病"：

| 概念 | 含义 | 举例 |
|------|------|------|
| **症** | 患者主观感觉或客观表现（单一症状/体征） | 头痛、发热、舌红、脉数 |
| **证** | 疾病某一阶段病因、病位、病性、病势的综合概括 | 风寒束表证、肝阳上亢证 |
| **病** | 疾病发生发展全过程的特点与规律 | 感冒、咳嗽、胃痛 |

> **核心理解**："症"是现象，"证"是本质，"病"是全程。辨证就是从"症"到"证"的推理过程。

### 二、辨证与诊法的关系

```
四诊（信息采集）────────→ 辨证（信息处理）────────→ 论治（决策执行）
      │                          │                          │
  望·闻·问·切              八纲·脏腑·六经等           治则·方药·针灸等
      │                          │                          │
  第11-13章内容                ← 本章内容 →              第15-19章内容
```

四诊为辨证提供**原材料**，辨证的质量取决于四诊资料的**全面性**和**准确性**——"四诊合参"是辨证的前提。

### 三、辨证方法的分类

中医在数千年发展过程中形成了多种辨证方法，各有侧重、互为补充：

| 辨证方法 | 创始人/出处 | 核心维度 | 适用范围 |
|----------|------------|---------|---------|
| 八纲辨证 | 《内经》奠基，明清成熟 | 表里、寒热、虚实、阴阳 | 各类疾病的纲领性辨证 |
| 脏腑辨证 | 《内经》《金匮要略》 | 五脏六腑定位 + 八纲定性 | 内伤杂病 |
| 六经辨证 | 张仲景《伤寒论》 | 六经层次传变 | 外感风寒（伤寒） |
| 卫气营血辨证 | 叶天士《温热论》 | 卫→气→营→血层次 | 外感温热病 |
| 气血津液辨证 | 历代发展 | 气血津液的盛衰 | 与脏腑辨证互补 |
| 三焦辨证 | 吴鞠通《温病条辨》 | 上→中→下三焦传变 | 湿热病 |

> **学习策略**：八纲是总纲，其他辨证方法是在八纲基础上的深化和具体化。先学八纲建立框架，再学各法充实内容。
>
> **说明**：气血津液辨证以气血津液的盈虚与运行失常为纲，常与脏腑辨证配合使用；三焦辨证以上、中、下三焦为纲归纳湿热病的传变。二者在本章仅作概述性提示，详细内容见后续《中医内科学》《温病学》等专业教材。

## 第二节 八纲辨证

八纲辨证是将四诊资料归纳为**表里、寒热、虚实、阴阳**四对纲领性证候的辨证方法，是各种辨证方法的**总纲**。

### 一、表里——判断病位深浅

表里是辨别病位内外深浅的一对纲领。

#### （一）表证

**概念**：外邪经皮毛、口鼻侵入人体肌表，正气抗邪于表所产生的证候。多见于外感病的**初期**。

**临床表现**：
- 主症：发热恶寒（或恶风）并见，头身疼痛
- 舌脉：舌苔薄白，脉浮
- 兼症：鼻塞流涕、喷嚏、咽喉痒痛、咳嗽

**特点**：起病急、病程短、病位浅。

#### （二）里证

**概念**：病变部位在脏腑、气血、骨髓等人体内部的证候。范围极广，凡非表证者皆属里证。

**成因**：①表邪不解，内传入里；②外邪直接侵犯脏腑；③情志、饮食、劳倦等内伤因素直接损伤脏腑。

**临床表现**：因具体脏腑和病性不同而异（详见脏腑辨证），但共同特点为**病程长、不恶寒**。

#### （三）半表半里证

**概念**：病邪既不在表、又未完全入里，邪正交争于表里之间的过渡阶段。

**临床表现**：往来寒热（恶寒与发热交替出现）、胸胁苦满、口苦咽干、默默不欲饮食、心烦喜呕、脉弦。

#### 表证与里证的鉴别

| 鉴别点 | 表证 | 里证 |
|--------|------|------|
| 寒热 | 发热恶寒**同时并见** | 但热不寒 或 但寒不热 |
| 舌象 | 舌苔薄白，舌质变化不明显 | 舌苔、舌质常有明显变化 |
| 脉象 | 脉浮 | 脉沉或各种病脉 |
| 病程 | 短，起病急 | 长，起病可急可缓 |

---

### 二、寒热——判断病邪性质

寒热是辨别疾病阴阳偏盛偏衰性质的一对纲领。

#### （一）寒证

**概念**：感受寒邪，或阴盛阳虚，机体功能活动衰减所表现的证候。

**临床表现**：
- 主症：恶寒喜暖、肢冷踡卧、口淡不渴
- 伴随：面色苍白、痰涎清稀、小便清长、大便稀溏
- 舌脉：舌淡苔白而润滑，脉迟或紧

#### （二）热证

**概念**：感受热邪，或阳盛阴虚，机体功能活动亢进所表现的证候。

**临床表现**：
- 主症：发热喜凉、恶热、口渴喜冷饮
- 伴随：面红目赤、烦躁不宁、痰涕黄稠、小便短赤、大便秘结
- 舌脉：舌红苔黄燥，脉数

#### 寒证与热证的鉴别

| 鉴别点 | 寒证 | 热证 |
|--------|------|------|
| 寒热喜恶 | 恶寒喜暖 | 恶热喜凉 |
| 口渴 | 口不渴（或喜热饮） | 口渴喜冷饮 |
| 面色 | 苍白 | 红赤 |
| 四肢 | 冷 | 热 |
| 二便 | 小便清长、大便稀溏 | 小便短赤、大便秘结 |
| 舌象 | 舌淡苔白润 | 舌红苔黄燥 |
| 脉象 | 迟或紧 | 数 |

> **常见误区**：发热 ≠ 热证。外感风寒表证初期可出现发热恶寒，此时病性属寒，发热是正邪交争的反应，不可误作热证清解。

#### 寒热真假——临证最需警惕的鉴别

当病情发展到严重阶段，有时会出现与本质相反的假象，即「真寒假热」与「真热假寒」：

| 类型 | 病机 | 假象 | 本质（真相） |
|------|------|------|------------|
| 真寒假热 | 阴盛格阳（阳气被阴寒格拒于外） | 身热、面红、口渴（但欲近衣被） | 喜暖、口不渴或渴喜热饮、肢冷、小便清长、舌淡苔白、脉沉微 |
| 真热假寒 | 阳盛格阴（阳热内盛、格阴于外） | 手足厥冷、脉沉（似寒） | 喜冷、口渴喜冷饮、胸腹灼热、小便短赤、舌红苔黄、脉虽沉但有力 |

**鉴别关键**：一看喜冷喜热（本质寒热），二看渴饮与否（真热多渴喜冷饮，真寒不渴或喜热饮），三看舌脉（舌淡苔白为寒，舌红苔黄为热）。假象多局限于体表、四肢等局部，真相反映在舌、脉、二便等整体，须「透过现象看本质」。

### 三、虚实——判断邪正盛衰

虚实是辨别邪正盛衰的一对纲领。"邪气盛则实，精气夺则虚"（《素问·通评虚实论》）。

#### （一）实证

**概念**：邪气亢盛而正气未衰，邪正相争剧烈所表现的证候。

**成因**：①外邪侵袭；②脏腑功能失调产生痰饮、水湿、瘀血、食积等病理产物停积。

**临床表现**：因邪气性质不同而异，共同特点为**亢盛有余**——声高气粗、痛处拒按、舌苔厚腻、脉实有力。

#### （二）虚证

**概念**：正气不足（精气血津液亏虚或脏腑功能减退）所表现的证候。

**临床表现**：因虚损的具体内容不同而异，共同特点为**衰退不足**——面色萎黄或苍白、神疲乏力、气短懒言、自汗盗汗、痛处喜按、舌淡少苔、脉虚无力。

#### 虚证与实证的鉴别

| 鉴别点 | 虚证 | 实证 |
|--------|------|------|
| 病程 | 长，起病缓 | 短，起病急 |
| 声音 | 声低息微 | 声高气粗 |
| 疼痛 | 喜按（按之痛减） | 拒按（按之痛甚） |
| 舌象 | 舌淡胖嫩，苔少或无 | 舌质苍老，苔厚腻 |
| 脉象 | 虚、细、弱、微 | 实、滑、弦、紧 |

> **常见误区**：虚实常相互转化、相互夹杂。如"真实假虚"（大实有羸状）和"真虚假实"（至虚有盛候），需要综合四诊资料细致鉴别。

### 四、阴阳——总纲之总纲

阴阳是辨别疾病类别的总纲领，统领其他六纲。《素问·阴阳应象大论》云：「善诊者，察色按脉，先别阴阳」——四诊所得，最终都须先以阴阳定其纲领。

#### 基本归类

| 阴证 | 阳证 |
|------|------|
| 里证、寒证、虚证 | 表证、热证、实证 |

#### （一）阴证

凡符合"阴"的属性和特点——抑制、沉静、衰退、晦暗——的证候均属阴证。
- 面色苍白或晦暗、精神萎靡、身重踡卧
- 畏寒肢冷、语声低微、口淡不渴
- 大便稀溏、小便清长
- 舌淡胖嫩、脉沉迟无力

#### （二）阳证

凡符合"阳"的属性和特点——兴奋、躁动、亢进、明亮——的证候均属阳证。
- 面色红赤、烦躁不安、身热喜凉
- 声高气粗、口渴喜饮
- 大便秘结、小便短赤
- 舌红苔黄、脉数有力

#### （三）亡阴与亡阳——阴阳离决的危重证

| 鉴别点 | 亡阴 | 亡阳 |
|--------|------|------|
| 汗 | 汗热、味咸、质黏 | 汗冷、味淡、质稀 |
| 四肢 | 温和 | 厥冷 |
| 面色 | 潮红 | 苍白 |
| 口渴 | 渴喜冷饮 | 口不渴 |
| 舌象 | 舌红干 | 舌淡润 |
| 脉象 | 细数无力 | 脉微欲绝 |

> 临床意义：亡阴亡阳均属危证，需紧急救治。治疗原则为"救阴"与"回阳"，临床常见"阴阳互损"——亡阴可迅速导致亡阳。

### 五、八纲之间的组合关系

临床实际中，八纲各纲之间不是孤立的，而是相互交织、组合出现的：

```
八纲组合模式
├── 表里 + 寒热 → 表寒证、表热证、里寒证、里热证
├── 表里 + 虚实 → 表实证、表虚证、里实证、里虚证
├── 寒热 + 虚实 → 虚寒证、虚热证、实寒证、实热证
└── 三者复合 → 表寒里热、表实里虚、上热下寒 等
```

**常见组合证型举例**：

| 组合证型 | 病位 | 病性 | 关键临床表现 |
|----------|------|------|-------------|
| 表寒实证 | 表 + 寒 + 实 | 风寒束表 | 恶寒发热、无汗、头痛、脉浮紧 |
| 里虚寒证 | 里 + 虚 + 寒 | 脾肾阳虚 | 畏寒肢冷、腹痛喜按、便溏、脉沉迟无力 |
| 里实热证 | 里 + 实 + 热 | 阳明腑实 | 高热、腹痛拒按、便秘、舌红苔黄燥、脉沉实 |
| 阴虚内热 | 里 + 虚 + 热 | 肝肾阴虚 | 潮热盗汗、五心烦热、舌红少苔、脉细数 |

## 第三节 脏腑辨证

脏腑辨证是在八纲辨证指导下，根据脏腑的生理功能和病理特点，对四诊资料进行分析归纳，判断疾病所在的脏腑部位及其寒热虚实性质的辨证方法。它是**内伤杂病辨证的核心方法**。

> **回扣情境导入**：还记得第二位王女士吗？头痛绵绵、头晕眼花、面色苍白、心悸失眠、脉细弱——待学完本节五脏证型，你便能看出这是一例典型的血虚证：心血不足、心神失养则心悸失眠，血虚不能上荣头目则头痛绵绵、头晕眼花。

### 一、脏腑辨证的基本思路

1. **定位**：根据各脏腑的生理功能和经络循行路线，确定病变脏腑
2. **定性**：运用八纲辨别病变的寒热虚实性质
3. **审因**：分析致病因素（外感、内伤、病理产物等）

### 二、五脏常见证型

#### （一）心病辨证

心的生理功能：主血脉、主神志。

| 证型 | 病机 | 主症 |
|------|------|------|
| 心气虚 | 心气不足，鼓动无力 | 心悸、气短、动则尤甚、神疲、脉细弱或结代 |
| 心阳虚 | 心阳虚衰，温煦不足 | 心悸、胸闷、畏寒肢冷、面色㿠白、脉沉迟 |
| 心血虚 | 心血不足，心神失养 | 心悸、失眠多梦、健忘、面色淡白、舌淡、脉细 |
| 心阴虚 | 心阴不足，虚热内生 | 心悸、心烦、失眠、盗汗、舌红少苔、脉细数 |
| 心火亢盛 | 火热内扰心神 | 心烦失眠、口舌生疮、小便赤涩、舌尖红、脉数 |
| 心血瘀阻 | 血行不畅，心脉痹阻 | 心胸憋闷疼痛（刺痛）、舌紫暗有瘀斑、脉涩 |

#### （二）肺病辨证

肺的生理功能：主气司呼吸、主宣发肃降、通调水道。

| 证型 | 病机 | 主症 |
|------|------|------|
| 肺气虚 | 肺气不足，宣降无力 | 咳喘无力、少气短息、自汗畏风、易感冒、舌淡脉虚 |
| 肺阴虚 | 肺阴亏虚，虚热内生 | 干咳无痰或痰少而黏、口燥咽干、潮热盗汗、舌红少津 |
| 风寒束肺 | 风寒袭肺，肺气失宣 | 咳嗽、痰白清稀、恶寒发热、鼻塞流清涕、脉浮紧 |
| 风热犯肺 | 风热犯肺，肺失清肃 | 咳嗽、痰黄黏稠、发热微恶寒、咽痛、舌尖红、脉浮数 |
| 痰湿阻肺 | 痰湿壅盛，肺气不降 | 咳嗽痰多、色白易咯、胸闷气喘、苔白腻、脉滑 |
| 痰热壅肺 | 痰热互结，壅塞肺气 | 咳喘、痰黄稠量多或脓血腥臭、胸痛、舌红苔黄腻 |

#### （三）脾病辨证

脾的生理功能：主运化、主升清、主统血。

| 证型 | 病机 | 主症 |
|------|------|------|
| 脾气虚 | 脾气不足，运化无力 | 食少腹胀、大便稀溏、神疲乏力、面色萎黄、舌淡脉缓弱 |
| 脾阳虚 | 脾阳不足，虚寒内生 | 腹胀冷痛、喜温喜按、便溏或完谷不化、畏寒肢冷、舌淡胖有齿痕 |
| 脾不统血 | 脾气亏虚，统摄无权 | 各种慢性出血（便血、崩漏、肌衄）兼脾气虚表现 |
| 中气下陷 | 脾气虚极，清阳不升 | 脘腹坠胀、久泻脱肛、内脏下垂（胃下垂、子宫下垂） |
| 寒湿困脾 | 寒湿内盛，困遏脾阳 | 脘腹胀满、头身困重、口淡不渴、便溏、苔白腻、脉濡缓 |
| 湿热蕴脾 | 湿热内蕴，脾失健运 | 脘腹痞闷、恶心欲呕、身热不扬、大便黏滞、苔黄腻、脉濡数 |

#### （四）肝病辨证

肝的生理功能：主疏泄、主藏血。

| 证型 | 病机 | 主症 |
|------|------|------|
| 肝气郁结 | 肝失疏泄，气机郁滞 | 胸胁或少腹胀痛窜痛、情志抑郁、善太息、脉弦 |
| 肝火上炎 | 肝火炽盛，气火上逆 | 头痛眩晕、面红目赤、急躁易怒、口苦、舌红苔黄、脉弦数 |
| 肝阳上亢 | 肝阴不足，阳亢于上 | 眩晕耳鸣、头目胀痛、面红目赤、烦躁易怒、腰膝酸软（上盛下虚） |
| 肝血虚 | 肝血不足，失于濡养 | 头晕眼花、视物模糊、肢体麻木、月经量少或闭经、舌淡脉细 |
| 肝阴虚 | 肝阴不足，虚热内扰 | 头晕耳鸣、两目干涩、胁肋隐痛、五心烦热、舌红少津 |
| 肝风内动 | 多种原因致内风扰动 | 眩晕欲仆、肢体震颤、抽搐、甚至突然昏倒（详见附注） |

> **肝风内动**是一个大类，包含四种亚型：①肝阳化风（老年多见，突发中风前兆）；②热极生风（高热抽搐）；③阴虚动风（慢抽、蠕动）；④血虚生风（肢体麻木、肌肉瞤动）。

#### （五）肾病辨证

肾的生理功能：主藏精、主水、主纳气、主骨生髓。

| 证型 | 病机 | 主症 |
|------|------|------|
| 肾阳虚 | 肾阳不足，温煦失职 | 畏寒肢冷、腰膝冷痛、阳痿早泄（男）/宫寒不孕（女）、小便清长、五更泄泻（多兼脾阳虚） |
| 肾阴虚 | 肾阴不足，虚热内生 | 腰膝酸软、头晕耳鸣、失眠多梦、潮热盗汗、男子遗精、女子经少或闭经 |
| 肾精不足 | 肾精亏虚，生长发育迟缓 | 小儿发育迟缓、成人早衰（发脱齿摇、健忘恍惚）、不孕不育 |
| 肾气不固 | 肾气亏虚，封藏失职 | 腰膝酸软、神疲、小便频数而清、尿后余沥、遗尿、滑精早泄、带下清稀 |
| 肾不纳气 | 肾气虚衰，纳气无力 | 久病咳喘、呼多吸少、气不得续、动则喘甚（兼肾气虚表现） |

### 三、常见脏腑兼证

临床上，两个或两个以上脏腑同时出现病证的情况十分常见，称为"脏腑兼证"。

| 兼证 | 病机 | 主症 |
|------|------|------|
| 心脾两虚 | 心血虚 + 脾气虚 | 心悸失眠 + 食少腹胀、便溏 |
| 心肾不交 | 心火亢 + 肾阴虚 | 心烦失眠 + 腰膝酸软、梦遗 |
| 肝脾不调 | 肝气郁 + 脾气虚 | 胸胁胀痛 + 食少腹胀、便溏 |
| 肝胃不和 | 肝气犯胃 | 胸胁胀痛 + 嗳气吞酸、胃脘胀痛 |
| 脾肾阳虚 | 脾阳虚 + 肾阳虚 | 腹部冷痛、五更泄泻 + 腰膝冷痛、水肿 |
| 肝肾阴虚 | 肝阴虚 + 肾阴虚 | 头晕目眩、两目干涩 + 腰膝酸软、耳鸣 |
| 肺肾阴虚 | 肺阴虚 + 肾阴虚 | 干咳少痰 + 腰膝酸软、潮热盗汗 |

> **记忆技巧**：脏腑兼证 = 两个单脏证候的叠加。只需掌握各脏的基本证型，兼证即可自然推导。例如：心脾两虚 = 心血虚（心悸失眠）+ 脾气虚（食少便溏）。

## 第四节 六经辨证概要

### 一、概述

六经辨证由东汉医家张仲景在《伤寒论》中创立，是用于**外感风寒**病证的辨证方法。它将外感病发生、发展过程中的证候，以**阴阳为纲**，归纳为三阳病（太阳、阳明、少阳）和三阴病（太阴、少阴、厥阴）六大类，揭示了外感病由表入里、由浅入深的**传变规律**。

### 二、六经病变纲要

```
循经传次序（一般传变顺序）：
太阳 → 阳明 → 少阳 → 太阴 → 少阴 → 厥阴

病位深浅（由浅入深）：
表（太阳）→ 半表半里（少阳）→ 里（阳明、太阴、少阴、厥阴）
```

> **辨析**：少阳的「半表半里」是指其**病位**介于表里之间，而它在**循经传次序**中却排在阳明之后——这是两个不同维度：循经传是外感病沿经络脏腑依次相传的规律，病位深浅是邪气由表入里的层次。二者不可混同，否则会产生「先里、后半表半里」的错觉。

#### （一）太阳病——外感初期的表证阶段

| 分型 | 病机 | 主症 | 治法 |
|------|------|------|------|
| 太阳中风（表虚） | 风邪袭表，卫强营弱 | 发热、恶风、汗出、脉浮缓 | 解肌祛风、调和营卫 |
| 太阳伤寒（表实） | 寒邪束表，卫阳被遏 | 恶寒发热、无汗而喘、身痛、脉浮紧 | 发汗解表、宣肺平喘 |

#### （二）阳明病——外邪入里化热的极盛阶段

| 分型 | 病机 | 主症 | 治法 |
|------|------|------|------|
| 阳明经证（热盛） | 邪热弥漫全身 | 大热、大汗、大渴、脉洪大（"四大症"） | 清热生津 |
| 阳明腑证（燥实） | 热与肠中糟粕相结 | 日晡潮热、腹满硬痛拒按、大便秘结、舌红苔黄燥 | 攻下实热、通腑存阴 |

#### （三）少阳病——邪在半表半里

| 病机 | 主症 |
|------|------|
| 邪犯少阳，枢机不利 | 往来寒热、胸胁苦满、口苦咽干、默默不欲饮食、心烦喜呕、脉弦 |

#### （四）太阴病——脾阳虚弱，寒湿内盛

| 病机 | 主症 |
|------|------|
| 中阳不足，寒湿内阻 | 腹满时痛、食不下、呕吐、自利不渴、舌淡苔白、脉缓弱 |

#### （五）少阴病——心肾虚衰，全身性虚证

| 分型 | 病机 | 主症 |
|------|------|------|
| 少阴寒化 | 心肾阳虚，阴寒内盛 | 无热恶寒、四肢厥冷、下利清谷、但欲寐、脉微细 |
| 少阴热化 | 肾阴虚，心火亢 | 心烦不得眠、口燥咽干、舌尖红、脉细数 |

#### （六）厥阴病——阴阳对峙，寒热错杂

| 病机 | 主症 |
|------|------|
| 阴阳失调，寒热错杂 | 消渴、气上撞心、心中疼热、饥而不欲食、或手足厥逆（复杂多变） |

### 三、六经辨证的核心思维

1. **动态观**：外感病是一个动态变化过程，证型随正邪消长而不断变化
2. **传变规律**：一般按太阳→阳明→少阳→太阴→少阴→厥阴的顺序传变，但也可「直中」「合病」「并病」——直中（病邪不经三阳而直接侵犯三阴）、合病（两经或三经同时受病）、并病（一经病证未罢，他经证候又起）
3. **治疗原则**：三阳病以祛邪为主，三阴病以扶正为主

### 四、六经病治疗要点

| 经病 | 治疗要点 |
|------|---------|
| 太阳病 | 解表（中风调和营卫、伤寒发汗解表） |
| 阳明病 | 清热（经证清热生津、腑证攻下通腑） |
| 少阳病 | 和解枢机 |
| 太阴病 | 温中散寒、健脾燥湿 |
| 少阴病 | 回阳救逆（寒化）／滋阴清热（热化） |
| 厥阴病 | 寒热并用、调理阴阳 |

> 与卫气营血辨证的「治疗总则」（辛凉解表、清热生津、清营透热、凉血散血）相呼应，共同体现外感病辨证的论治指向。

## 第五节 卫气营血辨证概要

### 一、概述

卫气营血辨证由清代医家叶天士创立，载于《温热论》，是专用于**外感温热病**的辨证方法。它用卫、气、营、血四个层次概括温热病由浅入深的传变过程。

### 二、与六经辨证的关系

| 对比维度 | 六经辨证 | 卫气营血辨证 |
|----------|---------|-------------|
| 适用病种 | 外感**风寒**（伤寒） | 外感**温热**（温病） |
| 创始人 | 张仲景（东汉） | 叶天士（清代） |
| 传变层次 | 六经 | 卫→气→营→血 |
| 核心病邪 | 寒邪为主 | 温热邪毒为主 |
| 伤及重点 | 伤阳气 | 伤阴液 |

> **学习提示**：两者不矛盾，而是互补。六经辨伤寒，卫气营血辨温病，共同构成中医对外感病的完整辨证体系。

### 三、四个层次

#### （一）卫分证——温病初期，邪在肺卫

| 病机 | 温热邪气侵犯肌表，肺卫失宣 |
|------|---------------------------|
| **主症** | 发热、微恶风寒、头痛、口微渴、咳嗽、咽痛 |
| **舌脉** | 舌尖边红、苔薄白或薄黄，脉浮数 |

**与太阳伤寒的鉴别**：太阳伤寒恶寒重发热轻、口不渴、脉浮紧；卫分证发热重恶寒轻、口渴、脉浮数。

#### （二）气分证——邪热入里，正邪剧争

| 病机 | 温热邪气入里，正盛邪实，阳热亢盛 |
|------|-------------------------------|
| **主症** | 高热、不恶寒反恶热、口渴喜冷饮、大汗出 |
| **舌脉** | 舌红、苔黄燥，脉洪大有力 |

**四大症**：大热、大汗、大渴、脉洪大——与阳明经证相似，但病因是温热邪气。

#### （三）营分证——邪热内陷，营阴受损

| 病机 | 邪热深入营分，灼伤营阴，扰动心神 |
|------|-------------------------------|
| **主症** | 身热夜甚、心烦不寐、口干反不甚渴、时有谵语、斑疹隐隐 |
| **舌脉** | 舌红绛、无苔或少苔，脉细数 |

> **关键特征**："舌红绛"是判断邪热入营的重要标志。

#### （四）血分证——邪热深入血分，动血耗血

| 病机 | 热入血分，迫血妄行，瘀热互结 |
|------|---------------------------|
| **主症** | 身热、躁扰不安、**各种出血**（吐血、衄血、便血、尿血、斑疹显露）、或见抽搐 |
| **舌脉** | 舌深绛或紫暗，脉细数或弦数 |

> **危险信号**：出血 + 舌深绛 = 热入血分，提示病情危重，需紧急清热凉血。

### 四、传变规律

```
一般传变（顺传）：  卫分 → 气分 → 营分 → 血分
特殊传变（逆传）：  卫分 ──────────→ 营分/血分（心包）
           逆传心包：温热邪气不经气分，由卫分直入心营，出现神昏谵语
```

**治疗总则**：
- 卫分：辛凉解表（银翘散类）
- 气分：清热生津（白虎汤类）
- 营分：清营透热（清营汤类）
- 血分：凉血散血（犀角地黄汤类）

> **"透热转气"**：是温病治疗的关键思路——即使邪入营分，也要设法将热邪透转至气分而解，不可一味寒凉遏伏。

## 第六节 辨证方法之间的关系

### 一、四种辨证方法的定位

```
                    八纲辨证（总纲）
                    /     |     \
                   /      |      \
          脏腑辨证    六经辨证    卫气营血辨证
         （内伤杂病）  （伤寒）     （温病）
```

### 二、临床综合运用

在真实的临床场景中，各种辨证方法不是割裂使用的，而是**综合运用**：

**案例**：
> 一位患者发热三天就诊。初起恶寒发热、头痛、脉浮（**八纲：表证**），伴咳嗽、痰白清稀（**脏腑：肺**），舌苔薄白、脉浮紧（**八纲：寒证、实证**）。
>
> 辨证结论：**风寒束肺证**（八纲定性：表寒实证 + 脏腑定位：肺）。

再看另一例：
> 高热五天，热勢不退，咳喘、痰黄黏稠、口渴、舌红苔黄、脉洪数。已无恶寒。
>
> 辨证结论：可用八纲辨为里实热证，用脏腑辨为痰热壅肺证，若从卫气营血角度则为气分热盛证。
>
> 三种方法从不同角度得出**一致的结论**，相互印证。

### 三、各类辨证方法的选用原则

| 疾病类型 | 首选辨证方法 | 辅助辨证方法 |
|----------|-------------|-------------|
| 内伤杂病（咳嗽、胃痛、失眠等） | 脏腑辨证 | 八纲辨证 |
| 外感风寒（伤寒） | 六经辨证 | 八纲 + 脏腑辨证 |
| 外感温热病（温病） | 卫气营血辨证 | 三焦辨证 + 八纲 |
| 慢性虚弱性疾病 | 脏腑辨证 + 气血津液辨证 | 八纲辨证 |
| 急症/初诊 | 八纲辨证 | 根据情况选用其他方法 |

> **补充说明**：上表中的「三焦辨证」「气血津液辨证」为辅助辨证方法，本书仅在方法学层面作概述性提示，其系统内容分别见后续《温病学》《中医内科学》等专业教材，在此不作展开。

## 本章小结

辨证是中医诊断学的核心环节，是连接"四诊"与"论治"的桥梁。

**核心知识框架**：

```
辨证体系
├── 八纲辨证（总纲，统领全局）
│    ├── 表里 → 判断病位
│    ├── 寒热 → 判断病性
│    ├── 虚实 → 判断邪正盛衰
│    └── 阴阳 → 总括分类
├── 脏腑辨证（内伤杂病核心）
│    ├── 五脏辨证（心、肝、脾、肺、肾）
│    └── 脏腑兼证
├── 六经辨证（外感伤寒）
│    └── 太阳 → 阳明 → 少阳 → 太阴 → 少阴 → 厥阴
└── 卫气营血辨证（外感温病）
     └── 卫 → 气 → 营 → 血（由浅入深的传变层次）
```

**本章关键术语**：

| 术语 | 含义 |
|------|------|
| 证 | 疾病某一阶段病因、病位、病性、病势的综合概括 |
| 四诊合参 | 望闻问切四诊资料综合分析、互参互证 |
| 表证 | 病在肌表，外感初期 |
| 里证 | 病在脏腑、气血、骨髓 |
| 纯虚/纯实 | 单纯的正气虚衰或邪气亢盛 |
| 虚实夹杂 | 正虚和邪实同时存在 |
| 顺传 | 外感病按一般层次由浅入深传变 |
| 逆传 | 外感病不按一般规律，越级深陷 |
| 透热转气 | 温病治疗中将营分热邪透转气分而解的治法思路 |
