## 图 3-1 经验三级结构：回合、回报与价值（对应节号：3.1.1、3.1.2）

- 图题：从诊疗经历到平均疗效：回合—回报—价值的三级台阶
- 内容说明：展示无模型学习的经验三级结构：第一级，一条完整诊疗（初诊→处方→复诊→转归）是一条回合（episode）；第二级，把这条回合的疗效累积起来得到回报（return）；第三级，把许多条同类回合的回报取平均得到价值（value）。右侧附临床对照：看一场球赛=回合、全场比分=回报、球队平均实力=价值；"这个证候用什么方"的规律从许多条"证候—方剂—转归"经历中平均出来。
- 绘制建议：
  - 结构：竖向三级台阶，自下而上逐级升高。第一级画一条回合链（初诊→处方→复诊→转归，四个圆角方块 + 箭头）；第二级画一个"累加器"框（Σ 符号），接收回合并输出回报 G；第三级画一个"平均"框（1/N Σ），汇聚多条回报并输出价值 v。
  - 标注：三级台阶右侧各注英文对照：episode / return / value；台阶旁注正文原句"回合是样本的载体，回报是样本本身，价值是样本的平均"。
  - 配色：三级台阶由浅到深（浅蓝→中蓝→深蓝），临床对照框用浅橙色，与第1章配色风格保持一致。
  - 注意：务必体现"层层递进"（回合→回报→价值），不可画成并列三项。

## 图 3-7 增量均值估计：来一个更新一个（对应节号：3.5.1）

- 图题：从"攒一批算一次"到"来一个更新一个"：增量更新示意
- 内容说明：左右对照。左栏"非增量式"：样本排队进入"仓库"，等数据齐了再统一计算（一个"Σ/平均"盒子，输出一次）；右栏"增量式"：样本逐条流入，每来一条就地更新 w_{k+1} = w_k + (1/k)(x_k − w_k)，估计值像一条"活"的曲线持续移动。下方附临床对照：复诊记录一条条入库、随访电话一个个打回——老中医"效不更方、效差变方"就是增量式。
- 绘制建议：
  - 结构：左右两栏各画一条"样本流"（三个样本方块 → 处理盒 → 输出）。左栏处理盒前画一个"存储架"（等全部样本齐）；右栏处理盒旁边画一条上升的折线（估计轨迹），每来一个样本折线挪一小步。
  - 公式：右栏处理盒上方标更新式 w_{k+1} = w_k + (1/k)(x_k − w_k)，并拆注"新估计 = 旧估计 + 步长 × (新样本 − 旧估计)"。
  - 标注：左栏注"统计估计（3.3节）：等回合结束才能更新"；右栏注"随机逼近（3.5节）：流式更新、实时响应"。
  - 注意：公式中步长写 1/k，与正文一致；不要画成常数步长形式（那是 3.5.3 的对比点）。

## 图 3-8 RM 定理的两个步长条件（对应节号：3.5.2）

- 图题：步长必须"慢到能走远，快到能平噪"：RM 定理条件示意图
- 内容说明：四条步长序列的收敛行为对比，横轴迭代次数 k、纵轴估计 w_k，真值 w* = 3（例3.5/例3.6）。① a_k = 1/k（同时满足两条件）：曲线平稳收敛到 3；② a_k = 1/√k（违反条件②，对应例3.6）：曲线剧烈抖动、噪声方差发散；③ a_k = 1/k²（违反条件①，对应例3.6）：曲线缓慢爬升后停在初值与真值之间（总行程有限）；④ 常数步长 α（对比，正文 3.5.1/3.5.3）：能跟随但围绕真值持续抖动。右侧注两个条件：Σa_k = ∞（能走远）、Σa_k² < ∞（能平噪）。
- 绘制建议：
  - 坐标轴：横轴"迭代次数 k"，纵轴"估计 w_k"；y = 3 画水平虚线标注"真值 w* = 3"。
  - 曲线：四条线用不同颜色/线型：1/k 平滑收敛（深蓝实线）；1/√k 收敛趋势但波动越来越大（橙色虚线，振幅发散）；1/k² 从 0 缓慢上升、停在中途（绿色点线）；常数 α 抖动不收敛（灰色细线）。

## 图 3-10 分布式学习：个体积累—系统汇总—交叉校验（对应节号：3.7.2）

- 内容说明：网状结构图。底部多个"学习节点"（医者/诊室）各自带小样本库与局部估计（w₁, w₂, …, w_n），向上汇入中央"系统汇总"层（按证据等级加权、按把握程度评估），再向上到"整体认知"层；两侧标注"交叉校验"：不同节点估计相互印证或矛盾，矛盾本身是信息（某方剂在某地显著、在另一地却无效 → 样本分布差异）。右侧附个人定位三步：状态定位（我在哪）→ 能力定位（我能做什么）→ 目标定位（我要去哪），并画住院医→学科带头人成长曲线（约 500 → 60000 余病证单元）。
- 绘制建议：
  - 结构：底部 3–4 个节点方块（各含"样本库 + w 估计"），箭头向上汇入中央汇总框（内含"加权平均 Σ w_i·evidence_weight"），再向上一个"整体认知"框；汇总框两侧各一条弧形箭头回指节点，标注"交叉校验"。
  - 成长曲线：图右侧小图，横轴职业阶段（住院医→主治→副高→学科带头人），纵轴病证覆盖数，阶梯上升曲线，节点标注 500 / 数千 / 60000 余。
  - 标注：图下注一行："全局信息不可得，局部决策必然发生——每个节点的样本都是整体认知的组成部分"。
  - 注意：成长曲线数值（500、60000 余）与正文 3.7.2 节一致。

## 图 3-11 六者和谐：处方—审方—转归的证据循环（对应节号：3.8.1、3.8.2）

- 图题：医者处方、药者审方与患者转归：互为证据来源的闭环
- 内容说明：中央闭环图：医者处方（动作的记录）→ 药者审方（质量门：配伍禁忌、剂量合理性、证候匹配校验）→ 通过后转归数据进入样本库（疗效证据库 + 安全样本库）→ 按证据等级与把握程度标注 → 反馈修正审方规则（系统层面的"策略迭代"：审方规则=策略、随访疗效=评估、规则修订=改进）。左侧附"坏样本"对照：一条含十八反配伍的处方若未拦截，其转归会污染疗效估计。右下角六边形列出医、患、药、械、规、法六方，药—医边加粗标注"相互成就"。
- 绘制建议：
  - 结构：中央一个圆形/环形流程：处方→审方→样本库→反馈，四节点 + 环形箭头；审方节点画一个"闸门"（质量门）符号，未通过箭头指向"拦截/退回"小框，通过箭头进入样本库。
  - 左侧对照：画一条含"十八反"红叉的处方卡片，旁注"坏样本：错误用药的后果被误当成疗效 → 估计被带偏"。
  - 右下角：六边形顶点布局六方（医、患、药、械、规、法），药—医连线加粗旁注"互为证据来源：处方提供样本、审方保证质量"。
  - 标注：图下注一行："每一次处方与审方的交互，都是对'合理用药知识'的一次就地更新——与 3.5 节增量更新同构"。
