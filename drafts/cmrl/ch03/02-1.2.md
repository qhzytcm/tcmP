## 3.2 大数定律与均值估计

### 3.2.1 大数定律与均值估计：概念与内涵

为什么全章要从“均值估计”讲起？因为价值函数的定义就是期望：v_π(s) = E[G_t | S_t = s]，q_π(s,a) = E[G_t | S_t = s, A_t = a]——状态价值是回报的条件期望，动作价值是回报在给定动作下的条件期望。因此，“估计价值”在数学上就是“估计期望”，即均值估计（mean estimation）问题；把均值估计讲透，价值估计就只剩“把随机变量换成回报”这一步替换。考虑一个随机变量 X，计算它的期望 E[X] 有两条路径。路径一，模型已知时按定义直接计算：E[X] = Σ_x p(x)·x——知道 X 的分布，期望就是一串加权求和，第2章的动态规划走的正是这条路径，只不过把求和换成了贝尔曼方程。路径二，模型未知时，手里只有若干独立同分布的样本 x_1, x_2, …, x_n，于是用样本均值逼近：x̄ = (1/n)Σ_{j=1}^{n} x_j，n 越大越准，n → ∞ 时 x̄ → E[X]。两条路径地位完全对称：一个用分布算，一个用样本估；前者精确但需要模型，后者粗糙但只需要数据——这正是第2章与本章的分界线。理解这个对称性，就理解了无模型学习为何“用平均替代公式”。

样本均值收敛到期望，不是经验之谈，而是一条严格的数学定理——大数定律（law of large numbers），通俗地说：观测的次数足够多，平均值就稳定在真值附近，单次的起伏被“摊平”了——这就是“平均的智慧”。设 X_1, X_2, …, X_n 是独立同分布的随机变量，公共期望 E[X] = μ 有限，则对任意给定的 ε > 0，当 n → ∞ 时，样本均值落在真值附近任意窄区间内的概率趋于 1，即 P(|x̄_n − μ| ≥ ε) → 0。这称为弱大数定律，它断言 x̄_n 依概率收敛于 μ。直观上，平均把所有样本的随机性摊平：单个样本可以偏离很远，但偏差相互抵消，n 越大抵消得越干净。大数定律只回答“是否收敛”，不回答“多快收敛”；回答速度问题的是中心极限定理（central limit theorem）：当 n 较大时，√n(x̄_n − μ) 近似服从均值为 0、方差为 σ² 的正态分布，等价地说，样本均值的标准差约为 σ/√n，其中 σ² = Var(X) 是 X 的方差。这个 1/√n 的速度极其重要：样本量翻四倍，误差标准差才减半——想要精度翻倍，样本要乘四。本节只需记住这个量化直觉，严格处理留到3.5节随机逼近：那里的增量均值估计与大数定律一脉相承，且会给出更一般的收敛条件。

### 3.2.2 大数定律与均值估计：方法与实现

用两个经典例子把上面的数学变成手感。例3.1（抛硬币，教学示例数据）：设随机变量 X 在正面时取 +1、反面时取 −1，且两种结果等概率，则 E[X] = 0。现在假设不知道这个分布（模型未知），只能反复抛硬币记录结果。假设 5 次抛掷得到 +1, −1, +1, +1, −1，则样本均值 x̄ = (1−1+1+1−1)/5 = 0.2；再抛 5 次，均值会变化；抛到 100 次，均值会明显向 0 靠拢（图 3-2）。这组模拟说明概率论与统计学的分工：单次抛掷的结果无法预测，但大量抛掷的平均结果可以预测——随机性在个体层面不可控，在平均层面可控。把 +1/−1 换成“方剂有效 +1、无效 −1”，同一套推理就变成临床疗效的估计：单个病例的转归千差万别，大量病例的平均疗效却有稳定规律，这正是“大样本统计”在医学中的根基。例3.2（骰子点数，教学示例数据）：设 X 为一次掷骰子的点数，等概率取 1 至 6，则 E[X] = 3.5（模型已知时按定义一算即得）。模型未知时模拟掷 5 次，若结果为 2, 6, 4, 1, 5，则 x̄ = 18/5 = 3.6，与 3.5 意外接近，但这是运气；换一组结果 1, 1, 2, 3, 6，则 x̄ = 13/5 = 2.6，偏离就明显了。小样本的均值波动很大，这是正常的，不是方法错了。

误差的量化让“估计”从含糊变成可操作。中心极限定理给出近似答案：当 n 较大时，x̄ 约以 95% 的概率落在 μ ± 1.96σ/√n 之内，这个区间称为 μ 的 95% 置信区间（confidence interval）——通俗地说，就是“按目前的样本量，真值大概落在哪个范围”。回到骰子例子：骰子点数的标准差 σ = √(35/12) ≈ 1.71，n = 30 时半宽为 1.96×1.71/√30 ≈ 0.61，即 x̄ 有 95% 的概率落在 3.5 ± 0.61 的范围内；n = 100 时半宽收窄到 0.34，n = 400 时进一步收窄到 0.17——“样本量翻四倍，区间宽度减半”与3.2.1节的结论完全一致。把置信区间翻译成工作语言：若两首方剂的疗效均值估计相差 0.6，而各自的标准误都是 0.31，那么两均值之差的标准误 √2×0.31 ≈ 0.44，0.6 仅约 1.4 倍差值标准误，还不足以令人信服——真正可信的疗效差异需要达到数倍差值标准误，或者加大样本量让标准误降下来。这个“信号 vs 噪声”的比值直觉，正是临床疗效判断的唯一依据：样本少时看到的一切差距都可能只是噪声，样本足够时微小差距也能被识别。读者务必养成一个职业习惯：任何均值估计都要附带它的标准误，否则“估计”与“猜测”没有区别；这一习惯在药企研发的疗效统计与临床医师的证据判断中同样适用。

### 3.2.3 大数定律与均值估计：小结与衔接

本节要点：第一，价值就是期望，估计价值就是均值估计。第二，期望有两种算法——模型已知按定义 E[X] = Σ_x p(x)x 计算，模型未知用样本均值 x̄ = (1/n)Σ x_j 逼近。第三，大数定律保证样本均值收敛到期望，中心极限定理给出收敛速度 σ/√n，样本量翻四倍误差减半。第四，误差可度量、可压缩，估计值附带标准误是职业习惯。易错点要反复核对。其一，样本均值是估计量，不是真值——抛 5 次硬币得 0.2，不代表期望是 0.2。其二，小样本均值可能严重偏离真值，1 至 5 条样本的均值几乎没有任何说服力。其三，不要因为“有误差”就否定估计，误差是统计世界的常态，关键是量化它。其四，大数定律要求样本独立同分布（independent and identically distributed, i.i.d.），样本之间若存在系统依赖，平均的性质就要重新考察——这一条在下一节会立刻派上用场，因为回合回报的样本并不严格独立：同一条策略、同一个环境生成的回报，共享结构上的关联，需要更精细的论证。

从均值估计到价值估计只有一步替换：把随机变量 X 换成“从状态 s 出发、按策略 π 交互、得到的回报 G_t”，样本均值就变成价值估计 v̂_π(s) = (1/N)Σ G_i；把起点换成“状态 s 与动作 a”，就得到动作价值估计 q̂_π(s,a)。这正是3.3节“统计估计法：从样本估计价值”的全部内容——把“取平均”套到“回报”上，就是统计估计法的主体。但有一个微妙差异必须预告：抛硬币的样本彼此独立，而“从同一状态出发的若干回合回报”虽然是不同回合的产物，却共享策略与环境的结构，并不严格独立——大数定律能否照用？答案是能，但需要更精细的论证，3.5节随机逼近将给出一般化条件，那里两个著名的步长条件会以更统一的形式接管收敛性分析。读者还应注意本节埋下的另一条线索：置信区间与把握程度的关系将在3.6节“证据等级与把握程度”中与临床证据分级结合，形成“样本量×样本质量”双维度的把握度量。学完本节，请自检三问：① 模型已知与模型未知，计算 E[X] 的方式有何不同？② 为什么说“四倍样本量，误差减半”？③ 如果样本均值与期望相差很远，下一步该做什么——改方法还是加样本？答案：先看样本量，样本太少时加样本，样本足够仍偏离才怀疑方法。
