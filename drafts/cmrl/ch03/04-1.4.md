## 3.4 探索与样本积累

### 3.4.1 探索与样本积累：概念与内涵

统计估计要求每个状态-动作对都有样本，样本从哪来？答案只有两个字：探索。探索（exploration），通俗地说，就是多试几种做法，才知道哪种做法好——没试过就永远不知道结果，试过才知道值不值。这个概念与“利用”（exploitation）构成一对永恒的矛盾：利用是沿着已知的好路走，把已知的收益拿到手；探索是去走没走过的路，可能发现更好的选择，也可能白费力气。一味利用，永远发现不了更优方案；一味探索，永远拿不到沿途奖励。临床上，一位医师面对疑难病例，是沿用稳妥的常用方（利用），还是尝试新的治法（探索），正是同一权衡；医学院校里“见过多少种病、试过多少种方案”的积累，本质上就是探索在扩大样本覆盖面。统计估计对探索的需求是刚性的：为了估计 q_π(s,a)，每个 (s,a) 都必须被访问至少一次；一个从未被访问过的 (s,a) 没有任何样本，价值估计无从谈起。这种“每个选项都要试过才能评价”的要求，正是统计学习与单纯模仿的本质区别——模仿只走已知的好路，学习则必须覆盖未知。

探索问题在理论上有一个干净但理想化的解法——探索起点（exploring starts）：回合的初始状态-动作对 (S_0, A_0) 从所有状态-动作对中随机选取，至少保证每个 (s,a) 都有无穷多次成为起点的机会。在这个假设下，每个 (s,a) 都会被访问无穷多次，探索问题在理论上被彻底解决：没有任何 (s,a) 会被永久冷落，全部 q 值都能得到样本支持。需要清醒认识的是这个假设的现实性：在网格世界等仿真环境里，确实可以“把智能体放到任意格子、命令它先做任意动作”，探索起点成立；但在真实系统中，初始条件往往不可控——临床诊疗不可能人为制造“错误起点”让患者从某个奇怪的状态开始治疗，自动驾驶不可能故意把车开进危险场景。因此，探索起点的严格版本是教学与理论的理想化假设，工程实践中通常改用软策略（soft policy）保证所有 (s,a) 被访问：例如 ε-贪婪策略（ε-greedy），以大概率选择当前最优动作、以概率 ε 随机选择其他动作——通俗地说，就是“大部分时候走最有把握的路，偶尔故意走条岔路看看”。这个“偶尔的岔路”就是探索的工程化形态。读者应理解：探索问题并未消失，只是被假设暂时搁置、又被软策略重新拾起，它是贯穿本章乃至全书的方法论主线。

### 3.4.2 探索与样本积累：方法与实现

探索与样本积累的实现，先要把“一条回合如何变成多个样本”落到实处。在探索起点假设下，算法可规范为四步：初始化——对全部 (s,a)，动作价值 q(s,a) 取任意初值，访问计数 N(s,a) = 0，策略 π(s) 任意；第一步，选探索起点——随机选取初始状态 S_0 与初始动作 A_0；第二步，按当前策略 π 生成一条完整回合；第三步，沿回合对每个访问过的 (S_t, A_t) 计算回报：G_t = R_{t+1} + γR_{t+2} + … + γ^{T−1−t}R_T，N(S_t, A_t) ← N(S_t, A_t) + 1，q(S_t, A_t) ← q(S_t, A_t) + [G_t − q(S_t, A_t)]/N(S_t, A_t)；第四步，策略改进——对每个状态 s，π(s) ← argmax_a q(s,a)。重复以上步骤至策略稳定。用网格世界手算（例3.4，教学示例数据，γ = 1，策略“总是向右”，沿用 3.3.2 节例3.3 的随机门网格）：随机起点落在 s1，第一条回合为 s1→s2→s3→s9。它沿途访问三个状态-动作对：(s1, 右)、(s2, 右)、(s3, 右)，无折扣时三时点回报都是 +1——一条回合产生 3 个样本，而朴素版要 3 条独立回合。若此前 (s1, 右) 已有 2 个样本、q = 0.5、N = 2，则更新后 N = 3，q ← 0.5 + (1/3)(1 − 0.5) = 2/3。

第二组细节是统计口径与学习范式。统计口径：同一状态（或状态-动作对）在一回合中可能出现多次。首次访问式（first-visit）只统计该状态在本回合首次出现的回报；每次访问式（every-visit）把每次出现的回报都纳入。两种方式渐近一致：首次访问式无偏、更常用，每次访问式样本更多、样本稀缺时值得考虑。学习范式：on-policy（同轨）用当前策略生成数据、学当前策略，行为策略与目标策略同一个；off-policy（离轨）用行为策略 b 生成数据，学另一个目标策略 π。引入 off-policy 的动机有二：探索与利用解耦——b 保持随机性持续探索，π 趋于最优互不干扰；经验复用——历史数据（旧策略、他人策略、教科书医案）不必作废。临床中，病案库大多由“医生习惯方案”生成（行为策略 b），而我们要估计“最优方案”的价值（目标策略 π），直接平均回报有偏。修正工具是重要性采样（importance sampling）：给每条回报乘上权重 ρ_t = Π_{k=t}^{T−1} π(A_k|S_k)/b(A_k|S_k)，即“目标策略产生这条轨迹的概率 ÷ 行为策略产生这条轨迹的概率”，给样本“重新称重”。两个注意：其一，权重分子永远放目标策略、分母放行为策略，颠倒即荒谬；其二，off-policy 需覆盖性假设——凡 π(a|s) > 0 的动作，必须 b(a|s) > 0。

### 3.4.3 探索与样本积累：小结与衔接

探索与样本积累的要点可以整理为三张并列的“二选一”。其一，探索手段：探索起点（理想化，假设能随意设定起点）与软策略 ε-贪婪（工程化，以概率 ε 随机探索）——前者理论干净，后者现实可行，临床与真实系统一律用后者。其二，统计口径：首次访问式无偏、常用、理论干净，每次访问式样本多、方差表现因任务而异——同一份数据，两种口径可能给出不同的疗效估计，报告必须声明采用哪种。其三，学习范式：on-policy 数据与目标同源、实现简单，off-policy 数据与目标异源、灵活但需重要性采样修正——临床病案库估计推荐方剂的价值，本质是 off-policy。读者应能对任意场景迅速给出选择：做临床病案统计（回合结构清晰）用统计估计直接估计；数据是别人采集的（异源）就上 off-policy 与重要性采样；状态在一回合中反复出现就考虑首次/每次访问的取舍。三个易错点务必记住：① 一条回合中同一 (s,a) 可能出现多次，首次访问与每次访问不可混用且必须注明口径；② 策略更新必须在整条回合的回报统计完毕之后进行，回合中途更新会使样本来自混合策略；③ off-policy 场景直接平均回报而不乘重要性权重，会得到有偏的估计——权重分子分母颠倒同样致命。

本节完成了样本“怎么来、怎么用”的讨论，但还有一个根本性的效率问题悬而未决：统计估计必须等一条完整回合结束才能拿到回报、才能更新一次估计。若回合极长（如慢病随访经年累月），等待就不可接受；若任务是持续进行的（如长期调理），根本没有“结束”可言。样本能否一条一条地来、来一条就更新一次，让估计像活水一样流动？这正是3.5节“随机逼近：增量更新与在线学习”的主题——它把“攒一批算一次”的非增量模式升级为“来一个更新一个”的增量模式，并给出保证收敛的数学条件。同时，探索获得的样本质量参差不齐：有的来自大样本随机对照研究，有的只是专家经验个案——样本的“质量标签”如何进入估计、如何转化为临床决策的把握程度，将在3.6节“证据等级与把握程度”中讨论。学完本节，请自检三问：① 为什么说探索是统计估计的刚性需求？② 探索起点与 ε-贪婪的适用场景有何不同？③ 为什么 off-policy 估计不能直接平均回报，而必须乘重要性权重？
