## 3.3 统计估计法：从样本估计价值

### 3.3.1 统计估计法：概念与内涵

统计估计法（statistical estimation），通俗地说，就是用一部分样本数字推算总体规律的数学方法：看不到“全部病案的平均疗效”这个总体量，就用手中有限样本的平均数去估计它。上一节建立了“价值就是期望”的桥梁，本节把这座桥正式走过去：既然 v_π(s) = E[G_t | S_t = s]，那么用 N 条从状态 s 出发的回合回报取平均，就得到状态价值的估计 v̂_π(s) = (1/N)Σ_{i=1}^{N} G_i；对动作价值同理，q̂_π(s,a) 是对从 (s,a) 出发的回报取平均。这就是统计估计法的核心操作——平均回报，估计价值。先回顾第2章建立的评价工具：第2章已经解决"给定策略算价值"——状态价值 vπ(s) 与贝尔曼方程；把"策略评估"（按策略 π_k 算价值）与"策略改进"（把概率移向更优动作）交替进行，就构成策略迭代（policy iteration, PI）：第一步策略评估，求解给定策略 π_k 的贝尔曼方程得到精确价值；第二步策略改进，贪婪更新 π_{k+1}(s) = argmax_a q_{π_k}(s,a)。问题在于，方程里的转移概率与奖励函数来自模型，模型未知时方程写不出来。统计估计法的改造方案朴素而彻底：从状态 s 出发按策略 π 生成 N 条完整回合，记录每条回报，取平均得 v̂_π(s)。于是“解方程组”被“跑回合取平均”替代，模型的角色由经验承担，其余结构原封不动——评估—改进循环不变，迭代到策略稳定为止。这就是“策略迭代的数据化”——读者应能指出每一步对应 PI 的哪一步，哪里换了原料，哪里没动。

为什么把这种算法称为“统计估计法”而非某个专属算法名？因为它是概念上最直接的无模型估计：不做任何工程优化，把“用样本估计价值”这一思想原样实现，是理解一切后续无模型方法的起点。它同时暴露了无模型学习遇到的第一个本质困难——探索（exploration）问题：为了估计 q_π(s,a)，每个状态-动作对 (s,a) 都必须被访问至少一次；一个从未被访问过的 (s,a)，没有任何样本，价值估计无从谈起。临床上，从未用某首方剂治疗过某类证候，就谈不上“这首方对这个证的平均疗效”——没有样本就没有估计。在朴素版统计估计中，探索问题被“强制绕开”：评估阶段规定从每个 (s,a) 出发分别生成回合，相当于假设能随意设定起始状态与起始动作——这个假设在网格世界成立（可以把智能体放到任意格子），但在真实问题中常常不成立（临床诊疗不可能人为制造一个“错误起点”让患者从某个奇怪状态开始治疗）。因此，朴素版统计估计的意义在于建立概念框架，而它的低效与探索困难，将在3.4节由探索与样本积累部分解决。估计量的性质也要在此立起来：样本均值是无偏的（unbiased）——E[v̂_π(s)] = v_π(s)，即“平均起来不偏不倚”，因为每条回报的期望就是价值定义本身；大数定律则保证样本足够多时误差消失。无偏性与收敛性合起来，构成统计估计的全部理论依据。

### 3.3.2 统计估计法：方法与实现

统计估计法的实现可规范为四步。输入：可交互环境、初始策略 π_0、评估回合数 N、迭代轮数 K。对 k = 0, 1, 2, …, K−1：第一步策略评估——对每个 (s,a) 从它出发按 π_k 生成 N 条完整回合，记录各条回报 G_i，置 q̂_k(s,a) = (1/N)Σ_{i=1}^{N} G_i；第二步策略改进——对每个状态 s，置 π_{k+1}(s) = argmax_a q̂_k(s,a)。回报按定义逐项累加：从 t 时刻的 (s,a) 出发，G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + … + γ^{T−1−t}R_T，γ = 1 时即奖励总和。注意：其一，评估与改进必须分离，先用旧策略 π_k 采完全部样本再更新，中途换策略会使样本来自混合策略；其二，平均分母是实际回合数 N。用3×3网格手算（例3.3，教学示例数据，γ = 1，策略“总是向右”，s6 禁区 −1，s9 目标 +1）：本例沿用图 1-1 的九宫格，但为演示随机转移（见 1.3.2 节），把 s3 的"向右"设为随机门——执行后 0.5 概率进入 s6（禁区，奖励 −1）、0.5 概率直达 s9（目标，奖励 +1）。估计 q_π(s1, 右)：从 s1 向右经 s2、s3，生成 3 条回合，两条落入 s6 得 −1、一条到达 s9 得 +1，于是 q̂_π(s1, 右) = (−1 + 1 − 1)/3 = −1/3（图 3-5）。由随机门设定，真值 q_π(s1, 右) = 0 + 0 + 0.5×(−1) + 0.5×(+1) = 0，样本均值 −1/3 是带噪声估计——有限样本下策略可能被噪声误导。

朴素版统计估计最大的问题是低效：为估计一个 (s,a) 的价值，要专门从它出发生成 N 条完整回合，一轮评估要对全部 |S|·|A| 个状态-动作对分别采样。可是一条回合明明沿途经过若干 (s,a)，这些“顺路”样本却被白白丢弃——利用率极低。改进思路由此而来：让一条回合沿途更新所有被访问过的 (s,a)，把“每条回合一个样本”变成“每条回合多个样本”。为什么可以这样？因为对回合中任意时刻 t，从 (S_t, A_t) 之后的剩余折扣奖励 G_t = R_{t+1} + γR_{t+2} + … 恰好就是该 (s,a) 的回报样本，携带了“从这个状态执行这个动作能走多远、拿多少奖励”的价值信息。一条回合 s0→s1→s2→…→sT 会产生一串 (s,a) 样本，每个样本对应一个不同的时刻——一次采样、多处受益。实现上采用访问计数与增量平均：N(S_t, A_t) ← N(S_t, A_t) + 1；q(S_t, A_t) ← q(S_t, A_t) + [G_t − q(S_t, A_t)]/N(S_t, A_t)。注意这个更新式是增量形式的样本均值：q 初值若为 0，更新 k 次后 q 恰好等于 k 条回报的算术平均。若取 γ = 0.9，一条回合 s1→s2→s3→s9 沿途三个时点的回报分别为 0.81、0.9、1——越早的决策折扣越重，远期奖励对早期决策的贡献被逐级衰减。

### 3.3.3 统计估计法：小结与衔接

统计估计法的性质可以列成一张清单，每一条都值得与第2章的动态规划对照着记。其一，无偏性：每个被访问的 (s,a) 的回报 G_t 都是 q_π(s,a) 的无偏观测，因为 E[G_t | S_t = s, A_t = a] = q_π(s,a) 是动作价值的定义本身；增量均值是这些无偏观测的平均，期望仍为 q_π(s,a)。其二，不需要模型：全程只使用采样得到的经验，转移概率与奖励函数从未出现——这是“无模型”三个字的落实。其三，不需要自举（bootstrapping）：估计 q_π(s,a) 时只依赖该 (s,a) 自己的回报样本，绝不使用后继状态的价值估计——第2章的动态规划用 v(s′) 估计 v(s)（自举），本章的统计估计完全没有这一依赖，这是它与动态规划及后续时序差分方法的标志性区别。其四，代价是方差大：一条回合的回报是沿途每一步随机性（随机转移与随机奖励）的叠加，噪声随回合长度累积；与动态规划的确定性递推相比，统计估计的每个估计都带着整条轨迹的随机波动。三个易错点要记住：① 回合必须完整走完才能计算回报，统计估计是“离线式”学习，回合进行中不能就地更新——这是它与3.5节增量方法的分水岭；② γ < 1 时回报按步折现，最后一步奖励的权重是 γ^{T−1}，不要漏乘；③ 增量更新中 N 必须先加 1 再用作分母，先除后加会得到系统性偏差的结果。

从本节到下一节只有一步之遥。统计估计暴露了两大短板：探索不足——每个 (s,a) 都要有样本，可现实里没法随意制造起点；样本积累低效——一条回合的沿途信息该怎样更充分地利用。把这两个短板放到临床语境中体会：一位医师若从未用过某首方剂治疗某类证候，该 (证候, 方剂) 组合就没有样本，疗效估计无从谈起；而若他只用过五次，这五次病案中“顺路”携带的辨证信息也远未被充分利用——样本既不够多，又用得不透。3.4节“探索与样本积累”将正面回答这两个问题：探索起点假设在什么条件下成立、工程上如何用软策略替代；一条回合中同一状态重复出现时按首次还是每次统计；数据由别的策略生成时如何用重要性采样修正。同时，统计估计的“攒一批算一次”模式也留下了伏笔：如果样本是一条一条到达的，能否来一条就更新一次，让估计像活水一样流动？这正是3.5节“随机逼近：增量更新与在线学习”的主题。学完本节，请自检三问：① 统计估计法的两步分别对应策略迭代的哪两步？② 为什么每个 (s,a) 都必须被访问？③ 有限样本下，策略改进为什么可能“错改”？
