# 六者读者阅读指南 —— 《强化学习的数学原理（中医药场景版）》

> 本指南把全书 10 章正文（315,251 字）按「六者」读者重排：每位读者给出
> ① 翻开教材时的核心问题 ② 推荐阅读路径（章.节） ③ 每站核心收获 ④ 平台对应物。
> 适用场景：医院各岗位人员培训导读、教材五阶段「教学应用」导读页、平台学习路径推荐。

---

## 一、医者（Healer）—— 临床医师 / 带教老师

**核心问题**：辨证开方如何更优？个人经验如何结构化、可传承？

| 阅读站 | 章.节 | 核心收获 |
|---|---|---|
| 第1站 | §1.1-1.6 | 辨证论治=状态(四诊)→动作(处方)→奖励(随访) 的同构；探索/利用=效不更方/效差变方 |
| 第2站 | §2.1-2.4 | 状态价值=某证候的长期疗效期望；贝尔曼方程=经验的可递归表达 |
| 第3站 | §3.1-3.3 | 贝尔曼最优方程=最优辨证择优决策；贪婪=每个证候选最优方 |
| 第4站 | §4.1-4.4 | 价值迭代=策略评估-改进循环；对应"治标-治本"动态调整 |
| 第5站 | §5.1-5.5 | 蒙特卡洛=疗效均值估计（随访数据的统计）；重要性采样=用他人数据学自己策略 |
| 第6站 | §7.1-7.6 | TD/Q-learning=对话日志在线进化；师带徒=行为策略向目标策略迁移 |
| 第7站 | §8.1-8.5 | 函数近似=平台 Top-K 推荐；半梯度=检索分监督学习 |

**读完能回答**：为什么"直接选证据分最高的方"不是好策略（§1.5 反例）？γ 与"治本"的关系（§1.6）？成长路径=从高探索低 γ 到低探索高 γ（§9 基线与方差）？

**平台对应物**：医圣 SOUL（张仲景/孙思邈）六经辨证=策略先验；DSU 病证单元=状态库；semantic-search=近似 argmax；/consult/sage-* 端点。

## 二、患者（Patient）—— 就诊患者 / 家属

**核心问题**：我的病会被怎样"建模"？医生为什么调整方案？AI 辅助诊疗可信吗？

| 阅读站 | 章.节 | 核心收获 |
|---|---|---|
| 第1站 | §1.2-1.5 | 症状组合=状态（医生看的是"状态"而非病名）；奖励=疗效反馈，不是一次开方定终身 |
| 第2站 | §1.1 | 探索与利用：医生试新方案（探索）与沿用旧方（利用）的权衡，解释"为什么换方" |
| 第3站 | §3.1 | 最优策略=对"我的这个状态"的最优方案；一人一方=状态依赖决策 |
| 第4站 | §1.6 | 折扣回报=远期疗效重要；"治未病"=大 γ 决策 |
| 第5站 | §7.5 | Q-learning=从就诊记录中学习最优方案；数据来自真实诊疗闭环 |

**读完能回答**：为什么同样的病不同人方子不同（状态不同）？为什么平台会推荐我没听过的方（检索 Top-K）？疗效随访的意义（奖励信号）？

**平台对应物**：症状自查引导=状态观测；随访康复指导=奖励回路；DSU 医案示例（失眠/感冒/头痛）——患者最亲切的入口。

## 三、药者（Pharmacist）—— 药剂师 / 药企研发

**核心问题**：审方如何自动化？疗效证据如何统计？用药安全如何策略化？

| 阅读站 | 章.节 | 核心收获 |
|---|---|---|
| 第1站 | §1.5 | 证据等级 A/B/C→奖励 1.0/0.7/0.4：奖励数值设计直接影响行为 |
| 第2站 | §5.2-5.3 | 大数定律/均值估计=疗效统计的基础（随访样本均值）；MC=证据等级的经验来源 |
| 第3站 | §6.1-6.3 | 随机逼近=在线增量估计（每来一例更新一次均值）；步长=新旧证据权重 |
| 第4站 | §7.3 | Sarsa=同策略评价：审方规则本身的价值评估 |
| 第5站 | §10.1-10.3 | 药者=critic 角色：审方 reject/accept 是给"处方动作"的奖励信号 |

**读完能回答**：证据等级为什么是 A/B/C 而不是"有效/无效"（奖励连续化）？药品疗效如何随样本累积更新（增量均值）？审方规则如何被评估与改进？

**平台对应物**：/pharmacists/review（accept/reject）=奖励信号；药企研发=off-policy（用真实处方数据学更优推荐，§9 重要性采样）。

## 四、械者（Device）—— 设备科 / 影像科 / 器械供应

**核心问题**：设备如何自适应调节？影像如何辅助诊断？维护调度如何优化？

| 阅读站 | 章.节 | 核心收获 |
|---|---|---|
| 第1站 | §8.1-8.4 | 函数近似=影像特征表示；DQN 三技巧（回放/目标网络/DDQN）=设备稳定训练配方 |
| 第2站 | §9.1-9.4 | 连续动作空间=高斯策略（康复设备力度/角度连续调节）；REINFORCE=试错调参 |
| 第3站 | §10.1-10.5 | Actor-Critic=设备自适应闭环（控制器=actor，状态评估=critic）；PPO=安全策略更新 |
| 第4站 | §4.1-4.3 | 价值迭代=维护排程优化（何时检修=动作选择） |
| 第5站 | §1.3-1.4 | 状态转移=设备运行状态机；策略=维护规则表 |

**读完能回答**：康复设备如何"学习"患者个体差异（状态→动作映射）？为什么设备参数不能大步更新（PPO 信赖域=安全）？影像辅助如何量化置信度（价值函数）？

**平台对应物**：可穿戴数据学习=状态流；设备自适应参数=策略参数；医工器械职业矩阵（§8/§10 职业应用节）。

## 五、规者（Regulator）—— 院办 / 质控 / 后勤

**核心问题**：质控指标如何设计？排班与资源如何优化？CDSS 如何质控？

| 阅读站 | 章.节 | 核心收获 |
|---|---|---|
| 第1站 | §1.5 | 奖励设计=质控指标设计：指标定错了，行为就歪了（奖励黑客警告） |
| 第2站 | §2.1-2.3 | 价值=长期绩效期望：不能只看单次指标，要看长期回报 |
| 第3站 | §4.1-4.4 | 价值迭代=排班/资源调度的策略优化；收敛性=流程改进的稳定性 |
| 第4站 | §7.5 | Q-learning=CDSS 行为策略学习；异策略=用历史数据优化未来流程 |
| 第5站 | §10.3 | 规者=critic：质控评价与决策分离（决策者与评价者分离=医疗质量管理制度设计） |
| 第6站 | §8.5 | 表格 vs 函数=简单规则 vs 数据模型：质控粒度权衡 |

**读完能回答**：质控指标为什么不能只考核"治愈率"（单步奖励 vs 长期回报）？CDSS 引入后如何质控 AI 的决策（critic 独立评价）？流程改进为什么需要"评估-改进"循环？

**平台对应物**：六者规者 Agent=质控 SOUL；质控规则=奖励函数；排班优化=价值迭代应用；应急调度=策略改进。

## 六、法者（Legal）—— 医事律师 / 法务

**核心问题**：AI 诊疗的决策责任如何界定？算法如何留痕审计？纠纷如何预防？

| 阅读站 | 章.节 | 核心收获 |
|---|---|---|
| 第1站 | §1.6 | 轨迹=完整诊疗决策链（状态-动作-奖励），是"决策留痕"的数学形式 |
| 第2站 | §2.1-2.4 | 价值函数=可检查的决策依据（为什么推荐这个方案，可以量化解释） |
| 第3站 | §3.1 | 最优策略=证据驱动的择优逻辑：argmax 可追溯（哪个候选取胜、凭多少分） |
| 第4站 | §10.1-10.3 | actor-critic 分离=决策与评价分离：责任划分的算法画像（谁决策、谁评价） |
| 第5站 | §8.4 | DQN 三技巧=算法稳定性的工程保障；半梯度的局限=Baird 反例→算法不可盲信 |

**读完能回答**：当 AI 推荐与医师判断冲突时，责任在"决策者"还是"评价标准"（actor/critic 分离）？诊疗决策链如何完整留痕（轨迹=审计日志）？算法的"推荐依据"能否向患者解释（价值/argmax 可量化）？

**平台对应物**：决策轨迹日志=审计证据；证据等级=可追溯的依据强度；法者 Agent 知识库（医保报销/执法分级）与决策链对接；纠纷预防=决策可解释性。
