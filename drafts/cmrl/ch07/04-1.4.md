## 7.4 多目标与约束：健康的多维平衡

### 7.4.1 多目标与约束：概念与内涵

单目标问题只有一个追求，多目标问题则要同时照顾多个互相竞争的方向。健康天然是多目标问题：疗效要好，代价要小；见效要快，根基要稳；指标要好看，体验要舒服；个人要受益，资源要公平。第 7.3 节的四维框架进一步表明，多目标不只是多几项打分，而是不同维度之间存在真实的此消彼长——调理肝郁可能伴随短暂的胃肠不适，增加运动量可能加重关节负荷，追求用药速效可能牺牲远期安全。强化学习处理多目标的标准方式，是把多个目标合成一个：奖励向量 R = (r1, r2, r3, r4) 通过加权求和化为标量 R = Σ wi·ri，权重 wi 表达设计者对各个目标的重视程度。权重不是技术细节，而是价值观的技术化：权重偏疗效，系统就偏激进；权重偏安全，系统就偏保守；权重由医者、患者、规者共同商定，多目标优化在本质上是一次关于何为好的集体协商。多目标在临床中随处可见：治疗咳嗽，既要止咳（症状目标），又要化痰以除病根（病因目标），还要不伤脾胃（安全目标）、价格可承受（资源目标）；三拗汤宣肺散寒、二陈汤燥湿化痰、六君子汤益气健脾，侧重点各不相同，没有一方能同时满足所有目标。中医复方本身就是多目标的载体——君药治主症，臣药佐之，佐使药兼顾兼症与安全，一张方子的结构就是对多目标的权衡；学习多目标优化，等于把复方配伍的逻辑翻译成数学语言。

多目标问题中，几乎没有全局最优，只有帕累托最优（Pareto optimality）：如果一个方案在不损害任何其他目标的前提下，已经无法再改善任何一个目标，它就是帕累托最优的。通俗地说，就是已经没法在不伤害任何一方的情况下让任何一方更好。健康的帕累托前沿上排列着许多合理方案——有的更重疗效、有的更重体验，没有一个是绝对最好的，选哪个取决于权重与情境。直观图景：在疗效与体验两个目标构成的平面上，可行方案形成一条向右上方凸起的曲线，右端方案疗效更高但体验更差，左端方案体验更好但疗效偏低，中间是一系列鱼与熊掌的不同配比。约束（constraint）则划出不可逾越的红线：用药禁忌、剂量上限、安全阈值、伦理底线、资源上限。有约束的多目标问题，可行域不再是全部方案，而是红线之内的部分，最适解必须在可行域内寻找。中医对此有天然理解：十八反、十九畏、妊娠禁忌药，就是千年临床总结的约束清单；有是证用是药、无是证则罢，是目标随证候调整的朴素表达。妊娠期用药的可行域被禁忌药清单大幅收窄，红线之外的高疗效方案即使存在也一律不可用——这就是约束对目标说不的合法权力。约束不是对优化的限制，而是对生命的保护，是适度哲学的底线条款。

### 7.4.2 多目标与约束：方法与实现

多目标与约束在实现上常用的有三条路线。其一，权重法：给每个目标设权重后线性加权，把多目标化为单目标，再用第 5 章的价值迭代、策略迭代等最优求解工具计算——简单直观，但权重选择不当会掩盖某项目标被牺牲的事实，需配合敏感性分析，看看权重微调会带来多大的策略变化。其二，约束法：把安全类目标写成硬约束，例如运动心率不得超过最大心率的 85%、肝功能指标不得超限，约束之外的区域直接排除；若目标本身触线，可用惩罚项处理：R' = R − λ·max(0, c − C)，其中 c 是当前取值，C 是红线，λ 是惩罚强度——越线越远，扣分越重。其三，分层法：先满足所有硬约束，再在可行域内优化主要目标，最后用次要目标微调——这最接近临床思维：先保安全，再求疗效，再顾体验。三条路线可以组合使用，工程上常把安全红线设为硬约束、把体验偏好放进权重。权重法的敏感性分析可以这样操作：把某项目标的权重从 0.2 调到 0.3，观察最优策略是否大变；若策略剧烈翻转，说明该权重正处在敏感地带，需要谨慎取值。惩罚项的数值例子（教学示例数据）：设肝功能指标红线 C = 3 倍正常上限，某候选方剂的预测指标 c = 3.5，取 λ = 10，则惩罚 = 10×(3.5−3) = 5 分，足以把该方剂从竞争中拉下；越线越远、扣分越重，系统便自动学会远离红线，这比事后禁止更符合临床的渐进决策习惯。

以高血压患者运动处方为例走一遍实现流程。目标向量：降压幅度、体重改善、心理愉悦、长期坚持；硬约束：静息心率评估后运动心率不超过上限、无胸痛气促等危险信号、膝踝关节负荷在可承受范围；软目标：每周运动频率 3 至 5 次、每次 30 至 50 分钟。先用分层法：排除一切可能诱发心血管事件的方案（硬约束），再在可行方案中按权重优化降压与愉悦（主要目标），最后用长期坚持度微调（次要目标）。再以用药方案为例：目标为症状缓解与证候转化，约束为肝功能、肾功能、妊娠可能、药物相互作用；惩罚项确保任何越线的候选方剂自动失分。读者应体会：约束与目标的分工，是把绝对不能做与尽量做好分开管理；权重法回答如何取舍，约束法回答哪里不能碰，两者合起来，正是适度哲学在优化语言中的完整表达，也是把四维最适度变成可运行算法的必经之路。运动处方的数值核算（教学示例数据）：设降压幅度 0.6、体重改善 0.4、心理愉悦 0.8、长期坚持 0.7，权重取 (0.3, 0.3, 0.2, 0.2)，总目标 = 0.3×0.6 + 0.3×0.4 + 0.2×0.8 + 0.2×0.7 = 0.60；若某方案运动心率越线，按惩罚公式 10×(c−C) 计得 0.15 分（如越线 0.015 个单位），总分从 0.60 被压低到 0.45，安全优先的结论自动浮现。用药方案再细化一层：症状缓解目标之外，把转氨酶、肌酐列为硬约束，把妊娠可能设为一票否决项——任何触碰禁忌的方案直接出局，这正是分层法与硬约束的组合拳。

### 7.4.3 多目标与约束：小结与衔接

本节要点回顾：健康是多目标问题，不同目标之间存在真实权衡；加权求和把多目标化为单目标，权重是价值观的技术化表达；帕累托最优刻画没有绝对最优、只有取舍的本质；约束划出安全、耐受与伦理的红线，可行域因此收窄；实现上有权重法、约束法与分层法三条路线，工程上常以硬约束保安全、以权重顾体验。多目标与约束给四个最适度装上了计算骨架：四个维度各有权重、各有红线，优化不再是冲极值，而是在可行域内求平衡。还要记住：权重与红线都不是一次定死的，随着病程、证据与患者意愿的变化，它们需要像随证治之一样动态调整；把这种动态性写进系统，是平台长期可用性的关键，也是奖励设计从纸面走向临床的最后一公里。动态性在病程中看得最清楚：一位肺炎患者急性期以退热为目标（生理权重极高、约束为生命体征稳定），恢复期转向咳嗽与体力恢复（生理权重回落、心理与社会权重上升），出院后进入调理期（四维权重趋于均衡、环境维度开始计入）。把这种动态权重写进平台，就是随证治之的算法化——系统定期根据证候状态重算权重与红线，而不是固守一张静态奖励表；这要求奖励模块与状态观测模块紧密联动，也要求权重调整有据可依、留有记录，让每一次改动都可解释、可追溯、可审查。如此，多目标与约束才不是一次性的设计，而是随健康演化的活系统。

如果权重失衡、约束缺位，会怎样？多目标会退化为单目标，红线会被绩效压力悄悄擦除，系统滑向极端化——这正是下节的课题。滑向极端化的路径可以预演一遍：医院考核指标从综合质量简化为平均住院日，权重自然倒向缩短住院，约束（患者稳定再出院）在绩效压力下被悄悄放宽，指标连年优化，患者却反复再入院，整体质量不升反降——这是指标异化的标准剧本。7.5 节将系统解剖这类剧本：奖励黑客如何钻空子、古德哈特定律如何解释指标失灵、极端化如何破坏尺度伸缩的整体潜能，并给出识别与防范的工具箱。从本节到下一节，逻辑连贯：理解了权衡与红线是健康优化的正道，就能更清醒地识别失衡与越线的歧途；读完陷阱的教训，读者会自然追问——有没有数学工具能把系统拦在适度区间内？答案是 7.6 节的正则化与信息熵。把两节连起来读，会看到适度哲学从理念到工具的一贯脉络：先立多目标的框架，再防极端化的失守，最后用正则与熵把防线焊牢，四把尺子才真正合奏出健康的乐章。回到本节，读者会理解：多目标与约束不只是数学技巧，更是对抗指标异化的制度设计——权重守权衡、红线守底线，两者共同把系统锁在适度的轨道上。
