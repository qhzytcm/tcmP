## 3.3 多看几回取平均：从样本看价值

上一节我们学会了一个本领：用样本平均去估计期望。这一节只做一步替换，就把这个本领变成完整的价值估计方法——把要平均的对象从"随机变量的观测"换成"一条完整经历的回报"。这就是本章的主角：多看几回取平均（蒙特卡洛方法，Monte Carlo method）。它的思想朴素到极致：想知道某个状态（或某个状态—动作组合）的价值，就反复从那里出发走完整条经历，把每次的总回报记下来，最后取平均。回看 3.1 节的例子：想知道"风寒表实状态用麻黄汤"的价值，就把三十例同类病案的疗效回报逐一相加取平均。这里没有任何高深技巧，只有一条坚定信念：样本均值逼近期望，多看几回取平均，平均的智慧（大数定律）自会给出答案。在模型已知的上一章，我们解方程求价值；在无模型的本章，我们跑经历取平均——两种方法殊途同归，样本无穷多时结果一致。请务必理解这种"数据化"的本质：多看几回取平均不是新发明，而是把旧算法里的"期望计算"换成"样本平均"。

先看最基本的版本——从固定起点出发，一条经历一个样本。要估计动作价值 q(s,a)，即"在状态 s 执行动作 a 之后按当前策略行事，平均能拿到多少回报"，做法是：从状态 s、动作 a 出发，按策略走完一条完整经历，记录总回报 G；重复 N 条这样的经历，得到 N 个回报，取平均即得估计值。用 3×3 网格世界手算一遍：从格 1 向右出发（策略为"总是向右"，边界弹回，格 6 是禁区奖励 −1，格 9 是目标奖励 +1），跑三条经历——第一条格1→格2→格3→禁区，回报 −1；第二条格1→格2→格3→目标，回报 +1；第三条同第一条，回报 −1。三条平均得 q̂ = (−1+1−1)/3 = −1/3。而真实值是多少？若从格 3 向右有半数概率进禁区、半数概率到目标，则真值 q = 0。−1/3 与 0 的差距，就是有限样本下的估计误差——平均起来不偏不倚，但具体这一次可能偏左或偏右。这个例子还透露一个关键区别：模型版给出精确值 0，改进决策万无一失；数据版给出噪声值 −1/3，改进决策可能被噪声误导，这是有限样本下策略可能震荡的根源。

多看几回取平均的估计有两个坚实的数学性质。其一是无偏性：从 (s,a) 出发的一条完整经历的回报，其期望恰好等于动作价值 q(s,a)——因为回报的期望就是价值定义本身；因此 N 条回报的平均的期望也等于 q(s,a)，即估计"平均起来不偏不倚"。其二是收敛性：由平均的智慧（大数定律），当 N 趋于无穷时，样本均值依概率收敛到真值——即"样本够多时误差消失"。无偏性保证方向正确，大数定律保证终点可达，两者合起来构成多看几回取平均的全部理论依据。但要注意它的适用条件：回报必须等整条经历结束才能计算——经历进行到一半，谁也不知道最终总分是多少。因此多看几回取平均是"离线式"学习：必须攒够完整经历才能更新一次。这带来第一个天然困难：如果任务没有明确的终止状态，例如慢性病长期管理、机器人持续作业，整条经历遥遥无期，回报就无法计算。回合任务（有终点，如一次完整诊疗、一局棋）天然适合多看几回取平均；持续任务（无终点）则必须把长轨迹人为截断成片段，截断本身就是一种近似。这个"必须等结束"的局限，正是后面边做边修正方法存在的理由。

更聪明的做法，是一条经历沿途更新多处。想象一条经历格1→格2→格3→格9（目标）：它沿途经过了三个状态—动作对 (格1,右)、(格2,右)、(格3,右)。在无折扣（γ=1）时，从每个经过的点算到结束，剩余回报都是 +1——一条经历就贡献了三个样本，而基本版本需要三条独立经历才能获得同样多的样本。这个改进叫作"沿途更新"：不再强制从每个 (s,a) 分别开始，而是从随机起点开始一条经历，走一路、算一路、更新一路，把"一条经历一个样本"变成"一条经历多个样本"，样本利用率大幅提高。若取折扣率 γ=0.9，回报更有味道：(格3,右) 的剩余回报是 1，(格2,右) 是 0.9，(格1,右) 是 0.81——越早的决策，其回报折扣越重。这直观体现了折扣率的含义：远期奖励对早期决策的价值贡献被逐级衰减。对临床而言，这意味着"当下辨证—开方"与"远期转归"之间存在权衡：折扣率大，模型看重远期康复质量；折扣率小，模型只看眼前疗效。选择多大折扣率，本质上是选择"急则治标"还是"缓则治本"。

还有一个细节必须讲清：同一状态在一条经历里出现多次怎么办。比如网格世界绕圈回到同一格，或一份病案中"心悸"在初诊和复诊反复出现。两种口径可选：首次访问式——只统计该状态（或状态—动作对）在一条经历中第一次出现时的回报，之后再次出现的回报一律丢弃；每次访问式——每次出现都统计。两种口径的性质值得记牢：首次访问式的期望恰为价值本身，无偏、理论分析最干净，实践中也最常用；每次访问式统计了同一条经历内相互关联的样本，样本之间不独立，期望仍等于价值，但方差表现因任务而异，优势是样本更多、经验利用更充分。对临床统计而言，选择哪种口径会直接影响疗效数字：同一份复诊记录，按首次访问统计与按每次访问统计，结果可能不同。因此凡是报告疗效估计，必须声明采用哪种口径——这不是吹毛求疵，而是保证"估计的是不是我们想要的那个量"的基本纪律。

回到本节要解决的终极问题：估计出价值之后干什么？答案是改进策略。把评估（多看几回取平均）与改进（选价值最高的动作）交替进行，就构成完整的"评估—改进"循环：先用大量经验估计当前策略下各动作的价值，再在每个状态把策略更新为选择价值最高的动作，然后重新评估、再次改进，直到策略不再变化。这个循环与模型已知的策略迭代完全同构，只是评估手段从解方程换成了取平均。但必须清醒地认识到一个现实困难——探索问题：为了估计某个 (s,a) 的价值，这个 (s,a) 必须被访问过；一个从未出现过的"症状组合—方剂"组合，没有任何样本，价值无从谈起。仿真世界可以把智能体放到任意格子、命令它做任意动作；真实临床却不能人为制造一个"错误起点"让患者从奇怪的状态开始治疗。这个困境的答案，正是下一节的主题：多见识——主动探索、见多识广，才能让每个角落都有经验覆盖。在结束本节前，请记住三个易错点：其一，回合必须完整走完才能计算回报，中途不能就地更新；其二，折扣率 γ<1 时回报逐项折现，最后一步奖励的权重是 γ 的高次方，不要漏乘；其三，估计价值用样本均值，分母是经历条数，不是状态数量。
