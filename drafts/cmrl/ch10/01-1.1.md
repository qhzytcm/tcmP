## 10.1 行动者-评价者架构：决策与评价分离

### 10.1.1 行动者-评价者架构：概念与内涵

行动者-评价者架构（actor-critic architecture）把决策与评价分离，是强化学习的经典框架。通俗地说，就是做事的与评事的互相配合：行动者（actor）负责决定做什么，评价者（critic）负责评估做得好不好，两者分工协作、共同进步。这一架构为什么必要？回到第9章策略梯度方法的起点。策略梯度定理指出，指标 $J(\theta)$ 的梯度可写成期望形式 $\nabla_\theta J(\theta) = \mathbb{E}_{S\sim d_\pi, A\sim\pi}[\nabla_\theta \ln \pi(A|S,\theta)\, q_\pi(S,A)]$，其中 $d_\pi$ 是策略 $\pi_\theta$ 下的状态稳态分布。期望无法解析计算，就用随机梯度逼近：$\theta_{t+1} = \theta_t + \alpha \nabla_\theta \ln \pi(a_t|s_t,\theta_t)\, q_t(s_t,a_t)$，其中 $q_t(s_t,a_t)$ 是动作价值 $q_\pi(s_t,a_t)$ 的一个估计。第9章的 REINFORCE 取 $q_t = G_t$，即蒙特卡洛回报。优点是无偏：$G_t$ 是回报的真实采样，其期望正是 $q_\pi$。缺点是方差大：$G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots$ 叠加了一整条轨迹的转移随机性与奖励随机性，两条看似相似的轨迹，回报可能天差地别。若读者在同一状态 $s$、同一动作 $a$ 下重复两次实验，一次回报 $+10$、一次回报 $-8$，以 $G_t$ 为权重的梯度更新正负颠倒，策略参数来回摆动，需要海量回合才能把期望平均出来。这就是 REINFORCE 样本效率低下的根源，也是行动者-评价者架构登场的出发点。临床中这一方差问题同样真实：同一位患者对同一首方剂的反应并非恒定，一次随访症状明显缓解，下一次随访却因饮食起居失当而反复；以整段疗程的回报为权重学习，就会在起伏中来回摆动，难以辨别方剂的真实疗效。

针对高方差，有两类自然的修正。第一类是减基线（baseline）：在加权信号中减去只依赖状态、与动作无关的函数 $b(s)$。可行是因为对任意状态 $s$，恒有 $\mathbb{E}_{A\sim\pi}[\nabla_\theta \ln \pi(A|s,\theta)\, b(s)] = b(s)\nabla_\theta \sum_a \pi(a|s,\theta) = b(s)\nabla_\theta 1 = 0$，状态相关基线对期望梯度毫无贡献；选择合适的 $b(s)$（如接近 $v_\pi(s)$）能显著压低更新步长的方差。第二类修正更根本：不再用完整回报 $G_t$ 估计 $q_\pi$，而用一个正在学习的价值函数 $\hat{q}(s,a,w)$ 提供估计——这就是评价者的登场。与 $G_t$ 相比，时序差分式的单步目标 $r_{t+1} + \gamma \hat{q}(s_{t+1},a_{t+1},w)$ 只含一步转移的随机性，方差小得多；代价是引入自举与函数近似带来的偏差。把两类修正放进一个框架，就得到行动者-评价者架构：行动者负责策略更新，评价者负责价值估计。一句话概括：用一个正在学习的价值函数（评价者），给策略梯度（行动者）提供低方差的加权信号。中医药场景中这一分工有天然的对应：医者（行动者）负责辨证开方，规者与药者（评价者）负责质控评估与处方审核——决策者与评价者分离，正是现代医疗质量管理的核心思想。这套分工可以记成一句话：行动者只管演好戏，评价者只管说真话，二者都不越位、不缺位，戏才能越演越好。平台上医者与规者、药者的参数各自更新、互不干扰，正是这套分工的工程实现。行动者与评价者分工协作、与环境环流互动的完整结构见图 10-1。

### 10.1.2 行动者-评价者架构：方法与实现

理解行动者-评价者架构有两种互补的视角。结构视角：它同时包含基于策略与基于价值两种方法。行动者指策略更新步——之所以叫行动者，是因为动作由遵循该策略产生，策略是表演者；评价者指价值更新步——之所以叫评价者，是因为它通过评估相应价值来评价行动者的表现，价值函数是评论家。两个模块并行演进：评价者用时序差分更新与函数近似学习价值，行动者用策略梯度更新策略参数，评价者的输出 $\hat{q}(s_t,a_t,w_t)$（或由它派生的信号）作为行动者更新时的加权系数。算法视角：行动者-评价者仍是策略梯度算法——策略梯度定理没有变，行动者的更新式 $\theta_{t+1} = \theta_t + \alpha_\theta \nabla_\theta \ln \pi(a_t|s_t,\theta_t)\, \hat{q}(s_t,a_t,w_t)$ 与第9章的随机梯度形式完全同构，只是把定理中的 $q_\pi$ 换成了评价者的估计。因此，行动者-评价者不是对策略梯度的否定，而是对"如何得到 $q_t$"这一环节的升级：REINFORCE 用蒙特卡洛，行动者-评价者用时序差分。为什么这样的分工合理？直觉在行动者想干什么、评价者说值不值的分离：行动者只负责把高价值动作的概率推高、把低价值动作的概率压低，不必关心价值从何而来；评价者只负责如实评估价值，不必关心策略如何更新。这种分离带来工程上的巨大便利——价值网络与策略网络可以分别设计、分别调参、分别替换。

最简的行动者-评价者算法是 Q actor-critic（QAC），把这一分工落实为两条更新式：评价者用 Sarsa 估计动作价值函数 $\hat{q}(s,a,w)$，行动者用策略梯度更新策略参数 $\theta$。评价者的更新为 $w_{t+1} = w_t + \alpha_w\big[r_{t+1} + \gamma \hat{q}(s_{t+1}, a_{t+1}, w_t) - \hat{q}(s_t, a_t, w_t)\big]\nabla_w \hat{q}(s_t, a_t, w_t)$，行动者的更新为 $\theta_{t+1} = \theta_t + \alpha_\theta \nabla_\theta \ln \pi(a_t|s_t,\theta_t)\, \hat{q}(s_t, a_t, w_t)$。对比 REINFORCE，QAC 的唯一结构性改动是把蒙特卡洛回报换成时序差分目标：评价者用一步真实奖励加上后继动作价值的当前估计构成学习目标，这与第6章 Sarsa 的更新式完全同构，只是价值函数换成了第8章的参数化形式。由于时序差分目标只包含一步转移的随机性，QAC 的更新是增量的——每与环境交互一步就更新一次，不需要等待回合结束，方差也显著低于蒙特卡洛回报。为什么说这是最简的行动者-评价者？两个模块都没有引入任何额外机制：评价者就是普通的 Sarsa，行动者就是普通的策略梯度，两者的耦合方式就是评价者的输出作为行动者的加权系数。算法流程如下：初始化策略参数 $\theta$ 与价值参数 $w$；循环执行——由当前策略采样动作 $a_t$，环境返回 $r_{t+1}, s_{t+1}$，再按同一策略采样后继动作 $a_{t+1}$；先用 Sarsa 式更新 $w$，再用策略梯度更新 $\theta$。注意时序差分误差 $\delta_t = r_{t+1} + \gamma\hat{q}(s_{t+1},a_{t+1},w_t) - \hat{q}(s_t,a_t,w_t)$ 的定义。两个学习率 $\alpha_w$ 与 $\alpha_\theta$ 可以不同，这一自由度并非可有可无：评价者必须学得比行动者快，为行动者提供相对稳定的标尺，这就是两时间尺度（two-timescale）思想，我们将在 10.2 节详细讨论。

### 10.1.3 行动者-评价者架构：小结与衔接

本节要点回顾：行动者-评价者架构是决策与评价分离的框架，行动者负责更新策略、评价者负责估计价值，评价者的输出作为行动者的加权信号；它的动机来自 REINFORCE 的高方差问题，用正在学习的价值函数替换蒙特卡洛回报，以偏差换方差；减基线是合法的，因为状态相关基线对期望梯度毫无贡献，却能显著降低更新步长的方差；最简实现 QAC 把 Sarsa 评价者与策略梯度行动者耦合起来，支持增量更新、天然适配持续任务。中医语境中，这一架构对应医者与评价者的制度分离：医者辨证开方是行动，质控与审方是评价，开方的人不管评方，评方的人不插手开方，系统才能既高效又自省。读者应当带走两个判断框架。第一个框架：评价信号的质量决定学习效率——从蒙特卡洛回报到时序差分目标，评价信号越纯，策略更新越稳。第二个框架：三个问题——每一步更新在更新什么参数、用什么信号加权、凭什么保证不偏；把三个问题应用到任何算法上，都能迅速定位它的设计动机。QAC 用 $\hat{q}$ 加权有一个隐蔽的缺点：$\hat{q}$ 的整体水平随状态起伏，状态本身值钱却被误读为这个动作好；两个动作的价值相等，概率却在随机游走，白白增加方差。问题根源在于 $\hat{q}$ 中包含了状态价值的整体水平，而策略梯度真正关心的是动作之间的相对优劣。

这引出下一节的修正：把基线 $v_\pi(s)$ 从 $q_\pi(s,a)$ 中减去，用优势函数加权——优势行动者-评价者。同时，QAC 的评价者要为每个动作维护一个价值估计，参数随动作空间线性增长；优势行动者-评价者的评价者只需估计状态价值 $v(s)$ 一个函数，参数更省。回顾全书脉络，行动者-评价者架构正是第9章策略梯度与第7、8章价值方法的汇合：行动者是策略梯度定理的化身，评价者是时序差分与函数近似的化身，两个模块的耦合又是第3章随机逼近理论中两条迭代的并行演进。把视角拉回幸福主题：决策与评价分离，正是幸福闭环的制度雏形——有人行动、有人评价、评价反馈行动，闭环由此而生。下一节，我们把评价信号从绝对水平升级为相对平均水平，看看优势函数如何让策略更新只对出乎意料的信号做出反应，而这正是中医效不更方、效改其方智慧的数学表达。带着本节的两个框架与三个问题，读者将看到：行动者-评价者不只是抽象算法，它精确刻画了辨证开方加质控反馈这一古老而现代的医疗决策循环。读者不妨带着一个问题合上本节：如果评价的标准不是绝对高低，而是相对平均的好坏，策略更新会有什么不同？
