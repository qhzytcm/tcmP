## 10.4 借力学习：用好别人的经验

### 10.4.1 借力学习：概念与内涵

借力学习是异策略学习（off-policy learning）在本书中的通俗表达：把生成数据的行为策略与被优化的目标策略解耦，让学习者能够复用别人的经验来改进自己。通俗地说，就是用别人的经验学自己的本事。10.2 与 10.3 节的 A2C、A3C 都是同策略（on-policy）算法：行为策略（生成数据的策略）就是目标策略（被优化的策略），数据用完即弃。异策略学习把两者解耦：行为策略 $\beta$ 负责收集数据，目标策略 $\pi_\theta$ 负责被优化。解耦带来三个现实收益。其一，数据复用——历史数据可以反复用于更新，样本效率大幅提升，经验回放成为可能；其二，向他人学习——可以用专家、前辈或异构智能体产生的数据优化自己的策略，例如学生医者从名老中医的医案日志中学习；其三，探索解耦——行为策略可以保持高探索（如较大熵），而目标策略稳步逼近最优。在中医语境中，借力学习有深厚的传统根基：师带徒的跟诊抄方，本质是从老师的行为数据中学习；历代医案汇编，本质是跨越时空的经验复用；经典名方的君臣佐使结构，本质是千百年前经验智慧的沉淀。借力学习把这些传承方式变成可计算、可规模化的算法机制——平台上每一份医案日志、每一次处方流转、每一段随访记录，都是可以反复学习的行为数据。

然而解耦有代价：当数据由 $\beta$ 生成时，期望 $\mathbb{E}_{A\sim\beta}[\nabla_\theta\ln\pi_\theta(A|s)\, q_\pi(s,A)]$ 一般不再等于策略梯度 $\nabla_\theta J(\theta)$——分布不对，梯度的期望就被污染。这个偏差的直观含义是：别人的经验是好经验，但那是别人的做法，与自己的策略风格未必一致；直接拿别人的数据按自己的方式学，方向就会被带偏。修正工具是重要性采样（importance sampling）。定义重要性比率（importance ratio）$\rho_t = \frac{\pi(a_t|s_t,\theta)}{\beta(a_t|s_t)}$，它度量该经验在目标策略下出现的概率相对于行为策略下出现的概率。异策略策略梯度定理给出：$\nabla_\theta J(\theta) = \mathbb{E}_{S\sim d_\beta, A\sim\beta}\big[\rho(S,A)\, \nabla_\theta \ln \pi(A|S,\theta)\, q_\pi(S,A)\big]$，其中 $d_\beta$ 是行为策略 $\beta$ 下的状态稳态分布（记号与 9.2 节一致）。直观上，重要性比率只修正了动作维度，状态维度的偏差由近似承担。于是异策略行动者-评价者的行动者更新为 $\theta_{t+1} = \theta_t + \alpha_\theta \rho_t \nabla_\theta \ln \pi(a_t|s_t,\theta_t)\, \hat{q}(s_t,a_t,w_t)$，评价者相应使用加权后的时序差分更新（如加权 Sarsa 或 Q-learning 式），保证价值估计与目标策略一致。用一个生活化的例子体会分布偏差：一位擅长温补的医者（行为策略）的医案，如果直接用来训练一位擅用寒凉的医者（目标策略），训练方向就会被带偏——前者多用温药、后者少用温药，同一份经验对两人的价值完全不同；重要性比率正是这把转换尺：经验在自己策略下越典型，权重越高，越不典型，权重越低。平台上的历史医案大多来自不同流派、不同风格的医者，直接拿来学习必然引入分布偏差，这正是借力学习必须配备重要性修正的原因。

### 10.4.2 借力学习：方法与实现

借力学习的核心操作是计算重要性比率。设行为策略为均匀分布 $\beta(a_1) = \beta(a_2) = 0.5$，目标策略 $\pi(a_1) = 0.8$，$\pi(a_2) = 0.2$。若某步实际采取 $a_2$，则 $\rho_t = \frac{0.2}{0.5} = 0.4 < 1$——这个经验在目标策略下不那么典型，其梯度贡献被调低；若实际采取 $a_1$，则 $\rho_t = \frac{0.8}{0.5} = 1.6 > 1$——这个经验在目标策略下更典型，贡献被调高。直观地说，异策略学习是用借来的数据学自己的策略：$\beta$ 采的数据要按 $\pi$ 与 $\beta$ 的相符程度重新加权，$\rho_t$ 就是那把尺子。风险在于 $\rho_t$ 可能很大（当 $\beta$ 远小于 $\pi$ 时），造成方差爆炸；工程上的对策是裁剪比率或采用自归一化估计——这些技术直接演化成 10.5 节近端策略优化的裁剪目标与 V-trace 等算法。把例子续成一笔完整的数值演算：取 softmax 策略设定（$\theta = (0.5, 0.3)$，$\pi(a_1) = 0.5498$，$\pi(a_2) = 0.4502$），假设数据由均匀行为策略 $\beta$ 产生，第 $t$ 步实际采取 $a_2$、评价者给出 $\hat{q}(s,a_2) = 0.4$、$\alpha_\theta = 0.1$。未修正的更新为 $\Delta\theta = 0.1 \times (-0.5498, 0.5498) \times 0.4 = (-0.0220, 0.0220)$；重要性比率 $\rho_t = \frac{0.4502}{0.5} = 0.9004$，修正后的更新为 $(-0.0198, 0.0198)$——因为目标策略给 $a_2$ 的概率（0.4502）低于行为策略（0.5），该经验被轻微调低。若目标策略给 $a_2$ 的概率远高于 $\beta$（例如 0.9），则 $\rho_t = 1.8$，同样的经验贡献被放大近一倍。这个例子的要义在于：借力学习不是简单地照搬别人的数据，而是先问一句——这份经验放在我的策略下，有多典型？典型则多学，不典型则少学，太过离谱则不学。这把尺子，让历史数据、名医医案、同行经验都能被安全地转化为自己的学习材料。

在平台上实现借力学习，有三个工程要点。第一，数据池的组织：历史数据要按来源、时间、质量分级标注——名老中医的医案、普通医师的病例、平台自产的经验轨迹，可信度不同、风格不同，需要分别对待；借力学习不是不加甄别地拿所有数据来学，而是有选择、有加权地借。第二，行为策略的记录：重要性采样需要知道每条数据由什么策略产生，因此数据池必须记录行为策略的分布信息——这对应医疗场景中的病历溯源要求：每一份处方来自哪位医者、基于什么辨证，都要可追溯。第三，比率的控制：为防方差爆炸，实践中常对 $\rho_t$ 设上限（如裁剪到 $[1-\varepsilon, 1+\varepsilon]$ 或直接截断），把借来的经验限制在可信范围内——正如跟师学习要选择与自己水平相称的医案，好高骛远地学习远超自身水平的经验，反而有害。异策略行动者-评价者是现代深度强化学习的重要谱系：SAC（Soft Actor-Critic）把最大熵纳入目标，熵项鼓励探索与鲁棒性，配合双 Q 评价者抑制最大化偏差；DDPG（深度确定性策略梯度）用确定性策略配合回放，直接处理连续动作空间。回到本章主线：异步并行回答如何更快，借力学习回答如何更省，两者都以 10.2 节的 A2C 为内核。这一谱系提醒读者：借力学习并非孤立的技巧，而是贯穿现代强化学习的一条主线。

### 10.4.3 借力学习：小结与衔接

本节要点回顾：借力学习即异策略学习，把行为策略与目标策略解耦，带来数据复用、向他人学习、探索解耦三个收益；代价是分布偏差，修正工具是重要性比率 $\rho_t = \pi(a_t|s_t,\theta)/\beta(a_t|s_t)$，按经验的典型程度重新加权梯度贡献；$\rho_t$ 过大造成方差爆炸，工程上以裁剪或截断控制；异策略行动者-评价者谱系包括加权 Sarsa、SAC、DDPG 等现代成员。借力学习的本质，是承认并善用经验的多样性：不同来源的经验都是财富，但要用对方法——按典型程度加权、按可信程度甄别、按适当程度控制。这与中医传承的智慧一脉相承：跟师抄方不是机械复制老师的每一张方子，而是理解老师辨证的思路（目标策略），在自己的临床中反复检验（行为策略），把老师的经验内化成自己的能力——借力学习的每一步，都是这一内化过程的算法化。读者应当体会：借力学习把幸福闭环从单人的闭环扩展为代际的闭环——前人经验滋养后人，后人实践反哺知识库，闭环在时间维度上不断延伸。三个要点还提示了一个制度含义：数据分级标注不是技术细节，而是伦理选择——什么样的经验值得被学习、以多大权重被学习，决定了一个知识库的品格；借力学习的每一步，都在回答如何对待别人的经验这一根本问题。

衔接下一节：借力学习用重要性比率修正分布偏差，但重要性采样有一个固有风险——$\rho_t$ 可能很大，导致方差爆炸；裁剪比率可以控制方差，但裁剪到哪里才是合理的？更重要的是，无论同策略的异步更新，还是异策略的重要性修正，都还缺少一个稳健性的系统保证：用近似的评价者替代 $q_\pi$，会不会把梯度方向带偏？每次更新的步子迈多大才不至于破坏已有的策略？这两个问题由下一节的近端策略优化回答。近端策略优化的核心思想是步子别迈太大、稳扎稳打地改进：每次更新都限制在与旧策略足够近的范围内，宁可小步慢走，不可大步跌倒。从幸福哲学看，这一思想正是适度而非最优化原则在算法层面的落实——第7章确立的最适度理念，在这里获得了最精确的数学表达：信赖域、裁剪目标、KL 散度约束，都是把别走极端写成可计算的公式。带着对借力与稳健的双重理解，读者将进入本章乃至全书在算法层面的收官——近端策略优化。简而言之：借力让学习看得远，稳健让学习走得稳——两者合璧，才构成了幸福闭环在数据维度上的完整支撑。下一节将给出稳健更新的具体算法，把适度哲学变成可运行的公式。
