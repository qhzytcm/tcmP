## 4.1 状态价值：长期健康的期望

### 4.1.1 概念与内涵

一位失眠三个月的患者坐在诊室里，主诉入睡困难、多梦、心悸，舌淡苔薄。医师心里有两个问题：这个证候将来会怎样发展？自己开出的归脾汤，从长远看能不能把患者带回健康？一次见效不能证明方案高明——失眠有自然波动，患者可能恰好自愈；一次不见效也不能证明方案错误——疗程未满，转机可能在后头。单次疗效的反馈充满随机性，就像掷骰子：一次的输赢说明不了骰子的偏心。要科学回答"这个方案从长远看好不好"，必须把随机性平均掉，考察长期好坏的期望。这正是中编“确认信仰”的第一环：把疗效的“信仰”转化为可以计算、可以比较的数字。上一章我们学会用统计方法直接从数据估计疗效，但要等完整过程、要攒够样本；本章换一条更系统的路径——利用证候之间的递归关系建立方程，把价值算出来。中编“确认信仰”共三章：第4章把信仰算成价值（价值估计），第5章把最优方案挑出来（最优价值迭代），第6章用在线经验检验信仰（时序差分）；三章环环相扣，读者无需跳跃，即可从“价值可算”走到“价值经得起检验”。我们称这种"站在某个健康状况上，对未来长期好坏的期望"为状态价值（state value）。在强化学习的语言里，健康状况就是状态（state），治法方剂就是动作（action），疗效反馈就是奖励（reward），医师的诊疗路径就是策略（policy）。状态价值要回答的，正是"按当前诊疗路径走下去，这个证候的长期前途如何"。

要把这个直觉写成数学，需要三个记号。第一是折扣回报（discounted return）Gt = Rt+1 + γRt+2 + γ²Rt+3 + …，它把未来各时刻的疗效奖励折算到今天：γ 是折扣率，取 (0,1) 内的值，γ 越接近 1，远期疗效越被看重。折扣回报解决一个现实问题：疗效沿病程逐日累积，今天的缓解与半年后的复发不能简单相加，必须用统一标尺折算。第二是条件期望 E[·|·]，它回答"平均意义上如何"。第三是状态价值函数 vπ(s) = E[Gt | St = s]，读作：在状态 s（如"入睡困难+多梦+心悸+舌淡苔薄"这个证候组合）上，按策略 π 诊疗，折扣回报的期望。这个定义有三点值得咀嚼：它依赖状态——接近康复的证候价值高，迁延难愈的证候价值低，这是"位置决定前景"的数学表述；它依赖策略——同一证候走归脾汤的路径与走银翘散的路径，长期前途不同；它不依赖时刻——同一证候的未来演化只由证候与策略决定，与"今天是什么日子"无关。三点合起来，状态价值就是"状态与策略的函数"，一个可计算、可比较的确定性数字。

### 4.1.2 方法与实现

知道了定义，如何计算状态价值？最直接的办法是枚举所有可能的病程轨迹：列出每一种转归、每一条处方史，计算每条轨迹的折扣回报，再按概率加权。这个方法理论上有理，实践上不可行——轨迹数随病程步数指数爆炸，一个九宫格迷宫三步以内就有百余条路径，真实临床的证候转归更是不计其数。但有一个特例可以手工起步：当策略和转归都是确定性的，从状态 s 出发只有唯一一条轨迹，期望作用于常数等于常数本身，此时状态价值就是那条唯一轨迹的折扣回报。例4.1 考虑一条简化的失眠病程链：s1 为"失眠初起"，s2 为"心脾两虚证"，s3 为"康复"，s4 为"迁延难愈"。取 γ=0.9，设从 s1 到 s2 奖励 0，从 s2 到 s3（康复）奖励 +1，此后停留在 s3 每步 +1。则 vπ(s3) = 1 + 0.9 + 0.81 + … = 1/(1−0.9) = 10（等比数列求和：公比 0.9 小于 1，总和 = 首项/(1−公比)）；vπ(s2) = 0 + 0.9×10 = 9；vπ(s1) = 0 + 0.9×9 = 8.1。数字说明：距离康复越远，价值越低；每一步延误都以折扣的形式磨损长期收益。这就是"长期健康的期望"的可计算版本。

当策略或转归带有随机性时，情形复杂一些：从同一状态出发可能走出不同轨迹，状态价值成为加权平均。设想按某个随机策略从 s1 出发一百次，大约一半走向康复、一半走向迁延，这一百次回报的平均值会趋近 vπ(s1)，但任何单次运行都只经历其中一条轨迹——期望抹平了随机性，实际运行永远只看到随机性的一个实现。落到临床上就是一句话：评价一位医师的诊疗方案，不能只看单次处方的即时反馈，而要看沿整个病程累积的期望疗效。同理，tcmP 平台评估"辨证→方剂"决策链时，也应以期望临床价值为准，而不是单次病例的成败。这里采用了期望准则——以长期平均收益最大化为目标。期望不是唯一选择：风险规避场合可以用最坏情形或条件风险价值，那是扩展方向；本书如无特别说明，一律用期望。有了状态价值这个指标，策略比较就完成了从"直觉"到"数字"的翻译：策略甲在每个状态的价值都不低于策略乙，就说甲不劣于乙。然而，枚举轨迹的计算方式注定走不远，下一节将给出不枚举轨迹的聪明办法。

### 4.1.3 小结与衔接

本节完成了一件事：把"这个方案从长远看好不好"翻译成"状态价值 vπ(s) = E[Gt | St = s]"这个可计算的数字。回顾这条逻辑链：回报是评价策略的合理起点，它把未来疗效折算到今天，γ 调节"短视"与"远视"的权衡；但当策略或转归随机时，回报本身成为随机变量，一次高分证明不了策略好，一次低分也证明不了策略差，于是必须取期望——期望就是状态价值。状态价值有三重身份：它是"状态与策略的函数"而非"时间的函数"；它是"平均意义上的长期前途"而非"某一次的具体遭遇"；它是策略比较的形式化指标，数值越大，从这个证候出发越有希望获得高疗效。本节还演示了两种计算途径：确定性情形下直接算轨迹回报，随机情形下取加权平均。它们共同说明了状态价值的基本性格——位置决定前景，策略决定命运，折扣决定远近。把状态价值与平台术语做一次对照：网格世界的格子对应症状组合，移动动作对应辨证—方剂决策，+1/−1 奖励对应证据等级映射，状态价值对应症状组合的临床价值。有了这张对照表，后续每一节的概念都能在平台上找到落点，读者可随时把抽象公式翻译回临床语言。

但本节留下两个悬而未决的问题。第一，枚举轨迹在真实临床中不可行，需要一种不枚举轨迹、直接由状态之间关系求解价值的数学工具；第二，仔细看状态价值的定义会发现一个"耦合"现象：vπ(s) 的回报跨越多步，必然经过中间状态，而中间状态的价值也是 vπ 的一部分——一个状态的价值依赖其他状态的价值，全体状态价值彼此纠缠。这个耦合既是麻烦，也是出路：如果能把这种依赖写成显式方程，就能把"枚举轨迹"转化为"解方程"。下一节的价值估计方程（Bellman equation，贝尔曼方程）正是这样一部"递归账本"：今天的判断来自过去经验的递归表达——当前证候的期望价值，等于当下的处理效果，加上折扣后的后继状态价值。这部账本将是量化疗效信仰的第一件核心工具。理解"回报→期望→状态价值→耦合方程"这条逻辑链，就握住了本章主线。状态价值的引入并不否定经验，而是给经验加了一把刻度尺：老医师的直觉依然珍贵，但直觉背后的"为什么"——哪些证候价值高、哪些路径价值低——从此可以被检查、被传递、被改进。下一节将推导那部递归账本，把"这个证候将来会怎样转"的经验写成可以求解的方程。
