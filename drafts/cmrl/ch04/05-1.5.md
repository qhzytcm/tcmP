## 4.5 收敛性与唯一性

### 4.5.1 概念与内涵

上一节的解析解回答了"价值可计算"，但留下两个悬而未决的问题：如果不用求逆、改用反复迭代，会不会收敛？如果方程有两个解，价值还谈得上"确认"吗？这两个问题分别指向价值估计方程的两个基本性质——收敛性与唯一性。把问题问全，其实是三个：价值存不存在？是不是只有一个？如何把它算出来？对应的答案是三个定理：存在性——对任意策略与任意转移结构，价值方程必有解；唯一性——解只有一个，状态价值是良定义的；迭代收敛——对任意初始估计，迭代 vk+1 = rπ + γPπvk 必然收敛到真实价值。通俗地说，这三个定理回答的是账本的基本质量：账本一定记得平（存在性）；只有一本账、不会出现两本对不上的账（唯一性）；反复核对账目会越对越准、不会越对越乱（收敛性）。对中医而言，这三条性质的临床含义是：只要远期疗效权重严格小于当下，疗效价值就一定存在、唯一、可被反复评估逼近——临床价值的估计是"越估越准"，而不是"越估越飘"。把三性质与上一节的矩阵论证对照，还能看到一条分工：存在性来自代数论证（矩阵可逆），唯一性与收敛性来自分析论证（范数收缩）——两者合起来，数学的"代数面"与"分析面"在价值理论上首次交汇。对读者而言，不必精通谱理论的全部细节，但应当理解三性质在说什么、为什么成立，以及它们如何支撑后续算法。后续章节遇到"算法收敛"的表述时，本质都是这三个定理的变体。

存在性其实在上一节已经证明过了：因为 ρ(γPπ) ≤ γ < 1，所以 I − γPπ 可逆，v = (I − γPπ)⁻¹ rπ 就是方程的解。这个证明的妙处在于，它只用到了矩阵谱理论的两条简单事实——随机矩阵谱半径不大于 1，以及数乘缩放谱半径——而完全不依赖 MDP 的具体结构。无论证候转归多么复杂、疗效奖励设计多么刁钻，只要 γ ∈ (0,1)，解就存在。这里值得体会"折扣"的分量：如果 γ=1 且系统含有吸收环（如例4.4 中一直停留在 s4 获得 +1），那么 (I − Pπ) 奇异，方程可能无解——直观上，无限长的 +1 序列求和发散。折扣率 γ 的引入本质上是对"无限未来"的一种正则化：它让几何级数收敛，让方程永远良定义。这也是为什么几乎所有强化学习理论都要求 γ ∈ (0,1)：不是技术上的吹毛求疵，而是理论大厦的地基。唯一性的证明思路同样简洁：假设 v1 与 v2 都是方程的解，两式相减得 v1 − v2 = γPπ(v1 − v2)，记 δ = v1 − v2，则 δ = γPπδ；取无穷范数，‖δ‖∞ ≤ γ‖Pπ‖∞‖δ‖∞ = γ‖δ‖∞，因 γ < 1，只有 ‖δ‖∞ = 0 才可能，故 v1 = v2，解只有一个。通俗地说：若两本"账"都记平了，它们的差额在转移一圈后必须至少缩小 γ 倍；可差额又等于它自己——唯一能同时满足"保持不变"与"必须缩小"的量只有零，所以两本账必是同一本。

### 4.5.2 方法与实现

存在性与唯一性回答了"解是什么"，迭代收敛回答"怎么算"。定理说：任取初始值 v0（例如全零向量），按迭代格式 vk+1 = rπ + γPπvk 反复更新，所得序列 {vk} 收敛到真实价值 vπ。证明同样走收缩路线：vπ − vk+1 = (rπ + γPπvπ) − (rπ + γPπvk) = γPπ(vπ − vk)，于是 ‖vπ − vk+1‖∞ ≤ γ‖vπ − vk‖∞ ≤ … ≤ γ^(k+1)‖vπ − v0‖∞。因为 γ^(k+1) → 0，误差以几何速率收缩到零——收敛速率是线性的，速率为 γ。这个定理把"求逆矩阵"的方案替换成"反复迭代"的方案：每次迭代只做一次矩阵乘向量乘法，复杂度 O(n²)，且不需要任何求逆运算；在稀疏转移结构下还可以降到 O(n) 量级。更重要的是，迭代方案只需要"能计算 rπ + γPπv"的能力，不需要显式知道 Pπ 的解析形式——这个看似不起眼的放松，正是后续无模型算法的伏笔：到时候连 Pπ 都不给，只给采样，但迭代的思想原封不动地保留下来。迭代背后的模式可以提炼为一个更一般的概念——收缩映射（contraction mapping）：若映射 F 满足对任意 v、v′ 都有 ‖F(v) − F(v′)‖ ≤ γ‖v − v′‖ 且 γ < 1，则 F 必有唯一不动点，且从任意初值出发的迭代都收敛到该不动点。

例4.5 对例4.4 的四状态模型演示迭代过程。已知 γ=0.9，rπ = [0,1,1,1]ᵀ，精确解 vπ = [9,10,10,10]ᵀ。取初始值 v0 = [0,0,0,0]ᵀ，迭代 vk+1 = rπ + γPπvk。第一步：v1 = [0,1,1,1]ᵀ。第二步：Pπv1 = [1,1,1,1]ᵀ，v2 = [0,1,1,1]ᵀ + 0.9×[1,1,1,1]ᵀ = [0.9,1.9,1.9,1.9]ᵀ。第三步：Pπv2 = [1.9,1.9,1.9,1.9]ᵀ，v3 = [0,1,1,1]ᵀ + 0.9×[1.9,1.9,1.9,1.9]ᵀ = [1.71,2.71,2.71,2.71]ᵀ。第四步：Pπv3 = [2.71,2.71,2.71,2.71]ᵀ，v4 = [0,1,1,1]ᵀ + 0.9×[2.71,2.71,2.71,2.71]ᵀ = [2.439,3.439,3.439,3.439]ᵀ。可以看到四个分量以相同速率逼近各自的极限 9 与 10，每步把差距乘以约 0.9，与误差界吻合；由于每步只缩到 0.9 倍，20 步后差距仍约为初始的 0.12 倍（尚余 1 左右），要到前三、四位小数完全一致，需迭代约 90 步——几何收敛的特点是"开始快、越到后面越慢"。这个例子直观地展示了"迭代逼近"与"直接求逆"殊途同归，也预告了价值迭代算法的雏形：把"解方程"变成"迭代逼近"，代价是无穷多步但每步便宜，收益是避开求逆且只依赖可计算的矩阵向量积。对临床价值估计而言，这条性质带来一个实用的推论：不同医师、不同初值出发，只要遵循同一套转归与奖励数据，反复评估终将收敛到同一个价值——临床共识在数学上是可以实现的。

### 4.5.3 小结与衔接

把三个定理连起来读：存在性 + 唯一性 + 迭代收敛，构成了一个完整的"可解性"结论——价值估计方程不仅总是有唯一解，而且总能通过简单的迭代把它算出来。这组结论对全书的意义怎么强调都不过分：它是价值迭代、策略迭代算法的直接理论依据——算法不过是在迭代格式 vk+1 = rπ + γPπvk 或其变体上叠加策略改进步骤；它是无模型算法的思想源头——真实环境中无法写出 Pπ，但可以采样，用采样得到的奖励与后继状态代替期望，迭代格式就变成时序差分更新；它揭示了折扣率 γ 的双重身份——在问题语义上，γ 调节短期与长期利益的权重；在数学结构上，γ 是保证收缩、保证收敛的参数。理解这层双重身份，是理解"强化学习为什么需要折扣"的关键。本节还给出了收缩映射的一般表述：价值估计方程右端定义的映射 v ↦ rπ + γPπv 正是压缩比为 γ 的收缩映射——这就是三个性质的共同根源。读者可以做一个简单的思想实验来感受收缩的含义：把两张略有出入的初始账本放进迭代，每过一步，它们之间的差距就缩小 γ 倍；二十步后，差距只剩下初始差距的 0.9²⁰ ≈ 0.12 倍——约一成多，还没到"几乎重合"；要到 0.1% 以内的"几乎重合"，还需约 90 步。这就是"不同医师、不同初值终将趋同"的数学直觉来源，也是几何收敛"前快后慢"的直观感受。收缩论证将在后续章节反复出现，建议读者把"γ < 1 → 收缩 → 收敛"这组对应关系当作一种本能反应来培养。

回顾本节，我们为"价值的可计算性"补上了最后一块理论拼图：解存在、解唯一、迭代必收敛。这组性质把上一节的解析解从"一个公式"升级为"一套理论"——不仅价值可计算，而且计算过程稳定、结果可重复。对信仰的量化而言，收敛性与唯一性还有一层深意：如果反复评估的结果彼此冲突，疗效的"信仰"就无从建立；正因为价值估计终将收敛到唯一答案，医患之间、医师之间才可能对"这个方案到底值多少"达成一致。三性质也是后续所有算法的地基：下一章引入最优策略后，价值迭代算法的收敛性、策略改进的单调性，都建立在本节的收缩论证之上。到目前为止，我们已经完成了价值理论的主体：状态价值、动作价值、价值估计方程、矩阵求解、收敛性与唯一性。但还有一个问题悬而未决——这些数字衡量的是"疗效"，而"疗效"到底包含什么？即时缓解、远期转归、生活质量、复发风险，哪些该进账本？下一节"价值与信仰：全要素疗效的确认"将回答这个问题：价值不是凭空设定的，它是对疗效全要素的量化确认。
