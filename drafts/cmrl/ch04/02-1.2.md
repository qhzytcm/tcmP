## 4.2 价值估计方程：经验的递归表达

### 4.2.1 概念与内涵

上一节定义了状态价值，却留下一个尴尬：按定义直接算，就要枚举所有病程轨迹，轨迹数随步数指数爆炸，九格迷宫尚且手忙脚乱，真实临床更不可能。转折点来自一个不起眼的观察——回报的递归结构。把折扣回报拆开看：Gt = Rt+1 + γRt+2 + γ²Rt+3 + … = Rt+1 + γ(Rt+2 + γRt+3 + γ²Rt+4 + …)，括号里不是别的，正是从下一时刻开始的折扣回报 Gt+1。于是得到恒等式 Gt = Rt+1 + γGt+1。这个结构称为自举（bootstrap）：一个量用它自己下一时刻的版本来表示。它把"无限长的折扣和"化为"一项即时奖励 + 一个未来量"，把跨越多步的问题化为"一步 + 剩余"的递归问题。对价值取期望后，这个递归结构就变成一部账本：一个状态的价值，等于当下的收获，加上折扣后的后继状态的期望价值。这就是价值估计方程（value estimation equation），也就是贝尔曼方程（Bellman equation）——通俗地说，它是"今天的判断来自过去经验的递归账本"：老医师说"这个证候我见过，将来会这样转"，就是在做一条递归记账。

老医师的经验为什么能写成方程？因为辨证论治本身就是递归的：面对"入睡困难+多梦+心悸"这个证候，医师先处理当下（开归脾汤，期望即时缓解），再预测转归（症状缓解进入恢复期，或并发心悸加重）。当下的处理效果加上折扣后的转归价值，就是这个证候的期望前途。写成数学，就是价值估计方程的标准形式：vπ(s) = Σa π(a|s)[Σr p(r|s,a) r + γ Σs′ p(s′|s,a) vπ(s′)]，对一切状态 s 成立。这个式子要逐字拆解：方括号内有两部分，Σr p(r|s,a) r 是采取动作 a 的期望即时奖励；γ Σs′ p(s′|s,a) vπ(s′) 是转移到各后继状态后未来价值的折扣期望。两者合起来，就是"在状态 s 采取动作 a"这一步的期望价值；再按策略 π(a|s) 对动作加权平均，就得到状态 s 的价值。方程传达的核心思想是：从一个证候出发的长期前途，取决于从其他证候出发的长期前途——状态价值相互耦合，有多少个状态就有多少个方程。这正是强化学习与单步决策的根本区别：单步决策只需比较即时奖励，多步决策必须同时解开所有状态之间的依赖。

### 4.2.2 方法与实现

价值估计方程的推导只有三步，每一步都有依据。第一步是自举：从回报的递归结构 Gt = Rt+1 + γGt+1 出发。第二步是取条件期望：对恒等式两端在条件 St = s 下取期望，左端正是状态价值 vπ(s)；右端利用期望的线性性，拆成即时奖励与未来回报两项。第三步是展开：对即时奖励，用全期望公式——状态 s 下按策略 π 以概率 π(a|s) 选择动作 a，环境以概率 p(r|s,a) 给出奖励 r，故 E[Rt+1 | St = s] = Σa π(a|s) Σr p(r|s,a) r；对未来回报，先对"下一步转移到哪个状态"取平均，再用马尔可夫性质（Markov property）切断历史依赖：E[Gt+1 | St+1 = s′] = vπ(s′)。三步合起来，就得到方程。这条推导链的每一步都值得背诵：自举给出递归结构，全期望公式处理随机性，马尔可夫性质切断历史。初学者常问：为什么能对"未来"取期望？答案正是马尔可夫性质——给定当前证候，未来的演化只由证候与策略决定，与更早的病史无关；在临床上，这意味着辨证论治关注的是"当下的证"，而不是"所有过去的因"。

例4.2 用价值估计方程重算例4.1 的失眠病程链：s1→s2（奖励 0）、s2→s3（到达康复，奖励 +1）、s3 停留（每步 +1），γ=0.9，策略确定。先写 s3 的方程：vπ(s3) = 1 + 0.9 vπ(s3)，解得 10。再写 s2：vπ(s2) = 1 + 0.9 vπ(s3) = 10——注意"到达康复"这一步本身奖励 +1，不能漏写。最后写 s1：vπ(s1) = 0 + 0.9 vπ(s2) = 9。与例4.1 按正确口径枚举的结果完全一致——例4.1 正文演示的 vπ(s2)=9、vπ(s1)=8.1 系漏记 s2→s3 奖励的错误记法（见 4.1.2 节说明），正确口径即图 4-1 的修正值 vπ(s1)=9、vπ(s2)=10、vπ(s3)=10。但这里有一个插曲：若把 s2 到 s3 的奖励误记为 0，方程也会解出 vπ(s1) = 8.1，与正确枚举结果矛盾。这个"看似矛盾"的插曲正是学习价值估计方程最有价值的一课——方程迫使你把每一步的奖励写清楚，任何含糊都会在联立求解时暴露出来。方程还带来一个好消息：它是线性的，v 只以一次幂出现，可以写成方程组用线性代数处理，这是下一节之后展开矩阵求解的前提。在 tcmP 平台的语境里，价值估计方程对应着辨证的递归本质：一个症状组合的期望疗效，等于当下处理的效果加上 γ 倍的后继状态价值——辨证不是一次性的静态判断，而是沿着病程递归展开的动态评估。

### 4.2.3 小结与衔接

本节完成了全章最关键的一步推导：由自举恒等式 Gt = Rt+1 + γGt+1 出发，对两端取条件期望，利用全期望公式与马尔可夫性质，得到价值估计方程 vπ(s) = Σa π(a|s)[Σr p(r|s,a) r + γ Σs′ p(s′|s,a) vπ(s′)]。这部"递归账本"的价值怎么强调都不过分：它把"枚举轨迹"的指数级难题，转化为"解线性方程组"的多项式级问题。枚举轨迹要列出所有可能的未来，解方程只需要状态之间的相邻关系——就像老医师不必重新经历每一位病人，只需把"这个证候会怎样转"的记账规则写下来。方程的每个组成部分都有临床对应物：即时奖励对应当下的处理效果，转移概率对应证候的转归规律，后继价值对应转归状态的长期前途，折扣率对应远期疗效的权重，策略对应诊疗路径。理解这些对应关系，是把方程当作临床工具而不是黑板公式的关键。方程还隐含一个方法论启示：经验的价值不在于罗列事实，而在于提炼规则。老医师见过千百例失眠，真正传下来的不是病例清单，而是"心脾两虚→归脾汤→多预后良好"这样的转归规则；价值估计方程正是这种规则的数学形态。当一位规培医师学会把老师的话翻译成转移概率与奖励，他就掌握了把经验写进账本的能力——这是师带徒制度在量化时代的延续方式。

回顾本节，我们建立了一个核心等式和一条推导链。核心等式即价值估计方程，它揭示了状态价值相互耦合的方程组结构。推导链是：自举→条件期望→全期望公式→马尔可夫性质，每一步都是后续所有强化学习算法的元构件。我们还看到一个重要性质：方程是线性的，这为矩阵工具打开了大门。但问题也随之而来：方程有 n 个未知数、n 个等式，如何求解？状态少时手工消元尚可，状态一多，方程之间的纠缠就超出人力范围。此外，目前的价值都依附于策略 π 而存在，医师更关心另一个问题：给定一个证候，到底该选哪首方剂？这两件事——求解方程的方法、决策的依据——分别指向下一节的动作价值与再下一节的矩阵求解。下一节先引入动作价值：站在某个证候上选择某首方剂，对未来长期好坏的期望。它是"方剂选择的依据"，也是把"评价"推进到"选择"的关键一步。需要说明的是，本节推导的价值估计方程是"评价"工具：给定策略，算价值；它不回答"哪个策略最好"，只回答"这个策略值多少"。区分这两件事很重要——下一章的最优策略研究将回答前一个问题，本章所有内容都为它做准备。
