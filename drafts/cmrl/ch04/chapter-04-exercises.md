## 第一部分 基础题（60 分，每题 10 分）

### 基础题 1（对应节号：4.1 状态价值）

【单选题】关于状态价值 vπ(s) = E[Gt | St = s]，下列说法正确的是（ ）

A. 它衡量的是某一次具体诊疗的即时疗效
B. 它依赖时刻 t，同一证候在不同日期就诊，价值不同
C. 它是在状态 s 上按策略 π 诊疗、折扣回报的期望，不依赖时刻 t
D. 它只由状态决定，与策略无关

【参考答案】C。正文 4.1.1 对状态价值定义的三点注解：它依赖状态（位置决定前景）、依赖策略（同一证候走归脾汤路径与银翘散路径前途不同）、不依赖时刻（从同一证候出发的未来演化只由证候与策略决定）。A 是常见误判——状态价值是"长期期望"而非单次反馈，单次疗效充满随机性；B 与"不依赖时刻"矛盾；D 忽略策略维度。

【评分要点】
- 选对 C 得 6 分；
- 能举例说明"同一证候在不同策略下价值不同"（如归脾汤路径 vs 银翘散路径，或"接近康复的证候价值高、迁延难愈的证候价值低"）得 4 分；仅复述概念但未举例得 2 分。

### 基础题 2（对应节号：4.1 折扣回报与状态价值计算）

【计算题】设康复状态 s3 停留时每步奖励 +1，折扣率 γ = 0.9。

（1）计算 vπ(s3) = 1 + 0.9 + 0.81 + …；
（2）设 s2→s3（到达康复）一步奖励 +1，写出 s2 的价值估计方程并求 vπ(s2)；
（3）说明折扣率为什么能使无限长奖励序列的回报有界。

【参考答案】
（1）vπ(s3) = 1 + 0.9 + 0.81 + … = 1/(1−0.9) = 10。
（2）vπ(s2) = 1 + 0.9×vπ(s3) = 1 + 0.9×10 = 10。注意"到达康复"这一步本身奖励 +1，不能漏写（正文 4.2.2 例4.2 的"插曲"强调：若误记为 0，会解得 vπ(s2) = 9，与枚举轨迹结果矛盾）。
（3）若单步奖励绝对值上界为 Rmax，则 |Gt| ≤ Rmax(1 + γ + γ² + …) = Rmax/(1−γ)；因 0 < γ < 1，几何级数收敛，故无限长轨迹的回报有界（与第 1 章 1.6 节同一论证）。

【评分要点】
- （1）写出等比求和 1/(1−0.9) = 10 得 4 分（有求和过程才给满分，只写 10 得 2 分）；
- （2）方程形式 2 分 + 数值 2 分（共 4 分），漏写 s2→s3 的 +1 奖励扣 2 分；
- （3）上界公式 Rmax/(1−γ) 得 2 分。

### 基础题 3（对应节号：4.2 价值估计方程）

【填空题】价值估计方程 vπ(s) = Σa π(a|s)[Σr p(r|s,a) r + γ Σs′ p(s′|s,a) vπ(s′)] 的五个组成部分各对应一项临床内容：期望即时奖励对应______；转移概率对应______；后继状态价值对应______；折扣率对应______；策略对应______。

【参考答案】当下处理效果；证候的转归规律；转归状态的长期前途；远期疗效的权重；诊疗路径（正文 4.2.3 明确列出的对应表）。

【评分要点】
- 五个对应各 2 分（共 10 分）；允许近似表述（如"即时奖励 = 当下的疗效""转移概率 = 证候会怎样转"），但须一一对应，张冠李戴不给该空分。

### 基础题 4（对应节号：4.3 动作价值）

【计算题】失眠证候 s（入睡困难+多梦+心悸）上：用归脾汤（B 级证据，期望即时奖励 0.7），转归为"症状缓解"状态（价值 9）；误用银翘散（证型不匹配，奖励 0），转归为"心悸加重"状态（价值 4）；γ = 0.9。

（1）计算 qπ(s, 归脾汤) 与 qπ(s, 银翘散)；
（2）若策略在 s 处以 0.5/0.5 概率选择两首方剂，求 vπ(s)；
（3）结合（1）的数值说明"即时见效最快的方剂未必是长期价值最大的方剂"。

【参考答案】
（1）qπ(s, 归脾汤) = 0.7 + 0.9×9 = 8.8；qπ(s, 银翘散) = 0 + 0.9×4 = 3.6。
（2）vπ(s) = 0.5×8.8 + 0.5×3.6 = 6.2。
（3）动作价值包含即时奖励与后续回报两个部分：银翘散若只带来即时缓解而让寒邪郁闭、拖长病程，其后续回报低，折扣回报精确惩罚这种"一步错、步步错"；8.8 对 3.6 的差异正是即时奖励（0.7 vs 0）与后继价值（9 vs 4）双重差距叠加的结果——方证对应不仅影响当下疗效，还通过后继状态价值放大为长期疗效差异（正文 4.3.2 例4.3）。

【评分要点】
- （1）两个数值各 2 分（共 4 分），须写出公式；
- （2）2 分；
- （3）4 分：须同时指出"即时奖励"与"后继价值"两个来源，只说其一得 2 分；能说出"折扣回报惩罚一步错步步错"加 1 分（满分封顶）。

### 基础题 5（对应节号：4.4 矩阵求解）

【填空题】设状态空间含 n 个状态。状态转移矩阵 Pπ 的第 i 行第 j 列元素 [Pπ]ij = ______；Pπ 是______矩阵（stochastic matrix），因为每一行元素______且行和为______。价值方程写成矩阵形式为______，其解为 v = ______。

【参考答案】Σa π(a|si) p(sj|si, a)；随机；非负；1；v = rπ + γPπv；v = (I − γPπ)⁻¹ rπ。

【评分要点】
- 每空 2 分（共 10 分）；"行和为 1"须答出理由（从任意状态出发，一步之后必然落在某个状态上），仅答数值不给该空分；最后两空须用矩阵符号，写成元素形式扣 1 分。

### 基础题 6（对应节号：4.5 收敛性与唯一性）

【简答题】为什么说"不同医师、不同初值出发，只要遵循同一套转归与奖励数据，反复评估终将收敛到同一个价值"？请结合迭代格式 vk+1 = rπ + γPπvk 与收缩映射说明。

【参考答案】迭代格式右端定义的映射 F(v) = rπ + γPπv 是压缩比为 γ 的收缩映射（‖F(v) − F(v′)‖∞ ≤ γ‖v − v′‖∞，γ ∈ (0,1)），它必有唯一不动点，即真实价值 vπ；从任意初值 v0 出发迭代都收敛到该不动点。两位医师的初始估计 v0 与 v0′ 的差距每步缩小 γ 倍：‖vk − vk′‖∞ ≤ γ^k‖v0 − v0′‖∞ → 0，例如 γ = 0.9 时二十步后差距只剩约 0.9²⁰ ≈ 0.12 倍——临床共识在数学上是可以实现的（正文 4.5.2/4.5.3）。

【评分要点】
- 写出收缩不等式或收敛速率 γ^k（每步差距缩小 γ 倍）得 5 分；
- 指出"唯一不动点/唯一解"得 3 分；
- 结合"不同医师趋同"的临床含义（临床共识可实现）得 2 分。

### 综合题 7（对应节号：4.1 / 4.2 / 4.4 状态价值、价值估计方程、矩阵求解）

【病案计算】一条三状态失眠病程链：s1 失眠初起 → s2 心脾两虚证 → s3 康复（吸收态）。γ = 0.9；s1→s2 奖励 0，s2→s3（到达康复）奖励 +1，s3 停留每步 +1，策略确定。

（1）用价值估计方程逐状态求解 vπ(s1)、vπ(s2)、vπ(s3)；
（2）写出 Pπ 与 rπ，用矩阵形式 v = (I − γPπ)⁻¹ rπ 求解，验证与（1）一致；
（3）若把 s2→s3 的奖励误记为 0，会得到什么数值？为什么价值估计方程能暴露这种"漏写奖励"的错误？

【参考答案】
（1）vπ(s3) = 1 + 0.9×vπ(s3)，解得 vπ(s3) = 10；vπ(s2) = 1 + 0.9×10 = 10；vπ(s1) = 0 + 0.9×10 = 9。即 v = [9, 10, 10]ᵀ。
（2）Pπ = [[0,1,0],[0,0,1],[0,0,1]]，rπ = [0,1,1]ᵀ；I − γPπ = [[1,−0.9,0],[0,1,−0.9],[0,0,0.1]]。下三角块回代：0.1×v3 = 1 → v3 = 10；v2 − 0.9×10 = 1 → v2 = 10；v1 − 0.9×10 = 0 → v1 = 9。与（1）一致。
（3）误记为 0 时：vπ(s2) = 0 + 0.9×10 = 9，vπ(s1) = 0 + 0.9×9 = 8.1——这违背"从 s1 出发唯一轨迹"的枚举结果（枚举：0 + 0.9×1 + 0.9²×1 + 0.9³×1 + … = 0 + 0.9×vπ(s3) = 9，其中到达 s3 的 +1 不可漏）。方程把每步奖励写成显式项，联立求解时任何含糊都会造成数值矛盾而暴露——这正是"方程迫使你把每一步的奖励写清楚"（正文 4.2.2 的插曲）。

【评分要点】
- （1）4 分：三值各 1 分 + 方程书写 1 分，s2 漏写 +1 扣 2 分；
- （2）3 分：Pπ、rπ 正确 1 分，回代过程与结果正确 2 分；
- （3）3 分：错误数值（9 与 8.1）1 分，解释"方程暴露含糊"2 分。

### 综合题 8（对应节号：4.3 / 4.5 动作价值、加权平均、收敛性）

【临床分析】一位发热患者，恶寒重、无汗、脉浮紧（风寒表实），候选方剂为麻黄汤（辛温解表）与银翘散（辛凉解表）。已估计 q(s, 麻黄汤) = 8.4、q(s, 银翘散) = 7.2。

（1）若策略以 0.3/0.7 概率选择麻黄汤/银翘散，求 vπ(s)，并验证 vπ(s) ≤ maxa q(s,a)；
（2）说明"状态价值是仪表盘、动作价值是信号灯"在策略改进中的含义；若把概率全部移向麻黄汤，vπ(s) 变为多少？
（3）结合收敛性定理说明：两位医师即使初始估计不同，只要遵循同一套转归与奖励数据，对同一证候的长期价值判断也会趋同。

【参考答案】
（1）vπ(s) = 0.3×8.4 + 0.7×7.2 = 2.52 + 5.04 = 7.56；maxa q(s,a) = 8.4 ≥ 7.56，满足 vπ(s) ≤ maxa q(s,a)，等号当且仅当策略把全部概率放在最优动作上。
（2）仪表盘报告"当前水平"（按现在的习惯用药前途如何），信号灯指示"改进方向"（换一首方剂会不会更好）。只要把概率从次优动作挪向更优动作，状态价值只升不降：全部移向麻黄汤后 vπ(s) = 1.0×8.4 = 8.4，达到上限——这就是下一章最优策略的雏形（正文 4.3.2）。
（3）价值估计方程右端是压缩比为 γ 的收缩映射，有唯一不动点，从任意初值迭代都收敛到同一 vπ；两位医师初值不同只影响收敛路径，不影响极限——"不同医师、不同初值终将趋同"，临床共识在数学上是可以实现的（正文 4.5.2）。

【评分要点】
- （1）4 分：计算 2 分 + 不等式验证 2 分；
- （2）3 分：两个比喻的含义 1 分，数值 8.4 与"只升不降"1 分，"最优策略雏形"或等价表述 1 分；
- （3）3 分：须含"收缩/唯一不动点/收敛"三要素之一，并落到临床趋同，缺一扣 1 分。

### 综合题 9（对应节号：4.6 / 4.7 / 4.8 全要素疗效、价值网络、六者和谐）

【分析题】慢病管理场景拟比较方案甲（即时见效快、半年复发率 30%）与方案乙（起效慢、半年复发率 5%）。

（1）结合 4.6 节全要素四类要素说明：为什么只记"即时疗效"的账本会得出颠倒的结论？
（2）用 4.6.2 的奖励映射习惯（A 级 = 1.0、B 级 = 0.7、C 级 = 0.4）为甲、乙各设计一组"即时疗效 + 远期转归"奖励，并说明 γ = 0.95 时乙为何可能反超；
（3）若该评价需形成六方共识（患者、医师、护理、药学、管理、社会），给出一个权重设定与合成奖励的计算示例，并说明"共识不是平均主义"。

【参考答案（示例，允许合理差异）】
（1）账本只记即时缓解是短视的：甲三剂见效却反复复发，乙起效慢却断根，单看即时疗效会得出"甲优"的颠倒结论；全要素要求同时记录即时疗效、远期转归、生活质量、安全与代价四类（正文 4.6.1）。
（2）示例：甲（A 级即时）r₁ = 0.9、复发转入低价值状态；乙（B 级即时）r₁ = 0.5、复发率 5%。γ 大时远期奖励权重高：γ = 0.95 下乙的低复发使后继状态价值远高于甲，长期折扣回报反超——"见效快"与"断根好"之争，在价值坐标系里有了明确答案（正文 4.6.2 例4.6）。
（3）示例：权重（患者 0.25、医师 0.25、护理 0.15、药学 0.15、管理 0.1、社会 0.1，和为 1），分量 (0.8, 1.0, 0.9, 1.0, 0.7, 0.9)，合成 r = 0.25×0.8 + 0.25×1.0 + 0.15×0.9 + 0.15×1.0 + 0.1×0.7 + 0.1×0.9 = 0.895 ≈ 0.89（与正文例4.8 同构）。权重由场景与临床目标决定：急性期以医护观察为主、恢复期提高患者自评权重，而非六方各投一票取平均数（正文 4.8.1/4.8.2）。

【评分要点】
- （1）3 分：须点出"复发/断根"维度与四类要素；
- （2）3 分：两组奖励数值合理 1 分，γ 与远期权重导致反超的解释 2 分；
- （3）4 分：权重合理且和为 1 得 2 分，合成计算正确得 1 分，"非平均主义"说明得 1 分。

### 挑战题 10（对应节号：4.4 / 4.5 / 4.6 / 4.7 / 4.8 开放设计）

【开放设计题】tcmP 平台要为"2 型糖尿病慢病管理"设计一个可计算的价值系统。

（1）按全要素四类要素（即时疗效、远期转归、生活质量、安全与代价）设计奖励表，每类至少 2 个信号并给出具体数值；选择 γ 并说明理由（可参考 4.6.2 慢病场景建议）；
（2）构造一个含 3 个状态的小 MDP（如 s1 血糖达标、s2 血糖偏高、s3 急性并发症），写出 Pπ 与 rπ（Pπ 须为随机矩阵），给出迭代格式并说明收敛依据；
（3）说明该价值系统在价值网络中如何与患者单元、医师单元耦合；若管理者把"床位周转率"权重调高，可能对患者/医师单元产生什么影响，如何用"环境共荣最适度"约束这种风险；
（4）用一句话说明价值估计的局限与使用边界。

【参考答案（示例，允许合理差异）】

（1）示例奖励表：

| 要素 | 信号 | 奖励 |
|---|---|---|
| 即时疗效 | 血糖下降且无低血糖 | +0.5 |
| 即时疗效 | 血糖改善但未达标 | +0.2 |
| 远期转归 | 半年 HbA1c < 7%（断根） | +1.0 |
| 远期转归 | 发生急性并发症 | −1.0 |
| 生活质量 | 自评生活质量提升 | +0.3 |
| 安全与代价 | 低血糖事件 | −0.8 |
| 安全与代价 | 费用超预算 | −0.2 |

γ 取 0.95：慢病管理重视长期转归，让"治未病"式早期干预在折扣回报中显现价值；若只记即时疗效，γ 小，会得到"见效快 = 好方案"的短视结论（正文 4.6.2）。

（2）示例：Pπ = [[0.8, 0.2, 0], [0.3, 0.6, 0.1], [0, 0.2, 0.8]]（每行和为 1，随机矩阵），rπ = [1.0, 0.2, −1.0]ᵀ；迭代格式 vk+1 = rπ + γPπvk，右端是压缩比为 γ = 0.95 < 1 的收缩映射，故从任意初值收敛到唯一解 v = (I − γPπ)⁻¹ rπ——价值可计算且算得稳（正文 4.5.2）。

（3）耦合：患者单元的状态（血糖水平）进入医师单元的转移概率，管理单元的资源配置（随访频次、检查预算）改变患者单元的可行动作集；若管理者把床位周转率权重调高，可能诱导过早出院、缩短疗程，损害远期转归（患者单元价值下降，进而拉低医师单元的价值）。环境共荣最适度要求个体价值与环境价值在同一目标中求解：患者的长期健康与医院的资源效率互为环境，任何一方过度扩张都会在价值网络上被扣分，需用反馈校准把联合价值拉回平衡（正文 4.7.2、4.8.2）。

（4）价值是估计不是真理：病例偏少时转移概率不可靠、证据等级映射是离散近似，价值数字必须伴随置信度与适用边界，临床决策以患者安全为最高约束，不能因"价值高"突破安全底线（正文 4.6.2）。
