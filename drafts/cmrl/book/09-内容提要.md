# 内容提要

## 内容提要（韵文版）

```
中医场景强化学习，状态动作奖励齐；
四诊合参是状态，方剂动作疗效励。
决策过程明规则，统计估计见真章；
贝尔曼方程做账本，价值迭代求最优。
时序差分走一步，Q学习向最优走；
函数近似一张表，策略梯度步步高。
行动者配评价者，六者协同幸福绕；
最适而非最大化，四个适度身心安。
提高认知开篇立，确认信仰中编牢；
追求幸福下编成，随证治之算法照。
须根干枝又生叶，知识之树节节高；
医学智能新基建，人机共进天地宽。
```

## 内容提要（正文版）

本书把强化学习的数学理论，完整讲进中医药场景：**四诊合参是状态，治法方剂是动作，疗效反馈是奖励，辨证论治是策略**。上编「提高认知」，从状态、动作与奖励讲起，经决策过程模型到统计估计与随机逼近，回答"AI 如何认识中医医院"；中编「确认信仰」，用贝尔曼方程把疗效记成账本，用价值迭代与策略迭代求出最优方案，用时序差分与 Q 学习边走边学，回答"疗效如何量化确认"；下编「追求幸福」，从四个最适度出发，经函数近似与策略梯度，走向行动者-评价者与医患药械规法六者协同，回答"为了什么而优化"——全书以"最适度而非最优化"为哲学主线，对应多目标、约束、正则化与信赖域等数学工具。

全书知识树：须为数学基础，根为三要素，干为三编，枝为十章，叶为终末知识点。读者沿树而上，无需跳跃，不必自悟——每章由浅入深，每节承上启下，例题皆可手算，插图皆可复看。**明理过渡丝滑，衔接逻辑顺溜**，计算机足够算力下的 AI 智能特征，正随书页徐徐展开。
