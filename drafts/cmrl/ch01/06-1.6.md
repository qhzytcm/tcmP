## 1.6 长远的总账：一次诊疗全过程的得失

### 1.6.1 知识要点

单步奖励只能评价"一个动作的即时好坏"，而医者关心的是整个疗程的成败。为此需要把一系列奖励累积起来。轨迹（trajectory）是一条状态-动作-奖励链：从某个初始状态出发，依次记录每个时刻的状态、动作与获得的奖励。例如 s1 --a2, r=0--> s2 --a3, r=0--> s5 --a3, r=0--> s8 --a2, r=1--> s9 就是一条轨迹：机器人从 s1 出发，向右、向下、向下、向右，最终到达目标，途中获得奖励 0, 0, 0, 1。轨迹也可以写成序列形式 s0, a0, r1, s1, a1, r2, …，完整记录一次交互的历史，是分析智能体行为的基本素材；后续无模型算法正是从一批轨迹中估计价值的——轨迹是数据，算法是数据的使用者。在临床语境中，一条轨迹就是一个完整的"就诊—辨证—处方—随访"过程：症状组合、治法方剂、疗效评价被依次记录下来——把轨迹写清楚，就是把"发生了什么"写清楚，这是任何分析的起点。试想一位失眠患者：初诊时"心烦、舌红、脉数"是一个状态，医者选"黄连阿胶汤"是一个动作；复诊时"睡眠好转、舌象转淡"是新的状态，这是疗效的第一次反馈；再诊再调，直到"夜寐安、舌脉平"，轨迹画上了完整的句号。病历上记载的每一次复诊，正是这样一段被记录下来的人类轨迹。

轨迹上所有奖励之和称为回报（return），它是评价策略好坏的直接指标：回报越大，策略越好。仍用上面的例子：按某策略从 s1 出发到达 s9，回报为 0 + 0 + 0 + 1 = 1；若按另一条经过禁区的策略，轨迹为 s1 --a2, r=0--> s2 --a2, r=−1--> s6 --a3, r=0--> s9，回报为 0 + (−1) + 0 = −1。前者回报更大，策略更好。回报把"单步奖励"累积为"整体效果"，使不同策略之间可以定量比较：同一患者，A 方案全程平稳好转，B 方案先加重后缓解，两条轨迹的回报自然不同——回报把"过程的好坏"浓缩成一个数，让方案之间的比较有了硬指标。注意：回报的定义依赖具体的轨迹，而轨迹由"策略+环境随机性"共同决定，因此同一策略在不同次交互中可能得到不同回报——这次得 1，下次可能得 0。如何把这种随机性处理掉，是第 2 章引入期望（状态价值）的动机。评价策略不能只看一次结果，要看平均表现，这就像评价一位医者不能只看一个病例的成败，而要看长期的整体疗效——期望的引入，将把"平均表现"变成可计算的数学对象；正如"疗效好"从来不是一个病例的故事，而是许多病例的统计结论；读者在此应记住：回报是随机变量，不是定值——比较策略好坏，必须借助第 2 章的期望运算，把随机性平均掉。

### 1.6.2 方法与示例

非折扣回报有一个根本局限：对于无限长的轨迹，直接求和可能发散。设想机器人到达目标后继续移动：0 + 0 + 0 + 1 + 1 + 1 + … = ∞，回报没有定义。只要任务没有明确的终止点，非折扣回报就可能出问题；好比一份永远写不完的流水账，账目越记越乱。解决办法是引入折扣：让远期的奖励"打折"，使无穷求和收敛。这一思想也符合人类与动物的行为直觉——"一鸟在手胜过两鸟在林"：远期奖励往往不如近期奖励可靠、有价值，因为未来充满不确定性，今天的 1 分比十年后的 1 分更值得把握。读者可以这样理解折扣的合理性：如果奖励可以无限累积，那么"活得越久越富有"的平凡策略就会淹没所有真正的决策差异；折扣为时间定价，使不同时长的策略可以公平比较，也让"越早越好"的偏好进入了数学模型。在临床中，这个直觉同样成立：一个疗程早期的改善，比十年后的"远期受益承诺"更可信、更可检验；而预防医学的价值恰恰在于用今天的确定性投入，换取远期的不确定收益——折扣率正是这种权衡的数学刻度。折扣不是数学上的权宜之计，而是对"时间价值"这一真实特性的建模；这一认识，是理解第 2 章贝尔曼方程适用性的前提；非折扣求和只在有限轨迹上有意义，这一认识本身就是折扣动机的一部分，读者应学会在两类任务间切换视角。

折扣回报（discounted return）的定义为 Gt = Rt+1 + γRt+2 + γ²Rt+3 + … = Σk=0∞ γ^k Rt+k+1，其中 γ ∈ (0,1) 称为折扣率（discount rate）。生活化地读这个公式：今天的奖励值 1 分，下一个时刻的奖励打 γ 折，再下一个时刻打 γ 的平方折——离现在越远，越不值钱。两个记号细节值得注意。其一，Gt 从时刻 t 之后的第一个奖励 Rt+1 开始累计，而不是 Rt——因为 Rt 是时刻 t−1 的动作得到的奖励，不属于"从 t 出发的未来回报"，这个下标错位是初学者最容易写错的地方，请务必记牢。若用 s0, a0, r1, s1, a1, r2, … 表示完整交互序列，则 G0 = r1 + γr2 + γ²r3 + …，下标错位一目了然。其二，第 k 项前的折扣因子是 γ 的 k 次方：离当前时刻越远，折扣越狠，远期奖励对回报的贡献越小——第一项是全额，第二项打九折，第三项打八一折，依此类推。这个公式是全书最重要的公式之一，值得花五分钟彻底消化：建议在纸上抄写一遍，把每一项的下标与折扣指数逐一核对，抄过一遍就再也不会写错；建议把它与第 1.5 节的奖励表对照阅读——公式里的每一项，都对应着奖励表里的一个具体数值。它将在第 2 章被“自举”分解，衍生出贝尔曼方程，成为所有价值计算的原点。

### 1.6.3 小结与衔接

折扣率的作用有二。其一，保证回报有界：若奖励绝对值的上界为 Rmax，则 |Gt| ≤ Rmax(1 + γ + γ² + …) = Rmax/(1−γ)，几何级数收敛，无限长轨迹的回报也有限——这就像给无限长的账本设置了一个"利率上限"，再长的账也能算出总账。其二，调节远近权重：γ 接近 0 时，远期奖励被严重打折，策略是短视的（myopic），几乎只看即时奖励；γ 接近 1 时，远期奖励几乎不打折，策略是远视的（far-sighted），愿意为远期收益承担近期损失。从极限看，γ = 0 时回报退化为即时奖励；γ → 1 时回报接近非折扣回报。γ 的取值是建模者的选择，它体现设计者对"长远 vs 眼前"的权衡，应用中通常取 0.9 至 0.99 之间的值；取值过大则学习慢、方差大，取值过小则策略短视，需要在两者间寻找平衡；读者今后看到任何强化学习算法，都要先问一句：它的 γ 是多少？这决定了它的‘眼光’有多远。在中医语境中，γ 的大小对应医者"治标"与"治本"的取舍：γ ≈ 0 的医者只会治标，γ ≈ 1 的医者才谈得上治本；临床上的"辨证施治、整体观念"，本质上是一种大 γ 的决策哲学——不为一时之效牺牲长远之利。反过来，急症处理中的"先治标、后治本"又说明：γ 不是越大越好，而应根据任务的时间尺度合理选择，这与"γ 体现设计者权衡"的论断完全一致。

用数值例子体会 γ 的调节作用。设某轨迹的奖励序列为 1, 1, 1, …：当 γ = 0.5 时，G0 = 1 + 0.5 + 0.25 + … = 2；当 γ = 0.9 时，G0 = 1 + 0.9 + 0.81 + … = 10——同样的轨迹，γ 越大，远期奖励对回报的贡献越大。再看延迟的影响：轨迹二奖励序列为 2, 1, 1, 1, …（γ = 0.9），G0 = 2 + 0.9 × 1/(1−0.9) = 11；轨迹三奖励序列为 0, 0, 0, 1, 1, …（前三步无奖励，之后每步 +1），G0 = 0 + 0 + 0 + 0.9³ × 1/(1−0.9) = 7.29。对比轨迹一与轨迹三：同样"此后每步 +1"，晚 3 步才开始，回报从 10 降到 7.29——延迟的代价是 0.729。这个数字直观展示了折扣的含义：时间就是折扣，迟到三拍的奖励只值七成多。临床上的"先调理体质后收获长期健康"，正是用今天的投入换远期回报；γ 不是越大越好或越小越好，而是与问题的时间尺度匹配才好——疗程以周计的取 0.9，以年计的宜取 0.99。读者应能独立完成这类计算，这是后续所有价值计算的基础：建议自编两三组奖励序列，分别计算不同 γ 下的回报，直到“看到序列能立即写出求和式”为止——这份熟练度，会让第 2 章的学习轻松许多。第 2 章的状态价值，本质上就是对"各种轨迹回报的加权平均"的系统计算。
