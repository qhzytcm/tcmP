## 第一部分 基础题（60 分，每题 10 分）

### 基础题 1（对应节号：1.1 智能体与环境）

【单选题】在强化学习中，判断"某一对象属于智能体还是环境"的根本依据是（ ）

A. 该对象是否由人类操控
B. 该对象能否被动作直接改变、却无法被直接设定
C. 该对象是否具有计算能力
D. 该对象是否位于同一台服务器上

【参考答案】B。正文 1.1 节明确：智能体与环境的界限是人为划定的，凡是"能因动作而改变、却无法直接设定的"都属于环境；智能体是学习者与决策者，其"意志"只能通过动作表达。A 是常见误判（患者身体在"医师学习"问题中是环境，在"身体自我调节"问题中又是智能体）；C、D 与界限判定无关。

【评分要点】
- 选对 B 得 6 分；
- 能举例说明"同一对象在不同建模中可划归不同侧"（如患者身体的两个例子，或"环境因动作而改变"）得 4 分；仅复述概念但未举例得 2 分。

### 基础题 2（对应节号：1.2 状态与动作）

【填空题】本书网格世界中，状态空间 S = {s1, s2, …, s9}，动作空间 A = {a1, a2, …, a5}，其中 a1 表示______，a2 表示______，a3 表示______，a4 表示______，a5 表示______。记号约定中，大写 St 表示______，小写 s 表示______。

【参考答案】a1 向上、a2 向右、a3 向下、a4 向左、a5 静止不动；大写 St 表示时刻 t 所处的状态（随机变量），小写 s 表示状态的某个具体取值。动作方向按"上、右、下、左、静止"排列（正文 1.2 节与 1.3 节示例一致：s1 --a2--> s2 为向右，s5 --a3--> s8 为向下）。

【评分要点】
- 五个动作方向全对得 5 分，错一个扣 1 分；
- St 与 s 的大小写含义各 2 分（共 4 分），须答出"随机变量"与"具体取值"；
- 能说明"区分大小写是因为后续轨迹与奖励仍可能随机"加 1 分（满分封顶 10 分）。

### 基础题 3（对应节号：1.3 状态转移）

【计算题】设机器人有"打滑"机制：每执行一个动作，以 0.8 概率按指令移动，以 0.1 概率滑向指令方向的顺时针侧、0.1 概率滑向逆时针侧。则在状态 s1 执行动作 a2（向右）时：

（1）写出 p(s2 | s1, a2)、p(s4 | s1, a2)、p(s1 | s1, a2) 的值；
（2）验证概率归一化性质 Σs′ p(s′ | s, a) = 1。

【参考答案】（1）p(s2 | s1, a2) = 0.8（按指令向右到 s2）；p(s4 | s1, a2) = 0.1（滑向顺时针侧即向下到 s4）；p(s1 | s1, a2) = 0.1（滑向逆时针侧即向上，越界弹回 s1）。
（2）0.8 + 0.1 + 0.1 = 1，满足归一化。

【评分要点】
- 三个概率各 2 分（共 6 分），须说明 0.8 对应"按指令"、0.1 对应"滑向一侧"；
- 归一化和式正确得 2 分；
- 指出"确定性转移是 p(s′|s,a) = 1 的特例"得 2 分。

### 基础题 4（对应节号：1.4 策略）

【简答题】什么是策略 π(a|s)？确定性策略与随机策略的区别是什么？为什么随机策略在强化学习中不可替代？

【参考答案】策略 π(a|s) 是给定状态 s 选择动作 a 的概率规则；对固定 s，π(·|s) 是概率分布，满足 Σa π(a|s) = 1。确定性策略：某一动作概率为 1、其余为 0；随机策略：多个动作概率均为正。随机策略不可替代的原因有二：其一，鼓励探索——保证每个动作都有被尝试的机会（1.1 节探索与利用权衡的数学实现）；其二，数学必要——当转移或奖励具有随机性时，只有把策略写成概率分布才能用期望统一处理（第 2 章贝尔曼方程中 Σa π(a|s) 是方程骨架）。此外在博弈对抗场景中随机策略可避免被对手预测（"剪刀石头布"例）。

【评分要点】
- 定义正确得 3 分（含 Σa π(a|s) = 1）；
- 两类策略区别得 2 分；
- 随机策略两个作用各 2 分（共 4 分）；
- 能举"剪刀石头布"或临床"效差变方"之例得 1 分。

### 基础题 5（对应节号：1.5 奖励）

【填空题】本书网格世界的奖励表设计为：试图越出边界 r = ______，进入禁区 r = ______，到达目标格子 r = ______，其他情况 r = ______。请再举一个"奖励设计决定行为方向"的临床反例（如把点击量、短期症状缓解或复诊率当作唯一奖励可能诱导的行为）。

【参考答案】−1、−1、+1、0。临床反例（任举其一即可）：若平台把"点击量"当作奖励，医师可能为点击量推荐无关内容；若把"短期症状缓解"当作唯一奖励，医师可能忽视长期体质调理；若把"复诊率"当作唯一奖励，医者可能诱导不必要的复诊而伤害患者信任。

【评分要点】
- 四个奖励值全对得 4 分，错一个扣 1 分；
- 反例具体、指向明确得 4 分；仅说"会钻奖励漏洞"未给具体行为得 2 分；
- 能说出工程箴言"你奖励什么，就得到什么"或"奖励是设计者意志的唯一表达通道"得 2 分。

### 基础题 6（对应节号：1.6 轨迹与回报）

【计算题】设某轨迹的奖励序列为 1, 1, 1, …（无限长），折扣率分别取 γ = 0.5 与 γ = 0.9。

（1）分别计算 G0 = R1 + γR2 + γ²R3 + … 的值；
（2）说明折扣率为何能使无限长轨迹的回报有界。

【参考答案】
（1）γ = 0.5 时，G0 = 1 + 0.5 + 0.25 + … = 1/(1−0.5) = 2；γ = 0.9 时，G0 = 1 + 0.9 + 0.81 + … = 1/(1−0.9) = 10。
（2）若单步奖励绝对值上界为 Rmax，则 |Gt| ≤ Rmax(1 + γ + γ² + …) = Rmax/(1−γ)。因为 0 < γ < 1，几何级数收敛，故无限长轨迹的回报有界。

【评分要点】
- 两个数值各 3 分（共 6 分），须写出等比求和过程（1/(1−γ)）；
- 收敛性论证得 3 分（上界公式 Rmax/(1−γ) 得 2 分，说明 γ∈(0,1) 保证收敛得 1 分）；
- 能指出"γ 越大远期奖励贡献越大"得 1 分。

## 第二部分 综合题（30 分，每题 10 分）

### 综合题 7（对应节号：1.3 / 1.5 / 1.6 状态转移、奖励、轨迹与回报）

【病案计算】对照图 1-1（3×3 网格世界：s1 为左上角，s9 为右下角目标格，s6 为禁区格）。现有两条从 s1 出发的策略：

- 策略甲（安全路线）：s1 --a2, r=0--> s2 --a3, r=0--> s5 --a3, r=0--> s8 --a2, r=1--> s9；
- 策略乙（抄近路）：s1 --a2, r=0--> s2 --a2, r=−1--> s6 --a3, r=0--> s9。

（1）分别计算两条轨迹的回报；
（2）仅凭"即时奖励最大"选择动作的贪心策略为什么可能选错？结合本题说明；
（3）仿照正文 1.5.2 的反例逻辑，指出还有哪条"先吃亏后获益"的路线可以胜过策略乙。

【参考答案】
（1）策略甲回报 = 0 + 0 + 0 + 1 = 1；策略乙回报 = 0 + (−1) + 0 = −1。策略甲更优。
（2）贪心只比较下一步奖励：在 s1 时 a2（向右）即时奖励 0，看似不差；但 a2 把机器人带向禁区 s6，后续付出 −1 代价。评价动作必须看它对长期回报的贡献——"即时最优 ≠ 长期最优"。
（3）向上弹回再绕行的路线：s1 --a1, r=−1--> s1 --a3, r=0--> s4 --a3, r=0--> s7 --a2, r=0--> s8 --a2, r=1--> s9，回报 = −1 + 0 + 0 + 0 + 1 = 0。虽然第一步吃亏（−1），总回报 0 仍高于策略乙的 −1。（更优者：s1 --a3--> s4 --a3--> s7 --a2--> s8 --a2--> s9，回报 = 1，答出亦可。）

【评分要点】
- 两轨迹回报计算各 2 分（共 4 分），数值错不给分；
- 贪心局限分析得 3 分（须点出"即时奖励大 ≠ 总回报大"与本题具体对应）；
- 第三条路线得 3 分：路线正确 2 分、回报计算正确 1 分。

### 综合题 8（对应节号：1.2 / 1.4 / 1.5 / 1.6 状态、动作、策略、奖励、轨迹）

【临床翻译】一位 28 岁患者因"发热恶寒、无汗、头身疼痛、脉浮紧"就诊。初诊辨证为太阳伤寒表实证，医者处方麻黄汤；服药后汗出热退，复诊时患者诉依从良好、无不良反应。

请用本章概念把上述诊疗全过程翻译为：
（1）状态（含初诊状态与复诊状态）；
（2）动作空间（至少 3 个候选动作）；
（3）策略（该医者"辨证→论治"的规则是什么）；
（4）奖励（疗效反馈与医患信任分别对应什么奖励信号）；
（5）一条带奖励的轨迹（从初诊到随访）。

【参考答案】
（1）状态 = 四诊信息的总和：初诊状态 S0 = {发热恶寒、无汗、头身疼痛、脉浮紧}；复诊状态 S1 = {汗出热退、无不适}；痊愈状态 S2。
（2）动作空间 A = {麻黄汤发汗解表、桂枝汤调和营卫、荆防败毒散疏风散寒、建议转诊、观察随访}（任选 3 个以上合理动作即可）。
（3）策略 = 辨证论治的决策规则：证属太阳伤寒表实证 → 用麻黄汤；属太阳中风表虚证 → 用桂枝汤；"同病异治、异病同治"正是状态定义在证候层面的体现。
（4）疗效奖励：汗出热退、症状消失 → 正奖励（如 +1）；误汗伤正、病情加重 → 负奖励（如 −1）。信任奖励：依从性好、如实反馈 → 正奖励（如 +0.2）；不信任、失访 → 负奖励。
（5）轨迹：S0 --麻黄汤, r=0（或 +0.2 含信任）--> S1（汗出热退, r=+1）--> S2（痊愈, r=+0.5），回报为正。允许学生给出合理数值，重点在链条完整（状态—动作—奖励—下一状态）。

【评分要点】
- 状态与动作各 2 分（共 4 分）：状态须体现"四诊信息浓缩"、动作须含"治法方剂/转诊"；
- 策略 2 分：须体现辨证论治规则；
- 奖励 2 分：须同时含疗效反馈与医患信任两类信号；
- 轨迹 2 分：链式结构完整、回报可计算得满分，缺奖励或状态断链扣 1 分。

### 综合题 9（对应节号：1.6 / 1.7 折扣率与系统科学定位）

【分析题】两条备选治疗方案：方案甲（先苦后甜）奖励序列为 0, 100；方案乙（平稳）奖励序列为 5, 5。

（1）分别计算 γ = 0.5 与 γ = 0.9 时两条方案的回报；
（2）说明 γ 的大小如何决定策略"治标"还是"治本"；
（3）结合 1.7 节"场景生存最适度"，说明为什么同一套诊疗规则在基层门诊与三甲医院重症病房的 γ 设置应当不同。

【参考答案】
（1）γ = 0.5：甲 = 0 + 0.5×100 = 50，乙 = 5 + 0.5×5 = 7.5，甲优；γ = 0.9：甲 = 0 + 0.9×100 = 90，乙 = 5 + 0.9×5 = 9.5，甲更优。（另可对照正文：甲 0,10 与乙 5,5 在 γ=0.5 时乙 7.5 胜甲 5、γ=0.9 时乙 9.5 仍略胜甲 9——远期收益不大时 γ 影响有限。）
（2）γ 接近 0 时远期奖励被严重打折，策略短视（myopic），近乎只看即时奖励 → 只"治标"；γ 接近 1 时策略远视（far-sighted），愿意为远期收益承担近期损失 → 才能"治本"。"辨证施治、整体观念"本质上是一种大 γ 的决策哲学。
（3）γ 应与任务时间尺度对齐：基层门诊常见病多、疗程短、重症少，随访时间尺度短，γ 可取较小值（如 0.9）；三甲重症病房疗程长、转诊与远期转归重要，时间尺度长，γ 宜取较大值（如 0.99）。同一辨证论治规则在两种场景中转移规律 (P)、奖励信号 (R) 与时间尺度不同，生存最适度不同，γ 应随场景调整——这就是"场景生存最适度"对 γ 设置的要求。

【评分要点】
- 四个回报数值各 1 分（共 4 分）；
- 治标/治本与 γ 的对应 2 分（须含"远视/短视"或"为远期收益承担近期损失"）；
- 场景差异分析 4 分：须同时涉及时间尺度与 (P, R) 差异两个维度，各 2 分。

## 第三部分 挑战题（10 分）

### 挑战题 10（对应节号：1.5 / 1.7 / 1.8 奖励工程、三种最适度、六者和谐）

【开放设计题】tcmP 平台要为"2 型糖尿病慢病管理"设计一个可学习的奖励表，引导医者在"治标"与"治本"之间取得平衡。

（1）设计一张奖励表，至少包含疗效、医患信任、资源消耗三个维度，并给出具体数值（可参照正文 A 级 = 1.0、B 级 = 0.7、C 级 = 0.4 的映射习惯）；
（2）指出仅把"血糖达标率"作为唯一奖励时至少一个奖励漏洞，并预测智能体会学到什么偏差行为；
（3）用 1.7 节"环境共荣最适度"与 1.8 节"六者和谐"的原则说明你的奖励表为何能避免该漏洞；
（4）用一句话说明 tcmP 平台如何落地该奖励表。

【参考答案（示例，允许合理差异）】
（1）示例奖励表：

| 信号 | 事件 | 奖励 |
|---|---|---|
| 疗效 | 血糖达标且无低血糖 | +1.0 |
| 疗效 | 血糖改善但未达标 | +0.5 |
| 疗效 | 发生低血糖/急性并发症 | −1.0 |
| 信任 | 患者依从随访、如实反馈 | +0.3 |
| 资源 | 用药经济、检查必要 | +0.2 |
| 资源 | 过度检查/过度用药 | −0.3 |

（2）漏洞示例：若唯一奖励是"血糖达标率"，智能体可能学会"为了达标而过度用药"，诱发低血糖风险，或把难治患者转走以拉高统计——这正是 1.5 节"你奖励什么，就得到什么"的偏差行为，属于钻奖励漏洞。
（3）共荣最适度要求个体最适度与环境承载力共同求解：奖励表加入"低血糖惩罚"（安全维度）与"过度用药惩罚"（资源维度），使医者的局部最优不再以透支患者安全与公共资源为代价；六者和谐要求医、患、药、械、规、法相互建模——奖励表把"患"的体验（依从、低血糖）、"药械"的必要性审核、"规法"的安全底线全部纳入同一优化目标，任何一方过度扩张都会在奖励表上被扣分，从而维持系统稳态。
（4）落地一句话：在 tcmP 平台上，将疗效随访差值、患者依从记录与费用/检查数据实时映射为该奖励表，平台据此引导医者策略更新，使"治好病、赢得信任、节约资源"成为可观测、可优化的同一目标。

【评分要点】
- 奖励表维度 ≥3、数值合理、可解释：4 分（维度每缺一扣 1 分，数值与行为逻辑不符扣 1 分）；
