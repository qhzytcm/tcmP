## 二、逐章审稿清单（条款/问题/改法/等级）

### 第1章《认知的起点》（4 条：重要 3、润色 1）

【条款 S1-1】ch01/03-1.3.md 1.3.1："从 s1 出发，走 s1→s2→s5→s8→s9 与 s1→s4→s7→s8→s9 两条路都到目标，前者只经四步、后者多绕一格"。
【问题】数值·几何表述错误：按行优先编号（s1s2s3/s4s5s6/s7s8s9），s1→s2→s5→s8→s9 与 s1→s4→s7→s8→s9 均为 4 步（右-下-下-右 与 下-下-右-右），不存在"后者多绕一格"；学生按图 1-1 手数即发现矛盾。
【改法】改为"两条路都到目标，且都只需四步——前者经中部走廊、后者沿左侧下行，路径不同而步数相同"。
【等级】重要（数值可验算红线：手算复核即出冲突）。

【条款 S1-2】ch01/05-1.5.md 1.5.2 奖励反例："但如果向右走到 s2、再向右进入禁区 s6"。
【问题】数值·几何错误：s2 向右是 s3（右上角），进入禁区 s6 需经 s2→s5→s6（右-下-右）或 s2→s3→s6（右-右-下）；"s2 再向右进 s6"在网格上不成立（s2 的右下对角线格为 s6，无对角线动作）。
【改法】改为"向右走到 s2、再向下到 s5、再向右进入禁区 s6"。
【等级】重要（反例是 1.5 节核心教学点，路径错误使"即时最优≠长期最优"的论证失去几何支撑）。

【条款 S1-3】ch01/06-1.6.md 1.6.1 禁区轨迹："若按另一条经过禁区的策略，轨迹为 s1 --a2, r=0--> s2 --a2, r=−1--> s6 --a3, r=0--> s9，回报为 0 + (−1) + 0 = −1"。
【问题】数值·几何错误（与 S1-2 同源）：s2 --a2--> 是 s3 而非 s6；该轨迹无法在 3×3 网格上执行（s2 到 s6 需经 s5）。check 脚本验算的是算式 0+(−1)+0=−1，无法捕获路径几何错误。
【改法】轨迹改为 s1 --a2, r=0--> s2 --a3, r=0--> s5 --a2, r=−1--> s6 --a3, r=0--> s9，回报为 0 + 0 + (−1) + 0 = −1（总值不变，路径可执行）。
【等级】重要（正文轨迹不可执行，直接破坏 1.6 节手算练习）。

【条款 S1-4】ch01/04-1.4.md 1.4.1："通俗地说，策略就是一份决策规则——换一个观察角度、新找一个解决方案式的决策规则：面对同样的情形，规则不同，选择就不同。"
【问题】语言·晦涩："新找一个解决方案式"成分残缺、读不通，通俗解释反而制造理解障碍；红线③要求"策略=换一个观察角度"的通俗解释应通顺可读。
【改法】改为"通俗地说，策略就是一份决策规则——换一个观察角度，就换一套应对方案：面对同样的情形，规则不同，选择就不同。"
【等级】润色（语言通顺性，术语通俗解释的既有红线口径）。
