## 第一部分 基础题（60 分，每题 10 分）

### 基础题 1（对应节号：6.1 时序差分思想：一步经验与自我修正）

【单选题】关于时序差分（TD）学习方法，下列说法正确的是（ ）

A. TD 必须等一个完整回合（疗程）结束，才能用整段回报修正价值估计
B. TD 的学习目标是"一步真实奖励加上后继状态的当前估计"，记作 Rt+1 + γv(St+1)
C. 自举（bootstrapping）指用真实回报替代一切估计值，因此 TD 是无偏估计
D. TD 既需要环境模型（转移概率表），又需要等待回合结束

【参考答案】B。正文 6.1.1 节明确：TD 的学习目标是"一步真实奖励加上后继状态的当前估计"，Rt+1 + γv(St+1)，不必等回合结束——"走一步看一步、边走边修正"。A 是统计估计法（蒙特卡洛式学习）的特征，与 TD 相反；C 后半句错误——自举指"用自己当前的估计改进自己"，正因目标中含有估计值，TD 是有偏估计（6.1.3 节明确提示）；D 错误——TD 是"数据+自举"，既不需要环境模型（不同于动态规划），也不需要等回合结束（不同于统计估计法）。

【评分要点】
- 选对 B 得 6 分；
- 能说明"自举=用估计改进估计、故 TD 有偏"得 2 分（答出"有偏但方差小"即可）；
- 能指出 TD 属于"数据+自举"、在 DP 与统计估计法之间居中的谱系位置得 2 分；仅复述概念未说明得 1 分。

### 基础题 2（对应节号：6.2 时序差分估计：状态价值的逐步修正）

【计算题】四状态链 s1→s2→s3→s4 只能向右走，到达 s4 获得奖励 1 并终止，其余转移奖励 0。取 γ = 0.9，α = 0.1，初始价值全为 0（正文例 6.1）。

（1）写出由价值估计方程解出的真实价值 v(s1)、v(s2)、v(s3)、v(s4)；
（2）回合 1 轨迹为 s2→s3→s4，逐步演算 TD(0) 更新，写出回合 1 结束后的价值表；
（3）回合 2 轨迹为 s1→s2→s3→s4，写出回合 2 结束后的价值表，并说明"奖励信息如何沿轨迹回传"。

【参考答案】
（1）v(s4) = 1；v(s3) = 0.9×1 = 0.9；v(s2) = 0.9×0.9 = 0.81；v(s1) = 0.9×0.9×0.9 = 0.729。
（2）回合 1：访问 s2，TD目标 = 0+0.9×v0(s3) = 0，误差 0，不变；访问 s3 同理不变；访问 s4，TD目标 = 1，误差 = 0−1 = −1，更新 v(s4) = 0−0.1×(−1) = 0.1。回合 1 后价值表为 (0, 0, 0, 0.1)——只有 s4 变化，因为它是本回合唯一观察到非零奖励的状态。
（3）回合 2：访问 s1、s2，TD目标为 0，不变；访问 s3，TD目标 = 0+0.9×0.1 = 0.09，误差 = −0.09，更新 v(s3) = 0.009；访问 s4，TD目标 = 1，误差 = 0.1−1 = −0.9，更新 v(s4) = 0.19。回合 2 后价值表为 (0, 0, 0.009, 0.19)。回传机制：奖励信息在第一回合到达 s4，第二回合传到 s3——每步更新最多回传一格，后继状态的新估计通过 TD 目标影响前驱状态的更新，这正是自举"步进式传播"的直观形态。

【评分要点】
- 真实价值四个值各 1 分（共 4 分），须体现"越靠近奖励源价值越高"（0.729/0.81/0.9/1）；
- 回合 1 演算正确得 2 分（关键在 s4 更新为 0.1）；
- 回合 2 演算正确得 2 分（关键在 v(s3)=0.009 与 v(s4)=0.19）；
- 回传机制说明得 2 分：须点出"每步最多回传一格"或"TD目标携带后继状态最新估计"；仅复述数值未解释机制扣 1 分。

### 基础题 3（对应节号：6.3 同策略学习法：按当前做法学习）

【填空题】Sarsa 的名字取自一次学习事件的五个要素：______、______、______、______、______（写符号与含义）。Sarsa 的更新式为 q(St,At) ← q(St,At) + α[Rt+1 + γq(St+1,At+1) − q(St,At)]，其中后继项 q(St+1,At+1) 用的是"______"（实际选择的动作 / 最优动作）的价值估计。Sarsa 是______（同策略 / 异策略）算法，其含义可浓缩为八个字："______"。

【参考答案】五要素依次为：状态 St、动作 At、奖励 Rt+1、后继状态 St+1、后继动作 At+1（取五者首字母得 Sarsa）。后继项用的是"实际选择的动作"的价值估计。Sarsa 是同策略（on-policy）算法，含义是"学什么，就做什么"——生成经验的行为策略与学习目标对应的目标策略是同一个策略，TD目标使用实际选择的动作，学到的是"当前这个含探索的做法"自身的价值，探索代价如实记入账本。

【评分要点】
- 五要素全对得 5 分，错一个扣 1 分；
- 后继项填"实际选择的动作"得 2 分（填"最优动作"不得分，且须能区分它与 Q 学习法的差别）；
- 同策略判定与八字含义各占 1.5 分（共 3 分），须写出"学什么，就做什么"并说明"行为策略与目标策略相同"。

### 基础题 4（对应节号：6.4 n 步回报法：看得更远一些）

【计算题】设一条轨迹的即时奖励为 r1 = 2、r2 = 3、r3 = 4、r4 = 5，第 4 步后到达终止状态，折扣率 γ = 0.9，终止状态价值为 0（正文例 6.3）。

（1）写出 G(1:1)、G(1:2)、G(1:3) 的表达式（保留自举项）；
（2）计算 G(1:4)（第 4 步已终止，无自举项）；
（3）说明 n 从 1 增大到 4 时，目标中"真实奖励的累计值"与"自举项系数"各如何变化，以及这体现了什么权衡。

【参考答案】
（1）G(1:1) = 2 + 0.9q(S2,A2)；G(1:2) = 2 + 0.9×3 + 0.81q(S3,A3) = 4.7 + 0.81q(S3,A3)；G(1:3) = 2 + 0.9×3 + 0.81×4 + 0.729q(S4,A4) = 7.94 + 0.729q(S4,A4)。
（2）G(1:4) = 2 + 0.9×3 + 0.81×4 + 0.729×5 = 2 + 2.7 + 3.24 + 3.645 = 11.585。
（3）真实奖励累计值从 2 增长到 11.585（n=1 时仅 r1，n=4 时为全部四项）；自举项系数从 0.9 递减到 0（γ^n 随 n 增大而减小，n=4 时终止、无自举项）。这体现偏差-方差权衡：n 越大，目标中真实奖励越多、自举项越小，受后继估计误差影响越小——偏差越小（n→∞ 无偏）；但目标包含的随机变量越多、样本方差越大——n 大则方差大。n 是"视野旋钮"，在"完全自举（n=1，Sarsa）"与"完全无自举（n→∞，统计估计法）"之间连续过渡。

【评分要点】
- 三个表达式各 1 分（共 3 分），系数须正确（0.9、0.81、0.729）；
- G(1:4) 数值正确得 2 分，须写出求和过程，仅写答案扣 1 分；
- 变化规律描述 2 分（真实奖励↑、自举系数↓）；
- 偏差-方差权衡 3 分：须同时点出"大 n 偏差小方差大、小 n 方差小偏差大"与"n=1 即 Sarsa、n→∞ 即统计估计法"的谱系定位；只写一句"n 越大越好"不得分。

### 基础题 5（对应节号：6.5 Q 学习法：向最优方案学习）

【简答题】Q 学习法的更新式为 q(St,At) ← q(St,At) + α[Rt+1 + γ·max_a′ q(St+1,a′) − q(St,At)]。

（1）与 Sarsa 相比，Q 学习法后继项的唯一差别是什么？
（2）为什么说这个差别使 Q 学习法成为异策略（off-policy）算法？
（3）异策略带来哪两大优势？

【参考答案】
（1）后继项从"后继时刻实际选择的动作的价值估计 q(St+1,At+1)"换成"后继状态上所有动作价值的最大值 max_a′ q(St+1,a′)"。这个 max 不是实现细节，而是直接来自贝尔曼最优方程右端的算子，意味着 Q 学习法求解的是最优性方程，而非某个给定策略的方程。
（2）因为更新式完全不关心行为策略在 St+1 处实际选了哪个动作：目标策略（贪婪策略，隐含在 max 中）与生成经验的行为策略（通常 ε-贪婪）不必相同，两者分离即异策略。
（3）两大优势：其一，数据复用——历史日志、其他医师的处方记录、甚至人类专家轨迹都可以离线学习，只要数据包含"状态-动作-奖励-后继状态"，不必自己亲自走一遍；其二，探索与利用解耦——可以用高探索的行为策略收集数据，同时学习纯贪婪的最优策略，探索时的失误不会污染对最优价值的估计（学到的账本记的是"最优做法的价值"而非"当前做法的价值"）。

【评分要点】
- 差别表述正确得 3 分（须点出"实际选择的动作 vs 最大值"与"贝尔曼最优方程"）；
- 异策略解释得 3 分（行为策略与目标策略分离）；
- 两大优势各 2 分（共 4 分）：数据复用须含"离线/他人数据可用"，解耦须含"探索失误不污染最优估计"。

### 基础题 6（对应节号：6.6 稳健学习：多种目标的折中）

【填空题】TD 家族所有成员共用同一副骨架：q(St,At) ← q(St,At) + α[目标 − q(St,At)]，差异只在"目标"的构造。6.6 节给出三种折中工具：① 期望Sarsa 把 Sarsa 的后继项从"单次采样动作"换成"______"，以少量计算换______降低；② 双Q学习维护______套独立的 q 表，由一套表______、另一套表______，切断______偏差的高估回路；③ 批量TD 先收集一批数据再反复扫描，其收敛值满足______（英文：certainty equivalence）——收敛到"由这批数据构造的最大似然马尔可夫决策过程"的精确解。

【参考答案】① 按策略加权平均（Σ_a′ π(a′|St+1)·q(St+1,a′)），方差；② 两（2），选择动作、评估价值，最大化偏差（maximization bias）；③ 确定性等价。补充：期望Sarsa 是站在 Sarsa 与 Q 学习法之间的"乐观旋钮"——若 π 为贪婪策略，加权平均退化为 max，恰好退化为 Q 学习法；双Q 的"选择与评估分家"对应医疗中的"开药方的人与审药方的人分设"；批量TD 隐含完成"从数据学模型、再在学到的模型上求解"两步工作，在持续任务与离群数据下更稳健。

【评分要点】
- ① 填对"按策略加权平均"与"方差"各 1.5 分（共 3 分）；
- ② 填对"两套表/选择/评估/最大化偏差"共 4 分（每空 1 分）；
- ③ 填对"确定性等价"得 3 分；能补充"等价于先学经验模型再求解"加 1 分（满分封顶 10 分）。

### 综合题 7（对应节号：6.3 / 6.5 同策略与异策略）

【病案计算】微型两状态问题（正文例 6.2 / 例 6.4 的环境）：状态 s1 处可选"左"（奖励 −1，终止，模拟误治陷阱）或"右"（奖励 0，转移到 s2）；s2 处可选"右"（奖励 1，终止）。取 γ = 1，α = 0.1，初始 q 全 0。

（1）用 Sarsa 演算：回合 1 轨迹 s1 选"右"→s2，s2 选"右"→奖励 1 终止；回合 2 同轨迹。写出回合 2 结束后 q(s1,右) 与 q(s2,右) 的值。
（2）改用 Q 学习法处理同一批经验：数据 1：s1 探索选"左"（奖励 −1 终止）；数据 2：s1 选"右"到 s2；数据 3：s2 选"右"得 1 终止；数据 4：s1 选"右"到 s2（假设此刻行为策略在 s2 处实际选了"左"且 q(s2,左) = 0）。写出数据 4 结束后 q(s1,右) 的值，并说明它与 Sarsa 处理同一情境的差异。
（3）把（2）的差异翻译成临床语言：一位医者（甲）"按现行诊疗路径学习"与另一位医者（乙）"研读名医医案、向最优方案学习"，各自的"学习目标"分别对应 Sarsa 还是 Q 学习法的哪一项？为什么乙即使看到的是"别人走出的路"也能改进自己的判断？

【参考答案】
（1）Sarsa 回合 1：更新 (s1,右)：TD目标 = 0 + 1×q0(s2,右) = 0，q(s1,右) 不变为 0；更新 (s2,右)：TD目标 = 1，q(s2,右) = 0.1。回合 2：更新 (s1,右)：TD目标 = 0 + 1×0.1 = 0.1，q(s1,右) = 0.01；更新 (s2,右)：TD目标 = 1，q(s2,右) = 0.19。回合 2 后 q(s1,右) = 0.01，q(s2,右) = 0.19。
（2）Q 学习法：数据 1：q(s1,左) = 0 + 0.1×(−1−0) = −0.1；数据 2：TD目标 = 0 + max{q(s2,左), q(s2,右)} = 0，q(s1,右) 不变；数据 3：q(s2,右) = 0.1；数据 4：TD目标 = 0 + max{0, 0.1} = 0.1，q(s1,右) = 0.01。关键：数据 4 中即使行为策略在 s2 实际选了"左"（q(s2,左) = 0），Q 学习法仍用 max = 0.1 更新 q(s1,右)；而 Sarsa 用 q(s2,左) = 0 作目标，q(s1,右) 将保持不变。差异即同策略与异策略的本质：Sarsa 问"按当前做法实际走下去，这条路价值多少"；Q 学习法问"如果在后继状态采取最优行动，这条路价值多少"。
（3）甲按现行路径学习，其 TD 目标的后继项用"实际选择的动作"——对应 Sarsa（同策略），学到的是含探索做法的价值；乙研读名医医案，其 TD 目标的后继项用"最优动作的价值"——对应 Q 学习法的 max 项（异策略）。乙能改进，因为 Q 学习法不要求经验必须由目标策略产生：医案数据只须包含"状态-动作-奖励-后继状态"四元组，更新时用 max 跳过后继状态上的实际动作，直接向"如果走最优路线会怎样"校准——前人走过的弯路与直路都是教材。

【评分要点】
- （1）四个数值正确各 1 分（共 4 分）：回合 2 后 q(s1,右)=0.01、q(s2,右)=0.19，过程错但数值对扣 1 分；
- （2）数据 4 的 q(s1,右)=0.01 得 2 分，与 Sarsa 对照说明得 1 分（须点出"Q 用 max、Sarsa 用实际动作"）；
- （3）临床翻译 3 分：甲→Sarsa、乙→Q 学习法各 1 分，解释"四元组即可学习"或"max 跳过后继实际动作"得 1 分。

### 综合题 8（对应节号：6.4 / 6.6 n步回报与稳健折中）

【临床分析】一位医者记录了一条诊疗轨迹，其逐次反馈（奖励）为 r1 = 2、r2 = 3、r3 = 4、r4 = 5，第 4 步后疗程结束（终止状态），折扣率 γ = 0.9（正文例 6.3 的数值结构）。

（1）计算 G(1:2) 与 G(1:4) 的数值（G(1:4) 为完整回报）；写出两者中自举项系数各为多少。
（2）n 步回报法如何在"偏差"与"方差"之间取舍？结合两类临床任务说明 n 应如何选择：① 疗效反馈噪声大的任务（患者自评波动、症状自然起伏）；② 奖励延迟的任务（疗程末才显效）。各给出 n 的取向并说明理由。
（3）期望Sarsa 是稳健折中之一。设后继状态 S′ 处 π(左) = 0.5、π(右) = 0.5，表值 q(S′,左) = 0.1、q(S′,右) = 0.3，即时奖励 R = 0，γ = 0.9（正文例 6.5）。分别写出：Sarsa 单次采样可能得到的目标值（两个）、期望Sarsa 的目标值、Q 学习法的目标值，并说明三者差异对应哪三种"哲学"。

【参考答案】
（1）G(1:2) = 2 + 0.9×3 + 0.81q(S3,A3) = 4.7 + 0.81q(S3,A3)，其中自举项系数为 0.81；G(1:4) = 2 + 2.7 + 3.24 + 3.645 = 11.585，第 4 步已终止，无自举项（自举项系数为 0）。
（2）n 越大，目标中真实奖励项越多、自举项系数 γ^n 越小，受后继估计误差影响越小——偏差小但方差大（每项奖励都携带环境随机性）；n 越小，自举强、偏差大但方差小、信息回传快。任务①疗效反馈噪声大：宜选小 n（少让噪声进目标，多用自举平均掉随机起伏，如 n=1 的一步修正）；任务②疗程末才显效、奖励延迟：宜适当增大 n（一步目标携带的信息少，n 步目标包含足够的疗效信息，让"迟到的奖励"尽早进入学习目标）。
（3）Sarsa 单次采样：0.9×0.1 = 0.09 或 0.9×0.3 = 0.27（每次更新都带抽样噪声）；期望Sarsa：0.9×(0.5×0.1 + 0.5×0.3) = 0.18（把抽样噪声平均掉）；Q 学习法：0.9×max{0.1, 0.3} = 0.27（永远朝最乐观处看）。三者差异对应"采样随机性、策略平均、乐观估计"三种哲学：同一个后继状态，三种算法读出的"前景"不同，长期累积就分化出三种学习性格。

【评分要点】
- （1）两个数值 + 自举系数 2 分（G(1:2) 表达式正确得 1 分、G(1:4)=11.585 得 1 分）；
- （2）偏差-方差取舍 2 分（须同时点出"大 n 偏差小方差大、小 n 方差小偏差大"），两类任务各 2 分（共 4 分），任务①须答"小 n"，任务②须答"大 n"，理由与正文一致；
- （3）三个数值各 1 分（共 3 分）+ 三种哲学对应 1 分。

### 综合题 9（对应节号：6.2 / 6.6 TD(0) 与批量TD、确定性等价）

【分析题】某慢病管理环境含两个状态 s1（稳定期）、s2（波动期），采集到三条数据：D1：s1→s2，奖励 0；D2：s2→s1，奖励 1；D3：s2→s1，奖励 1。取 γ = 0.9（正文例 6.6）。

（1）按确定性等价原理，写出由这批数据构造的经验模型（转移概率与奖励），并列出价值方程，解出 v(s1) 与 v(s2)（保留两位小数）；
（2）说明为什么批量统计估计法（蒙特卡洛式）在此数据上无法应用，而批量TD 可以；
（3）结合 6.2 节的 TD(0) 与第 3 章的统计估计法，从"在线学习 vs 批量学习""持续任务 vs 回合任务"两个维度，说明为什么 TD 家族在慢病管理等持续任务中天然占优。

【参考答案】
（1）经验模型：从 s1 以概率 1 转移到 s2、奖励 0；从 s2 以概率 1 转移到 s1、奖励 1。价值方程：v(s1) = 0 + 0.9v(s2)，v(s2) = 1 + 0.9v(s1)。联立解得 v(s1) ≈ 4.74，v(s2) ≈ 5.26（v(s2) = 1/0.19 ≈ 5.2632，v(s1) = 0.9×v(s2) ≈ 4.7368）。读者可验证：从 v = 0 出发反复扫描这三条数据，价值单调上升收敛到这两个数值。
（2）三条数据无一到达终止状态，无法构造任何完整回报——统计估计法（蒙特卡洛式）必须等回合结束才能更新；而 TD 的学习目标只需"一步真实奖励 + 后继状态估计"，不需要终止，因此在这批"永不终止"的数据上依然可以逐条更新。
（3）在线维度：TD(0) 每获得一步经验立即更新（即时性、增量性、样本高效性），批量TD 则先收集再反复扫描——但两者都不要求回合终止；统计估计法只能在回合结束时整段回传，方差大、更新慢。任务维度：持续任务没有终止状态，统计估计法无从构造回报，TD 却可步步为营；慢病管理正是"没有终点"的持续任务——疗程可能长达数年、随访永不终止，TD 家族（尤其增量式 TD 与批量TD 的组合）能边收集边学习，这是它相对统计估计法的天然优势，也是"走一步看一步"在临床持续场景中的价值。

【评分要点】
- （1）经验模型正确得 2 分、方程列对得 2 分、数值 v(s1)≈4.74 / v(s2)≈5.26 得 1 分（共 5 分）；
- （2）说明"无终止→无完整回报→统计估计法失效"得 2 分；
- （3）两个维度各 1.5 分（共 3 分）：在线维度须含"即时更新/增量"任一关键词，持续任务维度须把"慢病随访"与"无终止"对应起来；只贴概念未结合题境扣 1 分。

### 挑战题 10（对应节号：6.5 / 6.7 / 6.8 Q学习法、系统科学定位、六者和谐）

【开放设计题】tcmP 中医医院 AI 网络教育平台计划联合全国多家医院，为"2 型糖尿病慢病管理"开展多中心联邦学习：各中心医者 Agent 在本地用 TD 家族算法学习价值估计，只共享更新量、不共享原始病历。

（1）画出联邦学习的数据流（数据不动、模型动）：各中心如何在本地完成"一步经验→价值修正"，中央如何聚合与下发；说明 TD 的增量形式为何天然适配这种增量式聚合；
（2）若中心 A 采用 Q 学习法（含 max 运算），指出多中心数据场景下最大化偏差（maximization bias）被放大的可能路径，并给出至少两种缓解手段；
（3）用 6.7 节"系统科学定位"的三个概念（个人定位、场景生存最适度、环境共荣最适度）说明：各中心的 ε、学习率 α、折扣率 γ 是否应当完全一致？给出你的参数标定建议（可参照"急诊/慢病"或"南北方证候差异"举例）；
（4）用 6.8 节"六者和谐"说明：差分隐私、知情同意、审计问责、底线约束四项机制各守护六方中的哪一方（或哪几方），并写出一句该方案对"数据是公共的财富，隐私是个人的主权"的落地表述。

【参考答案（示例，允许合理差异）】
（1）数据流：① 各中心（医院 A/B/C…）数据不出院，在本地用 TD 更新式 v(St) ← v(St) + α[Rt+1 + γv(St+1) − v(St)]（或对应 q 表版本）完成价值修正；② 各中心只把"更新后的价值表或修正量（如 TD 误差 δt 的汇总）"而非原始数据上传中央；③ 中央聚合（如按样本量加权平均）后下发更新后的全局价值表；④ 各中心以全局表为新的起点继续本地学习，循环迭代。TD 的增量形式天然适配：每次更新只改变一个条目、单次更新信息量极小，正是"聚少成多、不见全貌"的联邦式汇聚——分享的是"学到了什么"，而不是"看到了什么"，就像各医院只交流诊疗经验、不交换病历原件。
（2）放大路径：max 会对噪声取乐观值——多中心数据噪声源更多（不同医院诊疗习惯、随访质量差异），若某动作在某中心被偶然噪声捧高，max 会把该高估沿自举链向上游传播，误导全局策略选择；中心间差异使"局部最优"与"全局最优"可能错位，高估被放大。缓解手段（至少两种，任选）：① 用更小的学习率，减弱单次高估幅度；② 奖励归一化，压缩噪声尺度；③ 双Q学习——两套独立 q 表，一套选择、一套评估，切断"自己选自己、自己夸自己"的高估回路；④ 聚合时对单中心修正量做异常值截断/加权，防止个别中心的乐观噪声主导全局。
（3）不应完全一致，应按"场景生存最适度"分别标定：个人定位——各中心先维护自己的基线（与同行均值、证据等级顶线的差距）再参与学习；场景生存最适度——基层门诊（常见病多、疗程短、随访噪声大）宜用小 α、小 γ、小 ε（重即时、重稳定利用），三甲内分泌科（重症多、疗程长、远期转归重要）宜用大 γ 与小 α（重远期），新开展的证候队列初期宜提高 ε 充分探索、随证据积累衰减；环境共荣最适度——各中心通过接口耦合（转归状态、依从水平互相关联），中央聚合时按"个体最适度×环境承载力"加权，避免任何单一中心的数据分布主导全局（如北方寒证数据淹没南方湿热证数据）。
（4）守护对应：差分隐私守护患者（患）——注入受控噪声使聚合结果无法反推个体；知情同意守护患者与医师（患、医）——使用范围、目的、期限采集前说明、可撤回授权；审计问责守护规者、法者（规、法）——每次访问与更新留痕、合规审查；底线约束守护患者利益与社会公平（患、社）——即使共享能提升疗效也不能绕过同意、不能据此歧视群体。落地表述示例："在 tcmP 平台上，各医院只共享'学到了什么'的更新量，配合差分隐私与分级授权，让数据作为公共财富流动、让隐私作为个人主权受保护——滴水成河，而不暴露一滴水的来源。"

【评分要点】
- （1）数据流完整（本地更新→只传更新量→中央聚合→下发→迭代）得 3 分，缺中央聚合或"只传更新量"关键点各扣 1 分；"TD 增量天然适配"说明 1 分；
- （2）放大路径 1 分（须点出"max 对噪声取乐观 + 自举链传播"或"多中心噪声源更多"），缓解手段每种 1 分（共 2 分，≥2 种，只写名称未说明机制扣 0.5 分/种）；
- （3）三概念各 1 分（共 3 分）：个人定位须含"基线校准/参照系"，场景生存最适度须给出具体参数取向，环境共荣最适度须含"接口耦合/加权聚合避免单一中心主导"；只贴名词扣 1 分；
- （4）四项机制各 0.25 分（共 1 分，须对应到具体六方），落地表述一句 1 分（须同时含"共享/流动"与"隐私/主权"两个关键词）。
