## 6.4 n 步回报法：看得更远一些

### 6.4.1 概念与内涵

Sarsa的TD目标只利用一步经验：Rt+1 + γq(St+1,At+1)；统计估计法的目标是完整回报，要等回合结束。一步太短，全程太长，两者之间隔着一条连续的谱带：n步回报法。把学习目标从"1步经验+1步自举"推广为"n步经验+n步后的自举"：G(t:t+n) = Rt+1 + γRt+2 + γ²Rt+3 + … + γ^(n−1)Rt+n + γ^n·q(St+n,At+n)。前n项是真实的奖励观测，最后一项是第n步后继状态-动作对的价值估计——自举项。当n=1时，G(t:t+1) = Rt+1 + γq(St+1,At+1)，恰好是Sarsa的目标；当n→∞且回合在第t+n步终止时，自举项消失，退化为完整回报，即统计估计法的目标。因此n步回报法把Sarsa与统计估计法统一在同一框架之下：n是从1到无穷的旋钮，转动它，就在"完全自举"与"完全无自举"之间连续过渡。"看得更远一些"的代价是要等得更久一些：n步回报要等n步的真实奖励都观察到才能构成目标——视野与等待，是同一个旋钮的两面。就像医师查房：只看今天一步，判断难免短视；要等整个疗程结束再总结，又错过及时修正；折中地看三五天，往往最能平衡速度与信息量——n步法给的正是这个"折中地看"的精确旋钮。

n的选择实质上是偏差与方差的权衡，这是理解整个TD家族性能的主线。n越大，目标中真实奖励的项越多，自举项系数 γ^n 越小，目标受"后继估计误差"的影响越小——偏差越小，n→∞时目标无偏；但目标包含的随机变量越多，样本方差越大：每一个奖励都携带环境随机性，n步积累的噪声远大于1步。反过来，n越小，自举越强、偏差越大，但方差越小、信息回传越快——每走一步就能更新一次。概括为一句话：自举项是"估计的估计"，携带系统性偏差；真实奖励是"观测"，携带随机噪声；n步回报法让我们按需调配两者的比例——想少受估计误差拖累，就多信真实奖励（大n）；想少受随机噪声干扰，就多信自举（小n）。在工程实践中n取3到5常能取得较好折中，但最优值高度依赖任务：奖励噪声大的任务宜用小n（少让噪声进目标），奖励稀疏而转移确定的任务可用大n（多让真实奖励进目标）。对中医场景而言，这条权衡给出一个实用启示：疗效反馈噪声大（患者自评波动、症状自然起伏）时，应偏向小n的一步修正；而像"疗程末显效"这类奖励延迟的任务，则应适当增大n，让目标包含足够的疗效信息。

### 6.4.2 方法与实现

n步Sarsa的实现有一个关键的时间错位：在时刻t+n（已观察到Rt+1…Rt+n与St+n、At+n）才能计算G(t:t+n)，进而更新n步之前的条目 q(St,At)。因此实现上需要维护一个长度为n的缓冲区，保存最近n步的"状态-动作-奖励"记录；每前进一步，计算最旧记录对应的n步回报并更新其价值。算法流程：初始化q表、缓冲区与ε-贪婪策略；对每个回合：初始化状态S0，按策略选A0并入缓冲；对t=0,1,2,…：执行At，观测Rt+1、St+1；若St+1非终止，按策略选At+1并入缓冲，否则记At+1为"无"；当缓冲满n步或回合已终止时，用G(t−n:t)更新q(St−n,At−n)；回合结束时，用从终止倒推的实际回报依次更新缓冲中尚未更新的条目——此时自举项为0，因为终止状态之后没有动作可自举。回合提前终止的处理值得强调：若轨迹在第T步终止（T < t+n），对尚未更新的条目，n步回报退化为从t到终止的完整回报，自举项自然消失，与统计估计法在回合末端平滑衔接——这个处理让n步法在任何任务上都不会出现"等不到回报"的死角，也保证了n步法在回合任务上的无偏性继承。

例6.3：设一条轨迹的即时奖励为 r1=2、r2=3、r3=4、r4=5，第4步后到达终止状态，折扣率γ=0.9，终止状态价值为0。逐项计算从t=1出发的n步回报：G(1:1) = r1 + γq(S2,A2) = 2 + 0.9q(S2,A2)；G(1:2) = r1 + γr2 + γ²q(S3,A3) = 2 + 2.7 + 0.81q(S3,A3) = 4.7 + 0.81q(S3,A3)；G(1:3) = r1 + γr2 + γ²r3 + γ³q(S4,A4) = 2 + 2.7 + 3.24 + 0.729q(S4,A4) = 7.94 + 0.729q(S4,A4)；G(1:4) = 2 + 2.7 + 3.24 + 3.645 = 11.585——第4步已终止，无自举项，即完整回报。观察数值结构：随着n从1增大到4，真实奖励的累计值从2增长到11.585，自举项系数从0.9递减到0——目标从"几乎全是估计"平滑过渡到"完全是观测"。若q表当前偏差很大，小n会把偏差通过自举项传播得更远；若奖励噪声很大，大n会放大方差——这就是"视野旋钮"的力学原理。读者可做一个思想实验：在例6.1的四状态链上改用n=2的回报，s1的价值在第一个回合就会收到s3的信息，信息传播速度比n=1快一倍——多看一步，就快一步，这是n步法最直接的收益证据，也是它常被用于加速学习的根本原因。

### 6.4.3 小结与衔接

本节把"一步"推广为"n步"，核心结论有三。第一，n步回报 G(t:t+n) 是Sarsa（n=1）与统计估计法（n→∞）之间的连续插值，n是"视野旋钮"：n大则多信真实奖励、少信估计，偏差小方差大；n小则多信估计、少信观测，方差小偏差大——两个方向各有代价，没有免费午餐。第二，实现要点是时间错位与缓冲区：n步回报要等n步之后才能构成，需用长度为n的缓冲保存近期经验；回合提前终止时，未更新条目改用完整回报，自举项消失——缓冲区是"记忆"，错位是"耐心"，两者缺一不可。第三，n步思想在TD家族中的定位是一条谱系——统计估计法（n=∞）—n步Sarsa（1<n<∞）—Sarsa（n=1）——沿着这条谱系，偏差从0单调增大、方差从大单调减小、信息回传从"回合结束一次"提高到"每步一次"。这条谱系的价值在于：它把"用多少步经验构造目标"从二选一变成可调参数，使算法设计者能针对具体任务的噪声结构做精细调优，而非在"等全程"与"看一步"之间勉强抉择。代价是两点：更新有延迟、需要n步缓冲区，在线体验与内存开销略逊于一步更新——视野的拓宽从来不是免费的。

n步思想在本书后续有两处重要延伸。第一，把"取单个n步回报"推广为"对多个n加权平均"，就得到TD(λ)方法与资格迹：对n=1,2,…的回报按 λ^(n−1) 加权求和，λ成为又一个旋钮——λ越接近1越像统计估计法，越接近0越像一步TD；虽然本书不展开TD(λ)，但"加权平均比单点更稳"的思想将在第8章函数近似中反复出现，届时读者会发现这里的直觉可以直接复用。第二，n步目标也是深度强化学习中DQN等算法的常用升级：n步目标比一步目标携带更多奖励信息，通常收敛更快——许多工程上的性能提升，其实就是在转动"视野旋钮"，把n从1调到3或5。对读者而言，本节最重要的收获不是公式，而是视角：TD家族不是几个孤立算法，而是一个由"经验长度n"与"自举强度"参数化的连续空间，理解这个空间的结构，比记住单个公式更重要——有了这张空间地图，任何新算法都可以在图上定位。下一节引入TD家族最著名的成员——Q学习法：它把"看多远"的问题放在一边，用最大值运算直接向最优方案学习，进入异策略学习的新天地。
