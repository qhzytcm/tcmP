## 图 6-1 时序差分的节奏：一步经验与自举（对应节号：6.1.1）

- 图题：走一步看一步：TD 的学习目标与自我修正
- 内容说明：展示 TD 区别于统计估计法的核心节奏。左侧为"老账/新账"比喻：医师初诊时的判断 v(St) 是"老账"，复诊看到一步真实反馈 Rt+1 后，结合对后继证候的预判 v(St+1)，得到"新账" Rt+1 + γv(St+1)；老账与新账之差即 TD 误差 δt，正负号自动指示修正方向。右侧给出更新式 v(St) ← v(St) + α[Rt+1 + γv(St+1) − v(St)] 与"自举"标注：用自己当前的估计改进自己。
- 绘制建议：
  - 结构：左半幅为两位"账房"示意图（老账本 vs 新账本），右半幅为更新式推导链条：v(St) → 目标 Rt+1+γv(St+1) → δt 误差 → 修正方向箭头（向上/向下）→ 新 v(St)。
  - 标注：在更新式下方用括号注明三个英文对照：TD 目标（TD target）、TD 误差（TD error）、自举（bootstrapping）；在"新账"旁标注"比老账多了一天的观察，自然更可信"。
  - 对比框：右侧浅灰小框对比统计估计法"必须等回合结束"与 TD"每走一步就更新"，用两种颜色箭头区分等待与即时。

  - 配色：DP 冷色（蓝）、统计估计法暖色（橙）、TD 高亮绿色并加"本书第6章主角"角标。

- 内容说明：一条横轴代表"视野旋钮 n"：n=1 处为 Sarsa（G(t:t+1) = Rt+1 + γq(St+1,At+1)，完全一步自举），n→∞ 处为统计估计法（完整回报、无自举），中间 1<n<∞ 为 n 步 Sarsa。轴下方标注偏差/方差随 n 的变化：n 增大，偏差↓、方差↑、信息回传从"每步一次"退化为"回合结束一次"。右上角小公式框：G(t:t+n) = Rt+1 + γRt+2 + … + γ^(n−1)Rt+n + γ^n·q(St+n,At+n)。附临床对照："只看今天一步，判断难免短视；等整个疗程结束再总结，又错过及时修正；折中地看三五天（n=3~5），往往最能平衡速度与信息量"。

## 图 6-9 稳健学习：三种折中工具（对应节号：6.6.1、6.6.2）

- 图题：稳健学习的三把折中钥匙：期望Sarsa、双Q、批量TD
- 内容说明：三栏对比三种折中工具。① 期望Sarsa：把后继项"单次采样动作"换成"按策略加权平均 Σ_a′ π(a′|St+1)·q(St+1,a′)"——正文例 6.5 数值：Sarsa 单次采样得 0.09 或 0.27、期望Sarsa 得 0.18、Q 学习法得 0.27，三者对应"采样随机性、策略平均、乐观估计"三种哲学；② 双Q学习：两套独立 q 表 q1、q2，一套选择动作、另一套评估价值，交替更新，切断最大化偏差的"自己选自己、自己夸自己"高估回路——附对照"开药方的人与审药方的人应当分设"；③ 批量TD：先收集数据再反复扫描，收敛值满足确定性等价——从数据学模型、再在学到的模型上求解。
- 绘制建议：
  - 结构：三栏等宽布局，栏头分别标"期望Sarsa / 双Q学习 / 批量TD"，栏内画各自的机制示意。
  - ① 栏：一个后继状态 S′ 下两个动作（左、右）的扇形图，标注 π=0.5/0.5 与 q=0.1/0.3，下方三个目标值并排（0.09/0.27 的采样、0.18 的平均、0.27 的 max），用不同底色区分。
  - ② 栏：两套表（q1 蓝、q2 橙）并排，画一条"选择"箭头从 q1 指向动作、一条"评估"箭头从 q2 指向该动作，中间画一把剪刀切断自环，标注"选择与评估解耦"。
  - ③ 栏：数据堆（三条记录 D1/D2/D3）→ 经验模型（转移+奖励）→ 求解 → 价值 v(s1)≈4.74、v(s2)≈5.26，箭头链标注"确定性等价"。
  - 图下注释：\"稳健不是在任何单点上做到极致，而是在整体上不塌方——中庸不是平庸，而是对复杂性的诚实尊重。\"

## 图 6-10 在线进化：系统科学定位三概念（对应节号：6.7.1、6.7.2）

- 图题：个人定位、场景生存最适度、环境共荣最适度：在线进化的坐标
- 内容说明：以递进结构展示在线进化的系统科学定位。核心三角：个人定位（individual positioning）——"我在哪"（每个个体在知识与策略坐标系中找到自己的位置，价值估计表是个人定位的形式化载体）；场景生存最适度（scenario survival optimality）——"我该怎样做"（与场景相宜的适度，而非脱离场景的最大值）；环境共荣最适度（environment co-prosperity optimality）——"我们该怎样一起做"（个体价值与环境价值共同繁荣）。右下角附场景参数标定表：急诊（大 α、小 γ、重即时）、慢病（小 α、大 γ、重远期）、康复（中 α、中 γ、重功能）、治未病（小 α、大 γ、重预防）。
- 绘制建议：
  - 结构：中央一个三层嵌套三角/同心结构：最内"个人定位"、中层"场景生存最适度"、外层"环境共荣最适度"，三层之间用递进箭头连接（基础→约束→目标）。
  - 标注：每层旁标三问——"我在哪 / 我该怎样做 / 我们该怎样一起做"；层间标注"个人是小天，场景是中天，环境是大天——天人合一的可计算版本"。
  - 场景参数表：右下角四行两列表格（场景 | α/γ/ε 取向），与正文 6.7.2 完全一致；用"场景切换时显式更换参数"的警示框提示"避免把急诊的最适误用到慢病场景"。
  - 实现四条路径：图底部列四个小图标——增量更新、探索-利用平衡（ε 随场景周期调度）、基线校准、反馈校准。
  - 配色：由内向外由深至浅（如深绿→浅绿→浅黄），体现"个体在系统中成长"。

## 图 6-11 六者和谐与联邦学习架构（对应节号：6.8.1、6.8.2）

- 图题：数据共享与隐私尊重：六者和谐与联邦学习
- 内容说明：左半幅为六者和谐关系图：患者、医师、药者、械者、规者、法者六方围成六边形，中央标注"数据是公共的财富，隐私是个人的主权"；共享与隐私分别指向"让财富流动"与"不让主权受损"两条护栏。右半幅为联邦学习架构："数据不动、模型动"——多家医院（中心 A/B/C…）数据不出院，各自在本地用 TD 更新价值估计，只把"更新后的价值表或修正量"上传中央，中央聚合后下发全局表，各中心继续本地学习；技术配套：差分隐私（注入受控噪声）、匿名化与去标识化、加密计算（同态加密/安全多方计算）；治理配套：知情同意、数据分级、审计与问责、底线约束。
- 绘制建议：
  - 左半幅：正六边形顶点布局六方（患者上、医师右上、药者右下、械者下、规者左下、法者左上），中央暖色圆斑标"健康共同体"；"共享"与"隐私"两条弧线分别沿顺时针/逆时针方向标注，弧线外标"两条护栏"。
  - 右半幅：三个"医院"方块（各含一个"本地TD更新"小循环）通过箭头连到中央"联邦聚合"圆，中央再以虚线箭头下发"全局价值表"；沿上传箭头标注"只传更新量（TD误差/价值表），不传原始数据"。
  - 技术/治理标签：右半幅底部两行小标签——技术行：差分隐私、匿名化、加密计算；治理行：知情同意、数据分级、审计问责、底线约束。
  - 尺度标注：图下三条横带——六者和谐 → 和谐社会 → 人类命运共同体，标注"从个体到社会再到人类，和谐层层放大，原则始终如一"。
  - 注意：联邦学习架构中的箭头方向（上传更新量、下发全局表）必须清晰，这是"数据不动、模型动"的视觉核心。
