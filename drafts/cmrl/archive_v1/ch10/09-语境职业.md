## [Part2] 10.8 中医药语境与职业应用

### 10.8.1 中医辨证的场景化理解

把本章的 AC 概念翻译成中医语言，会得到一幅自然的对应图景。四诊信息——望闻问切采集的症状集合——构成状态 $s$：如"失眠、心烦、舌红少苔、脉细数"是一个状态；辨证结论与治法方药构成动作 $a$：如"滋阴降火、交通心肾，予天王补心丹"；疗效转归构成奖励 $r$：症状缓解、复诊改善为正奖励，不良反应、病情反复为负奖励。在此映射下，优势函数的中医含义最为鲜明：$A(s,a) = q_\pi(s,a) - v_\pi(s)$ 度量"该方剂相对当前辨证方案平均水平的优劣"——这正是临床的"疗效优于基线"评价。临床直觉"效不更方"对应优势近似为零：疗效与预期平均相当，维持原法；"效改其方"对应负优势：疗效劣于预期，调整治法；"效如桴鼓"对应正优势：疗效显著优于平均，该治法值得强化沿用。TD 误差 $\delta = r + \gamma\hat{v}(s') - \hat{v}(s)$ 则是"本次疗效反馈与预后估计之差"：每次复诊都是一次自举更新，用"本次症状缓解 + 对后续转归的估计"修正"对该方剂价值的估计"，不必等病人完全痊愈才总结整段病程。actor 是辨证开方的决策主体（医者），critic 是疗效评价体系（疗效随访、同行评议、质控）——中医师承中"老师点评"就是 critic 信号，学生的开方风格（actor）在点评（critic）中逐步成型。

### 10.8.2 tcmP 平台映射

在 tcmP 平台中，本章知识有完整的对应物。六者 Agent：医者 = actor（辨证 + 方剂推荐）；规者 + 药者 = 双 critic（质控评估 + 审方把关）；患者 = 环境（提供转归反馈）。病证单元（DSU）是状态-动作-奖励的知识载体：平台病证库 60000+ 病证单元（教学切片 103+），每个 DSU 内含症状（状态）、方剂（动作）、证据等级映射分（奖励）——这正是 critic 先验 $w_0$ 与 actor 先验 $\theta_0$ 的来源。医圣 SOUL（sages/zhang-zhongjing 的六经辨证规则）构成策略先验与可行域，对应 AC 的"参数只允许在可行域内更新"。语义检索 /semantic-search 承担双重角色：为 actor 提供初始动作排序（检索 Top1 = 规则策略初值），为 critic 提供证据分奖励（归一化到 [0,1]）。医圣成长路径 = 先验初始化 + 在线进化：从静态知识库起步，每次对话产生 TD 误差 → 更新医者策略（actor）→ 质控验证（critic）→ 自动上线，这就是 AC 的工程闭环。平台 CI/CD 流水线（对话日志 → 批量离线更新 → 评估 → 上线）对应异策略批量学习：历史日志即训练数据，重要性采样修正分布偏差。双 critic 的架构思想（规者管疗效、药者管安全）与 SAC 的 min 操作、医院的双重审核制度同构——评价器分离是防止单一指标被过度优化的制度保障。

### 10.8.3 医案与病证数据示例

用三个真实病证单元演示本章概念。失眠 DSU：症状 = 入睡困难、多梦、心悸；候选动作 = {酸枣仁汤, 天王补心丹, 交泰丸}；证据等级映射分：系统综述 ≥ 0.8、随机对照试验 0.6~0.8、专家共识 0.4~0.6。感冒 DSU：症状 = 恶寒发热、头身痛、脉浮；动作 = {荆防败毒散（风寒）, 银翘散（风热）}——风寒/风热的辨证差异本身就是优势信号。头痛 DSU：症状 = 头痛、项强、脉弦；动作 = {川芎茶调散（风寒头痛）, 天麻钩藤饮（肝阳上亢）}。演示一次 A2C 更新：设失眠状态下 critic 估计 $\hat{v}(\text{失眠}) = 0.5$，医者推荐天王补心丹，语义检索证据分归一化后 $r = 0.72$，$\gamma = 0.9$，后继状态仍为失眠（复诊未愈但未恶化）：$\delta = 0.72 + 0.9 \times 0.5 - 0.5 = 0.67 > 0$——该方剂优于当前平均水平，actor 提升其概率；若药者审方拒绝（如与患者现有用药构成配伍禁忌），则 $\delta$ 置 $-1$（或 $-M$），该方剂概率被大幅压低——"证据等级 = 先验奖励、药者审方 = 硬约束、复诊转归 = 长期回报"完整复现了本章"评价信号驱动策略"的结构。三个 DSU 的共同点在于：证据等级决定了奖励先验，审方决定了安全边界，而 AC 决定了策略如何随真实反馈持续进化。

### 10.8.4 职业应用·临床医师

临床医师的强化学习应用围绕"辨证决策辅助、诊疗路径优化、师带徒学习"展开。辨证决策辅助：AC 提供 Top-K 概率推荐——actor 输出候选方剂的概率排序，critic 输出质控评分，推荐理由可标注"该方优于同类方案平均水平 X%"（优势的可解释表达）；鉴别诊断时，相似症状状态的候选优势差异能提示未考虑的病机。方法与工具链：医者 Agent 对话接口（/consult/sage-zhang-zhongjing）获取交互上下文 → 语义检索证据分（/semantic-search）→ actor 排序输出候选 → 药者审方与规者质控反馈回写更新。诊疗路径优化：把"首诊 → 复诊 → 转归"建模为 MDP，状态 = 病情分期 + 治疗阶段，动作 = 随访决策（何时复查、何时调方、何时转诊），奖励 = 转归 + 资源效率，用 A2C 学习最优随访策略。师带徒学习：把名老中医的历史医案作为异策略数据——行为策略是老师的开方风格，目标策略是学生（新医者 Agent）的策略，用重要性采样修正分布差异，"跟诊随记"由此算法化：每次跟诊的一步反馈都能即时修正学生的辨证估计。安全边界必须强调：AC 输出仅供参考，最终辨证权在医师手中；平台人格边界规定医者 Agent"不直接开具剂量"，对应强化学习的"人在回路"约束；药者红线（十八反、十九畏）是任何梯度都无法谈判的硬约束。趋势：人机协同辨证、辨证路径循证审计（critic 可解释扣分原因）、多 Agent 联合诊疗（六者互训）；职业素养要求：理解优势是相对概念（相对平均而非绝对疗效）、能设计奖励（复诊转归如何量化）、具备识别"评价器高估"的批判意识。

### 10.8.5 职业应用·医院管理

医院管理岗位（规者视角）的强化学习应用围绕"CDSS 质控、排班与资源调度、流程优化"展开。CDSS 质控：规者 Agent 的质控模型就是 critic——处方合规率、床位周转率、复诊依从性、平均住院日等指标构成价值估计 $\hat{v}$，实时评估每一条诊疗路径"是否优于基线"；质控反馈（扣分项、预警项）即 TD 误差 $\delta$，驱动医者策略（actor）调整。排班与资源调度：状态 = 医生负荷、床位占用、患者流；动作 = 调度决策（分诊去向、床位分配、手术排期）；奖励 = 效率指标；调度策略是 actor，绩效评估是 critic——这与 10.2 节 QAC 的结构完全同构，只是状态与动作换成了管理对象。流程优化：门诊流程、检查路径（先查什么、何时复测）的优化同样适用"动作优于平均"的优势信号。方法与工具链：质控数据仓库 → 指标基线（critic 的 $w_0$ 初始化）→ 患者流仿真环境（离线异策略学习，历史数据重放）→ 上线前在仿真中验证。趋势：联邦学习多中心质控（数据不出院，只传梯度或参数——AC 两模块天然支持分布式）、可解释 critic（质控扣分必须给出依据）、人机协同排班。

医院管理应用必须警惕"奖励黑客"：若 critic 只奖励床位周转率，调度策略可能学到"过早让患者出院"这类短期指标漂亮、长期疗效受损的行为。防范之道正是本章的双 critic 思想：效率 critic 与质量/安全 critic 并立，任何单一指标都被另一指标对冲；必要时叠加硬约束（法者 Agent 的合规红线）。职业素养提示：指标设计决定学习行为——奖励是管理者意图的数学化，必须反复审视"优化这个指标真的等于提升医疗质量吗"；同时理解两时间尺度的管理含义：指标基线（critic）要先稳定，管理策略（actor）再演进，频繁更换考核口径会让整个系统无所适从。从算法到管理，"评价机制与决策机制分离"这一 AC 的核心思想，正是现代医院精细化治理的方法论内核。
