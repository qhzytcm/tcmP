## [Part1] 第10章 Actor-Critic 方法（Actor-Critic Methods）：章引言

在进入本章之前，读者已经掌握了强化学习的两种基本范式。第8章的价值函数方法用参数化函数 $\hat{v}(s,w)$、$\hat{q}(s,a,w)$ 估计价值，通过贝尔曼方程驱动参数更新，代表算法是 Sarsa 与 Q-learning 的函数近似版本；第9章的策略梯度方法则直接参数化策略 $\pi(a|s,\theta)$，用策略梯度定理 $\nabla_\theta J(\theta) = \mathbb{E}_{S\sim\eta, A\sim\pi}[\nabla_\theta \ln \pi(A|S,\theta)\, q_\pi(S,A)]$ 指导参数更新，代表算法是 REINFORCE。然而这两条路线各有所短：价值方法擅长评估却难以直接处理连续或大动作空间；REINFORCE 虽然天然适配任意动作空间，但其策略梯度用蒙特卡洛回报估计动作价值，方差极大，学习缓慢。本章介绍的 Actor-Critic（AC）方法正是对这两条路线的折中与融合：它同时维护两个学习模块——actor 用策略梯度更新策略参数，critic 用时序差分估计价值函数——让价值估计以低方差的方式为策略梯度提供加权信号。actor 之所以叫 actor，是因为动作由遵循该策略产生，如同演员在舞台上表演；critic 之所以叫 critic，是因为它通过评估价值来"评价"actor 的表现，如同影评人评判演员。理解本章，读者需要先掌握第8章的价值函数近似与第9章的策略梯度定理，并借助第6章的随机逼近与第7章的时序差分视角理解收敛性。

本章的知识结构沿 AC 家族由简到繁展开。10.1 节从 REINFORCE 的方差问题出发，引出 actor 与 critic 的分工，给出理解 AC 的两种视角——结构视角（同时包含策略方法与价值方法）与算法视角（仍是策略梯度算法）；10.2 节介绍最简的 Q actor-critic（QAC）算法，critic 用 Sarsa 估计动作价值，actor 用动作价值加权策略梯度，并给出完整的一步数值演算；10.3 节引入优势函数 $A(s,a) = q_\pi(s,a) - v_\pi(s)$，得到优势 Actor-Critic（A2C），用 TD 误差作为优势的无偏估计，显著降低方差并节省参数；10.4 节介绍 A3C（异步并行，多个 worker 各自与环境交互并异步更新共享参数）与异策略 AC（用重要性采样修正行为策略与目标策略的分布差异，是 SAC 等现代算法的思想基础）；10.5 节给出两个理论工具——兼容性条件刻画"什么近似不破坏策略梯度"，自然梯度用 Fisher 信息矩阵实现参数化不变性，并延伸到信赖域方法 TRPO 与工程化裁剪目标 PPO；10.6 节总结全章。在理论之后，10.7 节把 AC 框架映射到 tcmP 中医药智能平台：医者 Agent 是 actor，规者与药者 Agent 构成双 critic，病证单元 DSU 中症状即状态、方剂即动作、证据等级即奖励，语义检索 semantic-search 提供先验排序与证据分奖励；10.8 节给出中医药语境下的重新诠释，以及临床医师与医院管理两类职业的应用场景。

学完本章，读者应当达到以下目标。知识目标：能够写出 QAC、A2C 的完整更新公式，准确解释优势函数、TD 误差作优势估计的无偏性、重要性采样比率、兼容性条件与自然梯度的数学含义，说出 A3C 并行机制与 PPO 裁剪目标的设计动机。能力目标：能够对小型马尔可夫决策过程手工演算 actor 与 critic 的一步更新，能够用 numpy 在 tcmP 平台接口上实现"医者 actor + 规者 critic"的六者 AC 闭环模拟，能够通过对比实验分析两时间尺度、优势基线、双 critic 对收敛的影响。素养目标：树立"actor 想干什么、critic 说值不值"的双模块思辨视角，理解评价机制与决策机制分离的系统思想，并能把这一视角迁移到辨证决策辅助、医院质控与资源调度等真实问题中。在阅读过程中，建议读者始终抓住三个问题：每一步更新在更新什么参数、用什么信号加权、凭什么保证不偏离正确方向——它们是贯穿本章 QAC、A2C、A3C 与理论工具的共同线索。
