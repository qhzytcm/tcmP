## [Part1] 10.5 兼容性条件与自然梯度

### 10.5.1 兼容性条件：什么近似不破坏策略梯度

本章所有 AC 算法都用一个正在学习的 critic 替代定理中的 $q_\pi$：QAC 用 $\hat{q}(s,a,w)$，A2C 用 TD 误差 $\delta_t$（其条件期望是优势）。一个根本的理论问题是：近似误差会不会把策略梯度的方向带偏？兼容性条件（compatibility condition）给出一个充分条件：若 critic 的近似 $\hat{q}(s,a,w)$ 满足如下两条——（i）结构条件：$\nabla_w \hat{q}(s,a,w) = \nabla_\theta \ln \pi(a|s,\theta)$，即价值近似关于参数 $w$ 的梯度恰好等于对数策略梯度；（ii）最优性条件：$w^*$ 最小化均方误差 $\mathbb{E}[(\hat{q}(s,a,w) - q_\pi(s,a))^2]$——则用 $\hat{q}(s,a,w^*)$ 替代 $q_\pi$ 不改变策略梯度的期望：

$$\mathbb{E}_{S\sim\eta, A\sim\pi}\big[\nabla_\theta \ln \pi(A|S,\theta)\, \hat{q}(S,A,w^*)\big] = \mathbb{E}_{S\sim\eta, A\sim\pi}\big[\nabla_\theta \ln \pi(A|S,\theta)\, q_\pi(S,A)\big] = \nabla_\theta J(\theta).$$

证明只需两行。均方误差在 $w^*$ 处取驻点，故 $\mathbb{E}[(\hat{q} - q_\pi)\nabla_w\hat{q}] = 0$；代入条件（i）$\nabla_w\hat{q} = \nabla_\theta\ln\pi$，即得 $\mathbb{E}[\nabla_\theta\ln\pi\, \hat{q}] = \mathbb{E}[\nabla_\theta\ln\pi\, q_\pi]$。此外，$\hat{q}$ 中可以任意叠加只依赖状态的项（基线 $b(s)$），因为基线恒等式保证其梯度贡献为零。相容 critic 的一般形态因此是 $\hat{q}(s,a,w) = (\nabla_\theta \ln \pi(a|s,\theta))^\top w + b(s)$：动作相关部分必须沿策略梯度的方向，状态相关部分则完全自由。这个条件的直觉是：critic 不必精确估计 $q_\pi$ 的全部，只需要把"策略梯度方向上的分量"估计正确——误差若落在梯度正交的方向上，对策略更新毫无影响。这解释了为什么实践中结构化 critic（如状态价值加线性修正项）往往与全量估计同样有效。

### 10.5.2 例：softmax 策略下兼容性的数值验证

把兼容性条件落到一个可手算的例子。考虑 10.1 节的单状态两动作问题，但改用一维参数化的 logistic 形式：$\pi(a_1|\theta) = \sigma(\theta) = \frac{1}{1+e^{-\theta}}$，取 $\theta$ 使 $\pi_1 = 0.6$、$\pi_2 = 0.4$（这等价于把二维 softmax 参数 $\theta_2$ 固定为零）。对数策略梯度为 $\nabla_\theta \ln \pi(a_1) = 1 - \pi_1 = 0.4$，$\nabla_\theta \ln \pi(a_2) = -\pi_1 = -0.6$。设真实动作价值 $q_\pi(a_1) = 1.0$，$q_\pi(a_2) = 0.2$。构造兼容 critic $\hat{q}(a,w) = w \cdot \nabla_\theta \ln \pi(a|\theta)$，即 $\hat{q}(a_1) = 0.4w$，$\hat{q}(a_2) = -0.6w$。第一步，求 $w^*$：最小化 $\mathbb{E}[(\hat{q} - q_\pi)^2] = 0.6(0.4w - 1)^2 + 0.4(-0.6w - 0.2)^2$，令导数为零得 $0.48w - 0.384 = 0$，故 $w^* = 0.8$。第二步，验证梯度不变：用真实价值，$\nabla_\theta J(\theta) = 0.6 \times 0.4 \times 1.0 + 0.4 \times (-0.6) \times 0.2 = 0.24 - 0.048 = 0.192$；用兼容 critic，$\mathbb{E}[\nabla_\theta\ln\pi\, \hat{q}] = 0.6 \times 0.4 \times (0.4 \times 0.8) + 0.4 \times (-0.6) \times (-0.6 \times 0.8) = 0.0768 + 0.1152 = 0.192$。两者完全相等。注意 $\hat{q}$ 与 $q_\pi$ 逐点相差很大（$0.32$ 对 $1.0$，$-0.48$ 对 $0.2$），但梯度方向的替代却无偏——这正是兼容性条件的威力：它保证"够用即可"，critic 只需在梯度方向上准确。

### 10.5.3 自然梯度、信赖域与 PPO

普通策略梯度 $\nabla_\theta J(\theta)$ 有一个隐蔽的缺陷：它依赖参数化方式。对参数做可逆变换 $\theta' = M\theta$（如把 $\theta$ 乘以常数），梯度向量与步长语义随之改变，同一策略的优化轨迹却不同——这叫参数化敏感。自然梯度（natural gradient）消除这一缺陷：用 Fisher 信息矩阵（Fisher information matrix）$F(\theta) = \mathbb{E}_{S\sim\eta, A\sim\pi}\big[\nabla_\theta \ln \pi(A|S,\theta)\, \nabla_\theta \ln \pi(A|S,\theta)^\top\big]$ 度量"策略分布空间"中的曲率，定义自然梯度 $\tilde{\nabla}_\theta J(\theta) = F(\theta)^{-1} \nabla_\theta J(\theta)$。之所以曲率由 $F$ 刻画，是因为两个参数化策略之间的 KL 散度满足二阶展开 $\mathrm{KL}(\pi(\cdot|s,\theta) \| \pi(\cdot|s,\theta + \Delta\theta)) \approx \frac{1}{2} \Delta\theta^\top F \Delta\theta$——$F$ 告诉你"参数挪动一小步，分布实际改变了多少"。自然梯度是在分布空间（KL 度量下）的最速上升方向，因此任何可逆重参数化都给出相同的更新方向，这就是参数化不变性。直觉上，自然梯度对"敏感"的参数方向（$F$ 大，分布随参数变化剧烈）自动走小步，对"迟钝"的方向走大步，从而在不同参数方向之间保持分布层面的均匀步幅。

仍以 10.5.2 的 logistic 策略为例：$F = \mathbb{E}[(\nabla_\theta\ln\pi)^2] = 0.6 \times 0.4^2 + 0.4 \times (-0.6)^2 = 0.24 = \pi_1\pi_2$，自然梯度 $\tilde{\nabla}J = 0.192 / 0.24 = 0.8$。有趣的是，这正是兼容 critic 的最优权重 $w^*$——这不是巧合。由 MSE 驻点条件 $\mathbb{E}[(\hat{q} - q_\pi)\nabla_w\hat{q}] = 0$ 代入兼容结构，可得 $F w^* = \nabla_\theta J(\theta)$，即 $w^* = F^{-1}\nabla_\theta J(\theta)$：兼容 critic 的最优参数恰好就是自然梯度。于是 10.5.1 与 10.5.2 的两个理论工具统一为一枚硬币的两面——"设计兼容 critic"自动把普通梯度更新变成自然梯度更新。若读者回看二维 softmax 参数化：$F = 0.24\begin{pmatrix}1 & -1 \\ -1 & 1\end{pmatrix}$ 是奇异矩阵（秩一），因为 softmax 参数存在冗余（只差 $\theta_1 - \theta_2$ 起作用），实践中固定一个参数或用伪逆处理即可——这本身也印证了"参数化冗余"正是普通梯度敏感的根源之一。

自然梯度直接催生了信赖域方法。TRPO（Trust Region Policy Optimization，Schulman 等，2015）把每次更新限制在信赖域内：最大化 $\mathbb{E}[\rho_t \hat{A}_t]$，约束 $\mathbb{E}[\mathrm{KL}(\pi_{\text{old}} \| \pi_{\text{new}})] \le \delta$；对目标做一阶近似、对约束做二阶近似（KL 的曲率正是 $F$），解出的更新方向就是自然梯度，再配合线搜索保证单调改进。PPO（Proximal Policy Optimization，Schulman 等，2017）则用裁剪代理目标 $\mathbb{E}\big[\min(\rho_t \hat{A}_t,\, \mathrm{clip}(\rho_t, 1-\varepsilon, 1+\varepsilon)\hat{A}_t)\big]$ 以纯一阶方式近似信赖域约束，实现简单、训练稳定，成为 ChatGPT 等大模型 RLHF 训练的标配算法。回顾本章脉络：兼容性条件回答"什么近似是安全的"，自然梯度回答"朝哪个方向走最稳"，TRPO/PPO 把这两个理论工具工程化——AC 家族由此从"两模块协作"成长为现代深度强化学习的主流框架。下一节，我们对全章做一次系统的回顾。
