## [Part1] 10.2 最简 AC：QAC 算法

### 10.2.1 从随机梯度形式到 QAC 的算法结构

第9章给出的策略梯度随机梯度形式为 $\theta_{t+1} = \theta_t + \alpha \nabla_\theta \ln \pi(a_t|s_t,\theta_t)\, q_t(s_t,a_t)$。这个式子本身就是一个微型的 actor-critic：它直接更新策略参数 $\theta$（policy-based 的 actor），但需要一个动作价值估计 $q_t(s_t,a_t)$（value-based 的信号）。$q_t$ 从哪来，决定了算法家族的分支：用蒙特卡洛回报 $G_t$，得到第9章的 REINFORCE；用时序差分估计，就得到本章的 Actor-Critic。最简的 Q actor-critic（QAC）把这一分工落实为两条更新式：critic 用 Sarsa 估计动作价值函数 $\hat{q}(s,a,w)$，actor 用策略梯度更新策略参数 $\theta$。critic 的更新为

$$w_{t+1} = w_t + \alpha_w\big[r_{t+1} + \gamma \hat{q}(s_{t+1}, a_{t+1}, w_t) - \hat{q}(s_t, a_t, w_t)\big]\nabla_w \hat{q}(s_t, a_t, w_t),$$

actor 的更新为

$$\theta_{t+1} = \theta_t + \alpha_\theta \nabla_\theta \ln \pi(a_t|s_t,\theta_t)\, \hat{q}(s_t, a_t, w_t).$$

对比 REINFORCE，QAC 的唯一结构性改动是把 MC 回报换成 TD 目标：critic 用"一步真实奖励加上后继动作价值的当前估计"构成学习目标，这与第7章 Sarsa 的更新式完全同构，只是价值函数换成了第8章的参数化形式 $\hat{q}(s,a,w)$。由于 TD 目标只包含一步转移的随机性，QAC 的更新是增量的——每与环境交互一步就更新一次，不需要等待回合结束，方差也显著低于 MC 回报。

为什么说这是"最简"的 AC？因为两个模块都没有引入任何额外机制：critic 就是普通的 Sarsa（第7章），actor 就是普通的策略梯度（第9章），两者的耦合方式就是"critic 的输出作为 actor 的加权系数"。算法流程如下：初始化策略参数 $\theta$ 与价值参数 $w$；循环执行——由当前策略 $\pi(\cdot|s_t,\theta)$ 采样动作 $a_t$，环境返回 $r_{t+1}, s_{t+1}$，再按同一策略采样后继动作 $a_{t+1}$；先用 Sarsa 式更新 $w$（注意 TD 误差 $\delta_t = r_{t+1} + \gamma\hat{q}(s_{t+1},a_{t+1},w_t) - \hat{q}(s_t,a_t,w_t)$ 的定义），再用策略梯度更新 $\theta$。两个学习率 $\alpha_w$ 与 $\alpha_\theta$ 可以不同，这一自由度并非可有可无：critic 必须学得比 actor 快，为 actor 提供相对稳定的"标尺"，这就是两时间尺度（two-timescale）思想。直观地说，如果批评家的标准天天变，演员就不知道该朝哪个方向改进；如果批评家的标准先稳定下来，演员才能安心沿标尺攀登。我们在 10.2.3 节会看到这一直觉的收敛性表述。

### 10.2.2 例：单状态双动作的 QAC 一步演算

让我们用 10.1.3 节的单状态两动作问题，完整演算 QAC 的一步更新，读者可以逐式核对。设只有一个状态 $s$，两个动作 $a_1, a_2$；策略为 softmax 形式，参数 $\theta = (0.5, 0.3)$，于是 $\pi(a_1) \approx 0.5498$，$\pi(a_2) \approx 0.4502$。critic 用线性近似 $\hat{q}(s,a,w) = \phi(s,a)^\top w$，其中 $\phi(s,a_1) = (1,0)$，$\phi(s,a_2) = (0,1)$，当前参数 $w = (0.6, 0.4)$，即 $\hat{q}(s,a_1) = 0.6$，$\hat{q}(s,a_2) = 0.4$。假设第 $t$ 步的交互为：$a_t = a_1$，即时奖励 $r_{t+1} = 1$，后继状态 $s_{t+1} = s$（自环），后继动作按策略采样得到 $a_{t+1} = a_2$。取折扣率 $\gamma = 0.9$，学习率 $\alpha_w = 0.5$，$\alpha_\theta = 0.1$。

第一步，critic 更新。TD 目标为 $r_{t+1} + \gamma\hat{q}(s_{t+1}, a_{t+1}, w_t) = 1 + 0.9 \times 0.4 = 1.36$，TD 误差 $\delta_t = 1.36 - 0.6 = 0.76$。由于 $\nabla_w \hat{q}(s_t, a_t, w) = \phi(s, a_1) = (1, 0)$，只有 $w_1$ 被更新：$w_1 \leftarrow 0.6 + 0.5 \times 0.76 \times 1 = 0.98$，$w_2$ 保持 $0.4$。更新后 $\hat{q}(s,a_1) = 0.98$，$\hat{q}(s,a_2) = 0.4$——被访问的 $(s,a_1)$ 的价值上调，因为这一经验给出的 TD 目标（1.36）高于旧估计（0.6）。第二步，actor 更新。对 softmax 策略，$\nabla_\theta \ln \pi(a_1) = (\pi_2, -\pi_2) = (0.4502, -0.4502)$，加权信号取更新后的 $\hat{q}(s, a_1, w_{t+1}) = 0.98$，于是 $\theta_1 \leftarrow 0.5 + 0.1 \times 0.4502 \times 0.98 = 0.5441$，$\theta_2 \leftarrow 0.3 - 0.1 \times 0.4502 \times 0.98 = 0.2559$。新策略下 $\pi(a_1) = \frac{e^{0.5441}}{e^{0.5441}+e^{0.2559}} \approx \frac{1.7234}{3.0150} \approx 0.5716$，即 $\pi(a_1)$ 从 $0.5498$ 上升到 $0.5716$。

结果解读：critic 评出"动作 $a_1$ 在当前经验下的价值（0.98）高于动作 $a_2$（0.4）"，actor 便提高了 $a_1$ 的概率。注意更新只沿被采样动作的对数梯度方向进行：$\theta_1$ 增加而 $\theta_2$ 减少，softmax 的归一化保证 $\pi(a_1) + \pi(a_2) = 1$。如果下一次采样到 $a_2$，则 $\theta_2$ 会上升而 $\theta_1$ 下降，两个动作"竞争"概率，最终胜出的是长期被 critic 评价更高的那个。读者可以自行验证：若第 $t$ 步改为 $a_t = a_2$（其余不变），TD 目标为 $1 + 0.9 \times 0.6 = 1.54$，$\delta_t = 1.54 - 0.4 = 1.14$，$w_2 \leftarrow 0.4 + 0.5 \times 1.14 \times 1 = 0.97$；actor 沿 $\nabla_\theta \ln \pi(a_2) = (-0.5498, 0.5498)$ 更新，$\theta_1 \leftarrow 0.5 - 0.1 \times 0.5498 \times 0.97 = 0.4467$，$\theta_2 \leftarrow 0.3 + 0.1 \times 0.5498 \times 0.97 = 0.3533$，$\pi(a_1)$ 降至 $\frac{e^{0.4467}}{e^{0.4467}+e^{0.3533}} \approx 0.5233$。这个对称的对照演算可以帮助读者确认更新方向与符号。

### 10.2.3 QAC 的收敛性与不足

QAC 是两条耦合的随机逼近（SA）迭代：critic 在学 $q_\pi$（以当前策略为目标的贝尔曼方程），actor 在爬 $J(\theta)$ 的山。这类"快慢耦合"系统的收敛性由两时间尺度随机逼近理论刻画：若学习率满足 $\alpha_w / \alpha_\theta \to 0$（即 critic 的步长相对更小、跑得更快），在温和条件下 $\theta$ 收敛到 $J(\theta)$ 的一个局部最优，且 $w$ 收敛到相应策略下的价值估计。直觉是：critic 在快时间尺度上"追上"当前策略的价值，actor 在慢时间尺度上看到的是近似稳定的标尺，于是梯度上升不至于追着移动的目标跑。实践中这一条件落实为学习率的配对选择，例如 $\alpha_w = 0.1$、$\alpha_\theta = 0.01$，并观察两条参数的曲线是否呈现"价值先稳、策略后动"的两层节奏。如果违反两时间尺度（如 $\alpha_w \ll \alpha_\theta$），常见病征是策略参数剧烈震荡甚至发散——actor 在评价标准尚未建立时就大步前进。

与 REINFORCE 相比，QAC 的改进与代价都很清晰。改进在于：增量更新（每步一更，天然支持持续任务与在线学习）、低方差（TD 目标只有一步随机性）、无需回合结束（免去 MC 的等待）。代价在于引入双重偏差：自举偏差（TD 目标含当前估计）与函数近似偏差（$\hat{q}$ 未必等于 $q_\pi$），因此 QAC 收敛到的是局部最优而非全局最优。但 QAC 还有一个更隐蔽的缺点，正是它"直接用 $\hat{q}$ 加权"造成的：考虑 10.2.2 的自环状态，若该状态长期价值很高（比如 $\hat{q}(s,a_1) = \hat{q}(s,a_2) = 10$），则无论采取哪个动作，QAC 都会把被采样动作的概率大幅推高——状态本身"值钱"，却被误读为"这个动作好"；两个动作的价值相等，概率却在随机游走，白白增加方差。问题根源在于 $\hat{q}$ 中包含了状态价值的"整体水平"，而策略梯度真正关心的是动作之间的相对优劣。这引出了下一节的修正：把基线 $v_\pi(s)$ 从 $q_\pi(s,a)$ 中减去，用优势函数加权——A2C。同时，QAC 的 critic 要为每个动作维护一个价值估计（参数随动作空间线性增长），而 A2C 的 critic 只需估计状态价值 $v(s)$ 一个函数，参数更省。我们由此进入 10.3 节。
