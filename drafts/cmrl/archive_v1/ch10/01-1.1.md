## [Part1] 10.1 Actor-Critic 结构

### 10.1.1 从 REINFORCE 的方差问题说起

让我们回到第9章策略梯度方法的起点。策略梯度定理指出，指标 $J(\theta)$ 的梯度可以写成期望形式 $\nabla_\theta J(\theta) = \mathbb{E}_{S\sim\eta, A\sim\pi}[\nabla_\theta \ln \pi(A|S,\theta)\, q_\pi(S,A)]$，其中 $\eta$ 是策略 $\pi_\theta$ 下的状态稳态分布。既然期望无法解析计算，就用随机梯度逼近：$\theta_{t+1} = \theta_t + \alpha \nabla_\theta \ln \pi(a_t|s_t,\theta_t)\, q_t(s_t,a_t)$，其中 $q_t(s_t,a_t)$ 是动作价值 $q_\pi(s_t,a_t)$ 的一个估计。第9章的 REINFORCE 取 $q_t = G_t$，即蒙特卡洛回报。这样做的优点是无偏——$G_t$ 是回报的真实采样，其期望正是 $q_\pi$；但缺点同样突出：方差大。原因在于 $G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots$ 是一整条轨迹上所有转移随机性与奖励随机性的叠加，两条看似相似的轨迹，回报可能天差地别。如果读者在同一状态 $s$、同一动作 $a$ 下重复两次实验，一次回报 $+10$、一次回报 $-8$，那么以 $G_t$ 为权重的梯度更新正负颠倒，策略参数来回摆动，需要海量回合才能把期望"平均"出来。这就是 REINFORCE 样本效率低下的根源，也是本章一切改进的出发点。

针对高方差，有两类自然的手术式修正。第一类是减基线（baseline）：在加权信号中减去一个只依赖状态、与动作无关的函数 $b(s)$。之所以可行，是因为对任意状态 $s$，恒有 $\mathbb{E}_{A\sim\pi}[\nabla_\theta \ln \pi(A|s,\theta)\, b(s)] = b(s)\nabla_\theta \sum_a \pi(a|s,\theta) = b(s)\nabla_\theta 1 = 0$，即状态相关基线对期望梯度毫无贡献；而选择合适的 $b(s)$（例如接近 $v_\pi(s)$）能显著压低更新步长的方差。第二类修正更根本：不再用完整回报 $G_t$ 估计 $q_\pi$，而是用一个正在学习的价值函数 $\hat{q}(s,a,w)$ 提供估计——这就是 critic 的登场。与 $G_t$ 相比，TD 式的单步目标 $r_{t+1} + \gamma \hat{q}(s_{t+1},a_{t+1},w)$ 只包含一步转移的随机性，方差小得多；代价是引入了自举与函数近似带来的偏差。把这两类修正放进一个算法框架，就得到了 Actor-Critic：actor 负责策略更新，critic 负责价值估计。一句话概括：AC 是"用一个正在学习的价值函数（critic），给策略梯度（actor）提供低方差的加权信号"。

### 10.1.2 Actor 与 Critic：结构视角与算法视角

理解 AC 有两种互补的视角。结构视角：AC 是同时包含基于策略与基于价值两种方法的结构。actor 指策略更新步——之所以叫 actor，是因为动作由遵循该策略产生，策略是"表演者"；critic 指价值更新步——之所以叫 critic，是因为它通过评估相应价值来"评价"actor 的表现，价值函数是"评论家"。两个模块并行演进：critic 用第7章的 TD 更新与第8章的函数近似学习价值，actor 用第9章的策略梯度更新策略参数，critic 的输出 $\hat{q}(s_t,a_t,w_t)$（或由它派生的信号）作为 actor 更新时的加权系数。算法视角：AC 仍是策略梯度算法——策略梯度定理没有变，actor 的更新式 $\theta_{t+1} = \theta_t + \alpha_\theta \nabla_\theta \ln \pi(a_t|s_t,\theta_t)\, \hat{q}(s_t,a_t,w_t)$ 与第9章的随机梯度形式完全同构，只是把定理中的 $q_\pi$ 换成了 critic 的估计。因此，AC 不是对策略梯度的否定，而是对其中"如何得到 $q_t$"这一环节的升级：REINFORCE 用 MC，AC 用 TD。表10-1 对比了本章将出现的家族成员：REINFORCE 无 critic、用 MC 回报、同策略；QAC 用 Sarsa 估计 $q$、同策略；A2C 用 TD 误差估计优势、同策略；异策略 AC 用重要性采样修正、异策略；A3C 是 A2C 的异步并行版本。

为什么这样的分工是合理的？直觉在于"actor 想干什么、critic 说值不值"的分离：actor 只负责把高价值的动作概率推高、把低价值的动作概率压低，它不必关心价值从何而来；critic 只负责如实评估价值，它不必关心策略如何更新。这种分离带来了工程上的巨大便利——价值网络与策略网络可以分别设计、分别调参、分别替换。在中医药场景中，这一分工有天然的对应：医者（actor）负责辨证开方，规者与药者（critic）负责质控评估与处方审核，决策者与评价者分离正是现代医疗质量管理的核心思想。值得注意的是，两个模块的学习速度必须协调：critic 若学得太慢，actor 就拿着过时的评价盲目表演；critic 若学得太快而 actor 跟不上，则评价标准自身也在漂移。实践中用两个不同的学习率 $\alpha_w$ 与 $\alpha_\theta$ 控制，这就是"两时间尺度"（two-timescale）的思想，我们将在 10.2 节详细讨论。

### 10.1.3 例：基线为何不改变梯度方向

让我们用一个可手算的例子把 10.1.1 的基线恒等式落到实处。考虑只有一个状态 $s$、两个动作 $a_1, a_2$ 的最简问题，策略为 softmax 形式 $\pi(a_1|\theta) = \frac{e^{\theta_1}}{e^{\theta_1} + e^{\theta_2}}$，参数取 $\theta = (0.5, 0.3)$。则 $\pi(a_1) = \frac{e^{0.5}}{e^{0.5}+e^{0.3}} \approx 0.5498$，$\pi(a_2) \approx 0.4502$。对 softmax 求对数策略梯度：$\nabla_\theta \ln \pi(a_1) = (\pi_2, -\pi_2) = (0.4502, -0.4502)$，$\nabla_\theta \ln \pi(a_2) = (-\pi_1, \pi_1) = (-0.5498, 0.5498)$。第一，验证 $\mathbb{E}_{A\sim\pi}[\nabla_\theta \ln \pi(A|\theta)] = 0$：$\pi_1(0.4502, -0.4502) + \pi_2(-0.5498, 0.5498) = (0.2475, -0.2475) + (-0.2475, 0.2475) = (0,0)$，精确成立——这是"对数策略梯度关于策略的期望为零"的一般性质，也是基线恒等式的根源。第二，设真实动作价值 $q_\pi(a_1) = 1.0$，$q_\pi(a_2) = 0.2$，取基线 $b = 0.5$，验证减基线前后期望梯度不变。不减基线时：$\sum_a \pi(a)\nabla_\theta\ln\pi(a)\, q_\pi(a) = 0.5498 \times (0.4502, -0.4502) \times 1.0 + 0.4502 \times (-0.5498, 0.5498) \times 0.2 = (0.2475, -0.2475) + (-0.0495, 0.0495) = (0.1980, -0.1980)$。减基线 $0.5$ 后，$a_1$ 项的加权系数变为 $1.0 - 0.5 = 0.5$，$a_2$ 项变为 $0.2 - 0.5 = -0.3$，于是：$a_1$ 项 $= 0.5498 \times (0.4502, -0.4502) \times 0.5 = (0.1238, -0.1238)$，$a_2$ 项 $= 0.4502 \times (-0.5498, 0.5498) \times (-0.3) = (+0.0742, -0.0742)$，合计 $(0.1238 + 0.0742, -0.1238 - 0.0742) = (0.1980, -0.1980)$，与不减基线时完全相同。恒等式成立的关键，正在于第一点验证过的 $\sum_a \pi(a)\nabla_\theta\ln\pi(a) = 0$——它保证基线项 $b\sum_a \pi(a)\nabla_\theta\ln\pi(a)$ 恒为零，与 $b$ 取什么值无关。

这个例子说明三个要点。其一，基线不影响期望梯度，这是"减基线合法"的数学根据；其二，若基线取 $b = \mathbb{E}[q_\pi|s] = v_\pi(s)$，加权信号恰好变成优势函数 $q_\pi - v_\pi$，方差显著下降——我们将在 10.3 节看到，这正是 A2C 比 QAC 更稳的根源；其三，手算这类式子时正负号极易出错（例如把 $a_2$ 项的 $(0.2 - 0.5) = -0.3$ 与 $\nabla_\theta\ln\pi(a_2) = (-0.5498, 0.5498)$ 相乘时，负负得正容易写反），建议读者养成"先分别验证 $\sum_a\pi(a)\nabla_\theta\ln\pi(a) = 0$，再比较减基线前后结果"的核对习惯。本例同时把基线思想与第9章的策略梯度定理衔接起来：REINFORCE 与 AC 家族都可以在加权信号中自由叠加状态相关基线，这为后面 QAC 到 A2C 的升级埋下伏笔。下一节，我们把 critic 具体化为 Sarsa 估计器，得到最简的 AC 算法 QAC。
