## [Part1] 10.6 本章小结

### 10.6.1 方法谱系与核心公式回顾

本章是全书方法的汇合：AC = 策略梯度（第9章）+ TD 价值估计（第7章）+ 函数近似（第8章）+ 随机逼近理论（第6章）。四章的知识在 AC 框架中各司其职：critic 的价值更新是第7章 TD 思想在第8章函数近似下的实现，actor 的策略更新是第9章策略梯度定理的随机梯度形式，两者作为耦合的 SA 迭代由第6章的理论保证收敛。整个 AC 家族构成一条清晰的演化链：REINFORCE（无 critic，MC 回报，同策略）→ QAC（Sarsa critic，$\hat{q}$ 加权，同策略）→ A2C（TD 误差作优势，$\hat{v}$ 单函数，同策略）→ A3C（异步并行 + n 步优势）/ 异策略 AC（重要性采样修正）→ 现代成员 DPG、SAC（异策略 + 回放）与 TRPO、PPO（信赖域 / 裁剪目标）。表10-2 浓缩了家族的谱系：算法、critic 学什么、加权信号、同/异策略、一句话贡献——读者应能不看原文复述这张表。

核心公式构成"一页纸工具箱"。策略梯度定理：$\nabla_\theta J(\theta) = \mathbb{E}[\nabla_\theta\ln\pi(A|S,\theta)\, q_\pi(S,A)]$；基线恒等式：$\mathbb{E}_{A\sim\pi}[\nabla_\theta\ln\pi(A|s,\theta)\, b(s)] = 0$（减基线合法，10.1.3 节数值验证）；QAC 双更新：critic 用 Sarsa 误差 $\delta_t = r_{t+1} + \gamma\hat{q}(s_{t+1},a_{t+1},w) - \hat{q}(s_t,a_t,w)$，actor 用 $\hat{q}$ 加权（10.2 节一步演算）；A2C 双更新：一个 $\delta_t = r_{t+1} + \gamma\hat{v}(s_{t+1}) - \hat{v}(s_t)$ 同时服务 critic 与 actor，且 $\mathbb{E}[\delta_t|s_t,a_t] = A_\pi(s_t,a_t)$（10.3 节）；异策略：$\rho_t = \pi(a_t|s_t,\theta)/\beta(a_t|s_t)$ 修正分布偏差（10.4.3 节比率计算）；自然梯度：$\tilde{\nabla}J = F^{-1}\nabla J$，$F = \mathbb{E}[\nabla\ln\pi\,\nabla\ln\pi^\top]$；兼容性：$\nabla_w\hat{q} = \nabla_\theta\ln\pi$ 且 $w^*$ 为 MSE 最优时梯度无偏，且 $F w^* = \nabla J$（10.5 节数值验证）。

### 10.6.2 直觉、理论保证与实践要点

理解 AC 有一条贯穿始终的直觉："actor 想干什么 vs critic 说值不值"。actor 是"想做事的"——它倾向于提高它认为好的动作概率；critic 是"把关的"——它提供客观评价，防止 actor 盲目自信。二者分离的工程价值在于：决策机制与评价机制可以独立演进、独立调参、独立审计。本章的每个算法变体都对应"评价信号"的一次升级：QAC 用 $\hat{q}$（绝对水平，含状态价值噪声），A2C 用 $\delta_t$（相对平均水平，自动扣除基线），异策略 AC 用 $\rho_t\delta_t$ 或 $\rho_t\hat{q}$（再修正分布偏差）。评价信号的纯度决定了学习效率——这是读者应当带走的第一个判断框架。第二个框架是"三个问题"：每一步更新在更新什么参数（$\theta$ 还是 $w$）、用什么信号加权（$\hat{q}$、$\delta_t$、$\rho_t$ 还是优势）、凭什么保证不偏（基线恒等式、两时间尺度、兼容性条件、自然梯度）。把这套问题应用到任何一个新出现的 AC 变体，都能迅速定位它的设计动机。

理论保证与实践要点需要配套掌握。收敛性：QAC/A2C 是两时间尺度耦合 SA 迭代，$\alpha_w/\alpha_\theta \to 0$ 时收敛到 $J(\theta)$ 的局部最优，实践中 $\alpha_w$ 取 $\alpha_\theta$ 的 5~10 倍；梯度正确性：兼容性条件刻画"什么近似不破坏策略梯度"，兼容 critic 的最优权重就是自然梯度；参数化不变性：自然梯度在分布空间最速上升，消除参数化敏感；异策略一致性：重要性采样在有界比率下给出无偏修正，方差问题用裁剪控制。工程要点提醒：奖励需归一化（跨任务尺度一致）、硬约束需显式处理（如审方拒绝直接屏蔽对应动作）、熵正则防止策略过早确定化、双 critic（如 SAC 的 min 操作与平台的规者+药者）同时约束效率与安全。风险清单同样重要：局部最优（梯度方法的固有局限）、函数近似发散（非线性近似的老问题，回放/目标网络缓解）、奖励黑客（评价信号被钻空子——见 10.8.5 的医院管理讨论）。

### 10.6.3 全书衔接与延伸

向后看，本章与前面各章环环相扣。第6章的随机逼近是 actor 与 critic 两条迭代共同的数学底座；第7章的 TD 家族为 critic 提供了学习目标（Sarsa 对应 QAC，TD(0) 对应 A2C，n-step 对应 A3C 的优势估计）；第8章的函数近似把 critic 从表格升级为参数化函数，DQN 三技巧（经验回放、目标网络、双 Q）在 AC 家族中各有对应（回放对应异策略 AC 的数据复用，目标网络进入 SAC，双 Q 进入 SAC 的 min 操作）；第9章的策略梯度定理是 actor 的根基。向前看，AC 框架是现代深度强化学习的主干：Atari 游戏、围棋、机器人控制，乃至 ChatGPT 的 RLHF 训练（PPO 是事实标准），都可以理解为"策略网络（actor）+ 价值网络（critic）+ 工程技巧"的组合。本教材从第6章到第10章的算法主线——SA → TD → 函数近似 → 策略梯度 → Actor-Critic——至此完成闭环：AC 是这条主线在算法层面的集大成者。

回到中医药智能的语境，本章的映射将在 10.7、10.8 节充分展开，这里先埋下三个锚点。其一，actor-critic 分离恰是平台六者架构的算法画像：医者 Agent 是 actor，规者与药者 Agent 构成双 critic——决策者与评价者分离，正是医疗质量管理的制度设计。其二，优势函数的"相对平均水平"语义对应临床的"疗效优于基线"评价：效不更方、效改其方、效如桴鼓分别对应优势为零、为负、为正。其三，两时间尺度的思想对应平台 CI/CD 闭环：评价标准（质控指标）先稳定，策略（医者行为）再演进。带着这三个锚点，读者将看到：AC 不只是抽象算法，它精确刻画了"辨证开方 + 质控反馈"这一古老而现代的医疗决策循环。

延伸阅读建议如下（均为本章思想的原始出处）。A3C 的原始论文（Mnih 等，2016，《Asynchronous Methods for Deep Reinforcement Learning》）完整呈现了异步并行、n 步优势与共享参数更新的工程细节，并报告了单机多线程在 Atari 上的加速效果；TRPO 论文（Schulman 等，2015）给出自然梯度与信赖域约束的完整推导，其中"KL 散度作为策略距离度量"的视角是理解参数化不变性的最佳读物；PPO 论文（Schulman 等，2017）说明裁剪目标如何以纯一阶方式近似信赖域，并给出各变体的消融实验；SAC 论文（Haarnoja 等，2018）演示异策略 AC + 最大熵 + 双 Q critic 在连续控制上的稳定性。读者可在阅读这些文献时，用本章的"三个问题"框架（更新什么、用什么信号、凭什么保证）逐一解剖：每个算法都只是对这三个问题的一次新回答。此外，第6章的两时间尺度随机逼近理论（Borkar 的《Stochastic Approximation: A Dynamical Systems Viewpoint》）为 QAC/A2C 的收敛性提供了严格表述，感兴趣且数学基础扎实的读者可以深入。最后提醒：本章的全部算法思想（而非具体网络结构）都可以用 numpy 在 tcmP 平台接口上复现——10.7 节的实训正是把这些公式变成可运行代码的最后一公里。
