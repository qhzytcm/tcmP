## [Part1] 10.4 A3C 与异策略 AC

### 10.4.1 A3C：异步并行与 n 步优势

A2C 是单学习者算法：一个策略、一个 critic、一条数据流，逐回合串行推进。串行采样有两个瓶颈：其一是速度——环境交互本身耗时，样本吞吐受制于单条流水线；其二是相关性——相邻经验高度相关，更新步之间的信息增量有限。A3C（Asynchronous Advantage Actor-Critic，异步优势 Actor-Critic，Mnih 等，2016）用并行打破这两个瓶颈：启动多个 worker，每个 worker 拥有自己的环境副本与参数副本，各自独立地执行 A2C 式的"交互—更新"循环，然后异步地把计算好的梯度推送给全局共享参数（或周期性地从全局拉取最新参数）。多个 worker 在互不相同的轨迹上采样，经验天然去相关——这一作用替代了经验回放（第8章 DQN 三技巧之一），却不需要额外的缓冲区与采样逻辑。每个 worker 内部仍是同策略的 A2C，因此 A3C 整体的数学基础与 10.3 节完全一致，只是把单机循环复制成了并行版本。

A3C 与单机 A2C 的另一个差别在于优势估计的步数。A3C 的每个 worker 先与环境交互 $n$ 步，再用 n 步回报估计优势：

$$\hat{A}_t = \sum_{k=0}^{n-1} \gamma^k r_{t+k+1} + \gamma^n \hat{v}(s_{t+n}) - \hat{v}(s_t).$$

这里 $n = 1$ 退化为 10.3 节的单步 TD 误差，$n \to \infty$ 趋于蒙特卡洛式的完整回报；$n$ 越大偏差越小但方差越大，反之亦然——这正是第7章 n-step Sarsa 的"偏差-方差旋钮"在 AC 中的再现，实践中常取 $n = 5$ 左右。工程上，worker 的循环是：拉取全局参数 $\theta, w$ → 交互 $n$ 步 → 计算 $\hat{A}_t$ 与梯度 → 异步推送累积梯度 → 重复。异步带来一个理论上的不完美：worker 推送梯度时全局参数可能已被其他 worker 更新，梯度是"陈旧"的。实践发现异步仍能工作良好，因为陈旧性引入了额外噪声，而随机梯度本身对噪声有鲁棒性；不过后续研究发现，同步版本 A2C（各 worker 算完梯度后取平均再更新）在多数任务上更稳定，代价是等待最慢的 worker。理解这一权衡比记住结论更重要：并行化提升的是吞吐与去相关，代价是更新的协调复杂度。

### 10.4.2 异策略 AC 与重要性采样

A2C 与 A3C 都是同策略（on-policy）算法：行为策略（生成数据的策略）就是目标策略（被优化的策略），数据用完即弃。异策略（off-policy）AC 把两者解耦：行为策略 $\beta$ 负责收集数据，目标策略 $\pi_\theta$ 负责被优化。解耦带来三个现实收益：其一，数据复用——历史数据可以反复用于更新，样本效率大幅提升，经验回放成为可能；其二，向他人学习——可以用专家、前辈或异构 Agent 产生的数据优化自己的策略，例如学生医者从名老中医的医案日志中学习（10.8 节详述）；其三，探索解耦——行为策略可以保持高探索（如较大熵），而目标策略稳步逼近最优。然而解耦有代价：当数据由 $\beta$ 生成时，期望 $\mathbb{E}_{A\sim\beta}[\nabla_\theta\ln\pi_\theta(A|s)\, q_\pi(s,A)]$ 一般不再等于策略梯度 $\nabla_\theta J(\theta)$——分布不对，梯度的期望就被污染。

修正工具是重要性采样（importance sampling）。定义重要性比率

$$\rho_t = \frac{\pi(a_t|s_t,\theta)}{\beta(a_t|s_t)},$$

它度量"该经验在目标策略下出现的概率相对于行为策略下出现的概率"。异策略策略梯度定理给出：$\nabla_\theta J(\theta) = \mathbb{E}_{S\sim\eta_\beta, A\sim\beta}\big[\rho(S,A)\, \nabla_\theta \ln \pi(A|S,\theta)\, q_\pi(S,A)\big]$，其中 $\eta_\beta$ 是行为策略下的状态稳态分布。严格推导要求状态分布仍按目标策略的稳态分布 $\eta_\pi$，异策略下只能用 $\eta_\beta$ 近似，这是实践中普遍接受的标准处理；直观上，重要性比率只修正了"动作"维度，状态维度的偏差由近似承担。于是异策略 AC 的 actor 更新为 $\theta_{t+1} = \theta_t + \alpha_\theta \rho_t \nabla_\theta \ln \pi(a_t|s_t,\theta_t)\, \hat{q}(s_t,a_t,w_t)$，critic 相应使用加权后的 TD 更新（如加权 Sarsa 或 Q-learning 式），保证价值估计与目标策略一致。

### 10.4.3 例：重要性比率的计算与异策略 AC 的现代发展

让我们用一个微小的例子体会 $\rho_t$ 的语义。设行为策略为均匀分布 $\beta(a_1) = \beta(a_2) = 0.5$，目标策略 $\pi(a_1) = 0.8$，$\pi(a_2) = 0.2$。若某步实际采取 $a_2$，则 $\rho_t = \frac{0.2}{0.5} = 0.4 < 1$——这个经验在目标策略下不那么"典型"，其梯度贡献被调低；若实际采取 $a_1$，则 $\rho_t = \frac{0.8}{0.5} = 1.6 > 1$——这个经验在目标策略下更典型，贡献被调高。直观地说，异策略学习是"用借来的数据学自己的策略"：$\beta$ 采的数据要按"$\pi$ 与 $\beta$ 的相符程度"重新加权，$\rho_t$ 就是那把尺子。风险在于 $\rho_t$ 可能很大（当 $\beta$ 远小于 $\pi$ 时），造成方差爆炸；工程上的对策是裁剪（clip）比率或采用自归一化估计——这些技术直接演化成 10.5.3 节 PPO 的裁剪目标与 V-trace 等算法。

把上例续成一笔完整的数值演算，读者可以体会修正的幅度。沿用 10.2 节的 softmax 策略设定（$\theta = (0.5, 0.3)$，$\pi(a_1) = 0.5498$，$\pi(a_2) = 0.4502$），但假设数据由均匀行为策略 $\beta$ 产生，且第 $t$ 步实际采取 $a_2$、critic 给出 $\hat{q}(s,a_2) = 0.4$、$\alpha_\theta = 0.1$。先算未修正的策略梯度更新：$\Delta\theta = 0.1 \times \nabla_\theta\ln\pi(a_2) \times 0.4 = 0.1 \times (-0.5498, 0.5498) \times 0.4 = (-0.0220, 0.0220)$。再算重要性比率 $\rho_t = \frac{0.4502}{0.5} = 0.9004$，修正后的更新为 $\Delta\theta = \rho_t \times (-0.0220, 0.0220) = (-0.0198, 0.0198)$——因为目标策略给 $a_2$ 的概率（0.4502）低于行为策略（0.5），该经验被轻微调低。若目标策略给 $a_2$ 的概率远高于 $\beta$（例如 $\pi(a_2) = 0.9$），则 $\rho_t = 1.8$，同样的经验贡献被放大近一倍——这正是"数据代表性"的定量刻画。注意这里 $\rho_t$ 用的是当前目标策略 $\pi_\theta$ 的概率，而 $\pi_\theta$ 随训练在变，因此 $\rho_t$ 每一步都要重新计算；这也提醒读者，重要性采样修正的是"动作分布"，状态分布层面的偏差依然存在，需要靠近似承担。

异策略 AC 是现代深度强化学习的重要谱系。SAC（Soft Actor-Critic）把最大熵纳入目标：$J(\theta) = \mathbb{E}\big[\sum_t \gamma^t (r_t + \alpha H(\pi(\cdot|s_t)))\big]$，熵项鼓励探索与鲁棒性，配合双 Q critic（取两个估计的较小者）抑制最大化偏差，并用目标网络稳定 TD 目标——这些技巧正是第8章 DQN 三技巧在 AC 框架中的对应物。DDPG（深度确定性策略梯度）则用确定性策略配合回放，直接处理连续动作空间。回到本章主线：A3C 回答"如何更快"（并行），异策略 AC 回答"如何更省"（复用），两者都以 10.3 节的 A2C 为内核。但无论是同策略的异步更新，还是异策略的重要性修正，都还缺少一个理论层面的保证：用近似的 critic 替代 $q_\pi$，究竟会不会把梯度方向带偏？普通梯度又为什么对参数化方式敏感？这两个问题由 10.5 节的兼容性条件与自然梯度回答。
