# 2.1 为什么回报重要（Why the Return Is Important）

## [Part1] 2.1 为什么回报重要

### 2.1.1 三个策略，一条直觉

我们回到第1章的网格世界。在一个 3×3 的九宫格中，机器人占据一个格子，可以向上、向右、向下、向左移动，也可以原地不动；白色格子可以进入，橙色格子是禁区，右下角有一个目标格子。现在假定机器人从状态 s1（左上角）出发，我们的任务是评价三个候选策略的优劣。第一个策略让机器人一路向右再向下，恰好绕过禁区，走一条最经济的路径到达目标，它从不靠近禁区；第二个策略让机器人从 s1 向右移动一步进入禁区，在禁区里受到惩罚后再继续前进；第三个策略在 s1 处掷一枚硬币：正面朝上就向右，背面朝上就向下——也就是说，它有 0.5 的概率进入禁区，0.5 的概率避开禁区。凭直觉，我们几乎不需要任何数学就能排出优劣：第一个策略最好，第二个策略最差，第三个策略居于两者之间。事实上，这正是人类在面对这类问题时自然而然的判断方式。但这里有一个严肃的问题：直觉可以被接受，却不能成为科学的依据。如果要编写程序让机器自动比较策略、自动改进策略，就必须把这句"第一个策略最好"翻译成一种可以用数字表达、可以机械计算的语言。本章的目的之一，就是完成这次翻译。

### 2.1.2 用折扣回报给直觉"编号"

数学上如何描述上述直觉？答案是折扣回报（discounted return）。设折扣率 γ ∈ (0,1)，并采用第1章的奖励设定：试图越出边界 r = −1，进入禁区 r = −1，到达目标 r = +1，其他移动 r = 0。现在依次计算三个策略从 s1 出发的回报。先看第一个策略：轨迹为 s1 → s3 → s4 → s4 → …，即从 s1 向下到 s3（奖励 0），再向右到 s4 目标（奖励 +1），此后一直停留在目标状态（每次停留获得 +1）。于是 return1 = 0 + γ·1 + γ²·1 + γ³·1 + … = γ/(1−γ)。再看第二个策略：轨迹为 s1 → s2 → s4 → s4 → …，即从 s1 向右一步进入禁区 s2（奖励 −1），随后到达目标 s4（奖励 +1），此后一直停留在目标。于是 return2 = −1 + γ·1 + γ²·1 + … = −1 + γ/(1−γ)。注意，两个策略的差别只在第一步：前者先向下拿到 0，后者先向右拿到 −1，之后完全一样，所以回报的差别恰好是第一步奖励之差，即 return1 − return2 = 1。这个"第一项决定差别"的现象并不是巧合，它正是折扣回报"把未来折算到现在"的体现。

### 2.1.3 随机策略的回报要取平均

第三个策略是随机的：在 s1 处，它以 0.5 的概率执行向右（进入禁区），以 0.5 的概率执行向下（避开禁区）。由于策略的随机性，从 s1 出发的轨迹不再唯一，而是两条轨迹各以 0.5 的概率出现。那么，第三条轨迹的回报应当如何定义？自然的做法是取期望：return3 = 0.5 × return1 + 0.5 × return2。代入前面两个结果，得到 return3 = 0.5 × γ/(1−γ) + 0.5 × (−1 + γ/(1−γ)) = −0.5 + γ/(1−γ)。于是我们得到三个数字：return1 = γ/(1−γ)，return2 = −1 + γ/(1−γ)，return3 = −0.5 + γ/(1−γ)。因为 γ/(1−γ) 对任何 γ ∈ (0,1) 都是正数，所以无论 γ 取什么值，都有 return1 > return3 > return2。直觉在这里得到了数学的确认：最好的策略回报最大，最差的策略回报最小，介于两者之间的策略回报也居中。这个简单的例子已经展示了回报的三个重要特征：第一，回报是一个数值，可以比较大小，从而可以排序；第二，回报是沿着整条轨迹累积的，而不是只看眼前一步；第三，当策略随机时，回报本身成为随机变量，我们需要借助期望来处理它——这三点将分别引向 2.2 节的状态价值与 2.3 节的贝尔曼方程。

### 2.1.4 决定动作的依据是总回报而非即时奖励

初学者此时常会提出一个问题：既然进入禁区会立即得到 −1 的惩罚，避开禁区的动作立即得到 0，为什么不直接比较即时奖励，选即时奖励最大的动作？答案是：即时奖励最大的动作，未必带来最大的总回报。让我们用一个极端一点的例子说明。假设机器人在 s1 有两个可选动作：a 立即获得 +1 但从此进入死路，以后每步只能拿到 0；b 立即获得 0，但会进入一条通往宝藏的通道，以后每步都能拿到 +1。只看即时奖励，a 优于 b；但计算总回报，b 的回报是 γ + γ² + … = γ/(1−γ)，而 a 的回报只是 1。当 γ 接近 1 时，γ/(1−γ) 远大于 1，b 明显优于 a。这个例子说明了一个贯穿全书的原则：强化学习的决策单位是整条轨迹，不是单个时刻。只看即时奖励的策略是短视的（myopic），它会被眼前的甜头迷惑，错失长远的收益。而折扣回报 γ 恰好提供了一个旋钮：γ 越小，未来奖励折算得越轻，策略越短视；γ 越大，未来奖励越被看重，策略越愿意"放长线钓大鱼"。2.4 节之后我们会看到，正是这个 γ 的存在，保证了贝尔曼方程的一系列良好性质。

### 2.1.5 从回报到期望：通向状态价值的桥梁

还有一个技术细节值得在这里说透。在上面的计算中，我们其实做了一件稍显"越界"的事：对第三个随机策略，我们说了"两条轨迹各以 0.5 概率出现"，然后取平均得到 return3。这个平均就是期望。然而细想之下，期望是对"同一个状态出发、多次重复实验"而言的：如果让机器人按第三个策略在 s1 出发一百次，大约五十次进入禁区、五十次避开禁区，这一百次回报的平均值会趋近 return3。但对于某一次具体的运行，我们看到的仍然只是其中一条轨迹的回报，而不是 0.5、0.5 的平均值。也就是说，在随机系统中，"从 s1 出发"本身并不能唯一确定回报——回报是一个随机变量。这带来一个根本性的麻烦：如果评价策略的指标自身是随机的，那么"策略 A 比策略 B 好"这句话在单次实验中可能不成立——这次 A 的回报高，下次可能反过来。为了得到一个确定性的、可重复的比较指标，我们必须把随机性平均掉，也就是把回报的期望作为评价指标。这个期望，就是下一节将要定义的状态价值。理解了"回报 → 期望 → 状态价值"这条逻辑链，你就理解了本章的第一块基石。

### 2.1.6 本节小结

本节通过网格世界中三个策略的比较，确立了三个观点。其一，回报是评价策略好坏的合理指标，而且直觉上的优劣可以被折扣回报的数值大小精确复现：return1 > return3 > return2。其二，评价策略必须看总回报而不是即时奖励，因为即时奖励最大的动作未必带来最大的总回报，折扣率 γ 调节着"短视"与"远视"的程度。其三，当策略或环境具有随机性时，回报成为随机变量，评价指标必须取期望——这正是下一节引入状态价值的动机。回到 tcmP 平台的语境，这三条结论可以立即翻译成临床语言：评价一位医师的诊疗方案，不能只看单次处方的即时反馈，而要看沿着整个病程累积的期望疗效；同样的道理，平台在评估"辨证→方剂"决策链时，应当以期望临床价值而不是单次病例的成败为准。这个思想将在 2.8 节展开。下一节，我们将把"回报的期望"定义为一个严格的数学对象——状态价值函数。

### 拓展思考：当 γ 趋于 1 时会发生什么

把 2.1.3 节的三个回报表达式对 γ 取极限：当 γ → 1 时，return1 = γ/(1−γ)、return2 = −1 + γ/(1−γ)、return3 = −0.5 + γ/(1−γ) 三者都趋于正无穷。这个极限现象意味深长：三个策略的回报都发散，彼此之间的差距 γ/(1−γ) − (−1 + γ/(1−γ)) = 1 虽然保持不变，但"比较大小"这件事本身变得没有意义——无穷大无法排序。换句话说，"回报能够区分策略"这一命题，依赖折扣的存在：没有折扣，几何级数不收敛，一切比较都失去数学基础。这个观察从极限的角度再次印证了 2.1.2 节的结论：折扣率不是锦上添花的修饰，而是"评价策略"这一任务得以成立的前提。它也为 2.5 节埋下伏笔——那里将看到，γ < 1 同时保证了贝尔曼方程解的存在性与唯一性，折扣在理论中扮演着地基的角色。
