# 2.5 贝尔曼方程的三个基本性质（Three Basic Properties of the Bellman Equation）

## [Part1] 2.5 贝尔曼方程的三个基本性质

### 2.5.1 三个性质的总体框架

2.4 节给出了贝尔曼方程的解析解 v = (I − γPπ)⁻¹rπ，但那一节的可逆性论证是"就事论事"的。本章需要更系统的结论：贝尔曼方程作为一类特殊的线性方程组，到底有哪些放之四海而皆准的性质？这些性质构成后续所有算法的理论基础。赵世钰老师把答案归纳为三个定理。定理2.1（存在性）：对任意策略 π 与任意 MDP，贝尔曼方程必有解。定理2.2（唯一性）：贝尔曼方程的解是唯一的，即状态价值函数 vπ 是良定义的。定理2.3（迭代收敛）：对任意初始估计 v0，迭代 vk+1 = rπ + γPπvk 生成的序列 {vk} 必然收敛到 vπ。三个定理合在一起，回答了关于状态价值的三类问题：它存不存在？是不是只有一个？如何把它算出来？前两个问题保证"状态价值"这个概念本身是站得住的，第三个问题为实际计算提供了路线图——而且这条路不需要求逆矩阵。

### 2.5.2 定理2.1 存在性：解一定存在

定理2.1 的存在性其实在 2.4.3 节已经证明过了：因为 ρ(γPπ) ≤ γ < 1，所以 I − γPπ 可逆，于是 v = (I − γPπ)⁻¹rπ 就是方程的解。这个证明的妙处在于，它只用到了矩阵谱理论的两条简单事实——随机矩阵谱半径不大于 1，以及数乘缩放谱半径——而完全不依赖 MDP 的具体结构。无论状态转移多么复杂、奖励设计多么刁钻，只要 γ ∈ (0,1)，解就存在。这里值得体会"折扣"的分量：如果 γ = 1 且系统含有吸收环（如例2.3 中一直停留在 s4 获得 +1），那么 (I − Pπ) 奇异，方程可能无解——直观上，无限长的 +1 序列求和发散。折扣率 γ 的引入本质上是对"无限未来"的一种正则化：它让几何级数收敛，让方程永远良定义。这也是为什么几乎所有的强化学习理论都要求 γ ∈ (0,1)：不是技术上的吹毛求疵，而是理论大厦的地基。

### 2.5.3 定理2.2 唯一性：解只有一个

存在性保证"至少有一个解"，唯一性保证"至多有一个解"。定理2.2 的证明思路如下：假设 v1 与 v2 都是方程的解，即 v1 = rπ + γPπv1 且 v2 = rπ + γPπv2，两式相减得 v1 − v2 = γPπ(v1 − v2)。记 δ = v1 − v2，则 δ = γPπδ。取无穷范数（最大值范数），利用范数的相容性：‖δ‖∞ = ‖γPπδ‖∞ ≤ γ‖Pπ‖∞‖δ‖∞。随机矩阵的行和范数为 1，即 ‖Pπ‖∞ = 1，因此 ‖δ‖∞ ≤ γ‖δ‖∞。因为 γ < 1，这个不等式只有在 ‖δ‖∞ = 0 时才能成立，故 δ = 0，v1 = v2。唯一性得证。这个证明是全书"收缩论证"（contraction argument）的第一次完整亮相：一个迭代映射把两个候选解的差距至少缩小 γ 倍，反复应用后差距只能趋于零。收缩论证在 2.6 节之后的课程中会反复出现（第3章对贝尔曼最优方程的收缩性分析、第5章对时序差分算法的分析），建议读者现在就把它刻进记忆：γ < 1 是收缩的来源，范数不等式是收缩的形式化。

### 2.5.4 定理2.3 迭代收敛：不必求逆矩阵

存在性与唯一性回答了"解是什么"，定理2.3 回答"怎么算"。它说：任取初始值 v0（例如全零向量），按迭代格式 vk+1 = rπ + γPπvk 反复更新，所得序列 {vk} 收敛到 vπ。证明同样走收缩路线：vπ − vk+1 = (rπ + γPπvπ) − (rπ + γPπvk) = γPπ(vπ − vk)，于是 ‖vπ − vk+1‖∞ ≤ γ‖vπ − vk‖∞ ≤ … ≤ γ^(k+1)‖vπ − v0‖∞。因为 γ^(k+1) → 0，误差以几何速率收缩到零，收敛性得证，而且收敛速率是线性的、速率为 γ。这个定理把 2.4 节"求逆矩阵"的方案替换成了"反复迭代"的方案：每次迭代只做一次矩阵乘向量乘法，复杂度 O(n²)，且不需要任何求逆运算。当 n 很大时，两者有天壤之别——求逆 O(n³) 且需要存储 n² 的矩阵，迭代 O(n²) 且可以稀疏实现。更重要的是，迭代方案只需要"能计算 rπ + γPπv"的能力，不需要显式知道 Pπ 的解析形式——这个看似不起眼的放松，正是第5章以后无模型算法的伏笔：到时候连 Pπ 都不给，只给采样，但迭代的思想原封不动地保留下来。

### 2.5.5 例2.4：迭代过程的数值演示

例2.4 对例2.3 的四状态模型演示定理2.3 的迭代。已知 γ = 0.9，rπ = [0,1,1,1]ᵀ，Pπ 如例2.3 所示，精确解 vπ = [9,10,10,10]ᵀ。取初始值 v0 = [0,0,0,0]ᵀ，进行迭代 vk+1 = rπ + γPπvk。第一步：v1 = [0,1,1,1]ᵀ + 0.9×Pπ×[0,0,0,0]ᵀ = [0,1,1,1]ᵀ。第二步：Pπv1 = [1,1,1,1]ᵀ（从每个状态出发的下一状态分别是 s2, s4, s4, s4，取 v1 对应分量均为 1），v2 = [0,1,1,1]ᵀ + 0.9×[1,1,1,1]ᵀ = [0.9, 1.9, 1.9, 1.9]ᵀ。第三步：Pπv2 = [1.9, 1.9, 1.9, 1.9]ᵀ，v3 = [1.71, 2.71, 2.71, 2.71]ᵀ。继续迭代：v4 = [2.439, 3.439, 3.439, 3.439]ᵀ，v5 = [3.0951, 4.0951, 4.0951, 4.0951]ᵀ。可以看到四个分量以相同速率逼近各自的极限 9 与 10，且每步把差距乘以约 0.9，与定理2.3 的误差界吻合。读者可自行验证：迭代 20 步后，v20 与精确解的前几位小数已完全一致。这个例子直观地展示了"迭代逼近"与"直接求逆"殊途同归，也预告了第4章价值迭代算法的雏形：把"解方程"变成"迭代逼近"，代价是无穷多步但每步便宜，收益是避开求逆且只依赖可计算的矩阵向量积。

### 2.5.6 三个性质与全书的关系

把三个定理连起来读：存在性 + 唯一性 + 迭代收敛，构成了一个完整的"可解性"结论——贝尔曼方程不仅总是有唯一解，而且总能通过简单的迭代把它算出来。这组结论对后续章节的意义怎么强调都不过分。第一，它是第4章价值迭代、策略迭代算法的直接理论依据：算法不过是在迭代格式 vk+1 = rπ + γPπvk 或它的变体上叠加策略改进步骤。第二，它是第5章以后无模型算法的思想源头：真实环境中无法写出 Pπ，但可以采样——用采样得到的奖励与后继状态代替期望，迭代格式就变成了时序差分（TD）更新。第三，它揭示了折扣率 γ 的双重身份：在问题语义上，γ 调节短期与长期利益的权重；在数学结构上，γ 是保证收缩、保证收敛的参数。理解这层双重身份，是理解"强化学习为什么需要折扣"的关键。本书反复强调：贝尔曼方程是理解强化学习全部算法的一把钥匙——三性质定理就是这把钥匙最核心的齿纹。下一节，我们将引入与状态价值相伴的第二个基本量：动作价值。

### 收缩映射的一般表述

定理2.3 的证明可以提炼为一个更一般的模式：若映射 F 满足对任意 v, v′ 都有 ‖F(v) − F(v′)‖ ≤ γ‖v − v′‖ 且 γ < 1，则称 F 为收缩映射（contraction mapping）；收缩映射必有唯一不动点，且从任意初值出发的迭代都收敛到该不动点。贝尔曼方程右端定义的映射 v ↦ rπ + γPπv 正是这样的收缩映射，压缩比恰为 γ——这就是三个性质的共同根源。这个模式的价值在于可迁移：第3章的贝尔曼最优方程将定义另一个映射（含 max 运算），它同样是收缩映射，因而存在唯一不动点；第5章的时序差分算法可以看作"采样版"的收缩迭代；甚至策略梯度目标也可以纳入"找不动点"的语法。"找收缩映射的不动点"是贯穿强化学习全部算法的通用语法，本节的定理2.3 是读者第一次完整见到它的地方，务必把它与 2.5.3 节的证明一起消化。
