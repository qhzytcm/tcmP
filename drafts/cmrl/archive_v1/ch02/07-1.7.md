# 2.7 综合例题与数值演算：从回报到价值的完整链条

## [Part1] 2.7 综合例题与数值演算

### 2.7.1 例2.6 的设定：一个带随机性的小型 MDP

前面六节分别介绍了回报、状态价值、贝尔曼方程、矩阵求解、三性质与动作价值，本节把它们串成一个完整的工作流。例2.6 考虑一个含有随机转移的小型 MDP，含三个状态 s1, s2, s4。状态 s4 是目标吸收态：执行停留动作后仍回到 s4，每次奖励 +1。状态 s2 只有一个动作：转移到 s4，奖励 +1。状态 s1 有两个动作：动作 a1 确定转移到 s2，奖励 0；动作 a2 以 0.5 的概率转移到 s2、以 0.5 的概率直接转移到 s4，两种转移的即时奖励分别为 0 与 +1（直接到达目标）。策略 π 在 s1 处以 0.5 的概率选择 a1、0.5 的概率选择 a2，在 s2 与 s4 处选择唯一动作。折扣率 γ = 0.9。这个例子虽然只有三个状态，却同时包含吸收态、随机策略与随机转移三类要素，足以演示本章全部求解工具；而且它的随机性真正影响了结果——如果 a2 是确定转移到 s4，结论会完全不同，这一点在 2.7.5 节还会回头讨论。

### 2.7.2 第一步：自顶向下列贝尔曼方程

先处理目标吸收态。s4 的方程为 vπ(s4) = 1 + γ vπ(s4)，解得 vπ(s4) = 1/(1−γ) = 10。再处理 s2：vπ(s2) = 1 + γ vπ(s4) = 1 + 9 = 10。s2 与 s4 的价值相同并非巧合：从 s2 出发，一步到达目标（+1），此后每步 +1，与"从 s4 出发"相比只差一个 +1 的时相，而折扣后两者都收敛到 10。现在处理最关键的 s1。先算两个动作价值：qπ(s1, a1) = 0 + γ vπ(s2) = 0.9 × 10 = 9；qπ(s1, a2) = 0.5 × (0 + γ vπ(s2)) + 0.5 × (1 + γ vπ(s4)) = 0.5 × 9 + 0.5 × 10 = 9.5。注意第二个式子里，随机转移必须按概率 0.5、0.5 对两条支路分别取期望——这正是 2.6.4 节关系二中 Σs′ p(s′|s,a) vπ(s′) 的逐项展开。最后由关系一（状态价值是动作价值的加权平均）：vπ(s1) = 0.5 × qπ(s1, a1) + 0.5 × qπ(s1, a2) = 0.5 × 9 + 0.5 × 9.5 = 9.25。三个状态的价值全部求出：vπ = [9.25, 10, 10]ᵀ。整个求解过程只用了两个法则——自举（Gt = Rt+1 + γGt+1）与全期望（先对动作、再对转移取平均），这正是 2.3 节推导贝尔曼方程的全部原料。

### 2.7.3 第二步：用矩阵形式复核

为验证手算无误，把同一问题写成矩阵形式。先构造 Pπ 与 rπ。从 s1 出发：a1 以概率 1 到 s2，a2 以 0.5 到 s2、0.5 到 s4，策略各取一半，故 Pπ 的第一行为 [0, 0.75, 0.25]（按状态顺序 s1, s2, s4）；s2 行 [0, 0, 1]；s4 行 [0, 0, 1]。即时奖励向量：rπ(s1) = 0.5 × 0 + 0.5 × (0.5 × 0 + 0.5 × 1) = 0.25，rπ(s2) = 1，rπ(s4) = 1。于是解 (I − 0.9Pπ)v = rπ：I − 0.9Pπ = [[1, −0.675, −0.225],[0, 1, −0.9],[0, 0, 0.1]]。从最后一个方程 0.1v4 = 1 得 v4 = 10；第二个方程 v2 − 0.9v4 = 1 得 v2 = 10；第一个方程 v1 − 0.675×10 − 0.225×10 = 0.25 得 v1 = 9.25。结果与 2.7.2 节完全一致：v = [9.25, 10, 10]ᵀ。这个复核过程展示了元素形式与矩阵形式的一致性：两种写法只是同一组线性方程的不同排版，解必然相同。也提醒读者一个容易犯的错：写 Pπ 时务必先约定状态顺序，再把"从 i 到 j 的概率"放在第 i 行第 j 列——顺序一乱，矩阵就失去意义。

### 2.7.4 第三步：用迭代法验证三性质定理

再换第三种方法：不用求逆，按定理2.3 的迭代格式 vk+1 = rπ + γPπvk 从 v0 = [0,0,0]ᵀ 出发迭代。v1 = rπ + 0.9 × Pπ × [0,0,0]ᵀ = [0.25, 1, 1]ᵀ。Pπv1 = [0.75×1 + 0.25×1, 1, 1]ᵀ = [1, 1, 1]ᵀ，故 v2 = [0.25, 1, 1]ᵀ + 0.9×[1,1,1]ᵀ = [1.15, 1.9, 1.9]ᵀ。Pπv2 = [0.75×1.9 + 0.25×1.9, 1.9, 1.9]ᵀ = [1.9, 1.9, 1.9]ᵀ，故 v3 = [0.25 + 1.71, 2.71, 2.71]ᵀ = [1.96, 2.71, 2.71]ᵀ。继续迭代得到 v4 = [2.689, 3.439, 3.439]ᵀ，v5 = [3.3451, 4.0951, 4.0951]ᵀ。观察三个分量的误差：vπ(s1) − v5(s1) = 9.25 − 3.3451 = 5.9049，恰好等于 0.9⁵ × 10；vπ(s2) − v5(s2) = 10 − 4.0951 = 5.9049，同样等于 0.9⁵ × 10。误差以几何速率 γ = 0.9 收缩，与定理2.3 的误差界 ‖vπ − vk‖∞ ≤ γ^k‖vπ − v0‖∞ 精确吻合（这里 ‖vπ − v0‖∞ = 10）。迭代 20 步后，v20 与精确解在小数点后六位完全一致。三种方法——逐状态方程、矩阵求逆、迭代逼近——得到同一个答案，这本身就是对贝尔曼方程三性质的一次实证。

### 2.7.5 第四步：动作价值与改进方向

最后回到动作维度，看看本例对"策略改进"说了什么。2.7.2 节已经算出 qπ(s1, a1) = 9、qπ(s1, a2) = 9.5。由于 qπ(s1, a2) > vπ(s1) = 9.25 > qπ(s1, a1)，动作 a2 的价值高于当前策略在 s1 的平均水平。这意味着：如果策略把 s1 处的概率分配改为"以概率 1 选择 a2"，状态价值将变为 v′(s1) = qπ(s1, a2) = 9.5，严格大于原来的 9.25——策略得到了改进。反过来，如果把概率改为"以概率 1 选择 a1"，v′(s1) = 9 < 9.25，策略会变差。这个简单的比较揭示了一个贯穿全书的原则：动作价值给出了"每个动作的价值刻度"，策略改进就是"把概率向高价值动作倾斜"；而"vπ(s) ≤ maxa qπ(s,a)"这个不等式正是改进永远可行的数学保证。同时注意，本例中 a2 的优势完全来自它有 0.5 的概率"抄近路"直接到达目标——如果 a2 改为确定转移到 s2（奖励 0），则 q(s1,a2) = 9，与 a1 相同，改进空间消失。这说明：动作价值的差异源自即时奖励、转移概率与后继价值的共同作用，只看其中任何一项都会误判。

### 2.7.6 综合例题的启示与第3章衔接

例2.6 虽然只有三个状态，却完整走过了本章的全部技术路线：由自举与全期望列出贝尔曼方程，由矩阵形式复核，由迭代法实证三性质，由动作价值读出改进方向。把这四步浓缩成一句话：评估（算价值）→ 验证（对模型）→ 迭代（求数值）→ 改进（比动作），这就是强化学习中"策略评价"的标准工作流，也是第3章"策略改进"的入场券。第3章将把"把概率向高价值动作倾斜"这个朴素思想推到极致：如果每个状态都选择动作价值最大的动作，得到的贪婪策略（greedy policy）是否就是最优策略？最优策略存在吗？如何高效求出？回答这些问题的数学工具——最优状态价值、贝尔曼最优方程、收缩映射——全部建立在本章的 vπ、qπ 与贝尔曼方程之上。因此，在进入第3章之前，请务必确保自己能独立完成例2.6 的四个步骤；本节的数值也将作为 2.8 节平台实践（用真实病证数据构造 MDP 并求解）的对照基准——那里会看到，同样的数学结构，如何为辨证决策计算"临床价值"。
