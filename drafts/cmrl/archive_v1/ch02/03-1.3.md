# 2.3 贝尔曼方程的推导（Derivation of the Bellman Equation）

## [Part1] 2.3 贝尔曼方程的推导

### 2.3.1 问题设定：如何计算状态价值

2.2 节定义了状态价值 vπ(s) = E[Gt | St = s]，并指出它是评价策略的形式化指标。接下来的问题是：如何计算它？最笨的办法是按定义直接算期望：枚举所有可能的轨迹、计算每条轨迹的回报、按概率加权求和。这在理论上总是可行的，但在实践中几乎不可行——轨迹的数量随步数呈指数增长，一个只有九个状态的网格世界，三歩以内的轨迹就已经数以千计，更不用说真实应用中的海量状态。我们需要一种更聪明的办法。仔细观察状态价值的定义会发现一个关键的"耦合"现象：vπ(s) 中的回报 Gt 是从状态 s 出发、跨越多步累积得到的，而跨越多步必然要经过中间状态——中间状态的价值也是 vπ 的一部分。也就是说，一个状态的价值依赖于其他状态的价值。如果这种依赖关系可以被写成显式的方程，我们就能把"枚举轨迹"转化为"解方程"：用一组代数方程把全体状态价值同时确定下来。本节的核心任务，就是推导出这组方程——贝尔曼方程（Bellman equation）。

### 2.3.2 关键一步：自举（Bootstrap）

推导的起点是回报的递归结构。把折扣回报拆开来看：Gt = Rt+1 + γRt+2 + γ²Rt+3 + γ³Rt+4 + … = Rt+1 + γ(Rt+2 + γRt+3 + γ²Rt+4 + …)。注意括号中的部分不是别的，正是从下一时刻 t+1 开始的折扣回报 Gt+1 = Rt+2 + γRt+3 + γ²Rt+4 + …。因此我们得到一个极其简洁的恒等式：Gt = Rt+1 + γGt+1。这个恒等式被称为自举（bootstrap）结构——"自举"的意思是：一个量用"它自己下一时刻的版本"来表示。Gt 与 Gt+1 是同一类随机变量，只是时间起点不同，而马尔可夫性质保证了两者只相差一个时间索引。这个式子虽然只是一个代数变形，却是整个强化学习理论的支点之一：它把"无限长的折扣和"化成了"一项即时奖励 + 一个未来量"，把跨越多步的问题化成了"一步 + 剩余"的递归问题。所有后续的递推算法（价值迭代、策略迭代、时序差分）本质上都是在反复使用这个递归关系。

### 2.3.3 推导过程：对两端取条件期望

现在对恒等式 Gt = Rt+1 + γGt+1 两端在条件 St = s 下取期望。由状态价值的定义，左端就是 vπ(s)。右端是两项之和的期望，利用期望的线性性拆开：vπ(s) = E[Rt+1 | St = s] + γ E[Gt+1 | St = s]。第一项是即时奖励的条件期望。在状态 s 下，智能体按策略 π 以概率 π(a|s) 选择动作 a，环境以概率 p(r|s,a) 给出奖励 r，于是由全期望公式（law of total expectation）：E[Rt+1 | St = s] = Σa π(a|s) Σr p(r|s,a) r。第二项是未来回报的条件期望。注意 Gt+1 是在时刻 t+1 的回报，条件"St = s"只确定了当前状态；要计算 E[Gt+1 | St = s]，需要先对"下一步转移到哪个状态"取平均：E[Gt+1 | St = s] = Σa π(a|s) Σs′ p(s′|s,a) E[Gt+1 | St+1 = s′] = Σa π(a|s) Σs′ p(s′|s,a) vπ(s′)。这里用到了马尔可夫性质：给定 St+1 = s′，未来回报的期望与更早的历史无关，因此 E[Gt+1 | St+1 = s′] = vπ(s′)。把两项合并，就得到了贝尔曼方程。

### 2.3.4 贝尔曼方程：形式与含义

合并 2.3.3 节的两项，得到贝尔曼方程的标准形式：vπ(s) = Σa π(a|s) [Σr p(r|s,a) r + γ Σs′ p(s′|s,a) vπ(s′)]，对一切 s ∈ S 成立。这个方程值得逐字解读。方括号内有两部分：Σr p(r|s,a) r 是采取动作 a 的期望即时奖励，γ Σs′ p(s′|s,a) vπ(s′) 是转移到各后继状态后未来价值的期望折扣和。两者合起来，就是"在状态 s 采取动作 a"这一步的期望价值；再按策略 π(a|s) 对动作加权平均，就得到状态 s 的价值。方程传达的核心思想是：从一个状态出发的回报，取决于从其他状态出发的回报——状态价值相互耦合，构成一个关于 vπ 的方程组，有多少个状态就有多少个方程。这个"耦合"正是强化学习与单步决策问题的根本区别：单步问题只需要比较即时奖励，多步问题则必须同时解开所有状态之间的依赖。另外请注意，贝尔曼方程是线性的：vπ 只以一次幂出现，没有 vπ² 或 vπvπ′ 之类的项。线性意味着它可以写成矩阵方程、可以用线性代数工具处理——这将在 2.4 节展开。

### 2.3.5 例题：由贝尔曼方程重算例2.1

例2.2 用贝尔曼方程重解例2.1：γ = 0.9，求"第一个策略"（避开禁区）在 s1、s3、s4 的状态价值。解：该策略是确定性的，每个状态只有一个动作。先写 s4 的方程：s4 是目标态，执行"停留"动作后仍回到 s4，奖励 +1，即 vπ(s4) = 1 + γ vπ(s4)，解得 vπ(s4) = 1/(1−γ) = 10。再写 s3 的方程：s3 向右到达 s4，奖励 0，即 vπ(s3) = 0 + γ vπ(s4) = 9。最后写 s1 的方程：s1 向下到达 s3，奖励 0，即 vπ(s1) = 0 + γ vπ(s3) = 8.1。等等——8.1？例2.1 算出的 vπ(s1) 明明是 9。哪里出了问题？请读者暂停阅读，回头核对轨迹：第一个策略从 s1 出发的轨迹是 s1 → s3 → s4 → s4 → …，其中 s1 → s3 的奖励是 0，s3 → s4 的奖励是 +1（到达目标），并非 0！问题出在奖励设定上：在本书的网格世界约定中，"到达目标"与"停留在目标"都给出 +1。因此 s3 的方程应为 vπ(s3) = 1 + γ vπ(s4) = 1 + 9 = 10，进而 vπ(s1) = 0 + γ×10 = 9。两种方法结果一致。这个"看似矛盾"的插曲恰恰是学习贝尔曼方程最有价值的一课：方程迫使你把每一步的奖励写清楚，任何含糊都会在联立求解时暴露出来。

### 2.3.6 本节小结

本节完成了本章最关键的一步推导：由自举恒等式 Gt = Rt+1 + γGt+1 出发，对两端取条件期望，利用全期望公式与马尔可夫性质，得到贝尔曼方程 vπ(s) = Σa π(a|s)[Σr p(r|s,a) r + γ Σs′ p(s′|s,a) vπ(s′)]。这条推导链的每一步都值得背诵：自举给出递归结构，全期望公式处理随机性，马尔可夫性质切断历史依赖。贝尔曼方程的价值在于把"枚举轨迹"的指数级难题转化为"解线性方程组"的多项式级问题。在 tcmP 平台语境中，贝尔曼方程的自举结构对应着辨证的递归本质：一个症状组合的期望疗效，等于当下处理的效果加上后续状态（转归、并发症）价值的折扣和——辨证不是一次性的静态判断，而是沿着病程递归展开的动态评估。下一节，我们将把贝尔曼方程写成矩阵形式，并给出它的解析解。

### 为什么线性如此重要

贝尔曼方程中 vπ 只以一次幂出现，这是"线性"的严格含义：方程可以写成 v = rπ + γPπv 这样的线性方程组。线性带来两个直接的好处。其一，可求解：线性代数为线性方程组准备了成熟的工具——矩阵求逆、迭代法、谱分析，2.4 节的解析解与 2.5 节的收敛定理全部建立在线性之上。其二，可分析：线性方程的任意两个解之差仍满足齐次方程，这个性质是 2.5 节唯一性证明的关键起点。对比之下，第3章的贝尔曼最优方程含有 max 运算，方程变成非线性的，求逆等线性工具全部失效，只能借助收缩映射理论另起炉灶。可以说，"线性 vs 非线性"是贯穿第2章与第3章的一条暗线：读懂这条暗线，就能预判哪些工具在什么时候能用、什么时候必须换工具，这是数学直觉的重要来源。
