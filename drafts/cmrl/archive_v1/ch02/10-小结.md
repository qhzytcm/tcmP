# 2.8.6 本章小结与习题（Chapter Summary and Exercises）

## [Part1] 2.8.6 章末小结

本章建立了"策略评价"的完整数学框架。核心知识点共六项：其一，回报（return）是评价策略的起点，折扣回报 Gt = Rt+1 + γRt+2 + γ²Rt+3 + … 使无限长轨迹的回报有限，γ 调节短期与长期的权衡；其二，状态价值（state value）vπ(s) = E[Gt | St = s] 把回报的期望作为评价指标，它依赖状态 s 与策略 π、不依赖时刻 t；其三，贝尔曼方程（Bellman equation）vπ(s) = Σa π(a|s)[Σr p(r|s,a) r + γ Σs′ p(s′|s,a) vπ(s′)] 由自举恒等式 Gt = Rt+1 + γGt+1 对两端取条件期望导出，揭示了状态价值相互耦合的方程组结构；其四，矩阵形式 v = rπ + γPπv 有解析解 v = (I − γPπ)⁻¹rπ，可逆性由谱半径论证保证；其五，三个基本性质——存在性（定理2.1）、唯一性（定理2.2）、迭代收敛（定理2.3），迭代 vk+1 = rπ + γPπvk 以速率 γ 收敛，是第4章价值迭代的雏形；其六，动作价值 qπ(s,a) = E[Gt | St = s, At = a] 与状态价值的关系 vπ(s) = Σa π(a|s)qπ(s,a)，是策略改进的关键工具。在 tcmP 平台上，这些概念对应为临床价值、辨证递归评估、方证对应量化与医圣成长路径。下一章将研究最优策略与贝尔曼最优方程。

## [Part1] 基础题（60%，回忆与理解）

1.（填空）状态价值定义为 vπ(s) = E[____ | St = s]。
答案：Gt（折扣回报）。

2.（选择）折扣回报中的折扣率 γ 满足（ ）。A. γ = 1  B. γ ∈ (0,1)  C. γ > 1  D. γ < 0
答案：B。

3.（填空）自举恒等式为 Gt = ____。
答案：Rt+1 + γGt+1。

4.（选择）矩阵形式贝尔曼方程 v = rπ + γPπv 的解析解为（ ）。A. v = Pπrπ  B. v = (I − γPπ)⁻¹rπ  C. v = γPπrπ  D. v = rπPπ
答案：B。

5.（选择）状态价值与动作价值的关系是（ ）。A. vπ(s) = Σa π(a|s)qπ(s,a)  B. vπ(s) = maxa qπ(s,a)  C. qπ(s,a) = Σs′ p(s′|s,a)vπ(s)  D. 两者无关
答案：A。

6.（判断）状态价值 vπ(s) 依赖于当前时刻 t。（ ）
答案：错误。由马尔可夫性质与平稳性，vπ(s) 不依赖 t。

## [Part1] 综合题（30%，应用与分析）

7.（简答）写出推导贝尔曼方程的三个关键步骤。
答案：① 自举：Gt = Rt+1 + γGt+1；② 对两端在 St = s 下取条件期望，左端为 vπ(s)，右端用期望线性性拆成即时奖励与未来回报两项；③ 用全期望公式展开：对动作按 π(a|s) 平均、对奖励按 p(r|s,a) 平均、对未来按 p(s′|s,a) 平均，并利用马尔可夫性质把 E[Gt+1 | St+1 = s′] 写为 vπ(s′)，合并得贝尔曼方程。

8.（计算）四状态 MDP：s1→s2（r=0）、s2→s4（r=+1）、s3→s4（r=+1）、s4→s4（r=+1），策略确定，γ=0.9。求 vπ(s1) 与 vπ(s4)。
答案：vπ(s4)=1+0.9vπ(s4) ⇒ vπ(s4)=10；vπ(s2)=1+0.9×10=10；vπ(s3)=10；vπ(s1)=0+0.9×10=9。即 v=[9,10,10,10]ᵀ。

9.（病案分析）失眠 DSU 中，症状组合"入睡困难+多梦+心悸"在路径 π 下先试归脾汤（B 级证据，r=0.7），转归为"症状缓解"状态（价值 9）；若误用银翘散（证型不匹配，r=0），转归为"心悸加重"状态（价值 4）。γ=0.9，分别计算两条路径在症状组合处的价值，并说明差异的临床含义。
答案：归脾汤路径价值 = 0.7 + 0.9×9 = 8.8；误用路径价值 = 0 + 0.9×4 = 3.6。差异（8.8 vs 3.6）来自即时奖励与后继价值双重差距，说明"方证对应"不仅影响当下疗效，还通过后继状态价值放大为长期疗效差异——这正是贝尔曼方程的自举结构在辨证中的体现。

## [Part1] 拓展题（10%，评价与创造）

10.（开放）在 tcmP 平台上，检索分数（如 /semantic-search 的 RRF 证据分）常被当作状态价值的近似。请从奖励设计、状态表示、候选集三个角度分析这种近似的误差来源，并设计一种改进方案。
参考答案要点：① 奖励设计：证据等级 A/B/C 的离散映射损失了疗效的连续信息，且未纳入负奖励（误治后果）；② 状态表示：bigram+TF-IDF 是词袋模型，丢失症状间关系（如"恶寒重+发热轻"的共现权重），与 MDP 状态语义存在偏差；③ 候选集：Top-K 截断使长尾病证的价值被系统性低估。改进方向：用 DSU 六段式结构化特征替代纯文本向量、引入误治负奖励、对检索候选做重排（rerank）或与矩阵求解结果做集成。评分标准：能指出两个以上误差来源（4 分），提出可行改进（4 分），分析严谨（2 分）。
