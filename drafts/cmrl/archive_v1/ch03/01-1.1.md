## [Part1] 1.1 策略改进的动机

### 1.1.1 一个策略改进的例子

强化学习的终极目标是寻找最优策略。在给出"最优"的严格定义之前，先用一个具体例子体会"策略改进"的含义——这是理解本章全部理论的最佳入口。回到贯穿全书的网格世界（图1-1）：智能体从状态s1出发，目标是到达目标状态s4；途中进入禁区会受罚，越出边界会被弹回，到达目标后每步获得奖励+1并停留在目标状态。考虑一个策略π，它在状态s1选择了动作a2（向右）。这个选择不好——向右会进入禁区，立即受到奖励-1并转移到s2。直觉告诉我们：在s1处应改为向下（a3）。这个直觉能否用数学实现？答案是肯定的，而且过程分三步：第一步，计算当前策略的状态价值；第二步，计算s1处各动作的动作价值；第三步，把策略更新为选择动作价值最大的动作。下面逐一展开。

第一步，计算当前策略π的状态价值。按π的转移规则：在s1执行a2，得奖励-1并转移到s2；在s2、s3执行策略动作，得奖励+1并转移到s4；在s4执行动作，得奖励+1并停留在s4（吸收态）。据此列出贝尔曼方程：vπ(s1) = −1 + γvπ(s2)，vπ(s2) = +1 + γvπ(s4)，vπ(s3) = +1 + γvπ(s4)，vπ(s4) = +1 + γvπ(s4)。取折扣率γ = 0.9。由最后一式解出 vπ(s4) = 1/(1−0.9) = 10；代回得 vπ(s2) = 1 + 0.9×10 = 10，vπ(s3) = 10；再代回第一式得 vπ(s1) = −1 + 0.9×10 = 8。于是当前策略的状态价值为 vπ(s1) = 8，vπ(s2) = vπ(s3) = vπ(s4) = 10。这个结果定量地说明了s1是"差"的位置：由于策略在s1的错误选择，s1的价值比相邻状态低了2——从s1出发，先要承受一步-1的惩罚，之后才走上正轨。

第二步，计算状态s1处各动作的动作价值。动作价值的定义来自第2章：qπ(s,a) = Σr p(r|s,a) r + γΣs′ p(s′|s,a) vπ(s′)，即"即时奖励的期望加上后继状态价值的折扣期望"。对s1的五个动作逐一计算。a1（向上）越出边界，得−1并弹回s1，故qπ(s1,a1) = −1 + γvπ(s1) = −1 + 0.9×8 = 6.2；a2（向右）进入禁区，得−1并转移到s2，故qπ(s1,a2) = −1 + γvπ(s2) = −1 + 0.9×10 = 8；a3（向下）转移到s3，得0，故qπ(s1,a3) = 0 + γvπ(s3) = 0 + 0.9×10 = 9；a4（向左）越界弹回，qπ(s1,a4) = −1 + γvπ(s1) = 6.2；a5（静止）留在s1得0，qπ(s1,a5) = 0 + γvπ(s1) = 7.2。五个动作价值依次为6.2、8、9、6.2、7.2，最大者是a3（向下），qπ(s1,a3) = 9。注意：动作a3的即时奖励是0，而a2的即时奖励是−1，a2反而更差——这再次印证第2章的结论：决策必须依据总回报（动作价值），而非即时奖励。

第三步，把策略在s1更新为选择a3：定义新策略π′，令π′(s1) = a3，其余状态的动作与原策略π相同。新策略是否真的更好？计算π′的状态价值。此时s1执行a3转移到s3、得0，故vπ′(s1) = 0 + γvπ′(s3)；而s3、s4的关系不变：vπ′(s3) = +1 + γvπ′(s4)，vπ′(s4) = +1 + γvπ′(s4)。由后两式得vπ′(s3) = vπ′(s4) = 10，于是vπ′(s1) = 0.9×10 = 9，比原策略的vπ(s1) = 8高出1，且其余状态的价值不变。改进成立。这个例子完整展示了策略改进的流程：用当前策略的价值，改进当前策略的动作；改进后的策略价值严格提升。它回答了本节开头的第一个问题——"如果现有策略不好，能否系统地改进它"——答案是肯定的，而且机制极其简单：评估，比较，择优。

### 1.1.2 从改进到最优：问题的提出

这个看似简单的例子揭示了三件值得反复咀嚼的事实。第一，"选择动作价值最大的动作"是策略改进的基本思想，它将成为后续几乎所有强化学习算法的核心机制：策略迭代、价值迭代、Q-learning、SARSA，无一不是围绕"用价值比较动作、按最大价值选动作"运转。第二，改进的每一步都有理论保证：新策略π′满足vπ′(s1) > vπ(s1)，其他状态价值不变，故改进严格有效——这回答了"选最大动作价值是否总能得到更好的策略"的第一个直觉层面。第三，也是最重要的，我们只改进了s1这一个状态；如果策略在多个状态都不好，逐个改进是否总能得到更好的策略？改进的极限——最优策略——是否一定存在？它长什么样？如何把它求出来？这四个问题正是本章后续各节的主题：1.2节给出最优状态价值与最优策略的严格定义，1.3节推导它们满足的贝尔曼最优方程，1.4节证明"贪婪策略即最优策略"，1.5节用收缩映射保证存在性、唯一性与迭代求解的收敛性。可以说，1.1节的这个小例子是整个第3章的种子，后续所有定理都在回答这个例子提出的追问。

## [Part2] 1.1 平台语境：策略改进与最优诊疗

在tcmP中医医院AI网络教育平台中，"策略改进"有直接的临床对应：医师的诊疗策略就是"辨证→方剂"的决策规则，最优策略就是最优诊疗方案。平台把医师成长建模为"医圣成长路径"：状态是医师当前的能力画像，从住院医师到学科带头人，对应的掌握病证数从500个增长到60000个；动作是每次诊疗决策（给出辨证结论、推荐方剂）与学习决策（选择进修课程）；奖励来自临床反馈（辨证正确得正奖励、误诊得负奖励）与考核结果。网格世界中"在s1把a2改为a3"的改进，对应临床上"在某症状组合下，把低效方剂调整为高效方剂"的决策修正。1.1节的三步法（评估当前价值→计算动作价值→按最大动作价值更新）正是平台中医者Agent改进自身诊疗策略的算法原型：先用真实病证数据评估当前诊疗路径的期望疗效，再比较各候选方剂的长期价值，最后把策略更新为价值最高的方案。平台的病证单元（DSU）为这套计算提供了结构化数据——症状组合即状态、方剂字段即动作、证据等级（A级=1.0，B级=0.7，C级=0.4）即奖励；数据源位于tcmP/kg/samples/目录下的dsu-samples-*.json，共103个以上真实病证单元。理解了这个映射，读者就拿到了把本章全部理论"翻译"到中医药场景的钥匙。
