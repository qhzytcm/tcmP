## [Part1] 本章小结与习题（60-30-10分层）

### 本章小结

本章围绕"寻找最优策略"建立完整理论。核心概念：v*(s) = maxπ vπ(s)、q*(s,a) = maxπ qπ(s,a)、最优策略π*（满足vπ*(s) = v*(s)对一切s）。核心方程：贝尔曼最优方程v*(s) = maxa [Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′)]，它与普通贝尔曼方程的唯一差别是把"对策略求期望"换成"对动作取max"。核心定理：定理3.1（贪婪策略最优）——每状态选动作价值最大的动作即最优，证明引擎是不等式"加权平均 ≤ 最大值"；定理3.2（存在唯一）——BOE有唯一解，最优价值存在且唯一；定理3.3（收缩映射）——T(v) = maxπ (rπ + γPπ v)是压缩比为γ的收缩映射，迭代vk+1 = T(vk)几何收敛到v*，这是第4章价值迭代的理论基础。平台映射：v* = 症状组合的最优期望疗效，BOE的max = 辨证引擎的argmax择优，收缩迭代 = 平台边积累病案边更新价值，γ = 近期疗效与远期预后的权衡。一句话记住本章：存在（定理3.2）、形态（定理3.1）、计算（定理3.3）。

### 基础巩固（60%）

1. 填空题：最优状态价值的定义是 v*(s) = ____。
2. 单选题：贝尔曼最优方程与普通贝尔曼方程的本质区别是（ ）。A. 前者含折扣率γ，后者不含；B. 前者把对策略的期望改为对动作的max；C. 前者是线性方程，后者是非线性方程；D. 前者只适用于确定性问题。
3. 判断题：最优策略一定是唯一的。（ ）
4. 填空题：映射T(v) = maxπ (rπ + γPπ v)的压缩比是____。
5. 单选题：γ = 0.9时，价值迭代要使误差降到初值的1%，约需迭代（ ）。A. 5轮；B. 10轮；C. 44轮；D. 100轮。
6. 填空题：从最优价值v*提取最优策略的公式是 π*(s) = ____。

### 综合应用（30%）

7. 计算题：沿用本章例1.2的网格世界（γ = 0.9），写出状态s1的贝尔曼最优方程，并求解v*(s1)。
8. 简答题：叙述定理3.1（贪婪策略最优），并说明证明中"加权平均 ≤ 最大值"这一不等式的作用。
9. 应用题：tcmP平台中，症状组合s = "恶寒重、发热轻、无汗、脉浮紧"，候选方剂及证据等级：麻黄汤A级、桂枝汤B级、桑菊饮C级、银翘散C级。设γ = 0.8、各候选方剂一次性治愈（后继价值0），计算动作价值并给出最优推荐。
