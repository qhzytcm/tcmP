## [Part1] 1.6 本章小结：三个基本问题的统一

### 1.6.1 知识要点：本章回答的三个基本问题

本章回答了强化学习中三个最基本的问题。问题一：最优策略是否存在？定理3.2的回答是肯定的：贝尔曼最优方程有解，最优状态价值存在且唯一，最优策略存在。问题二：最优策略长什么样？定理3.1（贪婪策略最优）的回答是：最优策略是贪婪策略——在每个状态选择使动作价值最大的动作；"贪婪即最优"是全书最重要的洞察之一，它把看似复杂的全局优化问题归结为每个状态的局部选择问题。问题三：如何求解最优策略？定理3.3（收缩映射）的回答是：映射T(v) = maxπ (rπ + γPπ v)是压缩比为γ的收缩映射，由不动点定理，迭代vk+1 = T(vk)从任意初值出发收敛到唯一不动点v*（即BOE的解）；从v*提取贪婪策略即得最优策略。三个定理环环相扣，构成"存在→形态→计算"的完整链条，也恰好对应本章1.5、1.4、1.7三节的核心内容。读者在复习时应当把这三个定理当作本章的地图：任何一个后续算法，都可以在这张地图上找到它的位置——它要么在回答"最优是什么"，要么在回答"最优怎么算"。

### 三定理的证明脉络

三个定理的证明脉络值得完整回顾一次，因为它们是全书"价值类算法收敛性"论证的模板。定理3.1的证明分三步：先立引理"加权平均 ≤ 最大值"——vπ(s) = Σa π(a|s) qπ(s,a) ≤ maxa qπ(s,a)；再逐状态归纳，利用贝尔曼方程展开把贪婪策略的价值与最优价值逐项对齐，得到vπ ≥ v*；最后由定义v* ≥ vπ，两端夹逼得vπ = v*。定理3.2的证明分两块：唯一性由收缩性免费得到——若两个不动点v1*、v2*同时存在，则‖v1* − v2*‖∞ = ‖T(v1*) − T(v2*)‖∞ ≤ γ‖v1* − v2*‖∞，γ < 1迫使二者相等；存在性由迭代收敛构造性给出——vk+1 = T(vk)收敛（定理3.3），极限即为不动点。定理3.3的证明只有一步关键不等式——max的Lipschitz性质：|maxa f(a) − maxa g(a)| ≤ maxa |f(a) − g(a)|，其余全靠概率归一性Σs′ p(s′|s,a) = 1与代数化简，最终得到压缩比恰为γ。读者若能把这三条证明脉络完整复述，就掌握了"最优性理论"的骨架：优化问题（定理3.1）→ 存在唯一（定理3.2）→ 算法收敛（定理3.3），三者通过收缩映射这一核心概念缝合。这一论证模板在第4章价值迭代、第5章Q-learning的收敛性分析中会被反复使用，值得现在就把它内化为自己的思维工具。

### 1.6.2 方法与示例：概念关系与求解路线

把第1至3章的概念串成一条链，可以画出本章的概念关系图：第1章给出MDP五元组(S, A, P, R, γ)与轨迹、回报；第2章定义状态价值vπ(s) = E[Gt | St = s]与动作价值qπ(s,a) = E[Gt | St = s, At = a]，并建立贝尔曼方程vπ = rπ + γPπ vπ；本章在第2章之上定义最优状态价值v*(s) = maxπ vπ(s)、最优动作价值q*(s,a) = maxπ qπ(s,a)，并建立BOE v* = T(v*)。全部关键关系式汇总如下：① vπ(s) = Σa π(a|s) qπ(s,a)——状态价值是动作价值的加权平均；② qπ(s,a) = Σr p(r|s,a) r + γΣs′ p(s′|s,a) vπ(s′)——动作价值是即时奖励加后继价值；③ v*(s) = maxa q*(s,a)——最优价值是最优动作价值的最大值；④ q*(s,a) = Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′)——最优动作价值的分解；⑤ v*(s) = maxa [Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′)]——BOE本身。建议读者把①至⑤抄写一遍并相互推导：从①和②推出③④⑤的每一步都只用本章的论证，推完一遍，本章就算真正掌握了。

方法层面，本章完成了从"评价策略"到"优化策略"的跃迁，留下两条求解最优策略的等价路线。路线一（策略迭代）：交替执行策略评估（解线性贝尔曼方程vπ = rπ + γPπ vπ）与策略改进（对qπ取argmax得到贪婪策略），1.4节的引理保证每轮改进价值单调不降，定理3.1保证改进到贪婪时即达最优；这是1.1节三步法的完整化。路线二（价值迭代）：直接迭代BOE，vk+1 = T(vk)，定理3.3保证收敛到v*，再从v*提取贪婪策略；这是1.7节将要落地的算法。两条路线的区别在于"评估"与"改进"是分开（策略迭代）还是融合（价值迭代），共同点是都以"贪婪提取"收尾。第4章将系统展开这两条路线；本章的三个定理是它们的全部理论依据，读者现在站的位置，正是全书算法大厦的地基。

### 1.6.3 易错点辨析与学习建议

把本章常见错误集中辨析，帮助读者在考试与实践中避免踩坑。易错点一：混淆"对动作取max"与"对策略取期望"——BOE是v*(s) = maxa […]，普通贝尔曼方程是vπ(s) = Σa π(a|s) […]，两者只差"max"与"加权平均"，但一个是非线性优化方程、一个是线性期望方程，性质完全不同。易错点二：忘记max不可分配——maxa [fa + γga] ≠ maxa fa + γmaxa ga，展开BOE时必须对同一动作a保持即时奖励项与后继转移项一致，1.3节例1.3中的逐项验证正是为了防止这种错误。易错点三：混淆v*与vπ的下标语义——v*不带策略下标，是所有策略价值的包络；vπ是具体策略的价值，逐分量满足vπ ≤ v*；把"vπ(s) ≥ v*(s)"当作可能情形是概念错误。易错点四：忽视γ ∈ (0,1)的前提——收缩性、存在性、收敛性全部依赖γ < 1；γ = 1时T不是收缩映射，BOE可能无解，不动点论证全部失效。易错点五：默认最优策略唯一——最优策略可以不唯一（多个动作并列最大时任选其一），但最优价值函数v*唯一（定理3.2）；1.4节例1.4已演示。易错点六：把"贪婪"理解为"只看即时奖励"——贪婪的对象是动作价值qπ（已经包含未来回报），不是即时奖励r；1.1节中qπ(s1,a3) = 9最大而即时奖励0，正说明贪婪于动作价值不等于贪婪于即时奖励。

学习建议有三条。第一，动手复现：把1.1节与1.2节的网格世界数值例子在纸上完整演算一遍（列方程、解方程、取max、验证BOE），再在Python中用字典实现价值迭代的前几轮，体会"手算"与"迭代"的一致性。第二，串联提问：学完本章后，用五个问题自测——为什么γ必须小于1？为什么迭代必然收敛？为什么最大值能打败所有加权平均？最优策略不唯一时价值还唯一吗？贪婪策略的"贪婪"到底贪婪于什么？五个问题分别对应定理3.3、不动点定理、1.4节引理、定理3.2、动作价值的定义。第三，主动映射：每学完一个概念，问一句"这在tcmP平台上对应什么"——v*对应症状组合的最优期望疗效，BOE的max对应辨证引擎的argmax，收缩迭代对应平台边积累病案边更新价值的学习模式，γ对应近期疗效与远期预后的医学权衡。下一节（1.7）将把三个定理落成可执行的算法蓝图；再下一节进入平台实践，读者将亲手在真实病证数据上运行这些算法。
