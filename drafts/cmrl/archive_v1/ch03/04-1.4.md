## [Part1] 1.4 贪婪策略最优定理

### 1.4.1 贪婪策略的定义

在给出本章最深刻的定理之前，先定义贪婪策略（greedy policy）。给定策略π及其动作价值qπ，称π在状态s是贪婪的，若 π(s) = argmaxa qπ(s,a)，即π在s选择的动作使动作价值最大；若π在每个状态都贪婪，则称π为贪婪策略。"贪婪"一词的直观含义是：只看当前状态的动作价值，选择眼前最大的一个，不做长远的权衡与随机化。在1.1节的例子中，改进后的策略π′在s1选择a3，而qπ(s1,a3) = 9是五个动作价值中的最大值，故π′在s1处是贪婪的。这里有一个微妙的循环需要注意：定义贪婪策略时使用的动作价值qπ，是策略π自己的动作价值；要验证"π是贪婪策略"，需要先求出π的价值函数。这不同于"对某个给定的价值v取argmax"——后者不依赖策略，形式为π(s) = argmaxa [Σr p(r|s,a) r + γΣs′ p(s′|s,a) v(s′)]。两种表述在定理3.1中都会出现，读者应能区分。

直觉上，"贪婪"听起来是短视的，贪婪策略似乎不可能是最优的。但下面的定理揭示了MDP中一个反直觉的深刻事实：贪婪即最优（greedy is optimal）。这个事实之所以成立，是因为动作价值qπ(s,a)已经包含了"采取a之后按π行动的长期回报"——它不是一个即时指标，而是一个"当前选择 + 未来最优行为"的复合指标。因此，在每个状态对这样一个复合指标取argmax，得到的策略会自动协调未来行为：贪婪不是目光短浅，而是"看得足够远之后只选最好的"。理解这一点的关键在于第2章的自举结构：价值函数把未来回报折算到当前，动作价值把未来行为折叠进当下选择，于是局部择优自然成为全局最优。下面用严格的定理与证明把这个直觉钉死。

### 1.4.2 定理3.1（贪婪策略最优）及其证明

定理3.1（贪婪策略最优）：设v是贝尔曼最优方程 v = T(v) 的解（由1.5节定理3.2，v = v*）。定义策略π为贪婪策略：对每个状态s，π(s) = argmaxa q(s,a)，其中 q(s,a) = Σr p(r|s,a) r + γΣs′ p(s′|s,a) v(s′)。则 v = vπ = v*，即π是最优策略。等价地，若v是某个策略的贝尔曼方程的解，且策略π在每个状态都选择使动作价值最大的动作，那么v = vπ = v*，π是最优策略。定理的威力在于：它把"在无穷多个策略中全局寻优"转化为"在每个状态做局部argmax"。证明分三步。

第一步，先证一个引理：对任意策略π与任意状态s，vπ(s) ≤ maxa qπ(s,a)。这由第2章的加权平均关系直接得到：vπ(s) = Σa π(a|s) qπ(s,a) ≤ maxa qπ(s,a)——加权平均不可能超过最大项。这个不等式虽简单，却是整个证明的引擎：它把"期望"（策略的折中）与"最大值"（贪婪的选择）联系起来，而定理3.1的全部力量恰好来自"最大值 ≥ 任意加权平均"这一事实。

第二步，证明vπ ≥ v*（逐分量）。设v = v*满足BOE，π(s) = argmaxa q(s,a)为贪婪策略，则v*(s) = maxa q(s,a) = q(s, π(s))。用数学归纳的思路逐状态比较：假设对所有s′已有vπ(s′) ≥ v*(s′)（归纳假设，从"下游"状态开始显然成立），则在状态s有 vπ(s) = Σa π(a|s) qπ(s,a) = qπ(s, π(s)) = Σr p(r|s,π(s)) r + γΣs′ p(s′|s,π(s)) vπ(s′) ≥ Σr p(r|s,π(s)) r + γΣs′ p(s′|s,π(s)) v*(s′) = q(s, π(s)) = v*(s)，其中第一个等号用了"π在s贪婪"（概率集中于最优动作），不等号用了归纳假设。于是由归纳法，vπ ≥ v* 对一切s成立。

第三步，由最优价值的定义，v* = maxπ vπ 蕴含 v*(s) ≥ vπ(s) 对一切s与一切π；结合第二步的 vπ ≥ v*，得 vπ = v*。再由1.5节定理3.2（v*唯一），v = v* = vπ，且π达到最优价值，故π是最优策略。证毕。整个证明只有两个不等式：加权平均 ≤ 最大值（引理），以及归纳传递；其余全是代数化简。读者应当能独立复述这四步——它比记忆公式更能揭示"贪婪即最优"的本质。

### 1.4.3 定理3.1的意义

定理3.1的意义无论怎么强调都不过分，这里列出四个层面。第一，计算层面的革命：寻找最优策略不再需要在策略空间中搜索——策略空间的大小随状态数指数增长，直接遍历在状态数稍大时就完全不可行；定理3.1保证，只需在每个状态比较有限个动作价值并取argmax，就得到最优策略。"全局优化 = 局部选择"从此有了严格依据。第二，算法层面的支点：它是策略迭代算法的理论支点——策略迭代 = 交替执行"策略评估（解贝尔曼方程得到vπ）"与"策略改进（对qπ取argmax得到贪婪策略）"，定理3.1保证：只要某轮改进后策略在每状态仍贪婪，该策略就是最优的；而在改进尚未到位时，1.4.2的引理保证每轮改进价值单调不降。第三，解释层面的统一：它解释了为什么几乎所有基于价值的算法——价值迭代、Q-learning、SARSA、DQN——最终都通过argmax提取策略；这些算法估计价值只是手段，贪婪提取才是通向最优策略的最后一公里。第四，回答1.1节遗留问题：如果策略在多个状态都不好，逐个改进是否总能得到更好的策略？——定理3.1的回答是：改进到"每个状态都贪婪"时，改进已达极限，策略必然最优；此前每一步改进都不会倒退。

例1.4（验证贪婪策略确实最优）：回到1.1节网格世界，γ = 0.9。改进后的策略π′在s1选a3，在s2、s3、s4分别选择到达s4的动作。我们已经求得v* = (9, 10, 10, 10)，且π′在各状态选择的动作分别达到q*(s1, a3) = 9、q*(s2, ·) = 10、q*(s3, ·) = 10、q*(s4, ·) = 10的最大值，故π′满足定理3.1的条件，确认为最优策略。若在s1处动作a3与某个其他动作并列最大（例如把奖励设计改一下），那么任选其一得到的策略仍然最优——最优策略可以不唯一，但价值函数唯一。这个例子演示了定理3.1的完整用法：先有最优价值v*（例1.3），再按argmax提取策略（定理3.1），策略即最优。把这两步连起来看，就是1.7节价值迭代算法的完整轮廓：迭代求v*，贪婪提取π*。

## [Part2] 1.4 平台语境：贪婪策略最优定理是"名医经验可计算化"的理论保证

在tcmP平台中，最优诊疗策略π*满足：对每个症状组合s，π*(s) = argmaxa q*(s,a)——选择期望疗效最高的方剂。定理3.1保证了"逐状态择优"的合法性：平台辨证引擎不需要穷举所有诊疗路径，只需在端点返回的Top-K候选中取证据分（疗效价值近似）最高的方案，就能达到最优疗效。反过来，定理也给"检索排序 = 诊疗决策"划定了理论边界：当且仅当证据分正确反映q*（即包含长期疗效与后继转归的价值）时，argmax才是最优的；若证据分只反映即时相关度而忽略后继状态的价值，贪婪于检索分可能不是真正最优——这正是平台从"纯检索"走向"价值学习"的动机：用BOE的递归结构把局部证据整合为全局一致的最优方案。临床上，这解释了"名医经验为什么可计算"：名医的辨证-用药模式本质上是一个在长期临床反馈（奖励）中逐步逼近最优策略（π*）的过程；贪婪策略最优定理保证了"在每个症状组合选最优方案"的名医式决策确实全局最优。同时，医者Agent的职责边界（SOUL.md中的约束，如不越权开具处方剂量）可理解为在策略空间上施加先验约束，使贪婪选择始终在合规范围内进行——约束缩小了可行策略集，定理3.1在受约束的策略集上依然成立，只是max改为在可行动作子集上取。
