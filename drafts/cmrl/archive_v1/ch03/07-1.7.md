## [Part1] 1.7 从BOE到计算：价值迭代的雏形

### 1.7.1 价值迭代算法

前五节完成了"最优"的数学刻画：v*是BOE的唯一解，π* = argmax贪婪策略。但数学刻画不等于可计算：BOE是非线性方程组，没有闭式解，状态空间稍大时直接解方程完全不可行。本节把定理3.3的收缩迭代落成第一个可执行的算法——价值迭代（value iteration, VI），它是第4章系统研究动态规划方法的先声。算法如下。输入：MDP (S, A, P, R, γ)，收敛阈值ε。初始化：任取价值向量v0（常取全零向量）。迭代：对k = 0, 1, 2, …，对每个状态s计算 vk+1(s) = maxa [ Σr p(r|s,a) r + γΣs′ p(s′|s,a) vk(s′) ]。停止：当‖vk+1 − vk‖∞ < ε时停止。输出：近似最优价值v ≈ vk+1。这个算法的每一步都只有两种运算：对动作取max、对后继状态取期望，两者都是局部的、可并行的——每个状态s的更新只需要自己与后继状态的值。这正是"全局优化 = 局部选择"在算法层面的体现：没有全局的矩阵求逆，只有逐状态的局部更新。

### 1.7.2 收敛性与误差界

价值迭代的正确性由定理3.3直接保证：T是压缩比为γ的收缩映射，故对任意v0，迭代vk+1 = T(vk)收敛到唯一不动点v*（BOE的解）。更有用的是显式误差界。由收缩性，‖vk+1 − v*‖∞ ≤ γ‖vk − v*‖∞，递推得 ‖vk − v*‖∞ ≤ γ^k ‖v0 − v*‖∞——误差按几何级数衰减，每步缩小γ倍。这个界还给出实用的停止准则：若‖vk+1 − vk‖∞ ≤ ε，则‖vk+1 − v*‖∞ ≤ γ‖vk − v*‖∞ ≤ γ/(1−γ)·‖vk+1 − vk‖∞ ≤ γε/(1−γ)（推导要点：由收缩性‖vk+1 − v*‖ ≤ γ‖vk − v*‖，与三角不等式‖vk − v*‖ ≤ ‖vk − vk+1‖ + ‖vk+1 − v*‖联立解出）。因此"相邻两步变化很小"确实意味着"离最优不远"，且界由γ/(1−γ)放大——γ越接近1，同样的ε对应的真实误差越大。数值感受：γ = 0.9时，要使误差降到初值的1%，需k ≈ ln(0.01)/ln(0.9) ≈ 43.7步；γ = 0.5时仅需k ≈ 6.6步。可见γ是"远见"与"计算代价"的权衡旋钮：γ越接近1，最优策略越远视（例1.5），但价值迭代收敛越慢。

### 1.7.3 从最优价值提取最优策略

价值迭代输出的是最优价值v*的近似，如何从中得到最优策略π*？利用定理3.1：π*(s) = argmaxa q*(s,a) = argmaxa [ Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′) ]。即：把v*代入动作价值公式，对每个状态取使动作价值最大的动作。两个细节值得注意。第一，提取策略只需当前状态的q值，每状态计算量是|A|次求和，远小于迭代本身。第二，若argmax并列（多个动作同时达到最大值），任选其一——定理3.1保证任一选择都是最优策略（它们价值相同）。例1.6（综合：在网格世界执行价值迭代）：回到1.1节网格世界，γ = 0.9，ε取小值。① v0 = 0；② v1(s) = maxa r(s,a)（因v0 = 0）：v1(s1) = max{−1, −1, 0, −1, 0} = 0（取a3或a5），v1(s2) = v1(s3) = v1(s4) = 1；③ v2(s1) = max{−1 + 0.9×0, −1 + 0.9×1, 0 + 0.9×1, −1 + 0.9×0, 0 + 0.9×0} = max{−1, −0.1, 0.9, −1, 0} = 0.9，v2(s2) = 1 + 0.9×1 = 1.9，v2(s3) = 1.9，v2(s4) = 1.9；④ v3(s1) = max{−1 + 0.9×0.9, −1 + 0.9×1.9, 0 + 0.9×1.9, …} = max{−0.19, 0.71, 1.71, …} = 1.71，v3(s2) = 1 + 0.9×1.9 = 2.71，……序列v4、v5、…逐步逼近v* = (9, 10, 10, 10)（约44轮达到1%误差）。提取策略：s1处使q最大的动作始终是a3（向下），与1.1节手算一致；s2、s3、s4的最优动作均为"转移到s4"。价值迭代与手算殊途同归——这验证了"迭代解BOE"与"直接解BOE"的一致性。

### 1.7.4 最优策略的进一步性质

价值迭代的应用带出最优策略的几个重要性质，它们在后续算法分析中反复使用。性质一（确定性最优策略存在）：MDP中总存在确定性的最优策略——因为max总能被某个动作达到，贪婪策略本身是确定性的（argmax取单值或在并列时任取一个）；随机化策略不会带来更高的价值，除非所有动作价值并列相等，此时随机化只是等价的另一种表示。性质二（最优策略不唯一、最优价值唯一）：价值函数并列时多个贪婪策略都是最优的，但它们的价值函数完全相同（定理3.2）；1.4节例1.4已演示。性质三（策略改进的单调性）：若π′由π贪婪化得到（π′(s) = argmaxa qπ(s,a)），则vπ′ ≥ vπ逐分量成立——这是1.4节引理"加权平均 ≤ 最大值"的直接推论，它保证策略迭代每一步都不倒退。性质四（最优价值的规模有界）：‖v*‖∞ ≤ ‖r‖∞/(1−γ)，因为每步奖励不超过‖r‖∞且折扣累计有限；这个界是1.5节存在性论证与误差界推导的共同基础。这四个性质分别回答了最优策略的"形态、唯一性、单调性、有界性"，把它们与三个定理放在一起，就构成对最优策略的完整认识。

### 1.7.5 从有模型到无模型的桥梁

价值迭代是"有模型"算法：它需要知道P与R（转移概率与奖励），才能计算vk+1(s) = maxa [Σr p(r|s,a) r + γΣs′ p(s′|s,a) vk(s′)]。现实问题中模型常常未知——例如真实临床环境中，没有人能给出精确的"症状转移概率"与"方剂奖励表"。第5章起，教材将把价值迭代中的"期望"换成"样本平均"，得到无模型（model-free）的迭代算法。最典型的例子是Q-learning，其更新规则为 q(s,a) ← q(s,a) + α[ r + γ maxa′ q(s′, a′) − q(s,a) ]。请读者观察：更新规则中的maxa′——它正是BOE的max结构在采样世界的化身：先在当前估计下选出最优后继动作，再用"即时奖励 + 最优后继价值"修正当前估计，学习率α控制修正步长。因此可以说：价值迭代是Q-learning的"已知模型原型"，Q-learning是价值迭代的"采样近似"；把价值迭代中的Σs′ p(s′|s,a) v(s′)换成实际观察到的v(s′)，把解方程换成梯度式修正，就从有模型平滑过渡到无模型。理解这条演化线，就能从本章的定理平稳进入第5章以后的算法森林。

## [Part2] 1.7 平台语境：从BOE迭代到平台的辨证价值学习

tcmP平台的实训（见第3.7节）将实现价值迭代的平台版：状态 = 症状组合（如"恶寒重、发热轻"），动作 = 候选方剂（麻黄汤、桂枝汤、桑菊饮、银翘散等），奖励 = 证据等级映射（A = 1.0、B = 0.7、C = 0.4），转移概率从病证—方剂共现统计估计。迭代vk+1(s) = maxa [ r(s,a) + γΣs′ p(s′|s,a) vk(s′) ]，收敛后提取π*(s) = argmaxa q(s,a)，再与语义检索端点/api/sages/semantic-search的Top-1方剂对比：一致性高，说明检索排序已接近最优决策；差异大，则提示奖励设计（证据等级到数值的映射）或状态特征（症状组合的表示方式）需要调整。这个实验是平台"从检索走向学习"的第一步：检索是记忆（返回已有相似案例），价值迭代是学习（用全局最优性BOE把局部证据整合成一致的最优诊疗方案）。临床意义上，价值迭代的收敛过程对应"临床经验的沉淀"：初值v0粗糙（相当于年轻医师的模糊直觉），每轮迭代用病案反馈（奖励）修正，逐步逼近v*（相当于名医的成熟疗效估计）。平台可进一步把γ设计为可调参数，在医圣成长路径的不同阶段采用不同γ：低年级阶段γ小，聚焦即时辨证正确率；高年级阶段γ大，训练远期预后优化——这使本章的算法蓝图直接嵌入平台的教学体系。
