## [Part1] 1.2 最优状态价值与最优策略

### 1.2.1 定义：最优状态价值与最优策略

1.1节的例子只改进了一个状态。随之而来的问题是：如果策略在多个状态都不好，选最大动作价值是否总能得到更好的策略？最优策略是否一定存在？长什么样？如何求解？本节先把"最优"用数学严格化。直观上，最优策略就是"最好的策略"，但"好"如何度量？第2章已经确立了一个判据：状态价值越大，策略越好。于是最优性的定义是自然的：在每一个状态s，取遍所有可能的策略π，把vπ(s)的最大值定义为该状态的最优状态价值（optimal state value）：v*(s) = maxπ vπ(s)，对一切s∈S成立。这个定义有三个要点。第一，max是在策略集合上取的：对每个策略π，vπ是一个定义在状态空间S上的价值向量；v*逐分量地取这些向量中的最大值，得到的仍是一个向量，称为最优状态价值函数。第二，v*(s)只依赖状态s，不依赖具体策略——它是所有策略在该状态的价值的"上包络"。第三，由于策略集合可能包含随机策略，max的范围原则上包含一切确定性策略与随机策略；1.7节将说明，在MDP中总存在确定性策略达到这个最大值。

接下来定义最优策略（optimal policy）：若策略π*满足 vπ*(s) = v*(s) 对一切s∈S成立，即该策略在每一个状态的价值都等于该状态的最优状态价值，则称π*为最优策略。定义中有两点必须强调。第一，"所有状态同时达到最大"并不是想当然的：完全可能存在一个策略在s1很好、在s2很差；要求存在一个策略在全部状态同时不劣于任何其他策略，需要专门的理论保证——这正是1.5节定理3.2（存在性）要证明的结论。在给出证明之前，我们把"最优策略存在"当作一个待验证的命题，这是严谨的数学态度。第二，最优策略可能不唯一：只要两个策略在全部状态达到相同的最大值，它们就都是最优策略。1.1节的例子中，改进后的策略π′在s1选择a3，而qπ(s1,a3) = 9是最大值；若某个动作与a3并列最大，选择它同样构成最优策略。这些细致之处在后续算法分析（尤其是argmax出现并列时）中很重要。

与最优状态价值相伴的另一个核心概念是最优动作价值（optimal action value）：q*(s,a) = maxπ qπ(s,a)，即所有策略下在状态s采取动作a的动作价值的最大值。最优状态价值与最优动作价值之间存在两个简洁而重要的关系式。第一个关系：v*(s) = maxa q*(s,a)。直观解释：在状态s，最优策略会选择最优动作a*，于是v*(s) = q*(s, a*) = maxa q*(s,a)；反过来，若在s选择任何非最优动作，价值都不可能超过maxa q*(s,a)。第二个关系：q*(s,a) = Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′)，即最优动作价值由即时奖励的期望与后继状态的最优价值决定。这两个关系式是1.3节推导贝尔曼最优方程的出发点，请读者务必先理解它们的含义：最优价值不是凭空出现的，它由"当下决策的即时效果"与"未来状态的最优价值"递归构成——这正是第2章自举（bootstrap）思想在最优化场景下的延伸。

### 1.2.2 性质与直观：网格世界示例

例1.2（网格世界的最优状态价值）：沿用1.1节的网格世界，γ = 0.9，求各状态的最优状态价值v*。分析：目标状态s4是吸收态，到达后每步得奖励+1并停留，故v*(s4) = 1 + γv*(s4)，解得v*(s4) = 10。状态s3可以直接转移到s4（得+1），也可以选择越界等动作（得−1或0），最优动作显然是转移到s4，故v*(s3) = max{−1 + γv*(s4), +1 + γv*(s4), …} = 10。同理v*(s2) = 10。对状态s1，五个动作的候选价值分别为：a1越界得−1并弹回s1，价值−1 + γv*(s1)；a2进禁区得−1并转移到s2，价值−1 + γv*(s2) = −1 + 9 = 8；a3转移到s3得0，价值0 + γv*(s3) = 9；a4越界弹回，价值−1 + γv*(s1)；a5静止留s1，价值γv*(s1)。于是v*(s1) = max{−1 + 0.9v*(s1), 8, 9, −1 + 0.9v*(s1), 0.9v*(s1)}。若最大项来自含v*(s1)的选项，则v*(s1) = 0.9v*(s1)或−1 + 0.9v*(s1)，解得v*(s1) = 0或10，均与第三项9矛盾（前者小于9，后者导致0.9×10 = 9恰等于9但带回−1项=8，需验证：若v*(s1) = 10，则−1 + 0.9×10 = 8 < 9，0.9×10 = 9，max = 9 ≠ 10，矛盾）；故最大项只能是第三项，v*(s1) = 9。解得v* = (9, 10, 10, 10)。

这个例子有几个值得注意的观察。第一，v*(s1) = 9恰好等于1.1节改进后策略π′的价值vπ′(s1)——这提示π′很可能已经是最优策略；1.4节的定理3.1将给出严格判据：只要策略在每个状态贪婪于动作价值，它就是最优的，而π′在s1选择最大动作价值a3，正是贪婪行为。第二，最优状态价值的求解在这里靠的是"从目标状态倒推"：先定s4，再定s3、s2，最后解s1的方程。这种倒推结构在1.7节将升级为通用的迭代算法。第三，v*(s1) = 9虽然与vπ′(s1)相等，但我们此刻还不知道它就是最大值——判断"是否已达最优"需要定理，这正是本章理论的用武之地。第四，注意q*与v*的关系在求解中反复出现：每个候选动作的价值都是"即时奖励 + γ×后继最优价值"，这正是v*(s) = maxa q*(s,a)的逐动作展开。

从性质上总结：最优状态价值函数v*是状态空间上的确定函数，它满足"v*(s) ≥ vπ(s)对一切策略π与一切状态s"的逐分量支配性质；最优策略π*是使vπ达到这个支配上界的策略。最优动作价值q*则提供了比v*更细的粒度：v*告诉我们"状态有多好"，q*告诉我们"在状态s采取动作a有多好"——后者正是策略改进与策略提取所需的直接信息。因此，虽然v*在定义上是主角，但几乎所有算法（包括第4章的价值迭代与第5章的Q-learning）在实际运作中都围绕q展开：先估计q，再对q取max或argmax。读者可以把这个观察记为"价值在v中定义，决策在q中发生"。最后回到本节开头的四个问题：最优策略是否一定存在（1.5节定理3.2回答"是"）、长什么样（1.4节定理3.1回答"是贪婪策略"）、如何求解（1.5节定理3.3与1.7节价值迭代回答"迭代"）、逐个改进是否总能得到更好的策略（1.4节引理回答"改进直到贪婪，贪婪即最优"）。下一节将推导v*满足的方程——贝尔曼最优方程。

## [Part2] 1.2 平台语境：最优状态价值即最优期望疗效

在tcmP平台中，最优状态价值对应"症状组合的最优期望疗效"：v*(症状组合)表示，面对该症状组合，在所有可用的辨证—方剂诊疗方案中，按最优方案处理所能获得的期望疗效回报。与网格世界一样，这个值不是孤立的：它由"当下处理的效果 + γ×后继状态（转归、并发症）的价值"递归决定。以风寒表实证"恶寒重、发热轻"为例，其最优价值v*取决于：当下选用麻黄汤的即时疗效（证据等级A映射奖励1.0），加上治愈后"正气来复"状态的价值；若误用针对风热证的桑菊饮，虽然可能有一定效果，期望价值却更低。平台60000+个病证单元（DSU）为每个"症状组合→方剂"对提供了证据等级，这正是计算q*所需的奖励数据；辨证端点返回的Top-K候选及其证据分，相当于"最优动作价值"的检索近似。v*(s) = maxa q*(s,a)在平台上还有一个直接推论：辨证引擎的推荐应当是"择优"（argmax）而非"折中"（加权平均）——给多名医师的辨证结论做平均并不能得到最优方案，这正如对多个动作价值取平均得不到最大值一样。这一原则将指导平台辨证端点的设计，也在1.3节的贝尔曼最优方程中得到数学表达。
