## [Part1] 1.3 贝尔曼最优方程

### 1.3.1 BOE 的推导

1.2节定义了最优状态价值v*与最优动作价值q*，并给出两个关系式。本节回答：v*满足什么样的方程？这个方程称为贝尔曼最优方程（Bellman Optimality Equation, BOE），它是对应最优策略的特殊贝尔曼方程。推导只需两个现成的工具：第2章的贝尔曼分解技巧（自举：把回报拆成即时奖励与后继回报），以及1.2节的最优关系式。先对照普通贝尔曼方程：vπ(s) = Σa π(a|s) qπ(s,a)——状态价值是动作价值的加权平均，权重是策略π在s处的选择概率。再对照最优关系式：v*(s) = maxa q*(s,a)——最优状态价值是动作价值的最大值。一个用"期望"（加权平均），一个用"最大值"，这正是两条方程之间唯一的结构差别。把这两个式子叠加，BOE的形态已经呼之欲出：把普通贝尔曼方程中的加权平均Σa π(a|s)换成最大值maxa，把vπ、qπ换成v*、q*，就得到BOE。

为了给出严格推导，先做一个关键论证：最优策略在s处"以概率1选择最优动作"是合理的。设π*最优，若π*在s以正概率选了多个动作，那么由于qπ*(s,a)中必有一个最大值a*，把π*在s的概率质量全部集中到a*上，得到新策略π̂，则vπ̂(s) = qπ*(s, a*) ≥ vπ*(s)，其余状态价值不变（s处的动作不影响其他状态的转移与奖励）。故π̂也是最优策略。这说明：存在最优策略在每个状态以概率1选择一个动作，且该动作使动作价值最大。于是 v*(s) = vπ*(s) = qπ*(s, π*(s)) = maxa qπ*(s,a) = maxa q*(s,a)，其中最后一个等号用到"在s取a、其余状态按最优策略"时q*(s,a) = qπ*(s,a)（a之后按π*执行）。再代入动作价值分解 q*(s,a) = Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′)，就得到BOE：

v*(s) = maxa [ Σr p(r|s,a) r + γ Σs′ p(s′|s,a) v*(s′) ] = maxa q*(s,a)，对一切s∈S。

把推导过程浓缩成一句话：最优状态价值 = 每个状态选择最优动作时，即时奖励与后继最优价值的最大组合。BOE与普通贝尔曼方程的唯一差别在于：普通方程对策略π求期望（加权平均），BOE对动作a求最大值（max）。这个"唯一差别"带来两个后果：其一，BOE是非线性方程（max不可分配到各项），没有形如v = (I−γPπ)⁻¹rπ的闭式解；其二，正是这个max把"所有策略"的优化浓缩进一个方程——解一个BOE等于在全部策略中寻优，这是普通贝尔曼方程（每个π一个方程）无法比拟的。

### 1.3.2 BOE 的等价形式与向量形式

BOE有几种等价写法，读者应当能自由切换。第一种是上面给出的"动作价值展开"形式。第二种是把奖励与转移合并：若转移-奖励联合分布记为p(r, s′|s,a)，则 v*(s) = maxa Σr,s′ p(r, s′|s,a) [ r + γ v*(s′) ]。第三种是动作价值形式：v*(s) = maxa q*(s,a)，其中q*(s,a)满足 q*(s,a) = Σr p(r|s,a) r + γΣs′ p(s′|s,a) maxa′ q*(s′, a′)——这是q*的自洽方程，第5章Q-learning更新规则的采样版本。第四种是向量形式。定义算子T：对任意价值向量v，令 (Tv)(s) = maxa [ Σr p(r|s,a) r + γΣs′ p(s′|s,a) v(s′) ] = maxπ Σa π(a|s) [ Σr p(r|s,a) r + γΣs′ p(s′|s,a) v(s′) ]，其中第二个等号成立是因为：对固定的s，加权平均Σa π(a|s) fa在π把全部概率质量放在fa最大的动作上时达到最大值maxa fa——即"maxa fa = maxπ Σa π(a|s) fa"。于是BOE写成 v* = T(v*)，即v*是算子T的不动点（fixed point）。更紧凑地，T可写成 T(v) = maxπ (rπ + γPπ v)，其中的max是逐分量的。请注意T是非线性算子：max不能分配到和号或矩阵乘法内部，T(v1 + v2) ≠ T(v1) + T(v2)。

非线性意味着什么？对普通贝尔曼方程，我们有完备的线性代数工具：v = (I − γPπ)⁻¹ rπ，可逆性由谱半径论证保证（第2章定理2.1）。对BOE，这些工具全部失效：不存在闭式解，也无法用高斯消元一次求出。出路只有一条——迭代逼近：构造序列v0, v1, v2, …，令vk+1 = T(vk)，希望它收敛到不动点v*。这个思路是否可行，取决于T是否具有"压缩"性质，这正是1.5节定理3.3的内容。这里先给出直观：T把任何两个候选价值向量的距离至少缩小γ倍（γ<1），因此反复作用后，所有候选被"吸"向同一个点——v*。读者可以把这个图像记在心里：BOE是"最优"的静态刻画，迭代vk+1 = T(vk)是"最优"的动态逼近，两者由不动点定理缝合。第4章的价值迭代算法即这个迭代的具体化。

### 1.3.3 BOE 的意义与应用

例1.3（用BOE验证网格世界的最优价值）：沿用例1.2的网格世界，γ = 0.9，直接写出BOE并验证v* = (9, 10, 10, 10)是它的解。对s4（吸收态）：v*(s4) = maxa [Σr p(r|s4,a) r + γΣs′ p(s′|s4,a) v*(s′)]，停留在s4得+1，故v*(s4) = 1 + γv*(s4)，解得v*(s4) = 10，与候选值一致。对s3、s2：最优动作均为转移到s4得+1，v* = 1 + γv*(s4) = 10，一致。对s1：v*(s1) = max{−1 + γv*(s1), −1 + γv*(s2), 0 + γv*(s3), −1 + γv*(s1), 0 + γv*(s1)}；代入候选值9，各选项为7.1、8、9、7.1、8.1，max = 9，一致。故v* = (9, 10, 10, 10)确实是BOE的解。本例说明：求解BOE与寻找最优价值是同一件事——BOE的解就是1.2节定义的最优状态价值；这为后续"用迭代解方程替代逐个比较策略"提供了明确目标。

BOE的意义可以从三个层面理解。理论上，BOE是最优性的一阶刻画：一个价值函数是最优的，当且仅当它满足BOE；这比"v*(s) = maxπ vπ(s)"的定义式更可操作，因为定义式需要遍历全部策略，而BOE只需要在当前价值上做逐状态max。算法上，BOE把"优化"转化为"求不动点"：v* = T(v*)，而求不动点有成熟的迭代工具（1.5节）。概念上，BOE揭示了"局部最优 = 全局最优"的深层结构：方程在每个状态独立地取max，却同时刻画了所有状态的全局最优价值——这个"独立性"与"全局性"的统一，是MDP问题区别于一般优化问题的根本特性，也是1.4节贪婪策略最优定理的伏笔。最后提醒一点：BOE的非线性意味着求解不能套用线性方程直觉，唯一性也需专门证明（1.5节定理3.2）。下一节进入本章最深刻的定理：贪婪策略最优。

## [Part2] 1.3 平台语境：BOE 是辨证引擎"择优决策"的数学依据

在tcmP平台中，贝尔曼最优方程对应辨证引擎的设计原则：给定症状组合（状态s），从候选方剂（动作a）中选出最优者。BOE的max结构恰好刻画了"择优"决策：医者Agent的辨证应当是argmax（选证据分与后继价值之和最大的方案），而不是对候选做加权平均（期望）。这与平台辨证端点的Top-K检索排序一脉相承：检索给出候选集，BOE给出"选哪一个"的数学依据。具体接口上：辨证端点 POST /api/sages/bianzheng，请求体形如 {"symptoms": ["恶寒重", "发热轻"], "top_k": 3}，返回Top-K病证—证候—方剂候选及其证据分；语义检索端点 /api/sages/semantic-search 返回的证据分rrf，可作为奖励信号与价值近似的真实来源。平台图谱本体 kg/schema/schema.json 用JSON Schema（$ref/required/enum/pattern）定义DSU六段结构，相当于"状态特征"的本体层；医者人格 agents/healer/SOUL.md 定义医者Agent的辨证职责与边界（如"不直接开具处方剂量"），相当于策略空间的先验约束。医者作为平台六者（医者、患者、学者、术者、统者、使者）的核心枢纽，其"择优"地位恰如BOE中的max角色——这是本章内容在平台架构上最重要的落点。
