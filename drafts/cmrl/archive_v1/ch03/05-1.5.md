## [Part1] 1.5 存在性、唯一性与收缩映射

### 1.5.1 定理3.2：最优状态价值存在且唯一

1.2节定义最优策略时，我们承诺"所有状态同时达到最大"需要理论保证；1.4节的证明中，又用到了"v* = T(v*)的解唯一"。现在兑现承诺。定理3.2（存在性与唯一性）：贝尔曼最优方程 v = T(v) 存在解，且解唯一；换言之，最优状态价值v*存在且唯一，最优策略存在。先看唯一性，它几乎是免费的：若T是收缩映射（定理3.3），则T至多有一个不动点——因为若v1*、v2*都是不动点，则‖v1* − v2*‖∞ = ‖T(v1*) − T(v2*)‖∞ ≤ γ‖v1* − v2*‖∞，由γ < 1迫使‖v1* − v2*‖∞ = 0，故v1* = v2*。再看存在性，它有两个途径。途径一（构造性）：考虑迭代序列v0任意、vk+1 = T(vk)，由定理3.3它收敛，极限v*满足 v* = T(v*)（T连续，极限与算子作用可交换），故v*是BOE的解。途径二（价值有界性）：v* = maxπ vπ 是有意义的，因为每个状态的价值被 ‖r‖∞/(1−γ) 界定（每步奖励不超过‖r‖∞，折扣累计有限），故策略集合上的最大值存在。两条途径殊途同归：既证明了存在，又给出了求解算法（迭代）——存在性证明与算法设计在这里合二为一，这是不动点理论的典型威力。

### 1.5.2 定理3.3：T 是收缩映射

定理3.3（收缩映射）：定义映射 T(v) = maxπ (rπ + γPπ v)（max逐分量取遍所有策略π），则T是关于无穷范数的收缩映射（contraction mapping），压缩比为γ。这里先交代两个概念。无穷范数：‖v‖∞ = maxs |v(s)|，衡量价值向量各分量的最大偏差。收缩映射：设T是定义在向量空间上的映射，若存在常数δ ∈ [0,1)使得对任意向量v1、v2都有 ‖T(v1) − T(v2)‖∞ ≤ δ‖v1 − v2‖∞，则称T为收缩映射，δ称为压缩比（contraction ratio）。几何直觉：T把任意两点的距离至少压缩δ倍，反复作用后所有点被"吸"向同一个点。著名的不动点定理（Banach不动点定理）说：完备度量空间上的收缩映射T存在唯一不动点v*（即T(v*) = v*），且对任意初始点v0，迭代vk+1 = T(vk)收敛到v*，收敛速度为几何级数：‖vk − v*‖∞ ≤ δ^k ‖v0 − v*‖∞。把定理3.3与不动点定理叠加，立即得到：BOE有唯一解v*，迭代vk+1 = T(vk)从任意初值收敛到v*——这正是第4章价值迭代算法的全部理论基础。

定理3.3的证明只用到一个不等式——max的Lipschitz性质：对任意两组数{f(a)}a∈A与{g(a)}a∈A，|maxa f(a) − maxa g(a)| ≤ maxa |f(a) − g(a)|。直观上，最大值对输入扰动的敏感度不超过输入的扰动幅度。现在对任意v1、v2与任意状态s，(T(v1))(s) = maxa [ r(s,a) + γΣs′ p(s′|s,a) v1(s′) ]，(T(v2))(s) = maxa [ r(s,a) + γΣs′ p(s′|s,a) v2(s′) ]。由Lipschitz性质，|(T(v1))(s) − (T(v2))(s)| ≤ maxa | γΣs′ p(s′|s,a) (v1(s′) − v2(s′)) | ≤ γ maxa Σs′ p(s′|s,a) |v1(s′) − v2(s′)| ≤ γ maxs′ |v1(s′) − v2(s′)| = γ‖v1 − v2‖∞，其中倒数第二个不等号用到Σs′ p(s′|s,a) = 1（概率归一）。由于s任意，‖T(v1) − T(v2)‖∞ ≤ γ‖v1 − v2‖∞。证毕。证明的每一步都是基本代数与概率归一性，唯一的新工具是max的Lipschitz性质。请读者注意压缩比恰为γ——这正是折扣率γ ∈ (0,1)在MDP设计中不可或缺的原因：若γ = 1（无折扣），压缩比退化到1，T不再是收缩映射，BOE可能无解（例如持续正奖励的回路使价值发散）。

### 1.5.3 例1.5：最优策略与折扣率 γ 的关系

例1.5（γ对最优策略的影响）：为突出折扣率的作用，考虑一个简化的两路径网格：智能体从起点s1出发，有两个动作可选。动作A（"绕远路"）依次经历奖励0、0、+10并终止；动作B（"走近路"）依次经历奖励+1、+1、0并终止。两条路径都只有一步决策，故最优策略在s1选择使折扣回报最大的动作。当γ = 0.1（短视）时，A的回报 = 0 + 0.1×0 + 0.01×10 = 0.1，B的回报 = 1 + 0.1×1 + 0.01×0 = 1.1，B > A，最优策略选B——眼前的小甜头（+1、+1）盖过了遥远的+10。当γ = 0.9（远视）时，A的回报 = 0 + 0.9×0 + 0.81×10 = 8.1，B的回报 = 0.9 + 0.81 = 1.71，A > B，最优策略选A——愿意牺牲眼前利益，绕远路追求更大的远期回报。这个例子定量地说明：γ小则最优策略短视（只关注即时奖励），γ大则最优策略远视（敢于为远期收益承担近期损失）。临床上的对应是直白的：若平台的疗效价值模型把γ设得很小，模型只会优化"当下辨证—开方"的即时效果，忽视长期转归；γ接近1则引导模型追求远期康复质量。折扣率因此是平台可调的教学/临床参数，其取值反映"近期疗效与远期预后"的医学权衡。

### 1.5.4 小结与衔接

本节把本章的理论补齐并钉牢。存在性（定理3.2）回答"最优策略是否一定存在"——是，且最优价值唯一；形态（定理3.1）回答"最优策略长什么样"——贪婪策略；求解（定理3.3 + 不动点定理）回答"如何求"——迭代vk+1 = T(vk)，几何收敛，压缩比γ。三个定理环环相扣：唯一性依赖收缩性，收缩性依赖γ < 1，存在性由迭代收敛构造性给出。与第2章对照，普通贝尔曼方程有"存在（(I − γPπ)⁻¹可逆）、唯一、迭代收敛"三性质，BOE有完全平行的三性质——区别只在于：线性方程有闭式解，非线性BOE只有迭代解；而迭代解在今天远比闭式解实用（状态空间大时求逆矩阵不可行，迭代却可以逐状态并行推进）。衔接上，1.7节将把迭代具体化为价值迭代算法的雏形，第4章将系统研究价值迭代与策略迭代；本节的不动点论证，是理解这两类算法收敛性的共同钥匙。读者学完本节，应能回答：为什么γ必须小于1？为什么迭代一定收敛？误差每步缩小多少倍？三个问题的答案分别是：收缩性需要；不动点定理；γ倍。

## [Part2] 1.5 平台语境：收缩映射迭代是平台价值学习的收敛性保证

tcmP平台的"最优诊疗价值"可以通过迭代逼近：v0(s) = 0，vk+1(s) = maxa [ r(s,a) + γΣs′ p(s′|s,a) vk(s′) ]，每次迭代相当于"用现有经验更新每个症状组合的最优期望疗效"。定理3.3保证：无论初值如何（哪怕用检索分数或专家经验初始化），迭代必然收敛到唯一的最优价值，且误差按γ^k几何衰减——这为平台"边积累病案边更新价值"的学习模式提供了理论安全网：初始估计粗糙没关系，迭代会逐步修正到一致的最优值。临床语义上，收缩映射还解释了一个现象：辨证经验的"自我一致性"。多位医师对同一症状组合的疗效估计可能分歧很大（v0相差很大），但只要他们都按"择优更新"的规则迭代（用临床反馈修正估计），分歧会按γ的幂次迅速收拢，最终收敛到同一个最优价值——这与"临床共识的形成"高度同构：循证反馈（奖励）反复作用，主观分歧（初值差异）指数衰减。实训层面，1.5节的例1.5提醒平台设计者：γ的取值直接决定最优方案是"急则治标"还是"缓则治本"；在医圣成长路径的教学场景中，可以设计γ随学习阶段变化的机制——早期γ小（学会即时辨证），后期γ大（学会远期调理），从"短视优化"逐步过渡到"远视优化"。
