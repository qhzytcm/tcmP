## [Part2] 3.7 平台实践与实训：在 tcmP 上求解最优诊疗方案

### 3.7.1 平台语境：最优策略 = 最优诊疗方案

本章的理论核心——最优状态价值、贝尔曼最优方程、贪婪策略最优——在tcmP中医医院AI网络教育平台中有清晰的一一对应：最优策略对应最优诊疗方案，v*(症状组合)表示该症状组合下选择最优辨证—方剂组合的期望疗效。平台的医圣成长路径把"从住院医到学科带头人"的成长建模为MDP：状态是医师的能力画像与当前面对的症状组合，动作是辨证结论、方剂推荐与学习决策，奖励来自临床反馈（辨证正确得正奖励、误诊得负奖励、考核通过得正奖励）与证据等级（A级=1.0、B级=0.7、C级=0.4）。平台的目标是帮助每位医师找到从当前水平到最优水平的成长策略与诊疗策略——这与智能体在网格世界中寻找最优路径的目标完全同构。平台的辨证端点（POST /api/sages/bianzheng）的设计原则正是BOE的max结构：医者Agent的辨证应当是"择优"（argmax）决策，而不是对所有候选做加权平均；语义检索端点（/api/sages/semantic-search）返回的Top-K候选与证据分rrf，相当于动作价值的检索近似。理解了这个整体映射，就可以开始动手实验。

### 3.7.2 平台接口与数据准备

实验依赖平台的三个接口与两类数据文件。接口一，辨证端点：POST /api/sages/bianzheng，请求体形如 {"symptoms": ["恶寒重", "发热轻"], "top_k": 3}，返回Top-K病证—证候—方剂候选及其证据分。接口二，语义检索端点：/api/sages/semantic-search?q=失眠&top_k=1，返回检索证据分，作为奖励信号与价值近似的真实来源。接口三，图谱本体：kg/schema/schema.json，用JSON Schema（$ref/required/enum/pattern）定义DSU六段结构（病侧/证侧/桥接/临床），是"状态特征"的本体层。数据文件：tcmP/kg/samples/下的dsu-samples-*.json（103个以上真实病证单元），每个单元包含症状（状态）、方剂（动作）、证据等级（奖励）字段。环境配置务必注意：①安装依赖 pip install numpy pandas matplotlib（如需标准RL环境可安装gymnasium）；②配置LLM环境变量 DEEPSEEK_API_KEY 激活平台的DeepSeek对话能力，密钥不写入代码或文档；③平台检索引擎（SQLite FTS5）在系统Anaconda python 3.9下会段错误，务必使用hermes venv python（C:\Users\DELL\AppData\Local\hermes\hermes-agent\venv\Scripts\python.exe）运行。

### 3.7.3 实训任务一：BOE 迭代与检索对比

任务目标：在"症状—方剂"网格上实现价值迭代（BOE迭代），并与平台检索结果对比。步骤：①数据构造——从dsu-samples中选取10个高频症状组合作为状态集S，选取5首高频候选方剂作为动作集A；②奖励表——把每个"症状组合→方剂"对的证据等级映射为数值奖励（A=1.0、B=0.7、C=0.4），无记录的置0；③转移估计——从病证—方剂共现统计估计转移概率P(s′|s,a)，或采用简化模型（选对则转移到"治愈态"，选错留在原态）；④初始化v0全零，迭代 vk+1(s) = maxa [ r(s,a) + γΣs′ p(s′|s,a) vk(s′) ] 直到‖vk+1 − vk‖∞ < ε（取γ = 0.9、ε = 0.01，约44轮收敛）；⑤提取最优策略π*(s) = argmaxa q(s,a)。对比分析：把BOE给出的最优动作与/api/sages/semantic-search检索的Top-1方剂逐状态比较，计算一致率；对不一致的状态，分析误差来源——特征表示（症状组合的编码粒度）、奖励设计（证据等级映射是否准确反映疗效）、候选集大小（漏掉真正最优方剂）、转移估计（共现统计的稀疏性）。本任务对应教材1.7节价值迭代，把核心定理落到平台真实数据上。

### 3.7.4 实训任务二：策略改进循环与成长路径模拟

任务目标：在医圣成长路径上模拟"策略改进—最优策略"的完整循环，体会1.1节三步法与定理3.1。步骤：①定义一个简化成长MDP——状态为医师能力画像（如"掌握病证数"分档：500/2000/10000/60000），动作为学习决策（基础课程/进阶课程/临床轮转/科研攻关），奖励为考核通过率（由证据等级与病案反馈给出）；②初始策略：随机策略π0；③策略评估：解贝尔曼方程 vπ = rπ + γPπ vπ 得vπ0；④策略改进：计算qπ0(s,a)，取π1(s) = argmaxa qπ0(s,a)；⑤重复③④直到策略不再变化——由定理3.1，此时策略最优；记录每轮的价值提升曲线，验证单调性（vπk+1 ≥ vπk）。进阶思考：把γ从0.5调大至0.95，观察最优策略是否从"短视课程"（即时通过率高）转向"远视路径"（远期能力增长大），复现例1.5的结论。最后撰写实验报告：包含状态/动作/奖励设计表、迭代收敛曲线、最优策略与检索对比表、误差来源分析与改进建议。报告可直接用于平台辨证引擎的评估会议。

### 3.7.5 小结与衔接

本节的实训任务把第3章的全部核心概念——策略改进（1.1）、最优状态价值（1.2）、贝尔曼最优方程（1.3）、贪婪策略最优（1.4）、收缩映射迭代（1.5）、价值迭代（1.7）——映射到tcmP平台的真实数据与接口上，形成"学完即能用"的闭环。任务一验证"检索排序 ≈ BOE近似argmax"的假设并定位误差来源；任务二在成长路径上复现"评估—改进—最优"的循环，直观体验定理3.1。两个任务共同回答了平台建设者最关心的问题：为什么辨证引擎要按argmax设计（BOE），为什么可以信任Top-1推荐（定理3.1），如何从数据中学习最优方案（价值迭代）。下一节将站在中医药语境与职业应用的角度，重新审视本章知识对临床医师与AI工程师两类职业的具体价值。
