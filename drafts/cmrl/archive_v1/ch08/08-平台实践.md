## [Part2] 8.8 平台实践与实训：泛化能力对比实验

### 8.8.1 平台语境：病证向量与泛化

本实践把本章"表格 vs 函数"之争落到可运行的数据上。背景：tcmP 平台知识库含 60000+ 病证单元，教学切片为 103+ DSU；每个 DSU 记录症状描述、推荐方剂与证据等级。实验目标：构建监督集（状态特征=TF-IDF 向量，标签=证据等级映射分），分别实现表格法（每个 DSU 一个格子）与函数法（线性价值函数 v̂=φTw），对比两者在"已入库病证"与"未入库病证"上的预测表现，实证 8.1 节 P2（状态空间太大）的解法与局限。实验同时也回答平台的一个真实问题：为什么不能为每个病证维护独立条目，而必须用向量化表示？预期结论：表格法在训练集上精确（MSE≈0），在未入库病证上失效；函数法在训练集上有逼近误差，但能对未入库病证给出有信息量的估计——泛化能力的量化呈现。

### 8.8.2 平台接口：特征与训练

环境与数据准备分四步。① 特征生成（对应 8.2 特征工程）：方案 A 用 tcm_embed.py（bigram 分词+TF-IDF 向量，零依赖），方案 B 用 pip install sentence-transformers 加载 BGE 中文模型（平台已预留 _bge 接口）生成语义向量；两种特征都归一化到单位长度，避免量纲差异主导梯度。② 监督数据（对应 8.3 v_target）：读 DSU 表，把证据等级映射为分数（A 级→5、B 级→4、C 级→3、专家共识→2、个案医案→1，可按平台文档调整），构成标签向量 v。③ 训练框架：numpy 即可完成线性近似——闭式解 w*=(ΦTΦ+λI)^{-1}ΦTv（岭回归）或小批量 SGD 100 轮；torch 可选（CPU 小实验）。④ 数据划分：DSU 随机分为训练/验证集（如 80/20）；另构造若干“未入库”症状组合作为泛化测试集（如把两个病证的症状合并、或人工改写症状描述）——这是平台中“新患者症状”的模拟。注意划分的随机种子需固定，保证表格与函数法、TF-IDF 与 BGE 两组实验在同一划分下比较，结果才有统计意义；泛化测试集的构造应与真实新患者场景对齐（症状改写而非病证 id 随意拼接）。

### 8.8.3 方法与步骤：实验设计

实验步骤六步。① 数据准备：读 DSU 表，bigram 分词构造 TF-IDF 特征矩阵 Φ（形状 DSU 数×特征维），标签向量 v；② 表格法基线：建立 dict {病证 id: 分数}，训练集病证直接查表；验证集与泛化集中未入库的病证返回全局均值（或 0）——这正是表格法对未见状态的"默认值"行为；③ 函数法：线性模型 w*=(ΦTΦ+λI)^{-1}ΦTv 或 SGD 训练，λ 取小值（如 0.01）防奇异；④ 评估：分别计算训练集、验证集、泛化集上的 MSE 与相关系数（预测 vs 标签）；⑤ 变体实验：用 BGE 语义向量替代 TF-IDF，重复②-④；⑥ 记录三组关键数据：表格法的验证集 MSE（非零，因部分验证病证未入库）vs 函数法的验证集 MSE（应更低）；泛化集上表格法基本失效（预测恒定均值）vs 函数法给出有区分度的预测。

为便于复现，给出 numpy 核心代码骨架（示意，非平台完整代码）：特征构建——from tcm_embed import tfidf_bigram; X = tfidf_bigram(dsu_texts)（返回 DSU 数×特征维矩阵）；标签映射——v = np.array([LEVEL_MAP[e] for e in dsu_levels])；岭回归——w = np.linalg.solve(X.T@X + lam*np.eye(m), X.T@v)；表格基线——table = dict(zip(train_ids, v_train)); pred = [table.get(i, np.mean(v_train)) for i in test_ids]；评估——mse = np.mean((pred - v_test)**2)。三个常见坑：① λ=0 且特征维度大于样本数时 ΦTΦ 奇异，solve 报错，需加正则或改用 SGD；② 特征未归一化时，高频词维度主导梯度，建议每行做 L2 归一化；③ 证据等级映射不一致（不同 DSU 的同一等级映射不同分数）会引入标签噪声，务必全局统一映射表。代码跑通后，把三组 MSE 填入实验记录表，与 8.8.4 的预期结果对照，即可完成本实验。

### 8.8.4 结果观察与讨论

预期结果与讨论要点如下。① 训练集：表格法 MSE=0（精确记忆），函数法 MSE>0（逼近误差）——复现"表格精确、函数有偏"（8.5 节）；② 验证集：函数法通常优于表格法——复现"函数泛化"；③ 泛化集：表格法只有全局均值的平庸预测，函数法借特征相似性给出有信息量的估计——实证 P2 的解法（8.1 节）；④ 特征质量：BGE 语义向量的验证/泛化 MSE 通常优于 TF-IDF——"失眠"与"不寐"在语义空间相近、在字面 TF-IDF 空间可能完全不同，特征质量决定泛化天花板（8.2 节结论）；⑤ 附加观察：λ 增大（正则化）对验证集 MSE 的影响（偏差-方差权衡）；训练样本量减半后两种方法的鲁棒性差异（表格法掉得更快）。思考题：若把标签改为"用药后复诊转归"（时间序列而非静态证据等级），表格与函数的差异会如何演化？半梯度 TD 在线更新（8.7 节）相对监督式拟合（本实验）的优劣如何？

### 8.8.5 小结与衔接

本实践把第8章全部概念（特征、线性近似、MSE、SGD、泛化、权衡）落到可运行的代码与可观测的数据上：表格法在训练集精确、在未见病证上失效；函数法在训练集有逼近误差、在未见病证上泛化——这正是 P2 的实证答案，也解释了平台为什么必须用向量化表示与函数近似。实验同时暴露了函数法的代价（逼近误差、特征依赖），为读者理解 8.5 节的权衡提供了第一手数据。下一节（8.9）把本章概念放入中医药语境与职业应用，讨论中医辨证的场景化理解、tcmP 平台映射，以及 AI 工程与医工器械岗位如何利用价值函数方法。
