# 第8章 价值函数方法（Value Function Methods）·章引言

## [Part1] 第8章 价值函数方法·章引言

从第4章到第7章，本书走过了从动态规划到蒙特卡洛（Monte Carlo, MC）、到时序差分（Temporal-Difference, TD）、再到 Sarsa 与 Q-learning 的完整旅程。细心的读者会发现，这些算法有一个共同的前提：价值都用表格表示。表格表示把状态价值 vπ(s) 或动作价值 qπ(s,a) 一一对应地存储在格子中，每个状态（或状态-动作对）独占一个条目。表格直观、精确，在小规模问题上表现优异，第4-7章的所有收敛性定理都建立在这种表示之上。然而，一个根本性的局限在悄然逼近：当状态空间变大时，表格的规模随之爆炸。一个 10×10 的网格世界有 100 个状态；一局围棋有约 10^170 个状态；而在临床诊疗中，症状、舌象、脉象的组合数量同样是天文数字。表格法在每个状态上独立存储、独立更新，它无法把"相似状态"的价值相互借用——这是"记忆式"学习的天然天花板。

本章引入价值函数方法（Value Function Methods）：用参数化函数 v̂(s,w) ≈ vπ(s) 表示价值，其中 w 是参数向量。函数近似的本质是让所有状态共享同一组参数，相邻（相似）状态因此获得相近的价值估计——这就是泛化能力（generalization）的来源。这一步看起来只是"换了一种存储方式"，实际上是从"精确记忆"到"模式学习"的范式转变：人工神经网络正是作为参数化函数逼近器进入强化学习的。本章的知识结构围绕"三大问题"展开：P1 模型未知、P2 状态空间太大、P3 策略如何表示。价值函数方法正面回应 P2，并为其后第9章回应 P3 的策略梯度方法铺平道路。可以说，读懂本章的"表格到函数"之跃，就拿到了理解现代强化学习（深度 Q 网络、Actor-Critic、大模型时代的检索增强决策）的钥匙。

本章路线图如下：8.1 节从表格到函数，正式提出三大问题；8.2 节给出最简单的参数化表示——线性函数近似 v̂(s,w)=φT(s)w，并讨论特征向量；8.3 节站在随机梯度下降（第6章）的视角推导参数更新规则，比较 MC 目标与 TD 目标，引出半梯度概念；8.4 节进入深度强化学习的代表算法 DQN（Deep Q-Network），剖析经验回放、目标网络、Double DQN 三个关键技巧；8.5 节系统比较表格法与函数法的权衡，给出工程选择判据；8.6 节对全章做全景式小结；8.7 节补充函数近似的策略控制——半梯度 Sarsa 与 Q-learning。平台部分：8.8 节给出"表格 vs 函数"泛化能力对比实验；8.9 节把本章概念放入中医药语境，讨论中医辨证、tcmP 平台映射与职业应用。数学上，本章主要调用第6章随机逼近（SA）与第7章 TD 的思想，读者需要熟练掌握梯度、期望与方差的运算，并将注意力集中在"表示方式的改变如何影响学习的统计性质"这一核心线索上。

## [Part2] 第8章 价值函数方法·平台导读

在 tcmP 教育平台上，本章对应"医圣成长路径"的第二个台阶：从"背医案"走向"悟规律"。平台的病证库包含 60000+ 病证单元（Disease-Symptom Unit, DSU），是典型的大状态空间——若沿用表格法，需要为每个病证单元单独维护一个价值格子，这在存储上不可行，在数据上更是永远喂不饱。平台用 TF-IDF 向量与 LLM embedding 表示病证，这些向量正是本章的特征 φ(s)；以"症状→疗效价值"为学习目标，用函数近似 v̂(φ(s),w)，就能把经验泛化到未入库的症状组合。本章的三个平台关键词请读者牢记：医圣成长路径（从查表到向量泛化的进化）、病证单元 DSU（症状=状态、方剂=动作、证据等级=奖励）、平台 API（/semantic-search 语义检索既提供监督信号也提供验证基准）。带着这三个关键词阅读全章，理论术语将在平台上有具体的落点。
