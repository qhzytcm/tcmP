## [Part1] 5.2 动机：均值估计

### 5.2.1 知识要点：期望的两种算法与大数定律

为什么全章要从"均值估计"讲起？因为价值函数定义就是期望：v_π(s) = E[G_t | S_t = s]，q_π(s,a) = E[G_t | S_t = s, A_t = a]——状态价值是回报的条件期望，动作价值是回报在给定动作下的条件期望。因此，"估计价值"在数学上就是"估计期望"，即均值估计（mean estimation）问题；把均值估计讲透，价值估计就只剩"把随机变量换成回报"这一步替换。考虑一个随机变量 X，计算 E[X] 有两条路径。路径一：模型已知时，按定义直接计算，E[X] = Σ_x p(x)x——知道 X 的分布，期望就是一串加权求和；第4章的动态规划走的正是这条路径，只不过把 Σ_x p(x)x 换成了贝尔曼方程。路径二：模型未知时，我们手里只有若干独立同分布的样本 x_1, x_2, …, x_n，于是用样本均值逼近：x̄ = (1/n)Σ_{j=1}^{n} x_j，n 越大越准，n → ∞ 时 x̄ → E[X]。两条路径的地位完全对称：一个用分布算，一个用样本估；前者精确但需要模型，后者粗糙但只需要数据——这正是第4章与本章的分界线。理解这个对称性，就理解了整个无模型学习为何"用平均替代公式"。

样本均值收敛到期望，这不是经验之谈，而是一条严格的数学定理——大数定律（law of large numbers）。设 X_1, X_2, …, X_n 是独立同分布的随机变量，公共期望 E[X] = μ 有限，则对任意给定的 ε > 0，当 n → ∞ 时，样本均值落在真值附近任意窄的区间内的概率趋于 1，即 P(|x̄_n − μ| ≥ ε) → 0。这称为弱大数定律，它断言 x̄_n 依概率收敛于 μ。直观上，平均把所有样本的随机性"摊平"了：单个样本可以偏离很远，但偏差相互抵消，n 越大抵消得越干净。大数定律只回答"是否收敛"，不回答"多快收敛"；回答速度问题的是中心极限定理：当 n 较大时，√n(x̄_n − μ) 近似服从均值为 0、方差为 σ² 的正态分布，等价地说，样本均值的标准差约为 σ/√n，其中 σ² = Var(X)。这个 1/√n 的速度极其重要：样本量翻四倍，误差标准差才减半——"想要精度翻倍，样本要乘四"。本节只需记住这个量化直觉，严格的处理留到第6章随机逼近：那里的增量均值估计与大数定律一脉相承，且会给出更一般的收敛条件。

### 5.2.2 方法与示例：抛硬币与数值演算

用两个经典例子把上面的数学变成手感。例5.2（抛硬币）：设随机变量 X 在正面时取 +1、反面时取 −1，且两种结果等概率，则 E[X] = 0。现在假设我们不知道这个分布（模型未知），只能反复抛硬币记录结果。假设 5 次抛掷得到 +1, −1, +1, +1, −1，则样本均值 x̄ = (1+1−1+1+1−1 共 5 项之和)/5 = 1/5 = 0.2；再抛 5 次，若新增结果为 +1, +1, −1, −1, +1，则前 10 次的均值变为 0.2 附近的某个值；抛到 100 次，均值会明显向 0 靠拢。这组模拟说明概率论与统计学的分工：单次抛掷的结果无法预测，但大量抛掷的平均结果可以预测——随机性在个体层面不可控，在平均层面可控。把 +1/−1 换成"方剂有效 +1、无效 −1"，同一套推理就变成了临床疗效的估计：单个病例的转归千差万别，大量病例的平均疗效却有稳定规律，这正是"大样本统计"在医学中的根基。

例5.3（骰子点数）：设 X 为一次掷骰子的点数，等概率取 1 至 6，则 E[X] = 3.5（模型已知时按定义一算即得）。模型未知时模拟掷 5 次，设结果为 2, 6, 4, 1, 5，则 x̄ = 18/5 = 3.6，与 3.5 意外接近，但这是运气；换一组结果 1, 1, 2, 3, 6，则 x̄ = 13/5 = 2.6，偏离就明显了。小样本的均值波动很大，这是正常的，不是方法错了。用中心极限定理可以量化这种波动：骰子点数的标准差 σ = √(35/12) ≈ 1.71，n = 30 条样本时样本均值的标准差为 σ/√30 ≈ 0.31，n = 100 时降为 0.17——样本量从 30 增至 100（约三倍），误差标准差只降到约一半。这个数值直接服务于 5.7 节平台实践：用 30 条病案估计疗效时，均值估计的波动幅度大约是多少、要多少样本才能把波动压到可接受范围，都可以先用这个公式估算。记住一条经验法则：估计有误差不等于估计错误，误差可度量、可随样本量压缩——"无模型"给出的从来不是确定值，而是"带误差的估计＋误差的尺度"。

误差的量化让"估计"从含糊变成可操作。给定样本均值 x̄，它距离真值 μ 有多远？中心极限定理给出近似答案：当 n 较大时，x̄ 约以 95% 的概率落在 μ ± 1.96σ/√n 之内，这个区间称为 μ 的 95% 置信区间（confidence interval）。回到骰子例子：σ ≈ 1.71，n = 30 时半宽为 1.96×1.71/√30 ≈ 0.61，即 x̄ 有 95% 的概率落在 3.5 ± 0.61 的范围内；n = 100 时半宽收窄到 0.34，n = 400 时进一步收窄到 0.17——"样本量翻四倍，区间宽度减半"与 5.2.1 节的结论完全一致。把置信区间翻译成工作语言：若两首方剂的疗效均值估计相差 0.6，而各自的标准误都是 0.31，那么这个差仅相当于约两倍标准误，还不足以令人信服——真正可信的疗效差异需要达到数倍标准误，或者加大样本量让标准误降下来。这个"信号 vs 噪声"的比值直觉，正是 5.7 节平台实践中判断"疗效差异是否可靠"的唯一依据：样本少时看到的一切差距都可能只是噪声，样本足够时微小差距也能被识别。读者务必养成一个职业习惯：任何均值估计都要附带它的标准误，否则"估计"与"猜测"没有区别；这一习惯在药企研发的疗效统计与临床医师的证据判断中同样适用。

### 5.2.3 小结与衔接

本节要点：① 价值就是期望，估计价值就是均值估计；② 期望有两种算法——模型已知按定义 Σ_x p(x)x，模型未知用样本均值 (1/n)Σ x_j；③ 大数定律保证样本均值收敛到期望，中心极限定理给出收敛速度 σ/√n；④ 误差可度量、可压缩，样本量翻四倍误差减半。易错点要反复核对：其一，样本均值是估计量，不是真值——抛 5 次硬币得 0.2，不代表期望是 0.2；其二，小样本均值可能严重偏离真值，1 至 5 条样本的均值几乎没有任何说服力；其三，不要因为"有误差"就否定估计，误差是统计世界的常态，关键是量化它；其四，大数定律要求样本独立同分布（independent and identically distributed, i.i.d.），样本之间若存在系统依赖，平均的性质就要重新考察——这一条在下一节会立刻派上用场，因为回合回报的样本并不独立。

从均值估计到价值估计只有一步替换：把随机变量 X 换成"从状态 s 出发、按策略 π 交互、得到的回报 G_t"，样本均值就变成价值估计 v̂_π(s) = (1/N)Σ G_i；把起点换成"状态 s 与动作 a"，就得到动作价值估计 q̂_π(s,a)。这正是 5.3 节 MC Basic 策略评估的全部内容。但有一个微妙差异必须预告：抛硬币的样本彼此独立，而"从同一状态出发的若干回合回报"虽然是不同回合的产物，却共享策略与环境的结构，并不严格独立——大数定律能否照用？答案是能，但需要更精细的论证，第6章随机逼近将给出一般化条件。学完本节，请自检三问：① 模型已知与模型未知，计算 E[X] 的方式有何不同？② 为什么说"四倍样本量，误差减半"？③ 如果样本均值与期望相差很远，下一步该做什么——改方法还是加样本？答案：先看样本量，样本太少时加样本，样本足够仍偏离才怀疑方法。
