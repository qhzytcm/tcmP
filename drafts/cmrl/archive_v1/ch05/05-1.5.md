## [Part1] 5.5 MC 的变体与性质

### 5.5.1 知识要点：回合/持续任务与首次/每次访问

MC 方法有若干实现细节，第一个要分清的是任务类型（task type）。回合任务（episodic task）存在终止状态，一条回合在有限步内结束，此时回报可以采用无折扣形式 G_t = R_{t+1} + R_{t+2} + … + R_T（相当于 γ = 1），因为奖励项有限、和必然有限；网格世界、棋类对弈、一次完整诊疗都属于回合任务。持续任务（continuing task）没有终止状态，交互无限进行，此时必须使用折扣回报 G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + …（γ < 1），否则奖励项无穷多、和可能发散到无穷大，价值函数失去意义；机器人长期作业、股票组合的持续管理属于持续任务。为什么这个区分对 MC 至关重要？因为 MC 的回报定义在"完整回合"上：回合任务天然提供完整的奖励序列，MC 可以直接应用；持续任务没有天然回合，MC 只能人为地把轨迹截断成片段（如固定长度窗口），截断本身就是一种近似。这个"必须等回合结束"的局限，正是后续 TD 方法（第7章）存在的重要动机之一。

第二个细节是均值统计的口径：首次访问（first-visit）与每次访问（every-visit）。同一状态（或状态-动作对）在一回合中可能出现多次，例如网格世界中智能体绕圈回到同一格子。首次访问式 MC（first-visit MC）：只统计该状态在该回合中首次出现的回报，之后再次出现的回报一律丢弃；每次访问式 MC（every-visit MC）：该状态每次出现的回报都纳入统计。两种方式的性质对比值得记牢：首次访问式估计量的期望恰为 v_π(s)（首访回报的期望就是价值定义本身），是无偏估计，理论分析最干净；每次访问式的期望也等于 v_π(s)（每个访问时点的回报期望同为价值，平均后线性保持），但它统计了同一条回合内相关的回报样本，样本之间不独立，方差表现因任务而异。两本经典教材——赵世钰《强化学习的数学原理》（5.5节）与 Sutton 与 Barto《Reinforcement Learning: An Introduction》（5.4节）——均以首次访问式为主要版本，实践中也以首次访问式更常用；每次访问式的优势是样本更多、经验利用更充分，在样本稀缺的场景值得考虑。

### 5.5.2 方法与示例：on-policy 与 off-policy、重要性采样

第三个细节是学习范式：on-policy（同轨）与 off-policy（离轨）。on-policy 学习用当前策略生成数据、学习当前策略，行为策略（behavior policy）与目标策略（target policy）是同一个策略 π；本章的 MC Basic 与 MC Exploring Starts 都是 on-policy——评估 π 就用 π 自己采样的回合。off-policy 学习则把两者分开：用行为策略 b 生成数据，学习另一个目标策略 π（b 与 π 可以不同）。为什么要引入 off-policy？动机有二。其一，探索与利用解耦：b 可以保持随机性（如 ε-贪婪，以概率 ε 随机动作）从而持续探索，而 π 可以是确定性的、趋于最优的策略，两者互不干扰——这解决了 on-policy 中"想学最优策略却又必须随机探索"的矛盾。其二，经验复用：历史数据（由旧策略、他人策略甚至教科书医案产生）不必作废，可以继续用于学习新策略——这在数据昂贵的领域（如临床病案）尤其宝贵。临床对应非常自然：现有病案库大多由"医生个人经验＋医院习惯方案"生成（行为策略 b），而我们想估计"最优辨证方案"的价值（目标策略 π），两者并不一致——这正是 off-policy 的典型场景。

当数据由 b 生成而目标是 π 时，直接平均回报是有偏的：样本来自错误分布。修正工具是重要性采样（importance sampling）：给每条回报乘上权重 ρ_t = Π_{k=t}^{T−1} π(A_k|S_k)/b(A_k|S_k)，即"目标策略产生这条轨迹的概率 ÷ 行为策略产生这条轨迹的概率"。权重的直观含义：把 b 下采集的样本"重新加权"成仿佛来自 π 的样本——若某条轨迹在 π 下比在 b 下更常见（ρ > 1），说明它对 π 更有代表性，应放大；反之缩小。普通重要性采样估计 v_π(s) ≈ (1/N)Σ_{i} ρ_i G_i，无偏但方差可能极大；加权重要性采样估计 v_π(s) ≈ (Σ ρ_i G_i)/(Σ ρ_i)，有偏但方差小得多，实践中更常用。例5.6：设动作空间 {动作1, 动作2}，目标策略 π 下动作1 的概率为 0.9，行为策略 b 下动作1 的概率为 0.1。从 b 采到一条使用动作1 的样本，其权重 ρ = 0.9/0.1 = 9——这条样本在目标策略下远比在行为策略下常见，故被放大 9 倍；若某动作在 π 与 b 下概率相同，则权重为 1，样本原样使用。两个必须强调的注意事项：其一，权重是 Π(π/b)，分子永远放目标策略、分母放行为策略，顺序颠倒会得到荒谬结果；其二，off-policy 需要覆盖性假设——凡 π(a|s) > 0 的动作，必须 b(a|s) > 0，否则某条轨迹在 b 下概率为 0 而 π 下不为 0，权重发散。本章只要求理解机制与几何直觉，完整实现与改进留待后续章节（策略梯度方法会再次见到这个权重）。

### 5.5.3 小结与衔接

MC 的变体可以整理为三张并列的"二选一"：任务类型——回合任务用无折扣回报（γ = 1 合法），持续任务必须用折扣回报（γ < 1）；统计口径——首次访问式无偏、常用、理论干净，每次访问式样本多、方差表现因任务而异；学习范式——on-policy 数据与目标同源、实现简单，off-policy 数据与目标异源、灵活但需重要性采样修正。读者应能对任意场景迅速给出选择：做临床病案统计（回合结构清晰）用 MC 直接估计；数据是别人采集的（异源）就上 off-policy 与重要性采样；状态在一回合中反复出现就考虑 first/every-visit 的取舍。把 MC 与下一章的主角 TD 做一次前瞻对比，也是本节该完成的功课：MC 无偏（不用自举）、方差大、必须等回合结束；TD 有偏（用一步后继估计，自举引入偏差）、方差小、每步都可更新。这个"无偏 vs 低方差、离线 vs 在线"的权衡是强化学习中最基本的方法论对比之一，第7章会反复展开。

回到本节要点：① γ = 1 的无折扣回报只适用于回合任务，持续任务必须折扣；② first-visit 与 every-visit 都是渐近一致的，first-visit 无偏更常用；③ on-policy 数据与目标同策略，off-policy 数据来自行为策略 b、目标为 π；④ 重要性采样权重 ρ = Π(π/b) 修正分布偏移，加权版本方差更小；⑤ off-policy 需要覆盖性假设。易错点复核：持续任务忘折扣、权重分子分母颠倒、覆盖性不满足——这三点是 MC 实现中最高频的错误。衔接第6章：随机逼近（Stochastic Approximation, SA）把"样本均值"升级为增量更新 wk+1 = wk + α_k(xk − wk)，给出步长序列的收敛条件，为 TD 铺路；第7章 TD 用"一步评估＋增量更新"同时克服 MC 的高方差与回合依赖，可视为价值迭代的增量近似。学完本节，请自检三问：① 持续任务为什么必须用折扣回报？② 一条回合中状态重复出现时，first-visit 与 every-visit 的结果为何可能不同？③ 为什么 off-policy 估计不能直接平均回报，而必须乘重要性权重？
