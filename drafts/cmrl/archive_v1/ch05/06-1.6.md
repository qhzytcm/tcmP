## [Part1] 5.6 本章小结

### 5.6.1 知识要点：范式、算法与记号回顾

本章确立了无模型学习的完整范式：没有模型，就用数据。全部内容可以压缩成一条公式链：价值是回报的期望（v_π(s) = E[G_t | S_t = s]，q_π(s,a) = E[G_t | S_t = s, A_t = a]）→ 期望可用样本均值逼近（x̄ = (1/n)Σ x_j，由大数定律保证收敛）→ 把随机变量换成回报，样本均值就变成价值估计（v̂_π(s) = (1/N)Σ G_i）→ 估计价值之后按 argmax 贪婪改进，形成"评估—改进"循环。链条上的每一环都在本章有对应小节：5.2 节建立"价值=期望、期望=平均"的统计基础；5.3 节 MC Basic 把平均套到回报上，成为策略迭代的数据化版本；5.4 节 MC Exploring Starts 用探索起点与沿途更新解决 Basic 的低效；5.5 节处理任务类型、统计口径与学习范式的变体。需要记住的记号清单：回合 episode、终止状态 S_T、回报 G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + …、访问计数 N(s,a)、价值估计 q̂(s,a)、首次访问与每次访问、行为策略 b 与目标策略 π、重要性权重 ρ_t = Π_{k=t}^{T−1} π(A_k|S_k)/b(A_k|S_k)。读者应能不看笔记说出每一个记号的定义与用途——它们是后续一切无模型算法的公共词汇。

算法之间的关系用一句话即可锚定：MC Basic 是"策略迭代的数据化"——用采样估计替代模型求解；MC Exploring Starts 是"MC Basic 的样本复用化"——一条回合沿途更新所有被访问的 (s,a)，把每条回合的样本产出从 1 提升到多个。若画一张 DP 与 MC 的对照表（建议读者自己动手画），行应该包括：评估的数据来源（模型 vs 样本）、是否要求完整回合（DP 否，MC 必须）、是否自举（DP 是——用后继价值估计当前价值；MC 否——只用自身回报样本）、估计性质（DP 精确，MC 无偏低方差）、收敛方式（DP 有限步或几何收敛，MC 依概率渐近收敛）、探索需求（DP 无，MC 必须保证每个 (s,a) 被访问）。这张表是本章最重要的复习载体：每一行对应一个概念，能画出来、能解释每一格，就说明真正掌握了 MC 与模型类算法的分界线。

### 5.6.2 方法与示例：例题串联与决策树

把三节例题串成一条线，可以最直观地看到"同一个思想、不同组织方式"的威力。5.2 节抛硬币：X 取 +1/−1 等概率，E[X] = 0，5 次样本均值 0.2、10 次 0.4、100 次向 0 靠拢——这是"平均收敛"的最小演示。5.3 节 MC Basic：从 (s1, 右) 出发生成 3 条回合，回报 −1, +1, −1，q̂ = −1/3，真值 0——样本均值在价值估计上的直接套用。5.4 节 MC ES：一条回合 s1→s2→s3→s9 沿途产生 3 个 (s,a) 样本，γ = 0.9 时回报分别为 0.81、0.9、1——一条回合的样本产出从 1 变成 3，折扣的含义也一并演示。三步串下来，读者应能回答：同样的"取平均"，抛硬币、Basic、ES 三处分别平均的是什么？答案：随机变量 X 的观测、从固定 (s,a) 出发的回合回报、沿途各 (s,a) 的剩余回报——平均的对象变了，平均的数学（大数定律）没变。这就是"统计基础—概念原型—实用算法"三层递进的最佳注脚。

面对一个具体问题如何选择变体？决策树如下。第一步问：任务有终止状态吗？有（回合任务）→ 可用无折扣回报；没有（持续任务）→ 必须折扣回报，且要考虑轨迹截断。第二步问：数据来源与学习目标一致吗？一致 → on-policy，直接用 MC Basic 或 ES；不一致（如数据是历史病案、目标是新方案）→ off-policy，必须引入重要性采样修正。第三步问：状态在回合中会重复出现吗？会且样本珍贵 → 考虑 every-visit 多采样本；不会或追求理论干净 → first-visit。第四步问：状态-动作对数量大吗？大 → 用 ES 的沿途更新提高样本利用率，而不是 Basic 的逐对采样。把这棵决策树走一遍，任何 MC 应用场景都能迅速定位到正确的算法组合。经验法则再补一句：无偏性（MC 的优势）在样本充足时价值最大；样本稀缺时，宁可引入一点偏差换取方差降低——这条法则将直接通向第7章的 TD。

把本章最常见的错误列成一张排查清单，供读者完成习题与平台实验时对照。错误一：回报漏乘折扣——γ < 1 时回报是逐项折现的加权和，最后一步奖励的权重是 γ^{T−1}，用无折扣公式计算持续任务的回报必然出错。错误二：平均对象混淆——MC Basic 平均的是"从 (s,a) 出发的回合回报"，MC Exploring Starts 平均的是"沿途各 (s,a) 的剩余回报"，两者混用会得到张冠李戴的估计。错误三：回合中途更新策略——样本来自混合策略，估计的就不再是单一策略的价值，随后的策略改进也随之失真。错误四：增量更新顺序颠倒——q ← q + (G − q)/N 中 N 必须先加 1 再作分母，先除后加等于每次都除以旧计数，估计会系统性偏离。错误五：首次访问与每次访问混用且不注明——同一份数据两种口径的结果可能不同，报告与论文必须声明采用哪种口径。错误六：off-policy 场景直接平均回报——数据由行为策略 b 生成、目标却是策略 π 的价值时，不加重要性权重 ρ = Π(π/b) 的均值是有偏的。这六条覆盖了 MC 从公式到代码再到平台实验的全部高频雷区，读者可在 5.7 节实验的验收清单中逐项核对；每一条都能在 5.2 至 5.5 节找到对应的理论根源——排查错误的过程，就是把公式重新理解一遍的过程。

### 5.6.3 小结与衔接：局限与后续

MC 方法的三条局限必须正视。其一，方差大、收敛慢：回报是整条轨迹随机性的叠加，误差按 1/√n 的速度收缩，想要精度翻倍需要样本乘四——这是 5.2 节就埋下的伏笔，也是 MC 在大规模问题上显得"笨重"的根本原因。其二，回合内无法更新：必须等回合结束才能获得回报，持续任务需要人为截断，在线学习的实时性差。其三，探索起点假设强：MC Basic 与 MC ES 都要求能够从任意 (s,a) 开始采样，真实系统中这个能力常常不存在。这三条局限决定了 MC 的适用场景画像：回合结构清晰、样本获取成本可接受、需要无偏估计的教学与统计任务——例如本章 Part2 的病案疗效统计：一次诊疗天然是一回合，30 条医案可以跑完整个算法，无偏性保证疗效估计"平均起来不偏"。对实时性要求高的场景（在线辨证辅助、动态用药调整），MC 需要让位给第7章的 TD。

把本章放进全书地图。第4章是"模型类"时代的终点：三个 DP 算法在模型已知的假设下精确求解。本章是"数据化"的第一步：MC 卸下模型假设，用采样重做策略评估——它是策略迭代的数据化。第6章随机逼近回答"如何用一条新样本就地更新估计"（增量均值 wk+1 = wk + α_k(xk − wk)，步长条件 Σα_k = ∞ 且 Σα_k² < ∞），为 TD 提供数学内核。第7章时序差分把"一步评估＋增量更新"结合，可视为价值迭代的增量近似：它克服 MC 的高方差（每步只用一步噪声）与回合依赖（每步都可更新），代价是引入自举偏差。整条线索是：模型类（第4章）→ 数据化（MC，本章）→ 增量数据化（TD，第7章）→ 表征学习（深度 RL）。带着这张地图进入章末 Part2：读者将在 tcmP 平台上用真实病案数据亲手复现"平均收敛"——把 5.2 至 5.4 节的数学，变成一张可以运行、可以解释的疗效估计表。
