## [Part1] 5.3 MC Basic 算法

### 5.3.1 算法思想：策略迭代的数据化

MC Basic 是第4章策略迭代（Policy Iteration, PI）的直接改造，改造点只有一个：策略评估的数据来源。先回顾 PI 的两步循环：第一步策略评估，求解给定策略 π_k 的贝尔曼方程 v_{π_k} = r_{π_k} + γP_{π_k} v_{π_k}，得到精确价值；第二步策略改进，贪婪更新 π_{k+1}(s) = argmax_a q_{π_k}(s,a)。问题在于，方程里的 r_{π_k} 与 P_{π_k} 来自模型，模型未知时方程根本写不出来。MC Basic 的改造方案朴素而彻底：既然 v_π(s) = E[G_t | S_t = s]，那就用样本估计——从状态 s 出发按策略 π 生成 N 条完整回合，记录每条回合的回报 G_1, G_2, …, G_N，取平均得 v̂_π(s) = (1/N)Σ_{i=1}^{N} G_i；对动作价值同理，从状态-动作对 (s,a) 出发生成回合，取回报平均得 q̂_π(s,a)。于是"解方程组"被"跑回合取平均"替代，模型的角色由经验承担，其余结构原封不动：仍然是评估—改进循环，仍然迭代到策略稳定。这就是"策略迭代的数据化"的含义——读者应能逐行指出：MC Basic 的每一步对应 PI 的哪一步，哪里换了原料，哪里没动。

为什么这个算法叫"Basic"？因为它是概念上最直接的无模型算法：不做任何工程优化，把"用样本估计价值"这一思想原样实现，是理解一切后续 MC 变体的起点。它同时暴露了无模型学习遇到的第一个本质困难——探索（exploration）问题：为了估计 q_π(s,a)，每个状态-动作对 (s,a) 都必须被访问至少一次；一个从未被访问过的 (s,a)，没有任何样本，价值估计无从谈起。在 MC Basic 中，探索问题被"强制绕开"：评估阶段规定从每个 (s,a) 出发分别生成回合，相当于假设我们能随意设定起始状态与起始动作——这个假设在网格世界成立（可以把智能体放到任意格子），但在真实问题中常常不成立（临床诊疗不可能人为制造一个"错误起点"）。因此，MC Basic 的意义在于建立概念框架，而它的低效与探索困难，将在 5.4 节由 MC Exploring Starts 部分解决，并在后续章节（ε-贪婪等软策略）中继续演化。

### 5.3.2 实现步骤：伪代码与元素形式

MC Basic 的伪代码可以写成如下形式（算法5.1，记号沿用本书统一约定）。输入：可交互的环境（无需模型）、初始策略 π_0、每轮每个 (s,a) 的评估回合数 N、迭代轮数 K。对 k = 0, 1, 2, …, K−1：策略评估——对每个状态 s 与每个动作 a，执行 i = 1, 2, …, N：从 (s,a) 出发，按 π_k 生成一条完整回合至终止状态，记录回报 G_i；然后置 q̂_k(s,a) = (1/N)Σ_{i=1}^{N} G_i；策略改进——对每个状态 s，置 π_{k+1}(s) = argmax_a q̂_k(s,a)。输出：策略 π_K。回报按定义逐项累加：从 t 时刻的 (s,a) 出发，G_t = R_{t+1} + γR_{t+2} + γ²R_{t+3} + … + γ^{T−1−t}R_T（γ = 1 时即奖励总和）。注意三个实现细节：其一，评估与改进必须分离，先用旧策略 π_k 采完全部样本再更新策略，不能在一条回合的进行中半途换策略；其二，平均的分母是实际回合数 N，不是状态空间的规模；其三，每轮评估需要 |S|·|A|·N 条回合，这是复杂度分析的基本单位。

用 3×3 网格世界手算一遍（例5.4，γ = 1，策略 π 为"总是向右"，边界弹回，s6 禁区 −1，s9 目标 +1）。估计 q_π(s1, 右)：从 (s1, 右) 出发生成 3 条回合——回合①：s1→s2→s3→s6，奖励序列 0, 0, −1，回报 G = −1；回合②：s1→s2→s3→s9，奖励序列 0, 0, +1，回报 G = +1；回合③：同回合①，回报 G = −1。于是 q̂_π(s1, 右) = (−1 + 1 − 1)/3 = −1/3。注意真值由转移概率决定：若"从 s3 向右"落入 s6 与 s9 的概率各为 0.5，则真值 q_π(s1, 右) = 0.5×(−1) + 0.5×(+1) = 0，样本均值 −1/3 是它的带噪声估计。策略改进时，若 q̂_π(s1, 右) 是 s1 处各动作估计中的最大值，则 π 在 s1 保持不变，否则换动作。这个例子透露出数据版与模型版的本质差别：模型版给出精确值 0，改进决策万无一失；数据版给出噪声值 −1/3，改进决策可能被噪声误导——这就是"有限样本下策略可能震荡"的根源，也是后续第6、7章引入增量更新与更低方差方法的原因之一。

### 5.3.3 收敛与性质：无偏性与探索困境

MC 估计的收敛性建立在两个数学事实上。第一，无偏性：对固定策略 π，从 (s,a) 出发的一条回合回报 G_t 满足 E[G_t | S_t = s, A_t = a] = q_π(s,a)——这是动作价值的定义本身；因此样本均值 q̂_π(s,a) = (1/N)Σ G_i 的期望等于 q_π(s,a)，即 E[q̂_π(s,a)] = q_π(s,a)，估计量无偏（unbiased）。第二，大数定律：N → ∞ 时样本均值依概率收敛到期望，即 q̂_π(s,a) → q_π(s,a)。无偏性保证"平均起来不偏不倚"，大数定律保证"样本够多时误差消失"，两者合起来构成 MC 策略评估的全部理论依据；对状态价值 v_π(s) 的估计完全同理。至于策略改进步骤，在"估计足够准"的极限下，MC Basic 与 PI 的行为一致（由第4章策略改进定理保证价值单调不降）；但在有限样本下，估计噪声可能使"改进"实际上是"错改"，策略在最优附近震荡。因此 MC Basic 的收敛性结论应表述为：随着每轮评估的回合数 N 与迭代轮数 K 同时增大，π_K 以概率趋向最优策略——这是"统计一致性"意义上的收敛，与 PI 的"有限步精确收敛"有本质区别。

MC Basic 的最大问题是低效。为估计一个 (s,a) 的价值，需要专门从它出发生成 N 条完整回合；一轮评估要对全部 |S|·|A| 个状态-动作对分别采样，总共 |S|·|A|·N 条回合。若 |S| = 100、|A| = 5、N = 100，则一轮评估就要 50000 条回合，而每条回合只贡献一个 (s,a) 的样本——样本利用率极低。更浪费的是，一条回合明明经过了若干 (s,a)，这些"顺路经过"的样本却被丢弃了。这引出了 5.4 节的改进思路：让一条回合沿途更新所有被访问过的 (s,a)，把"每条回合一个样本"变成"每条回合多个样本"。在离开本节前，请记住三个易错点：① 回合必须完整走完才能计算回报，MC 是"离线式"学习，回合进行中不能就地更新（这是它与第7章 TD 的分水岭）；② γ < 1 时回报按步折现，最后一步奖励的权重是 γ^{T−1}，不要漏乘；③ 估计价值用样本均值 (1/N)ΣG_i，分母是回合数 N，不要与状态数混淆。自检三问：① MC Basic 的两步分别对应 PI 的哪两步？② 为什么每个 (s,a) 都必须被访问？③ 有限样本下，策略改进为什么可能"错改"？
