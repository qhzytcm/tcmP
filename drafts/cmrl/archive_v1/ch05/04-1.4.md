## [Part1] 5.4 MC Exploring Starts 算法

### 5.4.1 算法思想：探索起点技巧

MC Basic 概念清晰，但效率之低一眼可见：为了估计一个 (s,a) 的价值，要专门从它出发生成 N 条完整回合；一轮评估要为全部 |S|·|A| 个状态-动作对分别采样，总回合数达到 |S|·|A|·N。可是一条回合明明沿途经过了若干 (s,a)，这些"顺路经过"的样本却被白白丢弃了——样本利用率极低。MC Exploring Starts（探索起点）算法针对的正是这个浪费：不再强制从每个 (s,a) 分别开始，而是从随机选择的状态-动作对开始一条回合，沿途更新所有被访问过的 (s,a) 的动作价值估计。为什么可以这样？因为对回合中任意时刻 t，从 (S_t, A_t) 之后的剩余折扣奖励 G_t = R_{t+1} + γR_{t+2} + … 恰好就是该 (s,a) 的回报样本：它携带了"从这个状态执行这个动作能走多远、拿多少奖励"的全部价值信息。一条回合 s0→s1→s2→…→sT 会产生一串 (s,a) 样本，每个样本对应一个不同的时刻，一次采样、多处受益——这正是 MC ES 提高样本利用率的机理。

MC ES 的名字来自它的核心假设——探索起点（exploring starts）：回合的初始状态-动作对 (S_0, A_0) 从所有状态-动作对中随机选取，至少保证每个 (s,a) 都有无穷多次成为起点的机会。在这个假设下，每个 (s,a) 都会被访问无穷多次，探索问题在理论上被彻底解决：没有任何 (s,a) 会被永久冷落，全部 q 值都能得到样本支持。需要清醒认识的是这个假设的现实性：在网格世界等仿真环境里，我们确实可以"把智能体放到任意格子、命令它先做任意动作"，探索起点成立；但在真实系统中，初始条件往往不可控——临床诊疗不可能人为制造"错误起点"让患者从某个奇怪的状态开始治疗，自动驾驶不可能故意把车开进危险场景。因此，探索起点的严格版本是教学与理论的理想化假设，工程实践中通常改用软策略（如 ε-贪婪，以概率 ε 随机探索）保证所有 (s,a) 被访问——这一工程化改造将在第7章及以后展开。本章先在假设下把算法讲清楚，读者应理解：MC ES 的"探索"问题并未消失，只是被假设暂时搁置了。

### 5.4.2 实现步骤：访问计数与样本均值

MC Exploring Starts 的伪代码如下（算法5.2，赵世钰《强化学习的数学原理》算法5.2，记号与算法5.1一致）。初始化：对全部 (s,a)，动作价值 q(s,a) 取任意初值（如 0），访问计数 N(s,a) = 0，策略 π(s) 取任意初值。对每一轮迭代：第一步，选择探索起点——从 (S, A) 空间中随机选取初始状态 S_0 与初始动作 A_0；第二步，按当前策略 π 生成一条完整回合 S_0, A_0, R_1, S_1, A_1, R_2, …, R_T, S_T；第三步，沿回合反向或正向计算每个时点的回报，并对每个访问过的 (S_t, A_t)：G_t = R_{t+1} + γR_{t+2} + … + γ^{T−1−t}R_T；N(S_t, A_t) ← N(S_t, A_t) + 1；q(S_t, A_t) ← q(S_t, A_t) + [G_t − q(S_t, A_t)]/N(S_t, A_t)；第四步，策略改进——对每个状态 s，π(s) ← argmax_a q(s,a)。重复第一至第四步，直到策略不再变化或达到回合预算。注意第三步的更新式是增量形式的样本均值：q 的初值若为 0，则更新 k 次之后 q 恰好等于 k 条回报的算术平均，读者可以自行展开验证（归纳法：q_k = (1/k)Σ_{i=1}^{k} G_i）。

用 3×3 网格世界手算一遍（例5.5，γ = 1，策略"总是向右"）。设随机起点落在 s1，第一条回合为 s1→s2→s3→s9（s9 得 +1 后终止，奖励序列 0, 0, +1）。这条回合沿途访问了三个状态-动作对：(s1, 右)、(s2, 右)、(s3, 右)。无折扣时，三个时点的回报都是 +1（剩余奖励总和相同），因此三个 (s,a) 各得到一个 +1 样本——一条回合产生 3 个样本，而 MC Basic 需要 3 条独立回合才能获得同样多的样本。若取 γ = 0.9，情况就更有味道：(s3, 右) 的回报 = +1；(s2, 右) 的回报 = 0.9×1 = 0.9；(s1, 右) 的回报 = 0.9²×1 = 0.81——越早的决策，其回报折扣越重，这直观体现了 γ 的含义：远期奖励对早期决策的价值贡献被逐级衰减。再演示增量更新：假设此前 (s1, 右) 已有 2 个样本、q = 0.5、N = 2，则更新后 N = 3，q ← 0.5 + (1/3)(1 − 0.5) = 2/3，恰为三条回报 (0.5×2 + 1)/3 的算术平均。读者应把这个手算过程与伪代码逐行对应，直到"一条回合如何变成多个样本"成为本能。

### 5.4.3 收敛与性质：无偏性、无自举与方差

MC 估计的性质可以列成一张清单，每一条都值得与第4章的 DP 对照着记。其一，无偏性：每个被访问的 (s,a) 的回报 G_t 都是 q_π(s,a) 的无偏观测，因为 E[G_t | S_t = s, A_t = a] = q_π(s,a) 是动作价值的定义本身；增量均值是这些无偏观测的平均，期望仍为 q_π(s,a)，故 q(s,a) 无偏。其二，不需要模型：全程只使用采样得到的经验，转移概率与奖励函数从未出现——这是"无模型"三个字的落实。其三，不需要自举（bootstrapping）：估计 q_π(s,a) 时只依赖该 (s,a) 自己的回报样本，绝不使用后继状态的价值估计——第4章的 DP 用 v(s′) 估计 v(s)（自举），第7章的 TD 也用一步后继估计（自举），而 MC 完全没有这一依赖，这是 MC 区别于 DP 与 TD 的标志性特征；自举与否直接决定了偏差与方差的权衡，后面会反复用到。其四，代价是方差大：一条回合的回报是沿途每一步随机性（随机转移与随机奖励）的叠加，噪声随回合长度累积；与 DP 的确定性递推相比，MC 的每个估计都带着整条轨迹的随机波动。

收敛性的直观论证如下：对每个 (s,a)，探索起点保证访问次数 N(s,a) 随迭代趋于无穷；在策略固定阶段，由大数定律，q(s,a) → q_π(s,a)；当估计足够准后，策略改进进入良性循环：改进得到的策略优于旧策略（策略改进定理的精神在无偏估计下依然成立），价值随迭代上升，最终在统计意义上收敛到最优策略。必须强调"统计意义"四个字：有限样本下，方差使估计波动，策略可能在最优附近长时间震荡——这正是 MC 与 PI 的收敛性表述的差异所在（PI 有限步精确收敛，MC 依概率渐近收敛）。缓解手段有三：增大每轮回合数（代价是回合预算）、在回报计算中取合适的 γ（γ 越小噪声放大越弱，但远见也越短）、或改用第7章的低方差方法。离开本节前记住三个易错点：① 增量更新中，N 必须先加 1 再用作分母，先除后加会得到错误结果；② 一条回合中同一 (s,a) 可能出现多次（如状态回环），按"每次访问"还是"首次访问"统计，效果不同，详见 5.5 节；③ 策略更新必须在整条回合的回报统计完毕之后进行——回合中途更新会使样本来自混合策略，估计的就不再是单一策略的价值。
