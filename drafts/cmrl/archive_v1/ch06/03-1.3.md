## [Part1] 6.3 Robbins-Monro 算法

### 6.3.1 算法思想：在噪声观测下求根

随机逼近的经典理论是 Robbins-Monro（RM）算法，它解决如下问题：求方程 g(w) = 0 的根，但函数 g 本身未知，只能获得带噪声的观测。具体地说，存在某个未知函数 g: R → R，其根 w* 满足 g(w*) = 0；对任意输入 w，我们无法直接读出 g(w) 的精确值，只能观测到 g̃(w, η) = g(w) + η，其中 η 是均值为零的噪声。这个设定被称为"无模型条件"：没有 g 的解析表达式，只有噪声观测的"黑箱"访问。现实中的例子俯拾皆是：想求"使期望疗效为零的用药剂量"，但每次用药的疗效都受个体差异干扰；想求"使预期收益最大化的定价"，但每次交易都有随机波动。RM 算法给出的迭代格式极其简洁：w_{k+1} = w_k − a_k·g̃(w_k, η_k)，其中 a_k > 0 是步长。直觉是：若当前 w_k 在根的右侧（g(w_k) > 0），则 g̃ 平均为正，减去 a_k·g̃ 使 w 减小、向根靠拢；若 w_k 在根左侧（g(w_k) < 0），则减去一个负值使 w 增大、同样向根靠拢。噪声 η 使每一步的方向未必准确，但步长递减可以逐步"平均掉"噪声的影响——这正是下一小节 RM 定理要严格化的直觉。

RM 迭代与 6.2 节的增量均值估计之间的承接关系值得先点明。取 g(w) = w − E[X]，则 g(w) = 0 的解是 w = E[X]，求根问题退化为均值估计问题；噪声观测取 g̃(w, x) = w − x（把单次样本 x 视为对 E[X] 的噪声观测），代入 RM 迭代得 w_{k+1} = w_k − a_k(w_k − x_k) = w_k + a_k(x_k − w_k)，当 a_k = 1/k 时正是增量均值估计。也就是说，6.2 节的增量均值估计是 RM 算法在"g 为线性函数"时的特例，而 RM 算法把增量更新的思想推广到了任意未知函数 g。反过来，RM 定理的两个收敛条件（6.3.3 小节）也解释了为什么增量均值估计的步长必须取 1/k：这个步长序列恰好满足定理条件。读者应把 6.2 节与本节视为同一思想的"特例与一般"关系，而不是两个独立话题。

### 6.3.2 实现步骤：从矩阵形式到元素形式

RM 算法的实现步骤可以规范为四步。第一步，明确目标：把待求解的问题写成 g(w) = 0 的形式，并确认只能获得噪声观测 g̃(w, η) = g(w) + η 而非精确的 g(w)。第二步，设定初值与步长：选定初始估计 w_1 与步长序列 {a_k}，步长须满足 6.3.3 小节的两个收敛条件（经典选择 a_k = 1/k）。第三步，迭代更新：对 k = 1, 2, 3, …，观测 g̃(w_k, η_k)，计算 w_{k+1} = w_k − a_k·g̃(w_k, η_k)。第四步，判断停止：由于 w* 未知，无法用"误差小于 ε"作为停止准则，工程上常用"相邻两步之差小于阈值"或"固定迭代轮数"停止，并输出 w_{k+1} 作为 w* 的估计。矩阵-向量形式适合理论分析：当 w 是向量时，g: R^n → R^n，g̃(w, η) = g(w) + η 逐分量成立，迭代格式不变，只是每个符号都从标量变为向量。元素形式适合编程实现：对 w 的第 i 个分量，w_{i,k+1} = w_{i,k} − a_k·g̃_i(w_k, η_k)，其中 g̃_i 是 g̃ 的第 i 个分量；不同分量的更新共用同一个步长 a_k，但在同一时刻读取相同的旧向量 w_k（同步更新）。

用两个数值例子展示实现细节。例一（线性求根）：求解 g(w) = w − 3 = 0，设噪声 η ~ N(0, 1)，即观测 g̃(w, η) = w − 3 + η。取 w_1 = 0，a_k = 1/k。k = 1：观测 g̃(0, η_1) = −3 + η_1，w_2 = 0 − 1×(−3 + η_1) = 3 − η_1；若 η_1 = 0.5，则 w_2 = 2.5。k = 2：观测 g̃(2.5, η_2) = −0.5 + η_2，w_3 = 2.5 − (1/2)(−0.5 + η_2) = 2.75 − η_2/2；若 η_2 = −0.4，则 w_3 = 2.95。可以看到：每步都在真值 3 附近修正，且修正幅度随步长递减。例二（均值估计回放）：X 取值 {1, −1} 各半（期望为 0），观测序列 x_1 = 1, x_2 = 1, x_3 = −1, x_4 = −1。取 g(w) = w − E[X] = w，g̃(w, x) = w − x，a_k = 1/k。w_1 = 1；处理 x_2 = 1：w_3 = 1 + (1/2)(1−1) = 1；处理 x_3 = −1：w_4 = 1 + (1/3)(−1−1) = 1/3；处理 x_4 = −1：w_5 = 1/3 + (1/4)(−1−1/3) = 0。四个样本的平均恰好是 0，增量估计也在第 4 步精确到达 0——再次印证与全量平均的等价性。

### 6.3.3 收敛与性质：RM 定理的两个条件

RM 算法收敛性的严格表述是 RM 定理，其核心结论是：在 g 满足一定正则条件（如对任意 w ≠ w*，有 (w − w*)g(w) > 0，即 w 在根左侧时 g 为负、在右侧时 g 为正，保证迭代方向正确）的前提下，若步长序列 {a_k} 同时满足两个条件，则 w_k 以概率 1 收敛到根 w*。条件①：Σ_{k=1}^∞ a_k = ∞，即步长之和发散；条件②：Σ_{k=1}^∞ a_k² < ∞，即步长平方和收敛。经典步长 a_k = 1/k 同时满足两个条件：调和级数 Σ(1/k) 发散到无穷，而 Σ(1/k²) 收敛到 π²/6。两个条件的直觉理解至关重要，且缺一不可。条件①保证估计能"走到任意远"：若步长之和有限，则总更新幅度有限，初始估计与真值相差较大时，迭代会被"步长预算"困住，永远无法到达真值——就像远足者的总路程被限额卡死，目标再近也走不到。条件②保证噪声能被"平均掉"：若步长平方和发散，则噪声 η 造成的累积扰动方差发散，估计会一直在真值附近剧烈抖动而无法稳定——就像远足者每一步的步幅都过大且不衰减，即使方向总体正确，也被随机扰动推得东倒西歪。

"缺一不可"还可以用两个反例体会。反例一（只满足①，不满足②）：取 a_k = 1/√k，则 Σa_k = ∞ 但 Σa_k² = Σ(1/k) = ∞，条件①满足而条件②不满足。此时步长衰减太慢，噪声扰动累积方差发散，RM 迭代不收敛：直观上，虽然总步幅无限、方向总体正确，但每一步的随机偏差都在同一量级上累积，估计在真值附近的波动范围随 k 增大而增大。反例二（只满足②，不满足①）：取 a_k = 1/k²，则 Σa_k² 收敛但 Σa_k = ∞？——不，Σ(1/k²) 收敛且 Σa_k = Σ(1/k²) < ∞，条件①不满足。此时步长衰减过快，迭代在到达真值之前就已经"走不动了"：直观上，估计的初始修正幅度足够大吗？若 w_1 远离 w*，则总更新幅度 Σa_k·|g̃| 有限，估计会停在某个与初值有关的中间位置，永远到不了根。这两个反例说明：步长序列必须"慢到能走远，快到能平噪"——这就是 RM 定理两个条件的全部含义。读者应把这两个条件背下来并牢记直觉，因为第7章 TD 算法的收敛性将原样复用它们：TD 更新中的步长（学习率）序列若违反任一条件，价值估计就不会收敛到真实价值函数。
