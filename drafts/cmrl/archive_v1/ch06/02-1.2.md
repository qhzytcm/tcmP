## [Part1] 6.2 增量均值估计

### 6.2.1 知识要点：从非增量均值到增量均值

本节用最简单的均值估计问题演示"非增量 → 增量"的转换，它是全章所有增量算法的原型。考虑随机变量 X，它服从某个未知分布，我们想估计它的期望 E[X]。非增量方法：收集全部样本 {x_1, x_2, …, x_n} 之后，一次性计算样本均值 x̄_n = (1/n)Σ_{i=1}^{n} x_i，把 x̄_n 作为 E[X] 的估计。这个方法的缺点显而易见：样本很多时要等待很久才能得到第一个估计值；若样本是流式到达的（例如在线传感器数据、逐日累积的病案），就必须全部保存下来，内存与延迟都不可接受；更关键的是，估计过程与数据到达过程完全脱节——新样本到达时，旧估计不会自动更新。增量方法：维护一个估计值 w_k（k 表示已经处理过的样本数），每来一个新样本 x_k，就地更新 w_{k+1} = w_k + (1/k)(x_k − w_k)。这个式子读作：新估计 = 旧估计 + 步长 × (新样本 − 旧估计)。其中 (1/k) 是步长（step size），(x_k − w_k) 是新样本与旧估计的误差（error）。每处理一个样本，估计值就朝新样本方向移动一小步，移动的幅度由步长控制。

增量公式与全量平均完全等价，这一点必须亲手验证。展开递推：w_2 = w_1 + (1/1)(x_1 − w_1)。取 w_1 = x_1，则 w_2 = x_1 + (x_1 − x_1) = x_1 = (x_1 + x_2)/2？——注意此处取 w_1 = x_1 时，k = 1 的更新式 w_2 = w_1 + (1/1)(x_1 − w_1) 给出 w_2 = x_1，而正确的两步均值应为 (x_1 + x_2)/2，看似矛盾。关键在于起始约定：增量均值估计通常从 w_1 = x_1 出发（用第一个样本初始化），之后第 k 步（k ≥ 2）的更新式为 w_{k+1} = w_k + (1/k)(x_k − w_k)，即处理第 k 个样本时步长为 1/k。按此约定：w_2 = w_1 + (1/1)(x_1 − w_1) 这一步不执行（因为 x_1 已用于初始化），直接从 k = 2 开始：w_3 = w_2 + (1/2)(x_2 − w_2)。归纳可得 w_{k+1} = (1/k)Σ_{i=1}^{k} x_i，与全量平均完全等价。这个等价性说明：增量更新不是全量平均的"近似"，而是它的另一种等价实现——只是改变了"什么时候算"。

### 6.2.2 方法与示例：归纳证明与数值演算

用归纳法严格证明等价性，避免符号混乱。命题：若 w_1 = x_1，且对 k ≥ 2 有 w_{k+1} = w_k + (1/k)(x_k − w_k)，则 w_{k+1} = (1/k)Σ_{i=1}^{k} x_i。归纳基础：k = 1 时 w_2 = (1/1)Σ_{i=1}^{1} x_i = x_1 = w_1，成立（约定第 1 步不更新）。归纳步：假设 w_k = (1/(k−1))Σ_{i=1}^{k−1} x_i，代入更新式得 w_{k+1} = (1/(k−1))Σ_{i=1}^{k−1} x_i + (1/k)(x_k − (1/(k−1))Σ_{i=1}^{k−1} x_i) = (1/(k−1))·(1 − 1/k)·Σ_{i=1}^{k−1} x_i + (1/k)x_k = (1/k)Σ_{i=1}^{k−1} x_i + (1/k)x_k = (1/k)Σ_{i=1}^{k} x_i。证毕。注意这个证明的数学含义：步长 1/k 并非随意选取，它是"使每一步更新后的估计恰好等于当前全部样本的均值"的唯一选择——当第 k 个样本到来时，旧估计 w_k 代表前 k−1 个样本的平均，新样本的权重应为 1/k，旧平均的权重相应降为 (k−1)/k，这正是 1/k 步长的几何意义。若改用常数步长 α，则新估计是历史样本的指数加权平均而非算术平均，旧样本的影响永不消失。

用一个数值例子让公式"活"起来。假设观测序列 x_1 = 2, x_2 = 4, x_3 = 6, x_4 = 8（期望为 5 的分布的一个样本实现）。非增量方法：攒齐 4 个样本后计算 x̄ = (2+4+6+8)/4 = 5。增量方法：w_1 = x_1 = 2；处理 x_2：w_3 = w_2 + (1/2)(x_2 − w_2)，其中 w_2 = w_1 = 2（第 1 步不更新），故 w_3 = 2 + (1/2)(4−2) = 3；处理 x_3：w_4 = 3 + (1/3)(6−3) = 4；处理 x_4：w_5 = 4 + (1/4)(8−4) = 5。观察估计轨迹 2 → 3 → 4 → 5：每一步都在朝真值靠拢，且步长递减使后续更新越来越"谨慎"。若用常数步长 α = 0.5：w_2 = 2，w_3 = 2 + 0.5×(4−2) = 3，w_4 = 3 + 0.5×(6−3) = 4.5，w_5 = 4.5 + 0.5×(8−4.5) = 6.25——估计越过真值继续攀升，因为常数步长让旧样本的影响按几何级数衰减、永不归零。这个对比预告了全章的主题：步长序列的选择决定增量算法的收敛行为。

### 6.2.3 小结与衔接

本节的核心收获可以概括为四个层次。第一层（公式层）：增量均值估计 w_{k+1} = w_k + (1/k)(x_k − w_k) 与全量平均 (1/k)Σ_{i=1}^{k} x_i 完全等价，前者是后者的流式实现。第二层（结构层）：更新式可写为"新估计 = 旧估计 + 步长 × (新样本 − 旧估计)"，这个"估计 + 步长 × 误差"的结构是所有增量学习算法的共同骨架，后续的 RM 算法、TD 算法、SGD 都是同一骨架的不同实例。第三层（步长层）：步长序列 {1/k} 随时间递减——递减的快慢决定"旧样本被遗忘的速度"，也决定估计最终能否收敛、以多快的速度收敛。第四层（局限层）：本节只处理了"估计均值"这一最简单问题，且步长 1/k 的选择依赖"样本独立同分布"的隐式假设；若目标是求解一般方程 g(w) = 0（均值估计只是 g(w) = w − E[X] 的特例），步长如何选、收敛如何保证，需要更一般的理论。

补充一个容易被忽视却极其重要的观察：步长 1/k 本质上是"每个样本等权"的体现。把增量更新展开成加权和的形式：w_{k+1} = (1/k)x_k + ((k−1)/k)w_k = (1/k)x_k + ((k−1)/k)·(1/(k−1))Σ_{i=1}^{k−1}x_i = (1/k)Σ_{i=1}^{k}x_i，可见每个样本 x_i 在最终估计中的权重都是 1/k——新样本与最古老的样本权重完全相同。这正是"算术平均"的定义：全体样本一视同仁。若改用常数步长 α，则 w_{k+1} = αx_k + (1−α)w_k = αΣ_{i=1}^{k}(1−α)^{k−i}x_i + (1−α)^{k−1}w_1——旧样本的权重按 (1−α)^{k−i} 几何衰减，越旧的样本权重越小，这就是指数加权平均（exponential moving average）：近期数据主导估计，适合跟踪缓慢变化的目标；而 1/k 步长适合估计静态均值。这个"等权 vs 遗忘"的对比，是理解后续所有步长设计（包括深度学习中学习率调度的 warmup 与衰减）的出发点：步长序列实际上定义了"对历史数据的记忆函数"，选择步长就是选择记忆的衰减曲线。这个视角将在 6.3 节的 RM 定理中重新出现：两个收敛条件本质上是给"记忆衰减曲线"加约束——总记忆量必须无限（Σa_k = ∞），单步记忆更新幅度必须趋于零（Σa_k² < ∞）。

这四层收获直接通向下一节。6.3 节把问题推广为：在只能观测到噪声版本的 g̃(w, η) = g(w) + η 的条件下，如何迭代求解 g(w) = 0？均值估计对应 g(w) = w − E[X]，其解 w = E[X] 正是我们要估计的均值；而增量均值估计 w_{k+1} = w_k + (1/k)(x_k − w_k) 恰是 RM 迭代在"g 取该线性函数"时的特例。读者可以带着一个具体问题进入 6.3 节：均值估计的步长 1/k 满足了什么一般条件，使得迭代能够收敛？这两个条件将概括为 RM 定理，成为全章乃至第7章 TD 算法收敛性的理论基石。
