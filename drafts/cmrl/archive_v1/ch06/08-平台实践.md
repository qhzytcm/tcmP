### 8.2 实验步骤与代码实现

实验按五步推进，每步都有明确的输入输出。第一步，数据准备：把采集到的证据分序列整理为数组 x = [x_1, x_2, …, x_n]，保存为 csv（列为 k, value, source），并打印描述统计（均值、标准差），作为后续对照的基准。第二步，实现增量均值估计：写函数 incremental_mean(x, mode)，mode 可选 "1/k" 与 "constant"，核心循环为 for k, xk in enumerate(x, start=1): w += alpha_k * (xk - w)；1/k 模式下 alpha_k = 1/k（注意起始约定：w 初始化为 x_1，从第 2 个样本起更新），常数模式下 alpha_k = alpha（取 0.5 与 0.1 各跑一遍）；记录每一步的 (k, w) 轨迹。第三步，实现对照基线：全量均值 w_full = x[:n].mean()，对每个 n 计算前缀均值，作为"非增量"的对照曲线。第四步，可视化：用 matplotlib 画三张图——图一为增量（1/k）轨迹 vs 全量均值水平线；图二为常数步长 0.5 与 0.1 的轨迹对比；图三为三条轨迹叠加对比；横轴统一为样本序号，纵轴为估计值。第五步，扩展实验：把样本换成"辨证反馈"（1/0 序列，来自模拟或教学病案），估计在线辨证准确率，并人为在第 30 条后把反馈均值从 0.5 改为 0.8，观察两种步长对"真值漂移"的跟踪速度。

代码实现给出核心骨架，读者自行补全输入输出。数据加载：import pandas as pd; df = pd.read_csv("scores.csv"); x = df["value"].values。增量估计：def incremental_mean(x, mode="1/k", alpha=0.1): w = x[0]; traj = [(1, w)]; for k in range(2, len(x)+1): ak = 1.0/k if mode == "1/k" else alpha; w = w + ak*(x[k-1] - w); traj.append((k, w)); return traj。对照：import numpy as np; full = [x[:n].mean() for n in range(1, len(x)+1)]。绘图：plt.plot([t[0] for t in traj], [t[1] for t in traj], label=mode)；plt.axhline(np.mean(x), ls="--", label="full mean")。注意三个易错点：其一，1/k 模式中枚举起点必须与起始约定一致（w = x[1] 后从 k = 2 更新），否则等价性验证会失败；其二，常数步长实验中 alpha 不可过大（超过 1 会导致振荡发散），建议 0.1–0.5 区间；其三，证据分取值范围影响收敛曲线的纵轴尺度，绘图前应确认统一量纲，必要时归一化。

### 8.3 结果分析与验收清单

实验报告应包含五部分。① 数据说明：查询词列表、每个查询的检索次数、证据分的均值与标准差、数据来源（接口调用记录或 DSU 字段）。② 代码清单：incremental_mean 函数与绘图代码，标注步长模式。③ 结果图表：三张收敛曲线图，每张图配 2–3 句解读——1/k 步长曲线是否快速逼近全量均值并在后期基本静止；常数步长曲线是否围绕均值持续抖动、抖动幅度是否随 alpha 减小而减小；叠加对比是否显示"常数步长前期快、后期抖，1/k 步长全程稳"。④ 步长对比结论：用 RM 定理的两个条件解释观察到的现象——常数步长不满足"平方和收敛"条件，因此噪声无法被完全平均掉，估计停留在真值邻域；1/k 步长满足两个条件，因此以概率 1 收敛。⑤ 扩展实验结论：真值漂移场景下常数步长更快跟上新均值（"适应性"）但波动大，1/k 步长滞后但稳定——平台上线期与稳定期应分别采用哪种步长策略，给出你的工程建议。

验收清单共八项，逐项自检：① 增量估计与全量均值在样本尾部重合（误差 < 0.05×数据尺度）；② 1/k 步长轨迹单调收敛、无明显发散段；③ 常数步长轨迹在均值附近波动、波动幅度随 alpha 减小；④ 三张图齐全且轴标签完整；⑤ 报告中能用一句话说清两个步长条件的直觉；⑥ 能回答"常数步长为什么不收敛到精确值"；⑦ 能回答"平台稳定期为什么应该衰减步长"；⑧ 报告中已声明数据边界（教学切片数据、证据分为结构化字段而非真实临床结局）。完成八项验收即视为实验通过。本实验仅需 numpy/pandas/matplotlib，全程零 LLM 依赖，DEEPSEEK_API_KEY 只用于可选的生成式解读。实验总用时约 2–3 学时，建议与 6.2–6.4 节理论学习同步进行：先读公式，再跑代码，最后回到公式解释代码输出——这一循环正是本章"学完即能用"的检验标准。
