## [Part1] 6.4 Dvoretzky 条件与均值估计的 SA 视角

### 6.4.1 知识要点：Dvoretzky 的更一般收敛条件

RM 定理给出了步长序列的两个条件，但它的适用范围限于"g 可写成 g(w) + η 的加性噪声观测"这一设定。Dvoretzky 把收敛理论推广到更一般的迭代格式：考虑 w_{k+1} = w_k − a_k(w_k − x_k)，其中 x_k 是带噪声的观测，它不必是某个确定函数在 w_k 处的值，而可以是任意"指向真值"的随机量。这个看似简单的推广非常有用：许多实际问题中，我们无法把观测写成"函数值 + 噪声"的形式，却可以直接说出"观测 x_k 与真值 w* 之间的关系"——例如 x_k 是围绕 w* 波动的观测值，E[x_k | 历史] 在某种意义上逼近 w*。Dvoretzky 定理的结论是：若步长序列满足 Σa_k = ∞ 且 Σa_k² < ∞（或更弱地，a_k → 0 且 Σa_k = ∞），则迭代 w_{k+1} = w_k − a_k(w_k − x_k) 以概率 1 收敛到 w*，条件是 x_k 的噪声在平均意义下趋于零、且观测的波动有界。注意这里的步长条件与 RM 定理完全相同——两个条件"和发散、平方和收敛"再次出现，说明它们是整个随机逼近理论的共同基石，而非某一具体算法的特例。

Dvoretzky 格式与 RM 格式的关系可以这样理解。RM 迭代 w_{k+1} = w_k − a_k·g̃(w_k, η_k) 中，噪声观测 g̃ 的均值是 g(w_k)，它依赖当前迭代点 w_k；Dvoretzky 迭代 w_{k+1} = w_k − a_k(w_k − x_k) 中，观测 x_k 的均值（给定历史）则是真值 w* 本身（或其线性变换）。把 RM 格式改写：w_{k+1} = w_k − a_k·g̃(w_k, η_k) = w_k − a_k·[g(w_k) + η_k] = w_k − a_k(w_k − w*) + 误差项，若 g(w) = w − w* 为线性函数，则 RM 迭代化为 w_{k+1} = w_k − a_k(w_k − w* + η_k)，恰是 Dvoretzky 格式（把 x_k = w* − η_k 视为对 w* 的噪声观测）。因此 Dvoretzky 条件涵盖 RM 条件：RM 定理可看作 Dvoretzky 定理在"观测均值 = 函数值"设定下的特例。对读者而言，更重要的是记住这个统一图景：无论观测怎样生成，只要"步长和发散、平方和收敛"成立，增量迭代就会收敛——这把 6.2 节增量均值估计的"个别现象"提升为"一般定理"。

### 6.4.2 方法与示例：均值估计的 SA 视角

现在把均值估计重新放入 SA 框架，这一步是全书"统一视角"的关键示范。目标：估计 E[X]。构造求根问题：令 g(w) = w − E[X]，则 g(w) = 0 的解 w* = E[X]，求根与估计是同一件事。噪声观测：对单次样本 x，取 g̃(w, x) = w − x，注意 E[g̃(w, X)] = w − E[X] = g(w)，即观测是函数值的无偏估计。代入 RM 迭代：w_{k+1} = w_k − a_k·g̃(w_k, x_k) = w_k − a_k(w_k − x_k) = w_k + a_k(x_k − w_k)。取步长 a_k = 1/k，得到 w_{k+1} = w_k + (1/k)(x_k − w_k)——正是 6.2 节的增量均值估计。这条推导链的每一环都有明确含义：均值估计 ↔ 求 g(w) = w − E[X] 的根；单样本 x_k ↔ 噪声观测 g̃；增量更新式 ↔ RM 迭代；步长 1/k ↔ 满足两个收敛条件的经典选择。读者应把这条推导链完整背下，因为第7章将把"均值估计"替换为"贝尔曼方程求解"，把"样本 x_k"替换为"回报的噪声观测"，把"增量均值估计"替换为"TD 更新"——结构一字不差。

用 Dvoretzky 视角重新审视 6.2 节的数值例子，可以看到更深的收敛机理。观测序列 x_1 = 2, x_2 = 4, x_3 = 6, x_4 = 8，真值 E[X] = 5，迭代 w_{k+1} = w_k + (1/k)(x_k − w_k) 的轨迹为 2 → 3 → 4 → 5。从 SA 视角看，每一步包含两个相反的作用力：噪声力——样本 x_k 与真值的偏差 (x_k − 5) 想把估计拉偏；收缩力——更新式中的 (w_k − x_k) 项把估计拉向样本，而步长 1/k 使这种拉动幅度递减。步长平方和收敛保证噪声力造成的扰动方差在累加后仍有限；步长和发散保证收缩力能累计足够的"总行程"把初始偏差 (2 − 5) 抹平。两个条件同时满足时，噪声力随 k 增大而衰减到零、收缩力则持续存在，估计最终停在真值上。若改用常数步长 α = 0.5，则噪声力永不衰减，估计围绕真值持续抖动（方差正比于 α·Var[X]）；若步长为 1/k²，则收缩力总行程有限，估计停在初始位置与真值之间的某处。用"两力平衡"的语言讲清楚这两个条件，是本章最重要的理解目标之一。

### 6.4.3 小结与衔接

本节完成了两个层次的提升。第一层是理论提升：从 RM 算法（观测 = 函数值 + 噪声）到 Dvoretzky 格式（观测 = 围绕真值的噪声），收敛条件的核心没有变——步长和发散、平方和收敛——说明这两个条件不是某一算法的巧合，而是随机逼近理论的基本定理。第二层是视角提升：均值估计被证明是 SA 的特例，推导链"均值估计 → 求根 g(w) = w − E[X] → RM 迭代 → 增量均值估计"把 6.2 节的公式纳入统一框架。由此读者获得一张重要对照表：均值估计问题（g(w) = w − E[X]，解 w = E[X]）、RM 求根问题（g(w) = 0，解任意未知函数的根）、以及第7章的 TD 学习问题（求解贝尔曼方程 v = E[R + γv(S′)]）——三者是同一数学结构（增量迭代 + 收敛条件）的三个实例，区别只在于函数 g 的具体形式。这张对照表是理解后续章节的"元知识"：每当看到一个增量算法，都可以问"它在求什么方程、观测是什么、步长满足什么条件"。

Dvoretzky 条件的普适性在强化学习史上有一个著名例证：Q-learning 的收敛性证明。Q-learning（第7章将详细介绍）的价值更新为 Q(s, a) ← Q(s, a) + α[r + γmax_{a′}Q(s′, a′) − Q(s, a)]，其中 max 操作使更新目标不是某个固定值而是另一个估计值——这是"自举"（bootstrap），MC 的均值估计理论无法覆盖；而其收敛性证明正依赖于把更新写成 Dvoretzky 格式：把 r + γmax_{a′}Q(s′, a′) 视为围绕"真实 Q 值"的噪声观测，步长 α 序列满足两个条件，则 Q 以概率 1 收敛到最优动作价值。这个证明历史表明：Dvoretzky 条件不是书斋里的理论装饰，而是无模型强化学习算法收敛性的标准工具。读者在学第7章时如果对"TD 凭什么收敛"仍有疑虑，可以回到本节：TD 与 Q-learning 的收敛性，最终都归结为"更新目标是否可视为真值的噪声观测 + 步长是否满足两个条件"这两个问题的肯定回答。

本节与后续章节的衔接有三条线索。线索一：第7章 TD 算法将证明，TD 更新 w_{k+1} = w_k + a_k·δ_k（δ_k 为 TD 误差）就是求解贝尔曼方程的 RM/Dvoretzky 迭代，步长序列满足两个条件时价值估计以概率 1 收敛——读者若在此处已把两个条件内化，第7章的收敛性证明将顺理成章。线索二：均值估计的 SA 视角解释了 MC 与 TD 的深层差异：MC 用"多个完整样本的算术平均"估计价值（非增量、无偏、方差大），TD 用"增量迭代 + 自举"估计价值（增量、有偏、方差小）——两者都是 SA 家族成员，只是步长与观测结构不同。线索三：6.5 节的随机梯度下降将从"求根"转向"求极值"，但收敛分析完全复用本节的步长条件。学完本节，读者应能独立回答：为什么增量均值估计能收敛？答案不是"因为样本多了"，而是"因为步长满足 Dvoretzky 条件"。
