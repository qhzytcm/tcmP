## [Part1] 6.5 随机梯度下降与 SA 的关系

### 6.5.1 知识要点：从求根到求极值

随机梯度下降（Stochastic Gradient Descent, SGD）是随机逼近的优化版本：SA 求方程 g(w) = 0 的根，SGD 求目标函数 J(w) 的极值。考虑如下优化问题：最小化 J(w) = E[f(w, X)]，其中 X 是随机变量，f 是已知的损失函数，w 是待优化的参数。问题的困难在于：期望 E[f(w, X)] 需要对 X 的分布求积分，若分布未知，则 J(w) 本身都无法计算，更不用说求梯度 ∇J(w)。这与 6.3 节的"无模型条件"如出一辙：RM 问题中没有 g 的解析式、只有噪声观测 g̃；SGD 问题中没有 J 的解析式、只有单样本损失 f(w, x)（它是 J(w) 在单样本 x 处的"噪声版本"）。如果分布已知，可以直接用解析解：令 ∇J(w) = 0 求解，或求闭式解（如最小二乘的 w = (X^T X)^{-1} X^T y）；但分布未知时，解析解无法获得，只能用数据驱动的方式迭代逼近。

SGD 的迭代格式与梯度下降（Gradient Descent, GD）一脉相承，区别只在梯度来源。梯度下降：w_{k+1} = w_k − a_k·∇J(w_k)，每步需要精确的期望梯度 ∇J(w_k)，这要求分布已知。随机梯度下降：w_{k+1} = w_k − a_k·∇f(w_k, x_k)，每步用单样本梯度 ∇f(w_k, x_k) 近似期望梯度 ∇J(w_k)。注意 E[∇f(w, X)] = ∇E[f(w, X)] = ∇J(w)（在可交换积分与求导的正则条件下），即单样本梯度是期望梯度的无偏估计——这正是"随机"二字的来源：用随机样本的梯度代替期望梯度，方向大致正确但有噪声。直观上，SGD 的每一步都在"沿着带噪声的方向下山"：梯度下降像在晴朗天气下沿最陡路线下山，SGD 像在浓雾中凭局部感觉踉跄下山——每步方向可能偏离最优方向，但只要步长选择得当，长期来看仍能到达谷底。把 SGD 与 RM 对照：RM 求 g(w) = 0 的根，SGD 求 ∇J(w) = 0 的根；令 g = ∇J，SGD 迭代 w_{k+1} = w_k − a_k·∇f(w_k, x_k) 正是 RM 迭代 w_{k+1} = w_k − a_k·g̃(w_k, η_k) 在 g̃ = ∇f、η 为采样噪声时的实例。SA 求根与 SGD 求极值是同一框架的两个视角。

### 6.5.2 方法与示例：SA 与 SGD 的统一

用线性回归把 SA 与 SGD 的统一讲透。假设数据由 y = θx + ε 生成，ε 是零均值噪声，目标是估计参数 θ*。损失函数取 f(w, x, y) = (1/2)(y − wx)²，则 J(w) = E[(1/2)(Y − wX)²]，最小化 J(w) 的解析解由正规方程给出，需要知道 (X, Y) 的联合分布或全部数据；在数据流式到达、分布未知的场景下，用 SGD：w_{k+1} = w_k − a_k·∇f(w_k, x_k, y_k) = w_k − a_k·(−(y_k − w_k x_k)x_k) = w_k + a_k·(y_k − w_k x_k)x_k。这个更新式与 6.3 节 RM 迭代的对应关系一目了然：定义 g(w) = −E[(Y − wX)X] = −(E[YX] − wE[X²])，则 g(w) = 0 的解 w* = E[YX]/E[X²] = θ*，SGD 的噪声观测 g̃(w_k, x_k, y_k) = −(y_k − w_k x_k)x_k 满足 E[g̃(w, X, Y)] = g(w)，于是 SGD 迭代就是 RM 迭代——收敛性由 RM 定理保证，步长需满足两个条件。

数值验证让统一性更具体。取真参数 θ* = 2，噪声 ε ~ N(0, 0.25)，生成样本 (x, y)：(1, 2.3)、(2, 3.8)、(3, 6.1)、(4, 8.2)。SGD 迭代 w_{k+1} = w_k + a_k(y_k − w_k x_k)x_k，取 a_k = 1/(k+1)，w_1 = 0：处理 (1, 2.3)：w_2 = 0 + (1/2)(2.3 − 0)×1 = 1.15；处理 (2, 3.8)：w_3 = 1.15 + (1/3)(3.8 − 1.15×2)×2 = 1.15 + (1/3)×1.5×2 = 2.15；处理 (3, 6.1)：w_4 = 2.15 + (1/4)(6.1 − 2.15×3)×3 = 2.15 + (1/4)(−0.35)×3 = 1.8875；处理 (4, 8.2)：w_5 = 1.8875 + (1/5)(8.2 − 1.8875×4)×4 = 1.8875 + (1/5)×0.65×4 = 2.4075。四步之后估计在真值 2 附近波动，与 RM 求根的行为完全一致——每次样本噪声把估计推离真值，递减步长把波动逐步压小。若把步长换成常数 α = 0.1，估计会持续抖动，这正是 SA 理论预言的"常数步长不收敛到精确值、只收敛到邻域"。

### 6.5.3 小结与衔接

本节的核心结论有三条。第一条：SGD 是 SA 的优化版本——SA 求 g(w) = 0 的根，SGD 求 ∇J(w) = 0 的根，令 g = ∇J 即完成统一；SGD 的收敛性分析建立在 RM/Dvoretzky 理论上，步长条件"和发散、平方和收敛"原样适用。第二条：单样本梯度 ∇f(w_k, x_k) 是期望梯度 ∇J(w_k) 的无偏估计，这是"随机"二字的数学含义，也是 SGD 每步方向"大致正确但有噪声"的原因。第三条：SGD 是机器学习中应用最广泛的优化器，深度学习训练（包括大语言模型的参数更新）几乎都建立在其变体（Adam、RMSProp 等）之上；理解 SGD 为何能工作，本质是理解 SA 理论——这正是本章全部铺垫的落点。读者可以这样记忆本节：RM 解决"不知道函数也能求根"，SGD 解决"不知道分布也能求极值"，两者共享同一条数学主线。

在 SGD 与梯度下降之间还有一个重要的中间形态——小批量随机梯度下降（mini-batch SGD），它把"单样本梯度"升级为"一批样本梯度的平均"：w_{k+1} = w_k − a_k·(1/|B_k|)Σ_{x∈B_k}∇f(w_k, x)，其中 B_k 是第 k 步采样的一个小批量（mini-batch，如 32 或 128 个样本）。从 SA 视角看，小批量的作用不是改变算法框架，而是降低噪声方差：单样本梯度的方差正比于单样本噪声方差，小批量平均后方差除以批量大小 |B_k|——噪声更小，估计的收敛轨迹更平滑，允许使用更大的步长，训练更快更稳。批量大小从 1（纯 SGD）到无穷（梯度下降）构成一个连续谱：批量越小噪声越大但每步计算越便宜、且引入的随机性有助于逃离局部极小（这是"噪声有益"的一个例子，超出本章范围）；批量越大梯度越准但每步代价越高。深度学习工程中"学习率随批量大小线性缩放"的经验法则，正是 SA 噪声方差分析的直接推论：批量翻倍 → 梯度噪声方差减半 → 步长可翻倍而保持相同的噪声水平。理解这个连续谱，读者就能看懂深度学习训练中的绝大多数超参数选择：它们本质上是 SA 理论中"步长—噪声"权衡在工程上的具体化。这一认识将直接服务于第9章及之后深度强化学习中"策略梯度 + 神经网络 + SGD"的训练理解。

本节还承担着连接强化学习与深度学习的桥梁角色。向前衔接：第7章的 TD 学习是求解贝尔曼方程的 SA 算法；当价值函数用深度网络参数化（第9章及之后的深度强化学习）时，TD 更新中的价值估计误差（TD 误差）成为网络的损失，梯度由反向传播计算，而参数的更新正是 SGD——于是"SA（求根）→ TD（贝尔曼方程求根）→ 深度 TD（神经网络 + SGD）"构成一条完整的逻辑链。向后呼应：第5章 MC 用样本均值估计价值（无偏、高方差），本章的 SA 视角指出其步长 1/N(s,a) 满足收敛条件，从而从理论上保证了 MC 估计的收敛；读者若回头审视 MC 的公式，会发现它也是 SA 家族的一员。全章的图景至此完整：增量均值估计、RM 求根、Dvoretzky 格式、SGD 优化——四个问题、一条主线、两个条件。带着这张全景图进入 6.6 节的小结与第7章，读者将第一次以"理论主人"而非"公式搬运工"的姿态学习 TD 算法。
