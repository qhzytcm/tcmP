## [Part1] 本章小结与习题

本章完成了一次重要跨越：从"攒数据、算一次"的非增量思维到"来一条、更新一次"的增量思维。增量均值估计 w_{k+1} = w_k + (1/k)(x_k − w_k) 与全量平均完全等价，是所有增量算法的原型；Robbins-Monro 算法在无模型条件下求解 g(w) = 0，迭代为 w_{k+1} = w_k − a_k·g̃(w_k, η_k)，收敛的两个条件是步长和发散（Σa_k = ∞，保证能走远）与步长平方和收敛（Σa_k² < ∞，保证噪声被平均掉），经典步长 a_k = 1/k 同时满足；Dvoretzky 把收敛条件推广到 w_{k+1} = w_k − a_k(w_k − x_k) 的一般格式，并揭示均值估计是 SA 的特例（g(w) = w − E[X]）；随机梯度下降是 SA 的优化版本——SA 求 g(w) = 0 的根，SGD 求 ∇J(w) = 0 的根，令 g = ∇J 即完成统一，SGD 用单样本梯度 ∇f(w_k, x_k) 作为期望梯度的无偏近似。全章主线可浓缩为一句话：增量迭代 w_{k+1} = w_k − a_k·(误差信号) + 两个步长条件。易错点：① 步长和发散不等于步长大，1/k² 虽小但和收敛、走不远；② RM 与 Dvoretzky 的前提不同（观测均值 = 函数值 vs 观测围绕真值）；③ 增量均值估计从 w_1 = x_1 起步，第 1 步不更新；④ 单样本梯度无偏 ≠ SGD 迭代无偏。掌握本章，就握住了第7章 TD 算法（求解贝尔曼方程的 SA 算法）的理论钥匙。

习题（60-30-10 分层）。基础题（回忆与理解，60%）：1. 填空：增量均值估计的更新式为 w_{k+1} = ____，其中 (1/k) 称为____，(x_k − w_k) 称为____。2. 选择：Robbins-Monro 算法解决的是（ ）A. 求极值 B. 无模型条件下求方程 g(w) = 0 的根 C. 求解线性方程组 D. 分类问题。3. 填空：RM 定理的两个收敛条件是 Σa_k = ____ 与 Σa_k² ____；经典步长 a_k = ____ 同时满足。4. 判断：常数步长 α 下，增量均值估计最终精确收敛到 E[X]。（对/错，并说明理由）5. 填空：SGD 的迭代格式为 w_{k+1} = w_k − a_k·____，其中单样本梯度是期望梯度 ∇J(w_k) 的____估计。6. 选择：Dvoretzky 格式 w_{k+1} = w_k − a_k(w_k − x_k) 中，x_k 表示（ ）A. 函数值 g(w_k) B. 围绕真值的噪声观测 C. 步长 D. 梯度。综合题（应用与分析，30%）：7. 设观测序列为 x = [1, 3, 5, 7]（期望为 4 的样本），用增量均值估计（1/k 步长）手算 w_2、w_3、w_4、w_5，并说明与全量均值 (1+3+5+7)/4 = 4 的关系。8. 解释为什么步长序列 a_k = 1/√k 不满足收敛条件：分别检查 Σa_k 与 Σa_k² 的发散/收敛性，并用"走远"与"平噪"的直觉说明不收敛的原因。9. tcmP 平台：失眠 DSU 的 evidence_level = A 映射奖励 1.0，现连续 5 次检索 Top1 证据分为 [0.8, 0.9, 0.7, 1.0, 0.6]，用增量均值估计在线更新疗效均值 w_k（w_1 = 0.8），求 w_3 与 w_5；若改用常数步长 α = 0.5，w_5 为多少？两种结果说明什么？拓展题（评价与创造，10%）：10. 设计一个"在线辨证准确率监控"实验：以中医师接受/修正 AI 辨证建议为反馈样本，用 SA 增量估计在线估计辨证准确率，要求给出样本定义、步长策略（上线期与稳定期）、异常值处理方案，并说明如何用 RM 定理论证该策略的合理性。

参考答案与评分要点。基础题：1. w_k + (1/k)(x_k − w_k)；步长；误差（每空 1 分，共 3 分）。2. B（2 分）。3. ∞；< ∞；1/k（每空 1 分，共 3 分）。4. 错；常数步长只收敛到真值邻域，噪声方差正比于 α·Var[X]，精确收敛要求步长平方和收敛（判断 1 分 + 理由 2 分）。5. ∇f(w_k, x_k)；无偏（每空 1 分，共 2 分）。6. B（2 分）。综合题：7. w_2 = 1，w_3 = 1 + (1/2)(3−1) = 2，w_4 = 2 + (1/3)(5−2) = 3，w_5 = 3 + (1/4)(7−3) = 4；与全量均值相等，验证等价性（计算 4 分 + 结论 2 分）。8. Σ(1/√k) 发散（满足走远），但 Σ(1/k) 发散即 Σa_k² = ∞（平噪失败）；噪声累积方差发散，估计在真值附近持续抖动不收敛（判断 3 分 + 直觉 2 分）。9. 1/k 步长：w_3 = 0.8 + (1/2)(0.9−0.8) = 0.85，w_5 计算得 0.776；常数步长 w_5 ≈ 0.7875；两者接近但常数步长波动更大，说明步长影响收敛路径与稳定性（计算 4 分 + 说明 2 分）。拓展题：样本 = 采纳反馈（1/0），w_{k+1} = w_k + a_k(反馈 − w_k)；上线期常数步长 0.2 快速适应，稳定期切换 1/k 衰减步长；异常值用 |反馈 − w_k| 阈值截断或降权；RM 定理保证衰减步长下准确率估计以概率 1 收敛到真值，常数步长提供漂移跟踪能力（方案完整 5 分 + 理论论证 5 分）。
