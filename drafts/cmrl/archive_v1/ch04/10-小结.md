## [Part1] 本章小结与习题

本章完成了一次重要跨越：从"什么是最优"（第2、3章的价值函数与贝尔曼最优方程）到"怎么算出来"（本章的三个动态规划算法）。价值迭代直接迭代求解 BOE：v_{k+1} = max_π (r_π + γP_π v_k)，收缩映射保证价值以几何速度收敛，价值从目标状态向全状态扩散；策略迭代交替进行策略评估（精确求解 v_π = r_π + γP_π v_π）与策略改进（贪婪更新 π_{k+1}(s) = argmax_a q_{π_k}(s,a)），策略改进定理保证价值单调不降、有限 MDP 中有限步收敛；截断策略迭代把两者统一为"截断评估步数 j"的连续谱：j = 1 时是 VI，j → ∞ 时是 PI。三者共享"评估—改进"骨架与元素级公式 q_k(s,a) = r(s,a) + γ Σ_{s′} p(s′|s,a) v_k(s′)、π_{k+1}(s) = argmax_a q_k(s,a)、v_{k+1}(s) = max_a q_k(s,a)，共同前提是模型已知。网格世界（s1–s9、s6 禁区、s9 目标、边界弹回）为全部推导提供了可手算的载体。易错点：① 同步更新须用旧值 v_k 算全部 q 再统一更新；② 停止准则看相邻差而非价值绝对值；③ 策略用 argmax（返回动作）、价值用 max（返回数值），不可混淆；④ γ < 1 是收敛前提；⑤ 实验前确认环境约定（禁区可入 vs 弹回）。

习题（60-30-10 分层）。基础题（回忆与理解，60%）：1. 写出价值迭代的矩阵—向量更新公式，说明一轮中的两个逻辑步骤。2. 判断正误：策略迭代中的策略评估需要求解线性方程组 v = r_π + γP_π v。（对/错）3. 填空：截断策略迭代中，j = 1 时退化为____，j → ∞ 时退化为____。4. 填空：网格世界中，越界、禁区、目标的奖励分别为____、____、____。综合题（应用与分析，30%）：5. 简述策略改进定理（定理4.1）内容并直观解释：为何贪婪改进后价值不降？6. 在 3×3 网格世界（γ = 0.9，s6 禁区、s9 目标）上，价值迭代第 1、2 轮后 v_1、v_2 的取值模式是什么？写出 s8 与 s6 在第 2 轮的价值并说明原因。7. tcmP 平台：把失眠 DSU 建模为状态 = 症状组合、动作 = 候选方剂、奖励 = 证据等级（A=1.0、B=0.7、C=0.4），VI 收敛后的策略表对应临床的什么概念？奖励改为随访疗效差值后策略如何变化？拓展题（评价与创造，10%）：8. 设计实验验证"检索 Top1 ≈ VI 一步近似"：给出状态/动作/奖励构建方案、对比指标、预期结果与失效条件（提示：即时证据分高但转归差的状态）。

参考答案。1. v_{k+1} = max_π (r_π + γP_π v_k)；两步为策略更新 π_{k+1} = argmax_π (r_π + γP_π v_k) 与价值更新 v_{k+1} = r_{π_{k+1}} + γP_{π_{k+1}} v_k（公式六成，两步四成）。2. 对（矩阵形式 v = (I − γP_π)^{−1} r_π）。3. 价值迭代；策略迭代。4. −1；−1；+1。5. v_{π_{k+1}} ≥ v_{π_k} 对一切状态成立；直观：v_{π_k}(s) 是当前策略下各动作 q 的加权平均，不超过最大值 max_a q_{π_k}(s,a)（即贪婪动作的 q），逐步代入贝尔曼算子得全程不等式（各半）。6. 价值从 s9（目标）向外扩散：第 1 轮 v_1(s9) = 1、其余 0；第 2 轮 s9 邻居"看见"目标，s8、s6 向右各得 0.9，v_2(s8) = v_2(s6) = 0.9；每外扩一圈乘以 γ（模式 60%，数值 40%）。7. VI 收敛后的策略表 = 平台"辨证—方剂表"，即每个症状组合的最优方剂，是辨证论治的表格化；奖励改为随访疗效差值后，策略转向重视长期转归（等效于增大 γ 的远视效应），对后继疗效更敏感，但需要随访数据支撑。8. 构建方案见 08-平台实践.md 实验二：状态 = 症状组合、动作 = 候选方剂、奖励 = 证据分；对比指标为 VI 最优方剂与检索 Top1 的一致性率；预期多数一致、差异集中在长期价值与即时奖励不一致的状态；失效条件：存在"即时证据分高但引向疗效差后继状态"的方剂（如治标方），或状态间转移显著影响长期转归。跑通 1.7 节双网格实验后，请带着"评估—改进"框架进入第 5 章。
