## [Part1] 1.2 价值迭代算法

### 1.2.1 概念引入：收缩映射定理建议的算法

价值迭代（Value Iteration, VI）是三个算法中直觉最直接的一个，它的思想完全来自第3章的收缩映射定理（定理3.3）。回顾该定理：贝尔曼最优算子 T 定义为 (Tv)(s) = max_a [ r(s,a) + γ Σ_{s′} p(s′|s,a) v(s′) ]，它是一个 γ-收缩映射——对任意两个价值函数 v 与 u，有 ‖Tv − Tu‖_∞ ≤ γ‖v − u‖_∞。收缩映射有一个优美的性质：它存在唯一不动点，且从任意初始点出发反复作用算子，序列一定收敛到该不动点。BOE 恰是 v = Tv，其唯一不动点正是最优状态价值 v*。因此，一个极其自然的算法浮现出来：任取初始估计 v_0，反复迭代 v_{k+1} = T v_k，直到收敛。这就是价值迭代。为什么收缩性足以保证收敛？因为每次作用算子，估计与真值之间的距离至少被压缩 γ 倍：‖v_{k+1} − v*‖_∞ = ‖Tv_k − Tv*‖_∞ ≤ γ‖v_k − v*‖_∞，于是误差以几何速度衰减——收敛是收缩性的直接推论，不需要任何额外假设。

价值迭代的完整形式可以写成矩阵—向量形式：v_{k+1} = max_π ( r_π + γP_π v_k )，k = 0, 1, 2, …。这个式子把"求最大"写在整个策略空间上，直观上是"每轮都问：在所有策略中，哪一个使 r_π + γP_π v_k 最大？"，然后把这个最大值作为新的价值。细看可以发现，每一轮其实包含两个逻辑步骤：第一步是策略更新，π_{k+1} = argmax_π ( r_π + γP_π v_k )，即在当前价值估计 v_k 之下找出贪婪策略——它是"当前看来最好"的策略，但未必是全局最优；第二步是价值更新，v_{k+1} = r_{π_{k+1}} + γP_{π_{k+1}} v_k，即用新策略的价值算子对旧价值作用一次，得到新价值。需要特别强调：这里的价值更新只做一步，不是把方程解到收敛——这是价值迭代与策略迭代（1.3 节）最本质的区别。矩阵—向量形式适合理解思想，实现时则必须落到元素形式：对每个状态逐一计算。

### 1.2.2 数学表述：元素形式的三个公式

实现价值迭代需要逐状态的元素形式。对每个状态 s 与每个动作 a，先计算动作价值的估计：q_k(s,a) = Σ_r p(r|s,a) r + γ Σ_{s′} p(s′|s,a) v_k(s′)，在确定性奖励下简化为 q_k(s,a) = r(s,a) + γ Σ_{s′} p(s′|s,a) v_k(s′)。然后做两件事：策略更新取最优动作，π_{k+1}(s) = argmax_a q_k(s,a)；价值更新取最大动作价值，v_{k+1}(s) = max_a q_k(s,a)。这三个公式是价值迭代的全部内容，请读者务必亲手写出并反复核对下标：q 用的是 v_k（旧值）而不是 v_{k+1}，这保证所有状态同步更新（synchronous update）——先基于旧价值算出全部 q，再统一更新 v 与 π；若逐状态原地覆盖（异步更新），算法通常也收敛，但分析与实现都更微妙，本书默认同步更新。还要注意 argmax 与 max 的区别：argmax 返回的是使 q 最大的那个动作（用于策略表 π），max 返回的是最大的数值（用于价值 v）——把两者混淆是初学者最常见的错误之一。

价值迭代的伪代码如下。输入：MDP 五元组、折扣率 γ、精度阈值 ε（如 1e−6）；初始化：v_0 为任意有限值（通常全 0）。循环 k = 0, 1, 2, …：第一步，对每个状态 s、每个动作 a 计算 q_k(s,a)；第二步，更新 π_{k+1}(s) = argmax_a q_k(s,a)、v_{k+1}(s) = max_a q_k(s,a)；第三步，检查终止条件 ‖v_{k+1} − v_k‖_∞ < ε，满足则停止；否则继续。输出：价值 v_k 与策略 π_k。为什么要用"相邻两次迭代之差"作为终止判据而非直接检查与 v* 的误差？因为 v* 未知，无法直接测距；而由收缩性可以证明 ‖v_k − v*‖_∞ ≤ γ/(1−γ) · ‖v_{k+1} − v_k‖_∞——相邻差小，意味着离真值也近，误差上界由 γ 与相邻差共同决定。注意这个上界随 γ 增大而变松：γ 越接近 1，同样的相邻差对应的真实误差可能越大，因此高折扣率场景需要更小的 ε 才能保证精度。这个终止准则在 1.5 节代码中会直接使用。

### 1.2.3 性质与直观：收敛性与网格世界示例

价值迭代的收敛性由收缩映射定理直接保证，可以总结为两个结论：第一，价值收敛，对任意初始 v_0，序列 {v_k} 在无穷范数下收敛到 v*，且 ‖v_k − v*‖_∞ ≤ γ^k ‖v_0 − v*‖_∞，收敛速度为几何级数，与 γ 的大小直接相关；第二，策略收敛，当 v_k 充分接近 v* 时，其贪婪策略 π_k 就是最优策略——更精确地说，存在一个阈值，当 ‖v_k − v*‖_∞ 小于该阈值后，argmax 返回的动作不再改变，π_k 锁定为最优策略。值得注意的一个有趣现象：策略往往比价值更早稳定。因为 argmax 只关心 q 值之间的相对大小与排序，不关心绝对数值；价值估计还差得很远时，排序可能已经正确，策略就提前收敛了。读者在 1.5 节的实验中将亲眼看到这一现象：价值表还在缓慢变化，策略箭头图却早已不再变动。这也解释了为什么实践中可以用"策略连续多轮不变"作为早停条件，从而大幅节省计算。

在 3×3 网格世界上手算价值迭代，是建立直观的最好方式。取 γ = 0.9，奖励约定：到达目标格 +1、进入禁区 −1、越界弹回 −1、其他 0，初始 v_0 = 0。第 1 轮：对每个格子算 q_0(s,a) = r(s,a) + 0.9 × 0 = r(s,a)，于是 v_1(s9) = 1（到达目标 +1），其余格子取 max r 后多为 0（普通移动奖励为 0；进入禁区或越界的动作 q 为 −1，不是最大值）。第 2 轮：只有 s9 的邻居能"看见"目标的价值——例如 s8 向右一步到 s9，q_1(s8, 右) = 0 + 0.9 × v_1(s9) = 0.9，故 v_2(s8) = 0.9；s6 虽为禁区（进入它要付 −1），但站在 s6 上向右一步也能到 s9，q_1(s6, 右) = 0 + 0.9 × 1 = 0.9，v_2(s6) = 0.9。第 3 轮：s5 向下到 s8，q = 0.9 × 0.9 = 0.81，s3 向左或向下可到达 s6 或 s9 方向的格子，次外层价值取 0.81，如此逐圈扩散。读者应亲手算前三四轮，把每个数字对应到图上的格子，就会理解"价值从目标格向整个网格扩散"的图景——这也是动态规划中价值传播（value propagation）最经典的直观画面。

下面给出一个完整的例题。例题 1-1：在 3×3 网格世界（γ = 0.9，s6 禁区、s9 目标，奖励约定同上）上运行价值迭代前两轮，写出 v_1、v_2 与 π_2。解：第一轮如前所述，v_1(s9) = 1，其余为 0。第二轮，对每个状态 s 计算 q_1(s,a) = r(s,a) + 0.9 Σ_{s′} p(s′|s,a) v_1(s′)，取最大即得 v_2：s8 向右 0.9、s6 向右 0.9，故 v_2(s8) = v_2(s6) = 0.9；其余格子能到达 s9 邻格的路径在第 2 轮尚未"打通"，v_2 为 0（例如 s5 向下到 s8，但 v_1(s8) = 0）。π_2 的取值为：s8 的最优动作为向右（指向目标），s6 的最优动作为向右，s5 处所有动作 q 相等（都是 0），取约定下的默认动作；其余格子同理。这个例题说明三点：其一，价值逐轮向外扩散，速度由 γ 决定；其二，策略在价值尚未精确时就已开始指向目标——s8、s6 在第 2 轮就选对了方向；其三，平局（多个动作 q 相等）在实现中需要约定取法（如取最小索引），不影响收敛结果。读者可进一步手算第 3、4 轮，验证价值确实按 γ 的幂次向外扩散，并与 1.5 节代码输出对照。
