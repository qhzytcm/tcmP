## [Part1] 1.6 轨迹、回报与折扣回报

单步奖励只能评价"一个动作的即时好坏"，而智能体的目标通常是长期的。为此需要把一系列奖励累积起来。轨迹（trajectory）是一条状态-动作-奖励链：从某个初始状态出发，依次记录每个时刻的状态、动作与获得的奖励。例如 s1 --a2, r=0--> s2 --a3, r=0--> s5 --a3, r=0--> s8 --a2, r=1--> s9 就是一条轨迹：机器人从 s1 出发，向右、向下、向下、向右，最终到达目标，途中获得奖励 0, 0, 0, 1。轨迹完整记录了一次交互的历史，是分析智能体行为的基本素材；后续无模型算法（第 5 章起）正是从一批轨迹中估计价值的——轨迹是数据，算法是数据的使用者。在临床语境中，一条轨迹就是一个完整的"就诊—治疗—随访"过程：症状组合、处方、疗效评价被依次记录下来，构成机器学习方法的训练样本。轨迹的起点与终点之间，承载着策略与环境的全部交互信息；把轨迹写清楚，就是把"发生了什么"写清楚，这是任何分析的起点。

轨迹上所有奖励之和称为回报（return），它是评价策略好坏的直接指标：回报越大，策略越好。仍用上面的例子：按某策略从 s1 出发到达 s9，回报为 0 + 0 + 0 + 1 = 1；若按另一条经过禁区的策略，轨迹为 s1 --a2, r=0--> s2 --a2, r=−1--> s6 --a3, r=0--> s9，回报为 0 + (−1) + 0 = −1。前者回报更大，策略更好。回报把"单步奖励"累积为"整体效果"，使不同策略之间可以定量比较。注意：回报的定义依赖具体的轨迹，而轨迹由"策略 + 环境随机性"共同决定；因此同一策略在不同次交互中可能得到不同回报——可能这次得 1，下次得 0。如何把这种随机性处理掉，是第 2 章引入期望（状态价值）的动机。读者在此应记住：回报是随机变量，不是定值；评价策略不能只看一次结果，要看平均表现，这就像评价一位医师不能只看一个病例的成败，而要看长期的整体疗效。期望的引入将把“平均表现”变成可计算的数学对象，请在第 2 章留意它的登场。

非折扣回报有一个根本局限：对于无限长的轨迹，直接求和可能发散。设想机器人到达目标后继续移动：0 + 0 + 0 + 1 + 1 + 1 + … = ∞，回报没有定义。只要任务没有明确的终止点，非折扣回报就可能出问题；这一困难在持续任务（第 1.7 节）中尤其突出。解决办法是引入折扣：让远期的奖励"打折"，使无穷求和收敛。这一思想也符合人类与动物的行为直觉——"一鸟在手胜过两鸟在林"：远期奖励往往不如近期奖励可靠、有价值，因为未来充满不确定性，今天的 1 分比十年后的 1 分更值得把握。读者可以这样理解折扣的合理性：如果奖励可以无限累积，那么"活得越久越富有"的平凡策略就会淹没所有真正的决策差异；折扣为时间定价，使不同时长的策略可以公平比较，也让"越早越好"的偏好进入了数学模型。折扣不是数学上的权宜之计，而是对“时间价值”这一真实特性的建模。学会在两类任务间切换视角，是理解第 2 章贝尔曼方程适用性的前提。非折扣求和只在有限轨迹上有意义，这一认识本身就是折扣动机的一部分。

折扣回报（discounted return）的定义为 Gt = Rt+1 + γRt+2 + γ²Rt+3 + … = Σk=0∞ γ^k Rt+k+1，其中 γ ∈ (0,1) 称为折扣率（discount rate）。两个记号细节值得注意。其一，Gt 从时刻 t 之后的第一个奖励 Rt+1 开始累计，而不是 Rt——因为 Rt 是时刻 t−1 的动作得到的奖励，不属于"从 t 出发的未来回报"；这个下标错位是初学者最容易写错的地方，请务必记牢。其二，第 k 项前的折扣因子是 γ 的 k 次方：离当前时刻越远，折扣越狠，远期奖励对回报的贡献越小。若用 s0, a0, r1, s1, a1, r2, … 表示完整交互序列，则 G0 = r1 + γr2 + γ²r3 + …，下标错位一目了然。建议读者在纸上抄写一遍这个公式，把每一项的下标与折扣指数逐一核对，抄过一遍就再也不会写错；这个公式是全书最重要的公式之一，值得花五分钟彻底消化。它将在第 2 章被"自举"分解，衍生出贝尔曼方程，成为所有价值计算的原点。

折扣率的作用有二。其一，保证回报有界：若奖励绝对值的上界为 Rmax，则 |Gt| ≤ Rmax(1 + γ + γ² + …) = Rmax/(1−γ)，几何级数收敛，无限长轨迹的回报有限。其二，调节远近权重：γ 接近 0 时，远期奖励被严重打折，策略是短视的（myopic），几乎只看即时奖励；γ 接近 1 时，远期奖励几乎不打折，策略是远视的（far-sighted），愿意为远期收益承担近期损失。从极限看，γ = 0 时回报退化为即时奖励；γ → 1 时回报接近非折扣回报（在回合任务中有定义）。γ 的取值是建模者的选择，它体现设计者对"长远 vs 眼前"的权衡——在应用中，γ 通常取 0.9 至 0.99 之间的值；取值过大则学习慢、方差大，取值过小则策略短视，需要在两者间寻找平衡。读者今后看到任何强化学习算法，都要先问一句：它的 γ 是多少？这决定了它的"眼光"有多远；比较两个算法时，γ 不同往往意味着它们在优化完全不同的目标函数。设置 γ 时建议与任务的时间尺度对齐：疗程以周计的，γ 可取 0.9；以年计的，宜取 0.99。

用数值例子说明 γ 的调节作用。设某轨迹的奖励序列为 1, 1, 1, …：当 γ = 0.5 时，G0 = 1 + 0.5 + 0.25 + … = 2；当 γ = 0.9 时，G0 = 1 + 0.9 + 0.81 + … = 10。同样的轨迹，γ 越大，远期奖励对回报的贡献越大。再比较两条备选轨迹：轨迹甲奖励序列为 0, 10（先苦后甜），轨迹乙为 5, 5（平稳）。γ = 0.5 时，甲回报 0 + 5 = 5，乙回报 5 + 2.5 = 7.5，乙更优；γ = 0.9 时，甲回报 0 + 9 = 9，乙回报 5 + 4.5 = 9.5，乙仍略优；若把甲的远期奖励加大为 0, 100，则 γ = 0.9 时甲回报 90，反超乙。这个例子直观展示了：γ 越大，智能体越愿意"为远期收益承担近期损失"——先苦后甜还是平平淡淡，取决于 γ 的设定。在临床语境中，γ 的大小对应医师"治标"与"治本"的取舍，详见 Part2；读者可把本例中的"先苦后甜"想成"先调理体质后收获长期健康"，体会折扣率的选择如何改变决策风格。这个例子也提醒我们：γ 不是"越大越好"或"越小越好"，而是"与问题的时间尺度匹配才好"。

用几何级数计算几个具体回报，巩固公式。设 γ = 0.9。轨迹一奖励序列为 1, 1, 1, …：G0 = 1/(1−0.9) = 10。轨迹二奖励序列为 2, 1, 1, 1, …：G0 = 2 + 0.9 × 1/(1−0.9) = 2 + 9 = 11。轨迹三奖励序列为 0, 0, 0, 1, 1, …（前三步无奖励，之后每步 +1）：G0 = 0 + 0 + 0 + 0.9³ × 1/(1−0.9) = 7.29。对比轨迹一与轨迹三：同样"此后每步 +1"，晚 3 步才开始，回报从 10 降到 7.29——延迟的代价是 (0.9)³ = 0.729。这个数字直观展示了折扣的含义：时间就是折扣，迟到三拍的奖励只值七成多。读者应能独立完成这类计算，这是后续所有价值计算的基础；第 2 章的状态价值本质上就是对"各种轨迹回报的加权平均"的系统计算，本节的算术功夫是读懂那一切的起点。建议读者再自编两三组奖励序列，分别计算不同 γ 下的回报，直到"看到序列能立即写出求和式"为止——这种熟练度，会让第 2 章的学习轻松许多。
