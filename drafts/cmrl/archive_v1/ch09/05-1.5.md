## [Part1] 9.5 优缺点与改进方向

### 9.5.1 知识要点：优缺点清单

把前四节的讨论汇总，策略梯度方法（以 REINFORCE 为代表）的优点可以列成四张"王牌"。第一，连续与大规模动作空间的天然适配：策略输出概率分布函数，动作空间只参与采样、不参与枚举，这是价值方法在结构上做不到的（9.2节已详述）。第二，随机策略的表达能力：softmax/高斯策略可以直接输出概率分布，能够表达"混合多个动作"的最优随机策略，石头剪刀布一例已说明其必要性。第三，平滑更新与稳定训练：梯度上升每次只移动参数一小步，动作概率连续变化，没有贪婪提取的跳变，训练曲线相对平稳、超参数鲁棒性更好。第四，简洁的实现与清晰的数学结构：策略梯度定理把"优化策略"化约为"估计一个可采样的期望"，REINFORCE 的核心代码只有几十行，且梯度方向无偏——这使策略梯度成为现代深度强化学习（PPO、SAC、A3C 等）的共同数学底座，几乎所有先进算法都是在这个底座上加工程技巧。

缺点同样突出，主要有三。第一，收敛到局部最优：J(θ) 对参数 θ 通常是非凸函数，梯度上升只能保证到达局部极大点；不同的参数初始化会收敛到不同的策略，无法保证全局最优——这与表格价值方法在有限 MDP 上的全局收敛保证形成鲜明对比。第二，样本效率低：REINFORCE 需要完整回合才能更新一次参数（MC 回报要求轨迹走完），且每个回合的梯度只有该回合信息，历史数据完全无法复用（同策略限制），实际中往往需要数十万甚至数百万次交互才能学到像样的策略，这在真实物理系统上常常不可接受。第三，梯度方差大：如9.4节分析，完整回报 G_t 累积了整条轨迹的随机性，单样本梯度的噪声极大，导致收敛缓慢、训练震荡——这是策略梯度方法最著名的痛点，也是大量改进工作的主攻方向。客观地看，三大缺点并非互相独立：样本效率低与方差大本质上是同一问题的两面（噪声大就需要更多样本去平均），而局部最优是非凸优化的固有难题。理解缺点是为了对症下药，改进方向正是围绕这三条逐一拆解。

### 9.5.2 方法与示例：基线思想与方差缩减

方差缩减的第一个有效工具是基线（baseline），它在9.4节末尾已经预告，这里给出完整的形式化。策略梯度定理右侧的 qπ(S,A) 可以替换为 qπ(S,A)−b(S)，其中 b(s) 是任意只依赖状态、与动作无关的函数，替换后梯度期望不变：E_{S∼dπ,A∼π}[∇θ ln π(A|S,θ)·b(S)]=E_{S∼dπ}[b(S)·Σ_a ∇θπ(a|S,θ)]=E_{S∼dπ}[b(S)·∇θ1]=0。这个恒等式的证明只用到了归一化条件 Σ_a π(a|s,θ)≡1，因此对任意 b 都成立——这是"基线自由"（baseline freedom）性质。然而期望不变、方差却改变：设随机变量 X=∇θ ln π(a|s)·qπ(s,a)、Y=∇θ ln π(a|s)·[qπ(s,a)−b(s)]，由于 X 与 Y 相差一个与动作无关的常数倍，当 b(s) 靠近 E[qπ(s,A)] 时，Y 的方差显著小于 X。直觉上：把"动作的绝对价值"换成"动作相对该状态平均水平的价值"，公共的环境噪声被减去，剩下的是动作间差异带来的信息——这正是我们想学的信号。注意这个思想与"优势函数"的渊源：A(s,a)=qπ(s,a)−vπ(s) 就是取 b(s)=vπ(s) 的特例，9.4节的数值演算（回报 50 与 −20 的波动）展示了基线如何把"状态本身难易"的干扰剔除。

用一个具体例子量化基线的效果。考虑单状态两动作的任务：状态 s 下，动作 a1 的回报恒为 100，动作 a2 的回报恒为 0，策略当前 π(a1|s)=0.5。无基线时，估计梯度 ∇θJ 的单样本为 G_t·g_t，其中 G_t 在 {0,100} 间波动，梯度估计的方差正比于 E[G²]≈5000（量级）；取基线 b(s)=E[G]=50 后，单样本变为 (G_t−50)·g_t，取值在 {−50,+50}，方差正比于 E[(G−50)²]=2500，方差减半。若基线再精确些——用 vπ(s)=50 甚至更接近 qπ 的均值——方差还能进一步下降。更一般的理论结论是：最优基线 b*(s)=E[‖g‖²·qπ(s,A)]/E[‖g‖²]（加权平均回报），实践中直接用 v̂(s,w) 近似即可获得绝大部分收益。这个例子也说明方差缩减是"免费午餐"：期望不变、方差变小，样本效率必然提升。REINFORCE with baseline 是文献与工程中 REINFORCE 的标准形态，代码只比原始版多一个"减去价值估计"的操作。

### 9.5.3 小结与衔接

综合改进方向，策略梯度方法的三条升级路径清晰浮现。路径一：基线技术（本章），用与动作无关的 b(s) 压低方差，代价是需要额外学习价值估计 v̂(s,w)——这恰好是第8章的方法，价值方法重新登场，只是角色从"主角"降为"助手"。路径二：用自举（bootstrap）替代完整回报——REINFORCE 用 MC 回报 G_t（无偏、高方差），如果改用 TD 目标 r_{t+1}+γv̂(s_{t+1},w)（有偏、低方差）来估计 qπ，更新可以做到"每步一次、无需完整回合"，这正是第10章 Actor-Critic 的核心改动：actor 用策略梯度更新策略，critic 用 TD 更新价值，两者交替进行，兼顾偏差与方差的平衡。路径三：信任域与自然梯度（trust region / natural gradient）——梯度上升的步长如果过大，更新后的策略可能与旧策略差异巨大，导致训练崩溃；用 KL 散度或 Fisher 信息矩阵约束"每次更新的策略变化幅度"，可以稳定大学习率训练，这是 PPO、TRPO 等现代算法的数学基础。三条路径不是互相排斥的，现代算法几乎同时使用全部三条：PPO=裁剪的代理目标（路径三）+ 优势估计（路径一）+ 价值辅助（路径二）。

决策框架也随之清晰：什么时候应该选择策略梯度方法？当动作空间连续或巨大、当最优策略本质随机、当需要平滑稳定的训练时，策略梯度是首选；而当动作空间小而离散、价值可精确表示、确定性策略已足够时，表格 Q 学习与 DQN 家族依然高效。两种范式最终在第10章汇合——Actor-Critic 同时容纳策略与价值，成为深度强化学习的主流框架。回顾本章：我们完成了从价值到策略的范式转换，建立了策略梯度定理这一理论基石，实现了 REINFORCE 这一最简算法，也看清了"高方差"这一核心痛点与"基线+自举+信任域"的改进地图。下一节将用一个贯穿性小问题把全章内容串成一条可操作的完整链条，随后转入平台实践，把同样的数学结构落到 tcmP 平台医者 Agent 的策略优化上。

把理论转化为工程决策，可以总结为一张"策略梯度适用性检查表"。第一项，动作空间形态：动作连续（关节力矩、剂量、转角）或离散但巨大（落子、组合选择）——是，优先策略梯度；动作少且离散（2-5 个）——价值方法通常更省。第二项，最优策略的随机性需求：任务存在对抗对手、隐藏信息、或同效多解（如中医"同病异治"）——策略梯度才能表达分布式行为；任务最优解唯一且确定——两者皆可，价值方法更简单。第三项，稳定性需求：系统对行为突变敏感（医疗、金融、机器人安全）——平滑更新是刚需；可接受离散切换（游戏、仿真）——价值方法可行。第四项，样本预算与数据来源：在线交互昂贵、只能离线学习——价值方法的异策略数据复用优势显著；交互廉价且可并行（模拟环境）——策略梯度（尤其 A3C 类并行架构）优势显著。第五项，收敛保证的期望：需要全局最优的强保证（小规模、可穷举）——表格价值方法；接受局部最优、追求表达力（大规模、复杂策略）——策略梯度。这张检查表不是教条，而是帮助读者建立"按任务特性选方法"的工程直觉：没有万能的算法，只有匹配的算法。在 tcmP 平台的语境中，医者 Agent 的方剂推荐恰好落在"动作离散但语义丰富、最优行为本质带概率、行为突变不可接受（临床安全）、数据来自真实问诊日志（宝贵）"的交叉点上——因此平台采用"策略梯度+检索增强"的混合架构，并在第10章引入价值估计（critic）来缓解样本压力，这正是检查表各项权衡在真实系统上的写照。
