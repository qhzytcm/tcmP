# 第9章 策略梯度方法（Policy Gradient Methods）

从第1章到第8章，本书的叙述始终沿着同一条主线展开：先定义马尔可夫决策过程（Markov Decision Process, MDP），再以贝尔曼方程（Bellman Equation）与贝尔曼最优方程（Bellman Optimality Equation）为核心工具，依次发展出动态规划（Dynamic Programming, DP）、蒙特卡洛（Monte Carlo, MC）、时序差分（Temporal-Difference, TD）以及带函数近似的价值函数方法（Value Function Methods）。在这条"基于价值"的路线上，策略始终是一个被动的角色：先估计状态价值或动作价值，再通过贪婪操作（greedy operation）从价值中提取策略。第8章完成了价值表示从表格到函数的升级，回应了贯穿全书的第二个问题"状态空间太大"；但第三个问题——"策略如何表示与优化"——仍然悬而未决：表格策略无法泛化到未访问状态，贪婪策略无法表达随机行为，连续动作空间更是无从枚举。本章将把策略本身推上舞台中央：不再"先估价值、再推策略"，而是直接把策略参数化为一个函数 π(a|s,θ)，并以梯度上升的方式在参数空间里优化它。这一转变不是技术细节的修补，而是一次范式转换——从基于价值（value-based）到基于策略（policy-based）的转换，也是全书的第三个里程碑。

范式转换的核心工具是策略梯度定理（Policy Gradient Theorem）。策略梯度方法要优化的目标是一个标量指标 J(θ)，它度量参数化策略 π(·|s,θ) 的总体表现。读者可能立刻会问：J(θ) 的表达式里含有状态分布与期望，没有环境模型根本算不出来，直接优化谈何容易？策略梯度定理给出了一个近乎神奇的回答：虽然 J(θ) 本身无法解析计算，但它的梯度 ∇θJ(θ) 可以写成"对数策略梯度乘以动作价值"的期望形式，即 ∇θJ(θ)=E_{S∼dπ,A∼π}[∇θ ln π(A|S,θ)·qπ(S,A)]。期望形式意味着它不需要模型，只需要沿着当前策略收集轨迹即可用随机梯度（stochastic gradient）来估计——这正是第6章随机逼近（Stochastic Approximation, SA）思想在策略侧的又一次运用。本章将给出该定理的完整推导：关键一步是 log-derivative trick（对数导数技巧），它把"概率的梯度"转化为"对数概率梯度的加权"，使采样成为可能；随后用平稳分布的递归关系消去状态分布梯度项。基于定理，最直接的算法是 REINFORCE（也叫蒙特卡洛策略梯度）：用完整回合的回报 G_t 作为 qπ 的估计，沿 ∇θ ln π(at|st,θt)·G_t 方向更新参数。REINFORCE 简单、无偏，但方差很高，这正是本章末尾要讨论的核心痛点，也是下一章 Actor-Critic 方法登场的理由。

本章的内容组织如下。9.1 节介绍策略的两种表示——表格策略与参数化策略，重点给出 softmax 策略与高斯策略（Gaussian policy）的数学形式；9.2 节论证策略梯度方法相比价值方法的四大优势，用石头剪刀布等例子说明"随机策略可以是最优的"这一反直觉事实；9.3 节是理论核心，完整推导并陈述策略梯度定理；9.4 节给出 REINFORCE 算法的思想、实现步骤与收敛性质，并附一个数值演算；9.5 节总结策略梯度方法的优缺点并介绍基线（baseline）这一方差缩减思想；9.6 节以贯穿性小问题做全章回顾；9.7 节深入 softmax 与高斯策略的梯度推导以及基线定理的数学细节；9.8 节把全章知识映射到 tcmP 平台——医者 Agent 的行为策略优化、病证单元（Disease-Symptom Unit, DSU）的"症状=状态、方剂=动作、证据等级=奖励"映射，并给出 REINFORCE mini 版实训；9.9 节是中医药语境与职业应用。学习本章需要第4章的策略与价值记号、第5章 MC 的回报估计、第6章的随机梯度下降，以及第8章函数近似的思维。建议读者在阅读9.3节时手推一遍定理的代数步骤——它值得。
