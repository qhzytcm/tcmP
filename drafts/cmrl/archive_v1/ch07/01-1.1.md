## [Part1] 7.1 TD 思想与算法家族

### 7.1.1 从 MC 到 TD：为什么要一步更新

让我们先回顾第5章蒙特卡洛方法的两大局限。第一，MC 必须等待一个回合结束才能更新价值估计，因为它的学习目标 $G_t = \sum_{k=0}^{T-t-1} \gamma^k r_{t+k+1}$ 依赖整条轨迹的奖励。对于没有终止状态的持续任务（continuing tasks），回合根本不存在，MC 无法直接使用；即使对于回合任务，等待也意味着在线学习机会的浪费——在回合进行中观测到的每一个"状态-奖励"对都被闲置。第二，MC 的估计方差大。$G_t$ 是许多随机变量的加权和，它同时包含转移随机性与奖励随机性，两条看似相似的轨迹回报可能差异悬殊；要使均值逼近期望，往往需要海量数据。时序差分（Temporal-Difference, TD）方法针对这两点给出了外科手术式的修正：每与环境交互一步，就立刻更新一次价值估计，学习目标不再是完整回报，而是"一步真实奖励 $r_{t+1}$ 加上后继状态价值估计的折扣值 $\gamma v_t(s_{t+1})$"。用记号写出来，TD(0) 对状态价值的更新式为

$$v_{t+1}(s_t) = v_t(s_t) - \alpha_t(s_t)\big[v_t(s_t) - \big(r_{t+1} + \gamma v_t(s_{t+1})\big)\big],$$

而所有其他状态的价值保持不变：$v_{t+1}(s) = v_t(s),\; s \neq s_t$。式中的 $\alpha_t(s_t)$ 是对应状态的学习率（learning rate）。注意一个容易被忽略的细节：每个时刻只更新被访问的那个状态的价值，这正是表格型（tabular）增量算法的标准形态——把学习率 $\alpha_t(s_t)$ 写在下标上，就是为了强调它是"状态相关的"。

上面这个看似简单的更新式，浓缩了 TD 方法的全部精髓。我们把 $r_{t+1} + \gamma v_t(s_{t+1})$ 称为 TD 目标（TD target），它是 $v_\pi(s_t)$ 的一个新的估计：与旧估计 $v_t(s_t)$ 相比，它多利用了"一步真实奖励"这一份经验信息，因而在直觉上"更可信"。把 $v_t(s_t) - (r_{t+1} + \gamma v_t(s_{t+1}))$ 称为 TD 误差（TD error），记作 $\delta_t$。之所以叫"时序差分"，正是因为 $\delta_t$ 本质上是两个相邻时刻价值估计之差：$v_t(s_t)$ 与 $r_{t+1} + \gamma v_t(s_{t+1})$ 的差。TD 目标中包含 $v_t(s_{t+1})$ 这一项，意味着我们在用"对后继状态的估计"去更新"对当前状态的估计"——这种用估计更新估计的做法称为自举（bootstrapping）。与 MC 对照：MC 的目标 $G_t$ 中不含任何估计，因而无偏（unbiased）但方差大；TD 的目标中含估计，因而有偏（biased）但方差小，且只需一步即可更新。这一"增量、低方差、有偏"的三重特征，正是 TD 方法区别于 MC 方法的核心。

### 7.1.2 算法家族总览与记号

TD 不是一个孤立的算法，而是一个家族。按学习对象的不同，本章的 TD 家族可分为两支：估计状态价值的 TD 算法（即 TD(0)，7.2 节）与估计动作价值的 TD 算法。动作价值这一支又按 TD 目标的构造方式分为三个成员：Sarsa（7.3 节）用后继时刻实际选择的动作 $a_{t+1}$ 的价值估计构成目标；n-step Sarsa（7.4 节）把单步经验推广为 n 步经验；Q-learning（7.5 节）用后继状态的最大动作价值构成目标。整个家族共享一套记号：$v_t(s)$ 表示第 $t$ 步对状态 $s$ 价值函数的估计，$q_t(s,a)$ 表示第 $t$ 步对动作价值函数的估计，$\alpha_t$ 表示学习率，$\gamma$ 表示折扣率（discount rate），$(s_t, a_t, r_{t+1}, s_{t+1})$ 表示第 $t$ 步到第 $t+1$ 步之间的经验元组。为统一起见，除非特别说明，本章假设折扣率 $\gamma \in [0,1)$ 或按任务取 $\gamma = 1$（如随机游走示例），学习率 $\alpha_t$ 满足 RM 条件，即 $\sum_{t=0}^{\infty} \alpha_t = \infty$ 且 $\sum_{t=0}^{\infty} \alpha_t^2 < \infty$。

读者在第6章已经熟悉了随机逼近（Stochastic Approximation, SA）的一般迭代格式 $w_{t+1} = w_t - \alpha_t g(w_t, \eta_t)$，其中 $g$ 是包含随机噪声 $\eta_t$ 的误差信号。现在可以指出一个贯穿本章的观察：TD 更新式正是这种 SA 迭代的特例，其误差信号取为 TD 误差 $\delta_t$。事实上，TD 学习算法可以视为求解贝尔曼方程或贝尔曼最优方程的随机逼近算法——这个视角将在 7.2.2 节与 7.6.1 节展开。TD 的优势正来自它的增量形式：不需要等待回合结束，因此天然支持在线（online）学习；只需要保存当前的价值估计表，内存开销极小；每一步的经验都立即转化为更新，样本利用率高。与第4章 DP 的全状态同步更新 $v_{k+1} = r_\pi + \gamma P_\pi v_k$ 相比，TD 每次只更新一个状态，却能在长期平均的意义上收敛到同一个解——因为它的更新方向是贝尔曼残差的无偏噪声估计。用一句话概括家族定位：DP 是"模型 + 自举"，MC 是"数据 + 无自举"，而 TD 是"数据 + 自举"，它兼有 DP 的信息快速传播与 MC 的无模型性。

### 7.1.3 例：随机游走——TD 与 MC 的直观对比

在正式定义 TD(0) 之前，我们先用原书中的经典实验——随机游走（random walk）——建立直觉。考虑一条由 5 个非终止状态 $A, B, C, D, E$ 排成的直线，两端各有一个吸收态（终止状态）：到达左端吸收态奖励为 0，到达右端吸收态奖励为 1，其余所有转移的即时奖励都是 0，折扣率 $\gamma = 1$。在每个非终止状态，智能体以等概率向左或向右移动一步；从中间状态 $C$ 出发，直至进入某个吸收态，一个回合结束。这个策略下的真实状态价值是 $v_\pi(A) = 1/6 \approx 0.167$，$v_\pi(B) = 2/6 \approx 0.333$，$v_\pi(C) = 3/6 = 0.5$，$v_\pi(D) = 4/6 \approx 0.667$，$v_\pi(E) = 5/6 \approx 0.833$——恰为从该状态出发最终到达右端的概率。现在分别用 TD(0) 与批量 MC（batch MC）从零开始估计这五个价值，学习率取 $\alpha = 0.1$。原书的实验结果表明：TD(0) 的估计误差随训练回合数下降的速度显著快于批量 MC——在约 100 个回合时 TD 的均方根误差已降至很低水平，而批量 MC 需要约 300 个回合才达到相近精度。

这个实验的结论对理解本章至关重要。为什么 TD 学得更快？因为 TD 在回合的每一步都进行更新，而且通过自举把"到达右端获得奖励"这一信息沿着轨迹逐步回传：一次访问右端附近的状态 $E$ 并观察到奖励 1，立即修正 $v(E)$；下一次访问 $D$ 时，TD 目标中包含新的 $v(E)$，于是 $v(D)$ 也随之修正。信息每经历一个回合就沿反方向传播一格，且回合内的每个状态都在同步受益。MC 则不同：它只在回合结束时一次性更新整条轨迹上的状态，且更新量完全由该回合的总回报决定，方差大。TD 之所以方差小，是因为它的学习目标只包含一步转移的随机性；之所以有偏，是因为目标中含有的后继状态估计 $v_t(s_{t+1})$ 本身未必准确。这个例子还给出一个形象的类比：医生的学习如果采用"TD 式"，就是每观察到患者一个新症状就修正一次对证候的判断；如果采用"MC 式"，就要等患者完全痊愈后才总结整段病程。前者即时、渐进、波动小，正是本章将要展开的 TD 家族；我们由此进入 7.2 节对 TD(0) 的形式化定义。
