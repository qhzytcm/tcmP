## [Part1] 7.6 统一视角：TD 家族与本章小结

### 7.6.1 统一视角：TD 家族都是随机逼近算法

把本章算法放在一起，可以发现它们共享同一个骨架。所有动作价值 TD 算法都可写成通用形式

$$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t\big[q_t(s_t, a_t) - \bar{q}_t(s_t, a_t)\big],$$

其中 $\bar{q}_t(s_t, a_t)$ 是 TD 目标，不同算法只是目标构造不同：Sarsa 为 $\bar{q}_t = r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$（采样后继动作）；期望 Sarsa 为 $\bar{q}_t = r_{t+1} + \gamma \sum_{a'} \pi(a'|s_{t+1}) q_t(s_{t+1}, a')$（策略期望）；Q-learning 为 $\bar{q}_t = r_{t+1} + \gamma \max_{a'} q_t(s_{t+1}, a')$（最优后继）。状态价值版 TD(0) 也归入同一骨架：$\bar{v}_t = r_{t+1} + \gamma v_t(s_{t+1})$。更深刻的是，各目标的条件期望恰好是相应方程的右端：Sarsa 与期望 Sarsa 的目标期望是动作价值贝尔曼方程（$\pi$ 为行为策略时）的右端，Q-learning 的目标期望是贝尔曼最优方程的右端。因此整个 TD 家族可一言以蔽之：它们都是求解某个贝尔曼方程（Sarsa 一族）或贝尔曼最优方程（Q-learning）的增量式随机逼近算法——TD 目标是方程右端的估计，TD 误差是残差的带噪声观测，更新式是第6章 RM 迭代的直接实例化。

这个视角可用"三大方法对比"收束（原书核心结论）：动态规划 = 模型 + 自举，需要转移概率与奖励函数，全状态同步迭代，典型算法为策略迭代与值迭代；蒙特卡洛 = 数据 + 无自举，使用完整回报，等待回合结束，无偏但方差大；TD = 数据 + 自举，使用一步（或 n 步）经验与后继估计，每步在线更新，有偏但方差小。三个维度——是否需要模型、是否自举、何时更新——把所有方法定位在同一个空间中：DP 与 TD 共享自举（信息快速传播），MC 与 TD 共享数据驱动（无需模型），TD 独占兼有两者的优点。代价是 TD 的有偏性在函数近似（第8章）情形下可能导致不收敛，而表格情形下 SA 理论给出严格保证。理解这三点，就理解了 TD 为何是实际应用中最常用的一族方法。

### 7.6.2 期望 Sarsa 与批量 TD

期望 Sarsa（Expected Sarsa）是 Sarsa 与 Q-learning 之间的插值，更新式为

$$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t\Big[q_t(s_t, a_t) - \Big(r_{t+1} + \gamma \sum_{a'} \pi(a'|s_{t+1}) q_t(s_{t+1}, a')\Big)\Big],$$

即对后继动作取策略 $\pi$ 的加权平均。与 Sarsa 相比，它不再对后继动作单次采样，消除了动作采样方差——动作数有限时是"以少量计算换方差降低"的划算交易；与 Q-learning 相比，用加权平均替代 $\max$：若 $\pi$ 为行为策略，算法是同策略的（可视为"方差更小的 Sarsa"）；若 $\pi$ 为贪婪策略，加权平均退化为 $\max$，恰好退化为 Q-learning。因此 Q-learning 是期望 Sarsa 的贪婪特例，期望 Sarsa 则是"乐观旋钮"：从完全按当前策略加权（同策略、保守）到完全取最优（异策略、乐观）。数值例：设 $s'$ 处 $\pi(\text{左}) = 0.5$、$\pi(\text{右}) = 0.5$，表值 $q(s', \text{左}) = 0.1$、$q(s', \text{右}) = 0.3$，$r = 0$，$\gamma = 0.9$，则期望 Sarsa 的 TD 目标为 $0.9 \times (0.5 \times 0.1 + 0.5 \times 0.3) = 0.18$；Sarsa 采样只得 $0.09$ 或 $0.27$ 之一；Q-learning 取 $0.27$——三者目标的不同，正是"采样随机性、策略平均、乐观估计"三种哲学的分野。

批量 TD（batch TD）从"数据使用方式"维度补全家族版图。在线算法每获得一步经验立即更新；批量方式先收集一批数据，再反复扫描、以批内经验平均为更新方向直至收敛。批量 TD 的收敛值具有深刻性质——确定性等价（certainty equivalence）：它收敛到"由这批数据构造的最大似然马尔可夫决策过程"的精确解，即把经验频率当作转移概率、经验平均奖励当作真实奖励后，对经验模型求解贝尔曼方程。换言之，批量 TD 隐含完成"从数据学模型，再在学到的模型上求解"两步工作；批量 MC 则收敛到批内完整回报的简单平均，不利用转移结构。原书经典对照表明，有限数据下批量 TD 的收敛值常优于批量 MC——因为 TD 通过自举利用了数据中的转移结构约束。例7.5 给出数值演示。

### 7.6.3 例7.5：批量 TD 的收敛值演算与本章小结

例7.5：环境含两状态 $s_1, s_2$，采集三条数据：$D_1: s_1 \to s_2$，奖励 0；$D_2: s_2 \to s_1$，奖励 1；$D_3: s_2 \to s_1$，奖励 1。$\gamma = 0.9$。求批量 TD 收敛值。由确定性等价原理，经验模型为：从 $s_1$ 以概率 1 转移到 $s_2$、奖励 0；从 $s_2$ 以概率 1 转移到 $s_1$、奖励 1。贝尔曼方程：$v(s_1) = 0 + 0.9 v(s_2)$，$v(s_2) = 1 + 0.9 v(s_1)$。联立得 $v(s_1) = 0.9(1 + 0.9 v(s_1)) = 0.9 + 0.81 v(s_1)$，即 $0.19 v(s_1) = 0.9$，$v(s_1) \approx 4.74$，$v(s_2) \approx 5.26$。读者可验证：从 $v = 0$ 出发按 $D_1, D_2, D_3$ 反复扫描并执行 $v(s) \leftarrow r + \gamma v(s')$，第一轮得 $v(s_1) = 0$、$v(s_2) = 1$；第二轮 $v(s_1) = 0.9$、$v(s_2) = 1.81$；第三轮 $v(s_1) = 1.629$、$v(s_2) = 2.466$……单调上升收敛到约 $(4.74, 5.26)$。作为对照，批量 MC 在此数据上无法应用：三条数据无一到达终止状态，MC 无法构造完整回报——这正是 TD 在持续任务（continuing tasks）中相对 MC 的天然优势。

至此本章理论版图完整。请读者回顾知识地图：TD 核心思想（7.1）是"一步经验 + 自举"；TD(0)（7.2）用目标 $r_{t+1} + \gamma v_t(s_{t+1})$ 估计状态价值，是求解贝尔曼方程的随机逼近；Sarsa（7.3）搬到动作价值，同策略，学到行为策略（含探索）的价值；n-step Sarsa（7.4）把一步经验推广为 n 步，是偏差-方差旋钮；Q-learning（7.5）用 $\max$ 直接求解 BOE，异策略，代价是最大化偏差；期望 Sarsa 与批量 TD（7.6）分别从"目标构造"与"数据使用"补全版图。本章是后续章节的引擎：第8章价值函数近似将把 TD 与函数逼近结合（DQN 即 Q-learning + 深度网络 + 三个关键技巧），第10章 Actor-Critic 将用 TD 误差作 critic 的更新信号。进入这些内容前，请确保能回答三个问题：每个算法的 TD 目标是什么？它在求解哪个方程？它的偏差、方差、同/异策略属性是什么？下一节，我们把数学结论映射到 tcmP 中医药智能平台，观察 Q-learning 如何在"对话日志"这一天然数据流上在线进化。
