## [Part1] 7.3 Sarsa 算法

### 7.3.1 Sarsa 算法：从状态价值到动作价值

TD(0) 解决了"给定策略 $\pi$ 估计 $v_\pi$"的问题，但控制需要动作价值：选择哪个动作最优取决于 $q_\pi(s,a)$，而 $v_\pi(s)$ 无法给出动作排序。Sarsa 把 TD 思想推广到动作价值，更新式为

$$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t\big[q_t(s_t, a_t) - \big(r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})\big)\big],$$

其中 $a_{t+1}$ 是按当前行为策略在 $s_{t+1}$ 处实际选择的动作；除 $(s_t, a_t)$ 外其他条目不变。算法名字来自五元组 $(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})$——一次学习事件恰好由五个要素构成，取首字母即得 Sarsa。与 TD(0) 逐状态更新对应，Sarsa 逐"状态-动作对"更新；TD 目标 $r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$ 包含两类随机性：一步经验（奖励与后继状态的随机性）与按策略选择 $a_{t+1}$ 的随机性。

Sarsa 是同策略（on-policy）算法，这是它与 Q-learning 的根本分野。同策略指生成数据的行为策略（behavior policy）与被估计、被优化的目标策略（target policy）是同一个策略。Sarsa 的 TD 目标必须使用实际选择的 $a_{t+1}$，而不是最优动作或期望动作——这个动作正是行为策略采样出来的。因此 Sarsa 学到的是行为策略自身的价值：若行为策略是 ε-贪婪（ε-greedy），Sarsa 估计的就是这个含探索策略的价值，探索概率 $\varepsilon$ 较大时价值会被"打折"。把 Sarsa 的价值更新与贪婪策略改进（$\pi'(s) = \arg\max_a q(s,a)$）交替进行，就构成完整的策略迭代式控制：先估计当前策略价值，再按估计改进策略，与第4章策略迭代同构，只是价值评估从"解贝尔曼方程"换成"TD 采样估计"。

### 7.3.2 Sarsa 的实现与直觉

Sarsa 的完整算法（含策略改进）按如下步骤实现。第一步，初始化 $q$ 表（通常全 0）与行为策略（通常 ε-贪婪）。第二步，对每个回合：初始化状态 $s$，按策略选动作 $a$；对每步：执行 $a$、观测 $(r, s')$、按策略在 $s'$ 处选 $a'$、更新 $q(s,a) \leftarrow q(s,a) - \alpha[q(s,a) - (r + \gamma q(s',a'))]$、令 $s \leftarrow s'$、$a \leftarrow a'$，直至终止。第三步，$\varepsilon$ 随回合数衰减（如 0.5 线性降至 0.05），使算法从充分探索平滑过渡到利用。两个实现细节必须注意：其一，$a'$ 必须在更新前选定，因为更新式需要 $q(s',a')$——这是 Sarsa 与 Q-learning 代码结构的关键差异；其二，$s'$ 为终止状态时 $q(s',a')$ 取 0，TD 目标退化为 $r$。

Sarsa 的直觉：$q_t(s_t, a_t)$ 是对"在 $s_t$ 执行 $a_t$、之后一直按行为策略行事"这一承诺的长期价值估计。承诺的价值应等于本步即时回报加上后继按策略行事的总价值估计，这正是动作价值贝尔曼方程 $q_\pi(s,a) = \mathbb{E}[r_{t+1} + \gamma q_\pi(s_{t+1}, a_{t+1}) \mid s_t = s, a_t = a]$（$a_{t+1} \sim \pi(\cdot|s_{t+1})$）的表述——Sarsa 用一步经验加后继估计去逼近它，因而是求解动作价值贝尔曼方程的随机逼近算法。类比：带教医师每开一剂药，复诊时获得"即时反馈 + 对病势的预判"，据此修正对药的价值判断。收敛性：在 RM 条件与充分探索下，$q$ 表收敛到行为策略的价值；若 $\varepsilon$ 渐近衰减到 0，则收敛到 $q^*$。

### 7.3.3 例7.2：两状态两动作的逐步演算

用两状态两动作的微型问题演算 Sarsa。环境：$s_1$ 处可选"左"（奖励 $-1$，终止，模拟陷阱）与"右"（奖励 0，到 $s_2$）；$s_2$ 处可选"右"（奖励 1，终止）。$\gamma = 1$，$\alpha = 0.1$，初始 $q$ 全 0；行为策略 ε-贪婪（$\varepsilon = 0.2$）。回合 1：$s_1$ 选"右"（到 $s_2$），$s_2$ 选"右"（奖励 1，终止）。更新 $(s_1, \text{右})$：TD 目标 $0 + \gamma q(s_2, \text{右}) = 0$，$\delta = 0$，不变。更新 $(s_2, \text{右})$：TD 目标 $1$，$\delta = 0 - 1 = -1$，更新 $q(s_2, \text{右}) = 0.1$。回合 2 走相同轨迹：更新 $(s_1, \text{右})$：TD 目标 $0 + 0.1 = 0.1$，$\delta = -0.1$，更新 $q(s_1, \text{右}) = 0.01$；更新 $(s_2, \text{右})$：TD 目标 $1$，$\delta = -0.9$，更新 $q(s_2, \text{右}) = 0.19$。可以看到 $s_2$ 处的奖励信息通过自举在回合 2 传到 $s_1$：$q(s_1, \text{右})$ 的目标中包含 $q(s_2, \text{右})$ 的最新值。若回合 3 中在 $s_1$ 处探索选了"左"：TD 目标 $-1$，$\delta = 1$，更新 $q(s_1, \text{左}) = -0.1$——陷阱动作价值立刻被压低，且本回合 $s_2$ 不被访问，$q(s_1, \text{右})$ 保持不变。这正是同策略特征：只更新实际走过的状态-动作对，学到当前含探索策略的价值。

本例的行为模式在原书的悬崖行走（Cliff Walking）问题中有经典演示：智能体须沿悬崖边缘从起点走到终点，跌崖惩罚 $-100$。Sarsa 学出的路径贴着悬崖但保持一格距离——因为其价值计入了"探索可能跌崖"的因素，ε-贪婪策略在悬崖边缘确有概率跌下去；Q-learning（7.5 节）学出的路径紧贴悬崖边缘——因为它估计纯贪婪策略的价值，认为不会跌崖。两种路径无绝对优劣：Sarsa 稳健保守，Q-learning 激进但充分探索后更接近最优。差异的根源正是同策略与异策略之别，7.5.3 节将用同一环境的数据并排演算，把这一差别看得更清楚。
