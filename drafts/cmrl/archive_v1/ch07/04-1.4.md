## [Part1] 7.4 n-step Sarsa

### 7.4.1 n-step 回报：Sarsa 与 MC 的插值

Sarsa 的 TD 目标只利用一步经验：$r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$；蒙特卡洛方法的目标则是完整回报 $G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}$，需要等待回合结束。n-step Sarsa 提供了一条介于两者之间的连续谱系：把学习目标从"1 步经验 + 1 步自举"推广为"n 步经验 + n 步后的自举"。具体地，定义 n 步回报（n-step return）

$$G_{t:t+n} = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots + \gamma^{n-1} r_{t+n} + \gamma^n q_t(s_{t+n}, a_{t+n}),$$

其中前 n 项是真实的奖励观测，最后一项是第 n 步后继状态-动作对的价值估计（自举项）。当 $n = 1$ 时，$G_{t:t+1} = r_{t+1} + \gamma q_t(s_{t+1}, a_{t+1})$，恰好是 Sarsa 的 TD 目标；当 $n \to \infty$ 时，若回合在第 $t+n$ 步终止，则 $G_{t:t+n}$ 退化为完整回报 $G_t$，即蒙特卡洛目标。因此，n-step Sarsa 把 Sarsa 与 MC 统一在同一框架之下：$n$ 是从 1 到无穷的旋钮，旋转这个旋钮，我们就在"完全自举"与"完全无自举"之间连续过渡。

$n$ 的选择实质上是在偏差（bias）与方差（variance）之间做权衡。$n$ 越大，学习目标中真实奖励的项越多、自举项 $\gamma^n q_t(s_{t+n}, a_{t+n})$ 的系数越小，因而目标受"后继价值估计误差"的影响越小——偏差越小，当 $n \to \infty$ 时目标无偏。但与此同时，目标包含的随机变量越多，样本方差越大：奖励 $r_{t+1}, \ldots, r_{t+n}$ 每一个都携带环境随机性，n 步积累的噪声远大于 1 步。反过来，$n$ 越小，自举越强、目标含估计误差的偏差越大，但方差越小，且信息回传越快——每走一步就可以更新一次。这个权衡可以概括为一句话：自举项是"估计的估计"，携带系统性偏差；真实奖励是"观测"，携带随机噪声；n-step 方法让我们按需调配两者的比例。在工程实践中，$n$ 取 3 到 5 常能取得较好的折中，但最优值高度依赖任务：奖励噪声大的任务宜用小 $n$，奖励结构稀疏而转移确定的任务可用大 $n$。这一偏差-方差视角在统计学习中有广泛的对应物，也是理解整个 TD 家族性能特征的主线。

### 7.4.2 n-step Sarsa 算法与实现

n-step Sarsa 的更新式为 $q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t\big[q_t(s_t, a_t) - G_{t:t+n}\big]$，即在时刻 $t$ 用 n 步回报 $G_{t:t+n}$ 更新 $n$ 步之前访问的状态-动作对 $(s_t, a_t)$ 的价值。注意时间索引的错位：在时刻 $t+n$（已经观察到 $r_{t+1}, \ldots, r_{t+n}$ 与 $s_{t+n}, a_{t+n}$）才能计算 $G_{t:t+n}$，进而更新 $(s_t, a_t)$。因此实现上需要维护一个长度为 $n$ 的缓冲区，保存最近 $n$ 步的"状态-动作-奖励"记录；每前进一步，计算对应记录的 n 步回报并更新其价值。算法流程如下：第一步，初始化 $q$ 表、缓冲区与行为策略（ε-贪婪）；第二步，对每个回合：初始化状态 $s_0$，按策略选择 $a_0$，并把 $s_0$ 加入缓冲；第三步，对 $t = 0, 1, 2, \ldots$：执行动作 $a_t$，观测 $r_{t+1}, s_{t+1}$；若 $s_{t+1}$ 非终止，按策略选择 $a_{t+1}$ 并入缓冲，否则令 $a_{t+1}$ 为"无"；若 $t \geq n$ 或回合已终止，则用 $G_{t-n:t}$ 更新 $q(s_{t-n}, a_{t-n})$；第四步，直至回合终止，用剩余的实际回报依次更新缓冲中尚未更新的条目（此时自举项为 0，因为已到达终止）。

回合提前终止时的处理值得专门说明。若轨迹在第 $T$ 步终止（$T < t + n$），则对尚未更新的状态-动作对 $(s_t, a_t)$，其 n 步回报退化为从 $t$ 到终止的完整回报 $G_t = \sum_{k=0}^{T-t-1} \gamma^k r_{t+k+1}$，自举项消失——因为终止状态之后没有动作可自举。这是自然的处理方式，也使 n-step Sarsa 与 MC 在回合末端平滑衔接。下面通过例7.3 演示 n 步回报的计算。设一条轨迹的即时奖励为 $r_1 = 2$，$r_2 = 3$，$r_3 = 4$，$r_4 = 5$，第 4 步后到达终止状态，折扣率 $\gamma = 0.9$，终止状态价值为 0。则：$G_{1:1} = r_1 + \gamma q(s_2, a_2) = 2 + 0.9 q(s_2, a_2)$；$G_{1:2} = r_1 + \gamma r_2 + \gamma^2 q(s_3, a_3) = 2 + 2.7 + 0.81 q(s_3, a_3) = 4.7 + 0.81 q(s_3, a_3)$；$G_{1:3} = 2 + 2.7 + 3.24 + 0.729 q(s_4, a_4) = 7.94 + 0.729 q(s_4, a_4)$；$G_{1:4} = 2 + 2.7 + 3.24 + 3.645 = 11.585$（第 4 步已终止，无自举项，即 MC 回报）。观察数值结构：随着 $n$ 从 1 增大到 4，真实奖励的累计值从 2 增长到 11.585，自举项系数从 $0.9$ 递减到 0——目标从"几乎全是估计"平滑过渡到"完全是观测"。若 $q$ 表当前偏差很大，小 $n$ 会把偏差通过自举项传播得更远；若奖励噪声很大，大 $n$ 会放大方差。这就是"旋钮"的力学原理。

### 7.4.3 n-step 在 TD 家族中的位置与选择

n-step Sarsa 在 TD 家族中的定位可以画成一条谱系：蒙特卡洛（$n = \infty$）— n-step Sarsa（$1 < n < \infty$）— Sarsa（$n = 1$）。沿着这条谱系，偏差从 0 单调增大、方差从大单调减小、信息回传速度从"回合结束一次"提高到"每步一次"。这个连续谱系的价值在于：它把"用多少步经验构造学习目标"从二选一的选择题变成了可调节的连续参数，使算法设计者能够针对具体任务的噪声结构做精细调优。n-step Sarsa 也带来两点代价。其一，更新有延迟：$(s_t, a_t)$ 的价值要等到第 $n$ 步之后才能更新，在线学习体验略逊于一步更新；其二，需要 n 步缓冲区，内存与实现复杂度增加。此外，n-step 回报中自举项使用的价值估计 $q_t(s_{t+n}, a_{t+n})$ 是"过期"的——它来自 $n$ 步之前的值函数，而非最新值函数；在函数近似（第8章）情形下这种"过期性"会引入额外偏差，需要谨慎处理。

n-step 思想在后续章节中有两处重要的延伸。第一，把 n 步回报推广为"加权平均的 n 步回报"就得到 TD(λ) 方法与资格迹（eligibility trace）方法：对 $n = 1, 2, \ldots$ 的回报按 $\lambda^{n-1}$ 加权求和，λ 成为又一个"旋钮"——λ 越接近 1 越像 MC，越接近 0 越像一步 TD。第二，在函数近似与深度强化学习中，n-step 目标（如 DQN 的 n-step 变体）常比一步目标收敛更快，因为它更充分地利用了奖励信息。从学习方法论看，n-step 方法给读者的核心启示是：TD 家族并非几个孤立的算法，而是一个由"经验长度 n"与"自举强度"参数化的连续空间，理解这个空间的结构，比记住单个公式更重要。读者可以自行验证一个简单事实：在例7.1 的四状态链上改用 n=2 的回报，$s_1$ 的价值在第一个回合就会收到 $s_3$ 的信息（因为 $G_{t:t+2}$ 包含两步奖励与两步后的估计），信息传播速度比 n=1 快一倍——这正是"n 是调节旋钮"的最直接证据。下一节，我们将引入 TD 家族中最著名的成员 Q-learning，它把 n-step 的"经验长度"问题抛在一边，转而用最大值运算直接求解贝尔曼最优方程。
