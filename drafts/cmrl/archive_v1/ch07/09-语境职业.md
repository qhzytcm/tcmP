## [Part2] 7.8 中医药语境与职业应用

### 7.8.1 中医辨证的场景化理解

把本章的 TD 概念翻译成中医语言，会得到一幅自然的对应图景。四诊信息——望闻问切采集的症状集合——构成状态 $s$：如"失眠、心烦、舌红少苔、脉细数"是一个状态。辨证结论与治法方药构成动作 $a$：如"滋阴降火、交通心肾，予天王补心丹"。疗效转归构成奖励 $r$：症状缓解、复诊改善为正奖励，不良反应、病情反复为负奖励。在此映射下，TD 目标 $r_{t+1} + \gamma v(s_{t+1})$ 的中医含义是"本方剂的即时反馈，加上对后续证候演变的预后估计"；自举对应中医"以方测证"——用一次用药反馈修正对证候的判断，不必等病人完全痊愈（MC 式）才总结。每一次诊疗都是一次对"辨证-方剂价值"贝尔曼方程的随机逼近：$v_\pi(s)$ 是按诊疗策略 $\pi$ 长期干预的预期健康收益，TD 误差 $\delta_t$ 是"本次辨证判断与经验证据的差距"——差距大，说明辨证需修正。

### 7.8.2 tcmP 平台映射

在 tcmP 平台中，本章知识有明确的对应物。六者 Agent 中，医者 Agent 是策略执行者（对应 actor，第10章展开），药者 Agent 的审方 reject/accept 是安全维度的奖励源，规者 Agent 的质控指标构成"证据等级"维度的评估信号，患者 Agent 提供环境反馈。病证单元（DSU）是状态-动作的知识载体：平台病证库有 60000+ 病证单元（教学切片 103+），每个 DSU 内含症状（状态）、方剂（动作）、证据等级映射分（奖励）——这正是本章 Q 表"先验初始化"的来源。医圣 Agent（sage-zhang-zhongjing）的 SOUL 承载张仲景六经辨证规则，构成策略先验：初始 Q 表可用病证库证据分填充（而非全零），对话日志再驱动在线调优——"医圣成长路径"即"先验知识初始化 + 经验在线进化"。平台算法对应：Sarsa 学当前诊疗流程的价值（同策略），Q-learning 离线重放日志学最优辨证（异策略），批量 TD 对应 CI/CD 定期离线批量进化。症状文本经 tcm_embed 向量化后即第8章特征 $\phi(s)$ 的前奏。

### 7.8.3 医案与病证数据示例

用三个真实病证单元演示本章概念。失眠 DSU：症状 = 入睡困难、多梦、心悸；辨证 = 心肾不交；候选动作 = {酸枣仁汤, 天王补心丹, 交泰丸}；证据等级映射分 = 系统综述 ≥ 0.8、随机对照试验 0.6~0.8、专家共识 0.4~0.6。感冒 DSU：症状 = 恶寒发热、头身痛、脉浮；动作 = {荆防败毒散（风寒）, 银翘散（风热）}。头痛 DSU：症状 = 头痛、项强、脉弦；动作 = {川芎茶调散（风寒头痛）, 天麻钩藤饮（肝阳上亢）}。演示一次 Q-learning 更新：状态 = 失眠症状组，动作 = 天王补心丹，检索证据分归一化后为 0.72，则 $Q(\text{失眠}, \text{天王补心丹}) \leftarrow 0 + 0.1 \times (0.72 - 0) = 0.072$；若药者审方拒绝（如与既往用药冲突），奖励取 $-1$，Q 值大幅下降。三份信号——证据等级 = 先验奖励、药者审方 = 实时负奖励、复诊转归 = 长期回报——完整复现了本章"即时奖励 + 自举 + 长期价值"的结构。

### 7.8.4 职业应用·临床医师

临床医师的强化学习应用围绕"辨证决策辅助、诊疗路径优化、师带徒学习"展开。辨证决策辅助：门诊中实时推荐 Top-K 辨证结论与方剂——Q 表检索替代静态规则；鉴别诊断时利用"相似症状状态的 Q 值差异"提示未考虑的病机；推荐理由中标注证据等级（奖励信号的解释性）。方法与工具链：医者 Agent 对话接口（/consult/sage-zhang-zhongjing）获取交互上下文 → 语义检索证据分（/semantic-search）→ 结合 Q 表排序输出候选 → 药者审方反馈回写更新；工具包括平台 API、tcm_embed、Q 值热力图看板。价值：减少漏诊（探索未纳入考虑的病机）、规范辨证流程（策略可审计）、持续积累名医经验（日志即训练数据）。必须强调安全边界：Q 表输出仅供参考，最终辨证权在医师手中——平台人格边界规定医者 Agent"不直接开具剂量"，对应强化学习的"人在回路"约束。

诊疗路径优化：把"首诊 → 复诊 → 转归"建模为马尔可夫决策过程，用 TD 学习最优随访策略——何时复查、何时调方、何时转诊，优化规者指标（床位周转率、复诊依从性）；此时状态 = 病情分期 + 治疗阶段，动作 = 随访决策，奖励 = 转归 + 资源效率。师带徒学习：把名老中医的历史医案作为经验重放数据（异策略的天然场景），学生（新医者 Agent）用 Q-learning 从老师日志中学习——TD 的自举特性使"每次跟诊的一步反馈"都能即时修正学生的辨证估计，无需等病例完整结束，这正是"跟诊随记"的教学本质。趋势：人机协同辨证（AI 提示 + 医师决策 + 反馈闭环）、多 Agent 联合诊疗（医者-药者-规者相互制约）、辨证路径循证审计。职业素养要求：理解 Q 值是长期期望而非单次疗效，能把临床反馈转化为奖励设计（复诊转归如何量化），具备识别"算法高估"（最大化偏差）的批判意识。

### 7.8.5 职业应用·医工器械

医工器械的强化学习应用围绕"可穿戴数据学习、康复设备自适应、诊疗仪器智能化"展开。可穿戴设备（腕表、贴片采集脉率、睡眠、运动）提供连续状态流：状态 = 实时生理特征（如心率变异性、睡眠分期），动作 = 干预参数，奖励 = 健康改善指标。这是 TD"每步更新"的天然场景——流式数据没有回合边界，MC 无法使用，TD 的低等待特性恰好适配；典型应用如睡眠障碍的个性化干预（失眠 DSU 动态调参）、慢病管理中用药提醒时机的学习。康复设备（外骨骼、电刺激仪）参数自适应：动作 = 设备参数档位，奖励 = 康复进度指标（步态对称度、关节活动度），TD 在步态康复中实时学习"下一步参数"，设备随患者状态动态调整。方法与工具链：传感器数据预处理（特征提取）、械者 Agent 对接平台、Q 表（参数离散）或函数近似（参数连续，第8章）实现。

诊疗仪器智能化：脉诊仪、舌象仪、经络检测仪把"望闻问切"客观化为结构化四诊特征——直接构成状态空间；Q-learning 可在仪器推荐环节学习"检查路径优化"（先查什么、何时复测），减少检查次数、提高阳性检出率。医工人员应关注三条趋势：其一，器械侧 TD 在线学习与医疗安全的冲突——设备参数更新必须有可解释性、审计日志与回滚机制，这是规者/法者 Agent 的约束落地；其二，从表格 Q 到函数近似——设备参数连续化后需用价值网络替代 Q 表（第8章 DQN 的舞台）；其三，联邦学习与隐私保护——多中心数据不出院，仅上传 Q 表更新或梯度，TD 的增量形式天然支持增量式联邦聚合。职业素养提示：医工人员需同时具备算法能力（实现 Q 学习并诊断不收敛）与临床安全认知——奖励设计不当会学到危险参数（如为追求步速而忽略安全），必须设置约束惩罚（负奖励）与硬边界（合规红线），这正是本章"奖励工程决定学习行为"结论的职业延伸。
