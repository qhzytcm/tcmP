## [Part1] 第7章 时序差分方法（Temporal-Difference Methods）：章引言

在进入本章之前，读者已经掌握了两种求解价值函数的基本路径。第4章的动态规划（Dynamic Programming, DP）方法依赖完整的环境模型，通过贝尔曼算子反复迭代求得价值函数；第5章的蒙特卡洛（Monte Carlo, MC）方法则完全不需要模型，只用采样得到的完整回合回报 $G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots$ 来估计价值。然而，这两种方法各有明显的短板：DP 要求已知转移概率与奖励函数，这在真实系统中几乎不可得；MC 必须等到一个回合完全结束才能更新价值估计，对于没有终止状态的持续任务（continuing tasks）根本无法使用，即使对于有终止状态的回合任务，它也浪费了回合进行过程中已经观测到的丰富信息。本章将要介绍的时序差分（Temporal-Difference, TD）方法，正是针对这两大短板的回应：它既不需要环境模型，也不需要等待回合结束，每与环境交互一步，就立刻用"一步真实奖励加上对后继状态的当前估计"构成学习目标，更新价值估计。这个目标中带有"当前估计"的部分，称为自举（bootstrapping）；而算法名称"时序差分"的来源，正是其误差信号是两个相邻时刻价值估计之差。

本章的知识结构围绕一条主线展开：TD 方法是求解贝尔曼方程或贝尔曼最优方程的增量式随机逼近（Stochastic Approximation, SA）算法。7.1 节从 MC 的局限出发引出 TD 的核心思想，并给出整个 TD 算法家族的谱系与统一记号；7.2 节介绍估计状态价值的 TD(0) 算法，建立"TD 目标（TD target）""TD 误差（TD error）"两个基本概念，并从随机逼近视角说明其收敛性；7.3 节把 TD 思想从状态价值推广到动作价值，得到同策略（on-policy）的 Sarsa 算法；7.4 节介绍 n 步 Sarsa（n-step Sarsa），它是 Sarsa 与 MC 之间的中间地带，为偏差与方差的权衡提供了一个可调节的旋钮；7.5 节介绍最经典的 Q-learning 算法，它用最大值运算直接求解贝尔曼最优方程，是异策略（off-policy）算法的代表；7.6 节给出统一视角，说明整个 TD 家族都是某个贝尔曼方程的随机逼近算法，并介绍期望 Sarsa（Expected Sarsa）与批量 TD（batch TD）两个重要变体。在理论之后，7.7 节把 Q-learning 与 tcmP 中医药智能平台的在线进化机制对接，7.8 节给出中医药语境下的重新诠释与临床医师、医工器械两类职业的应用场景。

本章的阅读需要第4章（贝尔曼方程）、第5章（蒙特卡洛方法）与第6章（随机逼近）的知识作为支撑，尤其是第6章建立的随机逼近框架——学习率满足罗宾斯-门罗（Robbins-Monro, RM）条件 $\sum_t \alpha_t = \infty$、$\sum_t \alpha_t^2 < \infty$——将是理解 TD 收敛性的直接工具。学完本章，读者应当达到以下目标。知识目标：能够写出 TD(0)、Sarsa、n-step Sarsa、Q-learning、期望 Sarsa 的更新公式，准确解释自举、采样、同策略与异策略、偏差与方差等概念的数学含义。能力目标：能够对小型马尔可夫决策过程手工演算每一步 TD 更新，能够设计 ε-贪婪（ε-greedy）探索策略并在 tcmP 平台的语义检索接口上实现一个 mini Q-learning 实验。素养目标：树立"任何增量式学习算法本质上都是对某个算子方程的随机逼近求解"的数学观，并能把这一视角迁移到辨证决策、康复设备自适应等真实问题中。在阅读过程中，建议读者始终抓住"TD 目标是什么、TD 误差是什么、这个更新在求解哪个方程"这三个问题，它们是理解本章乃至后续第8章价值函数近似与第10章 Actor-Critic 方法的关键线索。
