## [Part1] 7.2 TD 状态价值算法（TD(0)）

### 7.2.1 TD(0) 算法：定义与更新规则

本节给出估计状态价值的 TD 算法——TD(0) 的严格定义。问题设定：给定策略 $\pi$，目标是用与环境交互产生的经验样本估计 $v_\pi$，不需要知道转移概率与奖励函数，只需按 $\pi$ 行动并观测元组 $(s_t, a_t, r_{t+1}, s_{t+1})$。TD(0) 的更新规则为

$$v_{t+1}(s_t) = v_t(s_t) - \alpha_t(s_t)\big[v_t(s_t) - \big(r_{t+1} + \gamma v_t(s_{t+1})\big)\big], \qquad v_{t+1}(s) = v_t(s),\; \forall s \neq s_t.$$

算法流程：初始化价值估计（通常全 0）；对每个回合，从初始状态出发，每步按 $\pi$ 选动作、观测奖励与后继状态、仅对被访问的状态 $s_t$ 执行更新，其余状态不变，直至回合结束。三点值得强调。其一，每个时刻只更新一个状态，这是表格型增量算法的标志，与第4章 DP 的全状态同步更新形成鲜明对比。其二，学习率 $\alpha_t(s_t)$ 状态相关，常取为随访问次数衰减的常数（如 $\alpha = 1/N_t(s_t)$）；当取 $\alpha = 1/N$ 时，TD(0) 与增量平均形式完全一致。其三，TD 目标 $r_{t+1} + \gamma v_t(s_{t+1})$ 中使用的是更新前的 $v_t(s_{t+1})$，而非 $v_{t+1}(s_{t+1})$——因为 $s_{t+1}$ 本时刻尚未被访问，其估计尚未更新。

为什么 TD 目标可被视为 $v_\pi(s_t)$ 的"更可信"估计？把 $v_t$ 看作对 $v_\pi$ 的猜测：$v_t(s_t)$ 是纯猜测，$r_{t+1} + \gamma v_t(s_{t+1})$ 则额外包含一步真实奖励 $r_{t+1}$ 的信息。当 $v_t = v_\pi$ 时，由贝尔曼方程（Bellman equation）$v_\pi(s) = \mathbb{E}[r_{t+1} + \gamma v_\pi(s_{t+1}) \mid s_t = s]$，TD 目标的条件期望恰为 $v_\pi(s_t)$——不动点处 TD 误差的条件期望为零：$\mathbb{E}[\delta_t \mid s_t = s] = 0$。收敛之前，$\delta_t$ 的正负携带修正信息：$\delta_t > 0$ 说明估计偏高应下调，$\delta_t < 0$ 说明偏低应上调。TD(0) 正是沿"负 TD 误差"方向每次修正一小步。

### 7.2.2 为什么 TD(0) 收敛：随机逼近视角

TD(0) 的收敛性论证建立在随机逼近（Stochastic Approximation, SA）理论上。回忆贝尔曼方程 $v_\pi = T_\pi v_\pi$，其中 $T_\pi$ 是贝尔曼算子：$(T_\pi v)(s) = \mathbb{E}[r_{t+1} + \gamma v(s_{t+1}) \mid s_t = s]$，$v_\pi$ 是算子方程的唯一不动点。TD 误差可改写为 $\delta_t = [v_t(s_t) - (T_\pi v_t)(s_t)] + \text{噪声}$，第一项是残差 $v - T_\pi v$ 在 $s_t$ 处的取值，第二项是用一步采样代替期望的零均值噪声。因此 TD 更新正是对贝尔曼残差的随机逼近：$v_{t+1}(s_t) = v_t(s_t) - \alpha_t(s_t) \delta_t$。随机逼近理论（第6章 RM 定理）给出收敛条件：其一，学习率满足 RM 条件 $\sum_t \alpha_t(s) = \infty$、$\sum_t \alpha_t^2(s) < \infty$ 对所有状态成立；其二，每个状态被无限多次访问（遍历性）；其三，估计序列有界。在这些条件下，$v_t \to v_\pi$ 以概率 1 收敛。

把 TD(0) 与 DP、MC 并排比较，可见其在方法论谱系中的位置。DP：$v_{k+1}(s) = \sum_a \pi(a|s) \sum_{s'} p(s'|s,a)[r + \gamma v_k(s')]$，全状态同步更新、使用贝尔曼算子（自举），但需要模型 $p$（无采样）。MC：$v(s_t) \leftarrow v(s_t) + \alpha[G_t - v(s_t)]$，使用完整回报（无自举），完全靠数据（采样），但要等回合结束。TD(0) 同时使用自举与采样，是二者的中间形态：既继承了 DP 的信息快速传播（一步经验立刻回传），又继承了 MC 的无模型性。原书概括为：TD 是"DP 的自举 + MC 的采样"。从矩阵形式看，令 $v_t \in \mathbb{R}^{|S|}$、$e_{s_t}$ 为第 $s_t$ 分量为 1 的单位向量，更新可写为 $v_{t+1} = v_t - \alpha_t(s_t) e_{s_t} \delta_t$；元素形式便于实现，矩阵形式便于与 DP 的 $v_{k+1} = r_\pi + \gamma P_\pi v_k$ 对照分析。

### 7.2.3 例7.1：四状态链的逐步演算

用一个可手算的例题把 TD(0) 落到实处。考虑四状态链 $s_1 \to s_2 \to s_3 \to s_4$：只能向右移动；到达 $s_4$ 获得奖励 1 并终止；其余转移奖励 0。$\gamma = 0.9$，$\alpha = 0.1$，初始价值全 0。真实价值由贝尔曼方程解出：$v(s_4) = 1$，$v(s_3) = 0.9$，$v(s_2) = 0.81$，$v(s_1) = 0.729$。回合 1 轨迹：$s_2$（奖励 0）$\to s_3$（奖励 0）$\to s_4$（奖励 1）$\to$ 终止。逐步更新。访问 $s_2$：TD 目标 $0 + 0.9 \times v_0(s_3) = 0$，$\delta = 0$，不变。访问 $s_3$：TD 目标 $0$，$\delta = 0$，不变。访问 $s_4$：TD 目标 $1$，$\delta = 0 - 1 = -1$，更新 $v_1(s_4) = 0 - 0.1 \times (-1) = 0.1$。回合 1 后价值为 $(0, 0, 0, 0.1)$——只有 $s_4$ 变化，因为它是本回合唯一观察到非零奖励的状态。

回合 2 轨迹：$s_1 \to s_2 \to s_3 \to s_4$（奖励均 0，$s_4$ 处 1），当前价值 $(0, 0, 0, 0.1)$。访问 $s_1$：TD 目标 $0$，不变。访问 $s_2$：TD 目标 $0 + 0.9 \times v(s_3) = 0$，不变——$v(s_3)$ 本回合尚未更新。访问 $s_3$：TD 目标 $0 + 0.9 \times 0.1 = 0.09$，$\delta = -0.09$，更新 $v(s_3) = 0.009$。访问 $s_4$：TD 目标 $1$，$\delta = 0.1 - 1 = -0.9$，更新 $v(s_4) = 0.19$。回合 2 后为 $(0, 0, 0.009, 0.19)$。回合 3 同理：$s_2$ 更新 $v(s_2) = 0.00081$（目标 $0.9 \times 0.009$），$s_3$ 更新 $v(s_3) = 0.0261$（目标 $0.9 \times 0.19$），$s_4$ 更新 $v(s_4) = 0.271$。三个回合后估计为 $(0, 0.00081, 0.0261, 0.271)$，逐步逼近真实值 $(0.729, 0.81, 0.9, 1)$。

本例揭示 TD(0) 的四个关键性质。第一，每个时刻只更新被访问状态。第二，奖励信息沿轨迹反方向逐步传播：回合 1 中 $s_4$ 获得信息，回合 2 中传到 $s_3$，回合 3 中才传到 $s_2$——每步更新最多回传一格，这是自举"步进式传播"的直观形态。第三，越靠近奖励源的状态收敛越快（$s_4$ 最快，$s_1$ 最慢）。第四，学习率调大（如 $\alpha = 0.5$）则修正幅度成倍增大、收敛加快但震荡加剧，过大甚至发散——这正是 RM 条件"平方和有限"的直观体现。读者可自行演算 $\alpha = 0.5$ 情形，体会收敛速度与稳定性的权衡。本例的演算结构对全章具有模板意义：Sarsa、Q-learning 的演算与此完全同构——只是把"状态价值"换成"状态-动作价值"，把 TD 目标换成相应形式。
