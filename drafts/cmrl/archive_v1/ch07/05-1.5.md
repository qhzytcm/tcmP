## [Part1] 7.5 Q-learning 算法

### 7.5.1 Q-learning：直接求解贝尔曼最优方程

TD(0) 与 Sarsa 都在估计"给定策略的价值"，得到最优策略还需一轮策略改进。Q-learning 则直接估计最优动作价值 $q^*$，绕过显式策略迭代。回忆第4章最优性理论，$q^*$ 满足贝尔曼最优方程（Bellman optimality equation, BOE）：$q^*(s,a) = \mathbb{E}[r_{t+1} + \gamma \max_{a'} q^*(s_{t+1}, a') \mid s_t = s, a_t = a]$。Q-learning 的更新式正是对这个方程的随机逼近：

$$q_{t+1}(s_t, a_t) = q_t(s_t, a_t) - \alpha_t\big[q_t(s_t, a_t) - \big(r_{t+1} + \gamma \max_{a'} q_t(s_{t+1}, a')\big)\big].$$

与 Sarsa 的唯一差别在后继项：Sarsa 用后继时刻实际选择的动作 $a_{t+1}$ 的价值估计，Q-learning 用最大值 $\max_{a'} q_t(s_{t+1}, a')$。这个 $\max$ 不是实现细节，而是算法的灵魂——它直接来自 BOE 右端，意味着 Q-learning 求解的是最优性方程而非某个给定策略的贝尔曼方程。因此 Q-learning 不需要显式策略改进：更新式中内嵌"取最优后继动作"的算子，估计收敛即得 $q^*$，最优策略由 $\pi^*(s) = \arg\max_a q^*(s,a)$ 读出。

Q-learning 是异策略（off-policy）算法的代表：生成数据的行为策略（通常 ε-贪婪）与被学习的目标策略（贪婪策略，隐含在 $\max$ 中）可以不同。更新式完全不关心行为策略在 $s_{t+1}$ 处实际选了哪个动作，因此可以用任意（保证探索的）策略产生的数据学习。异策略带来两大优势。其一，数据复用：历史日志、其他智能体的记录、人类专家轨迹都可离线重放学习（第10章将深入运用）。其二，探索与利用解耦：可用高探索的行为策略收集数据，同时学习纯贪婪最优策略，不必像 Sarsa 那样为探索行为计入价值而付出保守代价。对比总结：行为策略与目标策略是否相同（Sarsa 相同、Q-learning 可以不同）；学到谁的价值（Sarsa 学行为策略价值、Q-learning 学贪婪策略价值）；后继项（Sarsa 用采样 $a'$ 的估计、Q-learning 用 $\max$）。

### 7.5.2 Q-learning 的实现与收敛

Q-learning 的实现比 Sarsa 更简洁：不需要在更新前选好后继动作。流程：初始化 $q$ 表与 ε-贪婪行为策略；对每个回合：初始化状态 $s$；对每步：按 ε-贪婪选 $a$、执行、观测 $(r, s')$、更新 $q(s,a) \leftarrow q(s,a) - \alpha[q(s,a) - (r + \gamma \max_{a'} q(s',a'))]$、令 $s \leftarrow s'$，直至终止；$\varepsilon$ 随训练衰减。与 Sarsa 代码对比一目了然：Sarsa 更新前必须先选 $a'$，Q-learning 直接扫描 $\max_{a'} q(s',\cdot)$；$s'$ 为终止状态时 $\max$ 取 0。收敛性保证与 TD(0)、Sarsa 一致：RM 学习率条件 + 每个状态-动作对被无限多次访问（充分探索）下 $q_t \to q^*$ 以概率 1。异策略收敛对探索有更精细要求：行为策略须对每个动作分配非零概率（或无限频繁探索），否则某些 $q(s,a)$ 永不更新，$\max$ 会基于残缺信息误判。

$\max$ 在带来异策略能力的同时有一个著名副作用——最大化偏差（maximization bias）。直觉：设某状态两个动作真实价值都是 0，估计噪声使 $q(s,a_1)$、$q(s,a_2)$ 在 0 附近波动，取 $\max$ 时正值噪声被保留、负值被舍弃，长期平均下 $\max$ 的期望大于 0——系统性高估。高估沿自举链向上游传播，误导策略选择。缓解手段：更小的学习率、奖励归一化、或双 Q 学习（Double Q-learning）——用两套独立 $q$ 表分别负责"选择动作"与"评估价值"，把选择与评估解耦。第8章 DQN 的双 Q 技巧即源于此，读者在此建立概念储备。

### 7.5.3 例7.4：Q-learning 逐步演算与 off-policy 演示

用例7.2 的环境并排演算 Q-learning，可直观看到与 Sarsa 的差别。环境：$s_1$ 处"左"（奖励 $-1$，终止）与"右"（奖励 0，到 $s_2$）；$s_2$ 处"右"（奖励 1，终止）；$\gamma = 1$，$\alpha = 0.1$，初始 $q$ 全 0；行为策略 ε-贪婪（$\varepsilon = 0.2$）。数据 1：$s_1$ 探索选"左"，奖励 $-1$ 终止。更新 $q(s_1, \text{左})$：TD 目标 $-1 + \gamma \max_{a'} q(\text{终止}, a') = -1$，$\delta = 1$，更新 $q(s_1, \text{左}) = -0.1$。数据 2：$s_1$ 选"右"（到 $s_2$）。更新 $q(s_1, \text{右})$：TD 目标 $0 + \max\{q(s_2, \text{左}), q(s_2, \text{右})\} = 0$，不变。数据 3：$s_2$ 选"右"（奖励 1，终止）。更新 $q(s_2, \text{右})$：TD 目标 $1$，$\delta = -1$，更新 $q(s_2, \text{右}) = 0.1$。数据 4：$s_1$ 选"右"（到 $s_2$）。更新 $q(s_1, \text{右})$：TD 目标 $\max\{0, 0.1\} = 0.1$，$\delta = -0.1$，更新 $q(s_1, \text{右}) = 0.01$。四步后 $q(s_1, \text{左}) = -0.1$，$q(s_1, \text{右}) = 0.01$，$q(s_2, \text{右}) = 0.1$。

关键对比：假设数据 4 中行为策略在 $s_2$ 处实际选了"左"且 $q(s_2, \text{左}) = 0$。Q-learning 更新 $q(s_1, \text{右})$ 仍用 $\max = 0.1$（得 0.01），与 $s_2$ 处实际动作无关；而 Sarsa 用 $q(s_2, \text{左}) = 0$ 作目标，$q(s_1, \text{右})$ 将保持不变。这就是异策略的本质：Q-learning 问"如果我在 $s_2$ 采取最优行动，这条路价值多少"；Sarsa 问"如果按当前策略实际行动，这条路价值多少"。前者向最优看齐，即使行为策略此刻未选最优；后者向现实看齐，把探索代价计入价值。本例还展示 $\max$ 的信息传播速度：$q(s_2, \text{右})$ 的正值在数据 4 就传到 $q(s_1, \text{右})$，比 Sarsa 依赖"实际走最优动作"更直接。当然 $\max$ 的乐观也有代价：若 $q(s_2, \text{右})$ 被噪声高估，高估立刻沿 $\max$ 链向上游放大——最大化偏差的传播路径。下一节将看到，期望 Sarsa 用加权平均替代 $\max$，恰好站在 Sarsa 与 Q-learning 之间。
