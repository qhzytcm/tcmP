## 1.6 轨迹与回报：诊疗全过程的长期评价

### 1.6.1 轨迹与回报：概念与内涵

单步奖励只能评价"一个动作的即时好坏"，而智能体的目标通常是长期的，为此需要把一系列奖励累积起来。轨迹（trajectory）是一条状态-动作-奖励链：从某个初始状态出发，依次记录每个时刻的状态、动作与获得的奖励。例如 s1 --a2, r=0--> s2 --a3, r=0--> s5 --a3, r=0--> s8 --a2, r=1--> s9 就是一条轨迹：机器人从 s1 出发，向右、向下、向下、向右，最终到达目标，途中获得奖励 0, 0, 0, 1。轨迹完整记录了一次交互的历史，是分析智能体行为的基本素材；第 5 章起的无模型算法正是从一批轨迹中估计价值的——轨迹是数据，算法是数据的使用者。在临床语境中，一条轨迹就是一个完整的"就诊—治疗—随访"过程：症状组合、处方、疗效评价依次记录，构成机器学习方法的训练样本。轨迹的起点与终点之间承载着策略与环境的全部交互信息；把轨迹写清楚，就是把"发生了什么"写清楚，这是任何分析的起点。一份规范的门诊病历，本质上就是一条人类书写的轨迹——初诊的症状与辨证、处方与医嘱、复诊的疗效与转归，环环相扣，正是强化学习意义上的"一次交互的完整记录"。读者可以把自己的最近一次完整就诊写成轨迹：初诊状态→动作（处方）→奖励（即时缓解程度）→复诊状态→动作→奖励，写一遍就会发现，病历里其实早就藏着轨迹的结构。

轨迹上所有奖励之和称为回报（return），它是评价策略好坏的直接指标：回报越大，策略越好。仍用上面的例子：按某策略从 s1 出发到达 s9，回报为 0 + 0 + 0 + 1 = 1；若按另一条经过禁区的策略，轨迹为 s1 --a2, r=0--> s2 --a3, r=0--> s5 --a2, r=−1--> s6 --a3, r=0--> s9，回报为 0 + 0 + (−1) + 0 = −1，前者回报更大，策略更好。回报把"单步奖励"累积为"整体效果"，使不同策略之间可以定量比较。注意：回报的定义依赖具体轨迹，而轨迹由"策略 + 环境随机性"共同决定，因此同一策略在不同次交互中可能得到不同回报——可能这次得 1，下次得 0。如何把这种随机性处理掉，是第 2 章引入期望（状态价值）的动机。读者在此应记住：回报是随机变量，不是定值；评价策略不能只看一次结果，要看平均表现，这就像评价一位医师不能只看一个病例的成败，而要看长期的整体疗效——一位名医也有失手的时候，但长期统计的疗效才是他策略价值的可靠度量。期望的引入将把"平均表现"变成可计算的数学对象，请在第 2 章留意它的登场。现在先做一件简单的事：把上面两条轨迹的回报各手算一遍，体会"路径不同、回报不同"的量化差别；再设想第三条路径 s1→s4→s7→s8→s9，其奖励序列为 0, 0, 0, 1，回报同样是 1——两条不同的好路可以得到相同的回报，这说明回报比较的是"整体效果"而不是"具体路线"。

### 1.6.2 轨迹与回报：方法与实现

非折扣回报有一个根本局限：对无限长的轨迹，直接求和可能发散。设想机器人到达目标后继续移动：0 + 0 + 0 + 1 + 1 + 1 + … = ∞，回报没有定义。只要任务没有明确的终止点，非折扣回报就可能出问题。解决办法是引入折扣：让远期的奖励"打折"，使无穷求和收敛。这一思想也符合人类与动物的行为直觉——"一鸟在手胜过两鸟在林"：远期奖励往往不如近期奖励可靠、有价值，因为未来充满不确定性。折扣回报的定义为 Gt = Rt+1 + γRt+2 + γ²Rt+3 + … = Σk=0∞ γ^k Rt+k+1，其中 γ ∈ (0,1) 称为折扣率（discount rate）。两个记号细节值得注意：其一，Gt 从时刻 t 之后的第一个奖励 Rt+1 开始累计，而不是 Rt——Rt 是时刻 t−1 的动作得到的奖励，不属于"从 t 出发的未来回报"，这个下标错位是初学者最容易写错的地方，请务必记牢；其二，第 k 项前的折扣因子是 γ 的 k 次方，离当前时刻越远，折扣越狠，远期奖励对回报的贡献越小。建议读者在纸上抄写一遍这个公式，把每项下标与折扣指数逐一核对——这是全书最重要的公式之一，值得花五分钟彻底消化；它将在第 2 章被"自举"分解，衍生出贝尔曼方程。抄写时不妨在心里默念：第一项不折扣，第二项乘一次 γ，第三项乘两次 γ——规律一目了然，也就不容易写错下标了。对照临床：一次完整的慢病管理横跨数月，医师给"当月缓解"和"半年转归"打的折扣不同，正是 γ 在时间维度上的定价。

折扣率的作用有二。其一，保证回报有界：若奖励绝对值的上界为 Rmax，则 |Gt| ≤ Rmax(1 + γ + γ² + …) = Rmax/(1−γ)，几何级数收敛，无限长轨迹的回报有限。其二，调节远近权重：γ 接近 0 时远期奖励被严重打折，策略短视（myopic），几乎只看即时奖励；γ 接近 1 时策略远视（far-sighted），愿意为远期收益承担近期损失。用数值例子说明：设某轨迹奖励序列为 1, 1, 1, …，γ = 0.5 时 G0 = 1 + 0.5 + 0.25 + … = 2，γ = 0.9 时 G0 = 1 + 0.9 + 0.81 + … = 10，同样的轨迹，γ 越大远期贡献越大。再比较两条备选轨迹：甲奖励序列为 0, 10（先苦后甜），乙为 5, 5（平稳），γ = 0.5 时甲回报 5、乙回报 7.5，乙更优；γ = 0.9 时甲回报 9、乙回报 9.5，乙仍略优；若甲的远期奖励加大为 0, 100，则 γ = 0.9 时甲回报 90，反超乙。这个例子直观展示了：γ 越大，智能体越愿意"为远期收益承担近期损失"。在临床上，γ 的大小对应医者"治标"与"治本"的取舍——γ ≈ 0 的医者只会治标，γ 较大的医者才谈得上治本，"辨证论治、整体观念"本质上是一种大 γ 的决策哲学。推拿针灸等以调理体质见长的疗法，疗效常显于疗程之后，用小 γ 建模就会低估其价值；而止痛退热等即时疗法，用小 γ 反而贴近临床直觉。设置 γ 时建议与任务的时间尺度对齐：疗程以周计的，γ 可取 0.9；以年计的，宜取 0.99；跨数年的慢病管理，甚至可取 0.995——γ 与疗程时长一一对应，这是避免"时间尺度错配"的实用准则，也是把"整体观念"落到数值上的关键一步。

### 1.6.3 轨迹与回报：小结与衔接

回报的定义与任务的类型密切相关。有终止状态的任务称为回合任务（episodic task），如走迷宫、下棋、一个疗程，轨迹有限，非折扣回报也有定义；没有终止状态的任务称为持续任务（continuing task），如慢病长期管理、恒温控制，轨迹无限，必须依赖折扣使回报收敛。两类任务可以通过吸收态（absorbing state）统一：把终止状态设计为吸收态，智能体到达后永远停留、此后奖励恒为 0，回合任务就化为带吸收态的持续任务——例如把"治愈出院"建模为吸收态、把"病情反复"建模为普通状态的转移。临床上，急性病诊治多为回合任务，慢病管理更接近持续任务；判断任务类型的依据是"是否存在自然的终止条件"，而非"是否人为停止交互"。至此，可以把本章的概念收束为强化学习的标准建模框架——马尔可夫决策过程（Markov Decision Process, MDP）：五元组 (S, A, P, R, γ) 中，S 是状态集，A 是动作集，P 是状态转移概率，R 是奖励，γ 是折扣率；回顾本章，1.2 节定义了 S 与 A，1.3 节定义了 P 与马尔可夫性质，1.5 节定义了 R，本节定义了 γ——五元组的每个成分都已有铺垫。读者应当把五元组当作"问题的身份证"：描述任何强化学习问题，先写清这五个成分；写不清楚五元组，就说明对问题还没有建模清楚。例如给一个中医诊疗问题写五元组：S 是常见证候集合，A 是常用方剂集合，P 是证候传变概率，R 是疗效反馈，γ 按疗程长度取值——五个成分一行一个，问题立刻清晰。本章建立的中医临床元素与强化学习概念的双向映射关系见图 1-6。

本节要点回顾：轨迹是状态-动作-奖励链，回报是轨迹上奖励之和；回报是随机变量，评价策略要看平均表现；折扣回报 Gt = Rt+1 + γRt+2 + γ²Rt+3 + … 既保证收敛又为时间定价；回合任务与持续任务通过吸收态统一；整个问题形式化为 MDP 五元组 (S, A, P, R, γ)。这条概念链正是全书的地基：第 2 章将引入期望运算，定义状态价值并推导贝尔曼方程，把"平均表现"变成可计算的数学对象；第 3 章刻画最优策略，第 4 章给出求解算法；第 5 章起进入无模型方法，从轨迹数据中直接学习。在进入第 2 章之前，读者应能独立完成回报计算、默写五元组，并能够把任一临床场景翻译成"状态—动作—奖励"的语言——例如把"辨证→方剂→随访"完整地写成一条带奖励的轨迹。具体可以这样检验：给同学讲一遍"甲 0,10 与乙 5,5 在 γ=0.5 和 γ=0.9 下的回报"是怎么算出来的，能讲清楚，就说明折扣回报真正理解了。本章前六节建立了单智能体学习的完整概念框架，下一节将把视角拉远，从系统科学的高度审视：智能体不是孤立的存在，它在更大的系统中有自己的位置——这就是个人定位与场景生存最适度。至此，单智能体的"认知起点"已齐备，从下一节开始，视角将从"个体如何学"转向"个体在系统中如何定位"，这也是全书由局部走向整体的第一次转折。
