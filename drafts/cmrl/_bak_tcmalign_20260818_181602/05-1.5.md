## 3.5 随机逼近：增量更新与在线学习

### 3.5.1 随机逼近：概念与内涵

先区分两种学习方式。非增量式（non-incremental）学习：先收集全部数据，再一次性计算估计结果——“收集数据 → 保存数据 → 等数据齐了 → 统一计算”，计算发生时所有样本都已就位；第3.3节的统计估计属于此类，要估计某状态的价值，必须等一条完整回合结束、拿到整条回报之后才能做一次更新。增量式（incremental）学习：每来一个样本，就地更新估计——“来一个样本 → 更新一次估计 → 等下一个样本”，估计值像一条“活”的曲线，随着样本不断流入而持续移动。随机逼近（stochastic approximation），通俗地说，就是“边做边修正”：每来一个新样本，就朝它挪一小步，走多了就逼近真值；它研究在只能观测到带噪声数据的条件下，如何通过迭代逐步逼近未知的真值。为什么必须补这块理论？因为临床上许多反馈是流式到达的：复诊记录一条条入库，随访电话一个个打回，不可能等全部数据攒齐再总结；老中医“效不更方、效差变方”的用方习惯，本质就是增量式——每接诊一例患者，就根据转归微调自己的用方倾向。增量更新带来实时性，也带来新的数学问题：每次只看到部分信息，估计凭什么收敛、怎样保证不跑偏？这正是随机逼近要回答的问题。

随机逼近最简单的原型是增量均值估计（incremental mean estimation）：维护一个估计值 w_k（k 表示已处理的样本数），每来一个新样本 x_k，就地更新 w_{k+1} = w_k + (1/k)(x_k − w_k)。这个式子读作：新估计 = 旧估计 + 步长 × (新样本 − 旧估计)，其中 (1/k) 是步长（step size），(x_k − w_k) 是新样本与旧估计的误差。每处理一个样本，估计值就朝新样本方向移动一小步，移动幅度由步长控制。这个增量公式与全量平均完全等价：若取 w_1 = x_1（用第一个样本初始化），从 k = 2 开始更新，归纳可得 w_{k+1} = (1/k)Σ_{i=1}^{k} x_i，与3.2节的样本均值逐字相同。等价性说明：增量更新不是全量平均的“近似”，而是它的另一种等价实现——只是改变了“什么时候算”。步长 1/k 的几何意义也由此清晰：当第 k 个样本到来时，旧估计 w_k 代表前 k−1 个样本的平均，新样本的权重应为 1/k，旧平均的权重相应降为 (k−1)/k——每个样本在最终估计中等权，这正是算术平均的定义。若改用常数步长 α，则新估计是历史样本的指数加权平均，旧样本的影响永不消失——近期数据主导估计，适合跟踪缓慢变化的目标。这个“等权 vs 遗忘”的对比，是理解后续一切步长设计的出发点。

### 3.5.2 随机逼近：方法与实现

把增量均值估计推广到一般问题，就得到随机逼近的经典算法——Robbins-Monro（RM）算法：求方程 g(w) = 0 的根，但函数 g 本身未知，只能获得带噪声的观测 g̃(w, η) = g(w) + η，其中 η 是均值为零的噪声。通俗地说，我们无法直接读出“使期望疗效为零的用药剂量”这类量，只能在噪声下观测带误差的值。RM 迭代格式极其简洁：w_{k+1} = w_k − a_k·g̃(w_k, η_k)，其中 a_k > 0 是步长。直觉：若当前 w_k 在根的右侧（g(w_k) > 0），则 g̃ 平均为正，减去 a_k·g̃ 使 w 减小、向根靠拢；若 w_k 在根左侧（g(w_k) < 0），则减去一个负值使 w 增大，同样向根靠拢。噪声使每一步的方向未必准确，但步长递减可“平均掉”噪声影响。RM 迭代与增量均值估计的承接关系：取 g(w) = w − E[X]，则 g(w) = 0 的解是 w = E[X]，求根问题退化为均值估计问题；噪声观测取 g̃(w, x) = w − x，代入 RM 迭代得 w_{k+1} = w_k − a_k(w_k − x_k) = w_k + a_k(x_k − w_k)，当 a_k = 1/k 时正是增量均值估计。也就是说，增量均值估计是 RM 算法在“g 为线性函数”时的特例，RM 把增量更新推广到任意未知函数。

例3.5（线性求根）：求 g(w) = w − 3 = 0 的根，设噪声 η ~ N(0, 1)，取 w_1 = 0，a_k = 1/k；k = 1 时若 η_1 = 0.5，则 g̃(w_1, η_1) = g(0) + η_1 = −3 + 0.5 = −2.5，代入迭代式 w_2 = w_1 − a_1·g̃ = 0 − 1×(−2.5) = 2.5。收敛由 RM 定理保证：若 g 满足正则条件（如 (w − w*)g(w) > 0）且步长序列满足两条件，则 w_k 以概率 1 收敛到根 w*。条件①：Σ_{k=1}^∞ a_k = ∞，步长之和发散；条件②：Σ_{k=1}^∞ a_k² < ∞，步长平方和收敛。经典步长 a_k = 1/k 同时满足：Σ(1/k) 发散，Σ(1/k²) 收敛到 π²/6。两条件缺一不可：①保证能“走到任意远”，步长之和有限时迭代会被“步长预算”困住；②保证能“平均掉”噪声，平方和发散时扰动方差发散，估计持续抖动。例3.6（步长反例）：沿用例3.5 求根问题（真值 w* = 3）。若取 a_k = 1/√k：Σa_k 发散，满足①；但 Σa_k² = Σ(1/k) 同样发散，不满足②——噪声方差逐项累积，估计剧烈抖动难收敛。若取 a_k = 1/k²：Σa_k = Σ(1/k²) 收敛到 π²/6，不满足①；Σa_k² = Σ(1/k⁴) 收敛到 π⁴/90，满足②——总行程有限，估计停在初值与真值之间，够不到 3。两反例说明：步长必须“慢到能走远，快到能平噪”（图 3-8）。

### 3.5.3 随机逼近：小结与衔接

随机逼近的核心收获可以概括为四个层次。第一层（公式层）：增量均值估计 w_{k+1} = w_k + (1/k)(x_k − w_k) 与全量平均 (1/k)Σ x_i 完全等价，只是流式实现。第二层（结构层）：更新式可写为“新估计 = 旧估计 + 步长 × (新样本 − 旧估计)”，这个“估计 + 步长 × 误差”的结构是所有增量算法的共同骨架——RM 求根、时序差分的更新都是同一骨架的实例。第三层（步长层）：步长序列决定收敛行为，两个条件“和发散、平方和收敛”是随机逼近理论的共同基石：前者保证能走远，后者保证噪声被平均掉。第四层（应用层）：增量模式天然适应流式数据与分布漂移——临床指南更新、季节病变化、患者群体改变，都会使“旧数据的均值”不再是“当前真值”的合理估计；配以合适步长，增量更新就能长期跟随真值。四个易错点：其一，增量均值估计的起始约定——w_1 = x_1 时第 1 步不更新，从 k = 2 起步长才为 1/k，若误用“第 1 步也更新”则推导出错；其二，“步长和发散”不意味着“步长很大”，Σa_k = ∞ 只需步长衰减得足够慢（如 1/k）；衰减太快的序列（如 1/k²）每步虽小，但和收敛、总行程有限；其三，常数步长能跟踪漂移但牺牲精度，估计围绕真值抖动，方差正比于步长；其四，步长条件对后续增量算法原样复用——违反任一条件就不收敛。

把随机逼近放进全章地图。第3.3节的统计估计是“非增量”的：攒一批回合、取平均，样本再多也要等回合结束；第3.4节的探索与样本积累解决了“样本怎么来”；本节解决“样本怎么用”——来一条就用一条，估计持续更新。这条线索正是从“统计”走向“在线”的关键一跃：统计估计是“大数定律的非增量应用”，随机逼近是“增量式的收敛理论”。随机逼近还有一个重要的延伸形态——随机梯度下降（stochastic gradient descent, SGD）：求目标函数 J(w) 的极值，每步用单样本梯度 ∇f(w, x_k) 近似期望梯度，迭代 w_{k+1} = w_k − a_k·∇f(w_k, x_k)；令 g = ∇J，SGD 迭代正是 RM 迭代在“g 为梯度”时的实例——深度学习训练中所谓“学习率”的调度，本质就是本节两个步长条件的工程实现。带着这张图景进入下一节：增量更新让估计不断流动，但“流动的估计”可信吗？证据等级（样本质量）与把握程度（统计精度）如何共同决定一个估计的可靠度？这是3.6节“证据等级与把握程度”的主题。学完本节，请自检三问：① 增量均值估计与全量平均为什么等价？② RM 定理的两个步长条件各保证什么？③ 为什么违反任一条件估计都不收敛？
