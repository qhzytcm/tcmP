## 5.1 最优状态价值与最优策略

### 5.1.1 概念与内涵

上一章我们学会给一套诊疗方案"算总账"：只要写出策略的价值估计方程，就能知道每种健康状况的长期期望疗效。但临床真正要回答的是另一个问题：面对同一位失眠患者，安神方、健脾方、疏肝方各有各的说法，究竟哪一套才是最好的？本章回答这个问题，核心是两个"最优"。最优状态价值（optimal state value），通俗地说，就是某个健康状况在"所有可行方案中挑最好的那一个"时，长期能够获得的最高平均疗效。最优策略（optimal policy）更直白：就是在每种健康状况下都选择最好方案的那套决策规则。形式上，把上一章的状态价值 vπ(s) 对所有可能的策略 π 取最大值，就得到最优状态价值 v*(s) = maxπ vπ(s)。这里有三点要说明。第一，最大值在策略集合上取，v* 是所有策略价值的上包络，不依赖任何具体策略。第二，v*(s) 只依赖状态 s 与环境动力学，是"位置决定前景"的极限表达。第三，若策略 π* 在每个状态都达到这个最大值，即 vπ*(s) = v*(s) 对一切 s 成立，它就是最优策略。另外，策略集合原则上包含随机策略；由于最大值总能由某个确定性策略达到，本书如无特别说明都按确定性策略讨论最优性。

与最优状态价值相伴的还有最优动作价值（optimal action value）：q*(s,a) = maxπ qπ(s,a)，它回答"在状态 s 采取动作 a，此后一切按最好的来，长期能获得多少"。两个最优价值之间有两个简洁关系。其一，v*(s) = maxa q*(s,a)：最优状态价值就是在该状态选最优动作所得的最优动作价值，它把"状态有多好"落实为"选哪个动作最好"。其二，q*(s,a) = Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′)：最优动作价值由"当下的即时效果"与"后继状态的最优价值"递归构成。这两个式子把第4章"递归账本"推进到最优化：最好的价值不是凭空出现的，它由每一步的最优选择环环相扣地累积而成。用临床语言说：一首方剂对一个证候的长期价值，等于它的即时疗效，加上治愈或转归之后那些状态的最好前景——这正是"愈后调养、防止复发"进入疗效账本的方式。还需提醒：最优价值未必只有一个最优策略能实现，两个策略只要在每个状态都达到相同最大值，就都是最优的；但最优价值函数本身唯一，这为后续算法收敛提供了统一靶心。以失眠为例：同样是心烦失眠，心脾两虚者用归脾汤价值高，心火亢盛者当用清心安神之品——同一个动作对不同状态的价值天差地别，这正是动作价值同时依赖状态与动作的临床含义。

### 5.1.2 方法与实现

有了定义，如何实际操作地找到最优策略？核心方法是三步循环：评估、比较、择优。先看一个例子。沿第4章的失眠链：s3 为康复吸收态（停留在 s3 每步得 +1），s4 为迁延难愈（每步得 0），取 γ = 0.9，则 v*(s3) = 1 + 0.9 + 0.81 + … = 10，v*(s4) = 0。在 s2（心脾两虚证）处有两个候选动作：归脾汤将患者带向 s3，黄连解毒汤将患者推向 s4，即时奖励皆为 0。于是 q*(s2, 归脾汤) = 0 + 0.9×10 = 9，q*(s2, 黄连解毒汤) = 0 + 0.9×0 = 0。比较两个动作价值，择优自然浮现：在 s2 处应选归脾汤；若现行策略在此误用黄连解毒汤，价值只有 0，换方后提升到 9。这个三步循环——用当前价值评估每个候选动作，比较动作价值大小，把策略更新为价值最大的动作——正是后面所有择优算法的共同内核（见图 5-1）。它回答了一个朴素问题：如果现行方案不好，能否系统地找到更好的方案？答案是肯定的，机制极其简单：算一算、比一比、改一改。整个过程不需要神秘直觉，只需要把疗效账本算清楚。需说明：三步循环初学时常被误以为只是"选个最大的"，其实关键在前两步——评估不准则比较失据，比较不准则择优失当。

把三步循环落到临床，就得到"最优诊疗方案"的操作定义。在 tcmP 平台语境中：状态是症状组合，动作是候选方剂，奖励来自证据等级（A 级 1.0、B 级 0.7、C 级 0.4），最优策略对应最优诊疗方案——对每个症状组合都选期望疗效最高的方剂。辨证引擎的推荐因此应当"择优"而非"折中"：v*(s) = maxa q*(s,a) 直接表明，把多名医师的辨证结论做平均并不等于最优方案，正如对多个动作价值取平均得不到最大值一样。名医经验之所以"可计算"，正因为名医的辨证用药模式，本质上是在长期临床反馈中逐步逼近最优策略的过程。实现上还有两个细节值得记住。其一，最优策略可能不唯一——只要两个策略在每个状态都达到相同最大值，它们都是最优的，但最优价值唯一；动作价值并列时任选其一即可，不影响最优性。其二，"价值在 v 中定义，决策在 q 中发生"——最优状态价值虽是理论主角，所有择优算法实际都围绕动作价值展开：先估计 q，再对 q 取最大或取 argmax。这一分工贯穿全书，请读者在后续各节反复体会。在 tcmP 平台上，病证单元（DSU）为这套计算提供结构化数据：症状组合即状态、方剂字段即动作、证据等级即奖励，数据源位于平台知识图谱的样例目录。

### 5.1.3 小结与衔接

本节把一个朴素问题"哪套方案最好"翻译成了严格概念：最优状态价值 v*(s) = maxπ vπ(s) 是所有策略在状态 s 的价值的最高点，最优策略是达到这个最高点的策略，最优动作价值 q*(s,a) 则给出更细粒度的选择依据。两个关系式 v*(s) = maxa q*(s,a) 与 q*(s,a) = Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′) 构成择优的递归结构：当下的最优选择与未来的最优前景互相嵌套。方法上，评估—比较—择优的三步循环是全部择优算法的种子：先知道每个候选方案有多好，再挑最好的。定义层面还有一个反复出现的提醒：最优价值是"所有策略的包络"，不依赖任何具体策略，只由状态本身与环境动力学决定——这使它成为衡量任何实际策略优劣的标尺：只要 vπ(s) < v*(s)，就说明该策略在状态 s 还有改进空间，差距大小正是指引改进方向的信号。这一标尺同时回答了上一章遗留的"策略比较"问题：与其逐个比较策略，不如直接对照最优价值——差距最小的策略就是当前最好的策略。

但本节留下一个悬而未决的问题：最优价值 v* 是"对所有策略取最大"定义的，而策略个数随状态数指数增长，直接比较全部策略绝无可能。有没有一个方程，让 v* 自己"满足"某个条件，就像第4章的价值估计方程刻画普通价值那样？下一节的最优价值估计方程将回答这个问题：把"遍历全部策略求最大"压缩成"在每个状态对有限个候选动作取最大"，再用递归把方程写出来。这个方程是最优性的一阶刻画——一个价值函数是最优的，当且仅当它满足这个方程——它将是我们从"知道最优长什么样"走向"把最优算出来"的桥。它同时预告了本章的路线图：定义最优（5.1），刻画最优（5.2），认识最优为何局部选择等于全局最优（5.3），求解最优（5.4、5.5），划清最优的边界（5.6），最后把最优放回系统与共同体（5.7、5.8）。值得一提的是，最优价值还能直接充当疗效评价的基准线：把任何一套实际方案的价值与它对照，差距一目了然，这为第6章以后用数据检验方案优劣埋下伏笔。带着"最优价值满足什么方程"的问题进入下一节，是本节最好的收尾——最优价值函数一旦算准，便成了检验一切实际方案优劣的公共标尺。
