## 5.4 价值迭代：反复评估与改进

### 5.4.1 概念与内涵

最优价值估计方程 v* = T(v*) 告诉我们最优价值是不动点，但没有给出求解方法。第5.3节已铺垫：最优价值可用迭代逼近。价值迭代（value iteration）就是把这个直觉变成算法：任取初始估计 v0（通常取全零向量），然后反复作用贝尔曼最优算子，vk+1 = T(vk)，即对每个状态计算 vk+1(s) = maxa [ Σr p(r|s,a) r + γΣs′ p(s′|s,a) vk(s′) ]，直到估计稳定。通俗地说，价值迭代就是"反复评估与改进"：每轮用公式把每个状态的最好价值重新算一遍，算的时候只看"当下的最优选择，加上打折后的上轮后继价值"。价值就像水波一样，从疗效确切的吸收状态（如"康复"）逐圈扩散到整个状态空间。为什么这样会收敛？因为贝尔曼最优算子 T 具有压缩性质：它对任意两个价值向量的距离，作用一次至少缩小 γ 倍（γ < 1）。收缩映射（contraction mapping）这个术语的几何直觉是：把任意两点之间的距离至少压缩一个固定比例，反复作用后所有点都被"吸"向同一个点——这个点就是不动点。由经典的 Banach 不动点定理，压缩映射存在唯一不动点，且从任意初值出发迭代都收敛到它——这是"反复评估与改进"能够成功的第一重保证。压缩比恰为 γ 这一点并不偶然：折扣率就是为收缩性而设的——γ < 1 是价值有界与迭代收敛的共同根源。

价值迭代的"反复评估与改进"内涵需要细看：每一轮其实融合了两个逻辑步骤。第一步是改进（策略更新）：在当前价值估计 vk 之下，找出每个状态的贪婪策略 πk+1(s) = argmaxa qk(s,a)——这是"当前看来最好"的动作；第二步是评估（价值更新）：用这个新策略的价值算子对旧价值作用一次，vk+1(s) = maxa qk(s,a)——注意这里只做一步，不是把方程解到收敛。因此价值迭代的每一轮都是"评估一步、改进一步"的混合：策略随时在换，价值只走一步。这个"只走一步"的特征，正是它与第5.5节策略迭代最本质的区别——后者把评估做到底才改进。用临床语言理解：价值迭代像一位医师每看完一批病例，就用最新疗效反馈修正自己对各证候价值的估计，同时调整下一次的选方倾向——评估与改进交织在同一次临床实践中，边看边学，边学边改。医师不需要等几年攒够数据才改一次方案，而是每积累一批反馈就更新一次认识，这正是价值迭代的节奏。反过来看，这种"边学边改"也解释了为何不必等到完美模型：只要反馈源源不断，粗糙的初始估计也会在迭代中逐步校正。

### 5.4.2 方法与实现

为把算法讲具体，引入一个 3×3 网格世界演算台：九个格子按行编号 s1 至 s9，s9 为目标（到达后每步 +1），s6 为禁区（进入得 −1），越界动作弹回原状态并得 −1，其余移动得 0，取 γ = 0.9。价值迭代的实现只有三个公式。对每个状态 s 与动作 a，先算动作价值估计：qk(s,a) = Σr p(r|s,a) r + γΣs′ p(s′|s,a) vk(s′)；然后做两件事：策略更新 πk+1(s) = argmaxa qk(s,a)，价值更新 vk+1(s) = maxa qk(s,a)。伪代码：输入 MDP（状态、动作、转移概率、奖励、γ）与精度阈值 ε；初始化 v0 = 0；循环：对每个状态算全部 qk，更新 vk+1 与 πk+1，检查终止条件 maxs |vk+1(s) − vk(s)| < ε；满足则停止，输出近似最优价值与贪婪策略。三个实现细节必须强调。其一，q 一律用旧值 vk 计算，全部状态算完再统一更新（同步更新），不能原地覆盖，否则破坏收敛保证；异步更新（逐个状态就地覆盖）通常也收敛，但分析与实现更微妙，本书默认同步。其二，argmax 与 max 要分清——argmax 返回使 q 最大的动作（填策略表），max 返回最大的数值（填价值表），二者混淆是初学者最常见的错误。其三，终止判据用"相邻两轮之差"而非"与真值之差"，因为真值 v* 未知——由压缩性质可证相邻差小即离真值近，误差上界为 γ/(1−γ) 倍的相邻差。

例5.4（3×3 网格世界的价值迭代前两三轮）。从 v0 = 0 出发。第1轮：q0(s,a) = r(s,a)，故 v1(s9) = 1，其余格子价值 0。第2轮：只有 s9 的邻居能"看见"目标——s8 向右一步到 s9，q = 0 + 0.9×1 = 0.9，故 v2(s8) = 0.9；s6 向下也能到 s9，v2(s6) = 0.9；其余格子仍为 0。第3轮：s5 向下到 s8，v3(s5) = 0.9×0.9 = 0.81；s7 向右到 s8，v3(s7) = 0.81。价值从目标格出发逐圈扩散，每外扩一圈乘 γ，这正是"价值传播"的直观画面（见图 5-2）。继续迭代，误差按 0.9^k 衰减，达到 1% 精度约需 44 轮，价值逼近 v*；再对 v* 贪婪提取即得最优策略：每个格子都指向目标方向、绕开禁区。注意一个有趣现象：策略往往比价值更早稳定——argmax 只关心动作价值的相对排序，不关心绝对数值，价值还差得远时箭头已经正确；实践中可用"策略连续多轮不变"作为早停条件，大幅节省计算。这个"策略先稳、价值后稳"的现象，是压缩映射收敛速度的直接推论，也是工程师可以利用的加速技巧。

### 5.4.3 小结与衔接

价值迭代是"反复评估与改进"的算法化：每轮对每个状态算动作价值、取最大、更新价值与策略，价值像水波一样扩散，直到相邻两轮之差足够小。它的理论基础是贝尔曼最优算子的压缩性质：距离每轮至少缩小 γ 倍，误差按几何级数衰减，‖vk − v*‖∞ ≤ γ^k‖v0 − v*‖∞，因此无论初值如何——哪怕是凭经验拍脑袋给的估计——迭代都会收敛到唯一的最优价值。三个操作要点值得内化：同步更新（用旧值算、统一覆盖）、区分 argmax 与 max、用相邻差判敛。收敛阈值 ε 与 γ 共同决定精度与轮数：γ 越接近 1，收敛越慢，同样的 ε 对应的真实误差越大，需要更小的 ε 才够。临床上，价值迭代的每一轮对应"用最新疗效反馈修正证候价值估计"，收敛对应"经验沉淀为稳定认识"——初值粗糙没关系，反复评估与改进会把它逐步修正到与最优一致，这正是年轻医师向名医成长的算法图景：谁也不敢说第一张处方就是最好的，但持续用反馈修正，认识会越来越接近最优。这种"越用越准"的性质，正是算法可以放心上线的底气。若读者动手手算一遍，会发现前几轮价值完全由奖励表决定，从第2轮起才出现"对未来价值的预支"——这是理解"价值来自未来"的关键观察。

价值迭代简单、可靠、理论干净，但它有一个可以挑剔之处：每一轮只做一步评估，价值是"走着瞧"式地逼近，轮数往往很多；而且每轮更新价值时，策略只是在旁边顺手更新，并没有被当作主角。反过来想：能不能把"评估"做彻底——先把当前策略的价值精确算出来，再据此一次性改进策略，交替进行？这正是策略迭代的思路，也是下一节的主题。两条路线殊途同归：价值迭代在价值空间里迭代、评估一步一改进，策略迭代在策略空间里迭代、评估到底再改进；它们共享"评估—改进"的循环骨架，只是火候不同。用烹饪作比：价值迭代是"每尝一口就改配方"，策略迭代是"把整锅菜彻底尝明白再改一次配方"——火候深浅不同，最终都能端出最优策略这道菜。值得记住的还有一条工程经验：在小规模问题上，两种算法应当解出同一个最优价值与最优策略，结果的一致性本身就是对实现正确性的交叉验证。带着"如何让评估更充分"的问题进入下一节，将看清这两种算法的分工与统一。同时把价值迭代与后面的 Q 学习对照：Q 学习正是把这里的期望求和换成采样平均，其余结构完全不变——本节的公式将是后续章节的模板。
