## 5.2 最优价值估计方程：辨证择优的决策依据

### 5.2.1 概念与内涵

第4章的价值估计方程 vπ(s) = Σa π(a|s) qπ(s,a) 用加权平均写"策略的价值"：在状态 s，策略 π 按概率 π(a|s) 混合各个动作，价值就是动作价值的加权平均。上一节我们已知最优关系 v*(s) = maxa q*(s,a)——最优状态价值不是加权平均而是最大值。把这两句话叠在一起，只做一个替换：把"加权平均 Σa π(a|s)"换成"最大值 maxa"，把普通价值换成最优价值，就得到最优价值估计方程（Bellman optimality equation）：v*(s) = maxa [ Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′) ]，对一切状态 s 成立。这个替换之所以成立，依赖上一节的关键论证：最优策略在每个状态必然选择使动作价值最大的动作——若它把概率分散给次优动作，把概率集中到最优动作上就能得到不差的价值，故可假设存在"每状态只选最优动作"的最优策略。通俗地说，这个方程讲了一句话：在每种健康状况下，把所有候选方案"当下的即时效果，加上打折后的后续状态最好前景"算出来，取其中最大的，就是该状态的最优价值。普通方程与最优方程的唯一差别是"期望"与"最大值"之差，正是这个差别，把"评价一个给定策略"升级为"直接刻画最优"。

这个方程为什么能成为辨证择优的决策依据？因为它的 max 结构恰是"择优"的数学形态。辨证论治的本质是选择：面对症状组合，从候选治法方剂中挑出最优者。最优价值估计方程说：这个"挑"不是折中平均，而是逐候选比较、取最大——与辨证引擎"检索候选、按证据择优"的设计完全同构。方程还有两个值得咀嚼的性质。其一，它把"在无穷多个策略中寻优"压缩为"在每个状态对有限个动作取最大"：解一个方程等于在全部策略空间中完成优化，这是普通价值估计方程做不到的——普通方程每个策略各有一个，而最优方程一个就网罗全部。其二，它是非线性方程——max 不能分配到各项内部，因此没有闭式解，不能用一次求逆算出来；这提示我们，求解最优价值只能走迭代逼近的路，为第 5.4 节价值迭代埋下伏笔。方程还揭示"局部最优与全局最优的统一"：它在每个状态独立取 max，却同时刻画所有状态的全局最优价值——这个看似矛盾的性质，正是第 5.3 节"贪而不婪"的理论伏笔。最后，方程以 max 而非期望为骨架，刻画的是"潜力"而非"现状"——它回答"如果处处选最优，能有多好"，而不是"当前做法有多好"。

### 5.2.2 方法与实现

把方程落到可操作的形式，需要掌握它的几种等价写法。动作价值形式：v*(s) = maxa q*(s,a)，其中 q*(s,a) = Σr p(r|s,a) r + γΣs′ p(s′|s,a) maxa′ q*(s′,a′)——把 q* 自身也写成自洽方程，这是后续 Q 学习更新规则的采样版本。算子形式：定义贝尔曼最优算子 T，对任意价值向量 v 作用得到 (Tv)(s) = maxa [ Σr p(r|s,a) r + γΣs′ p(s′|s,a) v(s′) ]，则最优价值估计方程写成 v* = T(v*)，即 v* 是算子 T 的不动点（fixed point）——被变换作用后保持不变的"点"。这个写法把"解方程"翻译成"找不动点"，而不动点有成熟的迭代工具，这正是价值迭代的理论入口。算子形式还有一种紧凑写法：T(v) = maxπ (rπ + γPπ v)，其中 rπ 是策略 π 下的奖励向量，Pπ 是策略 π 下的状态转移矩阵，max 逐分量地取遍所有策略——它把"所有策略都考虑一遍"的语义打包进一个符号。读者应能在三种写法间自由切换：逐状态展开式便于手算，动作价值形式便于理解，算子形式便于推理——三者描述同一个数学对象，只是视角不同。

例5.1（用最优价值估计方程验证失眠链的最优价值）。取 γ = 0.9。s3（康复）是吸收态，停留在 s3 每步 +1，故 v*(s3) = 1 + γv*(s3)，解得 10。s4（迁延难愈）每步 0，v*(s4) = 0。s2（心脾两虚证）有两个动作：归脾汤得 0 并转 s3，黄连解毒汤得 0 并转 s4，于是 v*(s2) = max{0 + 0.9×10, 0 + 0.9×0} = max{9, 0} = 9。s1（失眠初起）进一步辨证到 s2 得 0，草率安神转 s4 也得 0，故 v*(s1) = max{0 + 0.9×9, 0 + 0.9×0} = 8.1。解得 v* = (8.1, 9, 10, 0)。把这个结果与"将这条确定性策略（s1→s2→s3）代入价值估计方程直接求解"对照，两者一致——说明这条策略在每一步都已按最优动作行事；若某一步偏离最优动作，价值就会下降，下一节的贪婪定理将把这句话变成严格的判据。需要提醒：本章把"到达康复"的即时奖励设为 0（与第4章例4.1 的演示口径一致），故 s2、s1 的最优价值为 9、8.1；若按例4.2 修正口径的 +1 奖励，则分别为 10、9——奖励设定不同，数值随之不同，择优的逻辑不变。这个例子还展示验证方法：要判断一个候选价值是否最优，只需把它代入方程看两边是否相等——"验证"比"遍历全部策略"便宜得多，这正是方程作为决策依据的实用性所在。读者可以自己试一试：把 v* 的某个分量改小一号再代回方程，等号必然不成立。

### 5.2.3 小结与衔接

本节的核心是一条方程：v*(s) = maxa [ Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′) ]。它是普通价值估计方程的"最优版"——把加权平均换成最大值，把给定策略换成最优选择。掌握它要注意三点。其一，三种写法要能自由切换：动作展开式（逐动作计算即时奖励加后继最优价值）、动作价值形式（v* 与 q* 互相嵌套的自洽方程）、算子不动点形式（v* = T(v*)，配以贝尔曼最优算子 T 与策略空间上的 maxπ 记号）；它们描述同一件事，只是视角不同。其二，方程是非线性的，没有闭式解，但不动点形式指明了求解路线——迭代。其三，方程的解就是上一节定义的最优状态价值，二者是同一对象的两副面孔：定义式便于理解，方程便于计算。临床语义上，这个方程把"辨证择优"写成了数学：每个症状组合的最优价值，等于当下最优选择的即时效果，加上打折后的后续最优前景；它同时解释了为何辨证引擎必须"择优"（取 max）而非"折中"（取平均）——这是平台辨证端点设计不可违背的原则，也与临床"一人一方、随证治之"的精神一致。验证比求解便宜，这一事实在工程上极有价值：它让我们可以用"代入检验"快速发现价值估计的错误，而不必每次都重解方程。

最优价值估计方程还揭示了一个更深的事实：方程在每个状态独立取 max，解出来的却是全局最优价值——"局部选择"与"全局最优"在这里握手。这个看似平凡的现象，其实是 MDP 理论最深刻的性质之一，下一节"贪而不婪"将正面回答它：为什么在每个状态选择眼前价值最大的动作，得到的策略恰好是全局最优？同时，方程也把问题推向下一个台阶：它只是"最优长什么样"的静态刻画，并没有告诉我们"怎么把最优算出来"——非线性方程没有初等代数解，必须依赖迭代。第 5.4 节的价值迭代，就是把这个不动点方程变成可执行程序的直接产物。至此，本章的理论骨架已经立起：第5.1节给出最优的定义，本节给出最优的方程，接下来的任务是认识它、求解它、划清它的边界。读者若能在心中复述这条逻辑链——从"加权平均"到"最大值"，从"评价策略"到"刻画最优"——就握住了本章的主线。需要预告的是：这条方程是否有解、解是否唯一，并非不言自明——第5.6节将用收缩映射给出存在性与唯一性的严格保证，那时"最优"二字才算真正落地。此外，方程还暗示了最优价值与折扣率的关系：γ 越大，远期价值越重，方程的解越"远视"——这一主题将在5.6节正式展开。
