## 5.6 择优的边界：局部最优与整体最优

### 5.6.1 概念与内涵

前五节建立了一个漂亮的图景：最优价值存在且唯一，价值迭代与策略迭代都能求出它。但"最优"并不是无条件的，它有清晰的适用边界；看清这些边界，才不会把算法结论用到算法假设之外。第一道边界是折扣率的边界。折扣率 γ ∈ (0,1) 是收缩性质的来源：γ 越接近 1，远期收益越被看重；若取 γ = 1（无折扣），压缩比退化为 1，贝尔曼最优算子不再是收缩映射，最优价值估计方程可能无解——持续正奖励的回路会使价值发散。即使 γ < 1，γ 的取值也直接改变"最优"的内容：γ 小则最优策略短视（只盯即时疗效），γ 大则最优策略远视（愿为远期康复承担近期代价）。同一套数据，γ 不同，最优方案可能完全不同——"最优"从来是相对折扣率的，这在临床上正是"急则治标、缓则治本"的参数化表达：把 γ 调小，模型就学成"急则治标"；把 γ 调大，模型才学会"缓则治本"。平台在设计疗效价值模型时，γ 因此是一个必须由临床目标决定的参数，而不是可以随意默认的技术细节。

第二道边界是模型边界：价值迭代与策略迭代都需要已知转移概率与奖励表，属于"有模型"算法；真实临床中模型往往未知，无从给出精确的"证候转移概率"与"方剂奖励表"，此时"最优"只能靠数据去逼近，这要等第6章的无模型方法。第三道边界是规模边界：逐状态更新与矩阵运算的代价随状态数快速增长，状态空间稍大就出现"维数灾难"（curse of dimensionality）——表格型价值函数无法覆盖 60000 余个病证单元的全部组合，必须引入分层组织与函数近似。第四道边界，也是最哲学的一道，是"最优"与"最适度"的分界：前五节的"最优"是单目标（期望回报）的最大化；现实中还有安全、成本、公平、可持续等多重约束，被约束牵制的"局部最优"未必是"整体最优"，而被所有目标共同接受的"适度"往往不是任何单目标的极端——这正是第5.7节的主题。四道边界并非并列：折扣率边界决定"最优"的定义本身，模型与规模边界决定"最优"能否算出，最适度边界则决定"最优"是否值得追求——层层递进，缺一不可。认清这四道边界，"择优"才不会沦为"盲目求大"；边界不是择优的否定，而是择优的适用域——在域内择优严格可靠，在域外则需要换工具。公地悲剧（tragedy of the commons）的例子也提示：个体层面的"最优"在系统层面可能共同失效，这正是下一节系统科学定位的问题意识。质控与评价的边界同样存在：任何量化指标都不可能完全刻画医疗质量，指标之外的临床判断永远需要保留——这是择优边界最后的人文提醒。

### 5.6.2 方法与实现

边界不仅要说清，还要算得清。折扣率边界可以定量演示。例5.6（γ 改变最优策略；教学示例数据）：从起点出发有两个动作。动作甲"绕远路"依次经历奖励 0、0、+10 后终止；动作乙"走近路"依次经历 +1、+1、0 后终止。γ = 0.1 时，甲的折扣回报 = 0 + 0.1×0 + 0.01×10 = 0.1，乙的 = 1 + 0.1×1 + 0.01×0 = 1.1，最优选乙——眼前的小甜头盖过遥远的 +10；γ = 0.9 时，甲的回报 = 0 + 0.9×0 + 0.81×10 = 8.1，乙的 = 1 + 0.9×1 + 0.81×0 = 1.9，最优选甲——愿意为远期大收益绕远路。同一个问题，γ 从 0.1 调到 0.9，最优方案翻转。临床上这就是"急则治标、缓则治本"的数值化：若平台把 γ 设得很小，模型只优化当下辨证开方的即时效果；γ 接近 1 才引导模型追求远期康复质量。γ 因此是平台可调的参数旋钮，其取值应当与医学场景匹配，而不是随意默认——这是择优的第一条工程纪律。值得强调的是，γ 的选取不是纯技术问题，而是临床价值观的数值化：重视近期指标还是远期预后，团队必须事先达成一致。读者可以亲手验算例5.6：把 γ 换为 0.5，甲的回报 = 0 + 0.5×0 + 0.25×10 = 2.5，乙的 = 1 + 0.5×1 + 0.25×0 = 1.5，仍然选甲——γ 越大，"绕远路"越划算，边界位移的方向一目了然。

收敛边界也可以量化。价值迭代用相邻差判据，误差上界为 ‖vk+1 − v*‖∞ ≤ γ/(1−γ)·maxs |vk+1(s) − vk(s)|：γ 越接近 1，放大系数越大，同样的相邻差对应的真实误差越大，因此高折扣率场景需要更小的 ε。数值感受：γ = 0.9 时误差按 0.9^k 衰减，达到 1% 精度约需 44 轮；γ = 0.5 时仅约 7 轮——远见（大 γ）与计算代价（慢收敛）是一对矛盾。规模边界的对策是分层与近似：把 60000 余个病证单元按证候层级组织，先在大类上择优、再在细目上择优，或用函数近似替代逐状态表格；模型边界的对策是转向无模型：把"期望"换成"样本平均"，价值迭代的更新式就数据化为 Q 学习的形式——用采样的后继状态替换求和，用增量修正替换解方程。工程上还要给边界留出"护栏"：安全底线与公平权重是不可让步的约束，任何择优都不能越过——例如疗效再高的方案，若配伍禁忌或剂量超限，也必须被排除在动作集之外。四道边界的对策合起来是一条方法论：先认清问题落在哪道边界内，再选择相应的工具。ε 的选择也要随 γ 调整：γ = 0.9 时取 ε = 1e−6，误差上界约 9e−6，可以接受；若 γ = 0.99，同样的 ε 对应的误差放大到约 99 倍，必须收紧阈值才能保证精度。价值迭代、策略迭代与时序差分三类算法的统一循环结构见图 5-5。

### 5.6.3 小结与衔接

本节划清了择优的四道边界。折扣率边界：γ ∈ (0,1) 是收敛的保证，γ 的取值本身决定"最优"的含义——短视或远视，治标或治本；模型边界：价值迭代与策略迭代假设模型已知，模型未知时必须数据化；规模边界：状态空间过大时表格型方法不可行，需要分层与近似；最适度边界：单目标最大不是现实世界的全部，"局部最优"与"整体最优"在多约束下需要重新权衡，"适度"往往优于"极端"。这四道边界不是对择优的否定，而是对择优适用域的精确划定：在边界内，价值迭代与策略迭代收敛到全局最优有严格保证；在边界外，需要新的模型——无模型、函数近似、多目标优化——去扩展。对读者而言，最大的收获是养成一种"先问边界、再谈最优"的习惯：任何"最优方案"的结论，都要追问——在什么 γ 下最优？在什么模型假设下最优？在什么规模内最优？在什么目标下最优？四个追问下来，"最优"就从口号变成了有条件的、可检验的结论。边界意识因此也是一种科学态度：一切结论都标注其成立条件，正如中医开方必先辨明证候的适用范围——脱离了证候谈方剂，与脱离了前提谈最优，是同一类错误。这一习惯可以上升为一句职业守则：谈最优必谈前提，谈结论必谈条件——无论是在算法报告还是临床会诊中，都同样适用。

边界意识把我们引向更广的坐标系。前五节的择优，主角是单个决策者：一位医师为自己的证候—方剂选择算最优。但真实世界的择优者从来不是孤立的：医师的"最优"依赖科室的资源，科室的"最优"依赖医院的政策，医院的"最优"依赖医保制度与社会文化——每个层级的"最优"都在上层约束与下层反馈中成形。于是问题从"单个智能体如何择优"扩展为"无数个体如何共同择优"：个体的局部最优能否与系统的整体最优相容？个体追求价值最大时，是否会透支环境资源、损害其他主体的生存空间？这些问题超出单智能体算法，进入系统科学的地界。下一节"系统科学定位"将正面回答：择优中的个体与全局如何协调——个人定位、场景生存最适度与环境共荣最适度，正是把"最优"放回系统之后的三个落点。下一节的三个概念将分别回答：在系统里我是谁、我如何在场景中适度生存、我如何与环境共荣——把本章的"最优"从数学的绝对坐标，转换为人与系统共生的相对坐标。带着这重相对坐标进入下一节，"择优"才算真正落地。
