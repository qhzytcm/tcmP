## 第一部分 基础题（60 分，每题 10 分）

### 基础题 1（对应节号：5.1 最优状态价值与最优策略）

【单选题】关于最优状态价值 v*(s) = maxπ vπ(s)，下列说法正确的是（ ）

A. v*(s) 是某一个特定策略在状态 s 的价值，策略一变，v* 就变
B. v*(s) 是所有策略在状态 s 的价值的最高点（上包络），不依赖任何具体策略，只由状态本身与环境的动力学决定
C. 最优状态价值函数不是唯一的：不同的最优策略对应不同的 v*
D. 只要某个策略在某一个状态达到最大价值，它就是最优策略

【参考答案】B。正文 5.1.1 明确：v* 是在策略集合上取最大值得到的"上包络"，是"位置决定前景"的极限表达，不依赖任何具体策略；它只依赖状态 s 与环境的动力学。A 把 v* 误当成某一策略的价值；C 把"最优价值唯一"搞反——最优价值函数本身是唯一的（这为算法收敛提供统一靶心），只是最优策略可以不唯一；D 忽略最优性要求"在每个状态都达到最大值"（即 vπ*(s) = v*(s) 对一切 s 成立）。

【评分要点】
- 选对 B 得 6 分；
- 能补充"最优价值函数唯一、最优策略可以不唯一"得 2 分；
- 能举例说明"同一个动作对不同状态的价值天差地别"（如失眠：心脾两虚者归脾汤价值高、心火亢盛者当用清心安神之品）得 2 分。

### 基础题 2（对应节号：5.1 最优状态价值与最优动作价值）

【计算题】沿正文失眠链：s3 为康复吸收态（停留在 s3 每步得 +1），s4 为迁延难愈（每步得 0），取 γ = 0.9。在 s2（心脾两虚证）处有两个候选动作：归脾汤将患者带向 s3，黄连解毒汤将患者推向 s4，即时奖励皆为 0。

（1）求 v*(s3) 与 v*(s4)；
（2）求 q*(s2, 归脾汤) 与 q*(s2, 黄连解毒汤)；
（3）在 s2 处应选择哪个动作？若现行策略在此误用黄连解毒汤，换方后价值提升多少？

【参考答案】
（1）v*(s3) = 1 + 0.9 + 0.81 + … = 1/(1−0.9) = 10；v*(s4) = 0（每步得 0，任何折扣后仍为 0）。
（2）q*(s2, 归脾汤) = 0 + 0.9×10 = 9（即时奖励 0 + 折扣后继最优价值）；q*(s2, 黄连解毒汤) = 0 + 0.9×0 = 0。
（3）应选归脾汤（9 > 0）；若误用黄连解毒汤，s2 处价值只有 0，换方后提升到 9，即提升 9。

【评分要点】
- （1）两个数值各 2 分（共 4 分），须写出等比求和过程或"吸收态价值公式"；
- （2）两个 q 值各 2 分（共 4 分），须体现"即时奖励 + γ×后继最优价值"的结构；
- （3）结论 1 分 + 提升幅度 1 分（共 2 分）。

### 基础题 3（对应节号：5.2 最优价值估计方程）

【填空题】写出最优价值估计方程（Bellman optimality equation）的逐状态展开式，并说明它与第 4 章普通价值估计方程的唯一差别。

（1）v*(s) = maxa [ ____________ + γΣs′ ____________ ]，对一切状态 s 成立；
（2）普通价值估计方程用"加权平均"写策略的价值，最优方程的唯一差别是把 ____________ 换成 ____________；
（3）为什么这个方程没有闭式解？

【参考答案】
（1）Σr p(r|s,a) r（当下的即时效果期望）；p(s′|s,a) v*(s′)（后继状态的最优价值）；
（2）加权平均 Σa π(a|s)；最大值 maxa；
（3）因为 max 不能分配到各项内部，方程是非线性的，无法用一次求逆直接解出，只能走迭代逼近的路（这也为 5.4 节价值迭代埋下伏笔）。

【评分要点】
- （1）两处填空各 2 分（共 4 分），须含"即时奖励期望"与"折扣后继最优价值"两层；
- （2）"加权平均→最大值"得 2 分；
- （3）非线性论证得 2 分（答出"max 不可分配 / 非线性 / 只能迭代"任一核心均可）；
- 能补充算子形式 v* = T(v*)（v* 是贝尔曼最优算子 T 的不动点）或动作价值形式 v*(s) = maxa q*(s,a) 得 2 分。

### 基础题 4（对应节号：5.3 贪而不婪）

【单选题】关于贪婪策略（greedy policy）π(s) = argmaxa qπ(s,a)，下列说法正确的是（ ）

A. 贪婪策略只比较即时奖励，是短视的选择，所以本书中"贪婪"是贬义词
B. 贪婪选择的是长期动作价值最大的动作——q(s,a) 已经包含未来全部信息，因此"贪婪即最优"在 MDP 中是一条定理而非道德建议
C. 对任意价值估计做贪婪提取都能得到最优策略，价值算得准不准无所谓
D. 验证某策略是否贪婪时，无需先算出该策略的动作价值

【参考答案】B。正文 5.3.1 强调：强化学习里的贪婪不是日常用语的短视，而是"看得足够远之后只选最好的"——qπ(s,a) 是"当下采取 a、此后一直按策略行动"的长期总回报，已包含未来全部信息。A 把"贪婪"误解为贬义；C 与 5.3.3 的警示相悖——对错误的价值估计贪婪只会放大错误（"价值错一分，贪婪就偏一里"）；D 忽略 5.3.1 指出的微妙循环：验证策略是否贪婪用的 qπ 是策略自己的动作价值，必须先算出该策略的价值。

【评分要点】
- 选对 B 得 6 分；
- 能说出"贪婪的前提是价值账本既全且准"或"先有账本，后有选择"得 2 分；
- 能区分"对给定价值 v 取 argmax"与"验证策略是否贪婪"（后者依赖策略自身的 qπ）得 2 分。

### 基础题 5（对应节号：5.4 价值迭代）

【计算题】3×3 网格世界：九个格子按行编号 s1 至 s9，s9 为目标格（到达后每步 +1），s6 为禁区格（进入得 −1），越界动作弹回原状态并得 −1，其余移动得 0，取 γ = 0.9。从 v0 = 0 出发做价值迭代（同步更新）。

（1）写出第 1 轮价值 v1（提示：第 1 轮 q0(s,a) = r(s,a)）；
（2）求第 2 轮 v2(s8) 与 v2(s6)；
（3）第 3 轮哪些格子开始出现非零价值？结合"价值如水波扩散"说明其机制。

【参考答案】
（1）v1(s9) = 1（到达目标 +1），其余格子第 1 轮价值为 0。
（2）v2(s8) = 0 + 0.9×1 = 0.9（s8 向右一步到 s9）；v2(s6) = 0 + 0.9×1 = 0.9（s6 向下到 s9）。说明：s6 位于 s9 正上方，进入 s9 的动作是"向下"（与正文 5.4.2 一致；向右会越界弹回）。
（3）第 3 轮：s5 向下到 s8 → v3(s5) = 0.9×0.9 = 0.81；s7 向右到 s8 → v3(s7) = 0.81。机制：价值迭代每轮只看"当下最优选择 + 打折后的上轮后继价值"，只有能"看见"已有非零价值的格子才会在下一轮获得非零估计——价值从疗效确切的目标格出发逐圈外扩，每外扩一圈乘 γ，这正是"价值来自未来"的直观画面。

【评分要点】
- （1）v1(s9) = 1 得 2 分、其余为 0 得 2 分（共 4 分）；
- （2）两个数值各 2 分（共 4 分），须写出 0 + 0.9×1 的过程；
- （3）机制说明 2 分（须点出"外扩乘 γ"或"只看上轮后继价值"；只列数值不解释扣 1 分）。

### 基础题 6（对应节号：5.5 策略迭代与收敛）

【简答题】简述策略迭代的两步循环（策略评估与策略改进），并说明为什么在状态与动作均有限的 MDP 中，策略迭代必然有限步终止。

【参考答案】
两步循环：①策略评估——求解当前策略 πk 的价值估计方程 v = rπk + γPπk v，得到精确价值 vπk。对给定策略，该方程是线性方程组，可直接解出，无需迭代逼近（写成 vπk = (I − γPπk)^{-1} rπk；由于 γ < 1 且 Pπk 是每行和为 1 的随机矩阵，I − γPπk 必然可逆）。②策略改进——基于精确价值 vπk，对每个状态贪婪更新：πk+1(s) = argmaxa [ r(s,a) + γΣs′ p(s′|s,a) vπk(s′) ]。交替循环，直到策略不再改变。
有限步终止的理由（两条引理）：策略改进定理（定理5.2）保证价值序列单调不降，且一旦相邻策略价值相等即达最优；而有限 MDP 中确定性策略总数至多为 |A|^|S|，价值严格上升的策略序列不可能无限长，故算法必在有限步内到达"无法再改进"的策略——由等号条件它即是最优策略。

【评分要点】
- 两步循环各 2 分（共 4 分），须含线性方程组写法或逆矩阵形式、argmax 更新式；
- 单调不降 + 相等即达最优 2 分；
- 有限策略总数 |A|^|S| 论证 2 分；
- 终止条件（策略不再改变）2 分。

### 综合题 7（对应节号：5.2 / 5.3 最优价值估计方程、贪而不婪）

【验证计算】沿正文失眠链，已求得最优价值 v* = (8.1, 9, 10, 0)（γ = 0.9）。s1 处动作：进一步辨证（到 s2，即时奖励 0）与草率安神（到 s4，即时奖励 0）；s2 处动作：归脾汤（到 s3，即时奖励 0）与黄连解毒汤（到 s4，即时奖励 0）。

（1）把 v* 代入最优价值估计方程，逐状态验证等号成立；
（2）对 v* 提取贪婪策略，写出 s1、s2 处的动作选择；
（3）若把 v*(s2) 从 9 改成 8 再代回方程，说明为什么等号必然不成立；"验证比求解便宜"这一事实有什么工程价值？

【参考答案】
（1）s4：右边 = 0 + 0.9×0 = 0 = 左边 ✓；s3：右边 = 1 + 0.9×10 = 10 = 左边 ✓；s2：右边 = max{0 + 0.9×10, 0 + 0.9×0} = max{9, 0} = 9 = 左边 ✓；s1：右边 = max{0 + 0.9×9, 0 + 0.9×0} = max{8.1, 0} = 8.1 = 左边 ✓。四个状态等号全部成立，v* 确为最优价值估计方程的解。
（2）s2 处：q*(s2, 归脾汤) = 9 > q*(s2, 黄连解毒汤) = 0 → 选归脾汤；s1 处：q*(s1, 进一步辨证) = 0 + 0.9×9 = 8.1 > q*(s1, 草率安神) = 0 → 选进一步辨证。
（3）把 v*(s2) 改为 8：s1 方程右边 = max{0 + 0.9×8, 0} = 7.2 ≠ 8.1（左边）；s2 方程右边 = max{9, 0} = 9 ≠ 8（左边）——等号必然不成立。工程价值：判断一个候选价值是否最优，只需"代入检验"看两边是否相等，这比"遍历全部策略求最大"便宜得多——可快速发现价值估计的错误，不必每次都重解方程。

【评分要点】
- （1）四状态验证各 1 分（共 4 分），须写出 max 内的两个动作项；
- （2）两个动作选择各 1.5 分（共 3 分），须写出 q 值比较过程；
- （3）不等式论证 2 分（两个方程任一即可）+ 工程价值 1 分（共 3 分）。

### 综合题 8（对应节号：5.1 / 5.4 最优动作价值、价值迭代）

【临床综合】在 tcmP 平台语境中：状态是症状组合，动作是候选方剂，奖励来自证据等级（A 级 1.0、B 级 0.7、C 级 0.4）。设"心烦失眠"状态 s 有三个候选方剂：

- 安神方：证据 C 级，即时奖励 0.4，转向状态 s′（v*(s′) = 5）；
- 健脾方：证据 B 级，即时奖励 0.7，转向状态 s′（v*(s′) = 5）；
- 疏肝方：证据 A 级，即时奖励 1.0，转向状态 s″（v*(s″) = 2）。

取 γ = 0.9。

（1）分别计算三个动作价值 q*(s, a)；
（2）即时奖励最大的动作是不是动作价值最大的动作？结合 v*(s) = maxa q*(s,a) 说明辨证引擎为何应当"择优"（取 max）而非"折中"（取平均），并算出三者的平均值与最大值对照；
（3）价值迭代的每一轮在临床上对应怎样的节奏？为什么说它适配"边诊边学"？

【参考答案】
（1）q*(s, 安神方) = 0.4 + 0.9×5 = 4.9；q*(s, 健脾方) = 0.7 + 0.9×5 = 5.2；q*(s, 疏肝方) = 1.0 + 0.9×2 = 2.8。
（2）即时奖励最大的是疏肝方（1.0），动作价值最大的却是健脾方（5.2）——证据等级高不等于转归价值高，这正是"贪而不婪"：贪的是长期价值，不婪的是眼前甜头。平均值 = (4.9 + 5.2 + 2.8)/3 ≈ 4.3，最大值 = 5.2，折中不等于择优。v*(s) = maxa q*(s,a) 直接表明最优价值是"取最大"而非"取平均"：正如对多名医师的辨证结论取平均并不等于最优方案，辨证引擎应逐候选比较、取最大。
（3）价值迭代每轮 = 用最新疗效反馈修正对证候价值的估计、同时调整下一次选方倾向，"评估一步、改进一步"、边看边学——医师不必等几年攒够数据才改一次方案，每积累一批反馈就更新一次认识；只要反馈源源不断，粗糙的初始估计也会在迭代中逐步校正，这正是价值迭代适配"边诊边学"临床节奏的原因。

【评分要点】
- （1）三个 q 值各 1 分（共 3 分），须写出"即时奖励 + 0.9×后继价值"；
- （2）比较 3 分（即时最大 ≠ 价值最大 1.5 分、平均值 vs 最大值 1.5 分）+ 择优 vs 折中 2 分；
- （3）临床节奏 2 分（须含"评估与改进交织"或"边学边改"；只说"更新价值"扣 1 分）。

### 综合题 9（对应节号：5.5 / 5.6 策略迭代、择优的边界）

【分析计算】3×3 网格世界（s9 目标、s6 禁区、越界弹回 −1，γ = 0.9），初始策略 π0 = "总是向右"。按正文例5.5 第 1 轮评估结果，设 v(s8) = 0.9、v(s6) = 0.9。

（1）在 s5 处比较两个候选动作的 q 值：向下到 s8 与向右进禁区，说明策略改进第 1 轮为何把 π1(s5) 改为"向下"；
（2）写出策略迭代第 2 步（策略改进）的更新式；
（3）用 5.6 节误差上界公式 ‖vk+1 − v*‖∞ ≤ γ/(1−γ)·maxs |vk+1(s) − vk(s)| 说明：为什么 γ 越接近 1，需要把收敛阈值 ε 取得越小？结合 γ = 0.9（约 44 轮达 1% 精度）与 γ = 0.5（约 7 轮）说明。

【参考答案】
（1）向下到 s8：q = 0 + 0.9×v(s8) = 0.9×0.9 = 0.81；向右进禁区：q = −1 + 0.9×v(s6) = −1 + 0.9×0.9 = −0.19。0.81 > −0.19，故贪婪改进把 π1(s5) 改为"向下"。
（2）πk+1(s) = argmaxa [ r(s,a) + γΣs′ p(s′|s,a) vπk(s′) ]，对每个状态 s 逐一执行；全部状态更新完后回到策略评估，循环直到 πk+1 = πk。
（3）放大系数 γ/(1−γ) 随 γ 增大而急剧增大：γ = 0.9 时为 9，γ = 0.99 时放大到 99——同样的相邻差 maxs |vk+1(s) − vk(s)| 对应的真实误差上界放大近一个数量级，因此高折扣率场景必须收紧 ε 才能保证精度（正文：γ = 0.9 时取 ε = 1e−6，误差上界约 9e−6；γ = 0.99 时需更小阈值）。收敛轮数方面，误差按 γ^k 衰减：γ = 0.9 达 1% 精度约需 44 轮，γ = 0.5 仅约 7 轮——远见（大 γ）与计算代价（慢收敛）是一对矛盾。

【评分要点】
- （1）两个 q 值各 2 分（共 4 分）+ 结论 1 分（共 5 分）；
- （2）更新式 2 分（须含 argmax 结构；漏写 γΣs′ p(s′|s,a) vπk(s′) 扣 1 分）；
- （3）3 分：放大系数论证 1.5 分（含 γ/(1−γ) 与 ε 的关系）、44/7 轮对照 1.5 分。

## 第三部分 挑战题（10 分）

### 挑战题 10（对应节号：5.2 / 5.6 / 5.7 / 5.8 最优价值估计方程、择优的边界、系统科学定位、六者和谐）

【开放设计题】tcmP 平台要为"慢性阻塞性肺疾病（COPD）稳定期管理"设计一套择优系统，引导医者"治本"（防急性加重、控远期复发）而非"治标"（只压当下症状）。

（1）写出稳定期管理场景的最优价值估计方程，并用中文说明每个符号的临床含义（状态、动作、奖励、γ）；
（2）给出 γ 的设置建议，并用 5.6 节例5.6 的逻辑（甲"绕远路"奖励序列 0, 0, +10；乙"走近路"奖励序列 +1, +1, 0；γ = 0.1 时最优选乙、γ = 0.9 时最优选甲）说明 γ 如何决定"治标"与"治本"；
（3）用 5.7 节系统科学定位三个概念说明：基层全科医师做个人定位的三个步骤、场景生存最适度对 γ 与代价的约束、环境共荣最适度如何防止"只考核达标率"导致的过度用药；
（4）用 5.8 节规者与医者质量共识的四条机制说明如何把"最优"变成可共同接受的方案，并用一句话给出 tcmP 平台落地建议。

【参考答案（示例，允许合理差异）】
（1）v*(s) = maxa [ Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′) ]。临床含义：s = 症状组合/功能分级（如咳痰喘分级、肺功能分级）；a = 稳定期管理方案（中西医结合方案、单纯西药、单纯中药、肺康复训练等）；r = 疗效反馈（症状缓解、急性加重次数、肺功能变化，可映射证据等级 A 级 1.0 / B 级 0.7 / C 级 0.4）；γ = 远期权重——慢病管理重防复发，宜取大值（如 0.95–0.99）。
（2）γ 建议取大值。例5.6 的逻辑：γ = 0.1 时甲（绕远路）折扣回报 = 0 + 0.1×0 + 0.01×10 = 0.1，乙（走近路）= 1 + 0.1×1 + 0.01×0 = 1.1，最优选乙——眼前小甜头盖过遥远 +10；γ = 0.9 时甲 = 0 + 0.9×0 + 0.81×10 = 8.1，乙 = 1 + 0.9×1 + 0.81×0 = 1.9，最优选甲——愿为远期大收益绕远路。γ 正是"急则治标、缓则治本"的参数化表达：γ 小则模型学成"治标"（只盯即时疗效），γ 大才学会"治本"（愿为远期康复承担近期代价，如肺康复训练短期未见效）。
（3）个人定位三步骤：状态定位（我在哪——基层全科，掌握约 500 个病证单元）、能力定位（我能做什么——可用的方剂与康复指导、可调用的转诊渠道，动作集大小决定本地择优范围）、目标定位（我要去哪——降低急性加重率，翻译为可量化的回报信号）。场景生存最适度：稳定期管理 γ 大、重远期，但价值须与代价同账——费用过高的方案即便疗效价值大，在医保控费场景下也未必"最适"。环境共荣最适度：若只考核"达标率"，医者可能为达标而过度用药、或拒收难治患者，透支医保基金与患者信任（公地悲剧），奖励表须加入安全与资源维度惩罚，维持系统稳态。
（4）四条机制：①质量指标与奖励设计对齐——把"急性加重次数 + 远期复发率"设为复合指标，用 γ 思维修正质控导向；②质控闭环——处方 → 质控 → 反馈 → 修正，配伍禁忌与剂量校验嵌入流程必经环节；③规则共建与循证修订——基于随访数据修订规范，规则公开、可解释、可验证；④决策与评价分离——独立质控评估器监督医者决策，避免既当运动员又当裁判员。落地一句话：在 tcmP 平台上将慢阻肺随访数据实时映射为奖励信号，γ 按慢病场景取 0.95 以上，质控规则与疗效证据双向流动，使"最优"成为可观测、可检验、可问责的公共知识。

【评分要点】
- （1）3 分：方程正确 2 分（max 结构 + 即时奖励 + 折扣后继价值）、四个符号语义映射 1 分；
- （2）3 分：γ 建议 1 分、例5.6 逻辑复述 1 分（须含两个 γ 下的数值或结论对比）、治标/治本对应 1 分；
- （3）2 分：三个概念各落到实处（三步骤 / 价值与代价同账 / 公地悲剧式过度用药），只贴名词扣 1 分；
- （4）2 分：四条机制任答 ≥2 条 1 分、落地一句话含"可观测/可检验/可问责"或等义表述 1 分。
