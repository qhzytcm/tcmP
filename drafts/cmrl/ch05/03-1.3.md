## 5.3 贪而不婪：局部最优与整体最优

### 5.3.1 概念与内涵

上一节结尾我们注意到：最优价值估计方程在每个状态独立取最大，却解出全局最优。本节正面解释这个现象。先定义贪婪策略（greedy policy）：给定策略 π 及其动作价值 qπ，若 π 在状态 s 选择使 qπ(s,a) 最大的动作，即 π(s) = argmaxa qπ(s,a)，就说 π 在 s 是贪婪的；若在每个状态都如此，π 就是贪婪策略。"贪婪"一词来自日常用语，但含义必须澄清：日常的贪婪是短视的——只顾眼前利益，不顾长远后果；强化学习里的贪婪却是"看得足够远之后只选最好的"——因为 qπ(s,a) 不是即时指标，而是"当下采取 a、此后一直按策略行动"的长期总回报，它已经包含了未来全部信息。这里有一个微妙的循环值得指出：验证"某策略是否贪婪"时用到的 qπ，是策略自己的动作价值——必须先算出该策略的价值，才能判断它是否贪婪。这与"对给定价值 v 取 argmax"是两回事：后者不依赖策略，读者应能区分这两种表述。贪而不婪的智慧因此在于：贪，是每次选择都取当下价值最大的动作，不回避比较；不婪，是因为这个"价值最大"是全生命周期的账，不是眼前的甜头——不为一时小利而动摇长远最优。这个微妙的循环还提示一个实现要点：工程上通常先估计价值、再提取贪婪策略，而不是反过来——先有账本，后有选择。也正因如此，"贪婪"在本书中不是贬义词，而是一种被定理保证的理性选择模式。

"贪而不婪"在中医语境中有自然的回响。临床常说"效不更方、效差变方"：一个方剂有效就沿用，疗效变差就调整——这正是"用疗效反馈评估价值、按价值择优"的朴素版本。但它要求冷静的账本意识：评估一个方剂好不好，不能只看一两剂后的即时反应（单步奖励），而要看整个疗程乃至愈后防复发的长期价值（折扣回报）——一个初服即觉温热、却能根治宿疾的方剂，比一个"当下舒服、反复发作"的方案价值更高，这恰是"贪而不婪"：贪于长期疗效，不婪于一时舒适（见图 5-4）。再往深一层，"贪而不婪"还对应一种决策品格：择优不是见利忘义地追逐极端，而是清醒地在每个状态选择真正最优的路径——名医之所以"用药如神"，并不是每味药都新奇，而是每步选择都对准了长期最优；青年医师与名医的差距，也往往不在知识的多少，而在价值账本的完整与精确。理解了这层含义，就能明白为什么"贪婪即最优"在 MDP 中是一条定理，而不是一种道德建议——它是数学结构使然，而非品格修养使然。需要补充的是，"贪而不婪"并不排斥随证变化：当病情变化使状态转移，贪婪选择会自然地指向新状态下的最优动作——择优是随状态而变的，不是一劳永逸的。

### 5.3.2 方法与实现

定理5.1（贪婪策略最优，greedy is optimal）：设 v* 是最优价值估计方程的解，定义策略 π 使每个状态 s 都满足 π(s) = argmaxa [ Σr p(r|s,a) r + γΣs′ p(s′|s,a) v*(s′) ]，即对 v* 贪婪，则 π 是最优策略，且其价值 vπ = v*。这条定理的威力在于：它把"在指数多个策略中全局寻优"转化为"在每个状态对有限个动作取 argmax"。证明只有三步。第一步引理：对任意策略 π 和状态 s，vπ(s) = Σa π(a|s) qπ(s,a) ≤ maxa qπ(s,a)——加权平均不可能超过最大项，这是整个证明的引擎。第二步：设 π 是对 v* 的贪婪策略，用归纳法可证 vπ(s) ≥ v*(s) 对一切 s 成立，直觉是"贪婪选择的动作价值不低于任何加权平均"；归纳从后继状态向前推进，每一步都用贝尔曼分解把 vπ 与 v* 的差距沿状态链传递。第三步：由最优价值的定义，v*(s) ≥ vπ(s) 对一切策略成立；结合第二步的相反不等式，得 vπ = v*，π 即最优策略。整个证明只有两个不等式，其余全是代数化简——读者应当能独立复述这四步，它比记忆公式更能揭示本质。

用失眠链验证定理。上一节求得 v* = (8.1, 9, 10, 0)。对 v* 提取贪婪策略：在 s2，q*(s2, 归脾汤) = 9 > q*(s2, 黄连解毒汤) = 0，故选归脾汤；在 s1，q*(s1, 进一步辨证) = 0 + 0.9×9 = 8.1 > q*(s1, 草率安神) = 0，故选进一步辨证。这个贪婪策略在每个状态的价值都等于 v*，正是最优策略。若动作价值并列（例如某状态两个动作都达到同一最大值），任选其一仍是最优——定理保证并列选择不改变价值，最优策略可以不唯一。实现上的关键启示：所有基于价值的择优算法——价值迭代、策略迭代，乃至后面的 Q 学习——最终都是通过贪婪提取（argmax）得到策略的；估计价值只是手段，贪婪提取才是通向最优的最后一公里。操作规范因此只有一句：先把价值算准，再在每个状态取 argmax——顺序不能颠倒，价值错一分，贪婪就偏一里。这也解释了一类常见临床失误：凭直觉"看着像热证就用清热方"，其实是对价值的粗糙估计。把证据与转归数据纳入账本，贪婪选择才真正指向最优。若在 s1 处另设第三个动作"直接疏肝"，其 q 值为 0 + 0.9×0 = 0，同样不敌"进一步辨证"——候选再多，argmax 也只认价值最高者。

### 5.3.3 小结与衔接

本节回答了"为什么局部选择等于全局最优"：因为动作价值 q(s,a) 已经把未来行为折叠进当下选择，在每个状态对这个"复合指标"取 argmax，就自动协调了所有未来的行为。贪婪不是短视，而是远视之后的果断；贪而不婪，贪的是长期价值，不婪的是眼前小利。定理5.1（贪婪策略最优）给出了严格保证，证明的核心只是一个不等式：加权平均不超过最大值。这个结果的三个层面值得记住。计算层面，寻优从"遍历策略空间"（指数级）降为"逐状态 argmax"（多项式级），量级的差别决定了算法可行与否；算法层面，它是价值迭代、策略迭代与一切 argmax 提取策略方法的理论支点——后续算法的正确性最终都归结到这条定理；解释层面，它把"名医经验可计算化"落到实处——名医的每次抉择，都是对长期价值的贪婪选择，而名医与普通医师的差距，正在于价值账本算得准不准。定理还顺带回答了策略改进的单调性：只要价值账本正确，贪婪改进每一步都不倒退。定理5.1还隐含一个推论：最优策略是"自洽"的——它对自己的动作价值贪婪，而这一自我一致性正是最优性的判据。

但贪婪策略最优有一个不容忽视的前提：动作价值必须算得对。定理说的是"对最优价值 v* 贪婪"——如果用的是错误的价值估计，贪婪只会把错误放大，指向错误的方向。这引出两个问题。其一，如何获得 v*？最优价值估计方程没有闭式解，需要迭代求解——这正是第 5.4 节价值迭代与第 5.5 节策略迭代的任务；其二，贪婪在什么条件下可能失效？当价值估计有偏、模型不精确，或优化目标本身需要在多约束下权衡时，"局部最优"未必等于"整体最优"——这是第 5.6 节"择优的边界"要划清的界线。因此，本节是本章的枢纽：它把前两节的"最优是什么"接通到后三节的"最优怎么算、算到哪为止"。带着"如何把 v* 算出来"的问题进入下一节，是本节最自然的衔接。另外请记住，定理5.1的"贪婪"是对价值函数的贪婪，而不是对即时奖励的贪婪：即时奖励最大的动作未必是动作价值最大的动作——这正是"贪而不婪"与"见利忘义"的分水岭。一句话总结本节：局部择优之所以能成就整体最优，前提是价值账本既全且准。对临床决策者而言，这条定理给出了可操作的工作方式：不必纠结于"哪套方案最好"的玄思，先把各候选方案的长期价值算清，再逐状态取最大——择优因此从艺术变成了工程。
