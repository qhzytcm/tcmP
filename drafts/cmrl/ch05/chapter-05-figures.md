## 图 5-4 贝尔曼最优算子与不动点（对应节号：5.2.2、5.4.1）

- 图题：不动点：v* = T(v*)
- 内容说明：价值空间示意图：从任意初值 v0 出发反复作用贝尔曼最优算子 T：v1 = T(v0)、v2 = T(v1)、…… 逐次逼近 v*；v* 处标注"不动点（fixed point）：被变换作用后保持不变的点"。配压缩性质示意：T 把任意两点距离至少压缩 γ 倍（γ < 1），Banach 不动点定理保证唯一不动点且从任意初值出发都收敛。
- 绘制建议：
  - 结构：横轴为价值空间，箭头链 v0 → v1 → v2 → … → v*，步长逐次缩小（几何收敛的视觉）；
  - 标注：v* 位置画靶心符号；每条箭头上方标注"压缩 γ 倍"示意；
  - 双语：不动点旁注"fixed point"、压缩映射旁注"contraction mapping"；
  - 配色：收敛轨迹箭头由浅至深，突出逼近方向；
  - 注意：与 5.4.1"折扣率就是为收缩性而设的——γ < 1 是价值有界与迭代收敛的共同根源"表述一致。

## 图 5-7 价值迭代 vs 策略迭代（对应节号：5.4、5.5）

- 图题：两种火候：价值迭代"每尝一口就改配方"，策略迭代"整锅尝明白再改一次配方"
- 内容说明：左右两栏流程图。左栏价值迭代：vk → 算全部 qk → 取 max 更新 vk+1 → 检查相邻差 maxs |vk+1 − vk| < ε，循环；右栏策略迭代：πk → 策略评估（解线性方程组，评估到底）→ 策略改进（贪婪更新 πk+1）→ 检查 πk+1 = πk，循环。中间差异标注"评估一步 vs 评估到底"；下方统一框架条：截断策略迭代居中，j = 1 退化为价值迭代、j → ∞ 退化为策略迭代。
- 绘制建议：

  - 注意：两条算法在小规模问题上应解出同一最优价值与最优策略——结果一致性可作实现正确性的交叉验证（5.4.3）。

## 图 5-8 策略迭代流程图（对应节号：5.5.2）

- 图题：策略迭代：评估到底、改进到底，有限步到达最优
- 内容说明：标准流程框图：初始化（任取策略 π0，如全部取第一个动作）→ 策略评估（求解 v = rπk + γPπk v，元素形式 v(s) = r(s, πk(s)) + γΣs′ p(s′|s, πk(s)) v(s′)，写成 vπk = (I − γPπk)^{-1} rπk）→ 策略改进（πk+1(s) = argmaxa [ r(s,a) + γΣs′ p(s′|s,a) vπk(s′) ]）→ 判断 πk+1 = πk 是否对一切 s 成立：是 → 输出最优策略；否 → 回到策略评估。旁注三条性质：价值单调不降（定理5.2）、有限步终止（定理5.3，确定性策略总数 ≤ |A|^|S|）、I − γPπk 必然可逆（γ < 1 且 Pπk 为随机矩阵）。
- 绘制建议：
