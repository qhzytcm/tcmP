## 2.6 价值函数：从认知走向判断

### 2.6.1 价值函数：概念与内涵

价值函数把本章此前的概念收拢为一个可计算的判断依据。状态价值（state value）定义为 vπ(s) = E[Gt | St = s]。通俗地说：从状态 s 出发、按策略 π 行事，平均能获得多少折扣回报。它同时包含状态（从哪出发）、策略（如何行事）、回报（如何评价）与期望（如何处理随机性）四个要素：数值大，说明这个状态在既定策略下前景好；数值小，说明前景差。价值依赖策略：同一状态，按谨慎的策略与按冒进的策略行事，期望回报不同，价值就不同——这正对应临床中"同一证候，不同医者处理，预后不同"的经验。从认知走向判断的链条至此闭合：观测（2.1）、建模（2.2）、转移（2.3）、回报（2.4）、期望（2.5）五步描述世界，价值函数给出评价，判断由此获得数量基础。有了这个数字，"这个状态好不好"就不再是感觉，而是可以比较、可以排序、可以优化的对象。需要提醒读者的是，价值是"按策略 π"定义的：离开策略谈价值没有意义。一位按经验方治病的医师与一位按循证方案治病的医师，面对同一证候计算出的临床价值可能不同——价值测量的是"策略与状态的组合"，而非状态本身，这正是后续策略改进的立足点。判断之前先问策略，是价值函数给临床的第一条忠告：先明确"按什么路径治"，再谈"这个状态值多少"。

与状态价值相伴的是动作价值（action value）qπ(s,a) = E[Gt | St = s, At = a]。通俗地说：在状态 s 采取动作 a、此后按策略 π 行事，平均能获得多少折扣回报。两者的分工是：状态价值回答"我在这里好不好"，动作价值回答"这一步选什么好"。二者有确定的关系：vπ(s) = Σa π(a|s) qπ(s,a)——状态价值是各动作价值按策略概率的加权平均。由此立得 vπ(s) ≤ maxa qπ(s,a)：只要把策略的概率从次优动作移向更优动作，状态价值只会上升。这正是"策略改进"的方向，也是第 4 章最优策略研究的起点——中编将用贝尔曼最优方程与价值迭代、策略迭代把它变成算法。在中医语境中，状态价值对应某证候在既定诊疗路径下的期望疗效，可称为"临床价值"；动作价值对应某方剂在某证候下的期望疗效，正是"方证对应"的量化——同一症状组合，选方不同，动作价值不同，这就是"有是证用是方"的数学表达：方证对应得越准，动作价值越高。临床上还可以利用动作价值做"预演"：面对一个症状组合，把几首候选方剂的 qπ(s,a) 排成一列，高的优先、低的备用。这等于把"方证对应"的隐性经验显性化为一张可比较的清单，也为第3章的贪婪策略提供了直觉。这张清单还会随随访数据更新——每次复诊都是对 qπ(s,a) 的一次重新估计，动作价值因此是活的，不是一次算定。

### 2.6.2 价值函数：方法与实现

计算价值函数的核心工具是贝尔曼方程（Bellman equation），其推导只需两步。第一步，自举（bootstrap）：把折扣回报拆开，Gt = Rt+1 + γGt+1——当下的奖励加上折扣后的未来回报，一个量用它自己下一时刻的版本来表示，这正应了"未来从当下生长出来"的直觉。第二步，对两端在条件 St = s 下取期望，利用全期望公式与马尔可夫性质，得到 vπ(s) = Σa π(a|s)[Σr p(r|s,a) r + γ Σs′ p(s′|s,a) vπ(s′)]。其中 p(r|s,a) 是奖励分布：奖励也可以带随机性——同方异效时疗效反馈有大有小，p(r|s,a) 表示在状态 s 执行动作 a 后获得奖励 r 的概率，Σr p(r|s,a) r 正是"当下的平均效果"。通俗地说：一个状态的价值等于当下的平均效果，加上折扣后的未来各状态价值的加权平均。状态价值相互耦合，构成方程组；写成矩阵形式 v = rπ + γPπv，在 γ < 1 时解存在且唯一，解析解为 v = (I − γPπ)⁻¹ rπ。同时，迭代格式 v_{k+1} = rπ + γPπvk 从任意初值出发都收敛到解，误差每步至少缩小 γ 倍。存在性、唯一性、迭代收敛，三者合称贝尔曼方程的三个基本性质，它们保证了"价值"不是一个虚构的概念，而是一个算得出来、算得唯一、算得稳定的量。自举的美妙之处在于：它不需要枚举无限长的轨迹，只需要"当下"与"下一步"两层信息，就把无限问题化为有限递推。这正是贝尔曼方程能落地计算的根源。

用一个四状态的健康模型演示求解。设 s1 为表证初起、s2 为向愈、s3 为里证得治、s4 为痊愈（吸收态，absorbing state）：s1 用方后转到 s2（奖励 0），s2 转到 s4（奖励 +1），s3 转到 s4（奖励 +1），s4 维持痊愈每期 +1；取 γ = 0.9。由 vπ(s4) = 1 + 0.9 vπ(s4) 得 vπ(s4) = 10；再由 vπ(s2) = 1 + 0.9×10 = 10，vπ(s3) = 10，vπ(s1) = 0 + 0.9×10 = 9，得到价值向量 v = (9, 10, 10, 10)；认知阶梯与四状态求解见图 2-4。结果含义一目了然：痊愈状态价值最高，一步可愈的状态次之，初起状态最低——离健康越近，价值越高，这个"距离"正是折扣的直观体现。若不用求逆而用迭代：从 v0 = 0 出发反复套用 v_{k+1} = rπ + 0.9 Pπ vk，误差每步乘以 0.9，几十步即可收敛到同一答案——这说明即使状态很多、矩阵很大，价值依然可以高效求得。在 tcmP 平台上，可用真实病证数据构造小规模 MDP，用同样的方法求解每个症状组合的"临床价值"，具体实践见平台实训章节。读者可以自行验证：若把奖励改为到达痊愈才给 +1、其余为 0（维持痊愈不再给分），由 vπ(s4) = 0 + 0.9 vπ(s4) 得 vπ(s4) = 0，vπ(s2) = 1 + 0.9×0 = 1，vπ(s3) = 1，vπ(s1) = 0 + 0.9×1 = 0.9，价值向量变为 (0.9, 1, 1, 0)——痊愈状态的价值反而最低，因为模型不再为"保持痊愈"发放奖励：奖励设计变了，价值排序就变，这说明价值永远服务于目标设定。

### 2.6.3 价值函数：小结与衔接

本节要点回顾：状态价值 vπ(s) 与动作价值 qπ(s,a) 把回报的期望作为状态的评价，二者满足 vπ(s) = Σa π(a|s) qπ(s,a)；贝尔曼方程由自举与条件期望导出，矩阵形式 v = rπ + γPπv 有解析解，存在性、唯一性、迭代收敛三个性质保证了价值可算；四状态例题给出 v = (9, 10, 10, 10)，直观展示了"离健康越近价值越高"；在临床上，状态价值即临床价值，动作价值即方证对应的量化。至此，评价"状态好坏、动作优劣"的数学工具已经完备，辨证论治第一次获得了可计算的评价体系：一个证候、一首方剂的价值，从此可以放在同一把尺子上比较，证候的轻重缓急与方剂的优劣得失，都有了统一的度量。但也必须记住价值的条件性：一切价值都是"给定模型、给定策略、给定 γ"下的价值，模型一变、策略一变、时间偏好一变，数字就要重算。把价值当成永恒真理，恰恰违背了 2.5 节关于认知边界的告诫；带着这个条件意识去用价值，价值才真正可靠。反过来，正因为价值有条件，它才可更新：新证据、新策略、新时间偏好都会触发重算，价值函数因此成为活的学习对象，而不是刻在石头上的教条——这正是"辨证论治"动态性的数学对应。

然而，价值函数目前还只是"单智能体"的评价工具：它假设一位医者面对一个患者，在固定的转移与奖励下计算价值。真实世界远比这复杂——医者不是孤立的节点，他身处科室、医院、制度构成的层层系统；场景不同，转移与奖励就不同，同一价值在不同场景下要重新计算；他的行为还会影响其他主体与整体环境，开大处方或许提升单次收益，却可能透支公共资源。把价值函数放进分布式系统的视角，就引出本章最后两节的问题：个体如何在场景中定位，系统如何实现共荣？下一节 2.7 从系统科学的角度讨论个人定位、场景生存最适度与环境共荣最适度；2.8 节则把视角落到医、患、药、械、规、法六者，讨论相互理解与和谐——把"单人的价值"扩展为"众生的和谐"。这个扩展不是否定价值函数，而是给它加上两个坐标：横向的"场景坐标"——同一价值在不同场景下要重算；纵向的"系统坐标"——个体价值要放入环境承载力中检验。有了这两个坐标，单智能体的价值理论就获得了通向多智能体世界的桥梁。从方法上看，这种扩展还提示：当场景众多时，不必为每个场景单独建模，可以在公共模型上加场景参数，实现价值在不同场景间的迁移——这是后文分布式算法的思想萌芽。
