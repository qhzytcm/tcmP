## 2.4 折扣回报：治未病与远期健康

### 2.4.1 折扣回报：概念与内涵

即时奖励只能评价一步的得失，评价一条完整病程则需要累积的指标。折扣回报（discounted return）已在 2.2.2 节给出定义：Gt = Rt+1 + γRt+2 + γ²Rt+3 + …——把未来每一步的得失按折扣折算到当下再相加：越远的未来，权重越小，因为每往后推一步就要多乘一次折扣率 γ。本节展开它的两重作用与治未病的对应。折扣率 γ ∈ (0,1) 有两重作用。在数学上，它保证无限长轨迹的回报收敛为有限值——没有折扣，无限期的收益求和可能发散，比较策略就失去基础。在语义上，它体现时间偏好——现在的一分健康比未来的一分健康更真实、更紧迫，这与中医"急则治其标"的直觉一致。更重要的是，折扣率刻画决策者的目光远近：γ 越大，未来权重越高，越愿意为远期投入；γ 越小，越只顾眼前。评价策略因此从"看一步"升级为"看全程"：回报区别于即时奖励的本质，正在于它把时间的维度放进评价，让"长远"成为决策的一部分。如果把即时奖励比作眼前的分数，折扣回报就是整场考试的加权总分：一次小考失手不要紧，只要后面的比重大科目考好；反之，前面的甜头也可能被后面的失分吞没。折扣的本质是给时间定价：未来的一分健康值现在多少，由 γ 说了算；价格定得越高，越舍得为未来投资。

折扣回报为"治未病"提供了精确的数学语言。《素问·四气调神大论》说："圣人不治已病治未病，不治已乱治未乱。"治未病包含三个层次：未病先防，在健康时调摄养生；既病防变，在已病时截断传变；瘥后防复，在愈后巩固调养。三个层次的共同点是：为远期健康支付当下的成本。养生需要时间与自律，防变需要早期干预，防复需要持续随访；这些在即时奖励上常常"看不出好处"，却在长期回报上价值巨大。折扣回报告诉我们：选择"当下奖励小、未来回报大"的路径是否明智，取决于 γ 的大小。慢性病管理与养生保健对应大 γ 的远视策略，急诊抢救则对应小 γ 的当下策略。换言之，治未病不是道德口号，而是在折扣回报框架下"放长线钓大鱼"的理性选择，也是中医时间观与现代决策理论的汇合点：把"上工治未病"从一句格言，翻译成可以计算、可以比较的回报结构。需要澄清的是，"未病先防"并不等于否定治疗：防与治不是对立的两种策略，而是同一折扣框架下的不同时间投入——防的投入更早、更轻，治的投入更晚、更重。框架给出的比较是：同等健康收益下，投入越早越省，这正是"上工治未病"的算账逻辑。这也是为什么养生观念强的地区往往慢病负担更低——大 γ 的社会在系统层面受益，个体决策与公共健康因此同向。

### 2.4.2 折扣回报：方法与实现

计算折扣回报需要几何级数求和。设每个时期奖励恒为 +1，则 G = 1 + γ + γ² + … = 1/(1−γ)。用它比较三种健康策略。策略一（未病先防）：长期调摄，不病，第一期为投入期（记奖励 0），自第二期起每期健康奖励 +1，回报 G1 = 0 + γ·1 + γ²·1 + … = γ/(1−γ)。策略二（病后才治）：先受病痛之苦，即时奖励 −1，经治恢复后每期 +1，回报 G2 = −1 + γ/(1−γ)。策略三（时防时忽）：以 0.5 概率得病、0.5 概率不得，回报取两条路径的期望，G3 = 0.5×G1 + 0.5×G2 = −0.5 + γ/(1−γ)。因为对任意 γ ∈ (0,1) 都有 γ/(1−γ) > −0.5 + γ/(1−γ) > −1 + γ/(1−γ)，所以 G1 > G3 > G2：预防优于时防时忽，更优于病后才治。直觉在此得到数学确认——防大于治。同时，这个例子也说明随机策略的回报必须取期望，为 2.5 节处理随机性作了铺垫。从数值上还可以读出更有趣的信息：当 γ 接近 1 时，三种回报都趋于无穷大，但彼此之差保持不变——差距由"第一步"的即时奖励决定（G1−G3 = 0.5，G3−G2 = 0.5）。这说明第一步的决策虽小，却通过折扣把差距放大为长期回报之差；一步之差，千里之遥。时间轴、γ 旋钮与三策略比较见图 2-3。

折扣率 γ 的选择本身就是一个决策。γ 趋于 0 时，只看眼前一步，策略短视，宜于急症处理；γ 趋于 1 时，未来与现在几乎同等重要，宜于慢病管理与治未病。在建模实践中，应当把 γ 显式设定并写入决策文档：同一套数据，γ = 0.9 与 γ = 0.5 会给出不同的价值排序，管理者与医师必须知道自己在什么时间偏好下做判断。实现"治未病入模型"的另一关键是奖励设计：未病状态与养生行为不能给零奖励。预防的收益在于降低了未来大病的概率，应当通过折扣回报自然体现——把"减少大病风险"折算为长期回报，养生行为才能获得应有的价值。反过来也要警惕奖励设计的偏差：若奖励只统计当期疗效而不计远期转归，模型就会鼓励"治已病"而贬低"治未病"。折扣回报还提醒：即时奖励最大的动作未必带来最大的回报——眼前的一剂猛药若伤及正气，远期回报反而更低，这正是"中病即止"分寸观的价值判断所在：攻邪以祛邪为度，过用则伤正。实现上还要注意奖励的一致性：同一套疗效标准要贯穿所有状态，避免"甲状态看重缓解、乙状态看重根治"的尺度漂移；奖励表定稿后，应像质控文档一样受版本管理，任何调整都要记录理由与影响范围。奖励设计没有标准答案，但有检验标准：任何奖励映射都应能在临床上讲出道理，讲不出道理的映射迟早误导决策，须及时修正。

### 2.4.3 折扣回报：小结与衔接

本节要点回顾：折扣回报 Gt = Rt+1 + γRt+2 + γ²Rt+3 + … 把未来各时刻的得失折算到当下，γ ∈ (0,1) 在数学上保证收敛、在语义上刻画时间偏好；三种策略的回报比较 G1 > G3 > G2 以几何级数确认了"防大于治"；治未病三层次——未病先防、既病防变、瘥后防复——在折扣框架下都是为远期健康投入当下成本的理性选择；γ 的取值需要显式设定，奖励设计必须让预防收益进入回报。把本节与 2.3 节衔接：转移概率回答"病情会走向哪里"，折扣回报回答"远方的得失值多少"；两者合起来，才可能评价一条完整病程的长期价值。读者可以自问：我所在的科室、我管理的病种，γ 应该取多大？把这个问题想清楚，折扣就不再是抽象的公式，而是临床决策的时间观。三个层次还可以对应三种 γ 场景：未病先防对应健康管理的大 γ（十年尺度），既病防变对应治疗期中的中 γ（疗程尺度），瘥后防复对应康复期的较大 γ（随访尺度）——同一患者在不同阶段，医者手中的"望远镜"焦距不同。除了 γ，回报计算还隐含一个选择：每个时期的长度。以日、以周还是以疗程为一步，决定了对"远期"的定义，也决定转移矩阵的粒度，建模时应与临床随访节奏保持一致。选得越贴近临床节奏，价值数字就越能直接指导排班、随访与疗效评估。

然而，折扣回报的计算隐藏着一个尚未处理的困难：回报是沿轨迹累积的，而轨迹本身是随机的——同一种病，同一位医者，用同一首方，不同患者的转归仍可能不同。因此，单次运行得到的回报只是一个随机实现，可能偏高也可能偏低，不能直接当作评价依据。这就要求把随机性平均掉，用期望（expectation）来评价。下一节 2.5 将直面这一问题：模型与不确定性——认知的边界，讨论随机性从何而来、期望如何工作、模型的边界在哪里，以及医者如何在不确定性中保持判断的审慎。理解了不确定性，我们才能定义真正稳健的评价指标——这正是 2.6 节价值函数的铺垫：把"期望"写进"评价"，价值函数才站得住脚。单次运气不是规律，平均结果才是依据，这正是从"个案经验"走向"循证判断"的关键一跃。读者不妨做一个小实验：把 2.4.2 节三种策略的回报用 γ = 0.5 与 γ = 0.9 分别算一遍，观察排序是否变化、差距如何伸缩。这个实验虽小，却直观地展示了"期望"与"折扣"联手塑造评价的机制，也为 2.6 节的价值函数预演了运算。若实验中发现排序对 γ 极敏感，则说明该决策问题的时间偏好权重很大，管理者应组织讨论，明确组织层面的 γ 取值，而不是任其隐晦存在。
