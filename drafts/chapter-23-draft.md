## 23.1 常用腧穴定位与主治

### 23.1.1 腧穴定位方法快速回顾

在正式认识具体腧穴之前，请回顾第8章学习过的三种基本定位方法：

| 方法 | 说明 | 示例 |
|------|------|------|
| **骨度分寸法** | 以骨节为主要标志，将身体不同部位规定为一定分寸，据此折算取穴 | 前发际至后发际12寸，两乳头之间8寸 |
| **体表标志法** | 利用五官、毛发、爪甲、乳头、脐窝、骨节凸起凹陷等作为取穴标志 | 两眉之间取印堂，第7颈椎棘突下取大椎 |
| **手指同身寸法** | 以患者本人手指为标准度量取穴，包括中指同身寸、拇指同身寸、横指同身寸（一夫法） | 拇指指间关节横纹宽度为1寸，四指并拢横量为3寸 |

> **重要提醒**：骨度分寸法是最基础、最准确的取穴方法。手指同身寸法只能作为辅助，不应用来替代骨度分寸法用于关键腧穴的定位。

本节精选临床各部位最常用的腧穴，按头面→胸腹→背腰→上肢→下肢的顺序逐一讲解。每个腧穴均附有定位口诀、主治归纳和操作要点。

### 23.1.2 头面部常用腧穴

#### 1. 百会（Bǎihuì，GV 20）——督脉

| 项目 | 内容 |
|------|------|
| **定位口诀** | "两耳尖连线，颅顶正中间" |
| **详细定位** | 在头部，前发际正中直上5寸。简便取法：两耳尖直上连线的中点处 |
| **类属** | 督脉要穴，三阳五会之所 |
| **主治** | ① 头痛、眩晕、失眠、健忘（神志病症之首） ② 脱肛、阴挺（升阳举陷） ③ 中风失语、癫狂痫 |
| **操作** | 平刺0.5-0.8寸。可灸 |

> **临床经验**："头项寻列缺"虽为四总穴歌之一，但百会配风池对于头顶痛和眩晕的即刻效应更佳。艾灸百会为升阳固脱之要法，尤适用于中气下陷证。

#### 2. 风池（Fēngchí，GB 20）——足少阳胆经

| 项目 | 内容 |
|------|------|
| **定位口诀** | "胸锁乳突肌与斜方肌上端之间凹陷处，平风府" |
| **详细定位** | 在颈后区，枕骨之下，胸锁乳突肌上端与斜方肌上端之间的凹陷中 |
| **类属** | 足少阳、阳维之会。祛风要穴 |
| **主治** | ① 头痛、眩晕、颈项强痛 ② 感冒、鼻塞、发热 ③ 目赤肿痛、耳鸣、失眠 |
| **操作** | 针尖微下，向鼻尖方向斜刺0.8-1.2寸。**严禁深刺**（深部为延髓）。可灸 |

> **安全警示**：风池穴深部为椎动脉和延髓，进针时务必控制角度和深度。切勿向上朝枕骨大孔方向深刺，否则可能伤及延髓，危及生命。

#### 3. 太阳（Tàiyáng，EX-HN 5）——经外奇穴

| 项目 | 内容 |
|------|------|
| **定位口诀** | "眉梢与外眼角之间，向后约一横指凹陷处" |
| **详细定位** | 在头部，当眉梢与目外眦之间，向后约1横指的凹陷中 |
| **主治** | ① 偏正头痛 ② 目赤肿痛、目眩 |
| **操作** | 直刺或斜刺0.3-0.5寸；或三棱针点刺出血。可灸 |

> **临床提示**：太阳穴配合谷、太冲（"开四关"）为治疗各种头痛的经典配穴。实证头痛可在太阳穴处用三棱针点刺放血，常获速效。

#### 4. 印堂（Yìntáng，EX-HN 3）——经外奇穴

| 项目 | 内容 |
|------|------|
| **定位口诀** | "两眉头连线，正中间取之" |
| **详细定位** | 在头部，两眉毛内侧端连线的中点 |
| **主治** | ① 头痛、眩晕、失眠 ② 鼻渊、鼻衄 ③ 小儿惊风 |
| **操作** | 提捏局部皮肤，平刺0.3-0.5寸。可灸 |

> **临床经验**：印堂配迎香、合谷治疗鼻炎效果显著。印堂透刺攒竹（沿皮下）是治疗前额头痛和眉棱骨痛的常用手法。

### 23.1.3 胸腹部常用腧穴

#### 5. 膻中（Dànzhōng，CV 17）——任脉

| 项目 | 内容 |
|------|------|
| **定位口诀** | "两乳头连线，胸骨正中间" |
| **详细定位** | 在胸部，横平第4肋间隙，前正中线上。简便取法：两乳头连线的中点（女性因乳房形态差异，宜按骨度分寸定位） |
| **类属** | 八会穴之气会；心包之募穴 |
| **主治** | ① 胸闷、胸痛、心悸 ② 咳嗽、气喘 ③ 呃逆、噎膈 ④ 产后乳少、乳痈 |
| **操作** | 平刺0.3-0.5寸。可灸 |

> **临床提示**：膻中为"气会"，一切气机不畅之证均可选用。膻中配内关（心包经络穴）为宽胸理气的经典组合。

#### 6. 中脘（Zhōngwǎn，CV 12）——任脉

| 项目 | 内容 |
|------|------|
| **定位口诀** | "脐上四寸取中脘，胸骨剑突到脐半" |
| **详细定位** | 在上腹部，脐中直上4寸（胸骨剑突联合与脐中连线的中点） |
| **类属** | 八会穴之腑会；胃之募穴 |
| **主治** | ① 胃痛、腹胀、呕吐、呃逆 ② 泄泻、便秘 ③ 黄疸 ④ 癫狂、失眠 |
| **操作** | 直刺1-1.5寸。可灸 |

> **临床经验**：中脘配足三里为调理脾胃的"黄金搭档"。中脘长于和胃降逆，足三里善于健脾益气，二者一上一下、一募一合，相得益彰。

#### 7. 天枢（Tiānshū，ST 25）——足阳明胃经

| 项目 | 内容 |
|------|------|
| **定位口诀** | "脐旁两寸是天枢" |
| **详细定位** | 在腹部，横平脐中，前正中线旁开2寸 |
| **类属** | 大肠之募穴 |
| **主治** | ① 腹痛、腹胀、便秘、腹泻（双向调节） ② 月经不调、痛经 |
| **操作** | 直刺1-1.5寸。可灸 |

> **临床提示**：天枢为大肠募穴，是治疗肠道疾病的第一要穴。针刺天枢对功能性便秘和腹泻均有效，体现了腧穴的"双向调节"特性。

#### 8. 气海（Qìhǎi，CV 6）——任脉

| 项目 | 内容 |
|------|------|
| **定位口诀** | "脐下一寸半，气聚之海洋" |
| **详细定位** | 在下腹部，脐中直下1.5寸 |
| **类属** | 强壮保健要穴 |
| **主治** | ① 腹痛、泄泻、便秘 ② 遗尿、癃闭 ③ 遗精、阳痿 ④ 月经不调、崩漏 |
| **操作** | 直刺1-1.5寸。宜灸（为保健灸要穴） |

> **养生提示**：气海与关元均为养生保健灸的要穴，常言"春灸气海、秋灸关元"。明代医家张介宾云："气海者，人之元气所生也。"

#### 9. 关元（Guānyuán，CV 4）——任脉

| 项目 | 内容 |
|------|------|
| **定位口诀** | "脐下三寸是关元" |
| **详细定位** | 在下腹部，脐中直下3寸 |
| **类属** | 小肠之募穴；任脉与足三阴经交会穴；强壮保健要穴 |
| **主治** | ① 遗精、阳痿、早泄（男子固精要穴） ② 月经不调、痛经、带下（女子调经要穴） ③ 遗尿、癃闭 ④ 虚劳羸瘦、中风脱证 |
| **操作** | 直刺1-1.5寸。**针刺前排空膀胱**。宜灸 |

> **安全警示**：孕妇慎用（尤其禁针），关元穴深层为子宫，孕期刺激可能引发宫缩。

### 23.1.4 背腰部常用腧穴

#### 10. 大椎（Dàzhuī，GV 14）——督脉

| 项目 | 内容 |
|------|------|
| **定位口诀** | "第七颈椎棘突下，低头隆起最高处" |
| **详细定位** | 在颈后部，第7颈椎棘突下凹陷中，后正中线上。简便取法：正坐低头，颈后最隆起处即为第7颈椎棘突 |
| **类属** | 督脉与手足三阳经交会穴。清热要穴 |
| **主治** | ① 热病、感冒发热（退热要穴） ② 咳嗽、气喘 ③ 项强、脊痛 ④ 癫狂痫 |
| **操作** | 直刺0.5-1寸。可灸；三棱针点刺出血用于退热 |

> **临床提示**：大椎为"诸阳之会"，善于泻热。高热不退者大椎刺络拔罐（先点刺再拔罐），常能使体温快速下降。

#### 11. 肺俞（Fèishū，BL 13）——足太阳膀胱经

| 项目 | 内容 |
|------|------|
| **定位口诀** | "第三胸椎棘突下，旁开一寸半" |
| **详细定位** | 在上背部，第3胸椎棘突下，后正中线旁开1.5寸 |
| **类属** | 肺之背俞穴 |
| **主治** | ① 咳嗽、气喘、咯血 ② 潮热、盗汗 ③ 胸背痛 |
| **操作** | 斜刺0.5-0.8寸（**向脊柱方向斜刺**，切勿直刺过深以免伤及肺脏）。可灸 |

> **安全警示**：背部腧穴（尤其是上背部肺俞、心俞等）针刺深度必须严格控制。直刺过深可穿透胸壁伤及肺组织，导致气胸。正确的操作是朝脊柱方向斜刺。

#### 14. 脾俞（Píshū，BL 20）——足太阳膀胱经

| **操作** | 直刺0.5-1寸。宜灸 |

> **临床经验**：肾俞配委中（四总穴"腰背委中求"）为腰痛经典组合。急性腰扭伤以委中为主，慢性腰肌劳损加灸肾俞。

#### 16. 命门（Mìngmén，GV 4）——督脉

| 项目 | 内容 |
|------|------|
| **定位口诀** | "第二腰椎棘突下，与脐对平" |
| **详细定位** | 在腰部，第2腰椎棘突下凹陷中，后正中线上。与肾俞在同一水平面 |
| **类属** | 补肾壮阳要穴 |
| **主治** | ① 腰脊强痛 ② 阳痿、遗精 ③ 月经不调、带下 ④ 泄泻（五更泄） |
| **操作** | 直刺0.5-1寸。宜灸（尤为艾灸补肾阳之要穴） |

> **临床提示**：命门配肾俞、关元为温补肾阳的经典处方。命门长于补肾阳，肾俞偏于补肾气，关元善于固肾精，三穴合用对肾阳虚所致腰膝酸冷、阳痿早泄等症效果显著。

### 23.1.5 上肢部常用腧穴

#### 17. 合谷（Hégǔ，LI 4）——手阳明大肠经

| 项目 | 内容 |
|------|------|
| **定位口诀** | "一二掌骨间，平第二掌骨中点" |
| **详细定位** | 在手背，第2掌骨桡侧的中点。简便取法：以一手拇指指间关节横纹正对另一手拇指和食指之间的指蹼缘，拇指尖所压处即是 |
| **类属** | 大肠经原穴。"四总穴"之一（面口合谷收） |
| **主治** | ① 头痛、齿痛、面瘫、口眼歪斜（头面五官疾病首选） ② 发热恶寒等外感病症 ③ 闭经、滞产 ④ 上肢不遂、疼痛 |
| **操作** | 直刺0.5-1寸。可灸。**孕妇禁用** |

> **安全警示**：合谷穴有较强的催产作用，孕妇（尤其妊娠后期）严禁针刺。这是针灸临床必须牢记的红线。

#### 18. 曲池（Qūchí，LI 11）——手阳明大肠经

| 项目 | 内容 |
|------|------|
| **定位口诀** | "屈肘成直角，肘横纹外侧端" |
| **详细定位** | 在肘部，尺泽与肱骨外上髁连线的中点。简便取法：屈肘90°，肘横纹外侧端凹陷处 |
| **类属** | 大肠经合穴。清热、降压要穴 |
| **主治** | ① 热病、咽喉肿痛 ② 风疹、荨麻疹（皮肤病要穴） ③ 高血压 ④ 上肢不遂、肘臂疼痛 |
| **操作** | 直刺1-1.5寸。可灸 |

> **临床提示**：曲池配血海（"治风先治血，血行风自灭"）为治疗皮肤瘙痒、荨麻疹的经典配穴。曲池配太冲为平肝降压的常用处方。

#### 19. 内关（Nèiguān，PC 6）——手厥阴心包经

| 项目 | 内容 |
|------|------|
| **定位口诀** | "腕横纹上两寸，两筋之间取" |
| **详细定位** | 在前臂前区，腕掌侧远端横纹上2寸，掌长肌腱与桡侧腕屈肌腱之间 |
| **类属** | 心包经络穴；八脉交会穴（通阴维脉） |

## 23.2 毫针刺法

毫针是针灸临床最常用、最基本的针具。掌握毫针刺法的规范操作，是每一位针灸学习者的基本功。

### 23.2.1 毫针基本知识

**结构**：毫针由针尖、针身、针根、针柄、针尾五部分组成。

**规格**：临床常用毫针长度为 1-3 寸（25-75mm），直径为 0.25-0.35mm（32-28号）。长度和直径的选择取决于腧穴部位和患者体型：
- 头面部、手指足趾 → 短针（1寸）、细针（0.25mm）
- 四肢肌肉丰厚处 → 中长针（1.5-2寸）、中粗针（0.30mm）
- 腰臀部深层腧穴 → 长针（3寸以上）、粗针（0.35mm）

**针具检查**：每次使用前必须检查针具是否完好——针尖有无倒钩、针身有无锈蚀弯曲、针根有无松动。不合格的针具严禁使用。

---

### 23.2.2 进针法

进针是将毫针刺入腧穴皮下的操作，要求快速透皮以减少疼痛。临床常用的进针法有三种：

#### （一）单手进针法

用刺手（持针的手，通常为右手）的拇指、食指捏持针柄，中指指端抵住腧穴旁，针身依靠在中指指腹上。当拇食指向下用力时，中指也随之屈曲将针刺入。适用于短针的进针。

> **要领**：指力是关键。初学者可先在纸垫或棉团上练习指力，做到指实腕虚、力贯针尖。

#### （二）双手进针法（爪切进针法）

左手（押手）拇指或食指指甲切压腧穴皮肤，右手（刺手）持针紧靠指甲缘将针刺入。这是最常用的传统进针方法。

**步骤**：
1. 押手拇指甲切压腧穴，固定皮肤、减轻疼痛
2. 刺手持针，针尖紧贴指甲边缘
3. 快速捻转或直刺透皮

> **为什么用押手？** 押手的作用有四：①固定腧穴，防止皮肤滑移；②减轻进针疼痛（压痛点分散注意力）；③帮助控制进针方向和深度；④感知针下"得气"感。

#### （三）管针进针法

将毫针放入稍短的针管中，针管置于腧穴上，用食指快速叩击针尾使针尖刺入皮下，然后撤去针管。此法进针快、疼痛轻，适合初学者和怕痛的患者。

---

### 23.2.3 行针手法

行针是进针后在腧穴内施行捻转、提插等操作，以达到"得气"和施行补泻的目的。

#### （一）提插法

将针在腧穴内上提下插。插多提少为重插（补），提多插少为重提（泻）。

| 操作要点 | 说明 |
|----------|------|
| 幅度 | 一般 3-5 分（约 1-1.5cm），视腧穴部位调整 |
| 频率 | 一般 60-90 次/分钟 |
| 层次 | 天部（浅层）、人部（中层）、地部（深层） |

#### （二）捻转法

将针在腧穴内左右旋转。拇指向前食指向后为左转，拇指向后食指向前为右转。

| 操作要点 | 说明 |
|----------|------|
| 角度 | 一般 180°-360°，不超过 360°以免肌纤维缠绕 |
| 频率 | 一般 60-90 次/分钟 |

> **常见错误**：初学者常犯的两个错误——①单向捻转超过360°，导致肌纤维缠绕针身，造成滞针；②提插时用力不均匀，针尖晃动损伤组织。

---

### 23.2.4 得气与催气

**得气**（又称"针感"）是针刺操作的核心目标，指针刺入腧穴后产生的经气感应。得气时：
- **医者感觉**：针下沉紧、如鱼吞钩饵之感
- **患者感觉**：酸、麻、胀、重或传导感（沿经脉走向）

> **经典引述**：《灵枢·九针十二原》云："刺之要，气至而有效。"——得气是针刺取效的前提条件。一般而言，得气迅速者疗效较好，得气迟缓者疗效较差。

**催气**：若进针后久久不得气，可采用以下催气手法：
1. **循按法**：用手指沿经脉循行方向轻轻循按、叩击
2. **弹针法**：用手指轻弹针柄，使针体微微震动
3. **雀啄法**：小幅度、快频率地上下提插

---

### 23.2.5 针刺补泻

补泻是毫针刺法的精髓。本节重点介绍临床最常用的几种补泻手法。

| 补泻手法 | 补法 | 泻法 |
|----------|------|------|
| **捻转补泻** | 捻转角度小、用力轻、频率慢（拇指向前左转用力） | 捻转角度大、用力重、频率快（拇指向后右转用力） |
| **提插补泻** | 重插轻提（先浅后深，插多提少） | 重提轻插（先深后浅，提多插少） |
| **徐疾补泻** | 缓慢进针→快速出针 | 快速进针→缓慢出针 |
| **开阖补泻** | 出针时迅速按闭针孔 | 出针时摇大针孔，不按闭 |
| **迎随补泻** | 针尖顺经脉方向刺入 | 针尖逆经脉方向刺入 |

> **理解要点**：补泻手法的核心思想是——补法以"鼓舞正气、纳气入内"为目的，操作偏缓、偏轻、偏合；泻法以"祛除邪气、导气外出"为目的，操作偏急、偏重、偏开。

**补泻的选择原则**：
- 虚证用补法（如脾气虚之腹胀、肾气虚之腰痛）
- 实证用泻法（如肝火上炎之头痛、食积之胃痛）
- 虚实夹杂者，可补泻兼施或平补平泻

---

### 23.2.6 留针与出针

#### 留针

进针得气并施行补泻手法后，将针留置腧穴内一定时间，称为留针。

| 留针时间 | 适用情况 |
|----------|----------|
| 15-30 分钟 | 一般病症的常规留针时间 |
| 10-15 分钟 | 小儿、老人或体质虚弱者 |
| 30-60 分钟 | 顽固性疼痛、痉挛性疾病 |

> **临床提示**：留针期间应每隔 5-10 分钟行针一次，以维持"得气"状态。不可将针留置后不管不问——"针而不行，不如不针"。

#### 出针

出针时一般以押手持无菌干棉球轻压腧穴旁，刺手持针轻微捻转后缓缓提至皮下，然后快速拔出。出针后按压针孔片刻以防出血。

> **注意**：出针后应清点针数，确保不遗留针具在患者体内。这是针灸操作安全管理的铁律。

### 23.2.7 针刺注意事项与意外处理

#### 针刺禁忌与慎用情况

| 情况 | 处理原则 |
|------|----------|
| 过饥、过饱、醉酒、大怒 | 暂不针刺，待恢复正常后施治 |
| 孕妇（尤其妊娠3个月内） | 下腹部、腰骶部腧穴禁针；合谷、三阴交、昆仑等通经活血穴禁用 |
| 小儿囟门未闭 | 头顶部腧穴禁针 |
| 皮肤感染、溃疡、瘢痕 | 禁针该部位 |
| 有出血倾向者 | 慎针或不针 |

#### 常见针刺意外及处理

| 意外 | 表现 | 处理 |
|------|------|------|
| **晕针** | 针刺过程中出现头晕、心慌、冷汗、面色苍白，甚则晕厥 | 立即出针，去枕平卧，松解衣带，饮温糖水或温水。重者指压人中、合谷等 |
| **滞针** | 针在体内捻转不动、提插困难 | 嘱患者放松肌肉，稍延长留针时间，或在其旁再刺一针以缓解局部肌肉痉挛 |
| **弯针** | 针身在体内弯曲 | 顺着弯曲方向缓缓退针，不可强行拔出 |
| **断针** | 针身折断残留体内 | 患者保持不动。若断端露于体外，用镊子夹出；若完全没入皮内，须手术取出 |
| **血肿** | 出针后局部青紫肿胀疼痛 | 小血肿可自行吸收。较大血肿先冷敷止血，24小时后热敷促进消散 |

> **预防胜于处理**：晕针多因患者精神紧张、饥饿疲劳或手法过重所致，提前解释、缓解紧张是预防关键。断针则多因针具质量问题和暴力操作所致，严格检查针具即可避免。

---

## 23.3 灸法

灸法是借灸火的热力给人体以温热刺激，通过经络腧穴达到防治疾病目的的一种外治方法。《灵枢·官能》曰："针所不为，灸之所宜。"——针刺与艾灸各有所长，常配合使用，相得益彰。

### 23.3.1 灸法概述与作用

**灸用材料**：以艾叶制成的艾绒为最常用材料。艾叶性温，味辛苦，归肝脾肾经，具有温经散寒、行气活血、通经止痛的功效。《本草纲目》称："艾叶能灸百病。"

**灸法的主要作用**：

| 作用 | 机理 | 适应症举例 |
|------|------|-----------|
| 温经散寒 | 温热刺激驱散寒邪 | 风寒湿痹、寒性腹痛 |
| 扶阳固脱 | 温补阳气，挽救虚脱 | 阳气虚脱、虚寒泄泻 |
| 消瘀散结 | 温运气血，消散瘀滞 | 乳痈初起、瘰疬 |
| 防病保健 | 激发正气，增强抗病力 | 常灸足三里、关元以养生保健 |

---

### 23.3.2 艾炷灸

艾炷是将艾绒捏成圆锥形小体。每燃烧一个艾炷称为一"壮"。艾炷灸分为直接灸和间接灸。

#### （一）直接灸

将艾炷直接放在腧穴皮肤上施灸。

| 类型 | 操作 | 特点 |
|------|------|------|
| **无瘢痕灸（温和灸）** | 艾炷燃至 2/5 或患者感灼痛时取下，换炷再灸 | 灸后不留瘢痕，适用于一般虚寒证 |
| **瘢痕灸（化脓灸）** | 艾炷燃尽后才取下，以灼伤皮肤产生无菌性化脓 | "若要安，三里常不干"——化脓灸足三里为保健灸法，但须患者知情同意 |

> **临床现状**：瘢痕灸在传统保健灸中应用广泛，但因现代人对美观的要求和感染风险考虑，目前临床已较少使用，多改用无瘢痕灸或艾条温和灸代替。

#### （二）间接灸（隔物灸）

在艾炷与皮肤之间隔垫某种药物进行施灸。

| 灸法 | 隔垫物 | 功效特点 | 适应症 |
|------|--------|----------|--------|
| **隔姜灸** | 生姜片（约0.3cm厚，扎数孔） | 温中散寒、和胃止呕 | 虚寒性腹痛、呕吐、泄泻 |
| **隔蒜灸** | 大蒜片或蒜泥 | 清热解毒、杀虫 | 瘰疬、肺痨、毒虫咬伤 |
| **隔盐灸** | 食盐（填满脐窝） | 回阳救逆 | 虚脱、腹痛、泄泻 |
| **隔附子饼灸** | 附子粉末调制的药饼 | 温补肾阳 | 阳痿、早泄、命门火衰之证 |

> **操作要点**：隔姜灸为最常用的间接灸法。姜片中心扎数个小孔以透热，每穴灸 3-7 壮，至皮肤红润不起泡为度。

---

### 23.3.3 艾条灸

艾条灸是将艾绒卷成圆柱形艾条进行施灸，操作便捷，患者接受度高。

| 灸法 | 操作 | 特点 |
|------|------|------|
| **温和灸** | 艾条点燃端距皮肤 2-3cm，固定不动 | 热力稳定持久，最常用灸法 |
| **雀啄灸** | 艾条一上一下如雀啄食 | 热力间歇刺激，兴奋性强 |
| **回旋灸** | 艾条均匀地左右或回旋移动 | 温热面积大，适用于面积较大的病变 |

> **临床操作**：每穴灸 5-15 分钟，以皮肤温热发红、患者感到舒适为度。灸后皮肤微红属正常反应，次日可自行消退。

---

### 23.3.4 温针灸

温针灸是**针刺与艾灸的结合**——先在腧穴针刺并行针得气后，将艾绒（或艾条小段）裹捏于针柄上点燃，使热力通过针身传入穴位深部。

| 项目 | 说明 |
|------|------|
| 适应症 | 既需针刺又需灸治的寒湿痹痛、虚寒性疾病 |
| 优点 | 针刺直达病所 + 艾灸温经散寒，二效合一 |
| 注意 | 艾绒须裹紧，避免燃灰脱落烫伤皮肤；针柄下垫纸片防护 |

> **经典应用**：膝关节骨性关节炎（中医"膝痹"）——针刺犊鼻、内膝眼、阳陵泉、足三里，并在足三里施温针灸，效果显著。

---

### 23.3.5 其他灸法简介

| 灸法 | 简介 |
|------|------|
| 灯火灸 | 用灯心草蘸植物油点燃后快速触碰腧穴，发出"啪"声。多用于小儿腮腺炎（灯火灸角孙穴） |
| 天灸 | 将刺激性药物（白芥子、蒜泥等）贴敷腧穴使皮肤发泡，用于哮喘（冬病夏治三伏贴）、过敏性鼻炎等 |
| 温灸器灸 | 用温灸盒、温灸筒等工具代替手持，方便在背腰部大面积施灸 |

---

### 23.3.6 灸法注意事项

**施灸顺序**：先灸上部，后灸下部；先灸背部，后灸腹部；先灸头身，后灸四肢。先灸少，后灸多（逐增壮数）。

**禁忌情况**：
- 实热证、阴虚发热者慎灸
- 颜面部、大血管处不宜施瘢痕灸
- 孕妇腹部和腰骶部不宜施灸
- 过饥、过饱、酒醉后不宜灸

**灸后处理**：灸后出现小水泡可待其自行吸收，大水泡需消毒后刺破放出液体并涂抹烫伤膏。嘱患者勿搔抓。

---

## 23.4 拔罐法

拔罐法是以罐为工具，利用燃火、抽气等方法产生负压，使罐吸附于体表，造成局部瘀血或充血，以达到通经活络、行气活血、消肿止痛、祛风散寒等作用的外治法。

### 23.4.1 拔罐法概述

**作用原理**：负压吸引使局部毛细血管扩张甚至破裂，产生"自家溶血"效应，释放组胺、5-羟色胺等物质，刺激机体产生一系列神经-体液调节反应。

**主要功效**：
- 温经通络、祛风散寒（风寒湿痹）
- 行气活血、消肿止痛（软组织扭挫伤）
- 清热解毒（热证配合刺络拔罐）

---

### 23.4.2 罐具种类与拔罐方法

#### 常用罐具

| 类型 | 特点 | 适用场景 |
|------|------|----------|
| 玻璃罐 | 透明可观察罐内皮肤变化，临床最常用 | 各部位均可使用 |
| 竹罐 | 轻便价廉，可用药液煮罐（药罐法） | 四肢关节部位 |
| 抽气罐 | 利用机械抽气产生负压，不用火，安全简便 | 家庭自用、怕火患者 |

#### 拔罐方法

**（一）火罐法**（临床最常用）

| 方法 | 操作 |
|------|------|
| **闪火法** | 用止血钳夹住 95% 酒精棉球，点燃后在罐内绕 1-3 圈后迅速退出，将罐扣在拔罐部位。**最安全常用** |
| **投火法** | 将点燃的酒精棉球或纸片投入罐内，迅速扣罐。**仅适用于侧面横拔**（否则燃物易掉下烫伤皮肤） |

> **安全强调**：①酒精棉球不可蘸酒精过多，以免滴落烫伤；②烧罐时切勿烧及罐口，以免罐口过热烫伤皮肤；③拔罐部位涂抹适量凡士林可保护皮肤并增强吸附力。

**（二）水罐法**

将竹罐放入药液或水中煮沸 2-3 分钟，用镊子取出，甩去水液后迅速扣在拔罐部位。此法兼具热敷和药物作用，适用于风寒湿痹。

**（三）抽气罐法**

将抽气罐置于拔罐部位，用抽气装置抽出罐内空气产生负压。无需用火，安全度高，特别适合家庭使用和儿童患者。

---

### 23.4.3 拔罐方式

| 方式 | 操作 | 特点与适应症 |
|------|------|-------------|
| **留罐（坐罐）** | 罐吸附后留置 5-15 分钟 | 最常用方式，适用于多数病症 |
| **走罐（推罐）** | 在拔罐部位涂润滑剂，罐吸附后握住罐体来回推动 | 适用于面积较大、肌肉丰厚处（如背腰部） |
| **闪罐** | 罐吸附后立即取下，反复多次吸拔 | 用于局部麻木、功能减退；面瘫常用 |
| **刺络拔罐** | 先用三棱针或皮肤针点刺出血，再拔罐 | 加强活血祛瘀功效。适用于急性扭伤、带状疱疹、顽癣等 |

> **临床经典**：大椎穴刺络拔罐治疗风热感冒高热——先以三棱针在大椎穴点刺 3-5 下，再拔火罐留置 5-10 分钟，可拔出暗红色血液数毫升，退热效果迅捷。

---

### 23.4.4 拔罐的适应症与注意事项

**适应症**：
- 风寒湿痹（颈肩腰腿痛）
- 软组织扭挫伤
- 感冒、咳嗽（拔大椎、肺俞）
- 面瘫（闪罐法）
- 带状疱疹、荨麻疹等皮肤病

**注意事项**：
| 项目 | 说明 |
|------|------|
| 禁忌部位 | 皮肤溃疡、水肿、大血管处；孕妇腰骶部和腹部 |
| 留罐时间 | 一般 5-15 分钟。时间过长易起水泡 |
| 起罐方法 | 一手握罐体，另一手按压罐口边缘皮肤使空气进入，**不可强行拉扯** |
| 拔罐后护理 | 拔罐后 3-4 小时内不宜洗澡；罐印属正常反应，数日后可自行消退 |

> **安全提示**：起罐时不可用力猛拉——罐内负压使罐紧紧吸附于皮肤，强行拉扯会造成皮肤撕脱伤。正确做法是按压罐口边缘皮肤，让空气从缝隙进入以解除负压。

---

## 23.5 推拿基本手法

推拿（又称"按摩"）是以中医理论为指导，运用手法作用于人体体表特定部位，以调节机体生理病理状态的外治法。推拿与针灸在理论基础（经络腧穴）和辨证体系上完全相通，在治疗手段上互补——针灸以针具灸火作用于经穴，推拿以手法作用于经筋皮部。

### 23.5.1 推拿概述与作用原理

**推拿的作用**：

| 层面 | 作用 |
|------|------|
| **疏通经络** | 手法刺激经络腧穴，调畅气血运行 |
| **行气活血** | 促进局部血液循环，改善组织营养 |
| **理筋整复** | 松解粘连、整复关节错位 |
| **调整脏腑** | 通过皮部-经络-脏腑的反射作用调节内脏功能 |

**推拿手法操作的基本要求**：

> **持久、有力、均匀、柔和**——八字箴言。其中"柔和"最见功力，所谓"刚中有柔、柔中有刚、刚柔相济"。

**介质**：为减少摩擦、保护皮肤，常使用推拿介质（滑石粉、按摩乳、冬青油等）。

**适应症与禁忌**：
- 适应症：软组织损伤、颈椎病、腰椎间盘突出、肩周炎、头痛失眠、小儿食积等
- 禁忌：皮肤破损感染、骨折脱位、严重骨质疏松、出血倾向者；孕妇腹部及腰骶部慎用

---

### 23.5.2 摆动类手法

#### （一）一指禅推法

以拇指指端或螺纹面着力，通过前臂摆动带动拇指在治疗部位做节律性按压推动。

| 项目 | 说明 |
|------|------|
| 着力部位 | 拇指指端、螺纹面或偏锋（拇指桡侧） |
| 频率 | 120-160 次/分钟 |
| 特点 | 接触面积小、渗透力强、"力透溪谷" |
| 适用 | 全身各部位腧穴，尤适用于头面、胸腹 |

> **手法要领**："沉肩、垂肘、悬腕、掌虚、指实"。腕关节要放松，摆动灵活自如，不可僵硬。

#### （二）㨰法

以手背小指侧部分（小鱼际和手背尺侧）附着于治疗部位，通过前臂旋转和腕关节屈伸的复合运动，使手背来回滚动。

| 项目 | 说明 |
|------|------|
| 着力部位 | 手背尺侧（第5掌指关节背侧至尺骨茎突） |
| 频率 | 120-160 次/分钟 |
| 特点 | 接触面积大、压力均匀、舒适安全 |
| 适用 | 颈肩、背腰、四肢等肌肉丰厚处 |

> **手法要领**：肩臂放松，肘关节微屈（约120°）。滚动时手背的着力面要紧贴治疗部位皮肤，避免跳跃和摩擦。

#### （三）揉法

以手指螺纹面、手掌大鱼际或掌根着力，在治疗部位做轻柔缓和的环旋揉动，带动皮下组织一起运动。

| 类型 | 着力部位 | 适用 |
|------|----------|------|
| 指揉法 | 拇指或食中指螺纹面 | 头面部腧穴和小范围 |
| 鱼际揉法 | 大鱼际 | 头面、颈项、四肢 |
| 掌根揉法 | 掌根部 | 腰背部、臀部 |

> **与摩法的区别**：揉法带动皮下组织一起运动，摩法只摩擦皮肤表面。所谓"揉动皮下，摩摩皮上"。

---

### 23.5.3 摩擦类手法

#### （一）摩法

以手掌面或食中无名指指面贴附于治疗部位，做环形有节律的抚摩。

| 项目 | 说明 |
|------|------|
| 频率 | 100-120 次/分钟 |
| 特点 | 最轻柔的手法之一 |
| 适用 | 胸腹、胁肋部 |

> **补泻区分**：顺时针摩为泻（通便），逆时针摩为补（止泻）。

#### （二）擦法

以手掌面、大鱼际或小鱼际贴附于体表，做直线往返摩擦，使局部产生温热感。

| 类型 | 着力部位 | 适用 |
|------|----------|------|
| 掌擦法 | 全手掌 | 胸腹、腰背部大面积 |
| 鱼际擦法 | 大鱼际 | 四肢 |
| 小鱼际擦法（侧擦法） | 小鱼际 | 腰骶部、脊柱两侧（擦膀胱经） |

> **技术要点**：①必须直线往返，不可歪斜；②压力适中，以摩擦生热为目的；③一个部位擦至发热即可停止（约1-3分钟），不要反复过度摩擦损伤皮肤。

#### （三）推法

以指、掌或肘着力于治疗部位，做单向直线推动。

| 类型 | 着力部位 | 适用 |
|------|----------|------|
| 指推法 | 拇指螺纹面 | 头面、手足小范围 |
| 掌推法 | 掌根 | 背腰、四肢 |
| 肘推法 | 肘尖（鹰嘴） | 腰臀部深层肌肉 |

> **与擦法的区别**：推法是单向缓慢推进，力量较深层；擦法是往返快速摩擦，以生热为目的。

#### （四）搓法

双手掌面对称夹持肢体，相对用力做快速搓揉，同时上下往返移动。

| 项目 | 说明 |
|------|------|
| 适用部位 | 上肢、下肢 |
| 特点 | 松解肌肉、调和气血 |
| 操作要领 | 搓动要快，上下移动要慢 |

---

### 23.5.4 挤压类手法

#### （一）按法

以指、掌或肘逐渐用力深压治疗部位，按而留之。

| 类型 | 着力部位 | 适用 |
|------|----------|------|
| 指按法 | 拇指指端或螺纹面 | 全身腧穴 |
| 掌按法 | 全掌或掌根 | 背腰部 |
| 肘按法 | 肘尖（鹰嘴） | 腰臀部深层肌肉丰厚处 |

> **技术要点**：按法要"由轻到重、逐渐深压"，不可突然暴力。刺激性较强，结束后应配合轻柔的揉法以缓解不适。

#### （二）点法

以指端或关节突起部着力于点状刺激腧穴。

| 类型 | 着力部位 |
|------|----------|
| 拇指点法 | 拇指指端 |
| 屈指点法 | 屈指时指间关节突起部 |

> **点法与按法的区别**：点法接触面积更小、刺激性更强、作用更集中，"以指代针"即指此法。

#### （三）捏法

以拇指与其他手指对称用力，夹持并提捏肌肤。

| 项目 | 说明 |
|------|------|
| 适用部位 | 颈项、肩背、四肢 |
| 变式 | 三指捏（拇+食中指）、五指捏 |
| 临床 | 小儿捏脊——沿脊柱从下向上捏提肌肤，调节脏腑功能 |

#### （四）拿法

以拇指与其余四指相对用力，提捏并揉捏肌肤或肌腱。

| 项目 | 说明 |
|------|------|
| 适用部位 | 颈项、肩井、四肢肌肉丰厚处 |
| 操作 | "捏而提之谓之拿"——提起后稍停再放松 |

> **拿肩井**：为推拿结束时的经典收式手法——患者坐位，医者以双手拿捏患者两侧肩井穴部位，持续1-2分钟。有放松全身、调畅气血之功。

---

### 23.5.5 振动类手法

#### （一）抖法

双手握住患者肢体远端，做连续小幅度的上下抖动。

| 项目 | 说明 |
|------|------|
| 适用部位 | 四肢（上肢/下肢） |
| 操作要领 | 被抖肢体自然伸直放松，抖动幅度小、频率快 |
| 临床作用 | 松解关节粘连、放松肌肉 |

#### （二）振法

以掌或指附着于治疗部位，前臂和手部肌肉强力静止收缩，产生快速振颤。

| 项目 | 说明 |
|------|------|
| 频率 | 每分钟 400-600 次 |
| 适用 | 胸腹、头面 |

> **功力要求**：振法对操作者的功力和体能要求较高，需长期练习方能持久。

---

### 23.5.6 叩击类手法

#### （一）拍法

五指并拢，掌指关节微屈，用虚掌平稳而有节奏地拍打治疗部位。

| 项目 | 说明 |
|------|------|
| 适用部位 | 肩背、腰骶、四肢 |
| 操作 | 腕关节放松，以腕力带动手掌拍打 |
| 声音 | 发"啪啪"清脆声，不应为沉闷的"扑扑"声（后者说明手掌未成虚掌） |

#### （二）击法

| 类型 | 着力部位 | 适用 |
|------|----------|------|
| 拳击法 | 握拳，以小指侧小鱼际着力 | 腰背部 |
| 掌击法 | 手指自然伸开，以掌根部着力 | 腰臀部 |
| 指尖击法 | 五指指端 | 头面部 |
| 桑枝棒击法 | 特制桑枝棒 | 四肢、肩背 |

---

### 23.5.7 运动关节类手法

#### （一）摇法

一手固定关节近端，另一手握持远端，做被动的环形转动。

| 部位 | 操作 |
|------|------|
| 颈项摇法 | 一手扶后枕部，一手托下颌，做缓慢环转 |
| 肩关节摇法 | 一手扶肩部，一手握腕部做环转（大摇法） |
| 腕关节摇法 | 握持手掌做环转 |
| 腰部摇法 | 患者仰卧屈髋屈膝，医者握其双踝做腰部环转 |

> **注意事项**：摇动幅度由小到大，须在生理活动范围内进行。颈椎摇法尤其要缓慢柔和，切忌暴力，以免引起眩晕或损伤。

#### （二）扳法

双手沿相反方向或同一方向用力，使关节做短暂、快速的被动伸展或旋转，以整复关节错位、松解粘连。

| 部位 | 操作简述 |
|------|----------|
| 颈椎斜扳法 | 患者头前屈至适当角度，医者一手托下颌、一手扶后枕，快速扳动（常可闻及"咔嗒"弹响声） |
| 胸椎扳法 | 患者双手交叉抱于后枕，医者以膝顶住胸椎，双手向后扳双肩 |
| 腰椎斜扳法 | 患者侧卧位，医者一手推肩、一手推臀，反向用力扳动 |

> **安全警示**：扳法是技术要求最高、风险最大的推拿手法。操作不当可能导致颈椎损伤、椎动脉夹层等严重并发症。学习者必须在教师指导下反复练习，严禁自学后盲目施术。

#### （三）拔伸法

沿肢体纵轴方向施加拉力，使关节间隙增宽。

| 部位 | 操作 |
|------|------|
| 颈椎拔伸法 | 一手托下颌、一手托后枕，向上缓缓牵拉 |
| 肩关节拔伸法 | 一手扶肩、一手握腕，向下牵引 |
| 手指拔伸法 | 握持指端向远端牵拉 |

> **技术要点**：拔伸力量要持续、均匀、缓慢，切忌突然猛拉。

---

### 23.5.8 推拿手法治则

**操作顺序**：一般遵循"由轻到重、由表及里、自上而下、从前到后"的原则。

**补泻原则**：
- 轻手法为补，重手法为泻
- 缓摩为补，急摩为泻
- 逆时针为补，顺时针为泻
- 顺经络方向为补，逆经络方向为泻

**常见推拿流程**（以颈肩部为例）：
```
放松类手法（㨰法、揉法）→ 松解类手法（拿法、弹拨）→ 
整复类手法（摇法、扳法）→ 整理类手法（搓法、抖法、拍法）
```

## 23.6 常见误区与注意事项汇总

### 误区一："所有头痛都可以扎合谷"

**纠正**：合谷确实是治疗头面五官疾病的要穴（"面口合谷收"），但并非所有头痛都首选合谷。辨证不同，取穴各异：
- 前额头痛（阳明经）→ 合谷、印堂
- 偏头痛（少阳经）→ 外关、风池、太阳
- 头顶痛（厥阴经）→ 太冲、百会
- 后头痛（太阳经）→ 后溪、风池

### 误区二："针扎得越深越好"

**纠正**：针刺深度须依腧穴部位、患者体型、病情需要而定，绝非越深越好。
- 风池深部为延髓，深刺可致命
- 肺俞直刺过深可伤及肺脏导致气胸
- 正确的深度应根据腧穴解剖结构精确控制

### 误区三："补泻手法太复杂，随便捻转就行了"

**纠正**：补泻是针刺起效的核心机制。《灵枢》有云"补泻反则病益笃"——该补反泻、该泻反补，不仅无效，还可能加重病情。初学阶段至少应掌握捻转补泻和提插补泻两种基本手法。

### 误区四："艾灸就是离得远远地烤一烤"

**纠正**：艾灸要达到温热穿透的"灸感"——温热感向腧穴深部或沿经脉方向传导。距离太远只有表面温度，不能发挥艾灸的温通效应。理想距离为 2-3cm，以患者感到温热舒适、局部皮肤红润为度。

### 误区五："拔罐后罐印越紫越好，说明湿气重"

**纠正**：罐印颜色受多种因素影响——留罐时间、负压大小、个人体质等。罐印深紫并不简单等同于"湿气重"。留罐时间过长导致的水泡反而是一种不必要的皮肤损伤。一般留罐 5-15 分钟即可，以罐印淡红至红紫为度。

### 误区六："推拿力气越大越有效"

**纠正**：推拿讲究"持久、有力、均匀、柔和"，其中"柔和"是关键。患者感到疼痛难忍的手法属于暴力推拿，不仅无效，还可能造成软组织损伤。真正好的手法是——患者感到酸、胀、舒适，推拿后一身轻松。

## 练习

### 一、基础题（5题）

1. 简述腧穴的三种定位方法，并各举一例说明。

2. 列出"四总穴歌"中四个腧穴的名称及其主治概括（如"面口合谷收"），并说明其归经。

3. 毫针进针时使用"押手"的作用有哪些？（至少列出三点）

4. 比较温和灸、雀啄灸和回旋灸的操作异同。

5. 推拿手法操作的"八字箴言"是什么？为什么说"柔和"最见功力？

### 二、综合题（3题）

1. **案例分析**：患者男性，30岁，昨日因搬运重物后突然腰部剧痛，活动受限，不能弯腰。查体：腰椎两侧肌肉紧张痉挛，无下肢放射痛。请回答：
   - （1）从辨证角度，该患者属于实证还是虚证？
   - （2）列出你最可能选择的 3 个针灸腧穴，并说明选取理由。
   - （3）除针刺外，你还可能配合使用什么其他外治法？简述操作。

2. **配穴分析**：针对"脾胃虚寒型胃痛"（胃脘隐痛、喜温喜按、食少便溏），请设计一个针灸处方（3-5个腧穴），说明每个腧穴的选取依据和针刺/灸法选择（补或泻、是否加灸）。

3. **手法辨析**：推拿手法中，按法、点法和拿法同属挤压类手法，请分析三者之间的异同点（着力部位、作用深度、适用部位、注意事项）。

### 三、拓展题（2题）

1. **临床思维**：一位颈椎病患者同时存在两种看似矛盾的症状——颈项肌肉紧张痉挛（实证表现），但患者整体体质偏弱、畏寒肢冷（阳虚表现）。请问在针灸治疗中，你如何把握"补"与"泻"的平衡？取穴和手法上可以有哪些考量？

2. **跨学科思考**：现代康复医学中有"物理治疗"（Physical Therapy），其手法（如关节松动术、软组织松解术）与传统推拿手法在操作和理念上有哪些异同？请结合本章学到的推拿分类，至少从两个维度进行比较分析。
