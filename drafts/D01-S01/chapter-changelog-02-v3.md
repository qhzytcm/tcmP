## 逐项修改说明

### S1. 《内经》引文出处补齐 + "善补阳者"出处修正

**S1a 补齐 7 处具体篇章**（原仅标注"《黄帝内经》说"）：

| 引文 | 篇章 |
|------|------|
| "阴胜则阳病，阳胜则阴病" | 《素问·阴阳应象大论》 |
| "阴在内，阳之守也；阳在外，阴之使也" | 《素问·阴阳应象大论》 |
| "重阴必阳，重阳必阴" | 《素问·阴阳应象大论》 |
| "寒极生热，热极生寒" | 《素问·阴阳应象大论》 |
| "阴平阳秘，精神乃治" | 《素问·生气通天论》 |
| "善诊者，察色按脉，先别阴阳" | 《素问·阴阳应象大论》 |
| "谨察阴阳所在而调之，以平为期" | 《素问·至真要大论》 |

**S1b "善补阳者/善补阴者"出处修正**：原句紧邻《内经》引文却未标出处，易误读为《内经》原文。现明确标注为"明代医家张景岳在此基础上提出……（张景岳《景岳全书·新方八略·补略》）"，并与《内经》引文严格区分。§2.5 案例三临床要点第 3 条中"善补阴者"一处同步标注"张景岳所谓"。

**同步修正自检清单 1.4 条**：由"共引用 8 段原文，均标注具体篇章"改为"共引用《内经》原文 8 段（均已标注具体篇章）+ 张景岳《景岳全书》1 处（另标出处，非《内经》原文）"。

### M1. "盛/胜"用字统一

正文辨证术语统一用"盛"（"阳盛则热""阴盛则寒""阳虚则寒""阴虚则热"）；仅直接引用《内经》原文处保留"胜"并加括注"（胜，通"盛"）"（§2.3.1"阴胜则阳病"、§2.4.3 偏盛表经典表述列），并在 §2.4.3 偏盛表后新增"用字说明"块，一次性说明"胜"为《内经》原文用字、义同"盛"。

### M2. 自检清单评分卡口径

删除"加权得分"列（原 39×0.4=15.6 等二次加权，合计 27.5 无意义），改为"权重 + 满分 + 自评分"三列，并加说明"各维度满分已内置权重（40+25+20+15=100），总分 = 四维度自评分直接相加 = 96/100"。

### M3. 习题比例校准

新增拓展题 28《开放探究——阴阳平衡与当代健康观》，习题总数 27→28 题：基础 20（约 71%）+ 综合 5（约 18%）+ 拓展 3（约 11%）。拓展题占比由 7% 补足至 11%（≥10%）。同步校准习题集标题、三大题量标题与自检清单 3.5 条、DoD 条目 3 的比例表述。

### M4. 习题第 25 题病案重写

原病案"恶寒重发热轻→阴盛"（实为太阳伤寒表证）与"大汗后疲乏气短→阳虚"（跳过气随津脱病机）辨证链条牵强。现重写为清晰的里证转化链条：寒邪直中（阴盛实寒）→ 寒邪久郁化热（阳盛实热）→ 清热峻剂伤阳（阳虚虚寒），并明确各环节病机。

### M5. 案例三"黄连阿胶汤合六味地黄丸"名实相符

- 补"鸡子黄 2 枚冲服"——《伤寒论》黄连阿胶汤原方滋阴安神之要药，此前缺失。
- 方解注明六味地黄丸取舍：取生地黄、山茱萸、茯苓滋肾阴之要义；以生地黄易熟地黄（清热养阴更宜阴虚火旺）；去山药、泽泻、牡丹皮（防滋腻或渗利伤阴）。

### O1–O6. 优化建议落实

- O1：章首新增"前置章节（第1章 中医药学导论）/后续章节（第3章 五行学说）/建议学时（4学时）"三行元信息，与第 3 章体例一致。
- O2：新增开篇"情境导入"（盛夏运动后忽冷忽热场景），降低零基础读者代入门槛。
- O3：情境导入末段回指第 1 章"整体观念"，形成"承上启下"。注：第 1 章尚未产出，此过渡语为前向兼容，待第 1 章定稿后需终校衔接一致性。
- O4：§2.3.1 首次出现体温处注明"成人腋下正常体温约 36–37°C"；习题第 22 题同步标注。
- O5：§2.2.1 属性表"方位"行拆分为"空间方位（上下内外）/相对方位（左右）/地理方位（南北）"三行。
- O6：案例四"面色晄白"两处改为规范用字"面色㿠白"。
