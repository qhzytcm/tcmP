## 图2-1：阴阳的最初字义——山南水北

**位置**：§2.1.1 "阴阳从何而来" 段落后

**类型**：示意图

**描述**：
一座山丘的简笔画剖面图，左（南）面为阳光照射的向阳坡，标注"阳"；右（北）面为阴影覆盖的背阴坡，标注"阴"。山脚下一条小河，河北岸（阳面）标注"阳"，河南岸（阴面）标注"阴"。

**关键标注**：
- 太阳在左侧上方
- 向阳面：阳光直射、草木茂盛 → 标注"阳：向日"
- 背阴面：阴影覆盖、草木稀疏 → 标注"阴：背日"
- 河水流经山脚，标示"山南水北为阳，山北水南为阴"

**教学目的**：帮助学生从直观经验建立阴阳的最初概念，理解阴阳不是抽象"玄学"而是源于对自然现象的观察。

## 图2-2：阴阳属性对照表（双栏图）

**位置**：§2.2.1 "阴阳属性划分标准" 表格之后

**类型**：双栏对照图（或信息图表）

**描述**：
双栏对比图。左栏（阳）用暖色（橙/红）背景：向上箭头、太阳、火焰、奔跑的人、展开的扇面；右栏（阴）用冷色（蓝/灰）背景：向下箭头、月亮、水滴、静坐的人、闭合的伞。

**关键标注**：
- 左栏：上、外、热、明、动、兴奋、功能、发散 → 共用一个"阳"标签
- 右栏：下、内、寒、暗、静、抑制、物质、凝聚 → 共用一个"阴"标签
- 底部标注：加粗标准定义句

**教学目的**：将分散在文字中的对照关系压缩为一张视觉化的一览表，方便学生快速回忆和对比。

## 图2-3：阴阳无限可分——以"昼夜"为例

**位置**：§2.2.2 阴阳属性的相对性 "以昼夜为例" 段落下

**类型**：树状层次图

**描述**：
从上到下的层级展开图。第一层（一日24小时）→ 第二层（昼/夜）→ 第三层（上午/下午/前半夜/后半夜）。每层用不同深浅的颜色区分——阳系用暖色渐深，阴系用冷色渐深。

**关键标注**：
- 昼（06:00-18:00）→ 阳（暖黄色背景）
  - 上午（06:00-12:00，阳气上升）→ 阳中之阳（深橙色）
  - 下午（12:00-18:00，阳气渐衰）→ 阳中之阴（浅黄色）
- 夜（18:00-06:00）→ 阴（冷蓝色背景）
  - 前半夜（18:00-00:00，阴气渐盛）→ 阴中之阴（深蓝色）
  - 后半夜（00:00-06:00，阳气萌动）→ 阴中之阳（浅蓝色）

**教学目的**：用具体的数字（时间段）化解"无限可分"的抽象性，让学生看到阴阳划分是一个可操作的层次化分析方法。

## 图2-4：阴阳四对相互关系·速览图

**位置**：§2.3.5 "四种关系小结" 表格之后

**类型**：四象限概念图

**描述**：
一个2×2网格，四格分别对应四种关系：

| 对立制约 | 互根互用 |
|---------|---------|
| 两个相反箭头 ← → | 太极阴阳鱼（黑白互抱） |
| "制衡" | "依存" |
| 相互转化 | 消长平衡 |
| 一个箭头从阳转到阴 | 波浪曲线（此消彼长） |
| "质变" | "动态平衡" |

**关键标注**：
- 每一格内有一个简单的图形符号 + 一个关键词 + 一句短描述
- 顶部标题："阴阳的四种关系——同一个整体系统的四个观察角度"
- 下方总结句："对立制约是结构关系 → 互根互用是依存关系 → 消长平衡是运动状态 → 相互转化是变化结果"

**教学目的**：把分散在2.3.1-2.3.4四节中的四种关系整合为一张互相关联的总图，帮助学生建立整体理解。

## 图2-5：人体阴阳划分示意图

**位置**：§2.4.1 "人体阴阳划分示意图" 代码块处（替代原ascii图）

**类型**：人体正面+背面轮廓示意图

**描述**：
一个简易的人体轮廓图（正面），用不同颜色标注阴阳分部：
- 上半身（头至腰）→ 暖色（阳）
- 下半身（腰至脚）→ 冷色（阴）
- 背部（后视图小图）→ 暖色（阳）
- 腹部（正视图）→ 冷色（阴）
- 四肢外侧 → 暖色（阳），四肢内侧 → 冷色（阴）
- 体表 → 暖色虚线框（阳）
- 体内脏腑 → 冷色虚线框（阴）

**关键标注**：
- 每个区域旁边标注对应的阴阳属性
- 左下角图例：暖色=阳、冷色=阴
- 右下角标注："阴阳之中复有阴阳——五脏属阴，但五脏各自又可再分心阴心阳、肝阴肝阳等"

**教学目的**：将"说明人体的组织结构"一节中的分散描述集成到一张人体图上，让学生一目了然地看到阴阳在人体的总体分布。

## 图2-6：阴阳失调的四大基本类型

**位置**：§2.4.3 "一张图理解阴阳失调" 代码块处（替代原ascii图）

**类型**：四象限流程图/决策树

**描述**：
以平衡线（中线）为基准的上下偏离示意图：

- 第一层分支：分为"偏盛（实证）"和"偏衰（虚证）"
- 第二层分支：偏盛 → 阳盛则热（热证）/ 阴盛则寒（寒证）
- 第二层分支：偏衰 → 阳虚则寒（虚寒证）/ 阴虚则热（虚热证）

每个分支配小图标：
- ① 发热、面红（阳盛则热）→ 红色箭头向上
- ② 畏寒、肢冷（阴盛则寒）→ 蓝色箭头向下
- ③ 虚寒、乏力（阳虚则寒）→ 蓝色箭头略低
- ④ 潮热、盗汗（阴虚则热）→ 红色箭头略高（虚火）

下方配两个大字标注："实则泻之"（实者祛邪）、"虚则补之"（虚者扶正）。

**教学目的**：用统一的"偏离平衡线"模型澄清四种失调类型，帮助学生辨析"盛"（邪气有余→实证）与"衰"（正气不足→虚证）的本质区别。

## 图2-8：四类阴阳失调的临床鉴别流程图

**位置**：§2.5.5 "四个案例的阴阳分析对照总表" 之后

**类型**：流程决策图

**描述**：
自上而下的临床决策流程图，帮助学生掌握四类阴阳失调的鉴别诊断思路。

```
                 临床证候（恶寒/发热/疼痛等）
                          │
                    先辨虚实
                    /        \
               实证         虚证
              （邪气盛）    （正气虚）
              /    \        /    \
         阳盛则热  阴盛则寒  阴虚则热  阳虚则寒
         （实热）  （实寒）  （虚热）  （虚寒）
           │        │        │        │
        清热泻火  散寒温阳  滋阴降火  温阳散寒
```

**关键标注**：
- 每个分支节点标注鉴别要点
- 实证与虚证的鉴别框：起病急缓（实证急、虚证缓）、病程长短（实证短、虚证长）、体质强弱（实证壮、虚证弱）
- 底部标注：**鉴别黄金法则：实证——邪气有余当泻；虚证——正气不足当补**

**教学目的**：为§2.5的四个案例提供可操作的分析框架，让学生面对实际患者时知道从何入手。同时作为整章知识应用于临床的"桥梁图"。

## 图2-9：病证单位——双栏对照分析模板

**位置**：§2.5 章节开篇（作为本节导读图）

**类型**：版式/模板说明图

**描述**：
展示§2.5中每个病证单位使用的标准双栏对照版式：

```
┌──────────────────────────┬──────────────────────────┐
│      病 侧               │      证 侧               │
│ （Disease Aspect）       │ （Syndrome Aspect）      │
├──────────────────────────┼──────────────────────────┤
│ 临床表现（四诊资料）：   │ 阴阳属性归类：           │
│  望诊所见                │  从温度/运动/明暗/功能   │
│  闻诊所得                │  等维度分析              │
│  问诊详述                │                          │
│  切诊（舌脉）            │ 辨证结论：               │
│                          │  阳盛/阴盛/阴虚/阳虚     │
│                          │                          │
│ 治疗：                   │ 理论分析：               │
│  治法                   │  阴阳理论在临床的        │
│  方药                   │  具体应用                │
│  疗效                   │                          │
├──────────────────────────┼──────────────────────────┤
│  临床要点提示（预后/转归/注意事项）                  │
└──────────────────────────┴──────────────────────────┘
```

**关键标注**：
- 左栏用冷色（阴色调），右栏用暖色（阳色调）——视觉上呼应阴阳主题
- 左右栏之间标注"←→阴阳辨证分析"连接箭头
- 底部横跨两栏的"临床要点提示"用灰色背景

**教学目的**：让学生熟悉"病侧 + 证侧"双栏分析的阅读和使用方法，培养"从症状到证候"的中医临床思维。
