## 16.1 中药与中药学

### 16.1.1 什么是中药

**中药**，是指在中医理论指导下，用于预防、治疗、诊断疾病并具有康复与保健作用的物质。三个关键词缺一不可：

- **"中医理论指导"**——脱离中医理论，麻黄只是一把干草，石膏只是一块石头。只有在中医理论框架下，麻黄才具有"辛温解表、宣肺平喘"的功效。
- **"预防、治疗、诊断"**——中药不仅用来治病（治疗），也用来防病（"治未病"），还可用于诊断（如巴豆作泻下诊断用药）。
- **"物质"**——包括植物药、动物药、矿物药及加工品，以植物药为主体，故历代本草著作多称"本草"。

中药与"天然药物"是两个有交集但不重合的概念：

```
         ┌─────────────────────────┐
         │      天然药物           │
         │  ┌───────────────┐      │
         │  │    中药       │      │
         │  │ (中医理论指导)│      │
         │  └───────────────┘      │
         │                         │
         └─────────────────────────┘
```

凡在中医理论指导下使用的天然药物即为中药；天然药物中不按中医理论使用的部分则不属于中药。

### 16.1.2 什么是中药学

**中药学**，是研究中药基本理论和各种中药的来源、采制、性能、功效、临床应用等知识的一门学科，是中医学的重要组成部分。

中医学完整的"理-法-方-药"体系中，中药学处于"药"这个环节：

```
理（辨证）──→ 法（治则治法）──→ 方（方剂）──→ 药（中药）
   │                │                │              │
 第14章            第15章           第18-19章      第16-17章
```

### 16.1.3 中药学的发展脉络

中药学的知识体系经历了数千年的积累。以下是几个关键节点，帮助读者建立历史感：

| 时期 | 代表著作 | 里程碑意义 |
|------|---------|-----------|
| 东汉 | 《神农本草经》 | 现存最早的本草专著，载药365种，首创三品分类，奠定药性理论基础 |
| 南朝 | 《本草经集注》（陶弘景） | 载药730种，首创按药物自然属性分类 |
| 唐 | 《新修本草》（官修） | 世界上第一部药典，载药844种 |
| 宋 | 《证类本草》（唐慎微） | 载药1746种，保存了大量宋代以前的本草文献 |
| 明 | 《本草纲目》（李时珍） | 载药1892种，集16世纪以前本草学之大成，被达尔文称为"中国古代百科全书" |

## 16.2 四气

### 16.2.1 四气的概念

**四气**，又称**四性**，指药物具有的寒、热、温、凉四种不同的药性。它反映药物对人体阴阳盛衰、寒热变化的作用倾向。

从阴阳角度看：

```
        阳（热）                      阴（寒）
  热 ────── 温 ────── 平 ────── 凉 ────── 寒
  大热    微温     不偏     微寒    大寒
  ←─────────── 热性增强 ───│─── 寒性增强 ─────→
```

四气中，温与热属阳，寒与凉属阴。温次于热，凉次于寒。此外，还有一类药性平和、寒热偏性不显著的药物，称为**平性**药。但平性药并非绝对没有偏性，只是偏性较弱，故历来仍称"四气"而不称"五气"。

> **要点**：四气是从药物作用于人体后所产生的反应中概括出来的，与药物本身的温度无关。石膏摸上去是凉的，但其药性的"大寒"不是靠触觉，而是因它能清解阳明气分大热。

### 16.2.2 四气的确定依据

四气不是主观赋予的，而是通过长期临床观察总结出来的。判断依据有两方面：

**（1）药物作用于人体的反应**

- 能减轻或消除**热证**的药物 → 寒凉药（如石膏治高热烦渴，知母治潮热盗汗）
- 能减轻或消除**寒证**的药物 → 温热药（如附子治四肢厥冷，干姜治脘腹冷痛）

**（2）药物本身的特性**

某些药物生长于寒凉环境（如黄连生于高山阴湿处），或味苦、质地重坠者，多偏寒凉；生长于温热环境（如附子喜阳），或味辛、气芳香者，多偏温热。但这些仅为辅助判断，最终依据仍是临床效应。

### 16.2.3 四气的临床意义

《素问·至真要大论》提出："寒者热之，热者寒之。"这就是四气运用的总原则。

| 病证性质 | 用药原则 | 举例 |
|---------|---------|------|
| 热证（阳盛或阴虚） | "热者寒之"——用寒凉药 | 高热用石膏、知母；疮痈红肿用黄连、金银花 |
| 寒证（阴盛或阳虚） | "寒者热之"——用温热药 | 胃寒腹痛用干姜、高良姜；肾阳虚用附子、肉桂 |
| 寒热错杂 | 寒热并用 | 半夏泻心汤中黄连与干姜同用 |
| 真寒假热 | 热因热用（反佐法） | 里寒外热之戴阳证，用温热药回阳救逆 |

> **常见误区**：并非所有热证都只能用寒凉药。阴虚发热（虚热）需用甘寒养阴药（如麦冬、生地黄），而非苦寒直折。

### 16.2.4 四气的现代研究

现代药理学研究发现，寒凉药与温热药在以下方面存在系统性差异：

| 指标 | 寒凉药 | 温热药 |
|------|--------|--------|
| 对中枢神经系统 | 抑制（镇静、抗惊厥） | 兴奋（提高中枢兴奋性） |
| 对交感-肾上腺系统 | 降低儿茶酚胺水平 | 升高儿茶酚胺水平 |
| 对能量代谢 | 降低耗氧量、抑制Na⁺-K⁺-ATP酶 | 增加耗氧量、促进能量代谢 |
| 代表药物举例 | 黄连、黄芩、栀子 | 附子、肉桂、干姜 |

> 这些研究为四气理论提供了现代科学依据，但也提醒我们：四气是一个系统性的功能归类，不能简单地等同于某单一指标的变化。

## 16.3 五味

### 16.3.1 五味的概念

**五味**，指药物具有的辛、甘、酸、苦、咸五种基本味道。五味的最初确定依据是口尝的真实味觉，但后世逐渐演变为对药物功效的高度概括——即"功能味"，不完全等同于口感。

> **核心认知**：五味的实质是"味-效对应关系"，不是味觉描述。山茱萸口感酸涩，它的"酸味"主要指向其收敛固涩的功效；葛根口感微甜，但它的"辛味"指向的是发散表邪的功效。

### 16.3.2 五味与功效的对应关系

结合五行学说和长期临床实践，五味各有其对应的功效方向：

| 味 | 五行 | 阴阳 | 作用特点 | 功效方向 | 代表药物 |
|:--:|:---:|:---:|------|----------|---------|
| **辛** | 金 | 阳 | 能散、能行 | 发散表邪、行气、活血 | 麻黄（发散）、木香（行气）、川芎（活血） |
| **甘** | 土 | 阳 | 能补、能缓、能和 | 补益、缓急止痛、调和药性 | 人参（补气）、甘草（缓急、调和） |
| **酸** | 木 | 阴 | 能收、能涩 | 收敛固涩 | 五味子（敛肺）、山茱萸（固精） |
| **苦** | 火 | 阴 | 能泄、能燥、能坚 | 清热泻火、降泄肺胃之气、燥湿、坚阴 | 黄连（清热燥湿）、大黄（泻下）、杏仁（降气） |
| **咸** | 水 | 阴 | 能下、能软 | 泻下通便、软坚散结 | 芒硝（泻下）、牡蛎（软坚散结） |

此外，还有两种"附加味"：

- **淡**：能渗、能利，即利水渗湿（如茯苓、泽泻）。淡附于甘，常合称"甘淡"。
- **涩**：能收、能涩，与酸味功用相似（如龙骨、赤石脂）。涩附于酸，常合称"酸涩"。

> **记忆方法**：将五味想象成五只手，各司其职——辛推开大门、甘补充粮草、酸收紧口袋、苦清理垃圾、咸软化硬结。

### 16.3.3 五味与脏腑经络的关系

五味入五脏（五行配属），这是归经理论的雏形：

```
辛入肺（金）──→ 解表药多归肺经（如麻黄、薄荷）
甘入脾（土）──→ 补气药多归脾经（如黄芪、党参）
酸入肝（木）──→ 收敛药多归肝经（如白芍、山茱萸）
苦入心（火）──→ 清热泻火药多归心经（如黄连、栀子）
咸入肾（水）──→ 补肾药中咸味者多归肾经（如龟板、鹿茸）
```

但须注意：五味入五脏只是大致规律，不可绝对化。一味药常兼有数味（如当归甘、辛、温），具体归经还需结合药物的实际功效来判定。

### 16.3.4 四气与五味的结合

气与味是同一药物不可分割的两个方面。只有将两者结合起来，才能较完整地描述一味药的性能：

| 药物 | 性味 | 功效解读 |
|------|:----:|---------|
| 麻黄 | 辛、微苦，温 | 辛温发散风寒 + 微苦降泄肺气以平喘 |
| 黄连 | 苦，寒 | 苦能燥湿泄火 + 寒能清热，故善清中焦湿热 |
| 人参 | 甘、微苦，微温 | 甘温补气为主 + 微苦有降泄生津之功 |
| 大黄 | 苦，寒 | 苦寒沉降，泄热通便，为阳明腑实证要药 |
| 附子 | 辛、甘，大热 | 辛甘大热，纯阳之品，回阳救逆第一要药 |

> 理解药性要诀：**"气"决定该药是"冷兵器还是热兵器"，"味"决定该武器用来"刺、砍、砸还是缠"。两者不可偏废。**

## 16.4 升降浮沉

### 16.4.1 升降浮沉的概念

**升降浮沉**，指药物在人体内作用的四种不同趋向：

- **升**——上升提举，趋向于上（病势下陷者举之）
- **降**——下降平逆，趋向于下（病势上逆者降之）
- **浮**——向外发散，趋向于表（病在表者散之）
- **沉**——向内收敛或泄利，趋向于里（病在里者泄之）

升与浮、沉与降，作用趋向类似，常并称。升浮药上行向外，属阳；沉降药下行向内，属阴。

```
                    升 (向上)
                     ↑
            ┌────────┼────────┐
            │  升浮药        │
    浮      │  (属阳)        │
  (向外) ←─┼─ 麻黄 升麻 ───┼→  (向内)  沉
            │  柴胡 薄荷     │
            │                │
            │  沉降药        │
            │  (属阴)        │
            │  大黄 代赭石   │
            │  龙骨 牡蛎     │
            └────────┼────────┘
                     ↓
                    降 (向下)
```

### 16.4.2 升降浮沉的临床意义

药物升降浮沉的作用趋向，与疾病的病势趋向相对应：

| 病势趋向 | 治疗方法 | 用药趋向 | 举例 |
|---------|----------|---------|------|
| 向上：咳嗽、气喘、呕吐、呃逆 | 降逆 | 沉降药 | 杏仁降肺气、代赭石降胃气 |
| 向下：久泻、脱肛、子宫下垂、崩漏 | 升举 | 升浮药 | 升麻升阳举陷、黄芪补气升提 |
| 向外：自汗、盗汗、遗精 | 收敛 | 沉降（向内） | 五味子敛汗、煅龙骨收涩 |
| 向内：表邪不解、麻疹不透 | 发散 | 升浮（向外） | 麻黄发散风寒、薄荷疏散风热 |

"逆病势而用药"是升降浮沉理论的核心——病势向下的用升提药，病势向上的用沉降药。

### 16.4.3 影响升降浮沉的因素

升降浮沉不是药物的固定属性，受以下因素影响：

**（1）气味厚薄**（最根本的决定因素）

| 气味属性 | 趋向 | 说明 |
|---------|:---:|------|
| 气厚（味薄） | 升浮 | 辛甘温热之品：如附子气厚则大热升散 |
| 味厚（气薄） | 沉降 | 酸苦咸寒之品：如大黄味厚则苦寒泄下 |

**（2）药物质地**

| 质地 | 一般趋向 | 例外 |
|------|:---:|------|
| 花、叶、皮、枝等质轻者 | 升浮 | 旋覆花，花却沉降；沉香，木而降 |
| 种子、果实、矿物、贝壳等质重者 | 沉降 | 蔓荆子，子却升浮；苍耳子，果实而升 |

> **关键原则**：药物质地只能作为升降浮沉的参考，不可作为绝对标准。必须以药物的实际功效为最终依据。

**（3）炮制的影响**

炮制可以改变药物的升降浮沉趋向（详见16.9节）。简言之：
- **酒制**则升（如酒大黄由沉降变升浮，善清上焦血分热）
- **姜制**则散（如姜半夏增强降逆止呕之性）
- **醋制**则收敛（如醋柴胡增强疏肝止痛之力）
- **盐制**则下行（如盐黄柏引药入肾）

**（4）配伍的影响**

在复方中，一味药的升降浮沉趋向可被方中其他药改变：
- 大队升浮药中配少量沉降药 → 沉降药被牵制，随大队而升浮
- 大队沉降药中配少量升浮药 → 升浮药被牵制，随大队而沉降

如：桔梗本身升浮，配伍大黄等大队沉降药时，其升浮之性被制约。

## 16.5 归经

### 16.5.1 归经的概念

**归经**，指药物对于人体某部分（脏腑、经络）具有选择性作用，即药物的作用部位定位。

归经理论回答了一个关键问题：一味药吃下去后，主要"去哪里"发挥作用？

> **类比理解**：如果把人体比作一座城市，每味药就是一辆配送车。四气五味告诉你这车装的什么货（寒热属性 + 功效方向），归经则告诉你这车往哪个区送——有的专送"心肺区"（如丹参归心、肝经），有的专送"肝胆区"（如茵陈归肝、胆、脾、胃经）。

### 16.5.2 归经的确定依据

归经不是凭空想象的，其确定有以下依据：

**（1）以脏腑经络理论为基础**

经络是沟通人体内外的通道，药物的选择性作用常通过经络来实现。例如：
- 白芷善治前额头痛 → 阳明经循行于前额 → 白芷归阳明经（胃、大肠经）
- 羌活善治后头痛 → 太阳经循行于后头 → 羌活归太阳经（膀胱经）
- 柴胡善治两侧头痛 → 少阳经循行于头侧 → 柴胡归少阳经（胆、三焦经）

**（2）以药物所治病证的脏腑归属为依据**

某药能治某脏腑的病证，即认为该药归该脏腑的经络。例如：
- 酸枣仁能安神，治心悸失眠 → 归心、肝经（心主神明，肝藏魂）
- 麻黄能宣肺平喘，治咳喘 → 归肺经
- 大黄能泻下通便，治阳明腑实 → 归大肠、胃经

**（3）五行配属关系为补充**

结合五味入五脏的规律作为辅助判断（见16.3.3）。

### 16.5.3 归经的表述方式

一味药可以归多条经，按主次排列：

```
黄连：归心、脾、胃、肝、胆、大肠经
      ↑
    主归心经（苦入心，善清心火）
    其余各经为次要归经
```

### 16.5.4 归经的临床意义

**（1）提高用药的精确性**

同是清热药，性味相同（苦寒），但归经不同则用途迥异：

| 药物 | 性味 | 归经 | 主治 |
|------|:---:|------|------|
| 黄芩 | 苦寒 | 肺经 | 清肺热（肺热咳嗽） |
| 黄连 | 苦寒 | 心、胃经 | 清心火、清胃热（心烦、口疮、胃热呕吐） |
| 黄柏 | 苦寒 | 肾、膀胱经 | 清下焦湿热（淋证、带下） |

> 三黄均为苦寒清热药，性味相同，归经不同，犹如三把同样的灭火器，分别布置在不同楼层——"药有个性之专长"。

**（2）引经报使**

某些药物不仅自身归某经，还能引导其他药物进入特定经络，称为**引经药**。如：

| 引经药 | 引向经络 | 应用举例 |
|--------|---------|---------|
| 桔梗 | 能"载药上行"，引药入肺 | 血府逐瘀汤中用桔梗，引活血药上行 |
| 牛膝 | 引药下行，引血下行 | 镇肝熄风汤中用牛膝引血下行 |
| 柴胡 | 引药入少阳经 | 小柴胡汤中柴胡为君，引药入少阳 |
| 升麻 | 引药入阳明经 | 补中益气汤中用升麻引清气上行 |

> 掌握归经，才能实现"哪病靶向哪"的精准用药。这不仅是中医的理论追求，也与现代"靶向给药"理念暗合。

## 16.6 毒性

### 16.6.1 "毒"的双重含义

在中医药学中，"毒"的含义经历了历史演变：

**（1）古代广义之"毒"——药物的偏性**

《周礼》曰："医师掌医之政令，聚毒药以供医事。"此处的"毒"指药物的偏性。古人认为，药物之所以能治病，正是因其具有某种偏性，以偏纠偏。这种意义下，凡药皆有毒。

**（2）古代狭义之"毒"——药物的毒副作用**

《神农本草经》将药物分为上、中、下三品：

| 品级 | 特点 | 毒性描述 | 举例 |
|:---:|------|---------|------|
| 上品 | 无毒，可久服，主养命 | "多服久服不伤人" | 人参、甘草、枸杞 |
| 中品 | 有毒或无毒，斟酌其宜，主养性 | "无毒有毒，斟酌其宜" | 麻黄、当归、芍药 |
| 下品 | 多毒，不可久服，主治病 | "多毒，不可久服" | 附子、乌头、巴豆 |

**（3）现代之"毒"——药物的不良反应**

现代中药学中，毒性指药物对机体产生的损害性作用，包括急性毒性、慢性毒性、特殊毒性（致癌、致畸、致突变等）。

### 16.6.2 毒性分级

根据现代药理毒理学研究，《中华人民共和国药典》将有毒中药分为三级：

| 分级 | 标记 | 含义 | 代表药物 |
|:---:|:---:|------|---------|
| 有大毒 | 【毒】 | 毒性剧烈，治疗量与中毒量接近，须严格控制 | 砒石、巴豆、马钱子 |
| 有毒 | 【毒】 | 毒性较强，用量较大时可致中毒 | 附子、半夏、天南星 |
| 有小毒 | 【毒】 | 毒性较小，较大剂量或长期使用可出现毒性 | 杏仁、白果、细辛 |

### 16.6.3 中毒原因与防治

**常见中毒原因：**

1. 剂量过大（如附子超过安全剂量）
2. 炮制不当（如生半夏未经炮制内服）
3. 配伍失宜（违反十八反、十九畏）
4. 煎煮不当（如乌头类须先煎久煎以减毒）
5. 误服误用（品种混淆，如关木通混作川木通）
6. 体质差异（过敏体质、孕妇、儿童等特殊人群）

**防治原则：**

- 严格掌握用药剂量，尤其是"有毒"药物不可超量
- 规范炮制，该炮制减毒的不可省略
- 注意配伍禁忌
- 特殊人群（孕妇、老人、儿童）慎用或禁用
- 密切观察用药反应，一旦出现中毒症状立即停药并积极救治

> **核心理念**："以毒攻毒"并非中医用药的常态，而是在权衡利弊后的审慎选择。大多数情况下，中医追求的是"以平为期"——用偏性较小的药物调整人体的失衡状态。

## 16.7 配伍

### 16.7.1 配伍的概念与意义

**配伍**，指根据病情的需要和药物的性能，有选择地将两味或两味以上的药物配合应用。

单味药力量有限，复杂病证往往需要多味药协同作战。配伍的目的在于：
- 增强疗效（增效）
- 降低毒性或副作用（减毒）
- 适应复杂病情（多靶点）
- 扩大治疗范围

### 16.7.2 七情配伍

《神农本草经》将药物之间的相互作用归纳为七种关系，称为**七情**：

| 序号 | 配伍关系 | 含义 | 配伍效果 | 举例 |
|:---:|---------|------|:---:|------|
| 1 | **单行** | 单味药治病，不配伍他药 | — | 独参汤单用人参补气固脱 |
| 2 | **相须** | 性能功效相似的药物同用，增强疗效 | 增效 ✚ | 麻黄 + 桂枝 → 增强发汗解表之效 |
| 3 | **相使** | 一主一辅，辅药提高主药疗效 | 增效 ✚ | 黄芪 + 茯苓 → 茯苓助黄芪补气利水 |
| 4 | **相畏** | 一药的毒性被另一药减轻或消除 | 减毒 ▾ | 半夏畏生姜 → 生姜能解半夏之毒 |
| 5 | **相杀** | 一药能减轻或消除另一药的毒性 | 减毒 ▾ | 生姜杀半夏之毒（与相畏是一体两面） |
| 6 | **相恶** | 一药使另一药功效降低或丧失 | 减效 ▾ | 人参恶莱菔子 → 莱菔子削弱人参补气 |
| 7 | **相反** | 两药同用产生剧烈的毒副作用 | 增毒 ✘ | 甘草反甘遂 → 合用毒性大增 |

**配伍效果总结：**

```
          增效                    减毒                    避忌
     ┌─────┴─────┐          ┌─────┴─────┐          ┌─────┴─────┐
    相须    相使          相畏    相杀           相恶    相反
  (最佳配伍) (良配)    (安全配伍) (安全配伍)   (不宜同用)(严禁同用)
```

> **记忆口诀**："单行独立战，相须同类加，相使主辅配，相畏毒性压，相杀能解毒，相恶效变差，相反禁同用，七情记心匣。"

### 16.7.3 君臣佐使

君臣佐使是方剂组成的基本原则（详见第18章方剂学基础），此处简要介绍其与中药配伍的关系：

| 角色 | 定义 | 作用 | 举例（麻黄汤） |
|:---:|------|------|-------------|
| **君药** | 针对主病或主证起主要治疗作用的药物 | 药力居首 | 麻黄（辛温发汗解表，宣肺平喘） |
| **臣药** | 辅助君药加强治疗作用，或针对兼病兼证 | 辅助君药 | 桂枝（助麻黄发汗解表） |
| **佐药** | 佐助（协助君臣）、佐制（制约毒性/烈性）、反佐 | 辅助 + 制约 | 杏仁（降肺气，助平喘） |
| **使药** | 引经（引导药力达病所）、调和诸药 | 引经 + 调和 | 甘草（调和诸药，缓和峻烈） |

## 16.8 用药禁忌

### 16.8.1 配伍禁忌——十八反

**十八反**，指药物配伍后会产生剧烈毒副作用或降低药效的十八种（实际不止十八种）药物，属配伍中的"相反"关系，临床原则上禁止同用。

**十八反歌诀**（金元·张子和《儒门事亲》）：

> 本草明言十八反，半蒌贝蔹及攻乌。
> 藻戟遂芫俱战草，诸参辛芍叛藜芦。

逐句解析：

| 原文 | 现代解读 | 反药组 |
|------|---------|--------|
| 半蒌贝蔹及攻乌 | 半夏、瓜蒌、贝母、白蔹、白及——反乌头（川乌、草乌、附子） | 乌头组 |
| 藻戟遂芫俱战草 | 海藻、大戟、甘遂、芫花——反甘草 | 甘草组 |
| 诸参辛芍叛藜芦 | 人参、沙参、丹参、玄参、苦参、细辛、芍药——反藜芦 | 藜芦组 |

**列表形式便于查询：**

| 主药 | 反药 | 
|------|------|
| 乌头（川乌、草乌、附子） | 半夏、瓜蒌（全瓜蒌、瓜蒌皮、瓜蒌仁、天花粉）、贝母（川贝母、浙贝母）、白蔹、白及 |
| 甘草 | 海藻、大戟、甘遂、芫花 |
| 藜芦 | 人参、沙参、丹参、玄参、苦参、细辛、赤芍、白芍 |

> **重要提示**：
> 1. 十八反不是绝对禁忌——历代不乏"反药同用"成功案例（如《金匮要略》甘遂半夏汤中甘遂与甘草同用），但**初学者严禁尝试**，须在有经验的临床中医师指导下使用。
> 2. 某些反药组合在现代药理研究中确有增毒证据（如乌头类与半夏合用增加心脏毒性），不可轻视。

### 16.8.2 配伍禁忌——十九畏

**十九畏**，指十九种药物之间存在相畏关系，配伍后一种药物被另一种药物抑制或降低功效，甚至产生毒副作用。

> **注意**："十九畏"之"畏"含义不同于七情配伍中的"相畏"（毒性被制 = 好的配伍）。此处"畏"指"配伍禁忌"之意，同用会出问题。

**十九畏歌诀**（明·刘纯《医经小学》）：

> 硫黄原是火中精，朴硝一见便相争。
> 水银莫与砒霜见，狼毒最怕密陀僧。
> 巴豆性烈最为上，偏与牵牛不顺情。
> 丁香莫与郁金见，牙硝难合荆三棱。
> 川乌草乌不顺犀，人参最怕五灵脂。
> 官桂善能调冷气，若逢石脂便相欺。

**列表形式便于查询：**

| 药物A | 畏 | 药物B |
|-------|:--:|------|
| 硫黄 | 畏 | 朴硝（芒硝） |
| 水银 | 畏 | 砒霜 |
| 狼毒 | 畏 | 密陀僧 |
| 巴豆 | 畏 | 牵牛子 |
| 丁香 | 畏 | 郁金 |
| 牙硝（芒硝） | 畏 | 荆三棱 |
| 川乌、草乌 | 畏 | 犀角（现用水牛角代） |
| 人参 | 畏 | 五灵脂 |
| 官桂（肉桂） | 畏 | 赤石脂 |

> **识记技巧**：十九畏歌诀全篇押韵（"精/争"、"僧"、"情"、"棱"、"脂/欺"），建议背熟。临床上这是必查项，开方后需要逐一核对。

### 16.8.3 十八反与十九畏的关系辨析

| 比较维度 | 十八反 | 十九畏 |
|---------|--------|--------|
| 原始出处 | 《神农本草经》七情"相反" | 历代经验积累，刘纯整理 |
| 配伍关系 | 相反（增毒） | 相制（降效/增毒） |
| 可否使用 | 原则上不宜同用 | 原则上不宜同用 |
| 现代证据 | 部分有药理学证实 | 部分有药理学证实 |
| 歌诀 | "半蒌贝蔹及攻乌…" | "硫黄原是火中精…" |

> 总原则：十八反、十九畏均为配伍禁忌，临床开方时应严格回避。学术讨论上的"反药相激成奇效"只适合在深厚经验与严密监控下进行，不适合一般临床实践。

### 16.8.4 妊娠用药禁忌

妊娠期用药须格外审慎，按危害程度分为禁用药和慎用药：

**（1）禁用药**（妊娠期间绝对禁止使用）

多为毒性较强或药性峻猛的药物：

| 类别 | 代表药物 | 原因 |
|------|---------|------|
| 毒性药 | 巴豆、斑蝥、马钱子、砒石 | 毒性伤胎 |
| 峻下逐水药 | 芫花、甘遂、大戟、商陆 | 峻泻动胎 |
| 破血逐瘀药 | 水蛭、虻虫、三棱、莪术 | 活血堕胎 |
| 走窜开窍药 | 麝香、冰片 | 走窜动胎 |

**（2）慎用药**（妊娠期间谨慎使用，必要时可在严密观察下使用）

多为活血、行气、攻下、温里等药性较偏的药物：

| 类别 | 代表药物 | 注意事项 |
|------|---------|---------|
| 活血化瘀药 | 桃仁、红花、牛膝 | 需用时可小量、配伍安胎药 |
| 攻下药 | 大黄、芒硝 | 孕妇便秘忌用攻下，宜润下（如火麻仁） |
| 温里药 | 附子、肉桂 | 非必要不用，用量宜小 |
| 行气药 | 枳实、木香 | 需用时注意剂量 |

> **口诀**："妊娠用药须谨慎，峻烈有毒均当避；活血破瘀峻下药，通经走窜亦须忌。桃红牛膝附肉桂，大黄芒硝勿轻试。"

### 16.8.5 服药禁忌（忌口）

服药期间对某些食物的禁忌，俗称**忌口**：

| 禁忌类型 | 禁忌食物 | 原因 |
|---------|---------|------|
| 一般服药 | 生冷、黏腻、腥臭等不易消化及刺激性食物 | 影响药物吸收 |
| 热性病服寒药 | 辛辣、油腻、煎炸 | 助热碍药 |
| 寒性病服热药 | 生冷瓜果 | 增寒碍药 |
| 皮肤病、疮疡 | 鱼虾蟹等发物 | 助邪发疹 |
| 服人参/补气药 | 萝卜（莱菔子） | 萝卜消气，削弱补气之效 |
| 服何首乌/地黄 | 葱、蒜 | 影响药效 |

## 16.9 炮制

### 16.9.1 什么是炮制

**炮制**（又称炮炙、修治），是根据中医药理论，按照辨证用药的需要和药物自身性质，以及调剂、制剂的不同要求，对中药材进行加工处理的技术。

> 一句话总结：**炮制 = 给中药做"预处理"，使其更适合临床使用。**

### 16.9.2 炮制的目的

| 目的 | 说明 | 典型示例 |
|------|------|---------|
| **减毒** | 降低或消除药物的毒性、烈性或副作用 | 生半夏→姜半夏（生姜制，减毒性）；生附子→制附子（炮制减毒） |
| **增效** | 增强药物疗效 | 蜜炙款冬花→增强润肺止咳之效 |
| **改性** | 改变药物性能，使其更适合病情 | 生地黄（甘寒，清热凉血）→熟地黄（甘温，补血滋阴） |
| **改性味** | 改变或缓和药性 | 生大黄（苦寒峻下）→酒大黄（缓和泻下，引药上行）|
| **定向** | 改变药物作用趋向（升降浮沉） | 生柴胡（升散）→醋柴胡（增强疏肝止痛之功） |
| **纯净** | 除去杂质和非药用部位 | 去芦头（人参去芦）、去皮（肉桂去粗皮） |
| **矫味** | 矫臭矫味，便于服用 | 酒制乌梢蛇（去腥除臭） |
| **便用** | 便于调剂和制剂 | 矿物药煅后易于粉碎（如煅石膏） |

### 16.9.3 常用炮制方法

按操作方法分类：

**一、修治**（初步加工）

| 方法 | 操作 | 适用 |
|------|------|------|
| 净制 | 挑拣、筛选、风选、水选去除杂质 | 所有药材的基础加工 |
| 切制 | 将药材切成片、段、丝、块 | 便于煎出有效成分和调配 |

**二、水制**

| 方法 | 操作 | 目的/示例 |
|------|------|----------|
| 漂 | 流水反复漂洗 | 海藻漂去盐分 |
| 泡 | 清水浸泡 | 槟榔浸泡软化便于切片 |
| 润 | 少量水浸润，内外湿度一致 | 当归润透后切片完整不碎 |
| 水飞 | 研细粉加水搅拌，取混悬液干燥 | 朱砂研为极细粉 |

**三、火制**

| 方法 | 操作 | 典型应用 |
|------|------|---------|
| **炒** | 清炒（不加辅料）或加辅料炒 | 清炒：炒黄→焦→炭（如焦山楂消食导滞、炮姜炭止血）；麸炒白术增强健脾之效 |
| **炙** | 加液体辅料拌炒 | 蜜炙（润肺）、酒炙（活血/升提）、醋炙（入肝/止痛）、盐炙（入肾）、姜炙（止呕） |
| **煅** | 直接或间接高温加热 | 煅石膏（制粉外用）、煅牡蛎（收涩制酸） |
| **煨** | 面裹或纸裹加热 | 煨肉豆蔻（增强温中止泻之效） |
| **炮** | 武火急炒至发泡鼓起 | 炮姜（由干姜炮制） |

**四、水火共制**

| 方法 | 操作 | 典型应用 |
|------|------|---------|
| **蒸** | 隔水加热 | 何首乌经黑豆汁蒸制后由生品通便转为制首乌补肝肾 |
| **煮** | 与水或辅料共煮 | 川乌经水煮以降低毒性 |
| **燀** | 沸水短时间浸煮 | 燀杏仁（破坏酶活性，保留有效成分杏仁苷） |
| **淬** | 烧红后迅速投入液体辅料中 | 醋淬自然铜（增强散瘀止痛之效，易于粉碎） |

### 16.9.4 炮制对药性的影响总结

炮制是改变药物性能的重要手段，常言"制药如练兵"：

| 辅料 | 作用 | 代表药物变化 |
|:---:|------|------------|
| 酒制 | 提升、活血、上行 | 大黄（酒制上行清上焦血分热）、黄连（酒制清上焦） |
| 醋制 | 入肝、止痛、收敛 | 柴胡（醋制增强疏肝止痛）、元胡（醋制增强止痛） |
| 盐制 | 入肾、下行 | 黄柏（盐制引药入肾）、杜仲（盐制增强补肾之效） |
| 蜜制 | 润肺、补中、娇味 | 款冬花（蜜制增强润肺止咳）、黄芪（蜜制增强补中） |
| 姜制 | 止呕、发散 | 半夏（姜制增强降逆止呕、减去毒性） |
| 炒炭 | 止血 | 地榆（地榆炭止血更佳）、艾叶（艾叶炭温经止血） |

> **设计意图说明**：此处对炮制的介绍侧重其"改变药性"的功能，而非详细的工艺操作规范。工艺细节将是D02-S08（中药炮制学）的专属内容。本章只需让读者建立"炮制不是简单洗切，而是深度改造药性"的基本认知。

## 16.10 剂量与特殊用法

### 16.10.1 剂量

**剂量的概念**：指每一味药的成人一日量，也指方剂中各药的相对用量比例。

**确定剂量的依据**：

| 因素 | 规律 | 举例 |
|------|------|------|
| 药物性质 | 无毒者量大，有毒者量小；质轻者量小，质重者量大 | 灯心草1-3g，石膏15-60g |
| 配伍与剂型 | 单味药用量大，复方药用量小；汤剂用量大，丸散用量小 | 人参独用15-30g，复方中3-9g |
| 病情 | 重病用量重，轻病用量轻 | 急症高热石膏可用至120g |
| 体质 | 壮实者量大，老幼体弱者量小 | 一般成人量，老人酌减1/3-1/2 |
| 季节地域 | 温热季节/南方，解表药量宜小 | 麻黄在北方冬春季可用10g，南方夏季用3-6g |

### 16.10.2 特殊煎服法

| 类型 | 方法 | 适用药物 |
|------|------|---------|
| **先煎** | 打碎先煎15-30分钟 | 矿物、贝壳类（石膏、龙骨、牡蛎）；毒性药（附子、乌头先煎减毒） |
| **后下** | 其他药将煎好前5-10分钟放入 | 含挥发油的芳香药（薄荷、砂仁、豆蔻） |
| **包煎** | 用纱布包裹再煎 | 粉末状（滑石粉）、带绒毛（旋覆花）、细小种子（车前子） |
| **另煎** | 单独煎煮取汁后兑入 | 贵重药（人参、西洋参、羚羊角） |
| **烊化** | 加少量开水或药液溶化后兑入 | 胶类药（阿胶、鹿角胶、龟板胶） |
| **冲服** | 研粉后用温水或药液冲服 | 贵重细粉（三七粉、麝香、牛黄） |

### 核心要义

1. **四气五味的阴阳支撑**：四气（寒凉属阴，温热属阳）和五味（辛甘为阳，酸苦咸为阴）的底层逻辑是阴阳学说。理解这一点，药性就不是死记硬背，而是有章可循。

2. **归经使药性"落地"**：四气五味描述了药物的"能量属性"，归经则指定了"作用靶点"。三者结合，构成了药物性能的完整描述框架。

3. **升降浮沉是对病势的呼应**：药物升降浮沉的趋向针对的是疾病的趋向——逆病势而用药。理解这一点需要回顾第10章（病机）中关于病势的内容。

4. **配伍是安全有效的保障**：单味药力薄且有偏性，配伍既要"增效"（相须、相使），又要"减毒"（相畏、相杀），更要"避害"（慎忌相反、相恶）。

5. **炮制药同材异**：同一药材经不同方法炮制后，药性可有天壤之别（如生地与熟地、生大黄与酒大黄），这是中药学最具特色的部分之一。

6. **十八反十九畏是必须遵守的红线**：初学中药，先守规矩方能不犯错。熟记歌诀，开方必查。

> **衔接提示**：带着本章的药性理论知识，进入下一章（第17章 常用中药），将逐一学习各类中药的具体性能、功效和应用。你会发现，每一味药的学习路径正是"性味→归经→功效→主治→用法→禁忌"，与本章的学习框架完全对应。

### 综合题（每题10分，共30分）

6. **综合分析题**：麻黄性味辛、微苦，温；归肺、膀胱经；具有发汗解表、宣肺平喘、利水消肿的功效。请运用本章所学药性理论（四气、五味、归经、升降浮沉），分析麻黄的每一项功效与其药性之间的内在联系。
   > 答题提示：辛→发散解表；温→散寒；苦→降泄平喘；归肺经→作用于肺；升浮→向外发散。

7. **配伍分析题**：阅读以下方剂，回答后续问题。
   > 麻黄汤组成：麻黄9g、桂枝6g、杏仁9g、甘草3g
   > 
   > （1）请运用君臣佐使理论分析该方中各药的角色。
   > （2）麻黄与桂枝的配伍属于七情配伍中的哪一种关系？为什么？
   > （3）该方中有无违反十八反或十九畏之处？请逐一核验。

8. **炮制应用题**：生地黄性味甘、寒，功能清热凉血、养阴生津。经黄酒蒸制后成为熟地黄，性味变为甘、微温，功能变为补血滋阴、益精填髓。请分析：
   > （1）炮制使地黄的药性发生了哪些变化（四气、五味、升降浮沉、功效）？
   > （2）这种变化对临床应用有何影响？什么情况下用生地黄，什么情况下用熟地黄？
