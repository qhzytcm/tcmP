## 情境导入

> 小李牙痛得厉害，半边脸都肿了起来。他捂着腮帮子去看中医。医生在他脚背上扎了一针——小李还没来得及喊疼，就感觉一股酸麻胀的感觉从脚背直窜到牙龈，不到五分钟，牙痛就明显减轻了。
>
> 小李低头盯着自己的脚，百思不得其解："大夫，我明明是牙痛，您怎么在脚上扎针？脚离牙这么远，它们之间有什么关系？"
>
> 医生笑着解释道："我刚才扎的是'内庭穴'，它属于足阳明胃经。足阳明胃经的循行路线，从面部经过牙龈，一直延伸到脚背——所以脚上的这个穴位，可以通过经络这条'高速公路'，把治疗信号快速传递到牙齿和面部。"
>
> 小李还是不太明白："那为什么偏偏是胃经？牙痛跟胃有什么关系？"
>
> 医生答道："好问题！足阳明胃经的循行路线恰好经过上牙龈，而手阳明大肠经经过下牙龈。中医讲'经络所过，主治所及'——经络走到哪里，就能治疗哪里的病。你这是胃火上炎引起的牙痛，所以取胃经的穴位，清胃火、止牙痛。"
>
> 点滴药力通过一条看不见的"线路"，从脚背传到面部——这就是经络的威力。而本章的内容，正是要告诉你：人体内这张看不见却真实存在的"交通网络"，到底长什么样？十二经脉各自怎么走？它们之间又是如何相互衔接、周流不息的？

**导读**：如果说藏象学说告诉你每个脏腑"是干什么的"，那么经络学说就要告诉你：这些脏腑之间、脏腑与体表之间，是如何通过一张遍布全身的"网络"连接起来的。本章聚焦经络系统的核心——十二经脉，从命名规律、循行路线、表里关系、流注次序四个维度全面展开，为第8章的奇经八脉和腧穴学习打下坚实基础。

## 第一节 经络系统概说

### 一、什么是经络？

"经络"二字拆开理解："经"是路径，"络"是网络。经络就是人体内运行气血、联络脏腑、沟通内外、贯穿上下的**通道系统**。

> **生动类比**：如果把人体比作一座城市，脏腑就是城市中的各个功能区（工厂、商场、住宅区），气血就是城市运转所需的能量（水、电、信息），而经络就是这座城市的地下管网系统——经脉是主干管网（地铁线路），络脉是毛细血管般的分支管道（入户管线），穴位则是管网上的各个接口和阀门。

| 概念 | 字义 | 功能 | 比喻 |
|------|------|------|------|
| **经** | 路径，纵行的主干 | 贯通上下，沟通脏腑与体表 | 地铁主干线 |
| **络** | 网络，横斜的分支 | 纵横交错，遍布全身 | 毛细血管网 |

### 二、经络系统的组成

经络系统是一个层级分明、分工协作的整体网络，主要包括三大部分：

```
经络系统
├── 经脉（主干通道）
│   ├── 十二经脉（十二正经）—— 核心，本章重点
│   ├── 奇经八脉 —— 第8章重点
│   └── 十二经别 —— 第8章介绍
├── 络脉（分支网络）
│   ├── 十五络脉
│   ├── 孙络（最细小的分支）
│   └── 浮络（浮现于体表的络脉）
└── 连属部分（附属结构）
    ├── 十二经筋 —— 筋肉系统
    └── 十二皮部 —— 皮肤分区
```

> **本章定位**：十二经脉是整个经络系统的核心骨架。先学十二经脉，再学奇经八脉（第8章），就如同先建好城市的主干道，再修建环城高速、辅路和立交桥。

### 三、经络的三大基本功能

经络不是一条空洞的管道，而是承载着多重生理功能的活动系统：

| 功能 | 说明 | 举例 |
|------|------|------|
| **运行气血** | 经络是气血运行的通道，将气血输布全身 | "经脉者，所以行血气而营阴阳，濡筋骨，利关节者也"——《灵枢·本藏》 |
| **联络脏腑** | 沟通内脏与体表、内脏与内脏之间的联系 | 肝经上连目系——肝血不足则两目干涩 |
| **传导感应** | 传递针刺、艾灸等刺激，调节脏腑功能 | 针刺足三里可调节胃肠蠕动（足三里属胃经） |

> **与藏象学说的衔接**：第4-5章中我们学习了五脏六腑的功能。现在想象一下——五脏六腑各自为政，必须靠经络来串联。五脏产生的精气血，通过经络输送到全身；体表感受到的刺激，通过经络传递到内脏。经络就是藏象学说的"空间操作系统"。

**【思考题1】** 回顾第4章"心主血脉"的功能描述。结合经络的"运行气血"功能，请思考：心、血脉、经络三者之间的关系是怎样的？（提示：心是"泵"，血脉是"管道系统"的一部分，而经络是更广义的"通道网络"——它不仅运血，还运气。）

## 第二节 十二经脉的命名规律与归属

十二经脉的命名并非随意组合，而是遵循一套严密的三要素命名法则。

### 一、命名三要素

每条经脉的名称由三个部分构成：**手足 + 阴阳 + 脏腑**

```
手 太阴 肺 经
│   │    │  └── 所属脏腑（络属对象）
│   │    └────── 阴阳属性（三阴三阳之一）
│   └─────────── 循行部位（手/足）
└─────────────── 循行部位
```

| 要素 | 位置 | 含义 | 可选值 |
|------|------|------|--------|
| **手足** | 第一部分 | 经脉主要循行于上肢还是下肢 | 手 / 足 |
| **阴阳** | 第二部分 | 经脉的阴阳属性和气血盛衰程度 | 太阴 / 少阴 / 厥阴（三阴）；阳明 / 太阳 / 少阳（三阳） |
| **脏腑** | 第三部分 | 经脉所隶属的脏腑 | 肺 / 大肠 / 胃 / 脾 / 心 / 小肠 / 膀胱 / 肾 / 心包 / 三焦 / 胆 / 肝 |

### 三、命名规律总结

观察上表，可以提炼出以下六条核心规律：

#### 规律一：手经在上肢，足经在下肢

这条最简单——看名称的第一个字就知道大致位置。
- **手经** = 主要分布在上肢（6条：手三阴 + 手三阳）
- **足经** = 主要分布在下肢（6条：足三阴 + 足三阳）

> **注意**：这只是"主要分布"，手经也会走到头面躯干，足经也会走到胸腹——循行路线的完整描述见第三节。

#### 规律二：六脏属阴经（行于内侧），六腑属阳经（行于外侧）

这是一条**铁律**：

| 脏腑属性 | 经脉阴阳属性 | 循行部位 | 记忆口诀 |
|:-------:|:----------:|:-------:|---------|
| 五脏 + 心包 | **阴经** | 四肢**内侧** | 脏属阴，走内侧 |
| 六腑 | **阳经** | 四肢**外侧** | 腑属阳，走外侧 |

为什么？因为五脏主"藏精气而不泻"，属性偏阴；六腑主"传化物而不藏"，属性偏阳。阴阳属性决定了它们各自经脉的走行位置。

> **举手验证**：站直，双臂自然下垂——掌心向内的那一面就是**内侧**（阴经行走的区域），手背向外的就是**外侧**（阳经行走的区域）。

#### 规律三：阴经与阳经的表里配对

每一条阴经都有一条阳经与之配对，两者在手指/脚趾末端交接，构成表里关系：

| 表（阳经·六腑） | 里（阴经·五脏） | 共同特点 |
|:-------------:|:-------------:|---------|
| 手阳明大肠经 | 手太阴肺经 | 都与"呼吸—传导"系统相关 |
| 手太阳小肠经 | 手少阴心经 | 都与"血脉—分清泌浊"相关 |
| 手少阳三焦经 | 手厥阴心包经 | 都与"气化—护卫"相关 |
| 足阳明胃经 | 足太阴脾经 | 都与"消化—运化"相关 |
| 足太阳膀胱经 | 足少阴肾经 | 都与"水液代谢"相关 |
| 足少阳胆经 | 足厥阴肝经 | 都与"疏泄—决断"相关 |

> **回顾衔接**：这六对表里关系，与第4-5章藏象学说中脏腑的表里配对完全一致——肺与大肠、心与小肠、心包与三焦、脾与胃、肾与膀胱、肝与胆。经络的表里关系，正是脏腑表里关系的空间化体现。

#### 规律四：阴阳消长的命名逻辑

"三阴三阳"不是随意排列的，而是按照**阴阳之气由多到少**的次序：

| 类别 | 次序 | 阴/阳气量 | 含义 |
|:----:|:----:|:--------:|------|
| **三阴** | 太阴 → 少阴 → 厥阴 | 阴气递减 | 太（大）= 阴气最盛 → 少 = 阴气较少 → 厥 = 阴气将尽 |
| **三阳** | 阳明 → 太阳 → 少阳 | 阳气递减 | 阳明 = 阳气最盛 → 太阳 = 阳气较盛 → 少阳 = 阳气初生 |

> **记忆口诀**：
> - 三阴："太少了，绝（厥）了"——阴气从太（最多）→少（减少）→厥（将尽）
> - 三阳："明亮的太阳很少"——阳明（最亮）→太阳（明亮）→少阳（初升）

#### 规律五：手足同名经的"同名同气"

手和足有三对"同名经脉"——它们虽然循行部位不同，但阴阳属性相同，在功能上也有关联：

| 同名经脉 | 阴阳属性 | 功能关联 |
|---------|:-------:|---------|
| 手太阴肺经 + 足太阴脾经 | 太阴 | 肺主气，脾生气（气的生成与运行） |
| 手少阴心经 + 足少阴肾经 | 少阴 | 心主血，肾藏精（精血同源） |
| 手厥阴心包经 + 足厥阴肝经 | 厥阴 | 心包代心受邪，肝主疏泄（情志调节） |
| 手阳明大肠经 + 足阳明胃经 | 阳明 | 大肠传导，胃受纳（消化道的两端） |
| 手太阳小肠经 + 足太阳膀胱经 | 太阳 | 小肠泌别清浊，膀胱贮藏尿液（水液代谢） |
| 手少阳三焦经 + 足少阳胆经 | 少阳 | 三焦主气化，胆主决断（枢机运转） |

> **临床意义**：同名经之间存在"同气相通"的关系，取手经穴位可以治疗足经循行部位的病症，反之亦然。例如：手阳明大肠经的合谷穴（在手部）可以治疗足阳明胃经循行部位的面部牙痛——这就是"同经相应，以手治足"的取穴思路。

#### 规律六：三阴三阳的前中后排列

在四肢，三阴三阳经脉按照特定的前后顺序排列：

| 部位 | 前缘 | 中间 | 后缘 |
|------|:----:|:----:|:----:|
| 上肢内侧（三阴经） | 太阴（肺） | 厥阴（心包） | 少阴（心） |
| 上肢外侧（三阳经） | 阳明（大肠） | 少阳（三焦） | 太阳（小肠） |
| 下肢内侧（三阴经） | 太阴（脾） | 厥阴（肝） | 少阴（肾） |
| 下肢外侧（三阳经） | 阳明（胃） | 少阳（胆） | 太阳（膀胱） |

> **记忆口诀**：在四肢，"太厥少"对应"前中后"（阴经）；"明少太"对应"前中后"（阳经）。下肢内侧的小腿部分稍有交叉（内踝上8寸以下例外），在第三节详述。

## 第三节 十二经脉的循行路线

十二经脉的循行是本章最具挑战但也最核心的内容。本节先讲循行的**一般规律**，再按四组分类逐一展开，最后用总结表格帮你理清脉络。

### 一、十二经脉循行的一般规律

十二经脉虽然各有各走法，但遵循一些共同规律：

| 规律 | 说明 |
|------|------|
| **阴经升、阳经降（大部分）** | 手三阴从胸走手（由内而外），手三阳从手走头（由下而上），足三阳从头走足（由上而下），足三阴从足走腹胸（由下而上） |
| **阴阳相贯，如环无端** | 阴经与阳经在手足末端交接，形成闭环 |
| **内属于脏腑，外络于肢节** | 每条经脉在体内属络特定脏腑，在外循行于体表 |
| **对称分布** | 同名经脉左右对称，各有一条 |

> **一句话总结循行大方向**：
> - 手三阴：**胸→手**（离心走）
> - 手三阳：**手→头**（向上走）
> - 足三阳：**头→足**（向下走）
> - 足三阴：**足→腹胸**（回心走）

```
[头面]
  ↑ 手三阳从手走头      足三阳从头走足 ↓
[手] ← 手三阴从胸走手    足三阴从足走腹胸 → [胸腹]
```

### 二、四组经脉循行分述

下面按**手三阴→手三阳→足三阳→足三阴**的顺序，逐一描述每条经脉的循行路线。每条经脉的描述包括：①体表循行主线、②体内属络关系、③与其他经脉的交接点。

> **学习提示**：初次学习时不必强记每条经脉的完整路线。先掌握大方向和关键节点，细节可在后续经络腧穴学课程中逐步深化。建议配合经络挂图学习，效果更佳。

#### （一）手三阴经：从胸走手

三脏（肺、心包、心）的经脉从胸腔出发，沿上肢内侧下行至手指末端。

##### 1. 手太阴肺经

```
【体内属络】属肺，络大肠
【体表主线】起于中焦（胃脘部）→ 下络大肠 → 还循胃口 → 上膈 → 属肺
           → 从肺系（气管、喉咙）横出腋下（腋前纹头）
           → 沿上肢内侧前缘下行 → 过肘窝 → 入寸口（桡动脉搏动处）
           → 经鱼际 → 出拇指桡侧端（少商穴）
【分支】从腕后（列缺穴）分出 → 沿食指桡侧行至食指末端 → 交手阳明大肠经
【交接】在食指末端与手阳明大肠经交接
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 中焦 | 胃脘部 | 肺经起源于中焦——"肺为主气之枢，脾为生气之源"的经络基础 |
| 寸口 | 桡动脉搏动处 | **诊脉独取寸口**的理论依据——肺经经过寸口，最能反映全身气血状况 |
| 拇指桡侧端 | 少商穴 | 井穴，放血可治咽喉肿痛 |

> **重点理解**：为什么中医"独取寸口"就能诊察全身疾病？因为寸口（手腕桡动脉搏动处）是手太阴肺经循行的关键节点，而肺主气、朝百脉——全身经脉的气血都要汇聚于肺，再通过肺经反映于寸口。所以一个寸口脉，就能反映五脏六腑的状况。

##### 2. 手厥阴心包经

```
【体内属络】属心包，络三焦
【体表主线】起于胸中 → 出属心包络 → 下膈 → 历络三焦
           → 从胸中分出，循胸出胁 → 下腋三寸 → 上抵腋下
           → 沿上肢内侧中间下行 → 过肘窝 → 入掌中（劳宫穴）
           → 出中指末端（中冲穴）
【分支】从掌中（劳宫穴）分出 → 沿无名指出其末端 → 交手少阳三焦经
【交接】在无名指末端与手少阳三焦经交接
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 掌中 | 劳宫穴 | 握拳时中指尖所点之处，可清心泻火 |
| 中指末端 | 中冲穴 | 急救要穴，点刺放血可治中暑昏迷 |

##### 3. 手少阴心经

```
【体内属络】属心，络小肠
【体表主线】起于心中 → 出属心系 → 下膈 → 络小肠
           → 从心系上肺 → 下出腋下（极泉穴）
           → 沿上肢内侧后缘下行 → 过肘窝 → 入掌内后缘
           → 出小指桡侧端（少冲穴）→ 交手太阳小肠经
【分支】从心系上挟咽喉 → 连目系（眼球后的神经血管束）
【交接】在小指桡侧端与手太阳小肠经交接
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 目系 | 眼球后方 | 心经上连目系——心血不足则视力模糊（"目得血而能视"的经络基础） |
| 小指桡侧端 | 少冲穴 | 井穴，可治心悸、心痛 |

> **与第4章衔接**：第4章学过"心主血脉，其华在面，开窍于舌"——现在从经络角度理解：心经的体内分支"上挟咽喉""连目系"，正是心与舌、目相联系的物质基础。

#### （二）手三阳经：从手走头

三腑（大肠、三焦、小肠）的经脉从手指末端出发，沿上肢外侧上行至头面部。

##### 4. 手阳明大肠经

```
【体内属络】属大肠，络肺
【体表主线】起于食指桡侧端（商阳穴，接手太阴肺经）→ 沿食指桡侧上行
           → 经第一、二掌骨之间（合谷穴）→ 入腕后两筋之间
           → 沿前臂外侧前缘上行 → 过肘外侧 → 上肩（肩髃穴）
           → 交大椎（督脉）→ 入缺盆（锁骨上窝）→ 络肺 → 下膈 → 属大肠
【头面分支】从缺盆上颈 → 贯颊 → 入下齿中 → 还出挟口（人中沟）
           → 左脉向右、右脉向左 → 交对侧鼻翼旁（迎香穴）
           → 接足阳明胃经
【交接】在鼻翼旁（迎香穴）与足阳明胃经交接
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 合谷 | 第一、二掌骨之间 | "面口合谷收"——治头面五官疾病的首选穴 |
| 下齿中 | 下牙龈 | 下牙痛属大肠经（上牙痛属胃经） |
| 鼻翼旁 | 迎香穴 | 治鼻塞、鼻炎的常用穴 |

> **情境回顾**：还记得小李的牙痛吗？医生说是"胃火牙痛"，取的是足阳明胃经的内庭穴——为什么？因为上牙龈属于胃经循行范围。如果是下牙痛，则应取手阳明大肠经的合谷穴——因为下牙龈属于大肠经。同是牙痛，上牙下牙取穴不同——这就是经络循行指导临床的生动体现。

##### 5. 手少阳三焦经

```
【体内属络】属三焦，络心包
【体表主线】起于无名指尺侧端（关冲穴，接手厥阴心包经）→ 沿无名指尺侧上行
           → 经手背第四、五掌骨间 → 过腕 → 沿前臂外侧中间上行
           → 过肘尖（鹰嘴）→ 上肩 → 交大椎（督脉）→ 入缺盆
           → 散络心包 → 下膈 → 遍属三焦（上中下三焦）
【头面分支】从缺盆上项 → 沿耳后（翳风穴）→ 上出耳上角
           → 屈折下行经颊 → 至眶下
【耳部分支】从耳后入耳中 → 出走耳前 → 至目外眦（丝竹空穴）
           → 接足少阳胆经
【交接】在目外眦（丝竹空穴）与足少阳胆经交接
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 耳后 | 翳风穴 | 治耳鸣、耳聋的要穴——三焦经绕耳而行 |
| 目外眦 | 丝竹空穴 | 治偏头痛、目赤肿痛 |

##### 6. 手太阳小肠经

```
【体内属络】属小肠，络心
【体表主线】起于小指尺侧端（少泽穴，接手少阴心经）→ 沿小指尺侧上行
           → 经手背尺侧（后溪穴）→ 沿前臂外侧后缘上行
           → 过尺骨鹰嘴与肱骨内上髁之间 → 沿上臂外侧后缘上行
           → 出肩关节 → 绕肩胛 → 交大椎（督脉）→ 入缺盆
           → 络心 → 下膈 → 抵胃 → 属小肠
【头面分支】从缺盆沿颈上颊 → 至目外眦 → 入耳中（听宫穴）
【面颊分支】从颊分出 → 至目内眦（睛明穴）→ 接足太阳膀胱经
【交接】在目内眦（睛明穴）与足太阳膀胱经交接
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 后溪 | 握拳，第五掌指关节后横纹头 | 通督脉，治颈项强痛、落枕 |
| 听宫 | 耳屏前，张口凹陷处 | 治耳鸣、耳聋 |
| 目内眦 | 睛明穴 | 与膀胱经交接处，治目疾 |

#### （三）足三阳经：从头走足

三腑（胃、胆、膀胱）的经脉从头部出发，经过躯干，沿下肢外侧下行至足趾末端。足三阳经是全身最长、穴位最多的经脉。

##### 7. 足阳明胃经

```
【体内属络】属胃，络脾
【体表主线】起于鼻翼旁（迎香穴，接手阳明大肠经）→ 上行至鼻根部（目内眦）
           → 旁行入上齿中 → 还出挟口环唇 → 交承浆（任脉）
           → 沿下颌角上行 → 经耳前 → 上至额角（头维穴）
【面部下行分支】从下颌角前下方（大迎穴）→ 沿咽喉 → 入缺盆 → 下膈 → 属胃 → 络脾
【胸腹主线】从缺盆经乳头内侧下行 → 挟脐旁两寸 → 入少腹两侧（气冲穴）
【下肢主线】从气冲穴下行 → 沿大腿外侧前缘 → 过膝髌骨外侧
           → 沿胫骨前嵴外侧下行 → 过足背 → 出第二趾外侧端（厉兑穴）
【分支1】从膝下三寸（足三里穴）分出 → 入中趾外侧端
【分支2】从足背（冲阳穴）分出 → 入大趾内侧端 → 接足太阴脾经
【交接】在足大趾内侧端（隐白穴）与足太阴脾经交接
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 上齿中 | 上牙龈 | 上牙痛取胃经（下牙痛取大肠经） |
| 足三里 | 外膝眼下三寸 | "肚腹三里留"——治一切胃肠疾病，保健要穴 |
| 厉兑 | 第二趾外侧端 | 井穴，治齿痛、咽喉肿痛 |

> **趣味记忆**：胃经是人体最长、穴位最多的经脉（45穴）。记住"一头一腹一腿"——头上的迎香→头维，腹部的梁门→天枢，腿上的足三里→厉兑。胃经从头到脚，贯穿全身。

##### 8. 足少阳胆经

```
【体内属络】属胆，络肝
【体表主线】起于目外眦（瞳子髎穴，接手少阳三焦经）→ 上行至额角
           → 下行至耳后（风池穴）→ 沿颈侧 → 入缺盆
【耳部分支】从耳后入耳中 → 出走耳前 → 至目外眦后
【躯干主线】从缺盆下腋 → 沿胸侧 → 过季胁（章门穴）→ 属胆 → 络肝
           → 沿胁肋 → 出腹股沟（气冲穴）→ 绕阴毛 → 横入髋关节（环跳穴）
【下肢主线】从环跳穴沿大腿外侧中间下行 → 过膝外侧
           → 沿腓骨前缘 → 至外踝前 → 经足背
           → 出第四趾外侧端（足窍阴穴）
【分支】从足背（足临泣穴）分出 → 入大趾爪甲后丛毛中 → 接足厥阴肝经
【交接】在足大趾爪甲后丛毛中与足厥阴肝经交接
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 风池 | 枕骨下，胸锁乳突肌与斜方肌之间 | 治头痛、眩晕、感冒的要穴 |
| 环跳 | 股骨大转子与骶管裂孔连线的外1/3 | 治坐骨神经痛、下肢痿痹 |
| 足临泣 | 第四趾本节后方 | 通带脉，治偏头痛、胁肋痛 |

> **记忆特点**：胆经走"之"字形——头部弯弯曲曲，胁肋走侧面，髋部横穿，下肢沿外侧中线下行。胆经循行的侧面路线正好是人体侧面中轴。

##### 9. 足太阳膀胱经

```
【体内属络】属膀胱，络肾
【体表主线】起于目内眦（睛明穴，接手太阳小肠经）→ 上额 → 交巅顶（百会穴，督脉）
【头顶分支】从巅顶入络脑 → 还出
【项部分支】从头顶分出 → 下行至耳上角
【背腰主线】从头顶下行至项后 → 沿肩胛内侧 → 挟脊旁一寸五分（第一侧线）
           → 抵腰中 → 络肾 → 属膀胱
【腰部分支】从腰中下行 → 挟脊旁 → 经臀部 → 入腘窝（委中穴）
【背腰第二侧线】从肩胛内侧沿脊旁三寸下行 → 经臀部 → 过髋关节（环跳）
           → 沿大腿外侧后缘 → 与第一侧线合于腘窝
【下肢主线】从腘窝下行 → 经腓肠肌（承山穴）→ 过外踝后方（昆仑穴）
           → 沿足外侧赤白肉际 → 出小趾外侧端（至阴穴）
           → 接足少阴肾经
【交接】在足小趾外侧端（至阴穴）与足少阴肾经交接
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 睛明 | 目内眦角稍上方 | 治一切目疾 |
| 背俞穴 | 背部膀胱经第一侧线 | **五脏六腑之气输注于此**——诊断和治疗相应脏腑疾病的关键穴位群 |
| 委中 | 腘窝横纹中点 | "腰背委中求"——治腰背疼痛要穴 |
| 至阴 | 足小趾外侧端 | 纠正胎位不正的要穴 |

> **特殊地位**：膀胱经是人体最长、穴位最多（67穴）的经脉。它背部的第一侧线（距后正中线一寸五分）上排列着五脏六腑的"背俞穴"——肺俞、心俞、肝俞、脾俞、肾俞……这是诊断和治疗内脏疾病的重要部位。可以说，膀胱经的背部段就是一张"人体内脏投影地图"。

#### （四）足三阴经：从足走腹胸

三脏（脾、肝、肾）的经脉从足趾末端出发，沿下肢内侧上行至腹部和胸部。

##### 10. 足太阴脾经

```
【体内属络】属脾，络胃
【体表主线】起于足大趾内侧端（隐白穴，接足阳明胃经）→ 沿足内侧赤白肉际
           → 过内踝前 → 沿小腿内侧中间上行（内踝上八寸以下行于后缘）
           → 交出足厥阴肝经之前 → 沿大腿内侧前缘上行
           → 入腹 → 属脾 → 络胃 → 上膈 → 挟咽 → 连舌本 → 散舌下
【分支】从胃上膈 → 注心中 → 接手少阴心经
【交接】在心中与手少阴心经交接
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 隐白 | 大趾内侧端 | 井穴，治月经过多、崩漏 |
| 三阴交 | 内踝上三寸 | **足三阴经的交会穴**——治妇科、泌尿、消化系统疾病 |
| 舌本 | 舌根部 | 脾经连舌本——脾虚则舌淡胖有齿痕的经络基础 |

> **与第5章衔接**：第5章学过"脾主运化、主统血"。脾经"挟咽""连舌本""散舌下"——舌诊之所以能反映脾胃状况（舌苔由胃气所生），正是以脾经连舌为经络依据的。

##### 11. 足厥阴肝经

```
【体内属络】属肝，络胆
【体表主线】起于足大趾爪甲后丛毛中（大敦穴，接足少阳胆经）→ 沿足背上行
           → 经内踝前一寸 → 沿小腿内侧上行（内踝上八寸以下行于前缘）
           → 交出足太阴脾经之后 → 沿大腿内侧中间上行
           → 绕阴部 → 抵小腹 → 挟胃 → 属肝 → 络胆
           → 上贯膈 → 布胁肋 → 沿喉咙后 → 上入鼻咽部（颃颡）
           → 连目系 → 出额 → 与督脉会于巅顶
【分支】从目系下行 → 环唇内
【分支】从肝分出 → 上贯膈 → 注肺中 → 接手太阴肺经
【交接】在肺中与手太阴肺经交接（完成十二经脉大循环）
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 大敦 | 大趾外侧端 | 井穴，治疝气、遗尿 |
| 目系 | 眼球后方 | 肝经连目系——"肝开窍于目"的经络基础 |
| 巅顶 | 头顶 | 肝经上达巅顶——巅顶头痛多属肝经病变 |
| 肺中 | — | 十二经脉循环的终点，重新接回肺经 |

> **特殊地位**：肝经是十二经脉大循环的最后一条经脉。它从足走腹胸，最终"注肺中"，与手太阴肺经重新衔接，完成如环无端的经脉大循环。这就是中医"肝升于左，肺降于右"的经络气化基础。

##### 12. 足少阴肾经

```
【体内属络】属肾，络膀胱
【体表主线】起于足小趾下 → 斜走足心（涌泉穴）→ 出舟骨粗隆下
           → 沿内踝后 → 入足跟 → 沿小腿内侧后缘上行
           → 过腘窝内侧 → 沿大腿内侧后缘上行 → 贯脊 → 属肾 → 络膀胱
【直行分支】从肾上行 → 贯肝膈 → 入肺中 → 沿喉咙 → 挟舌本
【分支】从肺出 → 络心 → 注胸中 → 接手厥阴心包经
【交接】在胸中与手厥阴心包经交接
```

| 关键节点 | 体表标志 | 临床意义 |
|---------|---------|---------|
| 涌泉 | 足底前1/3凹陷处 | 急救要穴，也是保健灸的常用穴——"若要安，三里常不干；涌泉不可干" |
| 太溪 | 内踝与跟腱之间 | 肾经原穴，诊查肾气盛衰的要穴 |
| 舌本 | 舌根部 | 肾经挟舌本——肾精不足则舌体瘦小的经络依据 |

> **与第4章衔接**：第4章学过"肾主藏精、主水液、主纳气"。从经络角度看——肾经"入肺中""贯肝膈"，正是"肾主纳气"（肾协助肺吸气）和"肝肾同源"的经络基础。

## 第四节 十二经脉的表里络属与流注次序

### 一、表里络属关系

#### （一）"属"与"络"——一字之差，含义迥异

每条经脉都与两个脏腑发生关系——一个为"属"，一个为"络"：

| 关系 | 含义 | 亲疏程度 | 规律 |
|:----:|------|:-------:|------|
| **属** | 经脉"属于"本脏腑，是经脉的主归属 | 亲近（主） | 阴经属脏（如肺经属肺），阳经属腑（如大肠经属大肠） |
| **络** | 经脉"联络"相表里的脏腑 | 较疏（辅） | 阴经络腑（如肺经络大肠），阳经络脏（如大肠经络肺） |

> **精妙设计**：每一条经脉既"属"自己的本脏腑，又"络"相表里的对方脏腑。这样一来，表里两经通过"属络关系"紧密联系在一起，一脏一腑形成一个功能共同体。

#### （二）六对表里络属关系

| 表（阳经·络脏） | 里（阴经·络腑） | 络属关系 | 生理协同 |
|:-------------:|:-------------:|---------|---------|
| 手阳明大肠经 络肺 | 手太阴肺经 络大肠 | 肺←→大肠 | 肺气肃降助大肠传导 |
| 手太阳小肠经 络心 | 手少阴心经 络小肠 | 心←→小肠 | 心阳温煦助小肠分清泌浊 |
| 手少阳三焦经 络心包 | 手厥阴心包经 络三焦 | 心包←→三焦 | 心包护卫心神，三焦通达气化 |
| 足阳明胃经 络脾 | 足太阴脾经 络胃 | 脾←→胃 | 脾升胃降，共同完成消化 |
| 足太阳膀胱经 络肾 | 足少阴肾经 络膀胱 | 肾←→膀胱 | 肾气蒸化助膀胱气化排尿 |
| 足少阳胆经 络肝 | 足厥阴肝经 络胆 | 肝←→胆 | 肝主疏泄助胆汁排泄 |

> **"一脏配一腑"的经络实现**：为什么中医说"肺与大肠相表里"？不仅是功能上的联系——肺的肃降有助于大肠的传导（第4-5章学过），更因为手太阴肺经在体内"络大肠"，手阳明大肠经在体内"络肺"。两条经脉在体内互相联络，构成了表里两经的物质通道。

#### （三）表里关系的临床运用

| 运用方式 | 说明 | 举例 |
|---------|------|------|
| **原络配穴** | 取本经原穴 + 相表里经络穴 | 肺病取太渊（肺经原穴）+ 偏历（大肠经络穴） |
| **表里经同治** | 一脏有病，可治其相表里的腑（反之亦然） | 大便秘结除了通大肠，还可宣肺（肺与大肠相表里） |
| **经脉诊察** | 表里两经循行部位的异常互相反映 | 肺热可在手阳明大肠经循行部位出现压痛点 |

### 二、十二经脉的流注次序

经络中气血的运行不是杂乱无章的，而是按照固定次序，一条接一条，首尾衔接，如环无端——这就是**流注次序**。

#### （一）完整流注次序

```
         手太阴肺经
              │
              ▼ (食指端)
         手阳明大肠经
              │
              ▼ (鼻翼旁)
         足阳明胃经
              │
              ▼ (大趾内侧)
         足太阴脾经
              │
              ▼ (心中)
         手少阴心经
              │
              ▼ (小指端)
         手太阳小肠经
              │
              ▼ (目内眦)
         足太阳膀胱经
              │
              ▼ (小趾端)
         足少阴肾经
              │
              ▼ (胸中)
         手厥阴心包经
              │
              ▼ (无名指端)
         手少阳三焦经
              │
              ▼ (目外眦)
         足少阳胆经
              │
              ▼ (大趾丛毛)
         足厥阴肝经
              │
              ▼ (肺中)
         (回到手太阴肺经，循环往复)
```

#### （二）流注次序的记忆口诀

> **经典歌诀**（《针灸大成》）：
> 肺大胃脾心小肠，膀肾包焦胆肝详。
>
> 十二个字，一个不少：
> **肺 → 大(肠) → 胃 → 脾 → 心 → 小(肠) → 膀(胱) → 肾 → (心)包 → (三)焦 → 胆 → 肝**

也可以用分组记忆法：

| 循环圈 | 经脉流注链 | 特征 |
|:-----:|-----------|------|
| 第一圈 | 肺→大肠→胃→脾 | 始于太阴（肺），终于太阴（脾），涉及脾胃系统 |
| 第二圈 | 心→小肠→膀胱→肾 | 始于少阴（心），终于少阴（肾），涉及水液代谢系统 |
| 第三圈 | 心包→三焦→胆→肝 | 始于厥阴（心包），终于厥阴（肝），涉及气化疏泄系统 |

> **发现规律**：每个循环圈都以三阴经开始、阳经居中、三阴经结束——形成一个"阴→阳→阳→阴"的四步循环。三个循环圈依次流转，最终肝经回注肺经，完成大循环。

#### （三）流注次序的三大规律

观察流注图，可以提炼出三条铁律：

**规律一：阴阳交替原则**

经脉流注总是在阴经和阳经之间交替进行：

```
阴(肺)→阳(大肠)→阳(胃)→阴(脾)→阴(心)→阳(小肠)→阳(膀胱)→阴(肾)→阴(心包)→阳(三焦)→阳(胆)→阴(肝)
```

> 相邻的两条经脉必定一阴一阳（唯一的例外是胃经→脾经和膀胱经→肾经这两对表里经之间，阴→阴或阳→阳——这是因为表里经之间走的是体内络属路线而非四肢末端交接点）。

**规律二：表里经相连原则**

每一对表里经脉在流注次序中总是前后相连：

| 表里对 | 流注次序 | 交接点 |
|--------|---------|--------|
| 肺↔大肠 | 肺→**大肠** | 食指端 |
| 胃↔脾 | 胃→**脾** | 大趾内侧 |
| 心↔小肠 | 心→**小肠** | 小指端 |
| 膀胱↔肾 | 膀胱→**肾** | 小趾端 |
| 心包↔三焦 | 心包→**三焦** | 无名指端 |
| 胆↔肝 | 胆→**肝** | 大趾丛毛 |

> 表里两经总是**阴经在前、阳经在后**（四肢末端交接），或者**阳经在前、阴经在后**（体内属络交接，如胃→脾、膀胱→肾）。

**规律三：手足同名经相接不相邻**

手足同名经虽然"同气相通"（见第二节规律五），但它们在流注次序中不是紧邻的。例如：手太阴肺经与足太阴脾经并非直接相连，中间隔了手阳明大肠经和足阳明胃经。它们的关系是"同气"而非"接气"——同名经之间通过功能协同而非直接交接来发挥作用。

#### （四）流注次序的临床意义

| 应用场景 | 说明 | 举例 |
|---------|------|------|
| **子午流注** | 气血在十二经脉中按时间顺序盛衰 | 寅时（3-5am）肺经气血最旺——适合调理呼吸系统 |
| **循经传感** | 针刺感传沿流注方向传递 | 针合谷，酸麻感传至鼻旁——沿大肠经流注方向 |
| **疾病传变** | 疾病沿流注次序从一经传至另一经 | 外感风寒先犯肺经→沿流注传入大肠经（腹泻）→胃经（呕吐） |
| **补泻顺序** | 虚补其母、实泻其子须按流注关系确定 | 肺虚可补脾（脾经在流注中居肺经之前相关位置），取土生金之意 |

## 第五节 十二经脉的分布规律

掌握了各条经脉的独立循行和整体流注之后，本节将它们放在一起进行横向比较，提炼出十二经脉在体表的**分布规律**。

### 一、在四肢的分布规律

（本节核心内容已在第二节规律六中初步介绍，此处总结完善。）

| 部位 | 前缘 | 中间 | 后缘 |
|------|:----:|:----:|:----:|
| 上肢内侧（三阴经） | 太阴（肺） | 厥阴（心包） | 少阴（心） |
| 上肢外侧（三阳经） | 阳明（大肠） | 少阳（三焦） | 太阳（小肠） |
| 下肢外侧（三阳经） | 阳明（胃） | 少阳（胆） | 太阳（膀胱） |
| 下肢内侧（三阴经） | 太阴（脾）→厥阴（肝）→少阴（肾）[注] |

> **[注]** 下肢内侧的排列有一个特殊变化：在内踝上八寸以下，肝经行于脾经之前（前缘），脾经行于中间。内踝上八寸处，肝经和脾经交叉换位——肝经走到中间，脾经走到前缘。这是十二经脉分布中唯一的一个交叉换位。

> **举手自测**：想知道某条经脉在手/脚的大致位置？——三阴经在内侧（前中后：太厥少），三阳经在外侧（前中后：明少太）。记住这个口诀，就能快速定位。

### 二、在头面部的分布规律

头为"诸阳之会"——六条阳经全部上行至头部，而阴经大多不上头（唯足厥阴肝经上至巅顶，手少阴心经连目系）：

| 部位 | 分布经脉 |
|------|---------|
| 前额/面部 | 足阳明胃经（主面部）、手阳明大肠经（鼻旁） |
| 侧头部/耳周 | 足少阳胆经、手少阳三焦经 |
| 后头部/枕部 | 足太阳膀胱经（项后）、督脉 |
| 巅顶 | 足厥阴肝经、督脉、足太阳膀胱经 |

> **面部口诀**："面为胃经所主，侧为少阳所行，后为太阳之域，顶为厥阴所至"

### 三、在躯干部的分布规律

| 部位 | 分布经脉 | 规律 |
|------|---------|------|
| 胸腹前正中线 | 任脉（奇经，第8章介绍） | 单行 |
| 距腹中线0.5寸 | 足少阴肾经 | 双行 |
| 距腹中线2寸 | 足阳明胃经 | 双行 |
| 距腹中线4寸 | 足太阴脾经 | 双行 |
| 胁肋部 | 足厥阴肝经、足少阳胆经 | 双行 |
| 背腰部后正中线 | 督脉（奇经，第8章介绍） | 单行 |
| 距后中线1.5寸 | 足太阳膀胱经（第一侧线） | 双行，背俞穴所在 |
| 距后中线3寸 | 足太阳膀胱经（第二侧线） | 双行 |
| 肩胛部 | 手太阳小肠经、手少阳三焦经 | 双行 |

> **临床意义**：腹部和背部经脉的排列规律是"循经取穴"的重要依据。例如脐旁2寸是胃经的天枢穴（大肠募穴），脐旁4寸是脾经的大横穴。

### 四、交接规律

十二经脉的交接点不是随意的，而是遵循以下规律：

| 交接类型 | 交接部位 | 举例 | 规律 |
|---------|:-------:|------|------|
| 表里两经 | 四肢末端（手指/足趾） | 肺经→大肠经（食指端） | 六对表里经都在四肢末端交接 |
| 同名手足经 | 头面部 | 大肠经→胃经（鼻翼旁） | "手经交足经，必在头面部" |
| 相邻阴经 | 胸中/心中 | 脾经→心经（心中）；肝经→肺经（肺中） | 阴经之间在胸内交接 |

> **完整交接链**：手指末端（表里）→ 头面部（手足同名）→ 足趾末端（表里）→ 胸中（相邻阴经）→ 手指末端……形成一个闭环。
