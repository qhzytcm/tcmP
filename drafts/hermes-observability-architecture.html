Hermes Delivery 可观测性架构

三大支柱 — 日志(ELK) / 指标(Prometheus+Grafana) / 链路追踪(Jaeger+OTel) — 通过 TraceID 统一关联

三大信号 (3 Signals)

  • • 日志 — 离散事件，回答"发生了什么"
  • • 指标 — 时间序列，回答"量有多大/多快"
  • • 追踪 — 因果链，回答"在哪一步/为什么"
  • • TraceID 贯穿三者，形成排查闭环

工具选型

  • • 日志：ELK (Filebeat→ES→Kibana)
  • • 指标：Prometheus + Grafana + AlertManager
  • • 追踪：OpenTelemetry + Jaeger
  • • 统一标准：OTLP 协议 + W3C TraceContext

Hermes Delivery 关键指标

  • • 订单创建速率 (rate) + 错误率
  • • 调度成功率 + 骑手在线数
  • • P99 延迟分布 (Histogram)
  • • 调度队列深度 (Gauge)
