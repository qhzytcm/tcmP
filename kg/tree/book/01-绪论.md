# 第一章 绪论——从知识图谱到中医知识树

## 1.1 知识图谱的成就与局限

知识图谱以「实体—关系—实体」的三元组描述世界，在中医药领域已结出硕果：中药—靶点—疾病关联发现、方剂配伍规律挖掘、智能问答与辅助辨证。tcmP 平台的病证知识图谱以「病证单元（DSU）」为最小编写原子，把西医病侧（病名、ICD-11 编码、分子靶点）与中医证侧（证候、六经八纲、主症舌脉）锚定于同一个节点，目前落地 103 个单元、远期规划六万节点。

然而知识图谱是**扁平**的。它擅长回答「谁和谁有关系」，却难以回答三个教学中反复出现的问题：这个知识**从哪里来**？**该先学谁**？它属于**哪一门课、哪一章**？这正是教材体系必须回答的问题，也是纯图谱结构的天然缺口。

## 1.2 中医药知识的两层结构：层次与关系

中医的知识组织从来是双轨的。**层次**体现在经典与教材：阴阳→五行→藏象→经络→证候→方药，逐级从属、由总到分；**关系**体现在临证：五行生克乘侮、十二经脉流注表里、方证对应、君臣佐使、引经报使、六经传变。层次保证「学得进去」，关系保证「用得出神」。

一门课程若要既教会学生系统地记，又教会学生活用地推，就必须同时把两层结构显式化。中医知识树为此而生。

## 1.3 中医知识树的定义与核心隐喻

中医知识树是一棵**五级骨架**的知识结构，以草木生长为隐喻：

| 层级 | 名称 | 语义 | 平台对应 |
| :-: | --- | --- | --- |
| L0 | 须 | 哲学根基，根须吸养 | 阴阳/五行/精气神/天人相应/藏象经络/恒动整体 |
| L1 | 根 | 核心公理 | 整体观念/辨证论治/恒动平衡/治未病 |
| L2 | 干 | 院系域主干 | D01–D08 八域 |
| L3 | 枝 | 学科分枝 | 120 门学科 |
| L4 | 叶 | 终末知识点／病证单元 | 章节知识点 + 病证单元 |

须向根输送养分，根生出主干，干分主枝，枝展叶冠——这与中医「由道及术、由源及流」的认知顺序天然同构。

## 1.4 树图一体：知识图谱如何成为知识树的经脉

中医知识树不是要取代知识图谱，而是把它**收编**为自身的经脉。规则只有一条：**树的叶，就是图的节点**。

- 树的枝干路径 = 图的分层聚类；
- 图的关系边只在「同层叶之间」或「叶与概念丛之间」建立；
- 于是层级管从属，关系管推理，二者互不干扰，又能互相索引。

在 tcmP 的实现中，`neighbors(DSU-00001)` 会同时返回它的证候（`manifests_as`）、西医病（`disease_is`）、ICD-11 编码（`icd11_map`）与所属学科枝（`hierarchy`）——一棵树与一张图，在同一个节点上汇合。

## 1.5 知识树的编码体系：五级点分编码

为让「树」「图」「教材」三者可互相定位，本课程采用**五级点分编码**，横向读即完整编码：

```text
须 . 根 . 干 . 枝 . 叶
 1    0    0    0    0      →  X1 象数阴阳
 0    0    7   04    0      →  D07-S04 中医知识图谱
 0    0    1   13   D00001  →  DSU-00001（挂在 D01-S13 中医内科学（上））
```

编码与平台的教材四级目录（篇·章·节·目）互为补充：四级目录面向「教学编排」，五级编码面向「知识定位」。

## 1.6 中医知识树的平台意义与技术挑战

平台意义有三：其一，**教材与图谱不再是两张皮**——教材的每一章叶都挂在同一棵树上；其二，**技能与学科可自动对齐**——教育技能声明其学科即可挂树；其三，**六者 Agent 与医圣成长有了统一的知识坐标**。

技术挑战同样现实：源数据分布在领域规范 Markdown、病证单元 JSON、技能目录 JSON 三类异构文件里，排版格式各异；这要求构建管线具备**容错解析**能力，并以**可复现、可校验**为底线。第八章将给出工程解法。
