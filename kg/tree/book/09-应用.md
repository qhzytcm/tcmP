# 第九章 知识树的应用

## 9.1 教材编排与目录对齐

120 门学科的教材目录必须挂在同一棵树上才有可比性。用 `path(叶)` 反查任一知识点所属的域—学科—章节，即可自动检验教材目录是否缺章、错位。

```bash
python kg/tree/tcm_tree.py path D07-S04-K03
# → D07 → D07-S04 → D07-S04-K03（第3章）
```

## 9.2 教育资源技能路由

教育技能声明其学科即可自动挂树（`skill_bind`）。于是「某学科可用哪些技能」「哪些学科尚无技能覆盖」一查即得，为技能补齐提供清单。

## 9.3 以病索证／以证溯病的检索

知识树与 Embedding 引擎协作，支持双向检索：以症状索病（`/diag`）、以症状辨证（`/bianzheng`）、以语义检索（`/semantic-search`）、以检索结果生成 RAG 报告（`/rag`）。

```bash
curl "https://www.zyyywaccn.com.cn/api/sages/semantic-search?q=失眠"
# → DSU-00035 · 心脾两虚证 · 归脾汤 · ICD-11 MC81 · score 0.1601
```

## 9.4 六者 Agent 的知识边界加载

六者（医·患·药·械·规·法）各自只应看到其职责内的知识。知识树用 `path(节点)` 与 `subtree(域)` 精确裁剪上下文：医者加载 D01 临床 + D07 智能；药者加载 D02 中药 + 方证边；规者加载 D08 管理 + 质控叶。同一棵树，按角色投影出不同的知识边界。

## 9.5 医圣成长路径的可量化考核

医圣成长以「掌握病证数」为门槛（住院医-1 约 500 → 学科带头人约 60,000）。知识树把 DSU 叶按域—学科聚合，使「已掌握多少病证」「还差哪些学科」可直接计数，成长路径从主观描述变为可量化考核。

```bash
python kg/tree/tcm_tree.py subtree D07 | head   # 智能域的知识规模
```

## 9.6 知识树可视化与终端呈现

树图一体天然适合可视化：树干用层次布局，经脉用弧线跨接。PWA 终端上，用户可点开任一片叶，看到它的祖先链（我在学哪一章）、邻居（相关方证穴）与出处（教材编号 + ICD-11）。
