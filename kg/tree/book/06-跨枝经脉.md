# 第六章 跨枝经脉：五行与经络、六经

## 6.1 五行生克乘侮的图建模

五行是中医最早的关系网络。相生为激励边，相克为抑制边，整张图是带符号的有向图。知识树把五行建为五个概念节点，并生成两类边：

```text
wuxing_sheng（相生）：木→火→土→金→水→木        5 条
wuxing_ke  （相克）：木→土→水→火→金→木        5 条
```

乘侮（过度克制／反向欺凌）不单独建边，而是把对应边**加权放大或反向**，交由图算法（随机游走、消息传递）追踪失衡传播路径。

## 6.2 十二经脉流注与表里相合

十二经脉按流注次序首尾相接，构成一个大环；互为表里的两经成对。知识树把十二经建为概念节点，生成：

- `meridian_liuzhu`（流注）：手太阴肺经→手阳明大肠经→…→足厥阴肝经→（回手太阴），共 12 条；
- `meridian_biaoli`（表里）：肺—大肠、胃—脾、心—小肠、膀胱—肾、心包—三焦、胆—肝，共 6 条。

```bash
python kg/tree/tcm_tree.py neighbors M-01 --rel meridian_liuzhu
# → [out] meridian_liuzhu  M-02  手阳明大肠经
```

## 6.3 六经传变与病证桥接

六经（太阳、阳明、少阳、太阴、少阴、厥阴）既是辨证纲领，也是传变路径。知识树把六经建为节点，生成 `six_chuanbian`（传变）顺序边；同时，每个 DSU 的证侧若标注了六经归属，则建一条 `bridge` 边，把病证单元接回六经主线上。目前 103 个 DSU 中已有 81 条 `bridge` 边。

## 6.4 方证对应、君臣佐使、引经报使

这三类是中药方剂领域特有的关系边，教材阶段以「概念—关系」表形式给出，后续可实例化为图边：

| 关系 | 头 → 尾 | 用途 |
| --- | --- | --- |
| 方证对应 | 方剂 → 证候 | 由证选方、由方测证 |
| 君臣佐使 | 方剂 → 药（带角色） | 配伍结构分析 |
| 引经报使 | 药 → 经络 | 归经与靶向 |

## 6.5 经脉边的推理与路径发现

有了经脉边，知识树就能回答「多跳」问题：由「恶寒发热无汗」→ 证候「风寒束表」→ 六经「太阳病」→ 主方「麻黄汤」→ 归经「手太阴肺经」。这条推理链跨越了图与树、证与方与经络，正是中医思维的数字化表达。

```python
# 多跳路径发现（伪代码）
path = find_path("DSU-00001", "M-01", rels=["bridge", "manifests_as", "recipe"])
# → DSU-00001 →(bridge) SC-1 太阳病 →(六经对应) 麻黄汤 →(归经) 手太阴肺经
```
