# 第三章 须与根：哲学根基与核心公理

## 3.1 须层：象数阴阳/五行/精气神/天人相应/藏象经络/恒动整体

须是知识树最底、最抽象的一层，它不从属于任何一门课，却滋养全部学科。中医知识树的须层由六个根基构成：

| 编码 | 须 | 内涵 |
| :-: | --- | --- |
| X1 | 象数阴阳 | 对立、互根、消长、转化——认知的原初标尺 |
| X2 | 五行生克 | 木火土金水，生克乘侮——关系优先的拓扑网络 |
| X3 | 精气神形 | 精、气、神三宝与形神合一 |
| X4 | 天人相应 | 四时、五方、节气——人天耦合的边界条件 |
| X5 | 藏象经络 | 脏腑经络的生理图式根基 |
| X6 | 恒动整体 | 整体观念与恒动观 |

须层的设计原则是：**凡不能从任何单一学科教材导出的「共祖」知识，才配入须**。

## 3.2 根层：整体观念/辨证论治/恒动平衡/治未病

根是四大核心公理，中医全部方法论由此展开：

- **G1 整体观念**：人是一个有机整体，人与自然、社会相统一；
- **G2 辨证论治**：辨证求因、审因论治——中医临床的「操作系统」；
- **G3 恒动平衡**：阴平阳秘、以平为期；
- **G4 治未病**：未病先防、既病防变、瘥后防复。

## 3.3 须→根的滋养边构建

须与根不是简单的从属，而是「滋养」。构建器把这种语义固化为 `nourish` 边，例如：象数阴阳滋养整体观念与辨证论治；天人相应滋养整体观念与治未病。根与干之间另建 `spine`（脊梁）边，表示四条公理共同支撑每一个院系域。

## 3.4 根基层的动态更新与学术演进

公理层看似恒定，实则会随学术发展微调。例如温病学说兴起后，「卫气营血」「三焦」成为与六经并列的辨证主线，需要在须/根层予以容纳；扶阳学派则强化了「恒动平衡」中的阳主动一面。因此知识树把须根层设计为**可版本化**的常量区：修改后重跑构建器，全树自动跟上，`verify` 全绿即发布。
