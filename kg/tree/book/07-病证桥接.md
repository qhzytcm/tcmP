# 第七章 病证桥接与 ICD-11 编码

## 7.1 病侧与证侧的双向锚定

病证单元的核心设计是**双向锚定**：病侧锚定诊断终点（辨析式流程），证侧锚定干预着力点。教材编写要求双栏：左栏写病（分子靶点、ICD-11、流行病学），右栏写证（证候场论、六经八纲、主症舌脉），中缝设桥接栏（对应类型、生物学基础、证据等级）。知识树把两侧合并为一片叶，用 `disease_is`、`manifests_as`、`bridge` 三条边分别接入西医病、证候与六经。

## 7.2 内网 ICD-11 镜像与本地编码库

ICD-11 编码是病证单元对接病历与医保的关键。tcmP 采用双通道：

| 通道 | 地址/文件 | 说明 |
| --- | --- | --- |
| 内网 API | `192.168.0.111:8080`（whoicd/icd-api 容器） | 中文搜索、标准编码 |
| 本地 db | `data/icd11_mms.db` | 31,838 实体，Foundation ID → 编码 |

```python
# scripts/icd11_client.py 的核心调用（简化）
import json, urllib.request
def icd_search(q, base="http://192.168.0.111:8080"):
    req = urllib.request.Request(
        f"{base}/icd/release/11/2024-01/mms/search?q={q}",
        headers={"Accept": "application/json",
                 "Accept-Language": "zh",
                 "API-Version": "v2"})
    return json.load(urllib.request.urlopen(req, timeout=15))
```

> 实测（2026）：华为云公网访问不到内网 API，中文搜索自动降级英文；编码端点由镜像能力决定，本地 db 补齐。因此**离线降级**是必须写在教材里的纪律：平台不可达时，凡依赖编码的结论标注「未能核实」。

## 7.3 病证桥接的证据等级体系

桥接的严格性由证据等级标定：A级多中心RCT → B级单中心RCT → C级队列研究 → D级病例对照 → E级专家共识 → F级经典理论。知识树把等级写入边的 `meta`，使「这条对应关系有多可信」可被机读与排序。

## 7.4 编码映射的校验与冲突消解

编码映射会冲突：同一 DSU 可能对应多个 ICD-11 候选，或一词多码。消解策略是**三查一验**：查内网 API、查本地 db、查教材标注；三者不一致时以本地 db 的 Foundation ID 为准，并把分歧记入审核队列。

```python
# 编码落盘与校验（节选）
edge = {"source": "DSU-00001", "target": "ICD-CA00", "type": "icd11_map",
        "meta": {"code": "CA00", "entity": "2066255370", "title": "急性鼻咽炎"}}
assert edge["target"].startswith("ICD-")
```

> 实训：对 12 个 DSU 抽样，比较「内网 API 编码」与「本地 db 编码」的异同，统计一致率。
