# 第五章 叶层：章节知识点与病证单元

## 5.1 章节知识点的抽取与编址

叶是知识树的终末层，也是可被单独考核的最小单位。第一类叶来自教材章节目录：每门学科的「章节目录」被抽取为该枝下的叶。以本课程所属的 D07-S04 为例，原有《中医知识图谱》十章目录，被重写为《中医知识树》四篇十章。

抽取的关键是**容错**——八份领域规范使用至少四种排版（编号列表、Markdown 表格、`<br>` 拼接单元格、代码围栏），构建器须逐一识别：

```python
# 章节目录四种排版的统一抽取（节选）
CHP_ROW  = re.compile(r"^\|\s*(第[0-9一二三四五六七八九十百]+章)\s*\|\s*([^|]*?)\s*\|")
NUM_ITEM = re.compile(r"^\d{1,2}[\.、]\s*(\S.{0,60})$")
```

抽得 2489 片章节叶，覆盖 120/120 学科。

## 5.2 病证单元（DSU）作为最小编写原子

第二类叶来自病证知识图谱。每个 DSU 同时包含病侧与证侧，不可拆分：

| 侧 | 字段 |
| --- | --- |
| 病侧 disease_side | 病名、ICD-11 编码、分类、分子靶点、基因通路、生物标志物 |
| 证侧 syndrome_side | 证名、证型、脏腑、六经、八纲、主症、舌脉、证候场论、经典依据 |
| 桥接 bridge | 对应类型、生物学基础、证据等级 |
| 临床 clinical | 主方、加减、针灸、食疗、预后 |

知识树把每个 DSU 作为一片叶，挂到其归属的学科枝（如 DSU-00001 挂 D01-S13 中医内科学（上））。

## 5.3 中医智能服务单元的正名与降格（学科正名／服务降格）

叶层设计贯彻两条命名纪律：

- **学科正名**：凡进入「学科枝」的条目必须是真正的学科（一门课=一种教材），不把章节升格为学科；
- **服务降格**：平台的工程服务（检索、编码、生成）不冒充学科，而是以「技能挂点」或「概念丛」的身份降格接入。

这一纪律防止了「学科膨胀」与「目录漂移」，是本平台教材体系稳定性的关键。

## 5.4 叶节点的属性与质量门禁

每片叶携带 `code5`（五级编码）、`level`、`kind` 与 `attrs`。质量门禁要求：叶必须有父（无孤儿）、必须可定位（编码非空）、DSU 叶必须带病名与证名。`schema.json` 以 JSON Schema 形式固化这些约束，构建时逐条校验。

## 5.5 叶级检索与定位

叶是检索的落点。给定任一关键词，先在全树叶名上做包含匹配，再回到树与图提供上下文：

```bash
python kg/tree/tcm_tree.py search 桂枝汤
python kg/tree/tcm_tree.py path    DSU-00001      # 根→域→学科→单元
python kg/tree/tcm_tree.py neighbors DSU-00001    # 图邻接
```
