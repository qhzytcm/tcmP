# 第十章 实验

## 10.1 实验一：运行构建器生成知识树

**目标**：理解单一构建点，产出可校验的知识树。

```bash
cd <repo>
python scripts/build_knowledge_tree.py
python scripts/verify_knowledge_tree.py
```

**操作步骤**：
1. 观察构建日志：源文件、域/学科计数、章节叶数；
2. 打开 `kg/tree/tcm-knowledge-tree.json`，确认 `meta / stats / nodes / edges` 四段；
3. 记录 `stats.levels` 与 `stats.edge_types`。

**结果与分析**：预期 3063 节点 / 3370 边 / 章节覆盖 120/120。若某学科无章节叶，构建器以**告警**（非中断）提示，需回源修正排版。

## 10.2 实验二：用查询引擎做树导航与图邻接

**目标**：掌握树的路径算法与图的邻接查询。

```bash
python kg/tree/tcm_tree.py node       D07-S04
python kg/tree/tcm_tree.py path       DSU-00001
python kg/tree/tcm_tree.py neighbors  DSU-00001
python kg/tree/tcm_tree.py neighbors  W-木 --rel wuxing_sheng
python kg/tree/tcm_tree.py search     桂枝汤
```

**操作步骤**：对 `DSU-00001` 记录它的祖先链与全部邻居边类型；对 `W-木` 验证相生边「出→火、入←水」自洽。

## 10.3 实验三：基于知识树的中医问答／辨证辅助

**目标**：把「树定位 + 图证据 + 语义检索」装配为一次可解释的问答。

**操作步骤**：
1. 用 `/semantic-search` 由症状召回 Top-K 病证单元；
2. 对每个命中，取 `path` 给出学科坐标，取 `neighbors` 取证据（ICD-11、证候、六经、主方）；
3. 按证据等级排序，装配为 LLM 上下文（context engineering），生成带出处的回答；
4. 断言：每条结论都能回答「依据是什么」。

**结果与分析**：实测「失眠」→ DSU-00035 心脾两虚证 归脾汤（ICD-11 MC81）。核对平台不可达时的降级行为（标注「未能核实」）。

## 10.4 课程项目：知识树驱动的学科概览 App

**目标**：交付一个可运行、可演示的作品。

**交付物**：
1. 一个 HTML/单文件页面，读取 `/tree/*` 端点，展示八域骨架与任一学科的章节叶；
2. 一个检索框，接 `/semantic-search`，命中后高亮其在树上的位置；
3. 一份 800 字设计说明，阐明「树图一体」在本作品中的体现。

**评分**：结构正确 30% + 检索可用 30% + 出处可核 20% + 设计说明 20%。
