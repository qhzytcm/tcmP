# 中医知识树 · 卷首

中医药知识有一个被长期忽视的结构事实：它**既是层次的，又是关系的**。阴阳统五行、五行辖藏象、藏象连经络，这是一条自上而下的从属链；而证—方—药—穴之间又彼此勾连，构成一张没有中心的网络。过去我们用「知识图谱」表达网络，用「教材目录」表达层次——两套体系互不认账。

本教材提出**中医知识树（TCM Knowledge Tree）**：以「须—根—干—枝—叶」五级骨架承载层次，以「跨枝经脉图边」承载关系，**树图一体**。它的每一片叶，就是知识图谱的一个节点；而知识图谱的每一条边，就是这棵树的一条经脉。

本课程在 tcmP 中医药网络教育平台上项目驱动：学生将亲手运行构建器、用查询引擎导航知识树，并把 ICD-11 编码、TF-IDF+FTS5 检索与上下文工程（context engineering）接入自己的作品。课程结束时，每位学生都拥有一棵可查询、可校验、可部署的知识树。
