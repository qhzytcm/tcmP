# 第十九章 中医临床信息数据的存储与管理

> 对应《中医临床信息学》第三章。

## 19.1 临床信息数据的存储与管理

分三层设计：

1. **系统概述**：面向临床业务的数据底座（病历、医嘱、检验、影像）；
2. **系统业务流程**：挂号 → 接诊 → 四诊采集 → 辨证 → 开方 → 随访；
3. **系统功能设计**：结构化录入、模板复用、版本留痕、权限分级。

## 19.2 科研信息数据的存储与管理

| 环节 | 内容 |
| --- | --- |
| 技术概述 | 数据仓库/科研专病库，与临床库同源分置 |
| 数据存储模型设计 | 以**患者—就诊—变量**为主线的星型/宽表模型 |
| 数据管理 | 版本控制、数据字典、变更审计、导出脱敏 |

## 19.3 平台对照

| 教科书概念 | 平台实现 |
| --- | --- |
| 结构化病历 | DSU 六段式 Schema（`kg/schema/schema.json`） |
| 快速检索 | SQLite **FTS5** 倒排索引（`scripts/tcm_embed.py`） |
| 编码库 | `data/icd11_mms.db`（31,838 实体） |

> 工程陷阱提示：部分环境下 SQLite 的 DLL 与库文件不兼容会导致进程级崩溃；读写关键库应统一用固定 Python 版本，并在客户端“连接即测”。
