# 第八章 检索与排序

## 6.1 检索任务与评价指标

检索回答“哪些记录与查询相关”。评价用**准确率（P）/召回率（R）/F1**，以及**排序质量指标**（MRR、NDCG）。中医检索的难点是**同义异形**：“失眠”与“不寐”、“消渴”与“糖尿病”需能互相命中。

## 6.2 布尔检索与向量空间模型

布尔检索按词是否出现做集合运算（快但脆）；向量空间模型（VSM）把文档与查询都变成向量，用**余弦相似度**排序（软且稳）。后者是现代检索的基石。

```python
def cosine(qv, dv):
    return sum(w * dv.get(t, 0.0) for t, w in qv.items())   # 已归一化
```

## 6.3 词项加权：TF-IDF

TF-IDF 的核心思想：一个词在当前文档出现越多越重要（TF），但在全库出现越普遍越不重要（IDF）。它自动压低“疾病”“证候”这类高频词的权重。

```python
idf = math.log((1 + N) / (1 + df)) + 1.0        # 平滑 IDF
w   = (tf / len(tokens)) * idf                   # 归一化后即向量分量
```

## 6.4 中文分词与字符 n-gram

中医术语边界灵活（“少阳病”“半表半里证”），词典分词易错。**字符 n-gram**（bigram/trigram）无需词典、对未登录词稳健，是中医短文本检索的首选起步方案。

## 6.5 全文索引：SQLite FTS5

FTS5 提供倒排索引与 BM25 排序，适合大库快速召回。

```sql
CREATE VIRTUAL TABLE dsu_fts USING fts5(id UNINDEXED, text, tokenize='unicode61');
SELECT id, bm25(dsu_fts) FROM dsu_fts WHERE dsu_fts MATCH '失眠' ORDER BY 2 LIMIT 5;
```

## 6.6 多路召回融合：RRF

向量召回“语义相近”，FTS5 召回“字面命中”，二者互补。用**倒数排序融合（RRF）**合并，无需调权重：

```python
def rrf(rank_lists, k=60):
    score = {}
    for rl in rank_lists:
        for i, doc in enumerate(rl):
            score[doc] = score.get(doc, 0.0) + 1.0 / (k + i + 1)
    return sorted(score, key=score.get, reverse=True)
```

## 6.7 上下文工程：把检索结果装进 LLM

检索到 Top-K 后，不能整库喂给大模型（token 爆炸）。**上下文工程**按“出处锚定 + 证据等级排序”只装小上下文：平台实测 Top-5 约 1.5K token，比全库 31K 次下降约 **95%**。
