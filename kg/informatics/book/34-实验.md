# 第三十四章 实验

## 34.1 实验一：构建信息学数据目录

**目标**：理解单一构建点与可复现生成物。

```bash
cd <repo>
python scripts/build_informatics.py          # 读 103 条 DSU 语料现算
python scripts/verify_informatics.py         # 自检
```

**步骤**：观察日志（标准/资产/算子/规则/覆盖/质量计数）；打开 `kg/informatics/tcm-informatics.json` 确认 `meta/standards/assets/operators/distributions/rules/stats` 齐备。
**结果与分析**：预期 ICD-11 覆盖 74/103、规则 45 条、质量问题 36 项。两次构建输出应**字节一致**（确定性）。

## 34.2 实验二：检索与融合

**目标**：掌握 TF-IDF / FTS5 / RRF 三件套。

```bash
python kg/informatics/tcm_mining.py retrieve "失眠 多梦"
```

**步骤**：记录向量 Top5、FTS5 Top5 与 RRF 融合结果；构造一个“字面不命中但语义相关”的查询（如用现代说法“睡不着”检索），观察向量与 FTS5 的差异。
**结果与分析**：说明为何融合能兼顾“语义”与“字面”。

## 34.3 实验三：关联规则与虚假高提升度

**目标**：亲手复现“lift=103 的陷阱”。

```bash
python kg/informatics/tcm_mining.py rules symptom_to_syndrome
```

**步骤**：找出所有 lift > 50 的规则，检查其 support；解释为什么 support 越低 lift 越容易高。
**结果与分析**：给出你认为合理的 MIN_SUPPORT 阈值并说明理由。

## 34.4 实验四：编码覆盖与数据质量报告

**目标**：输出一份可交付的数据质量报告。

```bash
python kg/informatics/tcm_mining.py coverage
python kg/informatics/tcm_mining.py quality
```

**交付物**：
1. 未编码病证单元清单（含西医旧编码，便于反查）；
2. 六经“合病/过渡变体”归类方案；
3. `I级-专家共识` 的修正说明；
4. 一份 800 字报告，含问题分级与修复建议。

**评分**：数据准确 30% + 分析深度 30% + 修复方案可行 20% + 报告规范 20%。
