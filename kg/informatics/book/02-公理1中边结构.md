# 第二章 公理 1 · 中边结构：完备知识 = 隐中心 + 显边缘

## 2.1 直觉

一张靶，有靶心（中）才有靶面（边）。没有中心的集合，只是一堆散点。

## 2.2 What

**一切完备系统都由“隐中心 + 显边缘”构成**：边缘是可见的观测（症状、数据），中心是隐在其后的规律（证候、模型）。

## 2.3 Where

| 层 | 隐中心 | 显边缘 |
| --- | --- | --- |
| 临床 | 证候 | 症状·舌脉 |
| 检索 | 语义向量 | 关键词命中 |
| 平台 | 知识树/图谱 | 教材章节·技能 |
| 语义张量 | 球心 O（基准绿） | 球面上的语义点 |

## 2.4 When

当数据“看得见但说不清”时，先假设存在一个隐中心，再去逼近它。

## 2.5 Why

因为观测本身是中心的**显现**：没有中心，边缘就不可解释；没有边缘，中心就无法观测。

## 2.6 How

三步：① 采集显边缘（结构化）；② 用聚类/降维/编码去**估计隐中心**；③ 用中心回过来校验边缘的**一致性**。

## 2.7 例证

103 条病证单元共 396 个不同症状，看似杂乱；一旦以“证候”为隐中心聚类，`气阴两虚证（消渴）` 与 `阴虚燥热证` 立即归为一族（见第二十一章）。
