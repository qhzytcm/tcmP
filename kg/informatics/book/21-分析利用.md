# 第二十一章 中医临床信息的分析利用

> 对应《中医临床信息学》第五章（全书分量最重的一章）。

## 21.1 中医临床规律发现（对应 88–145 页）

- **数据挖掘方法**：频次统计、关联规则、聚类、序列模式、复杂网络；
- **内容与示范研究**：从电子病历中发现“证—症—方—药”规律，如本课程第十二章在 103 条病证单元上现算的 45 条关联规则。

## 21.2 中医临床经验传承（对应 146–256 页）

名老中医经验的**现代分析挖掘**：先“整理”（医案结构化），再“发现”（用药规律、辨证思路），最后“传承”（知识库 + 决策支持）。这是解决“经验难以传承”这一学科核心问题的路径。

## 21.3 中医护理规律发现（对应 257–261 页）

将护理记录结构化后挖掘**证候—护理措施**的对应规律，形成中医特色护理路径。

## 21.4 中医临床决策支持系统（对应 262–292 页）

| 实现方法 | 机理 |
| --- | --- |
| 基于**案例推理**（CBR） | 以相似医案为参照给出建议 |
| 基于**知识推理** | 以规则/本体推理（如六经辨证规则） |
| 基于**知识服务** | 以知识库+检索服务供给决策依据 |

> 平台对照：`/informatics/retrieve`（向量 ⊕ FTS5 ⊕ RRF）正是“知识服务型决策支持”的最小可运行实现。

## 21.5 中医医院运营与决策管理系统（对应 293–306 页）

- 建设目标与总体架构；
- 基于 **ERP 理念**建立医院资源规划系统（**HRP**）；
- 构建医院决策支持系统（BI 报表 + 运营指标体系）。

## 21.6 安全边界声明

以上系统均为**辅助性**能力：CDSS 输出不替代医师判断与签字；经验传承结果需专家复核；涉及患者数据须遵循最小可用与脱敏原则。
