# 第八章 三轴语义编码（可计算）

> 单一来源：`kg/semtensor/encoder.py`。**权威分量来自八纲字段的确定性映射**（同输入必得同数字）。

## 8.1 编码公式

```
x = 0.60·阴阳(八纲) + 0.40·寒热(八纲)
y = 0.70·表里(八纲) + 0.30·虚实(八纲)
z = (神分 − 精分) / (精分 + 气分 + 神分 + 1)     ← 精气神关键词判位
r = clip(0.35·证据等级 + 0.35·症状密度 + 0.30·桥接完备度, 0.20, 1.00)
n̂ = unit(x, y, z) ； θ = arcsin(z/|v|) ； φ = atan2(y, x) ； C = comp(x, y, z)
```

## 8.2 参数表

| 参数 | 取值 |
| --- | --- |
| 八纲 | 阳证 +1 / 阴证 −1；热证 +1 / 寒证 −1；表证 −1 / 半表半里 0 / 里证 +1；实证 +1 / 虚证 −1；未列项 0 |
| 证据等级 | A 1.00 / B 0.75 / C 0.50 / 其它 0.40 |
| 症状密度 | min(1, (主症数 + 次症数)/10) |
| 桥接完备度 | min(1, len(桥接描述)/200) |

## 8.3 平台实测（103 条病证单元）

| 项 | 实测 |
| --- | --- |
| x 范围 | [−1.0, 1.0] |
| y 范围 | [−1.0, 1.0] |
| z 范围 | [−0.9474, 0.8333] |
| r 范围 | [0.558, 0.967] |
| 卦限分布 | −+− 39 · +++ 21 · ++− 13 · −++ 12 · +−+ 7 · +−− 6 · −−+ 3 · −−− 2 |

> 解读：`−+−`（阴·里·精）最多（39），符合“内科里证、形质病”为主的语料构成；`+++`（阳·里·神）次之（21）。

## 8.4 自由文本投影

`encode_text()` 为确定性启发式（长短关键词按序切除，避免二次计数），**仅用于把一句话落到球面**；权威分量始终来自八纲字段。
