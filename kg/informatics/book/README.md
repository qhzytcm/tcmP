# 中医信息学 · 卷首

中医药有海量的“文本与经验”，却长期缺少把它变成**可计算数据**的通道。中医信息学就是这道通道：向下，它规定病证怎么**编码**（ICD-11、GB/T 分类、数据元）；中间，它把临床记录、古籍、方药**结构化**；向上，它用**信息挖掘**从数据中发现规律——哪些症状常同现？哪些证候是同一族？哪些编码还没补齐？

本教材以 tcmP 平台真实资产为实验田：103 个病证单元、31,838 条 ICD-11 实体、120 门学科目录、84 个教育技能。学生将亲手跑通「编码 → 检索 → 关联 → 聚类 → 质量门禁」的完整链条，并把 TF-IDF、FTS5 与 RRF 融合接进自己的作品。课程结束时，每位学生都拥有一套可在平台上查询、可复现、可校验的信息学工具。
