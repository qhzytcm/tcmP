# 第十章 聚类与降维

## 10.1 聚类的目标

聚类把“相似的样本”自动归成组，无需标签。中医信息学中的典型聚类任务：**证候归并**（哪些证是同一族）、**方剂分组**、**患者分型**。

## 10.2 相似度：Jaccard 与重叠系数

症状是集合，用集合相似度度量：

| 度量 | 公式 | 适用 |
| --- | --- | --- |
| Jaccard | \|A∩B\| / \|A∪B\| | 集合大小相近时 |
| 重叠系数 Overlap | \|A∩B\| / min(\|A\|,\|B\|) | **稀疏集合**（本课程） |

中文短文本的症状集很稀疏（103 单元共 396 个不同症状），单个单元往往只有 2–5 个症状，Jaccard 天然偏低。改用重叠系数后，平台得到：

- `气阴两虚证（消渴）` × `阴虚燥热证` —— 同为消渴证候族。

## 10.3 层次聚类与单链法

层次聚类不需预设簇数。**单链法**把“相似度 ≥ 阈值”的样本连成图，连通分量即簇：

```python
def find(x):                      # 并查集
    while parent[x] != x:
        parent[x] = parent[parent[x]]; x = parent[x]
    return x
```

## 10.4 K-means 与簇数选择

K-means 需预设 K，用**肘部法/轮廓系数**选 K。它适合数值型特征，对稀疏集合需先向量化。

## 10.5 降维：PCA 与因子分析

降维把高维稀疏特征压缩为少数主成分。中医经典用法是**因子分析提取证候要素**（如从多症状中提炼“气虚”“血瘀”等潜在因子），这正是“证候”这一概念的量化试探。

## 10.6 从聚类到证候族

聚类结果是**探索性**的：它提示“哪些证可能同族”，但命名与确认仍需专家。教材强调：算法给候选，人给意义。
