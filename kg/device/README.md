## 一、这门学科解决什么问题

中医的四诊（望闻问切）依赖医师经验，**"不可传输、不可复算、不可积累"**。智能仪器与可穿戴设备要做的，是把四诊中**可客观化的部分**变成信号：

| 四诊 | 仪器化对象 | 信号通道 | 可穿戴形态 |
| --- | --- | --- | --- |
| 切（脉） | 脉位/脉数/脉形 | 压力阵列 | 脉象采集仪、腕带 PPG |
| 望（舌） | 舌质/舌苔色度 | RGB/多光谱 | 舌象拍照终端 |
| 闻 | 声音/气味 | 音频/气体传感 | —（研究阶段） |
| 问 | 症状自评 | 电子问卷 | App |

**核心命题**：仪器不只是"测得更准"，而是让中医的**信息可流通**（这正是《中医信息学》D07-S02 的延伸）。

## 三、重点能力：Holter 心律检测（本节课的可运行实测）

`kg/device/holter.py` 是**真实实现**（零依赖）：输入 RR 间期序列 → 输出 HRV 时域指标 + 节律判读 + 中医药关联提示。

```
HR = 60000/mean(RR)     SDNN = std(RR)      RMSSD = rms(ΔRR)
pNN50 = |ΔRR|>50ms 占比   CV = SDNN/mean(RR)
```

**六场景实测**（`python kg/device/build_device.py`，验证序列为**标注的仿真数据**，非临床）：

| 场景 | HR | SDNN | RMSSD | pNN50 | 判读 |
| --- | ---: | ---: | ---: | ---: | --- |
| normal | 74.8 | 28.23 | 19.54 | 0.0 | 窦性节律 |
| tachy | 107.0 | 14.12 | 9.78 | 0.0 | 心动过速 |
| brady | 50.0 | 21.14 | 14.64 | 0.0 | 心动过缓 |
| pause | 71.4 | 310.09 | 439.22 | 3.4 | **停搏（danger）** |
| premature | 75.0 | 46.85 | 77.60 | 5.1 | 早搏（短-长偶联） |
| af | 76.6 | 110.56 | 175.38 | 78.0 | **房颤提示** + 早搏 |

### 中医药关联（规则表 · 平台裁定 · 仅提示不诊断）

| 条件 | 证候提示 | 依据 |
| --- | --- | --- |
| HR>100 且 RMSSD>60 | 心火亢盛 / 阴虚火旺 | 心率快而变异保留 |
| HR>100 且 RMSSD≤60 | 心气不足兼热 | 心率快而变异降低 |
| HR<60 且 SDNN>80 | 心阳不振（迟脉） | 心率慢而变异高 |
| SDNN<30 | 心气虚 / 心脉瘀阻 | HRV 总变异降低 |
| 房颤提示 | 心悸、怔忡（脉结代/促/涩） | 节律绝对不齐 |

> ⚠️ **边界声明**：输出由算法生成，仅供教学/研究参考，**不构成医学诊断**；临床须由医师结合症状、舌脉与体征判断，且不得据以调整用药。
