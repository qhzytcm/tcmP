# 第十三章 临床应用与可穿戴场景

## 13.1 四个典型场景

| 场景 | 设备 | 中医价值 |
| --- | --- | --- |
| 心律失常筛查 | Holter / 贴片心电 | 心悸、怔忡的客观化与随访 |
| 慢病管理 | 手环 + 电子问卷 | 体质与证候的动态追踪 |
| 治未病 | 可穿戴连续监测 | 未病先防的量化依据 |
| 名医经验数字化 | 脉象/舌象采集 + 病历 | 经验可传承 |

## 13.2 临床落地的工作流

```
采集（设备）→ 质控（SQI 门禁）→ 分析（算法）→ 提示（证候关联）→ 医师判断（签字）→ 随访
```

**关键**：算法只进入"提示"环节；"判断"与"签字"永远由医师承担。

## 13.3 与六者平台的对接

| 角色 | 与本层的关系 |
| --- | --- |
| 医者 healer | 读取设备指标作辨证参考 |
| 患者 patient | 佩戴设备、接收健康提示 |
| **械者 device** | 设备维护/质控/溯源/采购/急救（`/devices/*`） |
| 规者 regulator | 设备与数据合规核查 |
| 法者 legal | 隐私与数据治理 |

## 13.4 效果评价

必须报告**临床终点**（如阵发性房颤检出率）而非仅算法指标（AUC）；并做**与金标准（12 导联 ECG / 医师判读）的一致性对照**。

> 实训：设计一份"可穿戴心电筛查阵发性房颤"的小型临床研究方案要点。
