# 第十章 伦理、安全与展望（含实验）

## 10.1 伦理与合规红线

- **属性先行**：设备是否属医疗器械、属几类，决定可用场景与宣传口径；
- **最小可用**：只采集必要数据；去标识与加密传输；
- **不越权诊断**：算法输出为"提示"，不得生成诊断结论或用药建议；
- **可追溯**：数据来源、算法版本、判读依据必须留痕。

## 10.2 安全要点

| 风险 | 后果 | 对策 |
| --- | --- | --- |
| 漏报（假阴性） | 延误诊治 | 高敏感阈值 + 人工复核 |
| 误报（假阳性） | 过度检查、焦虑 | 多通道融合 + 随访确认 |
| 数据泄露 | 隐私侵害 | 脱敏、加密、访问审计 |
| 算法漂移 | 结论不稳 | 版本冻结 + 定期复验 |

## 10.3 技术展望

- **多模态**：ECG + PPG + 皮温 + 舌脉图像的统一时基融合；
- **个体基线**：以"自身历史"为参照而非群体阈值（中医"因人制宜"的量化）；
- **与大模型协同**：LLM 负责自然语言交互，仪器数据负责**可信事实供给**；
- **与知识结构联动**：设备数据 → 语义张量坐标（D07-S02）→ 证候定位 → 教学与科研应用。

## 10.4 实验

**实验一 · Holter 心律检测**
```bash
python kg/device/build_device.py     # 六场景 HRV 与判读
python kg/device/verify_device.py    # 自检 19 项
```
记录六场景的 HR/SDNN/RMSSD/pNN50 与判读；解释为何 `pause` 的 SDNN 异常高。

**实验二 · 自定义 RR 序列**
构造一段含 3 个早搏的 RR 序列，提交给 `holter.analyze()`，写出判读结果与中医提示。

**实验三 · 中医药关联规则复核**
列出 `TCM_RULES` 五条规则，逐条给出"可能误报的场景"及缓解办法。

**实验四 · 数据可用性报告**
就一段 24h 监测设计可用性报告字段（SQI、脱落率、有效时长、事件完整率），并给出判定阈值建议。

**评分**：数据准确 30% + 分析深度 30% + 边界意识 20% + 报告规范 20%。
