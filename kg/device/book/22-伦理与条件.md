# 第二十二章 智慧中医伦理要求与基本条件

> 对标《智慧中医学》**第一章第五节「智慧中医伦理要求」**与**第六节「智慧中医基本条件」**。

## 22.1 伦理要求四条（该书的框架）

| # | 伦理要求 | 本课程落点 |
| :-: | --- | --- |
| 1 | **中医大健康数据隐私与保密** | 第四章 数据安全 / 第十七章 采集规范（去标识·加密·审计） |
| 2 | **医疗事故责任与潜在风险** | 第十章 安全要点（漏报/误报/算法漂移） |
| 3 | **智能推理结果的偏见与道德规范实践** | 第六章 中医药关联规则**可能误报**的复核 |
| 4 | **决策建议与医患关系** | 第九章 工作流（算法仅到"提示"，签字属医师） |

## 22.2 为什么这四条对"仪器"尤其重要

仪器是**数据入口**：隐私问题在此产生，偏见在此固化，责任在此划分。

```
仪器采集（数据入口）→ 算法推理（偏见可能固化）→ 提示（责任分界）→ 医师决策（责任主体）
```

## 22.3 基本条件两条

| 条件 | 含义 | 本课程落点 |
| --- | --- | --- |
| **智慧中医标准化需求及体系构建** | 没有标准，设备之间不可比 | 第四章（FHIR/IEEE 11073/ICD-11/DSU） |
| **智慧中医临床应用需求** | 必须回到临床问题，而非技术炫技 | 第十九章（慢性疼痛样板） |

## 22.4 本课程的伦理红线（与第十章呼应）

1. 算法输出为**提示**，**不构成诊断**；
2. 设备属性的**取证路径**先于功能宣传；
3. 数据**最小可用**，去标识化与加密传输；
4. **不得**引用权威奖项或教材为具体疗法背书。
