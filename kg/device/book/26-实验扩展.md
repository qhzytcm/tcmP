## 26.2 实验六 · 六快自动化评价

**目标**：跑通"记录 → 评分 → 提示"。

```bash
python kg/device/sensing.py          # 示例记录评分（总分/分级/薄弱维度）
```

**步骤**：把 `DEMO_RECORD` 中的 `sleep_minutes` 改为 300（5 小时）、`fall_events` 改为 2，重跑；记录总分与薄弱维度的变化，并解释每一维的评分依据。
**分析**：说明"缺数据不猜"（`coverage`）在工程上的意义。

## 26.3 实验七 · 单位与时间口径复刻

**目标**：复刻参考实现的换算口径。

```python
import sensing as S
S.lb_to_kg(150)        # 68.0389  （POUNDS_PER_KILOGRAM = 2.20462）

S.minutes_to_nanos(1)  # 60000000000
```
**分析**：为什么 Google Fit 用**纳秒**时间戳？跨设备同步时它解决了什么问题？

## 26.4 实验八 · 光遗传学辨析（写作）

**目标**：建立技术分层与边界意识。

**要求**（600 字）：
1. 用自己的话说明光遗传学的三步（蛋白—导入—光照）；
2. 比较其与"中医光疗/经穴光刺激"的**三个本质差异**；
3. 指出一条最容易被越界的宣传口径，并给出合规表述。

**评分**：概念准确 30% + 分层清晰 30% + 边界意识 25% + 表述规范 15%。
