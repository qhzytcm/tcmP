# 第十一章 中医药通用六快：吃 / 喝 / 拉 / 撒 / 睡 / 警觉安全

## 11.1 为什么是"六快"

中医问诊的**通用底层问题**，不外乎六件事——而且是**每天都会发生、可被连续监测**的六件事：

| 快 | 内涵 | 可感测 | 中医关联 |
| :-: | --- | --- | --- |
| 吃 | 进食量/时/规律 | 咀嚼加速度·进食图像·餐次 | 脾胃运化；"饮食自倍，肠胃乃伤" |
| 喝 | 饮水 | 饮水量（称重/容量）·皮肤电 | 津液代谢；多饮多尿当察消渴 |
| 拉 | 大便 | 频次/形态（自评）·腹部体动 | 大肠传导；溏/秘辨虚实 |
| 撒 | 小便 | 尿量/频次 | 肾与膀胱气化；夜尿多属肾气虚 |
| 睡 | 睡眠 | 加速度+心率+皮温 → 睡眠分期 | 心神；阳入于阴则寐 |
| 警觉安全 | 警觉/跌倒/走失 | 跌倒检测（加速度）·HRV·定位 | 神与气血；跌仆多因正气不足 |

## 11.3 六快为什么适合"通用"

因为它**不预设病种**：无论什么病、什么体质，"吃得怎么样、睡得怎么样、大小便如何"都要问。所以六快既是**中医问诊的通用骨架**，也是**可穿戴连续监测的天然对象**。

## 11.4 六快与西医指标的互补

六快是**行为—功能**层，心率/血压/血糖是**生理—指标**层。二者互补：指标异常但六快正常，可能是早期；六快长期偏离而指标尚可，提示功能失调。中医"治未病"的量化入口，正在六快。
