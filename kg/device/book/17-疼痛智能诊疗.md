# 第十七章 典型应用：中医慢性疼痛智能诊疗

> 对标《智能中医学概论》**第七章第四节「典型应用：中医慢性疼痛智能诊疗」**——该书以疼痛为实例，完整展示采集→模型构建→临床验证的全流程。

## 17.1 为什么选疼痛作为第一个落点

① **症状明确**（患者能报告）；② **变化可测**（强度、频次、部位）；③ **可干预**（针灸、推拿、方药均有证据）；④ **客观指标可获取**（HRV、皮电、体动）。四点齐备，使疼痛成为"智能中医诊疗"最合适的样板。

## 17.2 疼痛的可感测化（四元映射）

| 维度 | 可感测指标 | 元 | 采集方式 |
| --- | --- | --- | --- |
| 自主神经反应 | HRV（SDNN/RMSSD） | E | 心电/贴片 |
| 应激/情志 | 皮肤电活动（EDA） | E | 皮电传感器 |
| 活动受限 | 体动幅度、步态 | K | 加速度计 |
| 睡眠受影响 | 睡眠分期、夜间体动 | K+E | 手环/贴片 |
| 主观强度 | 数字评分（NRS/VAS） | — | 电子记录 |

**关键**：主观评分（NRS）不可替代，但可与客观指标构成**复合终点**。

## 17.3 智能诊疗流程（该书的实现路径）

```
采集（仪器/可穿戴 + 电子记录）
  → 数据标准化（术语/结构/质量）
  → 特征提取（HRV、EDA、体动、睡眠）
  → 模型构建（机器学习/深度学习）
  → 智能辅助诊断（证候提示，医师确认）
  → 智能辅助治疗（方案推荐，医师决策）
  → 临床验证（疗效评价标准化）
```

## 17.4 平台可复跑的最小闭环

```bash
python kg/device/build_device.py     # Holter 六场景 + 六快评分（疼痛相关的 E/K 证据）
python kg/device/sensing.py          # 六快分维评分（含 HRV → 警觉安全）
```

> ⚠️ 教材只演示**技术闭环**，不给出任何处方、剂量或治疗方案；临床决策由医师承担。
> 实训：为"颈肩痛"设计一个含 HRV + 体动 + NRS 的 2 周监测方案（字段、频次、质控、终点）。
