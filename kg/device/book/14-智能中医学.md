## 14.1 学科定义与实现路径

**智能中医学 = 融合中医理论与人工智能技术的新兴交叉学科。**

实现路径（该书明确表述）：

```
客观化检测技术 + 中医药大数据 + 人工智能  →  中医药信息的客观化与智能化
```

这条路径的**第一个环节"客观化检测技术"，正是本课程（D07-S11 仪器与可穿戴设备）的全部内容**。仪器是入口，AI 是出口。

## 14.2 发展理念与辨证框架

| 项 | 内容 |
| --- | --- |
| 发展理念 | **数据筑基、智慧引航** |
| 辨证框架 | **象—素—候—证** |
| 方法学 | 中医药循证研究「**四证**」方法学体系（群体证据与个体证据相融合） |

**「象—素—候—证」的四级抽提**：

| 级 | 含义 | 仪器侧对应 |
| :-: | --- | --- |
| **象** | 现象（可观测的原始表现） | 波形/图像/记录（P·E·M·K 原始信号） |
| **素** | 要素（可提取的特征） | HRV 指标、脉象参数、舌色度、六快计数 |
| **候** | 证候（要素的组合模式） | 证候单元（DSU） |
| **证** | 证型（判定的结论） | 辨证结果（须医师确认） |

> 这条链与《中医信息学》（D07-S02）的**语义张量**互为投影：象/素 → 坐标 (x,y,z)，候/证 → 聚类与判读。
