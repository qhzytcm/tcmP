# 第十二章 健康自动评价：从可穿戴数据到评分

> 参考实现：**pkpio/fitbit-googlefit**（GitHub，518★）——"Export Fitbit data to Google Fit"，以细粒度导出多源数据。

## 12.1 参考实现做了什么

| 项 | 内容 |
| --- | --- |
| 数据源 | Fitbit API（OAuth2） |
| 目标 | Google Fit API |
| 转换 | `convertors.py`：磅↔公斤（2.20462）、英里↔米（1609.34）、分钟→纳秒（10⁻⁹s） |
| 粒度 | 步数/距离/卡路里/睡眠 **分钟级**；心率 **秒级**；体重/体脂 **按次** |
| 依赖 | `fitbit==0.3.1`、`google-api-python-client`、`oauth2client` |

**它的价值**：把"设备私有数据"变成"可计算的标准数据"。这正是本课程第六章（数据标准）的工程实证。

## 12.2 从"导出"到"评价"

数据导出只是第一步。**健康自动评价** = 导出 → 归一化 → 六快分维评分 → 总分分级 → 提示。

```
原始记录(steps/sleep/hr/weight/...) → 六快维度 → 0–100 分 → 加权总分 → 优/良/中/差 → 中医药提示
```

## 12.3 平台实现（`kg/device/sensing.py`）

| 快 | 评分口径（平台示范，可复核） |
| --- | --- |
| 吃 | 餐次落在 3–4 次 → 100；偏离线性衰减 |
| 喝 | 饮水 1200–2000 ml → 100 |
| 拉 | 1–2 次/日 → 100 |
| 撒 | 4–8 次/日 → 100 |
| 睡 | 7–9 h → 100 |
| 警觉安全 | 跌倒 0 次 + HRV（SDNN）越高越好 |

**实测**（示例记录）：总分 **96.6**，分级 **优**；覆盖 6/6 维；薄弱维度：警觉安全、吃。

> ⚠️ 口径是可配置的**示范阈值**，不是临床参考值。

## 12.4 三条工程铁律

1. **缺数据不猜**：某维无数据即标 `None`，不计入总分，并报 `coverage`；
2. **确定性**：同输入必得同分（可复算、可比对）；
3. **必带边界声明**：评分用于教学/自我记录，**不构成医学诊断**。

## 12.5 从评分到中医语义

评分给出"哪一维薄弱"，再由《中医信息学》的语义张量（D07-S02）把该维映射到证候坐标，形成"**设备数据 → 证候提示**"的闭环（本课程展望 V4）。

> 实训：把 13.3 的六条口径改成"你所在人群"的阈值，并说明依据来源。
