# 第七章 脉象与舌象的客观化

## 7.1 脉象：从"手感"到压力曲线

脉象采集仪用**压力阵列**在寸关尺三部施加梯度压力，得到压力—时间曲线。可提取：

| 中医要素 | 曲线特征 |
| --- | --- |
| 脉位（浮/沉） | 最佳压力阈值的高低 |
| 脉数（迟/数） | 主波间隔（等价于心率） |
| 脉形（弦/滑/涩） | 主波宽度、重搏波高度、谐波结构 |
| 脉势（虚/实） | 振幅与能量 |

> 与第六章同源：**脉数**可由 RR/脉搏间隔直接算出，是最容易客观化的脉象要素。

## 7.2 舌象：从"目视"到色度

舌象仪用标准光源 + 色卡校正拍摄，再做 **Lab 色域分割**：

```
图像 → 色卡校正 → 舌体分割 → 色度统计（舌质/舌苔分区）→ 苔色/苔质分类
```

关键难点是**光源一致性**：不同设备/光照下的同一舌象色度差异，常大于不同患者的真实差异——质控（第五章）在此决定成败。

## 7.3 客观化的边界

客观化 ≠ 替代。仪器给出的是**可比较的量**，医师给出的是**有意义的判断**。二者关系是"仪表盘与驾驶员"，不是"替代与被替代"。

> 实训：为一个"舌象客观化"模块设计质控指标（至少 3 条）。
