# 第十五章 智能四诊数据采集（与四元 / 六快衔接）

> 对标《智能中医学概论》**第七章第一节「四诊数据采集」**。

## 15.1 四诊的可采集化

| 诊 | 采集对象 | 本课程物理量 | 已有章节 |
| :-: | --- | :-: | --- |
| 望 | 舌象、面色、形态 | **P 光子**（RGB/多光谱） | 第九章 舌象客观化 |
| 闻 | 声音、气味 | （研究阶段，本课程未展开） | — |
| 问 | 症状自评、六快 | **M/E/K**（记录+传感） | 第十一章 六快 |
| 切 | 脉象、心脉节律 | **M**（压力） / **E**（ECG） | 第八章 Holter、第九章 脉象 |

该书把"四诊数据采集"列为智能中医诊疗技术的**第一项**——因为没有采集，就没有后面的分析、诊断与治疗生成。

## 15.2 采集的三个层次

```
① 传感层：把生命现象变成物理量（P/E/M/K）
② 记录层：把物理量变成结构化记录（时间戳+数值+质量标记）
③ 入库层：把记录变成可检索的数据（标准编码+溯源）
```

**最常见的失败**在②→③：波形采到了，但没有时间戳、没有信号质量标记，数据无法用于研究。

## 15.3 采集规范（本课程要求）

| 项 | 要求 |
| --- | --- |
| 时间戳 | 统一时基（参考 Google Fit 用**纳秒**） |
| 单位 | 统一量纲（kg/m/s，换算常量可追溯） |
| 质量标记 | 每段数据带 **SQI**、脱落率、佩戴依从 |
| 溯源 | 设备型号、校准时间、算法版本 |
| 隐私 | 去标识、加密、访问审计 |

## 15.4 与"象—素—候—证"的接口

采集层只负责到**象**（现象）；**素**（特征）的提取属于算子层（第九章），**候/证**属于判读层（须医师确认）。**越级判证＝越权诊断**。

> 实训：为"切诊（脉象）"写一份采集规范（时间戳/单位/质量/溯源四条）。
