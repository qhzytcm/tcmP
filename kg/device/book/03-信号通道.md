# 第三章 生理信号通道

## 3.1 六条信号通道

| 通道 | 采样率 | 可提取特征 |
| --- | --- | --- |
| 心电 ECG | 250–1000 Hz | HR、SDNN、RMSSD、pNN50、波形形态 |
| 光电容积 PPG | 25–100 Hz | 脉率、灌注指数、脉搏波形态 |
| 加速度 ACC | 25–100 Hz | 体动、睡眠分期、步态 |
| 皮温 TEMP | 0.1–1 Hz | 体表温度分布 |
| 压力 PRESS | 100–500 Hz | 脉象三部压力曲线 |
| 图像 IMG | — | 舌象色度与纹理 |

## 3.2 采样定理与中医信号的取值

奈奎斯特要求采样率 > 2×最高频成分。中医信号多为**低频**（脉率 ~1 Hz、体温更慢），但**心电的 QRS 波群**含 10–40 Hz 成分，故需 250 Hz 以上——这就是为什么 Holter 必须用 ECG 而非仅 PPG。

## 3.3 从原始信号到可计算量

```
原始波形 → 滤波（去基线漂移/工频）→ 峰值检测（R 波）→ RR 间期序列 → 指标
```

关键中间产物是 **RR 间期序列**：它是第六章 Holter 分析的唯一输入。

## 3.4 通道选择与冗余

多通道并非越多越好：每增加一路，就增加一份**同步、校准与依从**成本。工程上常用"**1 路参考 + N 路增量**"策略：以 ECG/PPG 为主参考，其余通道按场景增量接入。
