## 23.2 扩展现实（XR）在中医教学中的价值

| 场景 | XR 的作用 | 局限 |
| --- | --- | --- |
| 针刺手法训练 | 力反馈 + 视觉引导 + 可重复 | 缺乏真实组织反馈 |
| 经络腧穴可视化 | 叠加于人体（AR） | 定位精度依赖追踪 |
| 中医思维培养 | 情境化病例推演 | 不能替代临床 |

**关键**：XR 解决"看得见、可重复"，但**不解决"手感"**——手感仍需第七（脉象）/第十七章的量化采集来补。

## 23.3 生成式人工智能（该书列出）

| 模型类别 | 该书明确列出 |
| --- | --- |
| 基础模型 | **GPT 基础模型** |
| 生成模型 | **扩散模型** |
| 开源大模型 | **开源高性能大模型 DeepSeek** |

**生成式 AI 在中医仪器中的三种正当用法**：

```
① 交互层：把结构化指标转成患者能懂的自然语言解释
② 装配层：把检索到的规范文本装进上下文（context engineering）
③ 生成层：生成教学病例、训练数据（须标注为合成）
```

**三种越界用法（禁止）**：

```
✗ 让 LLM 直接给出诊断结论
✗ 让 LLM 生成处方剂量
✗ 把合成数据当作真实临床证据
```
