## 一、设计目标与定位

在 tcmP 平台（六者·中医医院AI网络教育平台）实现**三因辨证程序模块**：将中医病因学"三因学说"（陈言《三因极一病证方论》框架 + 内经依据）形式化为可计算的辨证引擎，与既有病证检索（/diag /bianzheng /semantic-search）形成 **"辨因 → 辨证 → 论治"** 的上游链路。

```
主诉/诱因文本
    │
    ▼
┌─ etiology.engine ─────────────────────────────────────┐
│ 内因辨证(nei)   七情 怒喜悲思恐忧惊 → 五脏主情          │
│ 外因辨证(wai)   六淫 风寒暑湿燥热 → (λ,α三维,s)签名     │
│ 不内外因(bunei) 7板块68细目 饮食/劳逸/外伤/虫兽/中毒/医过/先天 │
│   三因分类置信 + 辨证卡(病机/治则/方/穴/经脉/经文)       │
└──────────────────────────────────────────────────────┘
    │
    ▼
sage-api /diag /bianzheng（病证检索）→ 论治建议（可衔接）
```

## 三、符号体系（framework.py，四文件统一契约）

### 3.1 脏腑与经脉（四层拓扑 L2/L3）
| 记号 | 脏腑 | 记号 | 脏腑 | 记号 | 经脉 |
|---|---|---|---|---|---|
| H | 肝 | D/W | 胆/胃 | LU,LI | 肺经/大肠经 |
| X | 心 | XC/DC | 小肠/大肠 | ST,SP | 胃经/脾经 |
| P | 肺 | PG/SJ | 膀胱/三焦 | HT,SI | 心经/小肠经 |
| S | 脾 | PC | 心包 | BL,KI | 膀胱经/肾经 |
| R | 肾 | — | — | PC,TE,GB,LR + CV,GV | 心包/三焦/胆/肝 + 任/督 |

### 3.2 强度 5 区间（全域统一）
L1 虚甚 [0,0.20) · L2 偏虚 [0.20,0.40) · L3 平 [0.40,0.60) · L4 偏实 [0.60,0.80) · L5 亢盛 [0.80,1.00]（高斯归一化 σ=0.42）

### 3.3 五阶段对齐（三因各自阶段语义）
| 内因（七情五段） | 外因（S1→S5） | 不内外因（p1→p5） |
|---|---|---|
| 刺激感应→脏腑响应→情绪涌现→情绪劫持→病机固着 | 感→侵→传→化→损 | p1损→p2滞→p3虚→p4变→p5败 |

### 3.4 三因知识建模
**内因·七情**：`i∈{怒喜悲思恐忧惊}`；五脏主情（肝怒/心喜/肺悲/脾思/肾恐）+ 次主（忧→肺、惊→心肾）；归因判据（怒=有形外归因 α+1；悲=无形内归因 α−1）；每情：病机/症状集/舌脉/传变序列/治则/方/穴/经脉/经文。

**外因·六淫**：`k∈{风寒暑湿燥热}`；签名 `E_k=(λ有形性, α三维归因[波动/能量/物质], s强度)`——风(λ0.13,波动向,s0.75)、寒(0.45,能量降,0.70)、暑(0.40,能量升散,0.80)、湿(0.85,物质向,0.65)、燥(0.60,津亏,0.55)、热(0.35,能量升,0.85)。入册判据：邪之三条件（共生/主宰/所用 全过）。

**不内外因**：`I1饮食12/I2劳逸10/I3外伤10/I4虫兽8/I5中毒10/I6医过10/I7先天8`（68细目）；板块-脏腑亲和 `A_ji`（I1→脾/胃0.9、I2→肾/脾0.8、I5→肝/胃0.8、I7→肾0.9…）；内经锚点（饮食自倍/五劳所伤/缪刺恶血/疏五过/天癸肾气…）。

## 四、引擎算法（engine.py）

1. **输入清洗**：文本按标点粗切 + 噪声片段（时序/量词）滤除；支持结构化 `symptoms=[…] + trigger=…`
2. **三因门类评分**：门类特异诱因词一票 +2.0（"生气/受凉/暴饮暴食"…），知识库症状命中逐条 +1.0
3. **类内候选排序**：每门类取 Top-3 候选（内因7情/外因6淫/板块7）
4. **归一置信**：三因分数归一 → 主判（内因/外因/不内外因）+ 各门类置信
5. **辨证卡输出**：病因/病机/阶段序列/治则/方/穴/经脉/经文 + 简明文本报告（`report()`，面向终端与 LLM 注入）
