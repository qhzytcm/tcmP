# 中医中药系列教材编写 — 四层 Agent × 六阶段 × 八域映射 多智能体工作流

> **定位：** 本文档定义「系列教材产品」的六阶段生产流程，非软件开发流程。
> 四层 Agent 在每个阶段承担不同角色、行使不同权力、遵循不同的交互方向。
> 八域（八枝）深层映射中医药大学八类院系设置及对应的毕业生行业工作岗位。

## 一、八域映射：院系 → 知识域 → 行业岗位

> 八域不是随意划分的学科分类，而是**三层映射**的产物：
> 中医药大学的院系设置 → 该院系覆盖的知识域 → 该院系毕业生的行业工作岗位。

| 枝号 | 院系 | 领域主编 | 覆盖教材数 | 典型学科 | 毕业生核心岗位 |
|:--:|------|------|:--:|------|------|
| **枝1** | 基础医学院 | 领域主编·基础 | 8 | 中基、诊断、内经、各家学说、医史文献 | 高校教师、科研院所研究员、基础教育师资 |
| **枝2** | 中药学院 | 领域主编·中药 | 14 | 中药学、炮制、药理、鉴定、制剂、资源、栽培 | 医院药师、药企研发/质检、药监执法、中药种植技术 |
| **枝3** | 针灸推拿学院 | 领域主编·针灸 | 8 | 针灸学、推拿学、经络学、实验针灸、针刀 | 针灸科医师、推拿师、康复治疗师、运动医学 |

| **枝8** | 管理/人文学院 | 领域主编·管理 | 8 | 中医管理、卫生经济、医古文、中医英语、中医药传播 | 医院管理岗、卫生行政、中医药文化国际传播、医药企业 |

### 为什么是"深层映射"

```
中医药大学院系设置 ──→ 决定了教材的知识域划分
         │
         └──→ 院系的培养方案 ──→ 决定了教材的四层级（本/硕/博/博后）
                  │
                  └──→ 毕业生的行业岗位 ──→ 决定了教材的能力目标
                           │
                           └──→ 岗位的实际需求 ──→ 决定了教材的应用场景设计
```

**例子：** 枝2（中药域）的《中药学》教材——
- 院系：中药学院开设
- 培养方案：本科必修（U3-U4 学期）→ 硕士深化（M1-M2）→ 博士专题（D1-D3）
- 行业岗位：医院药师（需掌握临床用药）← 这就要求教材不能只讲药性，必须讲"临床应用"和"配伍禁忌"
- 应用场景：年轻药师在药房调配处方时遇到的真实问题 ← 教材案例应取材于此

## 二、六阶段教材生产流程

### 阶段一：需求分析（Needs Analysis）

> **阶段目标：** 明确"为谁编写、为何编写、编到什么程度"。
> **交互方向：L1 → L2 → L3 → L4（Top-Down 约束传递）**
> **核心问题：** 该教材培养的学生将来在什么岗位上、做什么工作、需要什么能力？

```
┌──────────────────────────────────────────────────────────────┐
│  L1 行业主编                                                  │
│  ├─ 制定系列教材总体目标与定位                                 │
│  ├─ 确定四层级（本/硕/博/博后）培养体系的衔接逻辑              │
│  ├─ 签批八域的领域边界（确认八个领域主编的覆盖范围）            │
│  └─ 产出：《系列教材总体规划纲要》                             │
│                         │                                     │
│          ┌──────────────┼──────────────┐                      │
│          ▼              ▼              ▼    (8个L2并行)       │
│  L2 领域主编（各域独立执行）                                   │
│  ├─ 调研本域对应院系的培养方案和行业岗位需求                    │
│  ├─ 确定本域知识边界和能力矩阵                                 │
│  │   例：中药域 → 岗位调研 → 医院药师需要"处方审核能力"        │
│  │        → 落实到《中药学》必须增加"临床用药安全性"章节       │
│  ├─ 评估本域内各学科的层级归属（哪些放本科、哪些放硕博）        │
│  └─ 产出：《XX域需求分析报告》                                 │
│                         │                                     │
│          ┌──────────────┼──────────────┐                      │
│          ▼              ▼              ▼    (N个L3并行)       │
│  L3 学科主编（各学科独立执行）                                  │
│  ├─ 调研该学科在行业岗位中的具体应用场景                        │
│  ├─ 梳理知识点清单 + 前序依赖关系                              │
│  ├─ 确定知识点在"认知觉醒路径"上的位置（见阶段五）              │
│  └─ 产出：《XX学科需求分析报告》+《知识点依赖图》              │
│                         │                                     │
│          ┌──────────────┼──────────────┐                      │
│          ▼              ▼              ▼    (N个L4并行)       │
│  L4 章节作者                                                  │
│  ├─ 调研目标读者的认知水平（问卷/访谈/前测）                    │
│  ├─ 收集典型学习难点和常见误解                                 │
│  ├─ 从一线教学场景中采集案例素材                               │
│  └─ 产出：《第X章目标读者分析》+《素材采风笔记》               │

```

### 阶段二：体系设计（System Design）

> **阶段目标：** 确定"知识如何组织、章节如何编排、层级如何衔接"。
> **交互方向：L1 → L2 → L3 → L4（规范下发 + 逐层细化）**

```
┌──────────────────────────────────────────────────────────────┐
│  L1 行业主编                                                  │

│  │   安全红线（如涉及民族医药的表述规范）                      │
│  ├─ 确定四层级之间的知识递进逻辑和断层检查规则                  │
│  ├─ 审核并签批八域的编写轮次计划                               │
│  └─ 产出：《编写规范 v1.0》+《四层级衔接审查标准》            │
│                         │                                     │
│          ┌──────────────┼──────────────┐                      │
│          ▼              ▼              ▼                      │
│  L2 领域主编                                                  │
│  ├─ 依据行业岗位能力矩阵，设计本域的知识体系架构                │
│  ├─ 确定域内各学科的编排顺序和跨学科前序依赖链                  │
│  ├─ 为每门学科标注教学层级（本/硕/博/博后）+ 必修/选修         │

│                         │                                     │
│          ┌──────────────┼──────────────┐                      │
│          ▼              ▼              ▼                      │
│  L3 学科主编                                                  │
│  ├─ 设计学科内章节结构（篇→章→节，不超过四级目录）              │
│  ├─ 为每章制定教学目标矩阵（知识目标·能力目标·素养目标）        │

│  └─ 产出：《XX学科章节结构设计》+《教学目标矩阵》+            │

│          ┌──────────────┼──────────────┐                      │
│          ▼              ▼              ▼                      │
│  L4 章节作者                                                  │
│  ├─ 接收章节设计框架                                           │
│  ├─ 将教学目标细化为每节的知识点排列                            │
│  ├─ 设计本节的认知递进路径（导入→讲解→例题→练习→小结）         │

### 阶段三：内容编写（Content Writing）

> **阶段目标：** 产出全部教材的章节草稿。
> **交互方向：L4 主力执笔 ← L3 实时指导 ← L2 跨域协调 ← L1 例外仲裁**
> **L4 是此阶段的绝对主角。**

```
┌──────────────────────────────────────────────────────────────┐
│  L4 章节作者（核心执行层）                                     │
│  ├─ 按《第X章教学详案》逐节撰写                               │
│  ├─ 每节包含：导入案例→知识讲解→例题演示→练习→本节小结        │
│  ├─ 标注需要插图的位置和插图说明                               │
│  ├─ 编写配套习题（基础60% + 综合30% + 拓展10%）               │
│  ├─ 自检清单：概念准确性、例题正确性、语言流畅度               │
│  └─ 产出：《第X章草稿 v1.0》→ 提交到 Kanban「writing」队列   │
│                                                                  │
│  L3 学科主编（指导层）                                           │
│  ├─ 实时解答 L4 的学科疑难（如"这个知识点放在第3节还是第5节"）  │
│  ├─ 协调本学科内各章之间的交叉引用和术语统一                     │
│  ├─ 检查各章的认知递进是否平滑                                   │
│  └─ 每日巡视本学科 Kanban 队列，优先处理阻塞项                   │
│                                                                  │
│  L2 领域主编（协调层）                                           │
│  ├─ 处理跨学科内容的归属问题（如"中药药理实验结果"属于           │
│  │   《中药学》还是《中药药理学》）                               │
│  ├─ 审核跨学科术语使用的一致性                                    │
│  └─ 仅在 L3 上报时介入，不主动干预                               │
│                                                                  │
│  L1 行业主编（仲裁层）                                           │
│  ├─ 处于半休眠状态                                               │
│  ├─ 仅当出现 L2 无法裁决的跨域争议时介入                         │
│  │   例：枝2(中药域)与枝6(结合域)对"中药安全性分级标准"有分歧   │
│  └─ 介入方式：召见两个 L2 → 听证 → 裁决 → 记录为判例             │
└──────────────────────────────────────────────────────────────┘
```

**编写阶段的并行策略：**

```
可并行的：
  不同枝叶下的学科 → 完全并行（如枝2中药学 与 枝3针灸学 同时编写）
  同一学科下无前序依赖的章 → 并行（如方剂学各论中解表剂与清热剂同时编写）

不可并行的（串行链）：
  核心链：中基 → 诊断 → 中药 → 方剂 → 内科
  学科内：总论 → 各论（因为各论依赖总论定义的框架）
```

### 阶段四：审核评阅（Review）

> **阶段目标：** 逐层审核，确保教材质量达标。
> **交互方向：L4 自审 → L3 学科审 → L2 领域审 → L1 终审（Bottom-Up 逐层上报）**
> **各层审核维度完全不同。**

```
┌──────────────────────────────────────────────────────────────┐
│  Step 1: L4 自审（作者自查）                                   │
│  审核维度：概念准确性 | 例题答案正确性 | 格式规范 | 插图标注   │
│  通过标准：全部自检项通过 → 标记为「待L3审核」                 │
│                         │                                     │
│                         ▼                                     │
│  Step 2: L3 学科审（同行评审）                                 │
│  审核维度：                                                   │
│    · 科学性 —— 知识点是否准确、无过时信息                      │
│    · 教学适用性 —— 难度是否适合目标学段、认知递进是否合理       │
│    · 章节一致性 —— 与前后章的衔接是否流畅、无重复或矛盾         │
│    · 习题质量 —— 习题是否覆盖教学目标、答案是否正确              │
│  审核结论：通过 / 有条件通过（附修改清单）/ 驳回重写             │
│                         │                                     │
│                         ▼                                     │
│  Step 3: L2 领域审（跨学科一致性审核）                         │
│  审核维度：                                                   │
│    · 跨学科一致性 —— 同一概念在本域不同学科中定义是否统一        │
│    · 岗位匹配度 —— 教材内容是否符合本域对应行业岗位的需求        │
│    · 层级衔接 —— 本/硕/博内容是否有效递进而非简单重复            │
│    · 术语规范 —— 域内术语使用是否符合域术语表                    │
│  审核结论：通过 / 有条件通过 / 驳回                              │
│                         │                                     │
│                         ▼                                     │
│  Step 4: L1 终审（全局合规 + 四层级衔接审查）                   │
│  审核维度：                                                   │
│    · 全局术语一致性 —— 跨域术语是否统一                         │
│    · 四层级衔接 —— 本科→硕士→博士→博后的知识递进是否完整         │
│    · 安全合规 —— 民族医药表述、人体图示、临床试验数据引用          │
│    · 思政与价值观 —— 是否蕴含正确的医学伦理和价值观              │
│  审核结论：签批通过 → 进入「教学应用」阶段                       │
│            有条件通过 → 退回 L2 督办修改                         │
│            驳回 → 驳回原因记录为全局判例                         │
└──────────────────────────────────────────────────────────────┘
```

**驳回与升级机制：**

```
L4 → L3：L3 驳回到 L4（修改后重新提交，限 2 次迭代）
  若第3次仍不通过 → 升级到 L2 裁定（可能更换 L4 作者）

L3 → L2：L2 驳回到 L3（域内重新协调，限 2 次迭代）
  若第3次仍不通过 → 升级到 L1 仲裁

L2 → L1：L1 终审驳回 → 直接记录为「全局判例」
  判例对后续所有教材具有约束力
```

**Cursor 3.0 在此阶段的作用：**

#### 觉醒触发的教材设计原则

```
原则1："跳一跳，够得着"
  教材不应平铺直叙所有知识，而应在关键节点设置"认知缺口"——
  让学生感到"这里缺了什么"，从而驱动自主探索。

原则2："先迷失，再找到路"
  阶段Ⅲ（整合应用）的案例设计不应给出完美诊疗路径。
  应呈现初诊→误判→反思→修正的完整过程，让学生在"迷失"中学会临床思维。

原则3："同一知识点，不同深度"
  例如"麻黄汤"：
    阶段Ⅰ → 记住：麻黄汤 = 麻黄+桂枝+杏仁+甘草，发汗解表
    阶段Ⅱ → 理解：为何麻黄配桂枝？君臣佐使如何分工？
    阶段Ⅲ → 应用：什么情况下麻黄汤不适用？如何加减？
    阶段Ⅳ → 批判：麻黄汤"峻汗"之说是否有文献依据？现代药理如何解释？
    阶段Ⅴ → 精通：临床上麻黄汤的最佳适应证判断、剂量安全范围、替代方案
```

#### 四层 Agent 在教学应用阶段的角色

```
L4 章节作者：
  接收使用反馈 → 标记自己负责章节的问题 → 提出修改预案
  （此时 L4 不能自行修改，需等待阶段六的统一修订指令）

L3 学科主编：
  汇总本学科的反馈数据 → 识别高频问题 → 判断是否需要结构性调整
  （如"第3章和第5章的知识点顺序需要调换"属于结构性调整）

L2 领域主编：
  分析反馈中的"岗位匹配度"问题 →
  "为什么毕业生反馈教材学的用不上、临床用的没学过？"
  → 调整域内知识重点的分配

L1 行业主编：
  汇总八域的反馈 → 识别跨域共性问题 →
  如"所有临床学科都反馈学生不会写病历"
  → 考虑是否需要增设「中医临床文书写作」新教材
```

### 阶段六：修订迭代（Revision）

> **阶段目标：** 基于教学应用反馈进行有组织的修订，并保持与行业需求的动态匹配。
> **交互方向：L1 发起修订令 → L2 制定域修订计划 → L3 批改 → L4 执笔修改**

```
┌──────────────────────────────────────────────────────────────┐
│  L1 行业主编（修订令签发）                                     │
│  ├─ 审阅阶段五的全局反馈报告                                   │

│  │   A类：勘误修订（事实错误 → 立即发布）                      │
│  │   B类：常规修订（基于反馈的优化 → 学期末集中发布）          │
│  │   C类：结构修订（章节目录调整 → 下一版发布）                │
│  │   D类：新增修订（行业新需求 → 下个编写周期）                │
│  └─ 产出：《第N次修订令》                                     │
│                         │                                     │
│          ┌──────────────┼──────────────┐                      │

│  ├─ 认领本域涉及的全部修订项                                   │
│  ├─ 区分修订优先级（A类立即/B类排期/C类规划）                  │
│  ├─ 评估修订对跨学科一致性的影响                               │
│  └─ 产出：《XX域修订计划》                                    │
│                         │                                     │
│          ┌──────────────┼──────────────┐                      │
│          ▼              ▼              ▼                      │

│  ├─ 将修订项拆分为章节级修改任务                               │
│  ├─ 通过 Kanban 分配给对应的 L4                                │
│  ├─ 对修改后内容进行复审                                       │

## 三、六阶段交互方向总览

```
阶段一（需求）  L1 ──→ L2 ──→ L3 ──→ L4   Top-Down 约束传递

```
