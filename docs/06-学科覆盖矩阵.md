# 06 · 学科覆盖矩阵（Subject Coverage Matrix）

> 用途：登记 120 门学科教材的**技能覆盖状态**，作为"缺口学科"识别与编写调度的唯一依据。
> 维护规则：由各领域主编（L2）在签发学科大纲时更新本表对应行；状态由 `uncovered → covered` 只能由 L2 变更。
> 配套技能目录：`skills/CATALOG.md`
> 最近更新：2026-10-20（D01 领域）

## 状态图例

| 状态 | 含义 | 判据 |
|:-:|---|---|
| `covered` | 已覆盖 | 学科大纲已签发 + 配套技能已登记 catalog |
| `in-progress` | 编写中 | 大纲已签发，章节卡已发放，正文未全部通过 G1 |
| `uncovered` | 未覆盖 | 无学科大纲 / 无配套技能 |

> 注意：`covered` ≠ 教材已出版。covered 指"该学科具备可执行的编写规范与技能支撑"；教材完成度见各领域《进度简报》。
