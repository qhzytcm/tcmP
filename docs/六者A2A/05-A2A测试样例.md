```

您今年48岁，身体的"肾水"（可以理解为身体的根基之水、阴液）开始自然变少，
这是每个女性到这个时候都会经历的阶段（中医叫"天癸将竭"）。
肾水少了，压不住上面的"心火"，火就往上飘，扰得心神不安——

【药怎么吃？】
给您开了7天中药，一天一剂，午饭后和睡前1小时各喝一次。
```

## 四、DDG 场方程样例（疾病诊断图谱场）

> DDG = Disease-Diagnosis Graph（病证诊断图谱场）：症状观测场 ψ → 证候诊断场 Φ → 干预场 Ψ。
> 场方程将"四诊证据的聚合"形式化为势场叠加（与平台 Embedding/图谱引擎同构）。

### 4.1 场结构

| 场 | 符号 | 载体 | 物理类比 |
|---|---|---|---|
| 症状观测场 | ψ(x) | 四诊证据（症状/舌/脉/械查） | 观测值分布 |
| 证候诊断场 | Φ(x) | 病证单元（L0 锚点） | 势场（波谷=证候吸引子） |
| 干预场 | Ψ(x) | 方药/针/调摄 | 调控算符作用 |

### 4.2 场方程（样例片段）

```
# 证候势场: 症状证据对证候单元 s 的势贡献叠加
Φ_s = Σ_i  w_i · K(ψ_i, s) · g_i(t)          # K=语义核(图谱边), g=时序衰减

# 样例: 心肾不交证(SA61) 势值计算
Φ(心肾不交) = 0.30·K(失眠, 不寐)              # 主诉: 入睡困难
            + 0.22·K(潮热盗汗后半夜, 阴虚内热)  # 典型阴虚征
            + 0.18·K(舌红少苔, 阴虚)           # 舌象
            + 0.15·K(脉细数, 阴虚内热)          # 脉象(要素分离后)
            + 0.10·K(心烦易怒, 心火亢)          # 情志
            + 0.05·K(围绝经期/48岁, 天癸竭)     # 年龄场 g(t)
            = 0.82                              # → 势谷(主诊断), 置信度0.82

# 竞争证候势（鉴别）:
Φ(心脾两虚) = 0.31  Φ(肝郁化火) = 0.44  Φ(心胆气虚) = 0.18
# 鉴别要点: 肝郁化火以情绪诱发+口苦为主(本例外热盗汗+舌红少苔偏阴虚), 排除

# 干预场（调控算符 U）:
Ψ_方药 = U(交泰丸) ∘ U(天王补心丹) |φ⟩      # 引火归元⊗滋阴安神
ΔΦ_after_7d = E[Φ(心肾不交) | 干预后] → 0.35  # 预期7日势降(可复诊验证)

# 图谱闭环: 复诊 outcomes → 更新 K(症状,证候) 边权 → 场方程自进化
```

### 4.3 与平台的映射

| 场方程项 | 平台实现 |
|---|---|
| ψ 观测场 | 四诊结构化（病历 Schema tcm 节）+ 械查参数 |
| K 语义核 | 病证图谱边权 / semantic_search 余弦核 / TF-IDF |
| g(t) 时序场 | 年龄·天癸·病程阶段算子 |
| Φ 势谷选择 | bianzheng 证候候选 + 置信度排序 |
| U 干预算符 | 方剂-证候疗效矩阵（图谱回流学习） |
| ΔΦ 复诊验证 | outcomes.follow_up_result 闭环信号 |
