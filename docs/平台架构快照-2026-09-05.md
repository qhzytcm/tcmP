## 四、知识层（KG · ICD-11 · Embedding 引擎）

**1) 病证知识图谱（KG）**：现落地 103 病证单位（kg/samples 7 JSON）；远期规划 ~60,000 节点 / ~80,000 关系、三层粒度（L0 病证单位=Agent 最小推理单元）。DSU 结构：病侧（病名+ICD-11 编码+分子靶点）× 证侧（证候+六经八纲）× 临床（方/穴/调护）——诊断流程锚病侧、辨证流程锚证侧，收敛同一 DSU。

**2) ICD-11 编码桥接 v2.2**：

| 通道 | 说明 |
|---|---|
| 内网 API | 192.168.0.111:8080（WHO whoicd/icd-api 容器，MMS 2026-01 en+zh，中文搜索） |
| 本地 db | data/icd11_mms.db（31,838 实体，release 2026-01）→ Foundation ID 标准化 |

103 单位已标注：74 标准编码 + 29 实体 ID（字段 disease_side.icd11_*）；华为云公网访问不到内网 API 时中文自动降级英文。

**3) Embedding 引擎 v3.0**（scripts/tcm_embed.py + 四个 API 端点，论著 ESWA 2025 "Decoding the mind: A RAG-LLM on ICD-11" 落地）：
- 管线：Document→向量→余弦 Top-K→上下文→LLM 诊断；技术 = TF-IDF 字符 n-gram + SQLite FTS5 + RRF 融合（k 倒数排序）
- 效果：103 DSU 检索 <10ms、零 token；Top-5 上下文 ~1.5K token（对比全库 31K/次 ↓95%）；实测 恶寒发热无汗→CA00 普通感冒·麻黄汤(0.52)、口苦咽干→肝胆湿热证
- 升级路径：BGE-small-zh-v1.5 语义向量（ModelScope 下载，接口已预留 _bge）；持久化 vectors.npy+docs.json、多路召回 RRF 四路融合、Agent tool 注入
