# tcmP 视频生成工具链 —— 条件（文本）→ 结果（课程讲解视频）

> 版本：v1.0 | 2026-08-20 | 输入：内经原文+注释转写（HDNJ 162 篇 / wy30 已有）；输出：课程讲解视频（L0/L1/L2/L3 四级）

## 一、总架构（七段流水线）

```
[条件] 文本(原文+注释转写 Excel)
   │ ① 文本解析
   ▼
结构化语料（原文-段/注释-段/理解-段 + 时间戳）
   │ ② 讲稿生成（LLM）
   ▼
八段讲稿（篇名破题/原文精读/疑难注释/独到理解/思维模型/临床启示/案例印证/下篇预告）
   │ ③ 语音合成（TTS）
   ▼
讲解音频（MP3/WAV + 逐句时间戳）
   │ ④ 字幕生成
   ▼
SRT/ASS 字幕（双语文言+白话）
   │ ⑤ 画面制作
   ▼
视觉流（PPT 页 / 思维模型图 / 原文大字卡 / 案例卡）
   │ ⑥ 视频合成
   ▼
MP4 成片（音频+字幕+画面，HLS 分片）
   │ ⑦ 平台发布
   ▼
[结果] tcmP 课程页面（视频+PPT+资料+案例四件套）
```

## 五、最小可行流水线（MVP：1 集/小时）

```
python scripts/video_pipeline.py --source HDNJ音频理解(2).xls --chapter 上古天真论
  1. 解析该篇转写（原文/注释/理解段）
  2. hermes 生成八段讲稿（1200-1500 字）
  3. edge-tts 逐段合成音频（晓晓音色）
  4. 转写时间戳 → SRT 字幕
  5. python-pptx 生成 12 页画面（原文大字卡/理解金句卡/模型图）
  6. moviepy 合成 MP4（每页 4-8 秒 + 音频对齐）
  7. ffmpeg 转 HLS 分片 → 输出到 Nginx 课程目录
```
