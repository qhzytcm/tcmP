## 五、怎么看

```powershell
# 概览（全部板）
hermes kanban boards list

# 单板详情
hermes kanban --board tcm-domain-d01 stats
hermes kanban --board tcm-domain-d01 list
hermes kanban --board tcm-domain-d01 runs <task-id>     # 单卡运行史/耗时/结论
hermes kanban --board tcm-domain-d01 log  <task-id>     # 运行日志

# 只读预演（安全）
hermes kanban --board tcm-domain-d01 dispatch --dry-run
```
> 注意：`dispatch`（不带 `--dry-run`）会**真实拉起 worker**；`assign`/`create` 作用于「当前板」，跨板必须写 `--board <slug>`。
