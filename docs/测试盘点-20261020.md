# tcmP 测试盘点（2026-10-20）

> 口径：`pytest --collect-only` 收集 + 全量实跑各一次（同日）。
> 结论：**122 个用例 / 100 个测试函数 / 11 个模块，全绿（0 fail / 0 error / 0 skip），耗时 13.2s**。

## 一、怎么跑

```powershell
cd C:\Users\DELL\tcmP
$env:PATH = "C:\ProgramData\Anaconda3;C:\ProgramData\Anaconda3\Scripts;" + $env:PATH
python -m pytest -q --tb=no          # 期望 122 passed，约 13s
```

- `pytest.ini` 已固定：`testpaths = constitution/tests tests`、`addopts = -q -p no:anyio`。
  **`-p no:anyio` 不可去掉**：本机 anyio 3.5.0 的 pytest11 插件在加载阶段就挂起（表现为 `python -m pytest` 无输出卡死）。
- 出证据用：`--junitxml=%TEMP%\tcmp-junit.xml`，再解析 `testsuites.testsuite` 的 `tests/failures/errors/skipped`。
- **不要**写 `& "<venv>\python.exe" -m pytest`：`&` 会被终端守卫判为后台符号直接拒执行；改把目录前置到 `PATH`。
