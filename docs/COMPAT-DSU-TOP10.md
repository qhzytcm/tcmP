## 0. 什么是"兼容性思维流"

**定义**：西医"病"的确定性（诊断标准明确、监测指标客观）与中医"证"的确定性（证候标准明确、方证对应、疗效确切）彼此兼容、互相补齐缺口的临床思维范式。其价值公式：

```
兼容性价值 = 西医确诊带来的「诊断确定性 + 客观监测」
           ⊕ 中医辨证带来的「病因机制解释 + 症状改善 + 治本疗效」
           − 单侧思维的必然代价（西药不良反应 / 辨证无指标可证）
```

**四条件判定（全部命中才入选）**：

| 条件 | 病侧（西医） | 证侧（中医） |
|:----:|:---|:---|
| ① 明确 | 疾病诊断明确（有指南/ICD-11编码） | 证候辨别肯定（有证候标准/主症规范） |
| ② 缺口 | **直接病因不确定**（原发性/特发性/机制复杂） | **病因缺乏直接化验指标佐证**（辨证依赖症状+舌脉） |
| ③ 代价 | **药物治疗必然引起不良反应** | **方剂疗效明显持久，却无对应疗效评价参数** |
| ④ 增益 | 病证兼容后，患者**生命质量利益最大化**（症状控制+减西药负荷+治本） | 同左 |

**一句话**：西医给了我们"确定地知道是什么病、怎么监测"，中医给了我们"确定地知道怎么治、真能治好"，双方各自的"不能"恰好被对方补上——这就是兼容性思维流。

## 2. Agent-Loop 通用骨架（平台级六步循环）

所有 DSU-Agent 共享同一条循环管线，差异只在每步的"领域算子"：

```
┌─ ①Perceive 感知 ─────────────────────────────┐
│  患者主诉/症状/舌脉 + 客观数据流(血压/血糖/手环/化验单) │
└──────────────┬───────────────────────────────┘
               ▼
┌─ ②Retrieve 检索（tcm_embed.py: TF-IDF+FTS5+RRF, <10ms, 零token）┐
│  diagnose(症状)→病侧锚定 │ bianzheng(症状)→证侧锚定 │ 两端收敛同一DSU │
└──────────────┬──────────────────────────────────────────────────┘
               ▼
┌─ ③Reason 辨证推理（规则积分 + 医圣人格LLM精修，仅Top-K注入~800token）┐
│  证候积分卡：主症权重×缺失症状→证型置信度 │ 客观指标↔证候双通道互证 │
└──────────────┬───────────────────────────────────────────────────┘
               ▼
┌─ ④Decide 决策处方（方证对应 + 西药协同）────────────────────┐
│  推荐方剂/加减/针灸/食疗 │ 西药剂量联动建议 │ 危险信号→转诊 │
└──────────────┬──────────────────────────────────────────────┘
               ▼
┌─ ⑤Act 执行 + 安全护栏（六者协同）──────────────────────────┐
│  医者Agent开方 │ 药者Agent审方(十八反/十九畏/西药相互作用) │ 械者Agent接监测设备 │
│  患者Agent执行 │ 规者/法者Agent合规审计 │ 不良反应哨兵 │
└──────────────┬──────────────────────────────────────────────┘
               ▼
┌─ ⑥Feedback→Learn 疗效闭环（CI/CD进化信号）────────────────┐
│  客观指标变化 + 证候积分变化 → 双终点判定 → 日志入库 → 图谱更新 → Agent调优 → 自动上线 │
└──────────────┬──────────────────────────────────────────────┘
               ▼
        回到 ①（每次随访=一次新循环）
```

**双通道互证原则（本设计的灵魂）**：客观指标通道（西医的确定性）与证候积分通道（中医的确定性）并行采集、交叉验证——**用客观指标给证候"补参数"，用证候积分给指标"补解释"**。这正是为"兼容性缺口"（条件②③）量身定制。

## 3. Top10 逐单元 Agent-Loop 设计原则

### DSU-1 原发性高血压 · 肝阳上亢证 → 天麻钩藤饮（BA00）

| 兼容性缺口 | 内容 |
|:---|:---|
| 病侧② | 原发性高血压直接病因不明（占95%，RAAS/交感/钠水多机制叠加） |
| 病侧③ | 降压药必然不良反应：CCB踝部水肿、ACEI咳嗽、利尿剂电解质紊乱；**降压过速→盗血→心梗灶扩大**（用户案例） |
| 证侧② | 肝阳上亢证无直接化验指标（头晕胀痛/面红/脉弦数全为症状学） |
| 证侧③ | 天麻钩藤饮平肝息风疗效明确持久，但"息风"无评价参数 |

**Agent-Loop 设计原则：血压-证候双通道闭环**
1. **Perceive**：家用血压计/ABPM 自动入库（客观通道）+ 眩晕/面红/心烦症状打卡（证候通道）——双通道并行，缺一不可；
2. **Retrieve**：以"头晕+面红+脉弦"命中肝阳上亢证 DSU，收敛 BA00；
3. **Reason**：肝阳上亢积分卡（主症权重：头晕胀痛0.3/面红目赤0.25/心烦易怒0.2/耳鸣0.15/失眠0.1）×舌脉修正；与血压分级(1-3级)交叉验证——收缩压≥160 且积分≥0.6 → 高置信；
4. **Decide**：血压梯度×证候积分 → 中西药配比矩阵（如：1级+实证→天麻钩藤饮为主、西药小剂量；3级+靶器官损害→西药为基+中药为辅）；
5. **Act+护栏**：**降压速率哨兵**——单次随访降幅>20mmHg 或出现头晕加重/肢麻/胸闷即告警（防盗血事件）；天麻钩藤饮不可骤停；仲景/思邈人格审核方义；
6. **Feedback→Learn**：4周双终点=证候积分降幅(≥50%有效)+血压达标率(<130/80)；西药减量成功案例回灌图谱 → 生成"西药减量阶梯方案库"。
7. **多快好省廉映射**：快=血压自动感知免录入；省=零token辨证、家庭监测替代住院；好=证候积分补"息风无参数"缺口；廉=长期西药减量降终身用药成本。

### DSU-2 高血压性腔隙性脑梗塞 · 肝热生风证 → 羚羊钩藤饮（8B22系）🆕

| 兼容性缺口 | 内容 |
|:---|:---|
| 病侧② | 腔隙性脑梗塞多机制（小动脉玻璃样变/微栓塞），直接病因链复杂 |
| 病侧③ | 溶栓时间窗窄（<4.5h）；长期抗血小板/他汀出血风险；血压管理两难（过高再出血、过低加重缺血） |
| 证侧② | 凉血清热无对应化验指标（热象靠舌红绛/脉弦数判断） |
| 证侧③ | **羚羊钩藤饮凉肝息风——既显著又根治（用户临床实证），却无"凉血"化验指标、无"息风"评价参数** |

**Agent-Loop 设计原则：神经功能-息风疗效闭环（旗舰单元）**
1. **Perceive**：NIHSS 评分+改良Rankin量表（客观通道）+ 神昏/舌强语謇/肢麻/舌红绛（证候通道）+ 影像(腔隙灶位置)标注；
2. **Retrieve**：新增 DSU 入库后以"半身不遂+舌强+苔黄+脉弦数"锚定肝热生风证；
3. **Reason**：急性期(≤4.5h)西医溶栓优先原则硬编码；恢复期肝热生风积分≥0.6 → 羚羊钩藤饮指征；**影像-证候关联**：基底节/放射冠腔隙灶 ↔ 肝风内动积分建模；
4. **Decide**：分期处方——急性期溶栓/取栓+羚羊钩藤饮凉肝息风防再发；恢复期羚羊钩藤饮（加菖蒲/郁金豁痰开窍、地龙/全蝎通络）；血压管理"两难解"：羚羊钩藤饮平肝降压与西药CCB协同而非叠加冲击；
5. **Act+护栏**：抗血小板出血风险哨兵（黑便/瘀斑/INR）；血压骤降禁忌（防梗死灶扩大）；吞咽评估防呛咳；
6. **Feedback→Learn**：**代理指标法补双缺口**——"凉血"以炎症/凝血代理（CRP、纤维蛋白原、D-二聚体下降）；"息风"以 NIHSS 改善率+mRS 降级代理；双终点达标 → 回灌图谱；长期随访积累"羚羊钩藤饮防复发/促康复"循证队列。
7. **多快好省廉映射**：好=代理指标法补"凉血无化验指标、息风无评价参数"双缺口（本单元核心创新）；廉=恢复期中医主导降低再住院与残疾护理成本；多=康复期方案可复用于缺血性脑卒中全谱系。

### DSU-3 2型糖尿病 · 阴虚燥热证 → 玉女煎/消渴方（5A11）

| 兼容性缺口 | 内容 |
|:---|:---|
| 病侧② | 胰岛素抵抗+β细胞衰竭机制复杂，"原发性"程度高 |
| 病侧③ | 磺脲类低血糖、二甲双胍胃肠道反应、SGLT2i泌尿系感染——降糖药不良反应"必然" |
| 证侧② | 早期无症状期（仅血糖高）"无证可辨"，阴虚靠舌红少津/脉细数 |
| 证侧③ | 玉女煎清胃滋阴疗效稳定，但"阴虚"无量化指标 |

**Agent-Loop 设计原则：血糖-阴虚双轨闭环**
1. **Perceive**：CGM 连续血糖+糖化血红蛋白（客观轨道）+ 舌象照片+口渴/五心烦热打卡（证候轨道）；
2. **Retrieve**："多饮+多食+消瘦+舌红" → 阴虚燥热证，收敛 5A11；
3. **Reason**：**无症状期以舌象为主线索**（舌红少津权重上调至0.4）——舌象AI(色/津液/裂纹)回归"阴虚程度分"；有症状期三多一少+脉象；
4. **Decide**：血糖分层×阴虚积分 → 玉女煎/增液汤+西药联动（如：HbA1c 7-8%+阴虚积分中→二甲双胍减量观察）；饮食运动处方联动；
5. **Act+护栏**：**低血糖零容忍哨兵**（CGM<3.9mmol/L 即时告警）；中药含糖/含鞣质与降糖药相互作用审查；
6. **Feedback→Learn**：3个月双终点=HbA1c 达标+阴虚积分下降；舌象图片→阴虚程度数据集积累 → 训练"阴虚量化模型"（补证侧③缺口）；并发症筛查提醒(眼底/尿微量白蛋白)。
7. **多快好省廉映射**：好=舌象AI给阴虚证补量化参数；快=血糖数据自动上传免手工；省=延缓并发症减少住院；廉=减西药剂量降终身药费。

### DSU-4 冠心病(稳定型心绞痛) · 气滞血瘀证 → 血府逐瘀汤（BA80.0）

| 兼容性缺口 | 内容 |
|:---|:---|
| 病侧② | 斑块形成/破裂事件不可预测，多因素叠加 |
| 病侧③ | 阿司匹林出血、他汀肌病/肝损、硝酸酯耐药+头痛 |
| 证侧② | 血瘀证无直接化验指标（舌紫暗/刺痛/脉涩全为症状学；血小板功能检测非临床常规） |
| 证侧③ | 血府逐瘀汤化瘀通络效佳持久，但"化瘀"无评价参数 |

**Agent-Loop 设计原则：胸痛日志-化瘀疗效闭环**
1. **Perceive**：心绞痛发作日记APP（时间/诱因/硝酸酯用量）+心电手环（客观通道）+ 舌下络脉照片/舌紫程度（证候通道）；
2. **Retrieve**："胸痛如刺+固定不移+舌紫" → 气滞血瘀证；
3. **Reason**：血瘀积分（刺痛0.3/固定0.25/舌紫0.2/舌下络脉迂曲0.15/脉涩0.1）；与心绞痛 CCS 分级交叉验证；
4. **Decide**：**西药二级预防（阿司匹林/他汀）不动摇**，血府逐瘀汤叠加活血通络；出血风险分层（HAS-BLED）决定叠加强度；硝酸酯用量>2次/周 → 升级评估；
5. **Act+护栏**：出血哨兵（黑便/瘀斑/牙龈出血）；血府逐瘀汤与抗凝药(华法林/DOAC)相互作用审查（药者Agent）；胸痛>20min 含服不缓解 → 急诊转诊（心梗警报）；
6. **Feedback→Learn**：三终点=硝酸酯周用量↓+发作次数↓+血瘀积分↓；"血小板聚集率/纤维蛋白原"作血瘀代理指标研究（补证侧③）；再狭窄预防案例回灌。
7. **多快好省廉映射**：好=硝酸酯用量客观化化瘀疗效；廉=减少支架术后再狭窄管理成本；快=发作日记自动统计。

### DSU-5 原发性失眠(慢性) · 心肾不交证 → 交泰丸/黄连阿胶汤（7A00）

| 兼容性缺口 | 内容 |
|:---|:---|
| 病侧② | 慢性失眠障碍直接病因不明（过度觉醒假说） |
| 病侧③ | 苯二氮䓬/非苯二氮䓬依赖、反跳、日间残留、认知损害——安眠药"必然"代价 |
| 证侧② | 心烦不寐/心悸/腰膝酸软全为症状学，无客观指标 |
| 证侧③ | 交泰丸交通心肾效佳，但"心肾不交"无量化参数 |

**Agent-Loop 设计原则：睡眠-心肾闭环（安眠药戒断引导）**
1. **Perceive**：智能手环睡眠分期（深睡/REM/觉醒次数，客观通道）+ 心烦/腰酸/舌尖红打卡（证候通道）+ PSQI 量表；
2. **Retrieve**："不寐+心烦+舌尖红+脉细数" → 心肾不交证；
3. **Reason**：心肾不交积分（心烦不寐0.3/心悸0.2/腰膝酸软0.2/五心烦热0.15/舌尖红0.15）；与睡眠效率(<85%)交叉验证；
4. **Decide**：交泰丸（黄连清心火+肉桂引火归元）+ CBT-I 认知行为干预 + **安眠药阶梯减量**（每2周减1/4片，戒断方案库驱动）；
5. **Act+护栏**：**撤药综合征哨兵**（焦虑/心悸/反跳失眠预警→放慢减量）；日间嗜睡监测（跌倒风险，老年患者）；与抗抑郁药相互作用审查；
6. **Feedback→Learn**：PSQI 降≥3分 或 睡眠效率↑10%为有效；安眠药减量成功路径沉淀为"戒断方案库"复用；手环数据→"心肾不交"客观化研究（补证侧③）。
7. **多快好省廉映射**：好=手环分期补"心肾不交无参数"缺口；省=摆脱安眠药依赖降长期成本；快=睡眠分期自动分析免日记。

### DSU-6 偏头痛(无先兆) · 肝阳上亢证 → 天麻钩藤饮/川芎茶调散（8A80）

| 兼容性缺口 | 内容 |
|:---|:---|
| 病侧② | 三叉神经血管学说+皮质扩布抑制，直接病因不明 |
| 病侧③ | 曲普坦心血管风险（禁用于缺血性心脏病）；NSAIDs 药物过度使用性头痛(MOH)反跳 |
| 证侧② | 肝阳上亢证无客观指标（眩晕/目赤/脉弦） |
| 证侧③ | 天麻钩藤饮/川芎茶调散预防发作效佳，但"息风"无评价参数 |

**Agent-Loop 设计原则：发作日记-息风预防闭环**
1. **Perceive**：头痛日记APP（发作时间/强度VAS/诱因/止痛药用量，客观通道）+ 眩晕/目赤/烦躁打卡（证候通道）；
2. **Retrieve**："偏头痛+眩晕+脉弦" → 肝阳上亢证（少阳经定位由仲景人格加持）；
3. **Reason**：肝阳上亢积分；与发作频率(≥4次/月=慢性化)交叉验证 → 预防治疗指征；
4. **Decide**：急性期曲普坦/NSAIDs（必要时）+ 缓解期天麻钩藤饮/川芎茶调散预防；诱因规避处方（天气/睡眠/饮食）；
5. **Act+护栏**：**MOH 哨兵**——止痛药月用量≥10天即告警（防反跳）；曲普坦禁忌审查（缺血性心脏病史）；
6. **Feedback→Learn**：月发作天数↓50%为有效；诱因-发作关联挖掘（天气/情绪/食物）回灌图谱；"息风"以发作频率+VAS 降幅作代理参数（补证侧③）。
7. **多快好省廉映射**：多=发作日记同时服务医/患/药三方；省=减少急诊与影像滥用；廉=预防用药降急性止痛药消耗。

### DSU-7 类风湿关节炎 · 寒湿痹阻证 → 独活寄生汤/乌头汤（FA15）

| 兼容性缺口 | 内容 |
|:---|:---|
| 病侧② | 自身免疫触发机制不完全清楚（遗传易感+环境触发） |
| 病侧③ | NSAIDs 肾损/消化道出血、糖皮质激素骨质疏松、DMARDs 骨髓抑制+感染 |
| 证侧② | RF/抗CCP 是**疾病指标而非证候指标**——寒湿痹阻无对应化验 |
| 证侧③ | 独活寄生汤补肝肾祛风湿效佳持久，但"寒湿"无评价参数 |

**Agent-Loop 设计原则：DAS28-寒湿闭环（激素减量引导）**
1. **Perceive**：28关节肿痛数自动录入+DAS28 评分+ESR/CRP（客观通道）+ 关节冷痛/遇寒加重/苔白腻（证候通道）；
2. **Retrieve**："关节冷痛+遇寒加重+舌淡苔白" → 寒湿痹阻证；
3. **Reason**：寒湿痹阻积分（冷痛0.35/遇寒加重0.25/苔白腻0.2/脉弦紧0.2）；与 DAS28 活动度分层交叉验证；
4. **Decide**：DMARDs(甲氨蝶呤)基线不动 + 独活寄生汤温经散寒通痹；**激素减量阶梯**（DAS28 缓解+证候积分↓ → 每4周减2.5mg 泼尼松）；
5. **Act+护栏**：感染哨兵（发热/白细胞↓，激素+DMARDs 双重免疫抑制）；肝肾功能监测（DMARDs+中药）；乌头类含毒性成分→药者Agent 用法用量强制审核；
6. **Feedback→Learn**：双终点=DAS28 改善+激素日剂量↓；**证候积分-炎症指标相关性建模**（寒湿积分 vs ESR/CRP）→ 补"寒湿无指标"缺口；乌头汤减毒增效案例库。
7. **多快好省廉映射**：廉=激素减量降骨质疏松/感染长期成本；好=证候-炎症相关性研究反哺辨证客观化；省=28关节自动评估减门诊负担。

### DSU-8 慢性肾小球肾炎 · 脾肾阳虚证 → 真武汤/济生肾气丸（GB40系）

| 兼容性缺口 | 内容 |
|:---|:---|
| 病侧② | 免疫复合物沉积机制复杂，部分病因不明 |
| 病侧③ | 激素/免疫抑制剂必然不良反应（感染、骨髓抑制、库欣、股骨头坏死） |
| 证侧② | 脾肾阳虚证（水肿/畏寒/舌淡胖）无特异指标 |
| 证侧③ | 真武汤温阳利水效佳，但"温阳"无评价参数 |

**Agent-Loop 设计原则：蛋白尿-温阳闭环（延缓肾衰）**
1. **Perceive**：24h尿蛋白定量/尿试纸+eGFR+血肌酐（客观通道）+ 水肿程度/畏寒/舌淡胖（证候通道）；
2. **Retrieve**："水肿+畏寒肢冷+腰膝酸软+舌淡胖" → 脾肾阳虚证；
3. **Reason**：脾肾阳虚积分（水肿0.3/畏寒0.25/腰膝酸软0.2/舌淡胖0.15/脉沉迟0.1）；与 CKD 分期交叉验证；
4. **Decide**：ACEI/ARB 保肾基线 + 真武汤温阳利水（附子先煎，药者Agent 强制审核）；激素/免疫抑制按病理类型（穿刺结果驱动）而非经验；
5. **Act+护栏**：**肾毒性零容忍**——eGFR<30 警示、含马兜铃酸类药材黑名单；**高钾哨兵**（ACEI+含钾中药叠加）；附子毒性监测（口舌麻木→停药）；
6. **Feedback→Learn**：双终点=尿蛋白↓30%+eGFR 稳定；证候演变轨迹（脾肾阳虚→阴阳两虚）与肾衰进展关联建模 → 提前干预窗口识别；"温阳"以尿蛋白降幅作代理参数。
7. **多快好省廉映射**：廉=延缓透析节省巨额医保支出（透析年费≈10万/人）；好=客观指标与温阳疗效直接挂钩；省=减少急性加重住院。

### DSU-9 特发性肺间质纤维化 · 气阴两虚痰瘀阻络证 → 生脉散合血府逐瘀汤（CB03.0）

| 兼容性缺口 | 内容 |
|:---|:---|
| 病侧② | **"特发性"=直接病因不明的最典型样本** |
| 病侧③ | 吡非尼酮/尼达尼布消化道反应+光敏；激素无效且有害（IPF 禁用）——西医"无特效药" |
| 证侧② | 进行性气短/干咳/舌暗红少苔——气虚/血瘀无指标 |
| 证侧③ | 生脉散益气养阴+活血化瘀，临床报告延长生存期，但无量化参数 |

**Agent-Loop 设计原则：肺功能-益气养阴闭环（生存期随访）**
1. **Perceive**：FVC/一氧化碳弥散量/6分钟步行距离+家用血氧仪（客观通道）+ 气短(改良MRC分级)/干咳/舌暗（证候通道）；
2. **Retrieve**："进行性气短+干咳+舌暗红" → 气阴两虚痰瘀阻络证；
3. **Reason**：复合积分（气短0.3/干咳0.2/舌暗0.2/乏力0.15/脉细涩0.15）；与 GAP 分期（疾病严重度）交叉验证；
4. **Decide**：抗纤维化药（吡非尼酮/尼达尼布）基线 + 生脉散益气养阴+血府逐瘀汤活血通络；肺康复+氧疗处方；
5. **Act+护栏**：**急性加重哨兵**——血氧<90% 或 气短MRC急升 → 急诊；药物相互作用（光敏+活血出血风险）；激素禁忌硬编码（IPF 不用激素）；
6. **Feedback→Learn**：双终点=FVC 下降斜率变缓+6分钟步行距离稳定/↑；长期生存数据随访 → 积累"中医药延缓 IPF 进展"循证队列（该单元学术价值最高，可产出论文）；"气虚"以 MRC/6MWD 作代理参数。
7. **多快好省廉映射**：好=补"气虚/血瘀无参数"缺口（肺功能代理）；廉=延缓进展节省靶向药（月费数千元）巨额开支；多=循证队列反哺教材与指南；省=减少急性加重住院。

7. **多快好省廉映射**：快=排便日记自动分析；廉=减少反复就医与检查支出；省=避免不必要结肠镜（省医保资源）。
