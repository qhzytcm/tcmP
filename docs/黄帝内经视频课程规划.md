# 《黄帝内经》视频课程规划 —— tcmP 教育平台示范课程

> 版本：v1.0 | 2026-08-20 | 依据：桌面《HDNJ音频理解(2).xls》（162 篇逐句转写 + 881 条 hermes 独到理解）

## 一、课程定位

| 维度 | 定位 |
|---|---|
| 课程性质 | tcmP 平台**首门示范课程**（中医经典 × AI 理解的范式样板） |
| 覆盖范围 | 《素问》81 篇 + 《灵枢》81 篇 = **162 篇全覆盖** |
| 内容底座 | 162 篇音频逐句转写（原文/注释/一致三类标注）+ **881 条 hermes 独到理解** |
| 差异化 | 不是朗读原文、不是传统注疏，而是 **AI 独到理解 × 中医临床落地**（每篇给出可执行的临床启示） |
| 平台衔接 | 挂接六者医圣引擎、ICD-11 桥接、图谱闭环（讲解→知识图谱→临床案例→反馈调优） |

## 二、视频规划（三级架构）

### 2.1 总架构：1 + 162 + 12

| 层级 | 数量 | 定位 | 单集时长 |
|---|---|---|---|
| L0 总览片 | 1 集 | 《黄帝内经》导论：成书、结构（素问/灵枢）、思维模型（阴阳五行/藏象/经络）、读书法 | 15-20 分钟 |
| L1 分篇讲解 | 162 集 | 每篇 1 集精华讲解（原文精读 + hermes 独到理解 + 临床启示） | 10-12 分钟 |
| L2 专题课 | 12 集 | 跨篇主题串讲（治未病/阴阳五行/藏象/经络针灸/体质/病机十九条/摄生/诊法…） | 15-20 分钟 |
| L3 案例课 | 12 集 | 典型临床案例 × 经典原文互证（每集 1-2 案例，展示"原文→辨证→方药→转归"） | 12-15 分钟 |

**合计：187 集**（L0×1 + L1×162 + L2×12 + L3×12），总时长约 **40 小时**。

### 2.2 单集讲解框架（L1 分篇，黄金结构）

每集固定八段，形成可复用的讲解模板：

| 段 | 内容 | 时长 | 来源 |
|---|---|---|---|
| ① 篇名破题 | 篇名含义、在全书中的位置与作用 | 1 分钟 | 原文 + 目录结构 |
| ② 原文精读 | 核心段落逐句解读（原文-条目） | 3 分钟 | 转写文本"原文-"段 |
| ③ 疑难注释 | 历代注家分歧点、关键词训诂 | 1.5 分钟 | 转写文本"注释-"段 |
| ④ 独到理解 | **hermes 独到理解**（该篇最亮点 1-3 条） | 2 分钟 | 881 条"理解-"条目 |
| ⑤ 思维模型 | 该篇对应的阴阳/五行/藏象等模型图 | 1 分钟 | 平台图谱 |
| ⑥ 临床启示 | 该篇对现代临床/养生的可执行启示 | 1 分钟 | 临床案例库 |
| ⑦ 案例印证 | 1 个典型案例（或案例预告） | 1.5 分钟 | 案例库（ICD-11 编码） |
| ⑧ 下篇预告 | 与下一篇的承接关系 | 0.5 分钟 | 全书脉络 |

### 2.3 视频制作流水线

```
① 原始音频（已有 162 篇转写）
   ↓
② hermes 独到理解（已有 881 条，精选每篇 1-3 条作"灵魂"）
   ↓
③ 讲解脚本（每集 1200-1500 字，八段模板，hermes 润色为口语化讲稿）
   ↓
④ 视觉素材（PPT 每篇 10-15 页 + 思维模型图：阴阳五行图/藏象表/经络图/治未病路径图）
   ↓
⑤ 录制（AI 数字人主播 或 真人讲师；建议双轨：AI 版先上线 + 专家版后补）
   ↓
⑥ 剪辑（字幕对齐转写时间轴：已有 开始/结束时间戳可直接生成逐句字幕）
   ↓
⑦ 质检（中医术语审校——ICD-11 编码挂接；教学审校——八段结构完整）
   ↓
⑧ 上线（tcmP 平台课程模块）
```

## 三、网络展示方案（视频 + PPT + 参考资料 + 典型临床案例）

### 3.1 课程页面结构（tcmP 平台，六者终端课程模块）

每篇（如"素问·上古天真论"）一个课程详情页，四件套分栏：

```
┌─────────────────────────────────────────────────────┐
│  《素问·上古天真论》  第 01 篇 / 162                │
│  视频区（主播放器 + 八段章节导航 + 逐句字幕）        │
├──────────┬──────────┬──────────┬─────────────────────┤
│ 📄 PPT   │ 📚 参考资料│ 🏥 临床案例│ 🧠 AI 理解库       │
│ 12 页    │ 原文/注家 │ 3 案例   │ 31 条独到理解       │
│ (下载/翻页)│ (在线/下载)│ (含 ICD-11)│ (可检索/问答)      │
└──────────┴──────────┴──────────┴─────────────────────┘
```

### 3.2 四件套明细

**① 视频区**
| 功能 | 实现 |
|---|---|
| 播放器 | HTML5 视频（HLS/MP4 双轨），支持倍速 0.5-2x |
| 章节导航 | 八段时间戳跳转（对齐转写时间轴） |
| 字幕 | 逐句 SRT 字幕（转写时间戳直接生成，双语文言文+白话） |
| 配套下载 | 音频 MP3（原有音频）+ 讲解稿 PDF |

**② PPT 区**（每篇 10-15 页，统一模板）
| 页序 | 内容 |
|---|---|
| 1-2 | 篇名 + 全书位置图（162 篇脉络图） |
| 3-5 | 原文核心段落（大字排版 + 白话对照） |
| 6-7 | hermes 独到理解（金句卡片） |
| 8-9 | 思维模型图（阴阳/五行/藏象/经络——Graphviz/matplotlib 生成） |
| 10-11 | 临床启示（可执行条目） |
| 12-13 | 案例（症状-舌脉-方药-转归四联卡） |
| 14-15 | 思考题 + 下篇预告 |

**③ 参考资料区**
| 类型 | 内容 |
|---|---|
| 原文 | 素问/灵枢原文电子版（分段对应转写） |
| 注家 | 王冰注、张介宾《类经》、马莳、张志聪等代表注 |
| 现代研究 | 每篇相关现代文献/实验研究（检索自平台知识库） |
| 编码桥接 | 病证条目关联 ICD-11 编码（不寐 7A00、心悸 MC81.2 等） |
| 延伸阅读 | 与本篇关联的其他经典章节（《难经》《伤寒论》互参） |

**④ 典型临床案例区**（案例库，每篇关联 2-5 例）
| 字段 | 示例（治未病·四气调神） |

## 六、认知方法主轴（新增：武夷山 wy30 系列集成）

> 依据：桌面《武夷山(1).xlsx》——夷陵君"内经素问篇"30 集（wy01-wy30）+ 30 条 Hermes Agent 独到注释 + 「0认知特色」方法论提炼。作为课程**贯穿始终的认知方法主轴**（不独立成章，而是织入每一集的"思维模型"段）。

### 6.1 八种认知算子（讲解中反复调用的思维工具）

| # | 算子 | 内经出处示例 | 讲解应用 |
|---|---|---|---|
| 1 | 分层观测 | 精-气-神三层（移精变气/宝命全形） | 任何病证先分物质/能量/信息三层，各层独立观测（色-脉-神） |
| 2 | 语境依赖 | 五味-脏腑-场景（脏气法时论） | 同一酸味对肝是补、对心是收——语义由场景锚定 |
| 3 | 时间-能量耦合 | 五运六气/天干地支/月相 | "给时间定性"：愈于夏、甚于秋（时间治疗学） |
| 4 | 一症多因·场景筛选 | 出汗至少五因（经脉别论） | 同一现象多成因，追问场景再定因 |
| 5 | 主趋势+个体修正 | 以胜相加+体质易感（玉机真藏论） | 模型给主趋势、体质做个体修正 |
| 6 | 顺逆调控 | 补泻=负反馈（八正神明论） | 刺实须虚、刺虚须实；顺呼吸为补 |
| 7 | 萌芽干预 | 上工救其萌牙（八正神明论） | 早期干预优于末期补救（治未病） |
| 8 | 默会知识 | 如临深渊、手如握虎 | 给目标不给方法——为临床直觉留空间 |

### 6.2 数学化表达（PPT 思维模型图素材，Graphviz/matplotlib 可绘）

|---|---|---|

### 6.3 现代科学映射（案例课的"科学对话"素材）

耗散结构（阴平阳秘=远离平衡态稳态）、勒夏特列原理（虚则补之实则泻之）、负反馈控制（刺实须虚）、信息论信道观测（观色察脉=信道解码）、量子观测（形=本征测量、神=隐变量）。
