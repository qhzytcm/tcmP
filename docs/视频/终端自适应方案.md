# 终端自适应配置与安装包方案 —— 素问01 视频课程

> 背景：浏览器不识别自定义 `.video` 扩展名（非标准 MIME）→ 已改用标准 `.mp4`（可播放）。
> 升级：终端自适应（浏览器 / 桌面应用 / 移动端 / 平台部署）四路方案。

## 一、问题与对策矩阵

| 终端 | 问题 | 对策 | 状态 |
|---|---|---|---|
| 浏览器（Chrome/Edge/火狐） | `.video` 不识别 | 标准 `.mp4` + `<source type="video/mp4">` | ✅ 已修复 |
| 桌面/手机（可安装应用） | 依赖浏览器 | **PWA**（manifest + Service Worker + 图标） | ✅ 已配置 |
| Windows 桌面（独立安装包） | 需安装程序 | **pywebview + PyInstaller → exe 安装包** | 🔄 可生成 |
| 移动端（Android/iOS） | 需应用 | PWA 添加到主屏（零安装）；APK 可选 | ✅ PWA / 可选 APK |
| 平台（网络教育平台） | 大视频传输 | 华为云 https + HLS 分片流媒体 | 📋 待部署 |

## 二、PWA 自适应应用（已配置）

**文件**（`docs\视频\`）：
- `manifest.json` —— 应用清单（名称/图标/主题色/standalone 全屏）
- `service-worker.js` —— 离线缓存（首次加载后离线可用）
- `icons\icon-192.png` / `icon-512.png` —— 应用图标（"素问·上古天真论"）
- HTML 已集成：`<link rel="manifest">` + SW 注册 + iOS 元标签

**使用**：浏览器打开 HTML → 地址栏出现"安装"按钮（或 菜单→安装应用）→ 生成桌面/手机独立应用（全屏、有图标、离线可看）。

> 注：SW 需 https 或 localhost 生效；file:// 下自动跳过注册（不影响视频播放）。

## 三、桌面安装包（pywebview 方案，可选生成）

```powershell
pip install pywebview pyinstaller
# 打包: 内置 HTML+视频+SW → 单文件 exe（Windows 双击安装即用）
pyinstaller --onefile --windowed --name "素问01上古天真论课程" launcher.py
```

- 优点：无需浏览器、离线观看、<60MB 单文件
- launcher.py 模板：pywebview 窗口加载本地 HTML（复用现有课件）
- 生成后可用 NSIS/Inno Setup 再做安装向导（.msi/.exe 安装包）

## 四、移动端

- **Android/iOS**：PWA "添加到主屏" = 图标应用（推荐，零成本）
- **APK 安装包**（可选）：WebView 封装 APK（Android Studio 或 `cordova` 打包）——如需，另建工程

## 五、平台部署（网络教育平台正式版）

```nginx
# 华为云 Nginx 站点配置（https）
location /course/suwen01/ {
    alias /var/www/course/suwen01/;
    try_files $uri $uri/ =404;
    # HLS 流媒体（视频转 m3u8 分片, 秒开+拖拽流畅）
}
```
1. 上传课件目录（HTML/mp4/manifest/SW/icons）至 `/var/www/course/suwen01/`
2. 视频转 HLS：`ffmpeg -i 素问01-上古天真论.mp4 -hls_time 10 -hls_list_size 0 course.m3u8`
3. https 证书（平台已有 zyyywaccn.com.cn 通配证书）→ PWA/全终端在线可用
