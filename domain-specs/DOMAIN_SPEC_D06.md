## 一、领域概述

### 1.1 领域定位

五官口腔学院是中医教材体系中聚焦人体头面部感官器官（眼、耳、鼻、喉、口）疾病防治的临床学科群。该领域以中医脏腑开窍理论为核心基础，整合中医辨证论治体系与局部器官的专科诊疗技术，形成"整体辨证—局部施治—内外结合"的学科特色。

五官学科在中医临床体系中具有"小而专、精而深"的特点：一方面，五官疾病在中医门诊中占比可达30%以上（流行病学数据）；另一方面，随着现代生活方式变化，干眼症、过敏性鼻炎、耳鸣耳聋、口腔溃疡、咽喉炎等疾病的发病率持续上升，对高素质五官科中医人才的需求日益迫切。

### 1.2 学科群构成

本领域包含两大模块：

| 模块 | 学科编号 | 学科数 | 学段范围 | 说明 |
|------|----------|--------|----------|------|
| 五官学科基础 | D06-S01 ~ D06-S05 | 5 | 本科U7-U8 | 中医眼科学、耳鼻喉科学、口腔科学、喉科学、五官科护理学 |
| 中西医结合与深化 | D06-S06 ~ D06-S10 | 5 | 硕士M1-M2 | 中西医结合眼科学、耳鼻喉科学，以及口腔内科学、颌面外科学、正畸学 |

### 1.3 编写原则

1. **传承与创新并重**：基础学科以经典传承为主，结合现代临床研究成果；深化学科突出中西医融合与技术创新。
2. **理论联系临床**：每门学科须设独立的"临床技能实训"模块，强调望闻问切在五官科的专科化应用。
3. **层级递进**：本科阶段构建"基础理论→辨证→常见病"知识链；硕士阶段强化"机制研究→疑难病→手术/治疗技术"。
4. **教材间横向协作**：S01-S05之间需统一五官解剖术语、辨证标准、常用方剂索引，避免各教材自成体系造成学生认知负担。

### 2.4 跨领域协作建议

1. **与D01领域（基础医学院）的协作**：五官科各教材的"基础理论"章节应引用D01-S01/D01-S02的通用表述，避免自创理论体系造成学生认知混乱。
2. **与D05领域（中医外科学）的协作**：口腔颌面部的外科疾病（S09）涉及中医外科的"消-托-补"三法，应与D05-S01保持方剂表述一致。
3. **外部医学协作**：S06-S07的中西医结合内容应邀请西医眼科学/耳鼻喉科学专家参与编审，确保西医内容的准确性。
4. **统一索引**：各教材应共享同一套"五官科常用方剂索引"和"五官科常用中药索引"，建议由S01-S03主编联合编制后分发各学科使用。

## 三、编写轮次分配

### 3.1 编写总策略

本领域10门学科分3个轮次完成编写，基本原则：

- **轮次3**（首批）：本科核心学科（S01-S03），须最先完成并投入使用
- **轮次4**（第二批）：本科深化学科（S04-S05）+ 硕士基础学科（S06-S07）
- **轮次5**（第三批）：硕士深化学科（S08-S10），依赖S03/S06成果

### D06-S01 中医眼科学

| 项目 | 内容 |
|------|------|
| **学科编号** | D06-S01 |
| **学科名称** | 中医眼科学 |
| **教材名称** | 《中医眼科学》 |
| **教材编号** | ENT-01 |
| **学段** | 本科 U7-U8（第七至第八学期） |
| **学分/学时** | 3学分 / 54学时（理论42学时 + 实训12学时） |
| **前置课程** | D01-S01（中医基础理论），D01-S02（中医诊断学），D01-S13（中医内科学上） |
| **编写轮次** | 轮次3 |
| **考核方式** | 理论笔试（70%）+ 实训考核（30%） |

#### 内容概要

本教材系统讲授中医眼科学的基本理论和临床诊疗知识。以"五轮学说"为核心理论框架，结合"八廓学说""肝开窍于目"等经典理论，构建眼病的病因病机—辨证分型—治法方药—预防调护的完整知识体系。教材涵盖从外眼病（胞睑疾病、两眦疾病）到内眼病（晶珠疾病、视衣疾病）的全谱系眼病，兼顾中医传统理论与现代眼科检查方法的融合应用。

#### 章节目录

| 章序 | 章名 | 核心内容 |
|------|------|----------|
| 第一章 | 绪论 | 中医眼科学发展史、现代学科地位、学习方法 |
| 第二章 | 眼的解剖与生理 | 中西医结合的眼球结构、视觉形成机制、附属器 |
| 第三章 | 眼科基础理论 | 五轮学说详解、八廓学说、肝开窍于目理论、目与经络关系 |
| 第四章 | 眼科辨证体系 | 五轮辨证、八纲辨证在眼科的应用、眼科常用辨证方法 |
| 第五章 | 眼科常用中药与方剂 | 明目药、退翳药、眼科常用方（杞菊地黄汤、石决明散、还睛丸等） |
| 第六章 | 眼科诊断与检查方法 | 中医望目诊法、视力检查、裂隙灯检查、眼底镜检查 |
| 第七章 | 胞睑疾病 | 针眼（麦粒肿）、胞生痰核（霰粒肿）、上胞下垂（眼睑下垂）、睑弦赤烂（睑缘炎） |
| 第八章 | 两眦疾病 | 流泪症、漏睛（慢性泪囊炎）、赤脉传睛、窝肉攀睛（翼状胬肉） |
| 第九章 | 白睛疾病 | 暴风客热（急性结膜炎）、天行赤眼（流行性结膜炎）、金疳（泡性结膜炎）、白睛溢血（结膜下出血） |
| 第十章 | 黑睛疾病 | 聚星障（单纯疱疹性角膜炎）、凝脂翳（化脓性角膜炎）、混睛障（角膜基质炎）、宿翳（角膜瘢痕） |
| 第十一章 | 瞳神疾病 | 瞳神紧小（虹膜睫状体炎）、五风内障（青光眼）、圆翳内障（白内障）、云雾移睛（玻璃体混浊） |
| 第十二章 | 眼底疾病 | 视衣脱离（视网膜脱离）、视瞻昏渺（黄斑病变）、消渴目病（糖尿病视网膜病变）、暴盲（视网膜中央动脉阻塞） |
| 第十三章 | 目视异常 | 近视、远视、弱视、斜视的中医诊治 |
| 第十四章 | 眼科疾病的中医外治法 | 点眼法、熏洗法、针灸治疗（眼周取穴）、耳穴疗法 |
| 第十五章 | 眼科急症与调护 | 眼科急症处理、术前术后调护、饮食起居指导 |

| 第十二章 | 职业相关性喉病 | 教师/歌手/主播的嗓音职业病、发声疲劳、声带疲劳综合征 |

| 第五章 | 牙髓病学 | 牙髓炎的病理分类、不可复性牙髓炎的根管治疗（RCT）、牙髓再生治疗 |

| 第八章 | 牙周-牙髓联合病变 | 诊断鉴别、联合治疗策略、中医辨证辅助治疗 |
| 第九章 | 口腔黏膜病鉴别诊断（上） | 白斑、红斑、红白斑的癌变风险评估、扁平苔藓的免疫治疗 |

| 第十一章 | 口腔疼痛管理 | 牙痛、灼口综合征、三叉神经痛的药物阶梯治疗、针灸镇痛 |
| 第十二章 | 口腔感染性疾病 | 疱疹病毒感染、念珠菌感染、多形性红斑、手-足-口病的系统治疗 |
