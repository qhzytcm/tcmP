## 1. 领域概述

### 1.1 领域定义

推拿学院（D04）是中医药120学科体系中以**推拿（Tuina/Chinese Therapeutic Massage）**为核心的临床学科群。推拿学是以中医理论为指导，运用手法作用于人体特定部位（经络、腧穴、经筋、皮部、关节等）以防治疾病的一门临床学科，是中医学的重要组成部分，具有操作简便、适应证广、疗效显著、无创伤、无毒副作用等特点。

### 1.2 学科范围

本领域涵盖以下10个学科方向，分为三个层次：

| 层次 | 学科编号 | 学科名称 | 属性 |
|------|----------|----------|------|
| 核心基础 | D04-S01 ~ S04 | 推拿学基础、手法学、诊断学、功法学 | 基础理论+基本技能 |
| 临床治疗 | D04-S05 ~ S07 | 推拿治疗学、小儿推拿学、脏腑推拿学 | 临床应用+专科方向 |
| 深化拓展 | D04-S08 ~ S10 | 一指禅推拿学、推拿康复学、国际推拿标准化 | 学术深化+国际视野 |

### 1.3 学科定位与特色

- **学科定位**：推拿学是中医学的优势学科之一，在骨伤科、神经科、儿科、康复医学等领域具有不可替代的地位。本领域定位于培养具备扎实推拿理论基础、规范手法操作能力、临床辨证施推能力的高素质推拿专业人才。
- **学科特色**：强调"手摸心会"的临床诊断方法、"以指代针"的治疗理念、手法操作的量化标准化、功法训练对推拿从业者的筑基作用。
- **国际影响**：推拿学已在全球180多个国家和地区传播，WHO已将推拿列入国际疾病分类（ICD-11）传统医学章节，国际标准化组织（ISO/TC 249）已制定多项推拿相关国际标准。

### 1.4 编写指导思想

1. **传承与创新并重**：系统整理传统推拿各流派（一指禅推拿、㨰法推拿、内功推拿、脏腑推拿等）的学术精华，同时吸纳现代生物力学、康复医学、疼痛医学的研究成果。
2. **理论-功法-手法-临床四位一体**：构建"理论奠基→功法筑基→手法训练→临床实践"的渐进式教材体系。
3. **量化与标准化**：推动推拿手法操作参数的量化（力度、频率、时间、角度），建立可教学、可考核的技术标准。
4. **中西医融合**：在保持中医特色基础上，融入解剖学、生物力学、神经生理学等现代科学知识，提升推拿学的科学内涵。
5. **分层教学**：本科阶段侧重基础技能与常见疾病推拿治疗，研究生阶段侧重学术流派深化与国际标准化研究。

本课程是推拿学院的核心技能课，系统教授推拿手法的分类体系、操作规范、训练方法和临床应用选择。涵盖六大类基本手法（摆动类、摩擦类、挤压类、叩击类、振动类、运动关节类）及复合手法的定义、操作要领、动作要领分解、力度频率参数、适应证和应用要点。注重手法的量化标准（力量、方向、频率、时间、节律）和标准化操作流程。

#### 内容概要

本课程是连接推拿基础理论与临床治疗的桥梁课程，着重培养推拿专科诊断能力。在中医诊断学（四诊合参、八纲辨证）基础上，突出推拿专科特色诊断方法——触诊（摸法）诊断体系，包括体表触诊、经筋触诊、关节触诊、痛点触诊、皮部诊察等。结合现代骨科检查方法（专科体格检查、神经检查、特殊试验检查）和影像学诊断（X线、CT、MRI在推拿科的解读要点），建立完整的推拿临床诊断思维。

#### 章节目录

| 章序 | 章名 | 核心内容 | 学时 |
|------|------|----------|------|

#### 内容概要

本课程是推拿学院的国际化拓展课程，面向推拿学硕士研究生的学术交流与标准化能力培养。涵盖推拿学在全球的传播现状（欧美、东南亚、大洋洲等地区的推拿发展情况）、推拿国际标准化进展（ISO/TC 249推拿标准、WHO传统医学推拿术语标准、世界针灸学会联合会推拿标准、世界中医药学会联合会推拿标准）、推拿的跨文化传播策略（英文术语规范、中英文双语教学能力）、推拿的海外立法与执业规范、推拿国际教育与学术交流。培养学生运用英语进行推拿学术交流和标准化研究的能力。

## 9. 附录：编写进度与质量要求

### 9.1 编写流程

```
需求调研 → 大纲编写 → 大纲审核（学术委员会）→ 初稿编写 → 内部审稿 → 修改 → 外审（2-3位同行专家）
  → 终审（学术委员会）→ 排版 → 校对印刷 → 试用反馈（1-2学期）→ 修订再版
```

### 9.2 编写质量控制标准

| 评审维度 | 权重 | 具体要求 |
|----------|------|----------|
| 科学性 | 30% | 内容准确无误，引证可靠（近5年文献占比≥40%），无医学错误 |
| 系统性 | 20% | 知识体系完整、逻辑连贯，章节间递进关系明确 |
| 实用性 | 25% | 临床操作内容详实可执行（实训学时占比≥1/3）、附有典型病案 |
| 创新性 | 10% | 反映推拿学科最新进展（生物力学、神经科学、康复医学等交叉研究成果） |
| 可读性 | 10% | 语言通顺、层次清晰、图表质量高、重点内容有标注 |
| 思政性 | 5% | 体现中医药文化自信、职业伦理、医德医风内容 |

### 9.3 教材编写体例要求

- 每个章节以**学习目标**（掌握/熟悉/了解三级）开头
- 正文中的**重要术语**首次出现时附英文
- 实训章节需列明**实训器材与准备**、**操作步骤**、**操作要点**、**常见错误**、**考核标准**
- 临床治疗章节的疾病部分需按统一模板编写（概述→病因病机→诊断→辨证分型→推拿治疗（取穴/手法/操作步骤/疗程）→预防调护→文献摘要）
- 每章末尾设**思考题**（3-5题）和**推荐阅读文献**（5-10篇）
- 全书末尾附**名词索引**、**主要参考文献**

### 9.4 数字资源配套要求

每本教材需配套建设以下数字资源：

| 虚拟仿真实验 | TU-02、TU-05≥2个 | HTML5/Unity |
| 教学大纲与教案 | 全套 | PDF/Word |

### 9.5 术语统一规范

- 本领域所有教材使用的推拿手法名称、穴位名称、疾病名称、辨证术语须在**领域术语委员会**审定的《推拿学领域术语表》基础上保持一致
- 与 D03（针灸学院）共同使用的经络腧穴术语须以国家标准《腧穴名称与定位》（GB/T 12346-2021）和《经络循行路线》（GB/T 40971-2021）为准
- 英文术语推荐参照 ISO 20389:2020《中医药—推拿基本术语》标准
