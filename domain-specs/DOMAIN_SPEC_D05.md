## 一、领域概述

### 1.1 学科定位

骨伤学院（中医骨伤科学）是中医学的重要组成部分，以中医理论为指导，研究人体骨、关节及其周围软组织的损伤与疾病的预防、诊断、治疗和康复的一门临床学科。本领域涵盖从基础理论到临床实践、从保守治疗到手术操作、从急性损伤到慢病康复的完整知识体系。

骨伤科学具有"动静结合、筋骨并重、内外兼治、医患合作"的特色治疗原则，在骨折复位、脱位整复、筋伤治疗、骨病防治等方面形成了一套独特的理论体系和技术方法。

### 1.2 培养目标

培养系统掌握中医骨伤科学基本理论、基本知识和基本技能，具备中医骨伤临床诊疗能力，能在各级医疗机构从事中医骨伤科临床、教学、科研工作的高素质专业人才。

### 1.3 学科体系结构

本领域12个学科方向按照"核心基础→临床治疗→专科深化"三阶段递进式设计：

```
第一阶段：核心基础（S01-S04）
  ├── S01 中医骨伤科学基础（骨科总论、病因病机、基础理论）
  ├── S02 骨伤诊断学（四诊、体格检查、诊断思维）
  ├── S03 骨伤影像学（X线、CT、MRI、超声在骨伤中的应用）
  └── S04 骨伤生物力学（骨骼力学、关节力学、固定力学）

第二阶段：临床治疗（S05-S08）
  ├── S05 中医正骨学（骨折复位固定、脱位整复）
  ├── S06 中医筋伤学（软组织损伤、韧带、肌腱疾病）
  ├── S07 中医骨病学（骨肿瘤、骨髓炎、骨结核等）
  └── S08 骨科手术学基础（围手术期、基本手术技术）

第三阶段：专科深化（S09-S12）
  ├── S09 关节损伤学（肩、肘、髋、膝、踝关节损伤）
  ├── S10 脊柱损伤学（颈椎、胸椎、腰椎损伤与疾病）
  ├── S11 骨伤康复学（功能评估、康复训练、康复评定）
  └── S12 骨伤手法学（正骨手法、理筋手法、特色手法）
```

### 2.3 边界界定特别说明

**D05-S12 骨伤手法学与 D04-S02 推拿手法学的区分：**

| 维度 | 骨伤手法学（D05-S12） | 推拿手法学（D04-S02） |
|------|----------------------|----------------------|
| 核心目标 | 关节整复、骨折复位 | 软组织松解、经络疏通 |
| 代表性手法 | 拔伸牵引、旋转回旋、提按端挤 | 一指禅推法、滚法、摩法、揉法 |
| 作用层次 | 骨关节、韧带 | 肌肉、筋膜、经络 |
| 适应证 | 骨折、脱位、关节错缝 | 颈肩腰腿痛、内科疾病 |
| 用力特点 | 瞬间爆发力、杠杆力 | 持续渗透力、柔和均匀 |
| 禁忌证 | 骨质疏松、骨肿瘤 | 急性感染、严重心血管病 |

### 2.4 西医院校基础医学协调

骨伤影像学（D05-S03）和骨科手术学基础（D05-S08）需与西医院校基础医学课程协调，确保内容深度与广度与临床执业医师资格考试要求衔接。

#### 内容概要

本课程是中医骨伤科学的入门与基础课程，系统介绍中医骨伤科学的发展史、基本理论、病因病机、诊法概要、治法概要等内容。重点讲述骨伤科的"气血津液学说""筋骨理论""动静结合原则"三大核心理论框架，以及骨伤科内治法（活血化瘀、接骨续筋、舒筋活络等）和外治法（正骨、固定、练功等）的基本知识。使学生建立中医骨伤科学的整体认知框架，为后续临床课程奠定理论基础。

#### 章节目录

| 章序 | 章名 | 核心内容 |
|------|------|---------|
| 第一章 | 绪论 | 中医骨伤科学的定义、范畴、发展简史（从《黄帝内经》到现代）、学术流派介绍（平乐郭氏、石氏伤科、清宫正骨等） |
| 第二章 | 骨伤科基础理论 | 筋骨理论（筋骨并重、筋骨失衡）、气血理论（气伤痛、形伤肿）、脏腑经络与骨的关系、肝肾与骨的关系 |
| 第三章 | 骨伤科病因病机 | 外力损伤（直接暴力、间接暴力、肌肉牵拉）、六淫邪毒（风、寒、湿、热）、七情内伤、瘀血与气血失调 |
| 第四章 | 骨折概论 | 骨折的定义、病因分类（闭合性/开放性、稳定性/不稳定性）、骨折移位方式（成角、侧方、缩短、旋转、分离）、骨折愈合过程与分期 |
| 第五章 | 脱位概论 | 脱位的定义、分类（新鲜/陈旧、完全/不完全）、脱位病理变化、脱位并发症 |
| 第六章 | 筋伤概论 | 筋伤的定义、分类（急性/慢性、扭伤/挫伤）、筋伤病理过程、筋与骨关节的关系 |
| 第七章 | 骨伤科诊法概要 | 骨伤科四诊特点（望诊观形、闻诊听声、问诊审因、切诊摸骨）、骨伤科常用检查法 |
| 第八章 | 骨伤科内治法 | 内治法三原则（初期攻、中期和、后期补）、分期辨证用药、常用骨伤内治方剂与中药 |
| 第九章 | 骨伤科外治法 | 外用药物（敷贴、熏洗、涂搽）、正骨手法基础、固定方法概述、练功方法概述 |
| 第十章 | 骨伤科固定技术概论 | 固定原理、小夹板固定、石膏固定、牵引固定、外固定架固定、内固定概述 |
| 第十一章 | 骨伤科练功疗法 | 练功疗法的作用原理、练功分类（局部练功、全身练功）、练功指导原则 |
| 第十二章 | 骨伤科护理与调养 | 骨伤患者体位护理、饮食调养（三期饮食原则）、功能锻炼指导、心理护理 |
| 第十三章 | 骨伤科临床思维 | 骨伤科辨证思维特点、常见证型与辨证要点、辨病与辨证结合模式 |
| 第十四章 | 骨伤科伦理与法规 | 医疗伦理、医患沟通、医疗纠纷预防、职业暴露防护、中医骨伤科执业规范 |
| 第十五章 | 骨伤科科研基础 | 骨伤科科研方法概述、文献检索、临床研究设计要点 |

#### 内容概要

本课程系统讲授骨伤科疾病的诊断方法和临床思维。涵盖骨伤科病史采集、全身与局部体格检查、神经与血管功能检查、骨关节功能评定、骨伤科常见症状的鉴别诊断等内容。注重培养学生在骨伤科临床实践中的望、闻、问、切四诊合参能力，以及逻辑推理与鉴别诊断能力。强调手法触诊在骨伤科诊断中的独特价值。实践环节安排大量的体格检查实训，使学生熟练掌握骨伤科标准检查流程。

#### 章节目录

| 章序 | 章名 | 核心内容 |
|------|------|---------|
| 第一章 | 骨伤诊断学概论 | 骨伤诊断学定义与范畴、诊断思维模式、诊断方法分类、诊断的准确性与可靠性 |

| 第四章 | 骨伤科闻诊与问诊 | 骨擦音与骨擦感、关节弹响与摩擦音、问疼痛（性质、部位、程度、诱因）、问功能障碍 |

| 第十章 | 血管功能检查 | 肢体血循环评估、动脉搏动检查、静脉回流评估、骨筋膜室综合征早期识别 |

| 第十二章 | 骨伤科常见症状鉴别诊断 | 颈肩痛的鉴别（颈椎病、肩周炎、肩袖损伤）、腰腿痛的鉴别（腰椎间盘突出、腰肌劳损、椎管狭窄）、关节痛的鉴别 |
| 第十三章 | 骨伤科急症识别 | 创伤性休克识别、脂肪栓塞综合征、骨筋膜室综合征、脊髓损伤早期判断 |

#### 内容概要

本课程系统讲授骨伤科常用影像学检查方法及其临床应用，包括X线、CT、MRI、超声及核医学在骨伤疾病中的应用。重点培养学生阅片能力，掌握骨折、脱位、骨病、关节疾病等的影像学特征和诊断要点。课程强调影像学与临床体征的结合分析，避免过度依赖影像学而忽视临床查体。实践环节安排大量的典型及疑难影像资料的阅片训练。

#### 章节目录

| 章序 | 章名 | 核心内容 |
|------|------|---------|
| 第一章 | 骨伤影像学总论 | 影像学发展简史、各种影像学方法的原理与特点、骨伤科影像学检查的合理选择、辐射安全与防护 |
| 第二章 | 骨与关节X线解剖基础 | 长骨X线解剖、关节X线解剖（肩、肘、腕、髋、膝、踝）、脊柱X线解剖、骨盆X线解剖 |
| 第三章 | 骨折的X线诊断 | 骨折线识别（横行、斜行、螺旋、粉碎、嵌入）、骨折移位判断、骨折愈合过程的X线表现、常见骨折漏诊与误诊分析 |
| 第四章 | 上肢骨折影像诊断 | 锁骨骨折、肱骨外科颈骨折、肱骨干骨折、肱骨髁上骨折、桡骨远端骨折（Colles、Smith、Barton）、腕骨骨折（舟骨骨折） |
| 第五章 | 下肢骨折影像诊断 | 股骨颈骨折（Garden分型）、股骨粗隆间骨折、股骨干骨折、胫骨平台骨折（Schatzker分型）、踝关节骨折（Lauge-Hansen分型）、跟骨骨折 |

#### 内容概要

本课程是骨伤科领域在硕士层次的整合提升课程，系统讲授骨伤科疾病的康复评定与康复治疗技术。内容包括功能评定方法、康复治疗技术（物理治疗、作业治疗、康复工程）、骨伤科各部位康复方案、中医康复技术（练功疗法、中药熏洗、针灸康复）、社区康复与家庭康复指导等。突出中医"动静结合"康复理念与现代康复医学的融合，培养学生制定个体化骨伤康复方案的能力。

### D05-S12：骨伤手法学

#### 基本信息

| 项目 | 内容 |
|------|------|
| 学科编号 | D05-S12 |
| 学科名称 | 骨伤手法学 |

| 编写轮次 | 第4轮 |

#### 内容概要

本课程是中医骨伤科学手法操作的高级深化课程，系统讲授并强化训练骨伤科各类手法的理论内涵、操作要领与临床应用。内容包括正骨手法（八法精要、复合手法）、理筋手法（舒筋法、弹拨法、点穴法）、脱位复位手法、关节调整手法、软组织松解手法、骨伤科特定部位的手法操作规范。突出"手摸心会、法从手出"的临床技能培养，注重手法操作的安全性与有效性评估。课程比D05-S05正骨学更聚焦于"手法技巧"本身，而正骨学侧重"骨折与脱位疾病的整体诊疗"。同时与D04-S02推拿手法学在软组织手法上有区分——骨伤手法以关节整复和骨折复位为核心导向。实践比例高，包含手法实训与临床带教。

#### 章节目录

| 章序 | 章名 | 核心内容 |
|------|------|---------|
| 第一章 | 骨伤手法学概论 | 骨伤手法学定义与学科定位、骨伤手法发展史（从《医宗金鉴·正骨心法要旨》到现代）、骨伤手法与推拿手法的关系与区别、手法操作基本原则（安全第一、明确诊断、因人而异） |
| 第二章 | 正骨基本功训练 | 手法感知训练（触感、手感、力感）、上肢力量与耐力训练（指力、腕力、臂力）、站位与身法训练（马步、弓步、身法协调）、手法的力学原理（力臂、支点、发力时机） |
| 第三章 | 正骨八法详解（上） | 手摸心会法（触摸诊断手法——骨折线定位、移位判断、骨擦感辨识）、拔伸牵引法（持续对抗牵引参数、牵引力与时间控制）、旋转回旋法（旋前/旋后角度控制）、屈伸收展法（屈曲/伸展/内收/外展的度数把握） |
| 第四章 | 正骨八法详解（下） | 成角折顶法（成角角度选择与反折时机）、端挤提按法（端法、挤法、提法、按法的单独与组合运用）、摇摆触碰法（侧方摇摆角度、纵轴叩击力度）、夹挤分骨法（骨间膜张力感知、分骨力方向） |
| 第五章 | 上肢正骨手法 | 锁骨骨折手法（膝顶复位法、外侧牵引复位）、肱骨外科颈骨折手法（外展/内收型的不同复位策略）、肱骨髁上骨折手法（伸直/屈曲型复位法、尺偏纠正）、前臂双骨折的分骨手法、Colles骨折的经典复位手法 |
| 第六章 | 下肢正骨手法 | 股骨颈骨折经筋束骨手法、股骨干骨折手法（牵引状态下端提按压）、胫骨骨折手法、踝关节骨折手法（Lauge-Hansen分型对应的复位手法）、跟骨骨折手法（Böhler角恢复手法） |
| 第七章 | 关节脱位复位手法（上肢） | 颞下颌关节脱位口腔内复位法（双手/单手）、肩关节前脱位（Hippocrates足蹬法、Kocher杠杆法、Milch法细节对比）、肘关节后脱位复位法、桡骨小头半脱位（旋后屈肘复位法） |
| 第八章 | 关节脱位复位手法（下肢） | 髋关节后脱位Allis法（仰卧位/俯卧位）、Bigelow问号法、Stimson重力法、膝关节脱位复位手法（牵引+提按复位）、髌骨脱位复位手法、跖跗关节脱位手法 |
| 第九章 | 理筋手法总论 | 理筋手法的分类体系（按压类、摩擦类、揉动类、叩击类、振动类、运动关节类）、理筋手法的作用机制（活血化瘀、舒筋通络、松解粘连、滑利关节） |
| 第十章 | 常用理筋手法详解 | 一指禅推法（沉肩、垂肘、悬腕操作要领）、滚法（吸定、滚动、压力均匀）、按法（指按、掌按、肘按）、揉法（鱼际揉、掌根揉、指揉）、拿法（五指拿、三指拿、抖动拿）、弹拨法（指弹拨、肘弹拨） |
| 第十一章 | 脊柱调整手法 | 颈椎调整手法（仰卧拔伸法、旋转复位法、定位旋转扳法）、胸椎调整手法（按压复位法、膝顶复位法、坐位旋转复位）、腰椎调整手法（斜扳法（Ferguson法）、后伸扳法、俯卧牵抖按压法）、骶髂关节调整手法 |
| 第十二章 | 骨伤科特定部位手法 | 肩部手法操作规范（肩关节松解六法、肩周炎扳法）、膝部手法（膝关节内、外侧间隙手法、髌骨活动度改善手法）、腰部手法（深部肌肉松解手法、骶棘肌弹拨法）、手法操作流程标准化 |
| 第十三章 | 手法治疗的辅助疗法 | 手法配合针刺（经穴透刺配合手法）、手法配合中药热敷（药透手法）、手法配合功能锻炼（练功动作与手法衔接）、手法配合拔罐与刮痧 |
| 第十四章 | 手法的安全性与禁忌证 | 手法操作的风险评估（骨质疏松评估、肿瘤筛查、血管条件评估）、骨伤手法的绝对禁忌证（骨肿瘤、严重骨质疏松、急性感染、脊髓压迫）、手法并发症的预防与处理（手法后疼痛加重、骨折移位、神经损伤） |
| 第十五章 | 手法流派与传承 | 主要骨伤手法流派介绍（平乐郭氏正骨手法特点、石氏伤科手法、清宫正骨手法流派、曹氏正骨、林氏正骨）、手法的规范化与标准化研究、手法的现代生物力学研究、手法传承模式与教学训练方法 |
