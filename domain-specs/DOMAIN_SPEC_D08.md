## 一、领域概述

### 1.1 领域定位

中医管理学院是中医药教材体系中聚焦医疗健康领域管理科学的核心学科群。该领域以现代管理学理论为基础，融合中医药行业的特殊性与规律，培养具备"懂医、善管、通法、能用"复合型能力的中医药管理人才。

中医药管理学科群的核心使命是：将现代管理科学（医院管理、经济学、市场营销、政策法规、人力资源等）与中医药行业的特有运行逻辑（辨证论治的个性化服务特征、中医药产业链条、医保政策特殊性、国际化传播规律等）有机融合，形成一套既符合管理学一般规律、又切合中医药行业实际需求的理论与实务体系。

随着"健康中国"战略的全面推进、中医药在医疗卫生体系中地位的提升、以及中医药国际化的加速推进，中医药管理领域的人才需求呈爆发式增长。中医药管理的特殊性体现在：

1. **医疗服务的公益性**：中医药服务兼具医疗公益性和市场经营性，管理需平衡社会效益与经济效益
2. **中医药产业链的复合性**：从种植/养殖 → 炮制加工 → 流通销售 → 医疗服务 → 康养服务的全链条管理
3. **政策的强干预性**：中医药发展受国家政策导向影响显著，政策研究是管理能力的重要组成部分
4. **标准化的紧迫性**：中医药的国际化亟需建立符合国际规则的知识产权保护与标准化体系
5. **信息化的后发优势**：中医药信息化建设虽起步较晚，但正借助数字技术实现跨越式发展

| 健康管理 | D08-S06 ~ D08-S09 | 4 | 本科U6-U8 | 健康管理、养生管理、公共卫生、医保管理 |

### 1.3 编写原则

1. **管理为本、中医为魂**：以现代管理学的成熟理论框架为基础，每一管理理论须与中医药行业的具体场景对接，避免"两张皮"——即空谈管理学理论而不聚焦中医药行业。
2. **政策敏感性与时效性**：中医药政策更新频繁（如《中医药法》配套政策、医保目录调整、国际标准制定动态），教材编写须建立"政策更新补充机制"，确保内容不过时。
3. **案例驱动教学**：每门学科须设独立案例模块，案例来源包括真实医院管理数据、中医药企业经营实例、政策实施效果评估等，体现"理论—案例—实务"三位一体。
4. **模块间纵向衔接**：S01-S05为核心管理基础，S06-S09为健康管理深化，S10-S14为国际化与交叉延伸。后一模块须引用前一模块的术语体系和理论框架。
5. **跨领域横向协同**：本领域管理学科须与D01（中医基础理论）、D07（中医信息学）等领域保持术语统一和内容协调。

### 2.4 跨领域协作建议

1. **与D01领域（中医基础医学院）的协作**：中医管理学院各教材中涉及的医学基础知识（如辨证论治的基本流程、常见证型的临床特征等）须引用D01-S01和D01-S24的标准表述，避免与基础医学教材内容冲突或重复。

2. **与D07领域（中医信息学）的协作**：S12（中医药信息管理）须与D07-S02（中医信息学）保持技术术语一致（如HTM系统架构、中医临床数据标准HL7 CDA等），建议两科共享"中医药信息化术语表"。

3. **与D01养生模块的边界协调**：S06（中医健康管理）和S07（中医养生管理）中的养生/治未病内容须与D01领域中已有的养生学教材明确分工——D01养生学聚焦"个体养生技术与方法"，本领域聚焦"养生服务的组织化管理和产业链运营"。

4. **与D03（药学院）的协作**：S02（中医药经济学）和S03（中医药市场营销）中涉及中药产业供应链分析的部分，应引用D03领域的中药资源学、中药炮制学等相关知识点，建立"从地头到药房"的全链条认知。

5. **统一术语管理**：本领域各教材应共享"中医药管理术语索引"（含管理学通用术语的中医药行业释义），建议由S01主编牵头编制。

## 三、编写轮次分配

### 3.1 编写总策略

本领域14门学科分4个轮次完成编写，基本原则：

- **轮次3**（首批）：核心管理基础（S01-S05），须最先完成。S01（医院管理学）作为整个领域的基石学科，须率先启动编写
- **轮次4**（第二批）：健康管理模块（S06-S09），依赖S01/S04的核心管理框架
- **轮次5**（第三批）：国际化与交叉模块主力（S10-S13），依赖前期成果
- **轮次6**（第四批）：最高阶综合学科（S14），依赖S06和S07的成果

### D08-S01 医院管理学

| 项目 | 内容 |
|------|------|
| **学科编号** | D08-S01 |
| **学科名称** | 医院管理学 |
| **教材名称** | 《医院管理学》（中医药院校版） |
| **教材编号** | MG-01 |
| **学段** | 本科 U4-U5（第四至第五学期） |
| **学分/学时** | 4学分 / 72学时（理论56学时 + 实训16学时） |

| **编写轮次** | 轮次3 |
| **考核方式** | 理论笔试（60%）+ 案例分析报告（25%）+ 实训考核（15%） |

#### 内容概要

本教材以现代医院管理学理论为基础，聚焦中医医院（含中西医结合医院）的特殊管理规律，系统讲授医院管理的核心职能与实务操作。教材从医院组织管理、医疗质量管理、护理管理、药事管理、财务与成本管理、后勤保障、信息化建设等维度展开，结合中医药行业的特殊属性（如中医辨证论治的服务个性化、中药调剂与煎煮的质量控制、中医护理特色技术管理、治未病服务流程管理等），建立一套既符合国际医院管理标准（JCI/等级评审）、又体现中医药特色的医院管理体系。教材注重案例教学，所选案例70%以上来自各级中医医院和中医药管理机构的真实管理实践。

#### 章节目录

| 章序 | 章名 | 核心内容 |
|------|------|----------|
| 第一章 | 绪论 | 医院管理学的基本概念、中医医院的发展历程与管理特点、学科地位与学习方法 |
| 第二章 | 医院组织管理 | 医院组织结构设计、中医医院科室设置特点（内科、外科、针灸科、推拿科、治未病科等）、医院章程与制度建设 |
| 第三章 | 医疗质量管理 | 医疗质量概念与评价指标、中医医疗质量特殊指标（辨证准确率、方剂配伍合理率、中医治疗率等）、质量管理工具（PDCA、品管圈、DRGs在中医院的应用） |
| 第四章 | 中医护理管理 | 中医护理管理体系、中医护理技术（艾灸、拔罐、刮痧、穴位敷贴等）的质量控制、中医护理人才培养、护理安全风险管理 |
| 第五章 | 药事管理 | 中药房管理（饮片验收、调剂、煎煮、代煎配送）、中药制剂管理（院内制剂的研发与备案）、中药质量追溯体系、药事管理委员会运作 |
| 第六章 | 门诊与急诊管理 | 门诊流程优化（预约挂号、分诊叫号、候诊管理）、中医急诊特点与管理、治未病中心（健康管理中心）的运行管理 |
| 第七章 | 住院管理 | 住院流程管理、中医优势病种的临床路径管理与单病种质量控制、床位资源调配、分级诊疗与双向转诊 |
| 第八章 | 医院感染管理 | 医院感染监测体系、中医诊疗器具的消毒规范（针灸针、火罐、刮痧板等）、医疗废物管理、传染病防控 |
| 第九章 | 医院财务管理 | 医院预算管理、成本核算（医疗服务项目成本、中药饮片成本）、医院绩效分配、医保结算管理、财务风险防控 |

### D08-S13 中医药人力资源与绩效管理

| 项目 | 内容 |

| **学科名称** | 中医药人力资源与绩效管理 |

#### 内容概要

本教材系统讲授中医药行业人力资源管理（HRM）与绩效管理的理论、方法与实务。教材以现代人力资源管理体系（规划—招聘—培训—绩效—薪酬—劳动关系六大模块）为框架，聚焦中医药行业人力资源的特殊性——包括中医药人才的培养路径（院校教育与师承教育的衔接）、中医药人才评价的特殊标准（中医临床思维能力的考察、师承经历的认定）、中医医疗机构的定岗定编（中医医师与西医医师的比例配置）、中医药高端人才的引进与留用（名老中医的柔性引进、学术继承人的培养）、中医药绩效管理（中医特色指标设计如辨证准确率、中医非药物治疗占比、中药饮片使用率等）以及中医药行业的薪酬激励设计。教材注重典型案例的深度剖析，培养学生具有中医药行业特色的人力资源管理实践能力。

#### 内容概要

本教材是中医管理学院领域的最高阶综合应用学科，系统讲授中医药康养产业的商业模式、运营管理与发展战略。教材以"健康中国"战略和老龄化社会为宏观背景，以中医药"治未病"和养生理论为内容基础，以现代产业经济学和战略管理理论为分析工具，围绕中医药康养产业的六大核心业态——康养小镇/康养社区、中医养生度假村、中医药健康养老、中医药康养旅游、中医药养生产品制造业、中医药康养金融保险——进行系统性的产业分析与运营管理论述。教材整合管理学、经济学、健康管理、养生管理、市场营销、政策法规等多学科知识，培养学生的产业视野与综合决策能力。教材以案例教学和实务项目为特色，要求学生分组完成康养产业项目策划书（商业计划书或可行性研究报告）。

### 附录C：与D01领域养生学的内容边界划分

本领域S06（中医健康管理）和S07（中医养生管理）与D01领域的养生学模块存在内容交叉，经协调明确分工如下：

| 内容领域 | D01养生学负责 | D08-S06/S07负责 |
