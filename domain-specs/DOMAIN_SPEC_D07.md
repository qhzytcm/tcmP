## 一、领域概述

### 1.1 领域定位

中医智能学院（Domain D07）是中医药学科体系中专门研究人工智能、数据科学与中医学交叉融合的学科方向群。本领域以中医基础理论、中医诊断学为核心知识前提，以现代人工智能技术（机器学习、自然语言处理、知识图谱、计算机视觉等）为核心方法论，致力于培养能够运用智能技术解决中医药领域实际问题的高层次复合型人才。

### 1.2 学科体系架构

本领域共设14个学科方向，按四大模块组织：

| 模块 | 学科编号 | 模块定位 |
|------|---------|----------|
| 智能基础（S01-S04） | D07-S01~S04 | 建立学科基础，覆盖AI导论、信息学、数据科学、知识图谱 |
| 智能诊断与决策（S05-S08） | D07-S05~S08 | 核心诊断智能化方向，覆盖诊断学NLP、问诊、机器学习 |
| 智能应用（S09-S11） | D07-S09~S11 | 应用落地方向，覆盖影像、电子病历、智能仪器 |
| 前沿与交叉（S12-S14） | D07-S12~S14 | 研究生层次前沿方向，覆盖计算中医、数字化诊疗、伦理治理 |

### 1.3 培养目标

通过本领域系统学习，学生应达到以下能力目标：

1. **基础能力**：掌握人工智能与数据科学的基本原理，能够运用Python等编程语言处理中医药数据
2. **核心能力**：能够构建中医知识图谱、设计智能诊断模型、开发中医自然语言处理应用
3. **应用能力**：能够完成中医影像分析、电子病历智能处理、可穿戴设备数据分析等实际任务
4. **前沿能力**：了解计算中医学、数字化诊疗的前沿方法，具备在中医AI领域从事科研的能力
5. **伦理素养**：理解中医药人工智能的伦理规范与治理框架，具备负责任的AI应用意识

### 1.4 技术栈要求

本领域所有教材需融入适量的计算示例，建议采用以下技术栈：

- **编程语言**：Python 3.8+
- **深度学习框架**：TensorFlow 2.x / PyTorch 2.x
- **科学计算**：NumPy, Pandas, Scikit-learn, SciPy
- **自然语言处理**：Jieba（中文分词）, HanLP, Transformers
- **知识图谱**：Neo4j, NetworkX, RDFlib
- **医学影像**：OpenCV, SimpleITK, MONAI
- **可视化**：Matplotlib, Seaborn, Plotly
- **开发工具**：Jupyter Notebook/Lab, VS Code, Git

### 2.2 跨领域深度依赖说明

#### 2.2.1 深度依赖：D01-S01（中医基础理论）

D01-S01为本领域提供最核心的知识基础——中医辨证体系的数字化基础。具体包括：

- **阴阳五行学说的数学模型化**：为D07-S05智能诊断提供辨证推理的符号化基础
- **脏腑辨证的逻辑结构**：为D07-S04知识图谱提供本体建模的理论框架
- **气血津液理论的系统性**：为D07-S08机器学习的特征工程设计提供理论依据
- **病因病机学的因果关系**：为D07-S12计算中医学的因果推断提供领域知识

> **教材编写要求**：D07-S05《中医智能诊断学》和D07-S04《中医知识图谱》中必须设置专门章节，介绍中医基础理论的数字转化方法，并提供对应的Python实现示例。

#### 2.2.2 深度依赖：D01-S02（中医诊断学）

D01-S02为本领域提供四诊信息的数字化基础：

- **望诊的数字化**：舌诊图像分析（D07-S09影像分析）、面诊特征提取
- **闻诊的数字化**：声纹分析、气味传感器数据建模
- **问诊的数字化**：结构化问诊单设计、自然语言理解（D07-S06 NLP、D07-S07智能问诊）
- **切诊的数字化**：脉象传感器信号处理、脉图智能识别

> **教材编写要求**：D07-S05《中医智能诊断学》和D07-S09《中医影像智能分析》中必须包含四诊信息数字化的完整技术方案章节。

#### 2.2.3 依赖：D02-S01（临床中药学）

D02-S01为D07-S04知识图谱和D07-S12计算中医学提供中药知识基础：

- **中药性味归经的知识表示**：为中药知识图谱构建提供领域本体
- **方剂配伍规律的挖掘**：为D07-S08机器学习中的关联规则挖掘提供应用场景
- **中药-靶点-疾病关系**：为D07-S12计算中医学的网络药理学分析提供数据基础

#### 2.2.4 依赖：D03-S01（经络腧穴学）

D03-S01为D07-S11智能仪器与可穿戴设备提供专业基础：

- **腧穴定位的标准化描述**：为智能针灸仪器提供定位算法基础
- **经络循行的空间表达**：为可穿戴设备的传感器布局提供理论依据
- **穴位电生理特性**：为智能诊疗仪器的信号采集与特征提取提供指导

#### 内容概要

本课程是研究生层次的前沿交叉课程，聚焦人工智能在中医药领域应用所带来的伦理、法律和社会治理问题。内容涵盖AI伦理基础理论（功利主义、义务论、责任伦理）、中医药AI的公平性与偏见（中医数据代表性、算法公平）、透明性与可解释性（可解释AI在中医临床中的重要性）、隐私与数据保护（患者健康信息保护、数据共享伦理）、AI与中医师的关系（人机协作、责任归属）、中医药AI的全球治理框架、以及中医药AI安全与风险管理。课程采用案例研讨式教学，选取国内外AI医疗及中医药AI领域的真实事件或假设案例进行深入探讨。
