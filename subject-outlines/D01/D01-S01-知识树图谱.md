## 一、总图（父子关系）

```
[根] R1 气一元论 ──┬────────────────────────────────┐
[根] R2 阴阳学说 ──┼──→ [干] T1 藏象学说            │
[根] R3 五行学说 ──┘        │                       │
[根] R0 中医学基本特点 ─────┤                       │
                            ├──→ [枝] B1 精气血津液 │
                            ├──→ [枝] B2 经络       │
                            └──→ [枝] B3 体质       │
                                                     ▼
                                            [枝] B4 病因
                                                     │
                                            [枝] B5 病机 ──→ [叶群] 防治原则
```

**推导链（必须成立的逻辑路径）**

1. 气一元论 → 万物由气构成 → 气的运动即"气机" → 气分阴阳 → **阴阳学说** → 阴阳配五行 → **五行学说**。
2. 阴阳＋五行 → 以"象"归纳脏腑功能 → **藏象学说**（五脏—六腑—奇恒之腑）。
3. 藏象 → 脏腑功能的物质载体 → **精气血津液**；藏象 → 脏腑之间的通路 → **经络学说**。
4. 藏象＋精气血津液 → 个体差异的稳定表达 → **体质学说**。
5. 体质＋藏象 → 外邪作用于人的结果 → **病因学说**。
6. 病因 → 正邪相争的动态过程 → **病机学说**（邪正／阴阳 → 气血津液 → 内生五邪／脏腑）。
7. 病机 → 逆转病机的原则 → **防治原则**。

> 任一环节缺失即构成"逻辑跳跃"。例：未经 ch8 气血津液就讲 ch13 气血失常 = 跳跃，G1 直接判系统性不通过。
